# 截图与录屏工具总览

> 梳理 Windows 平台下用于日常技术文档编写、问题复现记录、屏幕文字识别（OCR）及知识库图床工作流的截图与录屏工具。

这组笔记聚焦高效的屏幕捕获、标注与分发方案，重点掌握从“捕获屏幕 -> 标注处理 -> 本地归档 / 图床上传 -> 笔记引用”的自动化流水线。

| 顺序 | 笔记 | 学会什么 |
|---:|---|---|
| 01 | [[04-工具/截图与录屏/ShareX\|ShareX]] | 掌握 Windows 顶级开源截屏录屏与自动化工作流利器的核心机制、任务流水线与 Obsidian 联动配置。 |

## 最短总结

- 日常研发、硬件调试与知识管理中，高效、无干扰且支持高质量标注的截屏与动图录制工具是必备生产力基石。
- ShareX 是 Windows 下功能最强大的开源免费工具，其核心灵魂在于“任务流水线（Capture -> Tasks -> Destinations -> After Tasks）”与自定义热键工作流。
- 初次使用必须明确任务链配置，重点关闭默认上传公共图床的选项，优先建立“截图后自动保存至本地规范目录/复制到剪贴板”的稳健工作流。
