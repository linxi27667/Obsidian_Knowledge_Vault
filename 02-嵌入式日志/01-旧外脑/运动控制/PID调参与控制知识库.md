# Track_Car PID 调参与控制知识库

> 项目：MSPM0G3507 双轮差速循迹小车  
> 控制周期：5 ms（200 Hz）  
> 当前结论：远程 `+90°/-90°` 原地旋转已经完成调参，可冻结当前参数。  
> 最后更新：2026-07-15

## 1. 项目控制系统全景

本项目不是只有一个 PID，而是由多个控制环和状态机共同组成：

| 控制功能 | 控制器 | 输入/反馈 | 输出 | 当前用途 |
|---|---|---|---|---|
| 左右轮速度闭环 | 前馈 + 编码器 P | 目标轮速、编码器速度 | PWM | 所有闭环运动的内环 |
| 灰度循迹 | 离散 PD + 角速度阻尼 | 灰度位置误差、`gyro_z` | 左右轮差速量 | 正常循迹 |
| 航向 PID | 离散 PD | 目标航向、积分航向 | 左右轮差速量 | 丢线、直角弯 |
| 定角原地旋转 | 角度 P + 实测角速度 D | 相对角度误差、`gyro_z` | 左右轮目标速度 | 上位机指定 `-180°~+180°` 旋转 |
| 当前航向保持 | 与旋转共用 PD | 航向误差、`gyro_z` | 左右轮目标速度 | 原地抗扰保持朝向 |

控制链路如下：

```text
灰度/角度外环 -> 左右轮目标速度 -> 编码器速度内环 -> PWM -> 电机/车体
```

外环决定“车应该怎么动”，速度内环负责“左右轮实际跟上目标”。状态机和 Safety 模块始终位于控制器之上，通信、传感器或安全状态异常时可以直接撤销电机输出。

## 2. 通用离散 PID 实现

实现文件：`APP/Src/app_pid.c`、`APP/Inc/app_pid.h`。

### 2.1 公式

每次调用 `Pid_Compute(target, feedback)`：

```text
e[k] = target[k] - feedback[k]
I[k] = clamp(I[k-1] + e[k], -I_limit, +I_limit)
D_raw[k] = e[k] - e[k-1]
D[k] = alpha * D[k-1] + (1-alpha) * D_raw[k]
u[k] = clamp(Kp*e[k] + Ki*I[k] + Kd*D[k], -O_limit, +O_limit)
```

当 `integral_sep_threshold > 0` 且 `|e|` 超过阈值时，本周期停止累加积分，但 P、D 仍正常计算。

### 2.2 必须注意的实现特性

1. I 项没有乘 `dt`，D 项没有除 `dt`。因此项目中的 `Ki`、`Kd` 是“每采样点增益”，绑定当前 5 ms 控制周期。改变周期后必须重新换算和调参。
2. `deriv_alpha` 越大，保留的上一拍 D 越多，滤波越强、响应越慢。当前代码公式与 `user_tuning.h` 中“越大滤波越弱”的旧注释相反，应以公式为准。
3. 当前防积分饱和措施是积分限幅和积分分离，没有实现基于输出饱和的反算抗饱和。
4. D 是对误差微分。目标值突变时可能产生微分冲击，因此进入新状态时应调用 `Pid_Reset()`。
5. `target` 或 `feedback` 非有限数（NaN/Inf）时，控制器会复位并输出 0。

## 3. 左右轮编码器速度环

| `USER_MOTOR_SPEED_PID_KI` | 0.0 | 当前不使用积分 |
| `USER_MOTOR_SPEED_PID_KD` | 0.0 | 当前不使用微分 |
| `USER_MOTOR_SPEED_PID_ILIMIT` | 30 | 积分限幅 |
| `USER_MOTOR_SPEED_PID_OLIMIT` | 20 | PID 修正量限幅 |
| `USER_MOTOR_SPEED_PID_INTEGRAL_SEP` | 15 | 积分分离阈值 |
| `USER_MOTOR_SPEED_SCALE_LEFT` | 0.067 | 左编码器比例尺 |
| `USER_MOTOR_SPEED_SCALE_RIGHT` | 0.033 | 右编码器比例尺 |
| `USER_MOTOR_SPEED_FILTER_ALPHA` | 0.20 | 编码器低通的新样本权重 |
| `USER_MOTOR_SPEED_START_THRESHOLD` | 2.0 | 近静止判定 |
| `USER_MOTOR_SPEED_MIN_DRIVE_PWM` | 24 | 实测电机起转 PWM |

左右编码器分辨率不同：左侧 QEI 为 4 倍频，右侧 GPIO 计数约为 2 倍频，所以必须分别标定比例尺，不能强行使用同一个 scale。

### 3.2 控制公式

```text
filtered = filtered + 0.20 * (encoder_sample - filtered)
actual_speed = filtered / scale
correction = PID(target_speed, actual_speed)
pwm = target_speed + correction
```

这里 `target_speed` 同时充当前馈基础 PWM，PID 只修正负载、摩擦和左右机械差异。当前 `Ki=Kd=0`，实际是“前馈 + P”。这比纯 PID 更容易起步，也避免低速积分累积。

### 3.3 低速和方向保护

- 目标速度为 0 时立即复位 PID，并直接写 PWM=0。
- 轮速接近 0 且目标非零时，PWM 至少提升到 24，克服静摩擦。
- PWM 修正不得反向于目标轮速；如果修正结果方向相反，则输出 0，而不是反向制动。
- 最终 PWM 限制在 `-100~+100`。
- 切换到闭环时会清空 PID、滤波值并同步编码器基准，避免首次 delta 尖峰。

这套保护与旋转平滑度直接相关：如果外环在目标附近连续下发 `1、2、1、-1`，速度环会把每个很小的非零命令提升到起转 PWM 24，车就会明显点动。因此外环必须提供死区、滑行区和可靠的零命令。

## 4. 灰度循迹位置环

实现文件：`TASK/track.c`、`TASK/track.h`。

### 4.1 灰度误差

8 路传感器从左到右的权重为：

```text
S0   S1   S2   S3   S4   S5   S6   S7
-3.5 -2.5 -1.5 -0.5 +0.5 +1.5 +2.5 +3.5
```

归一化后计算加权平均，最大响应通道额外乘 1.5，提高靠近当前线位置的响应。负误差表示线在左边，正误差表示线在右边。全白时保持上一误差，由丢线状态机处理。

### 4.2 当前参数和公式

| 参数 | 当前值 |
|---|---:|
| `USER_LINE_PID_KP` | 5.0 |
| `USER_LINE_PID_KI` | 0.0 |
| `USER_LINE_PID_KD` | 1.0 |
| `USER_LINE_PID_ILIMIT` | 50 |
| `USER_LINE_PID_OLIMIT` | 30 |
| `USER_LINE_PID_DERIV_ALPHA` | 0.6 |
| `USER_LINE_FOLLOW_GYRO_DAMP` | 0.15 |

```text
line_turn = PID(target=line_error, feedback=0)
turn_output = line_turn - 0.15 * gyro_z
left_target  = base_speed + turn_output
right_target = base_speed - turn_output
```

灰度 PD 负责跟线，陀螺仪角速度项提供车身阻尼。车已经快速向某方向转动时，`-GDAMP*gyro_z` 会抑制继续加大的转向命令，减少直线左右摆动。

### 4.3 连续曲率变速

当前速度不是简单的“直道/弯道”两档跳变，而是按 `|line_error|` 线性插值：

```text
ratio = clamp(|error| / 2.5, 0, 1)
target_speed = 50 + (26 - 50) * ratio
```

当前参数：直道速度 50、弯道速度 26、每次渐变步长 2。误差越大，基础速度越接近 26；误差减小时平滑回到 50。循迹输出时左右轮最低目标均钳到 15，避免内侧轮反转导致急弯抖动。

### 4.4 循迹环调参判断

- 跟线迟钝、长期偏在线一侧：先加 `KP`。
- 左右误差频繁变号：先加 `KD` 或减 `KP`。
- 直道车身角速度仍明显摆动：小幅增加 `GDAMP`。
- 入弯反应迟缓：减小 `KD/GDAMP`，或降低弯道速度。
- 弯道冲出：先降 `VCUR`，不要立即用很大的 `KP` 硬拉。
- 通常保持 `KI=0`；只有确认存在稳定机械偏置且速度、传感器标定都正确后，才考虑极小的 KI。

## 5. 航向 PID：丢线与直角弯

当前参数：

| 参数 | 当前值 |
|---|---:|
| `USER_GYRO_PID_KP` | 3.0 |
| `USER_GYRO_PID_KI` | 0.0 |
| `USER_GYRO_PID_KD` | 0.5 |
| `USER_GYRO_PID_ILIMIT` | 30 |
| `USER_GYRO_PID_OLIMIT` | 30 |
| `deriv_alpha` | 0.4（代码中设置） |

丢线时以进入丢线前保存的 `target_heading` 为目标，用完整航向 PID 保持方向；500 ms 内仍未找回至少 2 路黑线则停车。没有可用陀螺仪时，才退化为根据最后一次灰度误差方向进行衰减修正。

直角弯以目标航向作为 setpoint，同样使用航向 PID。进入弯道后强制使用弯道速度 26。满足以下任一条件退出：

1. 航向误差进入 `±5°`；
2. 已转过至少 `55°`，并且中间传感器重新可靠捕获黑线；
3. 达到 1000 ms 超时保护。

这里的航向来自 MPU6050 角速度积分，不是磁力计绝对航向。零偏校准、温漂和振动会影响长时间精度。

## 6. 远程定角旋转控制器

### 6.1 为什么没有直接使用通用 PID

旋转控制器使用：

```text
error_deg = target_relative_deg - (heading - heading_baseline)
output = 0.80 * error_deg - 0.08 * gyro_z_deg_s
```

这是“角度 P + 实测角速度 D”，没有 I 项。通用 `Pid_Compute()` 的 D 是相邻两拍角度误差差值，单位是“度/采样点”；旋转需要的是 MPU6050 直接测得的物理角速度 `°/s`，才能在到达目标前按真实转动能量减速。因此旋转环独立实现。

正目标角命令左轮反转、右轮正转；负目标角相反。输出的单位是轮速目标，不是 PWM，后面仍经过编码器速度内环。

### 6.2 当前最终参数

| 参数 | 当前值 | 作用 |
|---|---:|---|
| `USER_ROTATE_PID_KP` | 0.80 | 角度误差转轮速 |
| `USER_ROTATE_PID_KD_RATE` | 0.08 | 实测角速度阻尼 |
| `USER_ROTATE_PID_MAX_SPEED` | 16 | 远离目标时最大轮速 |
| `USER_ROTATE_PID_MIN_SPEED` | 8 | 远区非零命令最小轮速 |
| `USER_ROTATE_PID_COAST_OUTPUT` | 2.4 | 输出小于此值时滑行，不强行驱动 |
| `USER_ROTATE_PID_FINE_ZONE_DEG` | 20° | 近区速度上限为 5 |
| `USER_ROTATE_PID_BLEND_ZONE_DEG` | 40° | 速度上限插值区外沿 |
| `USER_ROTATE_PID_FINE_MAX_SPEED` | 5 | 近区最大轮速 |
| `USER_ROTATE_PID_FINE_MIN_SPEED` | 3 | 近区非零命令最小轮速 |
| `USER_ROTATE_DONE_ERR_DEG` | 3° | 角度完成容差 |
| `USER_ROTATE_SPEED_SLEW_STEP` | 1/周期 | 非零目标速度渐变步长 |
| `USER_ROTATE_SETTLE_FRAMES` | 20 | 连续稳定帧数，约 100 ms |
| 稳定角速度阈值 | 6°/s | 完成判定角速度 |
| 超时 | `1000 + 50*|角度|` ms | 90° 时为 5500 ms |

### 6.3 分区减速

速度上限按剩余误差连续变化：

```text
|error| >= 40° : speed_limit = 16
|error| = 30°  : speed_limit = 10.5
|error| <= 20° : speed_limit = 5
```

20° 到 40° 之间线性插值，避免从高速突然切换到低速。控制器输出还要经过 `±speed_limit` 限幅。

当 `|output| < 2.4` 时下发 0，让车体利用惯性滑行。非零命令按每 5 ms 一个速度单位渐变；但目标为 0 时立即归零，不再走 `5→4→3→2→1→0`。这是因为每一个很小的非零目标都可能被速度内环提升为起转 PWM 24。

### 6.4 完成逻辑

角度一进入 `±3°`：

1. 左右轮目标立即归零；
2. `turn_output` 归零；
3. 不再主动反向刹车，只让残余角速度自然衰减；
4. 只有角度仍在 `±3°` 且 `|gyro_z|<=6°/s` 连续 20 帧，才报告 `complete`；
5. 如果滑出角度容差，则恢复控制。

这个策略有意用少量终点角度误差换取更平滑的停车。把容差强行改成 0 或 1°，会让电机在静摩擦区频繁正反补偿。

## 7. 2026-07-15 旋转调参完整复盘

### 7.1 初始问题

最初的实机现象是旋转时严重抖动、接近目标后反复正反补偿，部分动作最终超时。问题不是单纯“KP 太大”，而是外环、速度内环和电机死区叠加：

- 角度接近目标后仍持续输出小命令；
- 小轮速命令会被速度环提升到最小起转 PWM 24；
- 速度斜坡在停车时逐级经过 `±1/±2`，造成连续点动；
- 角速度 D 阻尼过强时，可能在目标前直接算出反向制动力矩；
- 固定的近区速度上限切换会带来不连续手感。

### 7.2 本次采取的调整

1. 将旋转完成容差统一为可配置的 `±3°`。
2. 增加 `Track_Rotate_AngleInside()`，把“已进入角度容差”和“角度、角速度均稳定”分开处理。
3. 进入 `±3°` 后立即把电机目标置零，在容差内不主动反转刹车。
4. 停车命令绕过速度渐变，直接变为 0，消除 `±1/±2` 触发 PWM 24 的点动。
5. 增加 20° 到 40° 的连续速度上限插值：近区上限 5，远区上限 16。
6. 保留输出滑行阈值 2.4，让很小的控制需求不触发电机静摩擦补偿。
7. 最后一轮只把角速度阻尼 `Kd_rate` 从 0.10 降到 0.08，其他参数不动。

坚持“一轮只改一个关键变量”，才能从下一轮日志判断变化究竟由哪个参数造成。

### 7.3 为什么把 Kd_rate 从 0.10 降到 0.08

上一轮曾出现一条典型日志：

```text
actual=-81.6°  error=-8.3°  rate=-101.3°/s
LeftTarget=-1 RightTarget=1  LeftPwm=-21 RightPwm=21
```

当 `Kd_rate=0.10`：

```text
output = 0.80*(-8.3) - 0.10*(-101.3)
       = -6.64 + 10.13
       = +3.49
```

角度还差 `-8.3°`，但强 D 项已经把输出翻成正方向，于是电机主动反向制动，体感像突然“拽一下”。

改为 `Kd_rate=0.08`：

```text
output = 0.80*(-8.3) - 0.08*(-101.3)
       = -6.64 + 8.10
       = +1.46
```

`1.46 < coast_output 2.4`，因此控制器选择滑行而不是反向驱动。这样既保留了角速度阻尼，又消除了明显反向刹车。

### 7.4 最终实机结果

最后一轮 `+90°/-90°` 共 6 次：

| 目标 | 结果 | 最终角度 | 日志误差 | 耗时 |
|---:|---|---:|---:|---:|
| +90° | complete | +87° | +2° | 1928 ms |
| -90° | complete | -88° | -1° | 2108 ms |
| +90° | complete | +87° | +2° | 2184 ms |
| -90° | complete | -90° | 0° | 2041 ms |
| +90° | complete | +87° | +2° | 2000 ms |
| -90° | complete | -87° | -2° | 1865 ms |

汇总：

- 完成率：6/6；
- 平均耗时：2021 ms；
- 最短/最长：1865/2184 ms；
- 所有结果均在 `±3°` 验收范围内；
- 原来的末段强反向制动已消失；
- 未出现 `Target=±1/±2` 对应约 24 PWM 的低速点动。

因此旋转参数可以冻结。`+90°` 多次停在约 `87°` 是 `±3°` 平滑完成策略的预期结果，不应为了日志上的零误差重新引入末端抖动。

## 8. 当前航向保持

航向保持复用旋转控制公式 `0.80*角度误差 - 0.08*gyro_z`，但有独立的执行边界：

| 参数 | 当前值 |
|---|---:|
| 航向死区 | 2° |
| 稳定角速度 | 8°/s |
| 最大轮速 | 14 |
| 最小非零轮速 | 6 |
| 滑行阈值 | 1.5 |

误差和角速度均进入死区时立即置零；超出时调用同一个旋转 PD 和速度渐变逻辑。它是相对 MPU 积分航向保持，不是带磁力计的绝对方位锁定。

## 10. 自动调参模块

项目有两类自动建议机制，但它们主要服务循迹，不负责本次定角旋转参数。

### 10.1 本地规则引擎

- 误差频繁变号：`KD * 1.5`；
- 超过一半帧 `|le|>2`：`KP * 1.2`；
- 平均 `|gyro_z|>2`：`GDAMP + 0.05`；
- 丢线帧过多：`VCUR - 5`；
- 直角状态过多：`RATHR + 0.3`。

规则建议只能作为候选，不能代替实机安全验收。例如弯道角速度本来就大，仅凭全局平均 `|gyro_z|` 判断直道抖动可能误判，应结合状态分段分析。

### 10.2 受约束坐标搜索

优化顺序：先搜索 `KP/KD/GDAMP/RATHR`，再搜索 `VBASE/VSTR/VCUR`，自动锁定 `KI=0`。每个候选做两组独立 5 圈试验，任何丢线、故障、超时或陈旧帧都回滚。

候选按以下优先级排序：

```text
完成且零故障 > P95 圈时 > 横向误差 RMS > 输出饱和率 > 左右轮速差
```

初始步长为 `KP 0.5、KD 0.2、GDAMP 0.02、RATHR 0.2、速度 2`；无改进时减半，最多测试 24 个候选。

## 11. 推荐的实机调参流程

### 11.1 调参前

1. 确认电池电压、轮胎、负载和测试地面一致。
2. 完成 MPU6050 静止零偏校准和黑白灰度校准。
3. 单独确认左右编码器符号、比例尺和电机方向正确。
4. 架空测试速度环，确认目标正负不会产生相反方向 PWM。
5. 保留急停，首次动作使用低速和宽阔场地。

### 11.2 调参顺序

1. 先调左右轮速度环和 scale，确保内环稳定。
2. 再调外环 P，使系统能到达目标但不过度激进。
3. 加 D/角速度阻尼抑制超调和振荡。
4. 最后处理速度上限、减速区、死区、滑行阈值和完成条件。
5. 每轮只改一个关键参数，并至少重复正反方向各 3 次。
6. 稳定后再提远区速度；不要同时提速度并降低阻尼。

### 11.3 旋转日志判据

每轮至少检查：

- 所有动作是否 `complete`，有无 timeout；
- 最终角度是否在 `87°~93°` 或 `-93°~-87°`；
- 最后 10° 内是否出现与目标方向相反的轮速/PWM；
- 是否出现 `Target=±1/±2` 但 PWM 接近 24；
- 完成时间是否稳定在约 2 秒；
- 正负方向结果是否存在持续偏差；
- 同样参数在不同电量和地面上是否仍稳定。

## 12. 参数症状速查

| 现象 | 优先检查 | 典型处理 |
|---|---|---|
| 远离目标也转得慢 | 最大速度、KP、速度环 scale | 先确认内环，再小幅加 KP/最大速度 |
| 接近目标冲过头 | Kd_rate、近区上限、减速区 | 加阻尼或更早减速 |
| 目标前突然反向拽车 | Kd_rate 过大 | 小幅减 Kd_rate，提高滑行作用 |
| 末端来回点动 | 容差太小、小命令触发最小 PWM | 立即零命令、加滑行区、合理容差 |
| 正反方向差异大 | 电机/编码器 scale、摩擦、重心 | 分别标定左右 scale，检查机械结构 |
| 直线左右摆 | 循迹 KP 大、KD/GDAMP 小 | 降 KP 或加 KD/GDAMP |
| 入弯迟钝 | KD/GDAMP 大、VCUR 不合理 | 小幅减阻尼或降低弯道速度 |
| 长期存在静差 | 传感器/电机偏置 | 先校准，最后才考虑小 KI |
| 一改周期行为全变 | 离散 PID 未归一化 dt | 保持 5 ms，或按新周期换算增益 |
