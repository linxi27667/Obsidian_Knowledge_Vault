# 射频电路公式与实验速查表

## 核心概念

- ==公式只能给出一阶判断，最终要回到器件数据手册、叠层和实测==。
- ==频率越高，寄生参数越重要==；同一颗电容在低频、高频和自谐振以上的行为可能完全不同。
- ==13.56 MHz RFID 主要是线圈近场耦合，不能用 2.4 GHz 远场天线公式直接替代设计==。

## 一、基本阻抗

~~~text
电容：X_C = 1 / (2π f C)
电感：X_L = 2π f L
串联/并联复阻抗：Z = R + jX
~~~

例：C=100 nF、f=13.56 MHz 时，理想容抗约 0.117 Ω；但实际还受 ESL、ESR、封装和自谐振影响，因此不能把结果当成真实阻抗。

## 二、LC 谐振

~~~text
f0 = 1 / (2π√(LC))
~~~

在谐振点附近，电感和电容的电抗互相抵消。串联谐振和并联谐振的电流/电压特征不同；匹配网络的具体拓扑决定它是低通、高通、带通还是阻抗变换网络。

## 三、波长与传输线

~~~text
λ = c / f
2.4 GHz自由空间波长 ≈ 125 mm
13.56 MHz自由空间波长 ≈ 22.1 m
~~~

四分之一波长只适合某些天线结构的初步估算；PCB 天线的有效长度受介质、地平面、弯折、端部效应影响。13.56 MHz 的读卡线圈依靠近场磁耦合，尺寸远小于自由空间波长是正常的。

## 四、反射与驻波

~~~text
Γ = (ZL - Z0) / (ZL + Z0)
VSWR = (1 + |Γ|) / (1 - |Γ|)
~~~

理想匹配时 ZL=Z0，Γ=0，VSWR=1。实际要明确测量参考平面；连接器、同轴线、匹配网络和天线位置都会改变结果。

## 五、晶振负载电容

常见近似：

~~~text
CL ≈ (C1 × C2) / (C1 + C2) + Cparasitic
~~~

因此不能看到“别人用 27 pF”就直接复制。需要根据晶振要求的 CL、芯片内部电容、焊盘与走线寄生、目标频率误差共同选择。

## 六、Buck 输出电压

~~~text
VOUT = VREF × (1 + Rtop/Rbottom)
~~~

还要检查：

- 电阻容差；
- FB 引脚漏电流；
- 前馈电容对环路的影响；
- 输出电容的有效容量；
- 电感纹波和峰值电流；
- 输入电压下降后的占空比和裕量。

## 接口 / 器件 API 速查表

| 参数 | 公式/意义 | 用途 |
|---|---|---|
| X_C | 1/(2πfC) | 判断电容对某频率的阻碍 |
| X_L | 2πfL | 判断电感对某频率的阻碍 |
| f0 | 1/(2π√LC) | LC谐振估算 |
| Γ | 反射系数 | 判断阻抗失配 |
| VSWR | 驻波比 | 天线/传输线匹配指标 |
| λ | c/f | 天线长度初估 |
| VOUT | VREF(1+Rtop/Rbottom) | Buck反馈设计 |

## 完整示例：从目标频率反推第一判断

~~~text
目标：判断 C 是否能旁路某个频率
1. 代入 X_C = 1/(2πfC)
2. 与电源网络/负载阻抗比较
3. 检查封装与自谐振频率
4. 将电容放在最短回路
5. 上电后在实际芯片脚测纹波
~~~

这套流程比单纯说“电容对高频短路”更可靠。

## 附录：单位换算

- 1 mil = 0.0254 mm
- 10 mil = 0.254 mm
- 16 mil = 0.4064 mm
- 50 Ω不是一个长度单位，必须说明频率、叠层、线宽、参考层和介质。
