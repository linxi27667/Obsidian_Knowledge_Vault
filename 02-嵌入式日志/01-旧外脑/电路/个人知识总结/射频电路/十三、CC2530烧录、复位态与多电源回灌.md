# CC2530 烧录、复位态与多电源回灌（把目标板链路单独验证）

> 本次对话暴露了两个容易混在一起的问题：烧录期间蜂鸣器响、ESP 支路供电时其他 3.3 V 网络异常。先拆成独立测试，不要把一个现象当成另一个的根因。

## 核心概念

- ==电脑识别到 CC Debugger，只证明 USB 到调试器这一段枚举成功==；不代表目标板的 VDD、RESET_N、DC、DD 或线缆方向正确。
- ==复位期间 MCU 固件没有运行==；开机初始化代码不能保证烧录/复位时蜂鸣器默认关闭。
- ==磁珠能滤高频噪声，不是直流隔离器==；独立供电测试必须断开直流路径并考虑信号线回灌。
- ==蜂鸣器复位态响的电气解释仍是待验证假设==；需测 CC2530 P0_0 与 S8050 基极波形，不要只按对话建议盲改电阻。

## 一、CC2530 烧录接口检查

本次原理图中 10 针排针 P1 标注的关键网络为：

| 排针 | 网络 | 核对目标 |
|---:|---|---|
| P1-1 | GND | 与调试器地导通 |
| P1-2 | VCC3V3_CC2530 | 目标板电压约 3.3 V，按调试器供电模式配置 |
| P1-3 | P2_2 / DC | 连到 CC2530 Debug Clock 管脚 |
| P1-4 | P2_1 / DD | 连到 CC2530 Debug Data 管脚 |
| P1-7 | RESET_N | 低有效复位，确认没有被其他电路拉住 |

排线方向以调试器官方定义、连接器 Pin 1 标记和万用表连通检查为准；不要仅凭彩色线或照片猜方向。逐项测：目标 VDD、GND、DC、DD、RESET_N；并检查 DC/DD/RESET_N 互相及对地没有短路。CC2530 Pin40 `DCOUPL` 是内部核心稳压输出，原图 C1=1 µF 对地；它不是外部 3.3 V 供电点。

建议的目标板最小化步骤：

1. ESP 电源支路断开，先测 CC2530 3.3 V。
2. 测 Pin39/DVDD 电源，并按器件手册确认 Pin40/DCOUPL 内部电源是否正常。
3. CC Debugger 接目标板前核对排针方向和目标供电方式。
4. 暂时断开 RC522、ESP UART 和非必要外设，保留 CC2530 与烧录接口。
5. 确认 P1-3/P1-4/P1-7 到芯片引脚网络正确后，再尝试擦写/校验。

## 二、烧录时蜂鸣器响：先测复位电平

原理图 PDF 可见：蜂鸣器由 3.3 V 供电，Q2 为 S8050 低边驱动；`BUZZER` 通过 R17=1 kΩ 接基极，R18=10 kΩ 下拉；`BUZZER` 网络连接到 CC2530 P0_0。

一种可能是：复位/下载时 P0_0 的复位默认配置和外部上拉状态使基极出现足够电压，S8050 导通。这个解释**尚未通过示波器/电压测量验证**，而且具体 GPIO 默认配置应查当前 CC2530 数据手册。

检查流程：

1. 在不接蜂鸣器或限制蜂鸣器电流的条件下，测烧录器拉低 RESET_N 前后 P0_0 电压。
2. 同时测 S8050 基极相对发射极电压，确认是 GPIO 偏置还是焊接/网名错误。
3. 核对 Q2 管脚顺序、R17/R18 实际值、蜂鸣器极性和 P0_0 网表。
4. 若确认为复位态误导通，再设计“硬件默认关闭”的驱动极性/电阻网络；修改下拉值前核对 GPIO 输出电流和正常鸣叫能力。

不要把“R18 改成 2.2 kΩ”当作已验证的定论。改变下拉会提高正常高电平驱动时的分流电流，需计算并实测。

## 三、磁珠后的 3.3 V 网络并非隔离电源

本次原理图标注 L3/L4/L7 为 `BLM18PG121SN1D`：

```text
VCC3V3 ─ L3 ─ VCC3V3_ESP12F
        ├ L4 ─ VCC3V3_CC2530
        └ L7 ─ VCC3V3_RC522
```

磁珠在直流下是低阻连接。因此若把外部 3.3 V 接到 `VCC3V3_ESP12F`，它可能经 L3 反向给主电源网供电，再经 L4/L7 影响 CC2530/RC522。类似地，即使拆下 ESP 电源 0 Ω，UART TX/RX 仍可能通过 GPIO 保护结构回灌。

要验证独立电源：

- 断开磁珠或设置的电源跳线，确认欧姆档下外部电源点与其他电源域不再直通；
- 保持信号连接时要防回灌，必要时暂拆 R9/R10（原图 22 Ω）或加适当电平隔离；
- 多电源共地，避免两路 3.3 V 输出直接并联；
- 分别测各电源网，确认没有“看似独立、实际由其他域回供”的假象。

## 四、蜂鸣器/烧录/供电的隔离测试矩阵

| 测试 | ESP 电源 | ESP UART | CC2530/调试器 | 观察目标 |
|---|---|---|---|---|
| A | 断开 | 断开 | CC2530 单独烧录 | 是否仍烧录失败/蜂鸣 |
| B | 断开 | 接通 | CC2530 单独烧录 | UART 是否引发回灌或复位态干扰 |
| C | 独立外供，主 3.3 V 隔离 | 断开 | CC2530 上电 | 检查电源域真实隔离 |
| D | 原板载供电 | 接通 | 全系统运行 | 记录 VOUT、FB、复位和蜂鸣器状态 |

每次只改变一项，记录电压、蜂鸣器状态和调试器结果。若目标板供电不稳定，先不要把 IAR 通信失败归因于软件或驱动。
