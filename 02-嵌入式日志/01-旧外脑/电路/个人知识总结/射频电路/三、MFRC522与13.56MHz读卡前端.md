# MFRC522 与 13.56 MHz 读卡前端

## 核心概念

- ==MFRC522 是 13.56 MHz 非接触式读写前端==，主机通过 SPI、I²C 或 UART 访问寄存器和 FIFO。
- ==27.12 MHz 是晶振/时钟频率，射频载波为 13.56 MHz==，不要把它们当成同一个频率。
- ==TX1/TX2 是发射输出，RX 是接收输入，VMID 是内部参考节点==；这些不是普通数字 GPIO。
- ==MFRC522 底部散热焊盘不要求必须连接==，NXP 数据手册允许不连接，也允许连接到 DVSS。
- MFRC522 已进入不推荐新设计状态；如果是量产项目，应评估 NXP 推荐的替代器件。

## 一、内部功能框图

~~~text
主控 SPI/I2C/UART
        │
寄存器/FIFO/Contactless UART
        │
模拟接口：调制、解调、接收放大
        ├─ TX1 ─┐
        ├─ TX2 ─┴─ 匹配网络 ─ 13.56 MHz 线圈
        ├─ RX  ←── 线圈回波/负载调制
        └─ VMID ── 内部模拟参考
~~~

读卡器给线圈施加 13.56 MHz 能量，卡片通过负载调制改变场，MFRC522 的接收链路从 RX 端检测变化。卡片的通信不是“天线收到 TTL 高低电平”，而是模拟载波上的调制和解调，最后才变成数字数据。

## 三、主机接口选择

MFRC522 在上电或硬复位后，通过控制脚电平自动判断主机接口。SPI 是最适合本项目练习的方案：

| MFRC522 | 主控 | 方向/说明 |
|---|---|---|
| SCK（脚29） | SPI SCK | 主控输出 |
| MOSI（脚30） | SPI MOSI | 主控输出到 MFRC522 |
| MISO（脚31） | SPI MISO | MFRC522 输出到主控 |
| NSS（脚24） | GPIO/CS | 主控片选，低有效 |
| IRQ（脚23） | GPIO/EXTI | 可选，用于中断 |
| NRSTPD（脚6） | GPIO/RESET | 建议可控 |
| PVDD/DVDD/AVDD/TVDD/SVDD | 3.3 V | 按参考设计去耦 |
| 所有相关 VS/S 地脚 | GND | 按数据手册连接 |

SPI 的第一个字节同时包含读写位和寄存器地址；MSB 先发送。MFRC522 作为从机，SPI 时钟由主控产生，数据在上升沿稳定、下降沿变化。

## 四、27.12 MHz 晶振与 13.56 MHz

晶振为内部振荡器提供 27.12 MHz 时钟，芯片内部产生 13.56 MHz 射频载波及相关时钟。晶振应靠近 OSCIN/OSCOUT，走线短、对称、远离 TX/RX 区域。负载电容不能只凭经验填写，应使用晶振数据手册的 CL、估算寄生并参考 NXP 典型应用。

~~~text
27.12 MHz crystal → internal clock generation → 13.56 MHz RF carrier
~~~

## 五、TX1/TX2、匹配网络和线圈

TX1/TX2 不是“一根正、一根负的普通差分线”这么简单。NXP 参考电路中的电感、电容、阻尼/匹配元件共同决定：

- 发射效率；
- 线圈谐振频率；
- 载波幅度；
- 调制波形；
- 接收灵敏度；
- 对卡片和周围金属的容忍度。

PCB 线圈天线通常由多匝铜线构成。线圈尺寸、匝数、线宽、线间距、板厚、铜厚和周围金属都会改变电感与损耗。30 mm × 30 mm、2～3 匝等只能作为学习起点，不能当成通用定值。

## 六、RX、VMID 与电容的正确理解

电容的“高频近似短路、低频近似开路”是小信号一阶模型：

~~~text
X_C = 1 / (2π f C)
频率升高 → X_C 变小 → 高频更容易通过
频率降低 → X_C 变大 → 低频更难通过
~~~

真实电容还有 ESR、ESL 和自谐振频率。因此不能说“每个高频波来时电容都永久短路”或“充满后变成完全断路”。在交流稳态下，电容电流由电压变化率决定；它既可能向信号节点提供电流，也可能把高频能量旁路到地，具体方向由整个网络的瞬时电压决定。

RX 与 VMID 的偏置、耦合和滤波必须按 NXP 典型应用电路连接。不要只凭“上拉电阻”“高通电容”类比就更改 C/R 数值。

## 接口 / 器件 API 速查表

| 对象 | 作用 | 注意 |
|---|---|---|
| SPI | 主控访问寄存器/FIFO | 最高速率、时序以数据手册为准 |
| NSS | SPI 片选 | 低有效，必须独立可控 |
| IRQ | 中断 | 可选，但可减少轮询 |
| NRSTPD | 复位/掉电 | 低有效掉电，建议引出 |
| TX1/TX2 | 发射模拟输出 | 只按官方 RF 参考设计连接 |
| RX | RF 接收模拟输入 | 不能按数字输入处理 |
| VMID | 内部参考电压 | 遵循官方应用图，避免外部加载 |
| OSCIN/OSCOUT | 27.12 MHz 时钟 | 晶振靠近、短线 |
| 13.56 MHz 线圈 | 近场天线 | 需调谐，不等同 50 Ω远场天线 |

## 完整示例：MFRC522 SPI 读版本寄存器

~~~c
uint8_t mfrc522_read_reg(uint8_t addr)
{
    uint8_t first = (uint8_t)((addr << 1) | 0x80); /* read + address */
    uint8_t value;

    CS_LOW();
    SPI_TX(first);          /* MSB first */
    value = SPI_TX(0x00);   /* clock in register data */
    CS_HIGH();

    return value;
}

/* bring-up:
 * 1. 3.3 V稳定
 * 2. NRSTPD释放
 * 3. SPI读 VersionReg
 * 4. 再打开天线驱动并测试线圈
 */
~~~

寄存器地址和初始化表应使用所选 MFRC522 版本的官方数据手册或经过验证的驱动，不要把模块厂商的引脚丝印直接当作芯片原始引脚名称。
