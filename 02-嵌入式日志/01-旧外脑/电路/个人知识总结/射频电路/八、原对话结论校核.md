# 原对话结论校核

> 本页把“可直接作为工程基线”的内容与“只能作为学习类比/待核对”的内容分开。完整原文见 [[00、对话归档与索引]]。

## 核心概念

- ==凡是涉及具体脚号、元件值、天线尺寸、阻抗线宽和焊盘连接，都必须以实际器件版本与官方资料为准。==
- ==类比有助于理解，但不能代替模拟电路的电压、电流、阻抗和频率响应分析。==

## 一、高可信，可作为设计基线

| 结论 | 依据/动作 |
|---|---|
| CC2530 P2_1=DD、P2_2=DC | TI CC Debugger 指南；物理脚 35/34 |
| RESET_N 是 CC2530 低有效复位 | CC2530 数据手册 |
| CC2530 RF_P/RF_N 是差分 RF 端口 | CC2530 数据手册 |
| CC2530 需要 32 MHz 晶振或外部时钟 | CC2530 数据手册/参考设计 |
| MFRC522 工作在 13.56 MHz | NXP MFRC522 数据手册 |
| MFRC522 使用 27.12 MHz 振荡器输入 | NXP MFRC522 数据手册 |
| MFRC522 SPI 连接为 SCK/MOSI/MISO/NSS | NXP MFRC522 数据手册 |
| MFRC522 TX1/TX2 是发射输出，RX 是 RF 输入 | NXP MFRC522 数据手册 |
| 电容和电感是频率相关器件 | 基本交流电路模型 |
| 四层板应优先保持连续 L2 地平面 | 高速/RF PCB 通用原则 |

## 二、需要明确修正的表述

### 1. CC2530 调试脚号曾被混淆

正确关系是：

~~~text
CC Debugger DD → CC2530 P2_1 → physical pin 35
CC Debugger DC → CC2530 P2_2 → physical pin 34
RESETn          → CC2530 RESET_N → physical pin 20
~~~

不要根据连接器丝印顺序猜物理脚号。

### 2. DCOUPL 不能当普通 3.3 V 电源

DCOUPL 是芯片内部数字电路的去耦节点，按 TI 典型应用放置电容即可；不要从这里给 RC522、ESP-12F 或其他外设供电，也不要把它与模拟电源磁珠隔离混为一谈。

### 3. Balun 数值不是通用答案

18 pF、2 nH、1 pF、2.2 pF 等是 TI 参考设计中的典型起始值。它们依赖芯片版本、封装、PCB 叠层、天线、连接器和测试参考面。不能把每个元件都解释为固定的相位差 90°元件。

### 4. MFRC522 底部焊盘不是强制接地

NXP 数据手册指出，封装底部散热焊盘连接不是必须；可选择连接到 DVSS。原对话中“必须接地”的说法应改为“按封装与热/EMI需求选择，并以数据手册为准”。

### 5. 高频电容不是永久短路

小信号近似是 X_C 随频率升高而减小；真实器件存在 ESR、ESL 和自谐振。不能用“电容先短路、充满后断路”的单向直流故事解释整个 RF 交流网络，也不能仅凭这个故事判断 RX/VMID 的瞬时电流方向。

### 6. 中心抽头不是 MFRC522 的通用接法

后续对话中出现了“TX1/TX2 线圈中心接 GND”的中心抽头方案。它只适用于原理图明确提供三个端点、且参考设计就是中心抽头结构的芯片/天线。常见的 MFRC522 两端子线圈只应连接两个天线端点，线圈几何中心空白区不得额外放 GND 铜、GND 走线或 GND 过孔。不能把其他芯片或评估板的中心抽头拓扑直接套用到当前 MFRC522。

## 三、需要实测或重新核对的项目

- CC2530 USART location、P0_4/P0_5 的实际 TX/RX 复用和优先级寄存器。
- 所选 32 MHz、27.12 MHz 晶振的 CL 与负载电容。
- TPS54302 的输入压降裕量：USB 5 V、SS34、线缆和满载叠加后的 VIN。
- TPS54302 的电感、输入/输出电容、前馈电容和反馈分压。
- MFRC522 具体版本、供电去耦和 TX/RX 匹配网络。
- MFRC522 线圈的尺寸、匝数、线宽、间距、Q 值、谐振点和卡片负载。
- 2.4 GHz RF 线的实际 50 Ω线宽；必须使用板厂实际叠层。
- 天线下方和附近的地铜、过孔、板框、螺丝、屏蔽罩及外壳影响。
- 820 Ω/820 kΩ、1.1 µH、75 pF、30×30 mm、2～3 匝等对话中出现的值是否真的属于当前原理图/参考设计。

## 四、本项目当前采用的 CC2530 射频走线规则

| 分段 | 当前采用标准 | 备注 |
|---|---:|---|
| 芯片端到 Balun LC 网络 | 8～10 mil 差分 | 适配 QFN 引脚和 0402 焊盘，优先紧凑、对称、短 |
| Balun 输出经匹配电容到天线 | 16 mil 单端微带线 | 以嘉立创 1.6 mm 四层 7628、L1-L2 约 0.21 mm 为当前假设 |
| 板载倒 F/蛇形天线 | 按官方尺寸；L1～L4 Keepout | 禁止地铜、过孔、电源层和其他金属进入辐射区 |

这组数值是本项目的 PCB 设计规则，不是所有四层板的通用规则。下单前应把板厂最终叠层输入阻抗计算器复核；若 L1-L2 介质厚度、铜厚或板材改变，16 mil 必须重新计算。RC522 的普通 SPI/UART 线可以走底层，但应避开 2.4 GHz 天线 Keepout、RF 参考地和 13.56 MHz 线圈敏感区域。

## 附录：学习时的判断模板

看到一个具体结论时，依次问：

1. 这是数据手册明确规定，还是经验建议？
2. 适用的是哪一个芯片版本、封装和 PCB 叠层？
3. 是直流结论、低频结论，还是目标频率下的交流结论？
4. 有没有把模拟节点误当成数字节点？
5. 能否用电压、电流、阻抗或实测波形验证？

## 五、ChatGPT 后续对话的结论边界

### 1. 天线替换成功定位了故障范围，不等于找到了唯一根因

用户报告：原 PCB 天线断开后，连接另一块可正常读卡的 RC522 模块天线可以读卡；之后漆包线天线也成功。该 A/B 证据将问题高优先级地指向原天线几何、连接、匹配或周边金属环境，但不能单独证明“某一小段重叠”就是根因。连续性/蜂鸣档不能代替 13.56 MHz 的阻抗、Q 和谐振测量。

### 2. 中心抽头接地是特定拓扑，不是普遍规则

后续原理图 A1 标有 `TX1_OUT / GND / TX2_OUT`，外接三线天线实测可读，因此对**当前板**可把三端连续绕组作为复现起点。但另一个设计的两端线圈不能照搬中心接地；还要区分电气抽头与矩形线圈的几何孔径。新 PCB 应先看器件参考设计和网表，必要时把抽头接地做成 `0 Ω / DNP` 选项，再实测决定。

### 3. TPS54302 的掉压原因没有定案

对话记录到 3.3 V 降至约 1.2–1.4 V、ESP 复位、FB 摆动，以及拆开 ESP 支路后其余供电正常；但没有得到故障瞬间 `VIN/VOUT/FB/ESP 电流` 的同步示波器数据。聊天中先后提出 Layout、输出电容、输入裕量、电感饱和、FB 虚焊和负载短路等假设，不能把其中任一个写成事实。

特别是“SW 到电感约 200 mil”单一尺寸，不足以判定整个 Buck Layout 合格或不合格。应按 TPS54302 数据手册整体检查 VIN/GND 热回路、输入/输出电容、SW 面积、FB Kelvin 回地和反馈避让，并用波形验证。

### 4. 烧录时蜂鸣器响：拓扑已知，复位态原因待测

原理图可确认 `P0_0 → R17 1 kΩ → S8050 基极`、R18=10 kΩ 下拉、蜂鸣器由 S8050 低边驱动。CC2530 GPIO 复位默认状态可能解释蜂鸣器误导通，但要实际测 `P0_0` 和基极电压，并按当前数据手册核对默认配置。不要未经计算就把 R18 改成某个数值。

### 5. 磁珠不是独立电源开关

ESP、CC2530、RC522 电源网通过磁珠相连时仍是同一条直流供电路径。外接 3.3 V 到 ESP 网可能回灌主电源；UART 信号也可能在一侧未供电时回灌。独立供电测试必须断开直流连接，并考虑信号线隔离。
