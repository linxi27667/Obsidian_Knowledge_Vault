# 三电源与多模块系统设计

## 核心概念

- ==先做电源树，再分配信号引脚==。
- ==先看输入裕量，再决定是否使用 SS34 防反接==；5 V 经二极管后给 TPS54302，实际可能接近输入下限。
- ==磁珠是频率相关的阻抗元件，不是模拟电源必加、数字电源必不加==。
- ESP-12F 是带射频的模组，除了串口，还必须处理 EN、RST、GPIO0、GPIO2、GPIO15 等启动配置脚。
- CH340N 的 TX/RX 连接原则仍是交叉：主控 TX 接对方 RX，主控 RX 接对方 TX。

## 一、电源树

~~~text
USB-C VBUS 5 V
      │
      ├─ ESD/保险/防反接（按实际器件）
      │
      ├─ SS34（若采用，核对压降与电流）
      │
      └─ TPS54302 Buck → 3.3 V主电源
                         ├─ CC2530
                         ├─ ESP-12F
                         ├─ MFRC522
                         └─ CH340N（按其供电规格）
~~~

如果 USB 输入只有 5 V，SS34 的压降会让 DCDC 输入低于 5 V。TPS54302 的工作输入范围从 4.5 V 起，系统必须在最差电源、最大负载、二极管温升和 USB 线压降下仍有裕量。可以考虑理想二极管、P 沟道 MOSFET 或其他保护拓扑，但器件数量和学习目标要权衡。

## 二、TPS54302 设计要点

TPS54302 是 3 A、400 kHz 同步降压器件，输入范围为 4.5～28 V。电源设计至少要核对：

1. 输入电容是否紧靠 VIN 与 PGND；
2. 输出电容的有效容量、直流偏压和纹波；
3. 电感饱和电流与温升；
4. 反馈分压阻值与输出电压；
5. BOOT-SW 之间的 0.1 µF 自举电容；
6. 反馈线是否远离 SW 节点；
7. 负载瞬态和上电软启动。

输出电压的基本关系：

~~~text
VOUT = VREF × (1 + Rtop / Rbottom)
~~~

47 µF 插件电容可以承担低频储能，但不能自动替代靠近芯片的低 ESL 陶瓷电容。更稳妥的组合是“芯片附近陶瓷 + 负载附近体电容”，具体数值按数据手册和实际负载确认。前馈电容会改变反馈网络的高频响应，不能只因“别人用了 75 pF”就直接照搬。

## 三、磁珠与模块隔离

RC522 模块、ESP-12F 的突发电流和 DCDC 的开关节点都可能成为噪声源。磁珠的使用位置可以是：

~~~text
3.3V主电源 ───────── CC2530
          ├─ FB ─── ESP-12F局部3.3V ─ 去耦
          └─ FB ─── MFRC522局部3.3V ─ 去耦
~~~

是否安装磁珠，需要基于额定电流、直流电阻、阻抗曲线、并联电容和稳定性测试判断。磁珠加上两侧电容可能形成 LC 谐振；若没有明确噪声问题，先使用短而低阻的电源分配与良好去耦通常更容易调试。

## 四、ESP-12F 启动与串口

ESP-12F 的串口连接：

| ESP-12F | 外部 UART | 说明 |
|---|---|---|
| TXD0 | 对方 RX | ESP 发出的数据 |
| RXD0 | 对方 TX | ESP 接收的数据 |
| EN/CH_PD | 3.3 V 上拉 | 芯片使能 |
| RST | 3.3 V 上拉，按需按键拉低 | 复位 |
| GPIO0 | 3.3 V 上拉，下载时拉低 | 启动模式 |
| GPIO2 | 3.3 V 上拉 | 启动配置 |
| GPIO15 | GND 下拉 | 启动配置 |
| VCC | 3.3 V | 单独就近去耦 |

ESP-12F 是否需要烧录固件取决于使用方式：如果只当 Wi-Fi 模块，仍需要有可执行固件；若使用 AT 固件，则要确认固件版本和命令集；若自定义功能，则要通过 UART 下载或其他烧录方式写入。

## 五、CH340N 与 USB-C

CH340N 只处理 USB 与 UART 的协议/电平转换，不会替代 CC2530 的 CC Debugger 接口。USB-C 作为供电/USB 数据口时，要核对：

- CC1/CC2 的下拉电阻和 USB 角色；
- VBUS 保护与输入电容；
- D+/D− 是否需要差分布线；
- CH340N 的供电电压与 I/O 电平；
- CH340N TXD/RXD 与目标 UART 是否交叉；
- USB 连接器屏蔽层的接地策略。

D+/D− 是差分对；普通 SPI/GPIO 不必套用 USB 的严格差分规则，但仍要避免不必要的长线和跨越噪声源。

## 接口 / 器件 API 速查表

| 器件/接口 | 关键参数 | 设计检查 |
|---|---|---|
| TPS54302 | 4.5～28 V输入、3 A、400 kHz | VIN、SW热回路、反馈、BOOT |
| SS34 | 肖特基压降与电流 | 5 V输入裕量、温升 |
| ESP-12F | 3.3 V、启动绑带、Wi-Fi突发电流 | EN/RST/IO0/IO2/IO15 |
| CH340N | USB-UART | TX/RX交叉、电平、D+/D− |
| 100 nF去耦 | 高频局部去耦 | 靠近对应电源脚 |
| 10/47 µF | 低频储能 | 注意有效容量和 ESR |
| 磁珠 | 频率相关阻抗 | 额定电流、DCR、谐振 |

## 完整示例：上电验证顺序

1. 不插入全部模块，只给 DCDC 输入供电。
2. 测量 TPS54302 的 3.3 V 空载和假负载电压。
3. 加入 CC2530，检查启动电流和晶振。
4. 加入 MFRC522，先用 SPI 读版本寄存器。
5. 最后加入 ESP-12F，观察 Wi-Fi 发射瞬间的 3.3 V 下陷。
6. 用示波器在模块 VCC 管脚处测纹波，不要只在电源入口测量。
7. 若异常，先拆分模块、关闭射频发射，再定位电源/地/接口问题。

## 附录：工程决策

- 学习板可以采用“DCDC + 防反接 + 局部去耦”的简洁方案。
- 工业产品会考虑浪涌、ESD、EMI、热、可生产性、测试点、版本追踪和法规。
- 多个射频模块同时工作时，必须定义时序、频段占用、地平面和天线净空，而不是只增加更多滤波电容。
