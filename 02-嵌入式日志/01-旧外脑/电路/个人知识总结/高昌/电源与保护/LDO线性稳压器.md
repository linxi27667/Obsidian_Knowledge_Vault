# 5V 转 3.3V LDO 设计

> 作用：从已经稳定的 5V 得到干净的 3.3V，供 STM32、逻辑电路和数字侧通信器件使用。

## 目标器件

暂定 `ME6217C33M5G`。它适合低到中等电流的 3.3V 逻辑电源，不适合直接承担 4G 模组的大脉冲电流或继电器线圈。

## 基本连接

```text
VCC5V -> CIN -> ME6217 VIN
                 ME6217 VOUT -> COUT -> VCC3V3
                 ME6217 GND  -> GND
                 ME6217 EN   -> 按数据手册接到确定逻辑电平
```

## 外围元件

| 元件 | 作用 | 建议 |
|---|---|---|
| 输入电容 CIN | 降低 5V 线上瞬态扰动，保证 LDO 输入稳定 | 紧贴 VIN-GND；数值和 ESR 按数据手册。 |
| 输出电容 COUT | 保证环路稳定、改善瞬态响应与纹波 | 紧贴 VOUT-GND；不能随意省略。 |
| 100nF 陶瓷电容 | 抑制 MCU/数字芯片的高频开关噪声 | 每个 IC 电源脚旁各放一颗。 |
| 0R 电阻（可选） | 便于断开 3.3V 后级测静态电流和排查短路 | 可放在 LDO 输出到逻辑 3.3V 母线之间。 |

## 两个必须先算的量

### 1. 电流是否够

LDO 输出电流必须大于 STM32、传感器、隔离器数字侧、指示灯和存储器的最大电流之和，并留余量。Air780E 的发射峰值电流不应由该 LDO 提供。

### 2. 发热是否可接受

```text
P_LDO = (Vin - Vout) x Iout
      = (5V - 3.3V) x Iout
```

例如 3.3V 负载为 150mA，LDO 约耗散 `1.7V x 0.15A = 0.255W`。封装较小时仍需检查温升；电流越大，越应考虑改用 Buck。

## 常见误解

- LDO 不是“什么 5V 负载都能供”。它的发热与负载电流成正比。
- 输入、输出电容不是装饰件，数值和 ESR 会影响 LDO 稳定性。
- 3.3V 逻辑地与 5V Buck 地通常共地；只有跨隔离器的两侧才需要严格隔离。
