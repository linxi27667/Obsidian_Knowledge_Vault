# 04、BOOT 自举与 SW 开关节点

## SW/PH 是什么

SW 或 PH 是内部高边 MOS 的输出端，也是功率开关节点。

```text
MOS 导通：SW 接近 24V
MOS 关断：SW 被续流回路拉到接近 GND
```

因此 SW 电压变化很快，是 DCDC 最容易产生干扰的地方。它连着 L1 和 D69，但应远离 FB、COMP、晶振、ADC、天线和通信线。

## BOOT 是什么

BOOT 是高边 MOS 的驱动辅助脚。

它不是让 MOS 永远导通，也不直接决定输出电压。它的工作是保证 MOS 每次需要导通时可以：

- 快速打开；
- 充分打开；
- 降低导通损耗；
- 在芯片要求时准确关断。

## 什么叫自举

原图 C20：100nF 接在 BOOT 与 SW 之间。它储存的不是固定“对地电压”，关键是两端压差：

```text
VBOOT - VSW = 高边 MOS 所需的驱动电压
```

当 SW 被抬高到接近 24V 时，BOOT 会跟着一起抬高。这样高边 MOS 的栅极仍能比它自己的源极高出几伏，所以 MOS 能完全打开。

## 最重要的纠正

```text
错误：BOOT 让 MOS 一直导通。
正确：BOOT 保证 MOS 在每次需要导通时能正常、快速、充分导通。
```

若 MOS 永远导通，24V 会持续送入后级，Buck 无法稳定输出 5V。真正决定每次导通多久的是芯片根据 FB 做出的 PWM 控制。
