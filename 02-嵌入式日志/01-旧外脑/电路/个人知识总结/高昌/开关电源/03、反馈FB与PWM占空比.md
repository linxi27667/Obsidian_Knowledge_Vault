# 03、反馈 FB 与 PWM 占空比

## 什么是反馈

反馈的意思是：芯片把输出结果拿回来检查，再修正下一次动作。

```text
输出低了 -> FB 读数低 -> MOS 每次多导通一点 -> 输出回升
输出高了 -> FB 读数高 -> MOS 每次少导通一点 -> 输出回落
```

这叫闭环控制。没有反馈的电源只能按固定比例开关，输入变化或负载变化时，输出很难维持 5V。

## FB 为什么要接两个电阻

TPS54360 的 FB 目标电压约为 `0.8V`，不能直接把 5V 接进去。两个电阻先将输出缩小：

```text
5V 输出
  |
 R上：约 53.6k
  |
  +---- FB
  |
 R下：约 10k
  |
 GND
```

当输出约为 5.088V 时：

```text
VOUT = 0.8V x (1 + R上 / R下)
     = 0.8V x (1 + 53.6k / 10k)
     约等于 5.088V
```

芯片的目标并不是“直接盯住 5V”，而是努力让 FB 保持在约 0.8V。反馈电阻比例换了，输出目标电压也会变化。

## 反馈电阻怎样选

`53.6kΩ` 是常见的 E96（1%）标准阻值，不是必须使用带小数的标称值。只要比例满足目标输出即可，例如 `105kΩ / 20kΩ` 理论上也对应 5V（前提是芯片基准为 0.8V）。

实际输出还受电阻误差、FB 基准误差、负载和 PCB 压降影响，所以不必为“计算结果刚好是整数”牺牲设计余量。优先按数据手册推荐的阻值范围、1% 精度、待机分压损耗和可采购性来选；改动反馈电阻后必须实测空载、满载和瞬态电压。

## PWM 和占空比

PWM 是高速开关信号。占空比是“一个开关周期内，MOS 导通时间所占比例”。

```text
导通时间长 -> 电感得到较多能量 -> 输出趋向升高
导通时间短 -> 电感得到较少能量 -> 输出趋向降低
```

所以：FB 负责说“输出现在偏高还是偏低”，芯片内部控制器负责据此改变 PWM 占空比。

## COMP 为什么存在

反馈不能调得过快或过猛，否则会出现过冲、振荡或啸叫。COMP 周围的阻容网络决定调节速度与稳定性。

工程结论：反馈电阻和 COMP 补偿网络不能凭感觉删掉或改值。
