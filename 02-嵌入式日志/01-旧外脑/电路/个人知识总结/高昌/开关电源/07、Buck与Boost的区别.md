# 07、Buck 与 Boost 的区别

## 共性

Buck 和 Boost 都是 PWM 开关电源，都包含：

- MOS 开关；
- 电感储能；
- 二极管或同步 MOS；
- 并联在输出端的滤波电容；
- 反馈控制网络。

## 核心对比

| 项目 | Buck 降压 | Boost 升压 |
|---|---|---|
| 目标 | 输出低于输入 | 输出高于输入 |
| 电感位置 | 开关后面，位于 SW 到输出之间 | 输入后面，位于 VIN 到 SW 之间 |
| 二极管位置 | 从 SW 向地的续流支路 | 从 SW 通向输出的主通路 |
| MOS 导通时 | 输入经电感向输出送能 | 电感经 MOS 向地储能，输出电容供负载 |
| MOS 关断时 | 电感经二极管续流，继续供输出 | 电感电压与输入叠加，经二极管送输出 |
| 输出电容 | 并联在输出与 GND | 同样并联在输出与 GND |

## 两句记忆

```text
Buck：二极管往地，关断时给电感续流，输出低于输入。
Boost：二极管往输出，关断时送出叠加电压，输出高于输入。
```

## 容易混淆的地方

```text
错误：Buck 用 PWM，Boost 靠电压叠加。
正确：Buck 和 Boost 都用 PWM。

Buck 主要靠控制占空比得到较低平均输出。
Boost 利用关断时的电感电压与输入电压叠加实现升压。
```
