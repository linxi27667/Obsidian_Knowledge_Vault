# 06、Boost 升压电路工作原理

## Boost 是什么

Boost 是升压型开关电源：把较低输入电压变为较高输出电压。

```text
VIN -> 电感 -> SW -> 二极管 -> VOUT
                |
               MOS
                |
               GND

VOUT -> 输出电容 -> GND
```

输出电容仍然是并联在输出与地之间，并不是串联电容。

## MOS 导通：电感储能

```text
VIN -> 电感 -> MOS -> GND
```

- 电感从输入取能，电流上升。
- 二极管反向截止。
- 输出电容暂时独立给负载供电。

## MOS 关断：电感与输入电压叠加

电感电流不能突然停止，因此它会把 SW 节点电压抬高。

```text
VIN 电压 + 电感释放时产生的电压
-> 二极管
-> 输出电容与负载
```

当 SW 电压高于输出端时，二极管导通。此时叠加的是**电压**，不是电流，所以输出可以高于输入。

## Boost 中二极管的作用

- MOS 关断时，将电感能量送往输出；
- MOS 导通时阻止输出电容向 MOS 和电感反向放电；
- 保证能量单向送入输出端。
