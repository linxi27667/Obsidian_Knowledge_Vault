# 04、24V数字量输入DI光耦隔离电路

> 原图位置：第 3 页上半区，共 12 路。典型通道：IN_SW1 -> R48 -> U18 -> IN1。

## 电路由哪几部分组成

| 部分 | 典型器件 | 作用 |
|---|---|---|
| 输入端子 | CN15/CN16/CN17 | 接入外部开关。 |
| 限流 | R48、R52、R53 等，典型 5.1k | 限制光耦 LED 电流。 |
| 反向保护 | D10 等：1N4148WS-E | 反向并联在 LED 两端，限制反向电压。 |
| 隔离 | U18、U22 等：EL357N(B)(TA)-G | 光隔离外部 24V 与 MCU 3.3V。 |
| 逻辑上拉 | 典型 3.3k | 把光耦输出转换为 3.3V 逻辑。 |
| 输出整形 | 典型 1k、680pF | 限流、低通滤波、硬件消抖。 |

## 工作过程

1. 外部开关闭合或输入有效 24V。
2. 电流经过 5.1k 电阻流入光耦 LED。
3. 光耦输出侧光敏三极管导通，改变逻辑侧电平。
4. 上拉电阻和 RC 网络将信号送往 MCU 输入。
5. 光耦两侧没有直接导电连接，降低地电位差与共模噪声的影响。

## 重点元器件作用

### 5.1k 限流电阻

- 设定光耦 LED 电流。
- 粗略估算：I ≈ (VIN - VF_LED) / R。24V、LED 约 1.2V、5.1k 时约 4.5mA。
- 实际设计应按输入上限、CTR 最小值、老化、温度和功耗留裕量。

### 1N4148WS-E 反向保护

- 光耦输入 LED 的反向耐压很低。
- 反接、感应负压或共地异常时，二极管优先导通，保护 LED。
- 它不替代输入 TVS；主要解决 LED 的反向击穿。

### EL357N 光耦

- 输入侧 LED 发光，输出侧光敏三极管导通。
- 两侧无金属导通路径，实现电气隔离。
- 关键指标为 CTR。必须按最坏 CTR、老化和温度，验证逻辑侧能够可靠翻转。

### 3.3k、1k 与 680pF

- 上拉电阻定义逻辑高电平和输出电流。
- 串联电阻限制逻辑侧电流并改善抗干扰。
- 680pF 与电阻形成 RC 低通，过滤毛刺和机械触点抖动。
- RC 不应代替软件消抖，软件仍应做时间确认。

## PCB 与新板注意事项

1. 要实现真正隔离，光耦两侧地不能在其他地方被直接短接。
2. 光耦两侧按目标隔离等级保留爬电距离，必要时开槽。
3. 输入端的保护与限流应靠近连接器。
4. 若用 EL817 替换 EL357N，需重新确认封装、引脚、CTR 分档和输入电流。
