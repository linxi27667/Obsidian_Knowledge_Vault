# 09、WiFi通信与天线电路

> 原图位置：第 4 页右上。核心模块：U50，USR-WIFI232-B2；射频端：IPEX1、RF1。

## 电路由哪几部分组成

| 部分 | 原图器件/信号 | 作用 |
|---|---|---|
| WiFi 模块 | U50：USR-WIFI232-B2 | 通过串口连接 MCU，完成 WiFi 通信。 |
| 串口信号 | WIFI_UART5_TX/RX | MCU 与模块之间发送、接收数据。 |
| 控制信号 | WIFI_RESET、WIFI_LINK、WIFI_NLINK、WIFI_NREADY、Reload | 复位、状态指示或进入配置/下载模式。 |
| 电源 | VDD3.3V、C39：100uF、C133：100nF | 为 WiFi 模块提供 3.3V 及瞬态去耦。 |
| 配置电阻 | R180、R181、R282 等 | 控制模块上电、复位和功能脚默认状态。 |
| 天线接口 | IPEX1、RF1 | 将模块射频端接到外置 IPEX 天线。 |

## 工作过程

MCU 通过 UART 向 WiFi 模块发送 AT 指令或数据，模块通过同一串口返回状态与网络数据。模块从 3.3V 取电，在发射时会产生脉冲电流；IPEX 接口把高频射频信号送往外部天线。

## 重点元器件作用

### WiFi 模块

- 模块内部集成射频、协议栈和网络功能，MCU 不直接处理 2.4GHz 射频。
- UART 电平、供电电压、复位时序和启动脚电平必须满足模块数据手册。
- 不能把 UART 线随意拉得很长或与功率开关节点并行，否则会增加通信异常。

### 100uF + 100nF 电源电容

- 100uF：支撑较低频的发射电流脉冲，减少 3.3V 瞬时跌落。
- 100nF：处理模块电源引脚附近的高频噪声。
- 两颗电容均应靠近模块电源脚，且电源回路短而宽。

### IPEX1 与 RF1

- IPEX 是同轴天线连接器，RF1 是射频匹配/保护相关位置。
- 射频走线应按 50Ω 阻抗设计，短、直、少过孔，周围保持连续参考地。
- 天线区域要按模块手册留空，不放铜、金属件或高速噪声线。

## PCB 要点

1. 天线端与 Buck SW 节点、继电器、MOS 驱动、大电流线保持距离。
2. RF 走线不随意加测试点、串联电容或 90 度转角。
3. 模块电源需从主 3.3V 支路独立引出，避免与 MCU 核心供电共用细窄回路。
4. 若使用 4G 模组而非 WiFi 模组，供电瞬态通常更苛刻，应额外核对峰值电流和大容量低 ESR 电容。
