# 01、24V入口保护电路

> 原图位置：第 2 页左上。路径：CN1 -> D1/D2 -> F9 -> D4 -> VDD24V。

## 电路由哪几部分组成

| 功能 | 原图器件 | 作用 |
|---|---|---|
| 接线入口 | CN1 | 接入外部 24V 正、负电源。 |
| 浪涌吸收 | D1、D2：SMBJ33CA | 并联在母线与地之间，钳位瞬态过压。 |
| 过流限制 | F9：1812L300/30GR | 自恢复保险丝，限制后级短路或持续过流。 |
| 防反接 | D4：SS510C | 串联肖特基二极管，反接时截止。 |
| 输入滤波 | C13、C21、C22 | 高频去耦和低频储能。 |

## 工作过程

正常 24V 输入时，TVS 基本截止、PTC 低阻、肖特基正向导通。发生浪涌时，TVS 把尖峰电流泄放到地；发生持续过流时，PTC 发热增阻；正负接反时，D4 截止。

## 重点元器件作用

### SMBJ33CA：双向 TVS 管

- TVS 是瞬态泄压器，不是稳压器，也不是保险丝。
- 正常电压下近似截止，浪涌超过击穿阈值时快速导通。
- 两颗并联可提高脉冲能量能力，走线应对称、短而宽。
- 必须靠近入口端子，TVS 到地的回路必须低电感。

### F9：PTC 自恢复保险丝

- 正常时低阻，持续过流时阻值上升。
- 保护的是持续故障能量，不能替代 TVS 的快速钳位能力。
- 选型应核对保持电流、动作电流、最大电压、最大故障电流和温度降额。

### D4：SS510C 肖特基二极管

- 串联防反接，结构简单可靠。
- 正向损耗约为 I × Vf，大电流时会产生明显温升。
- 更高电流时可考虑 MOS 理想二极管方案。

### 输入滤波电容

- 小陶瓷电容抑制高频尖峰。
- 大容量电容缓冲线束阻抗和 DCDC 的脉冲取电。
- 耐压需考虑浪涌和 TVS 钳位，不可只按 24V 标称选型。

## PCB 与复核要点

1. 推荐顺序：端子 -> TVS 分流点 -> PTC -> 防反接 -> 输入电容 -> DCDC。
2. TVS 回地不应走细长地线，应就近接入口大电流地。
3. 对电机、接触器环境，应按实际浪涌波形重新检查 TVS 的反向工作电压、钳位电压和能量能力。
