# 2026-07-24 · FreeRTOS 任务模板

## 概述

所有应用任务只在 `Task_CreateAll()` 创建；任务函数无限循环且 **必须阻塞**；栈大小在 ESP-IDF 里按 **字节** 理解。

## 核心概念

### 1. 任务函数形态

```c
static void Led_Task(void *argument)
{
    (void)argument;  // 无参时消除警告

    while (true) {
        /* 业务 */
        vTaskDelay(pdMS_TO_TICKS(1000));  // 必须有阻塞点
    }
}
```

- 任务一般不 `return`
- 空转会占满 CPU，必须 `vTaskDelay` / 队列接收 / 信号量等

### 2. xTaskCreate 参数顺序

```c
xTaskCreate(
    Led_Task,              // 函数
    "Led_Task",            // 名字（调试用）
    LED_TASK_STACK_SIZE,   // 栈（ESP-IDF：字节）
    NULL,                  // 传给任务的 argument
    LED_TASK_PRIORITY,     // 优先级，数字越大越高
    &g_led_task_handle);   // 句柄输出
```

成功返回 `pdPASS`；封装层可转成 `ESP_ERR_NO_MEM`。

### 3. 统一创建点

```c
// 只在这里创建全部任务
static esp_err_t Task_CreateAll(void);
```

| 约定 | 例子 |
|------|------|
| 全局/文件域变量 `g_` | `g_led_task_handle` |
| 任务名 `Xxx_Task` | `Key_Task` |
| 栈/优先级宏 | `KEY_TASK_STACK_SIZE` |

### 4. 调度直觉

中断 **不能直接“运行某个任务”**。  
ISR 最多把任务变为就绪；**调度器按优先级** 决定接下来跑谁。  
`portYIELD_FROM_ISR` 只是提示：若唤醒了更高优先级任务，退出中断时立刻切换。

## 实践要点

1. 硬件参数用宏；`1000ms` 这类业务延时可直接写在任务里。
2. 不要在 `app_main` 里散落多个裸 `xTaskCreate`。
3. 按键消抖的 `vTaskDelay(20)` 只能在任务里，不能在 ISR 里。

## API 速查

| API | 作用 |
|-----|------|
| `xTaskCreate` | 创建任务 |
| `vTaskDelay` | 延时阻塞 |
| `pdMS_TO_TICKS` | 毫秒 → tick |
| `TaskHandle_t` | 任务句柄 |
| `pdPASS` | 创建成功 |

## 相关文件索引

- `main/main.c` → `Task_Create` / `Task_CreateAll` / 各 `Xxx_Task`
- `main/config.h` → 各 `*_TASK_STACK_SIZE` / `*_TASK_PRIORITY`
