# 2026-07-24 · 工程结构、GPIO 与配置

## 概述

建立 ESP-IDF 竞赛工程的分层骨架：`config.h` 放公共配置，`hardware/` 放 HAL，`main.c` 只负责初始化和任务。GPIO 用 **位图** 选脚，不是 STM32 的 GPIOA/B 端口写法。

## 核心概念

### 1. 程序入口与职责

```text
app_main
  ├── Led_Init / Buzzer_Init / Key_Interrupt_Init
  └── Task_CreateAll
        ├── Led_Task
        ├── Buzzer_Task
        └── Key_Task
```

- ESP-IDF 从 `app_main` 开始，不需要自己写 `main`
- 初始化返回 `esp_err_t`，用 `ESP_ERROR_CHECK` 检查失败
- 业务写在任务里，HAL 只做「初始化 + 控制」

### 2. config.h 放什么

| 适合放宏 | 不必做成宏 |
|----------|------------|
| 引脚号、有效电平 | 业务流程里的 1000ms、20ms |
| 队列长度 | 一眼能看懂的临时延时 |
| 任务栈大小、优先级 | |

所有 HAL 头文件可统一由 `config.h` include，业务侧只 `#include "config.h"`。

### 3. GPIO 位图（最易错）

```c
// pin_bit_mask 是 64 位位图：第 n 位为 1 表示选中 GPIO n
1ULL << GPIO_NUM_1

// 多脚：先移位，再按位或
(1ULL << LED1_PIN) | (1ULL << LED2_PIN) | ...
```

| 写法 | 对不对 | 原因 |
|------|--------|------|
| `1ULL << GPIO_NUM_1` | ✅ | 第 1 位置 1 |
| `1 \| GPIO_NUM_1` | ❌ | 这不是掩码 |
| `1U << 40`（高编号） | ❌ 风险 | 可能溢出，必须用 `1ULL` |

ESP32-S3 没有 `GPIOA.1` 这种端口分组；`GPIO_NUM_x` 就是芯片 GPIO 编号。

### 4. gpio_config 一次配齐

```c
const gpio_config_t config = {
    .pin_bit_mask = pin_mask,
    .mode = GPIO_MODE_OUTPUT,      // 或 GPIO_MODE_INPUT
    .pull_up_en = GPIO_PULLUP_DISABLE,
    .pull_down_en = GPIO_PULLDOWN_DISABLE,
    .intr_type = GPIO_INTR_DISABLE,
};
gpio_config(&config);
```

### 5. CMake 组件注册

```cmake
idf_component_register(
    SRCS "main.c" "hardware/hal_led.c" "hardware/hal_buzzer.c" "hardware/hal_key.c"
    INCLUDE_DIRS "." "hardware"
    REQUIRES esp_driver_gpio esp_driver_ledc
)
```

新增 `.c` 后要 `idf.py reconfigure` 再编译。

## 实践要点

### ESP32-S3 引脚安全（竞赛必查）

- 避开 **GPIO26–32**（常被 Flash/PSRAM 占用）
- 避开启动脚 **GPIO0 / 3 / 45 / 46**
- 用 USB 时保留 **GPIO19 / 20**
- `config.h` 里的引脚是示例，必须对照原理图改

### 与 STM32 对照

| 概念 | STM32 | ESP-IDF |
|------|-------|---------|
| 选脚 | `GPIOA, GPIO_PIN_1` | `GPIO_NUM_1` + 位图 |
| 配置 | `HAL_GPIO_Init` | `gpio_config` |
| 写电平 | `HAL_GPIO_WritePin` | `gpio_set_level` |
| 读电平 | `HAL_GPIO_ReadPin` | `gpio_get_level` |

### API 速查

| API | 作用 |
|-----|------|
| `gpio_config` | 按结构体一次配置 |
| `gpio_set_level` / `gpio_get_level` | 输出 / 读入 |
| `ESP_ERROR_CHECK` | 检查 `esp_err_t`，失败中止 |
| `ESP_LOGI` / `ESP_LOGE` | 日志 |
