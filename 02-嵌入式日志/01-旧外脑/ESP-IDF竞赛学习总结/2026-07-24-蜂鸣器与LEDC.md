# 2026-07-24 · 蜂鸣器与 LEDC

## 概述

有源蜂鸣器用 GPIO 开关即可；无源蜂鸣器需要方波，用 ESP32 的 **LEDC（硬件 PWM）** 产生频率。

## 核心概念

### 1. 有源 vs 无源

| | 有源 | 无源 |
|--|------|------|
| 内部振荡 | 有 | 无 |
| 控制方式 | GPIO 有效电平 | PWM 方波 |
| 能变调吗 | 一般不能 | 改频率变音高 |
| 本工程 API | `Buzzer_Active_Set(bool)` | `Buzzer_Passive_Play(freq)` / `Stop` |

### 2. LEDC 三层

```text
定时器 timer  →  频率 + duty 分辨率
    ↓
通道 channel  →  接到哪个 GPIO
    ↓
duty          →  一个周期里高电平占比
```

```c
// 10 位分辨率：duty 0~1023，512 ≈ 50%
ledc_timer_config(... freq_hz, LEDC_TIMER_10_BIT ...);
ledc_channel_config(... gpio_num, timer_sel ...);
ledc_set_duty(...); ledc_update_duty(...);  // 必须 update 才进硬件
```

注意：`LEDC_TIMER_10_BIT` **不是** STM32 的 PSC/ARR，它描述的是 **duty 精细程度**。

### 3. 播放与停止

```c
// 播放：设频率 + duty=512 + update
Buzzer_Passive_Play(2000);  // 约 2kHz

// 停止：duty=0 + update
Buzzer_Passive_Stop();
```

`ledc_set_freq` 返回 0 表示频率配置失败。

## 实践要点

1. LEDC 模式/定时器/通道号是驱动私有实现细节，放在 `.c` 里用 `#define`，不必暴露到头文件。
2. 有源、无源可以同时初始化，初始都关闭。
3. 业务节奏（响多久、停多久）写在 `Buzzer_Task`，不要塞进 HAL。

## API 速查

| API | 作用 |
|-----|------|
| `ledc_timer_config` | 配定时器 |
| `ledc_channel_config` | 配通道 + GPIO |
| `ledc_set_freq` | 改频率 |
| `ledc_set_duty` | 写占空比 |
| `ledc_update_duty` | 应用到硬件 |
