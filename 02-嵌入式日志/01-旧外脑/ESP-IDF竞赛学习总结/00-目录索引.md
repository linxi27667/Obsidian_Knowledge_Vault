## 外设初始化地图（2026-07-30）

> [!TIP]
> ==先申请资源/创建对象 → 配置 → 启用 → 使用 → 释放==。  
> 不是每个外设都有 `install`；函数名随驱动类型而变化，但生命周期思路一致。

### 三种初始化模板

```text
1. 直接配置型（GPIO）
   gpio_config() → gpio_set_level() / gpio_get_level()

2. 驱动安装型（UART）
   xxx_driver_install() → xxx_param_config() → xxx_set_pin() → 收发 → xxx_driver_delete()

3. 句柄型（GPTimer、ADC 等新式驱动）
   xxx_new_xxx() → xxx_config_xxx() → xxx_enable() → xxx_start()/使用 →
   xxx_stop() → xxx_disable() → xxx_del_xxx()
```

### 当前工程的外设—库—初始化入口

| 外设 | ESP-IDF 组件 / 头文件 | 资源申请或配置 | 运行时常用 API | 释放方式 |
|---|---|---|---|---|
| LED、按键 GPIO | `esp_driver_gpio` / `driver/gpio.h` | `gpio_config()` | `gpio_set_level()`、`gpio_get_level()` | 通常无需 |
| GPIO 中断 | `esp_driver_gpio` | `gpio_config()` → `gpio_install_isr_service()` → `gpio_isr_handler_add()` | ISR 中仅用 `xQueueSendFromISR()` 入队 | 可移除 handler / ISR service |
| 无源蜂鸣器 PWM | `esp_driver_ledc` / `driver/ledc.h` | `ledc_timer_config()` → `ledc_channel_config()` | `ledc_set_freq()`、`ledc_set_duty()`、`ledc_update_duty()` | 停止或解绑通道 |
| GPTimer | `esp_driver_gptimer` / `driver/gptimer.h` | `gptimer_new_timer()` → 注册 callbacks → `gptimer_enable()` | 设 alarm → `gptimer_start()`；回调中入队 | `stop` → `disable` → `gptimer_del_timer()` |
| UART | `esp_driver_uart` / `driver/uart.h` | `uart_driver_install()` → `uart_param_config()` → `uart_set_pin()` | `uart_write_bytes()`、`uart_read_bytes()` | `uart_driver_delete()` |
| ADC 单次采样 | `esp_adc` / `esp_adc/adc_oneshot.h` | `adc_oneshot_new_unit()` → `adc_oneshot_config_channel()` | `adc_oneshot_read()` | `adc_oneshot_del_unit()` |

### UART 重点

```c
uart_driver_install(port, rx_buf_size, tx_buf_size, 0, NULL, 0);
uart_param_config(port, &uart_config);  // 波特率、8N1、校验、流控
uart_set_pin(port, tx_pin, rx_pin, UART_PIN_NO_CHANGE, UART_PIN_NO_CHANGE);
```

- `uart_driver_install()`：创建 RX/TX 环形缓冲区并申请 UART 驱动/中断资源。
- `uart_param_config()`：规定怎样通信，如 `115200, 8N1`。
- `uart_set_pin()`：把 UART 的 TX/RX 信号路由到指定 GPIO。
- 接线：==TX 接对方 RX，RX 接对方 TX，双方 GND 必须相连==。

### 竞赛代码的分层记忆

```text
config.h            ← 引脚、编号、波特率、缓冲区大小等“可变配置”
hal_xxx.c           ← 外设驱动初始化、读写与资源回收
main.c / Task        ← 业务逻辑；调用 Hal 接口，不直接操作寄存器
FreeRTOS Queue       ← ISR 与任务之间传递事件；不是外设本身
```

### CMake 中的 `REQUIRES`

`main/CMakeLists.txt` 中的 `REQUIRES` 用于声明本组件依赖的 ESP-IDF 内置组件；它让编译器找到头文件并链接实现库，==不是运行时安装库==。

```cmake
REQUIRES
    esp_driver_gpio
    esp_driver_ledc
    esp_driver_gptimer
    esp_driver_uart
    esp_adc
```

### 初始化时的通用检查

- 每一步都检查 `esp_err_t`；失败就停止后续初始化。
- 若中途失败，释放已经创建的资源，避免“半初始化”状态。
- 业务函数调用前检查 `ready` / 句柄是否有效。
- 当前目标为 ESP32-S3；引脚以 `config.h` 为准，避免与板载功能或启动相关引脚冲突。
