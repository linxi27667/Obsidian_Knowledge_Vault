# 05、24V数字量输出DO高边MOS电路

> 原图位置：第 3 页下半左侧。典型通道：OUT9、OUT12、OUT13、OUT14 等。  
> 典型器件：IRFR5305、MMBT5551、1N4148WS-E、PTC、SMBJ33CA。

## 电路由哪几部分组成

| 部分 | 典型器件 | 作用 |
|---|---|---|
| 24V 输入 | VDD24V_OUT | 给输出通道供电。 |
| 高边开关 | Q2/Q4/Q6/Q10/Q12/Q22：IRFR5305 | P 沟道 MOSFET，接通或断开 24V 输出。 |
| 栅极驱动 | Q1/Q3/Q5/Q9/Q11/Q21：MMBT5551 | 小信号三极管，拉低 P-MOS 栅极使其导通。 |
| 栅极偏置 | 47k、4.7k 等电阻 | 使 P-MOS 默认关断，并限制驱动电流。 |
| 驱动保护 | 1N4148WS-E | 改善栅极充放电或提供信号钳位。 |
| 过流保护 | F1-F6：SMB1812P125TF 等 | 单通道 PTC，负载短路时限制电流。 |
| 浪涌钳位 | D30/D32/D34 等：SMBJ33CA | 输出端对地钳位，吸收外部线束和感性负载瞬态。 |
| 外部端子 | CN11、CN12 等 | 将受保护的 24V 输出接到外部负载。 |

## 工作过程

P 沟道 MOSFET 位于电源高边：

1. 默认时，栅极被电阻拉向源极，VGS 接近 0，P-MOS 关断。
2. MCU 使 MMBT5551 导通，三极管将 P-MOS 栅极拉低。
3. P-MOS 的 VGS 变为负值，MOS 导通，24V 送至 OUTx。
4. 负载短路或过流时，PTC 增阻限制持续电流。
5. 线束或感性负载产生尖峰时，TVS 将输出端过压钳位。

## 重点元器件作用

### IRFR5305：P 沟道高边 MOSFET

- 放在正电源侧，导通时把 24V 送到外部负载。
- P-MOS 的优点是高边驱动简单，栅极拉低即可导通。
- 需核对 VDS 耐压、RDS(on)、封装热阻、SOA 和 VGS 最大额定值。

### MMBT5551：栅极驱动三极管

- MCU 不能直接将 24V 高边 MOS 的栅极拉低，因此用小信号管做电平转换和驱动。
- 基极电阻限制 MCU 输出电流；基极/栅极下拉保证上电复位时输出默认关闭。

### PTC：每路输出的过流限制

- 针对单一路外接负载或线束短路。
- 动作慢于电子限流，适合抑制持续过流和降低线束着火风险。
- 选型应和负载稳态电流、启动电流、环境温度匹配；否则会误动作或保护不足。

### SMBJ33CA：输出 TVS

- 外部线束很长或负载感性强时，输出端会出现尖峰。
- TVS 在连接器附近钳位尖峰，保护 MOSFET 和 PCB。
- 钳位电压必须低于 MOSFET 可承受的安全电压，并高于正常运行电压。

## 设计要点

1. 若负载是电磁阀、线圈等感性负载，TVS 的选型需同时考虑关断速度与线圈释放时间。
2. 外部负载必须明确是否共地、最大电流、浪涌电流和线束长度。
3. 输出连接器附近放 TVS、PTC；MOS 附近布置栅极网络。
4. P-MOS 的 VGS 需要限制在额定范围内。24V 系统遇到浪涌时，不能让栅源电压超限。

## 用于新板的建议

原图 DO 为分立高边 P-MOS。若要做 10 路工业输出，评估采用带诊断、限流和热保护的智能高边开关，会比完全分立方案更容易保证短路保护和一致性。
