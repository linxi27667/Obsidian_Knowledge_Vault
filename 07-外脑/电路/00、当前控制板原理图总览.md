## 总体信号路径

~~~text
外部 24V -> TVS / PTC / 防反接 -> 5V Buck -> 3.3V Buck -> 逻辑与通信
外部开关 -> 限流 / 反向保护 -> 光耦 -> MCU DI
MCU 输出 -> MOS 高边 DO 或 NPN 低边 -> 24V 负载 / 继电器线圈
~~~

## 使用原则

1. 先看电流路径，再看控制路径，再看故障时的泄放路径。
2. 原理图只说明连接关系，不自动保证电气安全、热设计和 EMC 合格。
3. 关键值、封装、耐压、浪涌和功耗，均以原 PDF 与器件数据手册为最终依据。
