# 07、RS485通信接口与防护电路

> 原图位置：第 4 页左侧。三组相似通道，核心为 U2、U52、U54：BL3085A(H)。

## 电路由哪几部分组成

| 部分 | 典型器件 | 作用 |
|---|---|---|
| 收发器 | BL3085A(H) | MCU UART 单端信号与 RS485 A/B 差分总线之间转换。 |
| UART 控制 | RO、DI、RE、DE | 接收数据、发送数据、收发使能。 |
| 电源去耦 | 100nF 等 | 为收发器提供就近高频去耦。 |
| 共模滤波 | L4/L5/L6 | 抑制 A/B 线上共模高频噪声，改善 EMC。 |
| 差模/高频滤波 | 390pF、1nF 等 | 与保护网络配合抑制高频干扰。 |
| 过流保护 | PT1-PT6：JK250-120U | 线缆故障、浪涌后持续过流时限制电流。 |
| 浪涌保护 | GS1-GS3：3R090A-5S 等 | 将高能量浪涌泄放到保护地。 |
| 外部端子 | CN2/CN3/CN4 | 连接外部 RS485 A/B/GND 或屏蔽。 |

## 工作过程

发送时 MCU 将 UART TX 送入 DI，并使 DE 有效；收发器把单端逻辑转换为 A/B 差分信号。接收时总线 A/B 差分电压被还原为 RO 逻辑输出。RE/DE 控制半双工收发方向。

## 重点元器件作用

### BL3085A(H) 收发器

- 实现 UART 与 RS485 的电平/物理层转换。
- A/B 是差分信号，能抑制两根线同时受到的共模干扰。
- 原图所用 BL3085 属于非隔离方案；外部地电位差大时，仍可能把干扰引入逻辑侧。

### 共模电感

- 对 A/B 差分有用信号影响较小。
- 对两线同向流动的高频共模干扰阻抗较大。
- 用于改善线缆接口的传导与辐射 EMI。

### PTC、浪涌器件和滤波电容

- PTC 处理持续故障电流。
- 气体放电管/浪涌器件处理高能量浪涌。
- 小电容处理高频尖峰。
- 三者分工不同，不能彼此替代。

## 终端与偏置

- RS485 总线两端通常需要终端电阻，阻值接近双绞线特性阻抗，常见为 120Ω。
- 总线空闲时还需要合适的失效保护/偏置，避免接收器因噪声随机翻转。
- 终端只能放在总线两端，不能每个节点都随意加。

## 对工业板的建议

举升机现场建议改用隔离 RS485 收发器，例如 CA-IS3082W 或同等级方案，并将逻辑地与总线侧地隔离。隔离后仍需保留端口 TVS、PTC、共模滤波和正确的端接。
