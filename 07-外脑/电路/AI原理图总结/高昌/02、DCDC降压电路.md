# 02、DCDC降压电路

> 原图位置：第 2 页上半区。  
> U20 TPS54360DDAR：24V 转 5V；U21 TPS54302DDCRC：5V 转 3.3V。

## 一、24V 转 5V：TPS54360 Buck

### 电路由哪几部分组成

| 部分 | 原图器件 | 作用 |
|---|---|---|
| 控制器 | U20：TPS54360DDAR | 60V 耐压非隔离 Buck，内部集成功率开关。 |
| 输入去耦 | C21、C22 等 | 为高频开关电流提供小回路。 |
| 自举 | C20：100nF | 给高边驱动提供自举电荷。 |
| 储能 | L1：15uH | 导通时储能、关断时续流。 |
| 续流 | D69：SS34 | 开关关断时承接电感电流。 |
| 输出滤波 | C23、C24：47uF；C25 等 | 降低纹波、支撑负载瞬态。 |
| 反馈 | R17、R18 等 | 设定 5V 输出。 |
| 补偿 | R16、C27、C28 等 | 保证控制环路稳定。 |

### 工作过程

U20 导通时，24V 向 L1、输出电容和负载供电，L1 电流上升；U20 关断时，L1 电流通过 D69 继续流动，向输出供电。FB 检测输出电压，控制器调整占空比实现稳压。

原图标注：

~~~text
VOUT = ((53.6k + 10k) / 10k) × 0.8V ≈ 5.088V
~~~

### 元器件作用

#### U20：TPS54360DDAR

- 60V 耐压给 24V 工业电源留出浪涌裕量。
- U20 不是完整电源；L、D、C、反馈和补偿共同决定效率、纹波和稳定性。
- 散热焊盘应以热过孔连接大面积地铜。

#### L1：15uH 电感

- 决定电流纹波和峰值电流。
- 选型重点是饱和电流、DCR、温升和屏蔽结构。
- 电感饱和会使峰值电流上升，可能损坏开关管。

#### D69：SS34 肖特基二极管

- 为电感电流提供续流回路。
- 低正向压降降低损耗，快速恢复降低尖峰。
- 需核对平均/峰值电流、反向耐压和热设计。

#### 输入、输出电容

- 输入电容靠近 VIN/GND，减小高 di/dt 回路。
- 输出电容与 L1 构成低通滤波，决定纹波与突变响应。
- 陶瓷电容会因直流偏压而降容；还需关注 ESR 与纹波电流能力。

#### 反馈与补偿

- 反馈电阻决定 VOUT。
- 补偿网络决定相位裕量、响应速度和过冲。
- 修改电感、输出电容或开关频率后，必须重新做环路设计或测试。

### PCB 要点

- 输入电容、U20、D69 的功率回路面积要小。
- SW 节点是强噪声节点，远离 FB、COMP、晶振、天线和 ADC。
- FB 应从输出电容附近 Kelvin 取样，避开功率地压降。

## 二、5V 转 3.3V：TPS54302 Buck

U21、L8、C1/C2、C6/C7/C8/C40、R211/R212 等构成同步 Buck。原图标注输出约 3.29V。

- U21：5V 到 3.3V 的开关稳压器。
- L8：储能并平滑电流。
- 输入电容：降低对 5V 母线的高频干扰。
- 输出电容：降低 3.3V 纹波，为 MCU/通信芯片提供瞬态电流。
- 反馈电阻：精确设定 3.3V。

## 面向新板的建议

24V 转 5V可参考此拓扑，但要按 4G 峰值、继电器、外设和温升重新设计。Air780E 等蜂窝模组必须在电源脚附近放置低 ESR 大容量储能电容和小陶瓷电容。
