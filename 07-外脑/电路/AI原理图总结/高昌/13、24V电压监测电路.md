# 13、24V电压监测电路

> 原图位置：第 5 页上中。可见主要信号链为 `VDD24V -> R51(3.3k) -> D27(1N4148W) -> Q13(MMBT3906) -> R99/R98/Q14(MMBT3904) -> VPP24V_Monitor`。本笔记描述其典型功能，未在 PDF 中清晰辨识的阻容数值、极性和逻辑电平必须回原图及数据手册复核。

## 电路由哪几部分组成

| 部分 | 原图器件 | 作用 |
|---|---|---|
| 被测电源 | VDD24V | 需要判定是否存在或是否高于阈值的 24V 母线。 |
| 输入限流 | R51：3.3k | 限制后级三极管、钳位支路在异常条件下的电流。 |
| 极性/瞬态保护 | D27：1N4148W | 对控制结点进行定向导通或钳位，抑制反向偏置和异常瞬态。 |
| 第一级转换 | Q13：MMBT3906（PNP） | 将 24V 母线状态转换为适合后级处理的电流/电平。 |
| 偏置与限流 | R99、R98 | 设定 Q13/Q14 的基极电流、开关阈值和默认状态。 |
| 第二级缓冲 | Q14：MMBT3904（NPN） | 把前级状态转换为 MCU 侧可读的逻辑信号 `VPP24V_Monitor`。 |

## 这不是“直接把 24V 接 MCU”

MCU GPIO 的额定电压通常只有 3.3V。24V 电压监测电路的任务是把“母线是否存在/是否达到阈值”变成低压逻辑状态，而不是输出一个可供 ADC 直接量化的精确 24V 比例电压。

若需要精确测量电压，应使用 [[10、模拟量采样与运放缓冲电路]] 中那种受控分压、缓冲和 ADC 方案；本页电路更接近数字状态检测。

## 工作过程

### 24V 正常存在时

1. VDD24V 通过 R51 向 Q13 的控制支路提供有限电流。
2. D27 按其极性在指定方向导通/钳位，防止控制结点出现不期望的反向电压。
3. PNP 管 Q13 根据其基极与发射极电位差进入导通或截止状态。
4. Q13 的输出通过 R99/R98 驱动 NPN 管 Q14。
5. Q14 在 `VPP24V_Monitor` 端形成低压逻辑高/低状态，供 MCU 读取。

### 24V 消失或低于导通阈值时

1. R51 支路不再提供足够控制电流。
2. Q13、Q14 回到由 R99/R98 决定的默认状态。
3. `VPP24V_Monitor` 翻转，软件据此判断供电掉电、接线异常或启动条件不满足。

该链路通常包含两次逻辑反相，最终“24V 正常时读取高还是低”必须根据 Q13/Q14 实际引脚连接和上拉位置确认，不能只凭晶体管型号推断。

## 重点元器件作用

### R51：3.3k 输入限流电阻

- 限制 24V 对后级基极、保护二极管的电流。
- 24V 工业母线可能持续偏高且有尖峰，电阻的耐压、脉冲功耗和封装不能只按 24V 直流功耗估算。
- 对于高浪涌环境，R51 前端的总线保护仍应由 [[01、24V入口保护电路]] 完成。

### D27：1N4148W

- 小信号快速开关二极管，常用作反向 VBE 保护、加速关断或定义单向电流路径。
- 它不等于 TVS，不能承担 24V 母线的浪涌吸收任务。
- 须回到 PDF 确认阴阳极方向，才能准确判断它在这里是钳位、旁路还是加速器件。

### Q13：MMBT3906（PNP）

- PNP 管适合从正电源侧感知或提供电流，常用于高端检测或电平转换。
- 导通条件是基极电压比发射极低约一个二极管压降，实际阈值随电流、温度和电阻网络变化。
- 基极-发射极反向耐压通常较低，D27 的保护方向和 R51 限流十分关键。

### Q14：MMBT3904（NPN）

- NPN 管常作为低边开关或逻辑缓冲级，将上一级较高电压域的信息隔离成安全的低压开集电极信号。
- 输出如果是开集电极形式，需要确认 `VPP24V_Monitor` 端的上拉电阻接到哪一路电源。
- MCU 输入端不要依赖内部上拉作为唯一防护，尤其在线缆或高噪声环境中。

### R98、R99：偏置与状态定义

- 设定三极管基极电流、限制开关电流，且在 24V 不存在时保证输出不会漂浮。
- 电阻比例决定检测阈值，但 BJT 的 VBE 与电流增益离散度较大，因此它不适合作高精度电压门限。
- 若要严格欠压/过压阈值，应采用电阻分压加比较器/基准源/专用监测 IC。

## 设计与验证要点

1. 在 0V、额定 24V、最低工作电压、最高持续电压及浪涌后的情况下，测量 `VPP24V_Monitor` 的逻辑状态。
2. 用示波器观察电机启停时的监测信号，确认不会因短暂尖峰产生误报警。
3. 确认 MCU 引脚任何时候都不超过 `-0.3V` 到 `VDD + 0.3V` 一类的绝对最大范围，具体以 MCU 手册为准。
4. 若该信号参与掉电保存，软件要同时考虑电容放电时间和 Flash/EEPROM 写入时间。
5. 24V 检测网络靠近受监测母线，不要跨越大电流回流缝隙；逻辑输出侧靠近 MCU 并增加适当去耦/滤波。
