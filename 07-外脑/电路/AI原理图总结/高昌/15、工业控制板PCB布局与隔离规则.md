# 15、工业控制板PCB布局与隔离规则

> 本页将当前原理图中可复用的布局原则整理为 PCB 规则。它们是工业控制板的底线，不替代安规、浪涌、热和 EMC 的实际测试。

## 1. 先分区，再布线

建议从左到右或从上到下明确划分以下区域，区域之间留出走线和安全间距，避免信号在不同区域来回穿插。

| 分区 | 典型器件 | 关键原则 |
|---|---|---|
| 24V 入口与保护 | 接线端子、TVS、PTC、防反接二极管 | 紧凑布置，TVS 的浪涌回路最短。 |
| 功率变换 | TPS54360、功率电感、SS34、输入/输出电容 | 高 di/dt 回路最小化，远离 MCU、天线和模拟量。 |
| 负载与继电器 | MOS、继电器、线圈/触点端子 | 大电流回路短宽，触点与逻辑侧保持间距/开槽。 |
| 外部接口保护 | RS485/CAN/RS232/DI 的 TVS、PTC、共模电感 | 保护器件贴连接器，线缆噪声不深入板内。 |
| 低压逻辑 | MCU、Flash、晶振、3.3V LDO/去耦 | 保持安静连续的参考地，远离功率与继电器。 |
| 模拟与射频 | ADC、LM358、晶振、WiFi/天线 | 避开开关节点、继电器与高电流回流。 |

## 2. 24V 入口与 TVS 回流

- 接线端子、SMBJ33CA、PTC 和防反接器件按电流路径依次靠近布置，见 [[01、24V入口保护电路]]。
- TVS 必须贴近端子。其正端到电源线、负端到参考地均应宽而短，不能让浪涌先走一段细长 PCB 线才到 TVS。
- 浪涌电流回路不要经过 MCU 地、晶振地、ADC 地或通信芯片地的狭窄区域。
- PTC、反接二极管、TVS 和输入电容都要检查热量；持续高电流下的温升比原理图更决定可靠性。

## 3. DCDC 功率环路

以 TPS54360 降压为例，参见 [[02、DCDC降压电路]]：

1. 输入陶瓷电容、芯片 VIN/GND、内部开关和续流二极管组成高频脉冲回路，必须面积最小。
2. SW 节点是最高噪声结点：铜皮小、走线短，禁止在它下方/旁边铺敏感信号或模拟地。
3. 电感、输出电容和负载构成输出回路；输出采样线从输出电容正端安静地引回反馈网络。
4. 反馈分压和补偿元件贴近控制器，远离电感和 SW 节点，不与功率电流并行。
5. 控制器散热焊盘按数据手册布置多颗导热过孔，连接到足够大的 GND 铜皮；过孔不能破坏关键高频回流。

## 4. 地与隔离边界

### 同一非隔离电源域

- 不要为了“数字地/模拟地”机械切割完整地平面。优先保持低压逻辑区连续参考地，让回流路径可预测。
- 模拟电源可通过磁珠和局部电容从数字电源取得，ADC/运放布局远离脉冲回流。
- 大电流负载回流从入口附近返回，不穿越 MCU/ADC 区域。

### 隔离域

- DI 光耦两侧、隔离 RS485 两侧属于不同电气域，铜皮、过孔、测试点和丝印均不能跨越隔离带。
- 隔离边界的爬电距离、间隙和开槽尺寸按目标绝缘等级、污染等级、电压和适用标准确定。
- 不要把非隔离原图的 BL3085 误当作隔离方案；当前原图 RS485 是非隔离的，详见 [[07、RS485通信接口与防护电路]]。

## 5. DI、DO 与继电器

- DI 入口端子附近先放 TVS/限流/反接保护，再放光耦；光耦输出侧再进入 MCU 区，详见 [[04、24V数字量输入DI光耦隔离电路]]。
- MOS 高边输出中，MOS、续流/TVS、PTC 与负载端子围绕电流方向紧凑放置，铜宽按持续电流和温升计算，详见 [[05、24V数字量输出DO高边MOS电路]]。
- 继电器触点侧与线圈/逻辑侧保留安全间距；目标举升机板应在触点隔离位置开约 1mm 宽的槽，但最终尺寸由电压、污染等级及相关标准决定。
- 继电器线圈反冲钳位器件紧贴线圈/驱动管。触点切换感性电机或电磁阀时，还应评估触点侧 RC 吸收或 TVS 的需求。

## 6. 通信接口

- CAN、RS485、RS232 的 ESD/TVS 靠近外部连接器；共模电感、PTC、终端电阻按信号链顺序布置。
- 差分线保持同层、同参考面、尽量等长并远离大电流和 SW 节点；不在地平面分割处跨越。
- 总线终端电阻只在物理总线两端安装，不能每个节点都永久并联 120 欧姆。
- 要达到工业隔离要求时，选隔离收发器及隔离电源，并按隔离带规则布局；外加 TVS 不能使非隔离收发器变成隔离接口。

## 7. MCU、时钟、模拟量与射频

- MCU 每个电源脚或电源脚组就近放 100nF 去耦，另设局部储能电容，见 [[11、MCU最小系统与存储电路]]。
- 8MHz、32.768kHz 晶振紧贴 MCU，走线短、对称，周围禁止放 DCDC 电感、继电器和高速边沿信号。
- ADC 分压与 LM358 靠近 MCU ADC 引脚，采用安静的参考地，远离继电器驱动回流，见 [[10、模拟量采样与运放缓冲电路]]。
- WiFi 天线区保持净空，天线馈线采用设计要求的受控阻抗；不在天线下方穿线或铺不受控铜皮，见 [[09、WiFi通信与天线电路]]。

## 8. 画板后的复核清单

- [ ] 入口 TVS 是否在连接器旁，且到地回路是否短宽？
- [ ] PTC、防反接器件、功率 MOS、DCDC 和电感的持续电流/温升是否做过计算？
- [ ] DCDC 的 VIN-CIN-SW-Diode/GND 脉冲环路是否最小？
- [ ] SW 节点是否远离反馈、晶振、ADC、通信与天线？
- [ ] 每个外部接口是否先经过适当 ESD/TVS，再进入内部 IC？
- [ ] 隔离两侧是否完全没有铜皮、过孔、测试点或走线跨越？
- [ ] 继电器触点与低压控制区是否满足间距、开槽和端子安全要求？
- [ ] 大电流回流是否避开 MCU、ADC、晶振和通信参考地？
- [ ] CAN/RS485 终端与差分走线是否符合系统拓扑？
- [ ] 天线、晶振、模拟量和 DCDC 是否已做物理隔离？
