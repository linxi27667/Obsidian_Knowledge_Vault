# 11、MCU最小系统与存储电路

> 原图位置：第 5 页。主控为 U7.1/U7.2：STM32F407ZET6。

## 电路由哪几部分组成

| 部分 | 原图器件 | 作用 |
|---|---|---|
| MCU | U7.1、U7.2：STM32F407ZET6 | 运行程序，处理 DI/DO、通信、ADC 和控制逻辑。 |
| 数字电源滤波 | L2、C114-C126 等 | 将 3.3V 分配给 MCU，并在各电源脚附近去耦。 |
| 模拟电源滤波 | L3、C127：4.7uF、C128：100nF | 为 VDDA/VREF 等模拟域提供较干净的电源。 |
| 主时钟 | X1：8MHz、C110/C111 | 为 MCU 提供高速外部时钟。 |
| 低速时钟 | X2：32.768kHz、C131 等 | 为 RTC 提供低功耗、长期计时基准。 |
| 复位 | SW2、R177、C130 | 上电复位和手动复位。 |
| 调试接口 | J1/J2、T5、U12 等 | SWD/调试信号与 ESD 保护。 |
| EEPROM | U51：AT24C02 | 保存小容量参数、配置或校准值。 |
| SPI Flash | U5：W25Q128JVSIQ | 保存固件、日志、较大参数或文件。 |
| 指示灯 | LED1/LED2/LED3、R173-R175 | 指示运行、通信、故障状态。 |

## MCU 电源电路

### 为什么每个电源脚旁都要放电容

MCU 内部逻辑在时钟边沿会瞬间取电。若电源路径电感和阻抗过大，电源脚会出现瞬态跌落和噪声。

- 100nF：主要处理高频瞬态，放在每个或每组 VDD/VSS 附近。
- 1uF/4.7uF/10uF：提供较低频储能，降低整片 MCU 电源纹波。
- 磁珠 L2/L3：隔离数字域与模拟域的高频噪声。

### VDDA / VREF 的处理

- ADC、参考电压、PLL 等对电源噪声更敏感。
- L3 和 C127/C128 对模拟电源进行局部滤波。
- 模拟地应与数字地在受控位置连接，避免继电器和 DCDC 回流穿过模拟参考区。

## 时钟与复位

### X1：8MHz 主晶振

- 提供 MCU 高速时钟基准。
- 两颗负载电容必须按晶振 CL、寄生电容和 MCU 手册选择。
- 晶振与电容靠近 MCU，走线短且对称，远离 SW 节点和高速功率线。

### X2：32.768kHz RTC 晶振

- 用于低功耗时钟和时间保持。
- 对漏电和噪声敏感，周围保持干净，避免高速数字线穿过。

### 复位网络

- R177 将 RESET 默认拉高。
- C130 形成上电延时/抗干扰滤波。
- SW2 手动将 RESET 拉到有效状态。
- 复位线不能靠近继电器、MOS 开关和通信线。

## 存储器作用

### AT24C02：I2C EEPROM

- 容量小，适合设备地址、配置、校准系数。
- 有擦写寿命，频繁写入日志不合适。
- I2C 的 SCL/SDA 需要上拉电阻，长度较长时注意总线电容。

### W25Q128：SPI Flash

- 容量更大，适合固件、日志和参数文件。
- SPI 走线在高频时需要控制长度、回流与串联阻尼。
- 写入前需擦除扇区，软件要管理磨损与掉电保护。

## 原图与新板的建议

原图使用 STM32F407ZET6，资源较多。若新举升机板 I/O 和性能需求较低，STM32F103C8T6/RCT6 可能更符合成本目标；但电源去耦、复位、时钟、下载接口和模拟电源分区原则不变。
