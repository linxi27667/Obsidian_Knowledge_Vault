# CC2530 核心与 2.4 GHz 前端

## 核心概念

- ==CC2530 的 RF_P/RF_N 是差分射频端口，不是普通 GPIO==。
- ==CC2530 的调试接口是 DD=P2_1、DC=P2_2；物理脚号分别为 35、34==。
- ==DCOUPL 是芯片内部数字电源去耦节点，TI 典型应用使用 1 µF；不要把它当成普通 3.3 V 输出给外部电路==。
- 官方参考设计的匹配值是特定设计的起点，不是所有板子都固定使用同一组值。

## 一、CC2530 QFN40 引脚地图

| 功能 | 管脚 | 物理脚号 | 备注 |
|---|---|---:|---|
| P0_0…P0_7 | GPIO | 19…12 | P0_0=19、P0_7=12 |
| P1_0…P1_5 | GPIO | 11、9、8、7、6、5 | 具体复用看用户指南 |
| P1_6、P1_7 | GPIO | 38、37 | 也可用于外设复用 |
| P2_0 | GPIO | 36 |  |
| P2_1 | DD | 35 | 调试数据 |
| P2_2 | DC | 34 | 调试时钟 |
| P2_3/P2_4 | GPIO/32 kHz XOSC | 33/32 | 不用 32 kHz 晶振时可作 GPIO |
| RESET_N | 复位输入 | 20 | 低有效 |
| RF_N/RF_P | 差分 RF | 26/25 | 靠近匹配网络 |
| XOSC_Q1/Q2 | 32 MHz 晶振 | 22/23 | 不要接普通长线 |
| RBIAS | 偏置电阻 | 30 | 参考设计常见 56 kΩ，按器件/版本核对 |
| AVDD1…6 | 模拟电源 | 28、27、24、29、21、31 | 统一接芯片规定的供电网络 |
| DVDD1/DVDD2 | 数字电源 | 39/10 | 按官方参考设计去耦 |
| DCOUPL | 数字去耦节点 | 40 | 典型 1 µF 到地 |
| GND | 地 | 1、2、3、4、裸露焊盘 | 焊盘连接按数据手册与封装建议执行 |

## 二、电源与去耦

CC2530 的 AVDD/DVDD 在系统上通常由同一颗 3.3 V 电源供电，但每个电源脚附近要按参考设计放置本地去耦。不要为了“模拟电源和数字电源分开”而在芯片电源入口随意串磁珠，除非已经考虑电流、压降、谐振和回流路径。

~~~text
3.3V主电源 ───────────────┬─ CC2530 AVDD/DVDD
                          ├─ 100 nF（每个关键电源脚附近）
                          ├─ 1 µF / 4.7 µF（芯片局部储能）
                          └─ 必要时才对外部噪声模块单独加磁珠
DCOUPL ──────────────────── 1 µF ─ GND
~~~

磁珠应根据阻抗曲线和额定电流选择，不能只看“600 Ω”这个单一数字。对于 RC522、ESP-12F 等外部模块，可把隔离放在模块电源入口，并保持主控电源的回流路径可控。

## 三、晶振与 RF 端口

32 MHz 晶振靠近 XOSC_Q1/Q2，两个负载电容靠近晶振和芯片。电容值应根据晶振负载电容、寄生电容和 TI 参考设计确定；对话中出现的 12 pF、15 pF、27 pF 不能混用。TI 典型应用中的 32 MHz 负载电容是 27 pF，但最终仍需核对所选晶振。

RF 走线顺序应是：

~~~text
RF_N/RF_P → 差分短线 → Balun/匹配网络 → 50 Ω单端线 → 天线
~~~

RF 线下方需要稳定的参考地；不要在其下方随意切割地平面，不要让高速数字线穿过匹配和天线区域。

## 四、Balun、匹配网络与 50 Ω

Balun 将差分端口转换为单端端口。LC 元件的作用可能同时包含：

- 差分到单端的变换；
- 阻抗变换；
- 直流隔离或交流耦合；
- 滤除不需要的谐波；
- 对天线、连接器和 PCB 寄生进行补偿。

TI 参考设计中的典型起始值包括 18 pF、2 nH、1 pF、2.2 pF 等，但元件编号和具体位置必须对应原理图。不要根据“两根正弦波合成一个正弦波”或“固定相差 90°”推导所有 RF 匹配值。

“天线是 50 Ω 电阻”是过度简化。更准确的说法是：在目标频率和参考平面上，系统希望天线端口经过匹配后接近 50 Ω；真实阻抗包含电阻性和电抗性部分，并受外壳、地平面、附近金属和环境影响。

## 五、CC Debugger 连接

TI CC Debugger 目标连接器的关键脚：

| CC Debugger | 目标板 | 说明 |
|---:|---|---|
| 1 | GND | 地 |
| 2 | Target Voltage Sense / 板上 VDD | 让调试器检测目标电压 |
| 3 | DC | 接 CC2530 P2_2，物理脚 34 |
| 4 | DD | 接 CC2530 P2_1，物理脚 35 |
| 7 | RESETn | 接 CC2530 RESET_N，物理脚 20 |
| 9 | Debugger 3.3 V | 仅在需要由调试器供电时使用 |

如果板子由 USB 或外部电源供电，通常仍连接目标电压检测脚，但不需要把调试器 3.3 V 并到板上电源，避免两个电源源头互相顶住。

## 六、接口配置示例

下面只是表达连接关系；实际 USART 复用位置、优先级寄存器和 GPIO 复用必须对照 CC2530 用户指南配置：

~~~c
/* 调试接口：硬件连接，不是普通 UART */
#define CC2530_DD_PIN   P2_1   /* physical pin 35 */
#define CC2530_DC_PIN   P2_2   /* physical pin 34 */

/* UART 交叉连接原则 */
#define HOST_TX  -> CC2530_RX
#define HOST_RX  <- CC2530_TX

/* 上电后建议检查：
 * 1. VDD 电压和纹波
 * 2. RESET_N 是否释放
 * 3. 32 MHz 晶振是否起振
 * 4. DD/DC 是否能被 CC Debugger 识别
 */
~~~

## 接口 / 器件 API 速查表

| 接口/节点 | 类型 | 关键约束 |
|---|---|---|
| RF_P/RF_N | 差分 RF I/O | 走线短、对称、连续地、紧邻匹配网络 |
| DD/DC | 调试接口 | P2_1/P2_2，不能与其他强驱动复用 |
| RESET_N | 复位 | 低有效，调试器需要访问 |
| XOSC_Q1/Q2 | 模拟晶振 | 远离数字时钟和 RF 输出 |
| RBIAS | 模拟偏置 | 精密电阻，靠近芯片 |
| DCOUPL | 内部去耦节点 | 只按数据手册连接电容 |
| USART | 数字串行 | 先确认 location/优先级，再核对 TX/RX |

## 完整示例：CC2530 最小可验证链路

1. 放置 CC2530、32 MHz 晶振、负载电容、RBIAS、DCOUPL 电容和全部电源去耦。
2. 引出 DD、DC、RESET_N、目标电压和 GND 测试点。
3. 先不接天线，完成上电和 CC Debugger 识别。
4. 再按 TI CC2530EM 参考设计复制 RF 匹配区。
5. 最后连接 50 Ω 天线线和天线 keepout，使用实际叠层计算线宽并做射频验证。
