# 调试、验证与常见错误

## 核心概念

- ==调试要分层：电源 → 复位/时钟 → 数字接口 → 射频发射/接收 → 空间性能==。
- “能烧录”不等于 RF 正常；“能读卡”也不等于线圈调谐、EMI 和批量一致性合格。
- 每个关键结论都要有证据：数据手册、原理图网络、实测电压/波形或仪器结果。
- 发现原理图看不清时，应先重新导出/放大/核对网络名，而不是凭图形猜脚号。

## 一、原理图审核

按模块逐项检查：

| 模块 | 必查项 |
|---|---|
| CC2530 | 所有 AVDD/DVDD、DCOUPL、RBIAS、晶振、RESET_N、RF_P/RF_N |
| CC Debugger | P2_1=DD、P2_2=DC、RESET_N、目标电压、GND |
| MFRC522 | SPI 模式控制脚、TX1/TX2、RX/VMID、晶振、各电源/地 |
| ESP-12F | EN/RST/IO0/IO2/IO15、VCC去耦、UART交叉 |
| CH340N | 供电、D+/D−、TX/RX、USB-C CC脚 |
| TPS54302 | VIN、PGND、SW、BOOT、FB、分压、输入输出电容 |
| 天线 | 匹配网络、网络名、keepout、板框和连接器 |

## 二、上电与烧录流程

~~~text
断开射频负载
  ↓
检查短路/电阻
  ↓
限流电源上电
  ↓
测 3.3 V、DCDC纹波、芯片VDD
  ↓
测 RESET_N 与晶振
  ↓
CC Debugger 识别 CC2530
  ↓
烧录最小固件
  ↓
串口/SPI回环或读寄存器
  ↓
开启 RF/读卡/联网
~~~

CC2530 第一次烧录优先使用 CC Debugger。只有芯片里已经存在合适的串口 bootloader，才可通过 UART 进行后续烧录；不能把 CH340N 直接当作 CC Debugger 替代品。

## 三、CC2530 验证

- 目标电压检测脚是否接到板上 3.3 V？
- DD、DC、RESET_N 是否被其他外设强驱动？
- 32 MHz 晶振是否起振？
- DCOUPL 是否按官方连接？
- RF 匹配元件是否错位、短路或漏装？
- 天线是否被铜、螺丝、外壳遮挡？
- 若能烧录但无线异常，先检查时钟、供电和 RF 区，而不是先改软件协议。

## 四、MFRC522 验证

1. 3.3 V稳定，NRSTPD 释放。
2. 选择 SPI，确认 NSS 独立控制。
3. 读取 VersionReg，确认 SPI 时序和片选。
4. 写入最小初始化寄存器。
5. 打开天线驱动，测量 TX1/TX2/线圈波形。
6. 无卡、贴卡、不同方向分别测试。
7. 观察线圈谐振频率、场强、读卡距离和误码。
8. 若读卡不稳定，检查线圈参数、匹配、电源纹波和周边金属。

RX 上有负电压、或者电容会不会反向流回 RX，不能只靠直流等效解释；要以数据手册允许的波形范围、探头负载、示波器测量点和参考电路为准。

## 五、常见错误与修正

| 错误直觉 | 修正 |
|---|---|
| 天线就是 50 Ω电阻 | 天线端口是频率相关复阻抗，50 Ω是系统目标 |
| 低通就是砍波峰 | 低通是频率响应，不是简单限幅 |
| 电容充满后永远断路 | 交流状态下由阻抗决定，且有 ESR/ESL/SRF |
| 所有电源脚串磁珠更干净 | 可能压降、谐振、破坏回流 |
| 四层板自动得到 50 Ω | 必须基于实际叠层计算 |
| 所有 RF 线都要做漂亮蛇形 | 过密蛇形可能增加寄生和串扰 |
| 底部焊盘一定必须接地 | 以具体器件数据手册为准；MFRC522 允许不接 |
| 能烧录就代表板子没问题 | 仅说明一部分数字链路可用 |

## 接口 / 器件 API 速查表

| 测试点 | 工具 | 通过标准 |
|---|---|---|
| 3.3 V入口/模块VCC | 万用表、示波器 | 电压在规格内、纹波可接受 |
| RESET_N | 示波器 | 上电后正确释放，无异常抖动 |
| XOSC | 示波器/有源探头 | 频率和幅度符合器件要求 |
| DD/DC | CC Debugger | 可识别、可擦写、可校验 |
| MFRC522 SPI | 逻辑分析仪 | NSS/SCK/MOSI/MISO时序正确 |
| DCDC SW | 有源探头 | 无异常振铃/过冲 |
| 2.4 GHz RF | 频谱仪/VNA | 频点、回波损耗、输出符合预期 |
| 13.56 MHz线圈 | 示波器/VNA | 谐振与场强稳定 |

## 完整示例：故障树

~~~text
无线不工作
├─ 3.3 V不对？──── 是 → 查DCDC/压降/负载
├─ RESET_N异常？── 是 → 查上拉/调试器/复位源
├─ 晶振不振？───── 是 → 查晶振、负载、电源、布局
├─ 能烧录吗？───── 否 → 查DD/DC/目标电压/复位
├─ SPI可读寄存器？ 否 → 查CS、时序、模式、供电
├─ RF有输出吗？─── 否 → 查匹配、时钟、寄存器
└─ 有输出但距离差？
   └→ 查天线、keepout、阻抗、外壳和周围金属
~~~
