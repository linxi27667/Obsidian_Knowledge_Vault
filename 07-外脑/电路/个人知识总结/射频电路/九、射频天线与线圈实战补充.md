# 射频天线与线圈实战补充

> 本页整理新增分享页中原第 161～241 轮，重点覆盖四层板布局、CC2530 2.4 GHz 天线、MFRC522 13.56 MHz PCB 线圈、TX/RX 走线和中心抽头争议。原对话中的参考值已区分为“项目规则”“起始值”和“必须实测”。

## 核心概念

- ==2.4 GHz 板载倒 F/蛇形天线优先放在板边或板角，馈线和匹配网络必须短，不能随意加长。==
- ==13.56 MHz PCB 线圈不是一个可直接购买的 0603 天线元件，而是 PCB 上定制的印制线圈。==
- ==普通两端子线圈只连接两个天线端点；几何中心空白区域不能因为“想找地回流”而放地铜或地孔。==
- ==中心抽头接地只有在原理图明确提供第三个中心抽头端点、且参考设计就是该拓扑时才成立。不能把另一颗芯片的中心抽头天线直接套到 MFRC522。==
- ==电气连接正确不等于 PCB 物理布局正确==：RF 匹配、RX、天线和 DCDC 都要同时检查网络、回流路径和寄生参数。

## 一、四层板的后续布局分工

推荐的起始层叠仍是：

~~~text
L1：器件、CC2530 RF、Balun、匹配、晶振、关键短线
L2：完整连续 GND 参考平面
L3：3.3 V / 5 V 等电源平面或分区
L4：低速 GPIO、LED、按键、蜂鸣器控制、部分调试线
~~~

低速信号和烧录线可以优先安排到 L4，但必须避开 2.4 GHz 天线、13.56 MHz 线圈、RF 匹配区和晶振投影区域。通孔会穿过 L2，但 L2 通过反焊盘 Anti-pad 把该过孔与地铜隔离；这不是“钻孔把地层打通后必然短路”。

CC2530 的 P0_0 可以控制蜂鸣器，但不要直接驱动大电流蜂鸣器。应使用三极管或 MOSFET，并加续流二极管（若负载是电感性），把 GPIO 当作控制信号。

### 1.1 走线规则示例

~~~text
低速 GPIO/烧录线 → L4
SPI/UART          → L1 或 L4，避开天线和 RF 投影
RF_N/RF_P        → L1，短直进入 Balun
Balun 后单端线    → L1，按当前叠层 16 mil 起始
L2               → 尽量只保留连续 GND
~~~

| 对象 | 当前项目建议 | 验证方式 |
|---|---|---|
| P0_0 蜂鸣器 | 只驱动外部开关器件 | 检查 GPIO 电流和负载电流 |
| L4 低速线 | 可以走，但避开天线 Keepout | 3D/层检查、DRC |
| L2 | 保持完整 GND | 检查分割、孤岛和回流过孔 |
| L3 | 作为电源层时避开 DCDC 噪声耦合 | 核对电源分区和 RF 投影 |

## 二、CC2530 2.4 GHz 天线走线

CC2530 射频链路按以下顺序布置：

~~~text
RF_N/RF_P → 8～10 mil 紧凑差分段 → Balun/LC匹配
         → 16 mil 单端 50 Ω起始线 → 板载倒F/蛇形天线
~~~

### 2.1 芯片端到 Balun

8～10 mil 是当前项目的封装和工艺优先级：QFN 引脚间距小，0402 焊盘密集，线宽过大容易堵住焊盘、增加连锡风险。这个数值不等于该段已经完成 50 Ω 阻抗控制；芯片侧差分段应以 TI 参考布局和实际寄生为主。

### 2.2 Balun 到天线

16 mil 是当前嘉立创 1.6 mm 四层 7628 叠层、L1 到 L2 约 0.21 mm 假设下的 50 Ω 起始值。只要板厂实际介质厚度、铜厚、板材或叠层改变，就必须重新计算。匹配电容焊盘到天线起点的线也属于 RF 结构，不要为了“绕得好看”随意增加长度。

Balun 区的保守规则是：L1 不放其他信号/电源穿越，匹配元件紧凑，L2 保持连续 GND。L3 是否需要局部避让，取决于 L1-L2 距离和参考设计；不能简单说所有内层都必须无铜，但绝不能破坏 L2 的 RF 参考面。

### 2.3 板载天线位置

倒 F/蛇形天线通常应靠近板边或板角，让辐射端面向自由空间。放在 PCB 正中央不是绝对禁止，但必须是经过专门设计、仿真和调谐的天线结构；对当前学习板，采用板边布局和官方 Keepout 更稳妥。

不要把“2.4 GHz 波长约 125 mm”直接换算成一段可以任意增加的馈线长度。馈线、焊盘、过孔、板框和天线本体共同构成射频结构，长度变化会移动谐振点。

## 三、MFRC522 线圈天线拓扑

### 3.1 先区分两端子和三端子

常见的 MFRC522 参考电路是两端子线圈：匹配网络的两个天线端点分别连接线圈两端，线圈自身是跨接在两个网络之间的电感负载。

~~~text
端点 A / ANT1 ─── PCB 线圈 ─── ANT2 / ANT2
                         （线圈内部不放 GND）
~~~

另一类芯片或评估板可能使用三端子中心抽头线圈：

~~~text
TPA ── 半段线圈 ──●── 半段线圈 ── TPB
                  │
                 GND
~~~

中心抽头不是“任何差分天线都应该接的地”。只有当当前芯片的原理图、匹配网络和参考设计明确给出 TPA、TPB、GND 三个端点时，才能使用它。若当前 MFRC522 原理图只有两个天线网络，就不要在几何中心空白区域额外打地孔。

### 3.2 两个中心不要混淆

| 名称 | 含义 | 是否可放地孔 |
|---|---|---|
| 电气中心抽头 | 三端子线圈中两半线圈的实际交汇点 | 只有原理图明确要求时才可 |
| 几何中心空白区 | 线圈包围的内部孔径 | 不应放地线、地铜、地孔或器件 |

TX1 和 TX2 如果通过一个两端子线圈形成直流通路，用万用表测到低电阻并不代表把它们直接短接到 GND。真正工作的对象是线圈的电感、匹配电容、损耗和谐振；“看起来像短路”不能替代拓扑分析。

## 四、PCB 线圈的绘制与调谐

PCB 环形天线、印制线圈天线、PCB 螺旋天线本质上都是 PCB 铜线的几何结构，不一定有现成封装。可以把原理图中的两个天线端点通过网络标签或天线连接器引出，再在 PCB 中自定义线圈。

### 4.1 线圈参数

线宽 20～30 mil、线间距 15～20 mil、3～4 圈、约 4×6 cm 等可以作为参考工程的起始参数，但不是 MFRC522 的通用定值。真正要确定的是：

- 线圈电感量 L；
- 线圈串联电阻和 Q 值；
- 匹配电容后的谐振频率；
- 无卡、贴卡、不同卡片和周边金属下的变化；
- TX 输出幅度、接收灵敏度和读卡距离。

基本谐振关系：

~~~text
f0 = 1 / (2π√(LC))
XL = 2πfL
~~~

“目标 1.1 µH”只在对应的参考匹配网络和线圈结构下有意义。不能只看一个电感数字就决定圈数；应使用线圈计算、参考设计、LCR/VNA 测量和实际调谐共同确认。

### 4.2 过孔、跨线和焊盘

- 线圈需要跨线时，可以使用过孔，但过孔应放在走线外侧、远离敏感匹配焊盘。
- 普通 SMD 焊盘上的通孔可能造成锡膏流失；盘中孔需要填孔、盖孔或板厂明确支持。
- 线圈内部空白区不要为了“引出地”而打孔。
- 天线所在区域按当前项目采用 L1～L4 Keepout；外部 GND 铜、过孔和金属件也要留出安全距离。
- 线圈拓扑、匹配网络和 PCB 网络名必须一致，不能只靠飞线标记判断“已经连接”。

## 五、RX、TX 和内层借道

MFRC522 的 RX 是敏感模拟接收节点，优先在 L1 短距离连接，远离 TX1/TX2、大电流发射回路、DCDC SW 和数字时钟。必须换层时，先检查换层后的参考平面和回流路径；在 SIG-GND-PWR-SIG 叠层中，L4 并不是天然直接参考 L2。

TX1/TX2 的 9 mil 长度差对 13.56 MHz 的相位影响很小，但保持对称仍有助于寄生一致性。对于 C46、R23 等处的较长连接，不能只用“波长很长所以绝对没问题”下结论；如果它属于高 Q 匹配/接收网络，线长、焊盘和过孔寄生仍可能改变调谐。

理想原理图中并联支路的电气顺序可以交换，但 RF PCB 上的物理顺序并不完全无关：每个支路到公共节点的线长、公共回路电感、焊盘寄生和回流路径都会影响实际结果。因此匹配电容阵列要按照参考布局摆放，不要只按“并联网络等价”随意拉线。

~~~c
/* MFRC522 RF routing review */
if (is_rx_net(net)) {
    keep_short(net);
    keep_away_from(net, TX1_NET);
    keep_away_from(net, TX2_NET);
    keep_away_from(net, DCDC_SW);
    verify_return_path_after_layer_change(net);
}
~~~

| 网络 | 优先层 | 约束 |
|---|---|---|
| TX1/TX2 | L1 | 对称、短、按参考匹配拓扑 |
| RX | L1 优先 | 短、远离 TX 和 DCDC |
| SPI | L1/L4 | 可换层，避开天线和模拟敏感区 |
| 低速 GPIO | L4 | 不穿越天线 Keepout |
| GND | L2 | 连续平面，配合回流过孔 |

## 六、参考设计到底该怎么抄

参考设计必须满足“同芯片、同频段、同天线拓扑、相近 PCB 叠层”四个条件。不能看到另一个芯片的天线绕法，就把它的中心抽头、阻尼电阻或 1.1 µH 直接搬过来。

评估板上常见的多组 C/R 焊盘可能是可调的 Pi/T 型网络或调试预留位。它们不代表所有元件都必须同时焊接。对于自己的学习板：

1. 先画清楚当前芯片的标准匹配网络；
2. 为 0 Ω、阻尼电阻或备选电容预留明确位号；
3. 用网络标签确认每个焊盘的两端网络；
4. 先按参考值装配；
5. 再用测试结果决定是否更改。

Altium 的 SchDoc/PcbDoc 可以作为学习资料导入立创 EDA，但导入后必须重新核对封装、网络、规则、层叠、Keepout 和未布线标记。DRC 忽略只是隐藏报错，不是修复连接。

## 七、完整示例：本项目的天线落地流程

### 示例：CC2530 + MFRC522 四层学习板

1. L1 放 CC2530、Balun、匹配元件、晶振和 MFRC522 模拟匹配。
2. L2 整面 GND；L3 分配 3.3 V；L4 放低速 GPIO、蜂鸣器控制和必要调试线。
3. CC2530 RF_N/RF_P 用 8～10 mil 紧凑差分段进入 Balun。
4. Balun 输出到板载倒 F 天线采用当前叠层计算后的 16 mil 单端线，天线靠近板边。
5. 2.4 GHz 天线 L1～L4 设置 Keepout，馈线只保留必要长度。
6. MFRC522 先确认原理图是两端子还是三端子天线；两端子方案不在几何中心加 GND。
7. PCB 线圈从两个明确的 ANT 网络引出，线宽/间距/圈数作为可调参数，不把 1.1 µH 当成盲目固定值。
8. RX 走最短安全路径，尽量不穿过 TX1/TX2；必须换层时检查相邻参考层。
9. 最后铺 L2 GND、检查天线 Keepout、跑 DRC，再进行限流上电和实际读卡/无线测试。

## 接口 / 器件 API 速查表

| 名称 | 设计含义 | 当前项目动作 |
|---|---|---|
| RF_N/RF_P | CC2530 2.4 GHz差分端 | 8～10 mil紧凑走入 Balun |
| Balun | 差分/单端和阻抗变换网络 | 元件紧凑，L2连续GND |
| 50 Ω馈线 | Balun到2.4 GHz天线的单端线 | 16 mil仅作为当前叠层起始值 |
| IFA/蛇形天线 | 2.4 GHz板载远场天线 | 板边/板角，按参考Keepout |
| PCB Loop/Spiral | 13.56 MHz印制线圈 | 自定义几何，不是0603器件 |
| TX1/TX2 | MFRC522发射端 | 按实际匹配拓扑连接 |
| RX | MFRC522敏感接收端 | 短、远离发射和开关节点 |
| Center Tap | 三端子线圈电气中点 | 只有参考设计明确要求才接GND |
| Anti-pad | 过孔穿越平面时的隔离区 | 防止与L2 GND意外短路 |
| Keepout | 禁止铺铜/器件/过孔区域 | 天线区当前采用全层净空 |

## 附录：射频天线布线检查表

- [ ] CC2530 芯片到 Balun 是否为 8～10 mil 紧凑差分段？
- [ ] Balun 到 2.4 GHz 天线的 16 mil 是否基于最终板厂叠层复核？
- [ ] 2.4 GHz 天线是否靠近板边，并且没有被器件、铜和螺丝包围？
- [ ] 2.4 GHz 天线 L1～L4 Keepout 是否完整？
- [ ] 当前 MFRC522 原理图到底是两端子还是三端子线圈？
- [ ] 两端子线圈的两个网络是否与 PCB 线圈的两个端点一致？
- [ ] 是否误把几何中心空白区当成中心抽头？
- [ ] 是否把另一个芯片的中心抽头天线拓扑直接套给 MFRC522？
- [ ] RX 是否短且远离 TX1/TX2、DCDC SW 和晶振？
- [ ] 过孔是否避开普通 SMD 焊盘，且有正确 Anti-pad？
- [ ] 并联匹配网络是否按照参考布局，而不是只按原理图等价性随意排列？
- [ ] 已完成 DRC、上电电流、3.3 V纹波、谐振和实际读卡/联网测试？
