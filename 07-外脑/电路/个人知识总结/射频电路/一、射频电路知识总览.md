# 射频电路知识总览

> 这份笔记把本次对话中的“为什么”整理成一条完整链路：芯片产生/处理信号，匹配网络变换阻抗，传输线把能量送到天线，电源与地平面保证系统稳定。

## 核心概念

- ==射频不是 TTL 方波直接从天线发出去==。芯片内部完成调制、变频、放大和收发切换，外部主要负责供电、时钟、匹配、传输线和天线。
- ==阻抗不是一个固定电阻==。在指定频率、指定参考平面上，天线和匹配网络表现为复阻抗；“50 Ω”是系统接口目标。
- ==两块射频电路可以共存，但必须按频段和空间隔离==：CC2530 工作在 2.4 GHz，MFRC522 工作在 13.56 MHz，ESP-12F 也包含 2.4 GHz 射频。
- ==四层板的核心价值是连续参考平面==，不是层数越多阻抗就自动越高或越低。

## 一、整机信号链

~~~text
USB-C 5 V
   │
   ├─ 防反接/保护 ─ TPS54302 Buck ─ 3.3 V 电源
   │                                  ├─ CC2530
   │                                  ├─ ESP-12F
   │                                  └─ MFRC522
   │
MCU data ─ SPI/UART ─ CC2530 ─ RF_P/RF_N ─ LC Balun ─ 50 Ω线 ─ 2.4 GHz 天线
       │
       └─ SPI ─ MFRC522 ─ TX1/TX2 ─ 匹配网络 ─ 13.56 MHz 线圈天线
~~~

### 1. 数字域、模拟域和天线域

数字域包含 MCU、SPI、UART、USB、寄存器和协议；模拟/RF 域包含晶振、PA/LNA、混频、匹配网络、接收放大器和天线。二者不是靠“把方波滤成正弦波”简单连接起来，而是由芯片内部功能模块完成信号处理。

### 2. 差分与单端

CC2530 的 RF_P/RF_N 是差分射频端口，常通过离散 Balun 变成单端 50 Ω 接口。Balun 同时承担差分/单端变换与阻抗变换；后面的电容、电感是匹配网络，必须结合参考设计、PCB 叠层、天线和实测调谐。

### 3. 近场与远场天线

2.4 GHz 天线通常是远场辐射天线，布局重点是 50 Ω 线、地参考和天线净空。MFRC522 的 13.56 MHz 读卡线圈主要依靠磁场近场耦合，重点是线圈尺寸、匝数、线宽、间距、Q 值、匹配和卡片负载；不能拿 2.4 GHz 天线的经验直接套用。

## 二、频率与波形的正确直觉

- 方波由基波和多次谐波组成。
- 低通网络会衰减高次谐波，输出可能更接近正弦波，但它不等于把所有波峰砍平。
- 高通网络会衰减低频和直流分量；它也可能改变方波形状，但不能简单理解成只把波谷变低。
- 电容/电感在某个频率上的行为由阻抗决定；实际器件还受 ESR、ESL 和自谐振频率影响。

## 三、工程上的优先级

1. 先确认器件数据手册、封装、管脚号和接口模式。
2. 复制官方参考设计的拓扑、叠层假设和关键元件位置。
3. 再根据实际 PCB 厂叠层计算 50 Ω 线宽。
4. RF、晶振、去耦和电源热回路优先布置，普通 GPIO 最后处理。
5. 通过 DRC、上电电流、示波器、频谱/VNA 和实际读卡/联网结果验证。

## 四、完整示例：本项目的分区草图

~~~text
┌────────────────────────────────────────────┐
│  CC2530 RF匹配/天线区       Zigbee 2.4G天线 │
│  (短、连续GND、keepout)                   │
│                                            │
│  CC2530       主控/调试/CH340              │
│                                            │
│  MFRC522 + 13.56M线圈      ESP-12F + Wi-Fi │
│  (线圈净空)                (模组天线净空)  │
│                                            │
│  USB-C → 保护 → TPS54302 → 3.3V            │
└────────────────────────────────────────────┘
~~~

布局只是起点。若 ESP-12F 是带板载天线的模组，模组天线端必须伸出板边或按模组厂 keepout 执行；若 MFRC522 线圈在 PCB 上，则线圈区域不能被电源层、地铜或其他金属结构破坏。

## 接口 / 器件 API 速查表

| 对象 | 作用 | 设计关键词 |
|---|---|---|
| CC2530 RF_P/RF_N | 2.4 GHz 差分 RF | Balun、50 Ω、短线、连续参考地 |
| CC2530 XOSC_Q1/Q2 | 32 MHz 晶振 | 靠近芯片、短、对称、远离 RF 线 |
| MFRC522 TX1/TX2 | 13.56 MHz 发射输出 | 参考匹配、线圈天线、净空 |
| MFRC522 RX/VMID | 接收与内部参考 | 按官方参考图走线和去耦 |
| SPI | 芯片到主控寄存器/数据接口 | 不是 RF；可换层，但避免穿越天线 |
| TPS54302 | 5 V/更高输入转 3.3 V | 热回路最小化、输入/输出电容靠近 |
| 磁珠 | 频段相关的噪声隔离 | 不是必装；要看电流、阻抗曲线、压降 |
