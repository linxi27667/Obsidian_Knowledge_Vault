# 四层 PCB 布局布线与阻抗

## 核心概念

- ==四层板最重要的是让 RF/高速线看到连续、稳定的参考地==。
- ==本项目把 CC2530 射频线分为 8～10 mil 差分段和 16 mil 单端 50 Ω段==；其中 16 mil 仅适用于当前假定的嘉立创 1.6 mm 四层 7628 叠层，实际下单前仍须用最终叠层复核。
- ==射频线优先保证参考地、长度短、拓扑正确；普通 GPIO 不必为了好看全部走圆弧==。
- 去耦电容的价值来自“芯片电源脚—电容—地过孔/平面”的小回路，不是来自把多个电容随便堆在一起。
- 天线净空必须按天线类型和参考设计决定，不能使用所有天线下面都不能有任何铜的绝对规则。

## 一、推荐四层思路

一种常见起点：

~~~text
L1：器件、RF、关键高速信号
L2：完整 GND 参考平面
L3：电源与低速信号（视设计而定）
L4：低速信号、控制线
~~~

L2 尽量保持完整，L1 的 RF 线不要跨越 L2 的分割/缺口。若必须换层，给信号过孔附近安排地回流过孔，减少回流绕路。

## 二、布局顺序

1. 先放连接器和机械边界。
2. 放置天线与 keepout，确定不能被占用的区域。
3. 放置 CC2530、Balun、匹配元件和 RF 线。
4. 放置 MFRC522、线圈及其匹配网络。
5. 放置晶振和去耦电容。
6. 放置 TPS54302 的 VIN、SW、BOOT、FB、GND 热回路。
7. 放置 ESP-12F，确保模组天线区域伸出板边或符合其 keepout。
8. 最后安排 SPI、UART、GPIO 和测试点。

ESP-12F 放右下、Zigbee 天线放右侧是否可行，取决于模组天线方向、板边、金属物和另一根天线的距离；位置本身不能替代天线厂商的净空要求。

## 三、去耦电容的摆放

优先级是：

~~~text
电源脚 → 最短铜线 → 100 nF → 最短回地路径/地过孔 → L2 GND
~~~

相邻电源脚可以共享一组局部电容，但不要把所有 100 nF 集中在一处当作等价方案。RF 芯片的每个关键电源脚、DCDC 的输入/输出和模组 VCC 都应就近布置。底面可以放电容，但只有在过孔和回流路径很短时才合适；对首次设计，L1 贴近电源脚更容易成功。

## 四、RF 走线与差分

CC2530 RF_N/RF_P 的差分对应：

- 从芯片到 Balun 尽量短；
- 两根线环境一致，避免一根靠地、一根靠空；
- 线宽/间距按参考设计或场求解计算；
- 不要让晶振、DCDC SW、USB、SPI 长线穿越；
- 匹配元件的焊盘和走线寄生也是电路的一部分；
- 过孔会引入寄生，非必要不换层。

差分等长是一个指标，但不是任何 RF 差分线都必须追求绝对相同长度。比起为了等长做很丑的大蛇形，更重要的是拓扑、参考面、线宽、间距和元件位置。若要蛇形，避免过密、急转和与自身/邻线耦合。

### 4.1 本项目采用的 CC2530 射频分段标准

| 走线分段 | 当前规则 | 设计目的 |
|---|---:|---|
| CC2530 芯片端 → Balun LC 滤波网络 | 8～10 mil，差分段 | 适应 QFN 引脚间距和 0402 焊盘，保持走线紧凑，减少连锡、立碑和不必要寄生 |
| Balun 输出 → 匹配电容 → 天线输入 | 16 mil，单端 50 Ω 微带线 | 按当前嘉立创 1.6 mm 四层板、7628 叠层、L1-L2 约 0.21 mm 的假设作为 50 Ω 起始线宽 |
| 板载倒 F/蛇形天线辐射区 | 按官方天线尺寸走线；L1～L4 全部 Keepout | 减少地铜、过孔、内层电源和周边金属对天线的加载 |

本项目的线宽关系可以记为：

~~~text
CC2530 RF_N/RF_P
       │ 8～10 mil 差分
       ▼
Balun + LC 滤波/匹配
       │ 16 mil 单端 50 Ω微带线
       ▼
板载倒 F / 蛇形天线
       │
       └─ L1～L4 天线 Keepout
~~~

注意：8～10 mil 是芯片端差分布线的工艺/封装约束，不等于该段已经是 50 Ω；16 mil 也不是所有四层板的通用答案。只要板厂实际介质厚度、铜厚或叠层改变，就要重新计算单端 50 Ω线宽。RC522 的 SPI、UART 等普通数字线可以借道底层，但不得进入 2.4 GHz 天线 Keepout、切断 RF 参考地或穿越线圈敏感区域。

## 五、45 度、圆弧和直角

- 普通低速信号：45 度或圆弧主要是可制造性、可读性和美观问题。
- USB D+/D−：按差分阻抗、等长和连续参考面布线。
- RF：短、连续、寄生可控优先；圆弧可以用，但不是必须。
- DCDC SW：面积和回路面积优先，通常短直比漂亮圆弧更重要。
- 晶振：尽量短且对称，避免不必要转弯。

全板都用圆弧不会自动变成高级设计；线型服务于电气约束。

## 六、阻抗与线宽

传输线阻抗由线宽 W、铜厚 T、线到参考平面的高度 H、介电常数 Er 和周围结构共同决定。阻抗控制流程：

1. 向板厂索取/确认实际四层叠层。
2. 明确目标是单端 50 Ω还是差分阻抗。
3. 用板厂阻抗计算器或场求解器得到 W/S。
4. 把 W/S 写入 EDA 规则。
5. 在 Gerber/制造反馈中确认阻抗线结构。

本项目暂定 Balun 后 16 mil 为 50 Ω 单端线、芯片侧 8～10 mil 为差分紧凑段；不要把这两段互换，也不要把 16 mil 或 10 mil 当作所有 RF/匹配线的统一值。Balun 后的单端线、芯片侧差分线和普通电源线可能需要不同规则。最终下单前必须确认嘉立创实际采用的 7628 叠层与 L1-L2 介质厚度，若不是约 0.21 mm，应重新计算。

## 接口 / 器件 API 速查表

| 规则对象 | 建议 |
|---|---|
| L2 GND | 尽量完整，RF 下方不可随意开槽 |
| RF线 | 短、连续参考地、按阻抗设计 |
| 去耦 | 电源脚附近，回流最短 |
| DCDC热回路 | VIN电容、芯片、SW、电感/输出回路紧凑 |
| USB D+/D− | 差分、连续地、少过孔 |
| 天线 | 按天线类型执行 keepout |
| 蛇形线 | 只在确有等长/时序需求时使用 |
| 过孔 | 数字线可换层，RF/晶振谨慎换层 |

## 完整示例：RF 区和电源区的物理隔离

~~~text
[2.4G 天线 keepout]──[50Ω线]──[Balun]──[RF_N/RF_P]──[CC2530]
       ↑ 连续边界地/地过孔栅栏              ↑ 晶振和DCDC远离

[USB-C]──[保护]──[VIN电容]──[TPS54302]──[电感]──[3.3V体电容]
                                         │
                         ┌───────────────┴──────────────┐
                         │ 局部去耦/磁珠（必要时）       │
                         └── CC2530 / ESP-12F / MFRC522 ┘
~~~

RF 区和 DCDC 区不是必须被完全割裂，而是要控制噪声源、回流路径、地平面连续性和空间耦合。

## 附录：DRC 前检查清单

- RF 线下方是否跨越地平面缺口？
- 匹配元件顺序、封装和网络名是否与参考电路一致？
- 去耦是否真正靠近电源脚？
- 天线 keepout 是否包含所有铜层、过孔、丝印禁布和金属件？
- CC2530 芯片端差分段是否保持 8～10 mil？
- Balun 输出到天线的单端线是否按当前叠层采用 16 mil，并完成 50 Ω复核？
- RC522 底层借道是否避开 2.4 GHz 天线 Keepout、RF 参考地和 13.56 MHz 线圈敏感区域？
- DCDC 的 SW 铜皮是否过大、反馈线是否靠近 SW？
- USB D+/D− 是否有正确的差分规则？
- CC Debugger 的 P2_1/P2_2/RESET_N 是否可达？
- 3.3 V 电源是否有足够测试点？
