# 24V 电源入口保护

> 作用：让来自举升机现场的 24V 在进入板内前，先经过过流、浪涌和反接防护。

## 推荐连接顺序

```text
外部 VPP24V -> F1 PTC -> 受保护的 24V 节点 -> D3 防反接 -> VIN_24V
                              |                    |
                           D1 TVS                 输入电容
                              |
                             GND
```

## 每个器件做什么

| 器件 | 作用 | 本板注意事项 |
|---|---|---|
| F1 PTC 自恢复保险丝 | 后级短路或 TVS 失效短路时限流 | 放在输入端最前面，维持电流要大于正常持续电流，动作电流要能覆盖故障。 |
| D1 SMCJ33CA 双向 TVS | 吸收 24V 母线的瞬态过压 | 并在 PTC 后的 24V 节点与 GND 之间，走线短、回地粗。 |
| D3 SS510C 肖特基 | 防止电源正负接反 | 串联在 TVS 后。压降会发热，需计算功耗并留散热铜皮。 |
| C1 小陶瓷电容 | 吸收高频尖峰 | 与 TVS 同处受保护节点，靠近接口/功率回路。 |
| C2 大电容 + C3 小电容 | 给 Buck 输入提供低频储能和高频去耦 | 靠近 TPS54360 的 VIN 与 GND。 |

## 为什么 PTC 放在 TVS 前面

TVS 遇到远超额定能量的浪涌，常见失效方式是短路。若 PTC 在 TVS 后面，TVS 的短路电流会绕开 PTC，输入线束仍可能持续大电流。将 PTC 放在最前面，TVS 短路时电流必须经过 PTC，PTC 才能升温限流。

## TVS 应选一颗还是两颗

优先选用单颗、额定浪涌能力足够的 TVS，例如 `SMCJ33CA`（具体钳位电压与浪涌能力以数据手册为准）。

两颗 `SMBJ33CA` 并联并不会可靠地均分浪涌电流，因为实际击穿电压有公差，较低的一颗会先承担大部分能量。两颗并联不是绝对不能用，但不如单颗更大封装、额定能量足够的 TVS 可控。

## 设计检查

- [ ] F1 位于外部 24V 输入与 TVS 支路之前。
- [ ] TVS 型号、工作反向电压、钳位电压与 TPS54360 VIN 耐压相匹配。
- [ ] D3 的正向电流、反向耐压和散热满足总负载。
- [ ] TVS、输入电容、D3 与 TPS54360 的功率回路很短。
- [ ] 明确 24V 母线的最大持续电流和可能浪涌来源，再最终选 PTC。
