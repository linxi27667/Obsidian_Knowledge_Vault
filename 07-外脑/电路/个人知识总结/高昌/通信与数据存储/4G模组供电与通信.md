# Air780E 供电与通信可靠性

> 作用：让 4G 模组在发射瞬间的电流脉冲和现场网络波动下仍能稳定工作。

## 供电重点

- Air780E 不应由 3.3V LDO 直接供电；应从能力足够的 5V/模组专用电源获得符合其规格的 VBAT 电压。
- 模组电源脚附近放低 ESR 的大容量储能电容，并配合 100nF 高频去耦；具体容量要按 Air780E 数据手册和实测发射峰值确定。
- 5V Buck 的额定电流、电感饱和电流、输出电容纹波电流必须覆盖模组峰值以及其它负载的同时工作。
- 4G 天线、射频走线和 DC/DC 功率开关节点保持距离，天线区域按模组参考设计布局。

## 控制与串口

- USART1 可连接 Air780E，MCU TX 接模组 RX，MCU RX 接模组 TX。
- PWRKEY 和 RESET 的电平、有效时间和上拉方式必须按模组手册确认，不能仅凭“拉低 1.5 秒”固定套用。
- 串口波特率、回显、SIM 卡、信号、注册和数据连接要做成有超时和重试的状态机。

## 断线自恢复

```text
上电 -> AT 握手 -> 关闭回显 -> 检查 SIM -> 检查信号/注册
     -> 建立连接 -> 定时心跳 -> 超时重连 -> 多次失败后硬复位
```

心跳周期、重试次数、硬复位条件和服务器协议要根据实际网络服务确定；不要把对话中的 45 秒、3 次等数值当成芯片硬性要求。
