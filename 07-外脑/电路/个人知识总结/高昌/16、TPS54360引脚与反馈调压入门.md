# 16、TPS54360引脚与反馈调压入门

> 对应原图：第 2 页 U20：TPS54360DDAR，负责把受保护的 24V 转为约 5V。

## 先记住一句话

TPS54360 通过内部 MOSFET 的高速通断，把 24V 的能量分批送入电感；再根据 FB 引脚看到的实际输出电压，持续调整每次导通的时间，使输出稳定在设定的 5V。

```text
24V -> 内部 MOS 开关 -> PH/SW -> L1 -> 5V 输出
                              |            |
                            D69          输出电容
                              |            |
                             GND          GND
```

## U20 的引脚作用

| 引脚 | 名称 | 简单理解 | 原图外围电路 |
|---:|---|---|---|
| 1 | BOOT | 保证内部高边 MOS 在每一次需要导通时都能快速、完全导通。 | C20：100nF 接在 BOOT 与 PH/SW 之间。 |
| 2 | VIN | 芯片的 24V 输入。 | 接入口保护后的 VDD24V 与输入去耦电容。 |
| 3 | EN | 允许芯片启动的控制脚。 | 两个电阻分压设置欠压锁定阈值。 |
| 4 | RT/CLK | 设定芯片每秒开关多少次，也可用于同步外部时钟。 | 电阻接此脚设定开关频率。 |
| 5 | FB | 检查输出电压是否准确的检测脚。 | 从 5V 输出经 R17、R18 等电阻分压取样。 |
| 6 | COMP | 让反馈调节既稳定又不过慢的控制脚。 | R16、C27、C28 等补偿网络。 |
| 7 | GND | 电压判断的零点和电流回流基准。 | 接地平面，和关键电容形成短回路。 |
| 8 | PH / SW | 内部 MOS 的高速开关输出节点。 | 接 L1、D69 与 C20；是高噪声节点。 |
| EP | 底部散热焊盘 | 芯片散热和接地。 | 接大面积 GND 铜皮并打导热过孔。 |

## BOOT、SW 和内部 MOS 的关系

### SW/PH 是真正的功率开关点

芯片内部 MOS 不会一直导通，而是在很高频率下不断开、关：

```text
MOS 导通：SW 接近 24V，L1 储能，输出获得能量
MOS 关断：电感电流经 D69 续流，L1 继续向 5V 负载供电
```

如果内部 MOS 一直导通，24V 会持续送往后级，输出无法稳定为 5V。因此 DCDC 的核心就是精确控制“每次导通多久”。

### BOOT 是高边 MOS 的驱动辅助

BOOT 不决定输出电压，也不是让 MOS 永远导通。它的作用是保证 MOS 每次要打开时能够：

- 快速打开；
- 完全打开；
- 导通损耗低；
- 在芯片要求的时刻关断。

C20 是自举电容。它的两端分别接 BOOT 与 SW/PH，因此关键电压不是 BOOT 对地多少伏，而是：

```text
VBOOT - VSW 约为内部 MOS 所需的驱动电压
```

SW 上升到接近 24V 时，BOOT 也会跟着升高，使内部高边 MOS 的栅极仍能比它的源极高出足够电压，从而充分导通。

## 什么是反馈 FB

反馈就是“芯片把输出结果拿回来检查，然后纠正下一次动作”。

可以把它理解为调水温：

```text
水太凉 -> 热水开大一点
水太热 -> 热水关小一点
水温合适 -> 保持调整
```

TPS54360 的对应过程：

```text
5V 输出变低
-> FB 检测到电压偏低
-> 芯片让内部 MOS 每次导通时间变长
-> L1 得到更多能量
-> 输出回升到 5V

5V 输出变高
-> FB 检测到电压偏高
-> 芯片缩短内部 MOS 的导通时间
-> L1 平均输出能量减少
-> 输出回落到 5V
```

## FB 外接两个电阻为什么能决定 5V

FB 脚内部比较的目标电压约为 0.8V，不能直接接 5V。因此输出必须先经过电阻分压：

```text
5V 输出
  |
 R上（原图约 53.6k）
  |
  +---- FB
  |
 R下（原图约 10k）
  |
 GND
```

当输出是约 5.088V 时，FB 点约为 0.8V：

```text
VOUT = 0.8V x (1 + R上 / R下)
     = 0.8V x (1 + 53.6k / 10k)
     约等于 5.088V
```

所以两个反馈电阻的比例，就是“输出目标电压”的设定值；芯片则不断调节 SW 的占空比，让 FB 尽量保持在约 0.8V。

## EN、COMP、RT/CLK 的快速记忆

| 引脚 | 记忆方式 |
|---|---|
| EN | 电压达到条件才允许开机，避免输入太低时反复启动。 |
| COMP | 决定反馈调节的快慢和稳定性，不能随意删除或换值。 |
| RT/CLK | 决定开关频率，频率会影响电感、电容、效率和 EMI。 |

## 画板时的三个重点

1. VIN 输入电容、U20、D69 的高频电流回路必须短小。
2. SW/PH 是最吵的节点，远离 FB、COMP、晶振、ADC、天线和通信线。
3. FB 从输出电容附近取样，避免取到功率走线的压降和噪声。
