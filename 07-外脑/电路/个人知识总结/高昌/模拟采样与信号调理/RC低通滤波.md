# RC 低通滤波

> RC 低通让慢变化的有用信号通过，衰减快速变化的噪声。

```text
运放输出 -> 串联 R -> ADC 节点 -> MCU ADC
                         |
                         C
                         |
                        GND
```

电容必须从 ADC 节点接地；若它跨接在串联电阻两端，高频噪声会绕过电阻，滤波失效。

截止频率近似：`f_c = 1 / (2πRC)`。例如 `1kΩ + 100nF` 约为 1.6kHz；滤波越强，响应越慢。
