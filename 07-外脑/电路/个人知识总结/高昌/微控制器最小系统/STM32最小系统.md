# STM32F103 最小系统

> 作用：保证 STM32F103C8T6 能稳定上电、运行、复位、下载和调试。

## 必须保留的部分

| 模块 | 作用 | 典型做法 |
|---|---|---|
| 3.3V 电源去耦 | 给内部逻辑提供就近低阻抗电源 | 每个 VDD 旁放 100nF，总电源入口再放 1uF~10uF。 |
| VDDA/VSSA | 给 ADC 等模拟部分提供干净电源 | 按数据手册连接；有模拟采样时增加磁珠/电阻和去耦。 |
| HSE 晶振 | 提供稳定主时钟 | 8MHz 晶振与两颗负载电容，数值按晶振规格。 |
| NRST 复位 | 上电和手动复位 | 10k 上拉、100nF 对地，保留复位按键可选。 |
| BOOT0/BOOT1 | 选择启动来源 | 默认下拉，保证从内部 Flash 启动。 |
| SWD | 量产烧录和在线调试 | 引出 3.3V、SWDIO、SWCLK、GND。 |
| 心跳 LED | 现场判断 MCU 是否运行 | GPIO 串限流电阻驱动，不得影响复位和启动。 |

## 可以裁剪的部分

- 不需要 USB 下载和日志时，可不放 Type-C、CH340 及自动下载三极管电路。
- 不需要掉电走时和 RTC 时，可不放 32.768kHz 晶振；是否保留取决于软件时间需求。
- 不需要外部存储时，不要为了“预留”盲目增加 EEPROM/Flash；若要保存运行参数，FRAM 要另行确认容量、接口和写入策略。

## 关于自动下载

STM32 工业板优先保留 SWD，不代表 STM32 不能使用串口 ISP，而是 SWD 更适合量产烧录和调试。BOOT0 下拉保证正常启动，必要时可通过测试点临时拉高进入系统存储区。

## 关键纠正

STM32F103C8T6 的具体电源、BOOT、晶振和引脚连接必须以对应封装的数据手册为准，不能照搬某个开发板的引脚说明。尤其是 `VBAT`、`VDDA/VSSA`、`PB2/BOOT1` 与调试复用功能，要结合实际芯片版本确认。
