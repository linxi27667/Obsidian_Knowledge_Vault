# 02、Buck 降压电路工作原理

## Buck 是什么

Buck 是降压型开关电源：把较高输入电压变为较低、稳定的输出电压。

原图中的 TPS54360 就是 `24V -> 5V` 的 Buck。

```text
24V -> 内部 MOS -> SW -> L1 -> 5V 输出
                         |          |
                       D69        输出电容
                         |          |
                        GND        GND
```

## 两个工作状态

### MOS 导通

```text
24V -> MOS -> SW -> L1 -> 输出/负载
```

- SW 接近输入电压。
- 电感 L1 电流上升，储存能量。
- 输入同时给输出电容和负载供能。
- D69 反向截止。

### MOS 关断

```text
L1 -> 输出/负载 -> GND -> D69 -> L1
```

- 电感电流不能突然为零。
- D69 导通，形成续流回路。
- 电感继续向负载和输出电容送能。

## 为什么能降压

芯片高速重复“导通、关断”，并通过 PWM 调整导通比例，也叫占空比。

- 导通时间较短：单位时间送出的能量较少，输出降低。
- 导通时间较长：单位时间送出的能量较多，输出升高。

电感和输出电容把高速脉冲能量平滑成稳定的直流电。因此 Buck 的输出平均电压低于输入电压。

## 你要记住的元件分工

| 器件 | 主要作用 |
|---|---|
| MOS 开关 | 决定什么时候从输入取能。 |
| L1 电感 | 储能、维持电流连续。 |
| D69 肖特基二极管 | MOS 关断时提供续流通路。 |
| 输出电容 | 平滑输出电压、支撑瞬时负载。 |
| FB 电阻 | 告诉芯片是否已经达到目标电压。 |
