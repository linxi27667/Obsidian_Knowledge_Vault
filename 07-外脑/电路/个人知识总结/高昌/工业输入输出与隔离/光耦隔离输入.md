# 光耦隔离数字输入 DI

> 作用：把外部 24V 开关信号转换成 MCU 能识别的 3.3V 逻辑，同时阻断外部地的干扰和故障电压。

## 一路输入的结构

```text
外部 IN_SWx -> 限流电阻 -> 光耦 LED -> 24V 外部地
                         并联反向保护二极管

MCU 3.3V -> 上拉电阻 -> 光耦三极管集电极 -> MCU GPIO
                         发射极 -> MCU GND
                         GPIO 对地并联电容作滤波
```

核心器件可采用 `EL817`；参考 PDF 中的 `EL357N` 时，封装替换必须确认引脚顺序与 CTR 参数，不是只改名字。

## 器件作用

| 器件 | 作用 |
|---|---|
| 5.1k 限流电阻 | 限制外部 24V 流过光耦 LED 的电流，保护 LED 并设定输入电流。 |
| 1N4148 反向并联二极管 | 输入极性反向时为 LED 提供低压通路，防止光耦 LED 反向击穿。 |
| EL817 光耦 | 用光传递开关状态，输入侧和 MCU 侧电气隔离。 |
| 10k 上拉电阻 | 光耦不导通时把 MCU 输入拉到 3.3V，避免 GPIO 悬空。 |
| 1nF~100nF 电容 | 与上拉电阻形成低通滤波，抑制触点抖动和 EMI；数值越大响应越慢。 |

## 逻辑关系

外部 24V 有效时，光耦 LED 亮，三极管导通，MCU 引脚被拉低。因此常见逻辑是 `Low-Active`：低电平代表输入有效。软件中要明确这一点，避免把高低电平含义写反。

## 需要确认的参数

- 5.1k 在最低输入电压、光耦正向压降和目标 LED 电流下是否能可靠触发。
- 光耦 CTR 在温度、老化和最小电流下，能否把 MCU 输入可靠拉低。
- 外部输入是否可能超过 24V、是否需要额外 TVS 或串联两级限流。
- `GND` 与 `24V_GND` 是否真的属于隔离两侧；不能仅因名字不同就认为已经隔离。
