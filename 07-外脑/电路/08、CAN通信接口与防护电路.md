# 08、CAN通信接口与防护电路

> 原图位置：第 4 页左下。核心：U16 TJA1040T/CM,118；保护：T3 PESD1CANVL、D5 SMBJ15CA。

## 电路由哪几部分组成

| 部分 | 原图器件 | 作用 |
|---|---|---|
| CAN 收发器 | U16：TJA1040T/CM,118 | MCU CAN_TX/CAN_RX 与 CANH/CANL 差分总线转换。 |
| 总线保护 | T3：PESD1CANVL | 低电容 ESD 保护，钳位 CANH/CANL 静电尖峰。 |
| 浪涌钳位 | D5：SMBJ15CA | 吸收较高能量瞬态，保护端口。 |
| 滤波/匹配 | R39、R41、C43、C47 等 | 抑制高频噪声、改善信号完整性。 |
| 外部接口 | CN5 | 连接 CANH、CANL。 |
| 逻辑侧保护 | D7：BAT54S 等 | 对逻辑/控制引脚做钳位保护。 |

## 工作过程

MCU 的 CAN_TX 控制收发器向总线发送差分信号；CANH 与 CANL 上形成反相电压变化。接收时，收发器比较两线差分电压，将总线状态恢复为 CAN_RX。

## 重点元器件作用

### TJA1040 CAN 收发器

- 将 3.3V/5V 逻辑侧信号转换为抗干扰的差分物理层信号。
- MCU 引脚不能直接连接 CANH/CANL，必须经过收发器。

### PESD1CANVL

- 低电容 ESD 保护器件，适合高速差分线。
- 寄生电容过大可能损坏 CAN 波形，因此不能随意用大电容 TVS 替代。

### SMBJ15CA

- 用于吸收能量更高的浪涌。
- 它与 ESD 阵列的分工是：ESD 阵列快速、低电容；大 TVS 负责更高能量。

## 总线规范

1. CAN 总线两端应有 120Ω 终端，不应每个节点都加。
2. CANH/CANL 应以差分对布线，等长、靠近、少分叉。
3. 端口保护器件应靠近连接器，收发器应放在保护器件后面。
4. 长线和多节点环境要明确参考地与屏蔽连接策略。

## 注意

原图为非隔离 CAN。若现场地电位差或共模干扰很大，应考虑隔离 CAN 收发器及隔离电源。
