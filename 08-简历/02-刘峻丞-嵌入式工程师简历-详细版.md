## 代表项目

### 大模型驱动的 ESP32-P4/S3 多模态 AIoT 智能家居中控｜队长 / 嵌入式核心开发

**技术栈：**ESP32-P4/C6/S3、ESP-IDF、FreeRTOS、LVGL 9、MQTT、MCP、ESP-DL、MIPI-DSI/CSI、I2S、PSRAM

**项目简介：**基于 ESP32-P4 中控、ESP32-C6 无线协处理器和 3 台 ESP32-S3 楼层节点构建分布式智能家居。系统不仅提供触屏和传感器控制，还将云端大模型的自然语言理解能力与 MCU 可执行设备能力连接，并在 P4 端集成本地视觉 AI。

- 设计“**语音/文本 → 云端 STT/LLM → MCP 工具调用 → P4 参数校验与设备模型 → MQTT → S3 GPIO/PWM → 回执/UI**”控制链路：大模型负责理解自然语言意图，P4 将意图限定为预先注册的灯光、窗帘、门禁和场景工具，避免直接执行不受约束的自然语言命令。
- 基于小智开源框架集成语音唤醒、STT/LLM/TTS 和 MCP 工具注册，把“打开二楼灯光”“执行回家模式”等自然语言转换为结构化函数调用，实现 AI 对多节点嵌入式设备的可控编排。
- 在 ESP32-P4 上集成 SC2336 MIPI-CSI 摄像头、硬件 JPEG 与 ESP-DL 人脸检测/识别模块，将本地身份验证与回家场景联动；本地视觉与云端大模型两条 AI 链路相互独立。
- 基于 LVGL 9 完成 1024×600 MIPI-DSI 触控界面，建立位于 PSRAM 的统一设备模型和 UI 事件队列，使触屏、语音、传感器、人脸与 MQTT 共用同一状态源，避免跨线程直接操作 LVGL。
- 设计 P4/S3 共享二进制协议，覆盖设备命令、场景、心跳、响应、传感器上报和离线判定；通过 response/heartbeat 将实际执行结果回传中控并刷新设备模型和 UI。
- 针对摄像头、JPEG、网络、LVGL 和人脸任务并发产生的内部 RAM 峰值，采用 PSRAM 缓冲、编码器复用、单槽队列、原子忙标志、互斥访问、分块上传与失败资源释放提升系统稳定性。
- 项目获 **第九届（2026）全国大学生嵌入式芯片与系统设计竞赛全国总决赛二等奖**。
