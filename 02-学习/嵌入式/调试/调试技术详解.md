# 调试技术详解

## 核心概念

- **调试** - 发现和修复程序错误
- **JTAG** - 联合测试行动组接口
- **SWD** - 串行线调试
- **断点** - 程序暂停点

---

## 一、调试接口

### 1.1 JTAG接口

**JTAG信号：**
| 信号 | 说明 |
|------|------|
| TCK | 测试时钟 |
| TMS | 测试模式选择 |
| TDI | 测试数据输入 |
| TDO | 测试数据输出 |
| TRST | 测试复位(可选) |

**JTAG TAP状态机：**
```
Test-Logic-Reset → Run-Test/Idle → Select-DR → Capture-DR → Shift-DR → ...
```

---

### 1.2 SWD接口

**SWD信号：**
| 信号 | 说明 |
|------|------|
| SWDIO | 双向数据线 |
| SWCLK | 时钟线 |

**SWD vs JTAG：**
| 特性 | JTAG | SWD |
|------|------|-----|
| 引脚数 | 4-5 | 2 |
| 速度 | 快 | 快 |
| 功能 | 完整 | 调试 |
| 适用 | 开发/生产 | 生产 |

---

### 1.3 调试器

| 调试器 | 接口 | 特点 |
|--------|------|------|
| J-Link | JTAG/SWD | 专业、快 |
| ST-Link | SWD | STM32专用 |
| OpenOCD | JTAG/SWD | 开源 |
| DAPLink | SWD | ARM官方 |
| ESP-Prog | JTAG | ESP32专用 |

## 二、GDB调试

### 2.1 GDB基础

```bash
# 启动GDB
arm-none-eabi-gdb firmware.elf

# 连接远程目标
(gdb) target remote :3333

# 加载固件
(gdb) load

# 运行
(gdb) continue
(gdb) c

# 单步
(gdb) step        # 进入函数
(gdb) next        # 跳过函数
(gdb) finish      # 执行到返回

# 断点
(gdb) break main
(gdb) break file.c:100
(gdb) break function_name
(gdb) info breakpoints
(gdb) delete 1

# 查看变量
(gdb) print variable
(gdb) print /x variable  # 十六进制
(gdb) display variable

# 查看寄存器
(gdb) info registers
(gdb) print $pc
(gdb) print $sp

# 查看内存
(gdb) x/10xw 0x20000000  # 10个32位十六进制
(gdb) x/20xb 0x08000000  # 20个字节
(gdb) x/s 0x08001000     # 字符串

# 查看栈
(gdb) backtrace
(gdb) bt
(gdb) info locals

# 修改变量
(gdb) set variable x = 10
(gdb) set {int}0x20000000 = 42
```

## 三、断点类型

### 3.1 软件断点

```c
// 软件断点指令
// ARM: BKPT #0  (0xBE00)
// RISC-V: ebreak (0x00100073)
// Xtensa: break 0,0

// 代码中插入断点
__asm("bkpt #0");  // ARM
__asm("ebreak");   // RISC-V
```

---

### 3.2 硬件断点

```
硬件断点：使用CPU的调试寄存器
- 数量有限(通常4-8个)
- 可以断在Flash上
- 不修改代码
```

---

### 3.3 数据断点(观察点)

```c
// GDB设置数据断点
(gdb) watch variable        // 变量改变时断
(gdb) rwatch variable       // 变量被读时断
(gdb) awatch variable       // 变量被访问时断

// 地址断点
(gdb) watch *(int*)0x20000000
```

## 五、故障分析

### 5.1 HardFault分析

```c
// HardFault处理
void HardFault_Handler(void) {
    __asm volatile (
        "TST LR, #4     \n"
        "ITE EQ         \n"
        "MRSEQ R0, MSP  \n"
        "MRSNE R0, PSP  \n"
        "B hard_fault_handler_c \n"
    );
}

void hard_fault_handler_c(uint32_t *stack) {
    uint32_t r0 = stack[0];
    uint32_t r1 = stack[1];
    uint32_t r2 = stack[2];
    uint32_t r3 = stack[3];
    uint32_t r12 = stack[4];
    uint32_t lr = stack[5];
    uint32_t pc = stack[6];
    uint32_t psr = stack[7];

    printf("HardFault at PC=0x%08lX\n", pc);
    printf("R0=0x%08lX R1=0x%08lX R2=0x%08lX R3=0x%08lX\n", r0, r1, r2, r3);
    printf("R12=0x%08lX LR=0x%08lX PSR=0x%08lX\n", r12, lr, psr);

    while(1);
}
```

### 5.2 堆栈溢出检测

```c
// FreeRTOS堆栈溢出检测
#define configCHECK_FOR_STACK_OVERFLOW  2

void vApplicationStackOverflowHook(TaskHandle_t xTask, char *pcTaskName) {
    printf("Stack overflow in task: %s\n", pcTaskName);
    while(1);
}

// 堆栈标记法
#define STACK_FILL_PATTERN  0xA5A5A5A5

void check_stack_usage(uint32_t *stack_bottom, int stack_size) {
    int unused = 0;
    for (int i = 0; i < stack_size / 4; i++) {
        if (stack_bottom[i] == STACK_FILL_PATTERN) {
            unused++;
        } else {
            break;
        }
    }
    int used = stack_size - unused * 4;
    printf("Stack used: %d/%d bytes\n", used, stack_size);
}
```

### 5.3 内存泄漏检测

```c
// 简单的内存跟踪
typedef struct {
    void *ptr;
    size_t size;
    const char *file;
    int line;
} alloc_record_t;

#define MAX_RECORDS 100
static alloc_record_t records[MAX_RECORDS];
static int record_count = 0;

void *tracked_malloc(size_t size, const char *file, int line) {
    void *ptr = malloc(size);
    if (ptr && record_count < MAX_RECORDS) {
        records[record_count].ptr = ptr;
        records[record_count].size = size;
        records[record_count].file = file;
        records[record_count].line = line;
        record_count++;
    }
    return ptr;
}

void tracked_free(void *ptr) {
    for (int i = 0; i < record_count; i++) {
        if (records[i].ptr == ptr) {
            records[i] = records[--record_count];
            break;
        }
    }
    free(ptr);
}

void print_leaks(void) {
    printf("Memory leaks:\n");
    for (int i = 0; i < record_count; i++) {
        printf("  %s:%d - %zu bytes at %p\n",
               records[i].file, records[i].line,
               records[i].size, records[i].ptr);
    }
}

#define malloc(size) tracked_malloc(size, __FILE__, __LINE__)
#define free(ptr) tracked_free(ptr)
```
