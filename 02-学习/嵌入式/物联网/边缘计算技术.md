# 边缘计算技术

## 核心概念

- **边缘计算** - 在数据源附近处理数据
- **边缘节点** - 执行计算的设备
- **雾计算** - 边缘与云之间的计算层
- **边缘AI** - 在边缘运行AI模型

---

## 一、边缘计算概述

### 1.1 云计算 vs 边缘计算

| 特性 | 云计算 | 边缘计算 |
|------|--------|----------|
| 位置 | 远程数据中心 | 数据源附近 |
| 延迟 | 高(50-200ms) | 低(1-10ms) |
| 带宽 | 需要大量 | 本地处理 |
| 隐私 | 数据上传 | 数据本地 |
| 计算力 | 强大 | 有限 |
| 成本 | 按需付费 | 硬件投入 |

---


### 2.2 边缘网关

```c
// ESP32作为边缘网关
typedef struct {
    // 传感器数据
    float temperature;
    float humidity;
    int motion_detected;

    // 处理结果
    int anomaly_detected;
    float prediction;

    // 统计
    uint32_t data_count;
    uint32_t last_update;
} edge_gateway_t;

void edge_process(edge_gateway_t *gw) {
    // 本地预处理
    if (gw->temperature > 40.0f) {
        // 本地告警
        trigger_local_alarm();
    }

    // 异常检测
    if (detect_anomaly(gw)) {
        gw->anomaly_detected = 1;
        // 立即上报云端
        upload_to_cloud(gw);
    }

    // 定期汇总上报
    if (gw->data_count % 100 == 0) {
        upload_summary(gw);
    }
}
```

## 三、边缘AI

### 3.1 边缘推理

```c
#include "tensorflow/lite/micro/micro_interpreter.h"

// 模型嵌入
#include "anomaly_model.h"

#define TENSOR_ARENA_SIZE (32 * 1024)
uint8_t tensor_arena[TENSOR_ARENA_SIZE];

bool edge_anomaly_detect(float *sensor_data, int data_len) {
    const tflite::Model *model = tflite::GetModel(g_anomaly_model);

    static tflite::MicroInterpreter interpreter(
        model, resolver, tensor_arena, TENSOR_ARENA_SIZE);

    interpreter.AllocateTensors();

    // 输入数据
    TfLiteTensor *input = interpreter.input(0);
    memcpy(input->data.f, sensor_data, data_len * sizeof(float));

    // 推理
    interpreter.Invoke();

    // 输出
    TfLiteTensor *output = interpreter.output(0);
    float anomaly_score = output->data.f[0];

    return anomaly_score > 0.5f;
}
```

### 4.2 边缘数据聚合

```c
#define AGGREGATION_WINDOW 60  // 60秒

typedef struct {
    float min_val;
    float max_val;
    float sum;
    int count;
    uint32_t window_start;
} aggregation_t;

void aggregation_add(aggregation_t *agg, float value, uint32_t timestamp) {
    if (timestamp - agg->window_start >= AGGREGATION_WINDOW) {
        // 窗口结束，上报统计
        float avg = agg->sum / agg->count;
        upload_aggregated_data(agg->min_val, agg->max_val, avg, agg->count);

        // 重置
        agg->min_val = value;
        agg->max_val = value;
        agg->sum = value;
        agg->count = 1;
        agg->window_start = timestamp;
    } else {
        // 累加
        if (value < agg->min_val) agg->min_val = value;
        if (value > agg->max_val) agg->max_val = value;
        agg->sum += value;
        agg->count++;
    }
}
```

### 5.2 数据同步

```c
typedef struct {
    uint32_t last_sync_id;
    uint32_t pending_count;
} sync_state_t;

void sync_to_cloud(sync_state_t *state) {
    FILE *f = fopen("/spiffs/sensor_log.csv", "r");
    if (!f) return;

    char line[256];
    uint32_t line_id = 0;

    while (fgets(line, sizeof(line), f)) {
        line_id++;
        if (line_id <= state->last_sync_id) continue;

        // 上传到云端
        if (upload_data(line) == 0) {
            state->last_sync_id = line_id;
            state->pending_count--;
        } else {
            break;  // 网络失败，停止
        }
    }
    fclose(f);
}
```

## 八、边缘数据分析

### 8.1 流处理

```c
typedef struct {
    float window[100];
    int index;
    int count;
} sliding_window_t;

float moving_average(sliding_window_t *sw, float new_value) {
    sw->window[sw->index] = new_value;
    sw->index = (sw->index + 1) % 100;
    if (sw->count < 100) sw->count++;

    float sum = 0;
    for (int i = 0; i < sw->count; i++) {
        sum += sw->window[i];
    }
    return sum / sw->count;
}

bool detect_spike(sliding_window_t *sw, float new_value, float threshold) {
    float avg = moving_average(sw, new_value);
    return fabsf(new_value - avg) > threshold;
}
```
