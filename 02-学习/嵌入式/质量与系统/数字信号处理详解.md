## 一、信号与系统基础

### 1.1 连续信号与离散信号

| 特性 | 连续时间信号 $x(t)$ | 离散时间信号 $x[n]$ |
|------|---------------------|---------------------|
| 定义域 | $t \in \mathbb{R}$（实数） | $n \in \mathbb{Z}$（整数） |
| 取值域 | 连续实数 | 连续实数（采样前）或离散整数（量化后） |
| 典型来源 | 模拟传感器输出 | ADC 采样结果 |
| 数学描述 | 微分方程 | 差分方程 |
| 频域工具 | 傅里叶变换 $X(j\omega)$ | DTFT $X(e^{j\omega})$ / DFT $X[k]$ |

**离散信号的表示形式：**
$$x[n] = \{..., x[-2], x[-1], x[0], x[1], x[2], ...\}$$

常用的离散信号：

- **单位脉冲** $\delta[n] = \begin{cases} 1, & n=0 \\ 0, & n \neq 0 \end{cases}$
- **单位阶跃** $u[n] = \begin{cases} 1, & n \geq 0 \\ 0, & n < 0 \end{cases}$
- **矩形序列** $R_N[n] = \begin{cases} 1, & 0 \leq n \leq N-1 \\ 0, & \text{其他} \end{cases}$

### 1.2 采样定理（Nyquist-Shannon 定理）

**定理陈述：** 对于带限信号 $x(t)$，其最高频率分量为 $f_{max}$，当采样频率 $f_s$ 满足：

$$f_s \geq 2 f_{max}$$

时，可以由采样序列 $x[n] = x(nT_s)$ 完全重建原始信号 $x(t)$。

其中 $f_N = f_s / 2$ 称为 **Nyquist 频率**（折叠频率）。

**关键概念：**

| 概念 | 定义 | 说明 |
|------|------|------|
| $f_s$ | 采样频率 | 每秒采样点数（Hz） |
| $T_s$ | 采样周期 | $T_s = 1/f_s$ |
| $f_{max}$ | 信号最高频率 | 带限信号的带宽上限 |
| $f_N$ | Nyquist 频率 | $f_N = f_s / 2$ |
| 混叠 (Aliasing) | 频率折叠 | $f_s < 2f_{max}$ 时高频分量伪装成低频 |

**混叠频率计算：** 当信号频率 $f_0 > f_s/2$ 时，混叠后观测到的频率为：

$$f_{alias} = |f_0 - k \cdot f_s|$$

其中 $k$ 为使 $f_{alias}$ 落入 $[0, f_s/2]$ 的整数。

**示例：** $f_s = 1000\text{ Hz}$，$f_0 = 1200\text{ Hz}$，则 $f_{alias} = |1200 - 1 \times 1000| = 200\text{ Hz}$。

### 1.3 量化

**量化 (Quantization)** 是将连续幅度值映射到有限个离散级别的过程。

**均匀量化器：**

$$\hat{x} = \Delta \cdot \text{round}\left(\frac{x}{\Delta}\right)$$

其中 $\Delta$ 为量化步长（LSB 大小）。

**n 位量化器参数：**

| 参数 | 公式 | 说明 |
|------|------|------|
| 量化级数 | $L = 2^n$ | $n$ 为位宽 |
| 量化步长 | $\Delta = \frac{V_{ref}}{2^n}$ | $V_{ref}$ 为满量程电压 |
| 量化噪声功率 | $\sigma_q^2 = \frac{\Delta^2}{12}$ | 均匀分布假设 |
| SQNR（信号量化噪声比） | $\text{SQNR} = 6.02n + 1.76 \text{ dB}$ | 正弦信号输入 |

**重要结论：** 每增加 1 位量化精度，SQNR 提升约 6 dB。

### 1.4 ADC 信噪比 (SNR / SINAD / ENOB)

**ADC 关键性能指标：**

| 指标 | 定义 | 说明 |
|------|------|------|
| SNR | $\text{SNR} = 10\log_{10}\frac{P_{signal}}{P_{noise}}$ | 信号与噪声功率之比 |
| SINAD | $\text{SINAD} = 10\log_{10}\frac{P_{signal}}{P_{noise}+P_{distortion}}$ | 含谐波失真的信噪比 |
| ENOB | $\text{ENOB} = \frac{\text{SINAD} - 1.76}{6.02}$ | 有效位数 |
| THD | $\text{THD} = \frac{\sqrt{V_2^2+V_3^2+...}}{V_1}$ | 总谐波失真 |
| SFDR | 无杂散动态范围 | 信号基频与最大杂散分量之比 |

## 二、离散傅里叶变换 (DFT)

### 2.1 DFT 定义

**正变换（时域 -> 频域）：**

$$X[k] = \sum_{n=0}^{N-1} x[n] \cdot e^{-j\frac{2\pi}{N}kn}, \quad k = 0, 1, ..., N-1$$

**逆变换（频域 -> 时域）：**

$$x[n] = \frac{1}{N}\sum_{k=0}^{N-1} X[k] \cdot e^{j\frac{2\pi}{N}kn}, \quad n = 0, 1, ..., N-1$$

令 $W_N = e^{-j2\pi/N}$（旋转因子），则：

$$X[k] = \sum_{n=0}^{N-1} x[n] \cdot W_N^{kn}$$

**DFT 的性质：**

| 性质 | 时域 | 频域 |
|------|------|------|
| 线性 | $a \cdot x_1[n] + b \cdot x_2[n]$ | $a \cdot X_1[k] + b \cdot X_2[k]$ |
| 圆周移位 | $x[(n-m)_N]$ | $W_N^{mk} X[k]$ |
| 圆周卷积 | $x_1[n] \circledast x_2[n]$ | $X_1[k] \cdot X_2[k]$ |
| 频域卷积 | $x_1[n] \cdot x_2[n]$ | $\frac{1}{N} X_1[k] \circledast X_2[k]$ |
| Parseval 定理 | $\sum \|x[n]\|^2$ | $\frac{1}{N}\sum \|X[k]\|^2$ |

### 2.2 FFT 快速算法

**DFT 直接计算复杂度：** $O(N^2)$ -- $N^2$ 次复数乘法 + $N(N-1)$ 次复数加法。

**FFT（快速傅里叶变换）复杂度：** $O(N\log_2 N)$ -- 当 $N$ 为 2 的幂时。

**Cooley-Tukey 基 2-FFT（时间抽取 DIT）：**

将 $N$ 点 DFT 分解为两个 $N/2$ 点 DFT：

$$X[k] = \underbrace{\sum_{r=0}^{N/2-1} x[2r] W_N^{2rk}}_{G[k]} + W_N^k \underbrace{\sum_{r=0}^{N/2-1} x[2r+1] W_N^{2rk}}_{H[k]}$$

**蝶形运算单元：**

```
    x[偶数索引] ──┬──(+)──> X[k]
                   │
    x[奇数索引] ──×W_N^k──(-)──> X[k+N/2]
```

**蝶形运算公式：**
$$X[k] = G[k] + W_N^k H[k]$$
$$X[k+N/2] = G[k] - W_N^k H[k]$$

**FFT 级数与运算量：**

| $N$ | DFT 乘法次数 | FFT 乘法次数 | 加速比 |
|-----|-------------|-------------|--------|
| 64 | 4,096 | 192 | 21x |
| 256 | 65,536 | 1,024 | 64x |
| 1024 | 1,048,576 | 5,120 | 205x |
| 4096 | 16,777,216 | 24,576 | 683x |

### 2.3 频率分辨率

**DFT 频率分辨率（Rayleigh 分辨率）：**

$$\Delta f = \frac{f_s}{N} = \frac{1}{T_{obs}}$$

其中 $T_{obs} = N \cdot T_s$ 为观测时间长度。

**关键理解：**

- 频率分辨率由**观测时间长度**决定，而非采样率
- 增大 $N$（不改变 $f_s$）可以提高频率分辨率
- 增大 $f_s$（不改变 $N$）反而会降低频率分辨率

**补零 (Zero-Padding)：**

在时域序列末尾补零至 $M$ 点（$M > N$），可以使 DFT 频域采样更密集（插值效果），但**不能**提高真正的频率分辨率，因为没有增加新的信号信息。

### 2.4 窗函数

对有限长信号做 DFT 时，等效于对无限长信号加矩形窗，会导致频谱泄漏。使用非矩形窗可以抑制泄漏。

**常用窗函数对比：**

| 窗函数 | 主瓣宽度 (-3dB) | 最大旁瓣 (dB) | 旁瓣衰减速率 | 适用场景 |
|--------|----------------|---------------|-------------|---------|
| 矩形窗 | $0.89 \cdot \Delta f$ | -13 dB | -6 dB/oct | 频率分辨率最高 |
| Hanning | $1.44 \cdot \Delta f$ | -32 dB | -18 dB/oct | 通用，平衡型 |
| Hamming | $1.30 \cdot \Delta f$ | -43 dB | -6 dB/oct | 旁瓣抑制好 |
| Blackman | $1.68 \cdot \Delta f$ | -58 dB | -18 dB/oct | 高动态范围 |
| Kaiser | 可调 ($\beta$ 参数) | 可调 | -- | 灵活，可定制 |
| Flat-top | $3.72 \cdot \Delta f$ | -44 dB | -- | 幅度精度最高 |

**窗函数选择原则：**

1. 需要**频率分辨**两个相近频率 -> 窄主瓣窗（矩形、Hanning）
2. 需要**检测弱信号**在强信号旁 -> 低旁瓣窗（Blackman、Kaiser）
3. 需要**精确测量幅度** -> Flat-top 窗
4. 通用场景 -> Hanning 窗是最佳默认选择

**Kaiser 窗公式：**

$$w[n] = \frac{I_0\left(\beta\sqrt{1-\left(\frac{2n}{N-1}-1\right)^2}\right)}{I_0(\beta)}$$

其中 $I_0$ 为零阶第一类修正 Bessel 函数。$\beta$ 参数控制主瓣宽度与旁瓣衰减的权衡。

## 三、数字滤波器

### 3.1 FIR 滤波器设计

**FIR（有限脉冲响应）滤波器差分方程：**

$$y[n] = \sum_{k=0}^{M} b_k \cdot x[n-k]$$

**特点：**
- 脉冲响应 $h[n]$ 有限长（$M+1$ 个系数）
- 可以实现严格的**线性相位**
- 总是**稳定**的（无反馈，极点全在原点）
- 实现为直接卷积或快速卷积（FFT）

**线性相位 FIR 条件：**

对称性条件（$M$ 阶滤波器）：
$$h[n] = h[M-n] \quad \text{(I 型，M 为偶数)}$$
$$h[n] = h[M-n] \quad \text{(II 型，M 为奇数)}$$
$$h[n] = -h[M-n] \quad \text{(III 型，反对称，M 为偶数)}$$
$$h[n] = -h[M-n] \quad \text{(IV 型，反对称，M 为奇数)}$$

**设计方法：**

#### (a) 窗函数法

1. 确定理想滤波器的脉冲响应 $h_d[n]$（如 sinc 函数）
2. 选择窗函数 $w[n]$
3. $h[n] = h_d[n] \cdot w[n]$

**低通 FIR 的理想脉冲响应：**
$$h_d[n] = \frac{\sin(\omega_c (n - M/2))}{\pi(n - M/2)}$$

其中 $\omega_c = 2\pi f_c / f_s$ 为归一化截止频率。

#### (b) 频率采样法

在频域指定若干采样点的值，通过 IDFT 得到时域系数。

#### (c) 最优等波纹法（Parks-McClellan 算法）

利用 Remez 交换算法，在通带和阻带之间最小化最大逼近误差（Chebyshev 准则），产生等波纹频率响应。

**滤波器阶数估计（Kaiser 经验公式）：**

$$M \approx \frac{A_s - 7.95}{2.285 \cdot \Delta\omega}$$

其中 $A_s$ 为阻带衰减（dB），$\Delta\omega$ 为过渡带宽度（rad/sample）。

### 3.2 IIR 滤波器设计

**IIR（无限脉冲响应）滤波器差分方程：**

$$y[n] = \sum_{k=0}^{M} b_k \cdot x[n-k] - \sum_{k=1}^{N} a_k \cdot y[n-k]$$

**特点：**
- 脉冲响应无限长（含反馈）
- 无法实现严格的线性相位
- 可能**不稳定**（极点在单位圆外）
- 同等性能下，阶数远低于 FIR

**设计方法：从模拟滤波器转换**

| 模拟原型 | 特点 | 转换方法 |
|----------|------|---------|
| Butterworth | 最大平坦，无纹波 | 双线性变换 |
| Chebyshev I | 通带等波纹 | 双线性变换 |
| Chebyshev II | 阻带等波纹 | 双线性变换 |
| 椭圆 (Cauer) | 通带+阻带均有纹纹，过渡带最窄 | 双线性变换 |
| Bessel | 最平坦群延迟（线性相位） | 双线性变换 |

**双线性变换 (Bilinear Transform)：**

$$s = \frac{2}{T_s} \cdot \frac{1 - z^{-1}}{1 + z^{-1}}$$

或等价地：
$$z = \frac{1 + sT_s/2}{1 - sT_s/2}$$

**频率预畸变：** 由于双线性变换的非线性频率映射，需要对截止频率进行预校正：

$$\Omega = \frac{2}{T_s} \tan\left(\frac{\omega}{2}\right)$$

其中 $\Omega$ 为模拟频率，$\omega$ 为数字频率。

### 3.3 FIR vs IIR 对比

| 特性 | FIR | IIR |
|------|-----|-----|
| 脉冲响应 | 有限长 | 无限长 |
| 线性相位 | 可以实现 | 无法保证 |
| 稳定性 | 总是稳定 | 可能不稳定 |
| 实现结构 | 非递归（无反馈） | 递归（有反馈） |
| 同等性能阶数 | 高（50-200） | 低（5-20） |
| 计算量 | 较大 | 较小 |
| 延迟 | 线性相位时为 $M/2$ 个样本 | 非线性，难以定义 |
| 量化效应 | 不敏感 | 敏感，极点可能漂移 |
| 适用场景 | 音频、通信（相位敏感） | 实时控制、嵌入式（资源受限） |

### 3.4 滤波器系数计算

**Python 示例 -- 使用 scipy 设计滤波器：**

```python
import numpy as np
from scipy import signal

# === FIR 低通滤波器（窗函数法）===
fs = 8000        # 采样率
fc = 1000        # 截止频率
N = 51           # 滤波器阶数
b_fir = signal.firwin(N, fc, fs=fs, window='hann')

# === IIR 低通滤波器（Butterworth）===
order = 4
b_iir, a_iir = signal.butter(order, fc, btype='low', fs=fs)

# === 频率响应 ===
w, h_fir = signal.freqz(b_fir, worN=1024, fs=fs)
w, h_iir = signal.freqz(b_iir, a_iir, worN=1024, fs=fs)

# === FIR vs IIR 阶数对比 ===
# 相同规格：fc=1000Hz, fs=8000Hz, 阻带衰减=60dB
# FIR: ~43 阶
# IIR Butterworth: ~8 阶
# IIR 椭圆: ~5 阶
```

**C 语言嵌入式实现示例（FIR）：**

```c
#define FIR_ORDER  51
#define FIR_TAPS   (FIR_ORDER + 1)

static float coeffs[FIR_TAPS];  // 预计算的滤波器系数
static float buffer[FIR_TAPS];  // 延迟线缓冲区
static int buf_idx = 0;

float fir_filter(float input) {
    buffer[buf_idx] = input;

    float acc = 0.0f;
    int idx = buf_idx;
    for (int i = 0; i < FIR_TAPS; i++) {
        acc += coeffs[i] * buffer[idx];
        idx--;
        if (idx < 0) idx = FIR_ORDER;  // 循环缓冲
    }

    buf_idx++;
    if (buf_idx > FIR_ORDER) buf_idx = 0;

    return acc;
}
```

## 四、Z 变换

### 4.1 Z 变换定义

**双边 Z 变换：**

$$X(z) = \sum_{n=-\infty}^{\infty} x[n] z^{-n}$$

**单边 Z 变换：**

$$X(z) = \sum_{n=0}^{\infty} x[n] z^{-n}$$

其中 $z = re^{j\omega}$ 为复数变量。

**常见序列的 Z 变换：**

| 序列 $x[n]$ | Z 变换 $X(z)$ | ROC |
|-------------|---------------|-----|
| $\delta[n]$ | $1$ | 全 $z$ 平面 |
| $u[n]$ (单位阶跃) | $\frac{1}{1-z^{-1}}$ | $\|z\| > 1$ |
| $a^n u[n]$ | $\frac{1}{1-az^{-1}}$ | $\|z\| > \|a\|$ |
| $-a^n u[-n-1]$ | $\frac{1}{1-az^{-1}}$ | $\|z\| < \|a\|$ |
| $n \cdot a^n u[n]$ | $\frac{az^{-1}}{(1-az^{-1})^2}$ | $\|z\| > \|a\|$ |
| $\cos(\omega_0 n) u[n]$ | $\frac{1-\cos\omega_0 \cdot z^{-1}}{1-2\cos\omega_0 \cdot z^{-1}+z^{-2}}$ | $\|z\| > 1$ |
| $\sin(\omega_0 n) u[n]$ | $\frac{\sin\omega_0 \cdot z^{-1}}{1-2\cos\omega_0 \cdot z^{-1}+z^{-2}}$ | $\|z\| > 1$ |

**ROC（收敛域）的重要性：** 不同的序列可以有相同的 Z 变换表达式，只有通过 ROC 才能唯一确定时域序列。

### 4.2 逆 Z 变换

**方法一：部分分式展开法**

将 $X(z)$ 分解为简单分式之和，查表反变换。

$$X(z) = \frac{B(z)}{A(z)} = \sum_i \frac{A_i}{1 - p_i z^{-1}}$$

**方法二：长除法（幂级数展开）**

直接做多项式长除法，得到 $z^{-n}$ 的系数即为 $x[n]$。

**方法三：围线积分（Cauchy 定理）**

$$x[n] = \frac{1}{2\pi j} \oint_C X(z) z^{n-1} dz$$

**示例 -- 部分分式展开：**

$$X(z) = \frac{1}{(1-0.5z^{-1})(1-0.8z^{-1})}$$

展开为：
$$X(z) = \frac{-4/3}{1-0.5z^{-1}} + \frac{7/3}{1-0.8z^{-1}}$$

因此：
$$x[n] = \left(-\frac{4}{3}(0.5)^n + \frac{7}{3}(0.8)^n\right) u[n]$$

### 4.3 系统函数 H(z)

**LTI 系统的系统函数：**

$$H(z) = \frac{Y(z)}{X(z)} = \frac{\sum_{k=0}^{M} b_k z^{-k}}{\sum_{k=0}^{N} a_k z^{-k}} = \frac{b_0 \prod_{k=1}^{M}(1-z_k z^{-1})}{a_0 \prod_{k=1}^{N}(1-p_k z^{-1})}$$

- **零点 (Zeros):** $z_k$ -- 分子多项式的根，使 $H(z)=0$
- **极点 (Poles):** $p_k$ -- 分母多项式的根，使 $H(z) \to \infty$

**零极点与频率响应的关系：**

$$H(e^{j\omega}) = H(z)\big|_{z=e^{j\omega}}$$

- 在零点附近，频率响应趋向**谷值**
- 在极点附近，频率响应趋向**峰值**
- 极点越靠近单位圆，对应的频率分量增益越大（峰值越尖锐）

### 4.4 稳定性分析

**BIBO 稳定（有界输入有界输出）充要条件：**

$$\sum_{n=-\infty}^{\infty} |h[n]| < \infty$$

**Z 域稳定性判定：**

- **因果系统稳定的充要条件：** 所有极点严格位于单位圆内（$|p_k| < 1$）
- **临界稳定：** 有一阶极点在单位圆上
- **不稳定：** 有极点在单位圆外

**稳定性判据表格：**

| 极点位置 | 系统行为 | 稳定性 |
|----------|---------|--------|
| $|p| < 1$（单位圆内） | 脉冲响应衰减 | 稳定 |
| $|p| = 1$（单位圆上） | 脉冲响应恒幅振荡 | 临界稳定 |
| $|p| > 1$（单位圆外） | 脉冲响应发散 | 不稳定 |
| $p = 0$（原点） | 脉冲响应为 $\delta$ | 稳定（FIR） |

## 五、自适应滤波

### 5.1 LMS 算法（最小均方）

**核心思想：** 通过迭代更新滤波器系数，使输出误差的均方值最小化。

**LMS 更新公式：**

$$\mathbf{w}[n+1] = \mathbf{w}[n] + \mu \cdot e[n] \cdot \mathbf{x}[n]$$

其中：
- $\mathbf{w}[n]$ -- 滤波器系数向量（$N$ 维）
- $\mathbf{x}[n]$ -- 输入向量 $[x[n], x[n-1], ..., x[n-N+1]]^T$
- $e[n] = d[n] - y[n]$ -- 误差信号（期望信号 - 滤波器输出）
- $\mu$ -- 步长因子（学习率）
- $y[n] = \mathbf{w}^T[n] \cdot \mathbf{x}[n]$ -- 滤波器输出

**LMS 算法流程：**

```
初始化 w[0] = 0
对每个时刻 n = 0, 1, 2, ...:
    1. 读取输入 x[n]，组成向量 x_vec
    2. 计算输出: y[n] = w' * x_vec
    3. 计算误差: e[n] = d[n] - y[n]
    4. 更新系数: w = w + mu * e[n] * x_vec
```

**步长 $\mu$ 的约束：**

$$0 < \mu < \frac{2}{\lambda_{max}}$$

其中 $\lambda_{max}$ 为输入信号自相关矩阵的最大特征值。

工程上常用经验约束：
$$0 < \mu < \frac{2}{N \cdot P_x}$$

其中 $P_x = E[x^2[n]]$ 为输入信号功率，$N$ 为滤波器阶数。

**LMS 的优缺点：**

| 优点 | 缺点 |
|------|------|
| 算法简单，计算量 $O(N)$ | 收敛速度慢 |
| 数值鲁棒 | 对输入信号相关性敏感 |
| 易于硬件实现 | 步长选择困难（速度 vs 精度权衡） |

### 5.2 NLMS 算法（归一化 LMS）

**NLMS 更新公式：**

$$\mathbf{w}[n+1] = \mathbf{w}[n] + \frac{\mu}{\|\mathbf{x}[n]\|^2 + \epsilon} \cdot e[n] \cdot \mathbf{x}[n]$$

其中 $\epsilon$ 为小正数（防止除零），通常 $\epsilon = 10^{-6}$。

**NLMS vs LMS 的优势：**

- 步长自动归一化，对输入功率变化**不敏感**
- 收敛速度比 LMS 更快、更一致
- 无需估计输入功率来设定步长
- 实际应用中 $\mu$ 通常取 $0.5 \sim 1.0$

### 5.3 RLS 算法（递推最小二乘）

**目标函数：** 最小化加权误差平方和：

$$J[n] = \sum_{i=0}^{n} \lambda^{n-i} |e[i]|^2$$

其中 $\lambda$ 为遗忘因子（$0 < \lambda \leq 1$），典型值 $0.95 \sim 0.999$。

**RLS 算法步骤：**

```
初始化:
    w[0] = 0
    P[0] = delta * I    (delta 为大正数, 如 100)

对每个时刻 n:
    1. 计算增益向量:
       k[n] = (P[n-1] * x[n]) / (lambda + x'[n] * P[n-1] * x[n])
    2. 计算误差:
       e[n] = d[n] - w'[n-1] * x[n]
    3. 更新系数:
       w[n] = w[n-1] + k[n] * e[n]
    4. 更新逆相关矩阵:
       P[n] = (1/lambda) * (P[n-1] - k[n] * x'[n] * P[n-1])
```

**LMS vs NLMS vs RLS 对比：**

| 特性 | LMS | NLMS | RLS |
|------|-----|------|-----|
| 计算复杂度 | $O(N)$ | $O(N)$ | $O(N^2)$ |
| 收敛速度 | 慢 | 中等 | 快 |
| 收敛条件 | 依赖 $\mu$ 和 $\lambda_{max}$ | 自动归一化 | 总是收敛 |
| 跟踪能力 | 差 | 中等 | 优 |
| 数值稳定性 | 好 | 好 | 可能不稳定 |
| 适用场景 | 低资源嵌入式 | 通用 | 高性能要求 |

### 5.4 自适应噪声消除 (ANC)

**经典 ANC 架构：**

```
                    噪声源
                      │
                      v
主麦克风 ----> [+] ----> e[n] (输出 = 信号 + 噪声 - 消除噪声)
                 ^
参考麦克风 ---> [自适应滤波器 W(z)] ---> 消除噪声
```

- **主通道：** 包含信号 $s[n]$ 和噪声 $v[n]$
- **参考通道：** 只包含与主通道噪声相关的参考噪声 $x[n]$
- **自适应滤波器** 学习噪声从参考通道到主通道的传递函数
- **输出：** $e[n] = s[n] + v[n] - \hat{v}[n]$

**收敛后：** $\hat{v}[n] \approx v[n]$，输出接近纯净信号 $s[n]$。

**实际应用：**
- 耳机主动降噪 (ANC)
- 工业环境噪声消除
- 语音通信中的背景噪声抑制

## 六、频谱分析

### 6.1 功率谱密度 (PSD)

**功率谱密度定义：**

$$P_{xx}(e^{j\omega}) = \sum_{m=-\infty}^{\infty} r_{xx}[m] e^{-j\omega m}$$

其中 $r_{xx}[m] = E[x[n] \cdot x^*[n-m]]$ 为自相关函数。

**PSD 估计方法：**

#### (a) 周期图法 (Periodogram)

$$\hat{P}_{xx}[k] = \frac{1}{N} |X[k]|^2$$

- 方差大，不一致估计
- 随 $N$ 增大不收敛

#### (b) Bartlett 方法

将 $N$ 点数据分为 $K$ 段，每段 $M$ 点，分别计算周期图后取平均：

$$\hat{P}_{Bartlett}[k] = \frac{1}{K}\sum_{i=1}^{K} \hat{P}_i[k]$$

- 方差降低 $K$ 倍
- 频率分辨率降低（段长 $M < N$）

#### (c) Welch 方法

与 Bartlett 类似，但允许段之间**重叠**，且每段加窗：

- 常用 50% 重叠 + Hanning 窗
- 实际工程中最常用的 PSD 估计方法

#### (d) 参数模型法

- **AR 模型（自回归）：** 适合窄带信号
- **MA 模型（滑动平均）：** 适合宽带信号
- **ARMA 模型：** 更通用

### 6.2 短时傅里叶变换 (STFT)

**STFT 定义：**

$$X[n, k] = \sum_{m=0}^{N-1} x[m+nH] \cdot w[m] \cdot e^{-j\frac{2\pi}{N}km}$$

其中：
- $w[m]$ -- 窗函数（长度 $N$）
- $H$ -- 帧移（hop size）
- $n$ -- 帧索引
- $k$ -- 频率 bin 索引

**时频分辨率权衡（Heisenberg 不确定性原理）：**

$$\Delta t \cdot \Delta f \geq \frac{1}{4\pi}$$

| 窗长 | 时间分辨率 | 频率分辨率 | 适用场景 |
|------|-----------|-----------|---------|
| 短窗（64-256） | 高 | 低 | 瞬态信号、打击乐 |
| 中窗（512-2048） | 中 | 中 | 语音分析 |
| 长窗（4096+） | 低 | 高 | 稳态信号、音乐分析 |

**重叠率 (Overlap)：**

- 常用 50% 或 75% 重叠
- 重叠率越高，时间连续性越好
- 重叠率越高，计算量越大

**语谱图 (Spectrogram)：**

$$S[n, k] = 20\log_{10}|X[n, k]|$$

以时间 $n$ 为横轴、频率 $k$ 为纵轴、幅度为颜色深度，形成二维时频图。

### 6.3 频谱泄漏与栅栏效应

#### 频谱泄漏 (Spectral Leakage)

**原因：** DFT 假设信号是周期性的，截断后的非整数周期信号在边界处不连续，导致能量扩散到相邻频率 bin。

**数学解释：** 截断等效于乘以矩形窗，频域为 sinc 卷积：

$$X_{windowed}[k] = X[k] * W[k]$$

**缓解方法：**
1. 使用非矩形窗函数（Hanning、Hamming 等）
2. 增加信号长度（提高分辨率）
3. 使信号频率与 DFT bin 对齐（整周期采样）

#### 栅栏效应 (Picket Fence Effect / Scalloping Loss)

**原因：** DFT 只在离散频率点 $k \cdot f_s / N$ 处计算，信号频率如果落在两个 bin 之间，观测到的幅度会偏低。

**最大栅栏损失：**
- 矩形窗：-3.92 dB
- Hanning 窗：-1.42 dB
- Flat-top 窗：-0.01 dB

**缓解方法：**
1. 补零（增加 DFT 点数，在频域插值）
2. 使用 Flat-top 窗
3. 抛物线插值（三点校正）

## 七、采样与重建

### 7.1 抗混叠滤波

**目的：** 在 ADC 采样之前，用模拟低通滤波器滤除 $f_s/2$ 以上的频率分量，防止混叠。

**抗混叠滤波器要求：**

| 参数 | 要求 |
|------|------|
| 通带截止频率 | $f_{pass} < f_s/2$ |
| 阻带起始频率 | $f_{stop} \leq f_s/2$ |
| 过渡带 | $f_s/2 - f_{pass}$ |
| 阻带衰减 | 通常 $\geq 60$ dB（取决于应用） |

**滤波器阶数与过渡带宽度的关系：**

过渡带越窄 -> 阶数越高 -> 延迟越大 -> 成本越高

**实际设计策略：**
1. 先确定信号带宽 $B$
2. 选择 $f_s \geq 2.2B \sim 2.5B$（留余量）
3. 设计抗混叠滤波器：$f_{pass} = B$，$f_{stop} = f_s/2$
4. 过渡带宽度 = $f_s/2 - B$

### 7.2 过采样与欠采样

#### 过采样 (Oversampling)

以远高于 Nyquist 频率的速率采样：$f_s \gg 2f_{max}$。

**优势：**

| 优势 | 原理 |
|------|------|
| 放松抗混叠滤波器要求 | 过渡带更宽，滤波器阶数降低 |
| 提高信噪比 | 过采样率 $M$ 倍，SNR 提高 $10\log_{10}M$ dB（约 3 dB/倍频程） |
| 降低量化噪声 | 噪声能量分散到更宽频带，带内噪声减少 |
| 简化模拟前端 | 模拟滤波器要求降低 |

**过采样与分辨率关系：** 过采样率每增加 4 倍，等效增加 1 位分辨率。

$$\text{ENOB}_{eff} = n + \frac{1}{2}\log_2(M)$$

其中 $M$ 为过采样率，$n$ 为原始 ADC 位数。

#### 欠采样 (Undersampling / Bandpass Sampling)

对窄带带通信号，采样率可以远低于信号中心频率，只需满足带通采样定理。

**带通采样条件：**

$$f_s \geq 2B$$

且 $f_s$ 的选择需满足：

$$\frac{2f_H}{k+1} \leq f_s \leq \frac{2f_L}{k}$$

其中 $f_L$、$f_H$ 为信号带通下限和上限频率，$k$ 为正整数。

### 7.3 Delta-Sigma (DeltaSigma) ADC 原理

**核心思想：** 以极高采样率、极低分辨率（1 位）进行量化，然后通过数字抽取滤波得到高分辨率输出。

**一阶 DeltaSigma 调制器结构：**

```
x(t) --> [+] --> 积分器 --> [量化器(1-bit)] --> y[n] (高速1-bit流)
             ^                    |
             |                    v
             +---- [1-bit DAC] <---+
```

**差分方程：**

$$v[n] = v[n-1] + x[n] - y[n-1]$$
$$y[n] = Q(v[n])$$

其中 $Q$ 为 1 位量化器（比较器）。

**噪声整形 (Noise Shaping)：**

DeltaSigma 调制器将量化噪声推移到高频区域。一阶噪声传递函数为：

$$NTF(z) = 1 - z^{-1}$$

量化噪声功率谱：
$$|NTF(e^{j\omega})|^2 = |1 - e^{-j\omega}|^2 = 4\sin^2(\omega/2)$$

低频噪声被抑制，高频噪声增大。后续数字低通滤波器（抽取滤波器）去除高频噪声。

**高阶 DeltaSigma：**

| 阶数 | 噪声整形斜率 | SNR 改善 | 稳定性 |
|------|-------------|---------|--------|
| 1 阶 | 20 dB/dec | 9 dB/oct | 稳定 |
| 2 阶 | 40 dB/dec | 15 dB/oct | 稳定 |
| 3 阶 | 60 dB/dec | 21 dB/oct | 需要设计注意 |
| 4 阶+ | 80 dB/dec | 27 dB/oct | MASH 结构 |

**DeltaSigma ADC 典型参数：**

- 过采样率：64x ~ 256x
- 有效分辨率：16-24 位
- 输入带宽：DC ~ 数百 kHz
- 典型应用：音频 ADC、精密测量、传感器接口

**主要功能模块：**

**使用示例：**

```c
#include "arm_math.h"

#define FFT_SIZE  1024

// FFT 实例
arm_rfft_fast_instance_f32 fft_instance;

float input_buf[FFT_SIZE];
float output_buf[FFT_SIZE];
float magnitude[FFT_SIZE / 2];

void init_fft(void) {
    arm_rfft_fast_init_f32(&fft_instance, FFT_SIZE);
}

void compute_spectrum(float *signal) {
    // FFT
    arm_rfft_fast_f32(&fft_instance, signal, output_buf, 0);

    // 计算幅度谱
    arm_cmplx_mag_f32(output_buf, magnitude, FFT_SIZE / 2);

    // 转换为 dB
    for (int i = 0; i < FFT_SIZE / 2; i++) {
        magnitude[i] = 20.0f * log10f(magnitude[i] + 1e-10f);
    }
}
```

### 8.2 定点 vs 浮点运算

| 特性 | 定点运算 | 浮点运算 |
|------|---------|---------|
| 数据格式 | 固定小数点位置 | IEEE 754 浮点 |
| 动态范围 | 小，受位宽限制 | 大 ($\pm 3.4 \times 10^{38}$ for float32) |
| 精度 | 固定，均匀分布 | 相对精度固定，大数精度低 |
| 硬件需求 | 无需 FPU | 需要 FPU 单元 |
| 速度 | 通常更快 | FPU 加速后接近 |
| 功耗 | 低 | 较高 |
| 编程复杂度 | 高（需手动管理溢出和舍入） | 低 |
| 典型平台 | Cortex-M0/M3（无 FPU） | Cortex-M4F/M7（有 FPU） |

**溢出处理策略：**

1. **饱和 (Saturation)：** 超出范围时截断到最大/最小值
2. **回绕 (Wrap-around)：** 利用模运算自动回绕
3. **缩放 (Scaling)：** 预先缩小信号幅度

### 8.3 Q 格式定点数

**Q 格式表示法：** $Qm.n$ 表示 $m$ 位整数部分 + $n$ 位小数部分（含 1 位符号位）。

| Q 格式 | 总位数 | 范围 | 精度 |
|--------|--------|------|------|
| Q15 | 16 | [-1, 0.999969] | $3.05 \times 10^{-5}$ |
| Q31 | 32 | [-1, 0.9999999995] | $4.66 \times 10^{-10}$ |
| Q1.14 | 16 | [-2, 1.999939] | $6.10 \times 10^{-5}$ |
| Q2.13 | 16 | [-4, 3.999878] | $1.22 \times 10^{-4}$ |
| Q4.12 | 16 | [-16, 15.999756] | $2.44 \times 10^{-4}$ |

**Q 格式运算规则：**

```
加法/减法:  直接运算（需相同 Q 格式）
乘法:       Q(a.b) * Q(c.d) = Q(a+c).(b+d)，结果右移回目标格式
除法:       左移后相除
```

**C 语言 Q15 乘法示例：**

```c
typedef int16_t q15_t;
typedef int32_t q31_t;

// Q15 乘法: 两个 Q15 相乘得到 Q30, 右移 15 位回到 Q15
q15_t q15_mul(q15_t a, q15_t b) {
    q31_t temp = (q31_t)a * (q31_t)b;
    return (q15_t)((temp + (1 << 14)) >> 15);  // 四舍五入
}

// Q15 乘加: acc += a * b
q31_t q15_mac(q31_t acc, q15_t a, q15_t b) {
    return acc + (q31_t)a * (q31_t)b;
}
```

**ARM 内置 Q 格式指令（Cortex-M3/M4）：**

```c
// 使用 __SSAT 饱和
int32_t saturated = __SSAT(value, 16);  // 饱和到 16 位有符号

// 使用 __SMUAD 双 16 位乘加
int32_t result = __SMUAD(a, b);  // a_lo*b_lo + a_hi*b_hi
```

## 九、常用 DSP 应用

### 9.1 音频均衡器 (Audio Equalizer)

**均衡器类型：**

| 类型 | 说明 | 实现 |
|------|------|------|
| 图形均衡器 (GEQ) | 固定频率段，用户调增益 | 并联双二阶滤波器 |
| 参数均衡器 (PEQ) | 频率/增益/Q 值均可调 | 双二阶 (Biquad) 滤波器 |
| Shelving EQ | 低频/高频整体提升或衰减 | 一阶或二阶 shelving 滤波器 |

**双二阶 (Biquad) 滤波器结构：**

$$H(z) = \frac{b_0 + b_1 z^{-1} + b_2 z^{-2}}{1 + a_1 z^{-1} + a_2 z^{-2}}$$

**直接 I 型实现：**

```c
typedef struct {
    float b0, b1, b2;  // 分子系数
    float a1, a2;       // 分母系数
    float x1, x2;       // 输入历史
    float y1, y2;       // 输出历史
} Biquad;

float biquad_process(Biquad *f, float x) {
    float y = f->b0 * x + f->b1 * f->x1 + f->b2 * f->x2
                           - f->a1 * f->y1 - f->a2 * f->y2;
    f->x2 = f->x1;  f->x1 = x;
    f->y2 = f->y1;  f->y1 = y;
    return y;
}
```

**参数均衡器系数计算（Audio EQ Cookbook, RBJ）：**

Peak EQ（峰值均衡器）中心频率 $f_0$、增益 $G$ dB、Q 值：

```
A  = sqrt(10^(G/20))
w0 = 2*pi*f0/fs
alpha = sin(w0) / (2*Q)

b0 =   1 + alpha*A
b1 =  -2*cos(w0)
b2 =   1 - alpha*A
a0 =   1 + alpha/A
a1 =  -2*cos(w0)
a2 =   1 - alpha/A

// 归一化 (除以 a0)
```

### 9.2 噪声消除 (Noise Cancellation)

**频域噪声消除（谱减法）：**

$$|\hat{S}[k]|^2 = |X[k]|^2 - \alpha |\hat{N}[k]|^2$$

其中 $|X[k]|^2$ 为含噪信号功率谱，$|\hat{N}[k]|^2$ 为估计的噪声功率谱。

**谱减法流程：**

1. 在信号静默期估计噪声功率谱 $\hat{N}[k]$
2. 对每帧信号做 FFT
3. 减去噪声功率谱（设下限 $\beta$ 防止负值）
4. 逆 FFT 重建信号

**改进：带限谱减法 (Spectral Subtraction with Floor)**

$$|\hat{S}[k]| = \max\left(|X[k]| - \alpha|\hat{N}[k]|, \quad \beta|X[k]|\right)$$

$\beta$ 为谱下限因子（典型 0.01 ~ 0.1），抑制 "音乐噪声" 伪影。

### 9.3 回声消除 (AEC)

**回声消除原理：**

```
远端信号 x[n] --> 扬声器 --> 声学路径 --> 回声 d[n]
                                        |
近端语音 s[n] --> 麦克风 --> s[n] + d[n] --> [+] --> e[n]
                                              ^
                                              |
x[n] --> [自适应滤波器 W(z)] --> 回声估计 d_hat[n]
```

**核心公式：**

$$e[n] = (s[n] + d[n]) - \hat{d}[n]$$

自适应滤波器学习扬声器到麦克声之间的声学传递函数。

**双讲检测 (Double-Talk Detection)：**

当远端和近端同时说话时，自适应滤波器会发散。需要双讲检测来暂停自适应更新。

**常用检测方法：**
- Geigel 算法：比较远端和误差信号幅度
- 基于能量比的检测
- 基于互相关的检测

### 9.4 语音活动检测 (VAD)

**VAD（Voice Activity Detection）** 判断当前音频帧是否包含语音。

**常用特征：**

| 特征 | 计算方法 | 说明 |
|------|---------|------|
| 短时能量 | $E = \sum x^2[n]$ | 简单但受噪声影响 |
| 过零率 | $\text{ZCR} = \frac{1}{2}\sum|\text{sgn}(x[n])-\text{sgn}(x[n-1])|$ | 区分清音/浊音 |
| 频谱质心 | $\frac{\sum k \cdot |X[k]|}{\sum |X[k]|}$ | 语音能量集中在低频 |
| MFCC | 梅尔频率倒谱系数 | 语音识别的标准特征 |
| 信噪比 | $\text{SNR} = 10\log(P_s/P_n)$ | 自适应门限 |

**简单 VAD 实现思路：**

```
对每帧音频:
    1. 计算短时能量 E 和过零率 ZCR
    2. 如果 E > 高门限 -> 语音帧
    3. 如果 E < 低门限 && ZCR > 门限 -> 可能是清音
    4. 能量平滑 + 挂起计时器（防止语音中间断）
```

## 十、PID 控制器数字化

### 10.1 PID 控制基础

**连续 PID 控制律：**

$$u(t) = K_p e(t) + K_i \int_0^t e(\tau)d\tau + K_d \frac{de(t)}{dt}$$

其中 $e(t) = r(t) - y(t)$ 为误差（设定值 - 实际值）。

| 参数 | 名称 | 作用 |
|------|------|------|
| $K_p$ | 比例增益 | 减小稳态误差，加快响应 |
| $K_i$ | 积分增益 | 消除稳态误差 |
| $K_d$ | 微分增益 | 抑制超调，改善动态性能 |

### 10.2 位置式 PID

**离散化（后向差分）：**

$$u[n] = K_p e[n] + K_i T_s \sum_{i=0}^{n} e[i] + K_d \frac{e[n] - e[n-1]}{T_s}$$

**C 语言实现：**

```c
typedef struct {
    float Kp, Ki, Kd;
    float Ts;           // 采样周期
    float integral;     // 积分累积
    float prev_error;   // 上一次误差
    float out_min;      // 输出下限
    float out_max;      // 输出上限
} PID_Pos;

float pid_positional(PID_Pos *pid, float setpoint, float measurement) {
    float error = setpoint - measurement;

    // 比例项
    float P = pid->Kp * error;

    // 积分项
    pid->integral += error * pid->Ts;
    float I = pid->Ki * pid->integral;

    // 微分项
    float D = pid->Kd * (error - pid->prev_error) / pid->Ts;
    pid->prev_error = error;

    // 输出限幅
    float output = P + I + D;
    if (output > pid->out_max) output = pid->out_max;
    if (output < pid->out_min) output = pid->out_min;

    return output;
}
```

### 10.3 增量式 PID

**增量式公式：**

$$\Delta u[n] = u[n] - u[n-1] = K_p(e[n]-e[n-1]) + K_i T_s e[n] + K_d \frac{e[n]-2e[n-1]+e[n-2]}{T_s}$$

$$u[n] = u[n-1] + \Delta u[n]$$

**C 语言实现：**

```c
typedef struct {
    float Kp, Ki, Kd;
    float Ts;
    float prev_error;
    float prev_prev_error;
    float output;       // 当前输出
    float out_min, out_max;
} PID_Inc;

float pid_incremental(PID_Inc *pid, float setpoint, float measurement) {
    float error = setpoint - measurement;

    float delta_P = pid->Kp * (error - pid->prev_error);
    float delta_I = pid->Ki * pid->Ts * error;
    float delta_D = pid->Kd * (error - 2.0f * pid->prev_error + pid->prev_prev_error) / pid->Ts;

    pid->prev_prev_error = pid->prev_error;
    pid->prev_error = error;

    pid->output += delta_P + delta_I + delta_D;

    // 输出限幅
    if (pid->output > pid->out_max) pid->output = pid->out_max;
    if (pid->output < pid->out_min) pid->output = pid->out_min;

    return pid->output;
}
```

**位置式 vs 增量式对比：**

| 特性 | 位置式 PID | 增量式 PID |
|------|-----------|-----------|
| 输出 | $u[n]$ 的绝对值 | $\Delta u[n]$ 的增量 |
| 积分项 | 显式累积 $\sum e[i]$ | 隐含在公式中 |
| 手动/自动切换 | 需要跟踪积分项 | 无扰切换（增量小） |
| 误动作影响 | 大（直接影响绝对输出） | 小（只影响增量） |
| 执行器故障 | 可能积分饱和 | 安全（增量趋于零） |
| 嵌入式推荐 | 一般场景 | 执行器控制、安全关键 |

### 10.4 积分饱和 (Integral Windup)

**问题描述：** 当执行器输出达到饱和限幅时，误差持续累积在积分项中，导致严重超调。

**抗积分饱和方法：**

#### (a) 输出限幅 + 积分限幅

```c
// 单独限制积分项范围
if (integral > integral_max) integral = integral_max;
if (integral < integral_min) integral = integral_min;
```

#### (b) 条件积分（Clamping Anti-Windup）

只在输出未饱和时才累加积分：

```c
float output = P + I + D;
if ((output < out_max && error > 0) || (output > out_min && error < 0)) {
    integral += error * Ts;
}
```

#### (c) 反馈抗饱和 (Back-Calculation)

```c
float output_raw = P + I + D;
float output = constrain(output_raw, out_min, out_max);

// 将饱和量反馈回积分项
float saturation = output - output_raw;
integral += (error + Kb * saturation) * Ts;
```

其中 $K_b$ 为反馈增益。

### 10.5 参数整定

#### Ziegler-Nichols 临界振荡法

1. 将 $K_i = 0$, $K_d = 0$
2. 逐渐增大 $K_p$，直到系统出现持续等幅振荡
3. 记录临界增益 $K_u$ 和振荡周期 $T_u$
4. 按下表计算参数：

| 控制器类型 | $K_p$ | $K_i$ | $K_d$ |
|-----------|-------|-------|-------|
| P | $0.5K_u$ | -- | -- |
| PI | $0.45K_u$ | $0.54K_u/T_u$ | -- |
| PID | $0.6K_u$ | $1.2K_u/T_u$ | $0.075K_u T_u$ |

#### Ziegler-Nichols 阶跃响应法

1. 记录系统开环阶跃响应
2. 测量纯延迟时间 $L$ 和时间常数 $T$
3. 按下表计算：

| 控制器类型 | $K_p$ | $K_i$ | $K_d$ |
|-----------|-------|-------|-------|
| P | $T/L$ | -- | -- |
| PI | $0.9T/L$ | $0.3/L$ | -- |
| PID | $1.2T/L$ | $0.6/L$ | $0.5L$ |

#### Cohen-Coon 整定法

适用于有较大纯延迟的系统，给出更精细的整定公式。

#### 工程整定建议

1. **先 P 后 I 再 D：** 先调 $K_p$ 到临界稳定，再加 $K_i$ 消除稳态误差，最后加 $K_d$ 抑制超调
2. **采样时间选择：** $T_s \leq T_{process}/10$，其中 $T_{process}$ 为被控对象主要时间常数
3. **微分滤波：** 纯微分对噪声敏感，使用一阶低通滤波的不完全微分：

$$D_{filtered}[n] = \frac{K_d}{T_s + \alpha} \left(e[n] - e[n-1]\right) + \frac{\alpha}{T_s + \alpha} D_{filtered}[n-1]$$

## 附录 B：Python DSP 常用代码片段

```python
import numpy as np
from scipy import signal
import matplotlib.pyplot as plt

# ========== FFT 频谱分析 ==========
def analyze_spectrum(x, fs, n_fft=None):
    """计算单边幅度谱"""
    if n_fft is None:
        n_fft = len(x)
    X = np.fft.rfft(x, n=n_fft)
    freq = np.fft.rfftfreq(n_fft, 1/fs)
    magnitude = 20 * np.log10(np.abs(X) / len(x) + 1e-10)
    return freq, magnitude

# ========== FIR 滤波器设计 ==========
def design_fir_lowpass(fs, fc, num_taps=101, window='hamming'):
    """设计 FIR 低通滤波器"""
    coeffs = signal.firwin(num_taps, fc, fs=fs, window=window)
    return coeffs

# ========== 双二阶级联 IIR ==========
def design_iir_lowpass(fs, fc, order=4):
    """设计 Butterworth IIR 低通滤波器（双二阶级联）"""
    sos = signal.butter(order, fc, btype='low', fs=fs, output='sos')
    return sos

# ========== 自适应 LMS ==========
def lms_filter(x, d, N=32, mu=0.01):
    """LMS 自适应滤波"""
    n_samples = len(x)
    w = np.zeros(N)
    y = np.zeros(n_samples)
    e = np.zeros(n_samples)

    for n in range(N, n_samples):
        x_vec = x[n-N:n][::-1]
        y[n] = np.dot(w, x_vec)
        e[n] = d[n] - y[n]
        w += 2 * mu * e[n] * x_vec

    return y, e, w

# ========== 功率谱密度 (Welch) ==========
def compute_psd(x, fs, nperseg=1024):
    """Welch 方法估计 PSD"""
    freqs, psd = signal.welch(x, fs=fs, nperseg=nperseg,
                               window='hann', noverlap=nperseg//2)
    return freqs, 10 * np.log10(psd + 1e-20)

# ========== STFT 语谱图 ==========
def compute_spectrogram(x, fs, nperseg=512, noverlap=384):
    """计算语谱图"""
    f, t, Sxx = signal.spectrogram(x, fs=fs, nperseg=nperseg,
                                     noverlap=noverlap, window='hann')
    return f, t, 10 * np.log10(Sxx + 1e-20)

# ========== 双二阶参数均衡器 ==========
def peaking_eq(f0, gain_db, Q, fs):
    """Peak EQ (RBJ Cookbook)"""
    A = 10**(gain_db / 40)
    w0 = 2 * np.pi * f0 / fs
    alpha = np.sin(w0) / (2 * Q)

    b0 = 1 + alpha * A
    b1 = -2 * np.cos(w0)
    b2 = 1 - alpha * A
    a0 = 1 + alpha / A
    a1 = -2 * np.cos(w0)
    a2 = 1 - alpha / A

    return np.array([b0/a0, b1/a0, b2/a0]),
           np.array([1.0, a1/a0, a2/a0])
```

// DSP 处理任务示例
void dsp_task(void *pvParameters) {
    const TickType_t period = pdMS_TO_TICKS(10); // 10ms 周期
    TickType_t last_wake = xTaskGetTickCount();

    // 初始化滤波器、FFT 等
    init_filters();

    while (1) {
        // 等待 DMA 双缓冲满（通过信号量或任务通知）
        ulTaskNotifyTake(pdTRUE, portMAX_DELAY);

        process_buffer(current_buffer);

        // 周期延时（精确周期）
        vTaskDelayUntil(&last_wake, period);
    }
}
