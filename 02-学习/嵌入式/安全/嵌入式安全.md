# 嵌入式安全

## 核心概念

- **安全启动** - 验证固件完整性和真实性
- **加密** - 保护数据机密性
- **认证** - 验证设备身份
- **安全存储** - 保护密钥和敏感数据

---

## 一、安全威胁

### 1.1 常见攻击

| 攻击类型 | 说明 | 防护措施 |
|---------|------|----------|
| 固件提取 | 读取Flash内容 | 读保护、加密 |
| 固件篡改 | 修改固件 | 安全启动、签名 |
| 侧信道攻击 | 通过功耗/时序分析 | 恒定时间算法 |
| 重放攻击 | 重发捕获的数据 | Nonce、时间戳 |
| 中间人攻击 | 截获通信 | TLS、证书验证 |
| 物理攻击 | 直接访问硬件 | 防拆设计、加密芯片 |

---

### 1.2 安全等级

| 等级 | 说明 | 应用 |
|------|------|------|
| 无安全 | 无防护 | 学习项目 |
| 基本安全 | 读保护、简单加密 | 消费电子 |
| 中等安全 | 安全启动、TLS | 物联网设备 |
| 高安全 | 安全芯片、认证 | 支付、门锁 |

---

## 二、安全启动

### 2.1 安全启动流程

```
BootROM → 验证Bootloader → 验证应用程序 → 运行
   │           │                │
   │      签名验证          签名验证
   │           │                │
   └─── 根公钥 ┘                │
                                │
                           Bootloader公钥
```

---

### 2.2 签名验证

**RSA签名：**
```
签名 = Hash(固件)^d mod n
验证 = 签码^e mod n == Hash(固件)
```

**ECDSA签名：**
- 更短的密钥
- 更快的验证
- 更小的存储

---

### 2.3 ESP32安全启动

**Secure Boot V2：**
```bash
# 生成签名密钥
espsecure.py generate_signing_key --version 2 signing_key.pem

# 启用安全启动
idf.py menuconfig
# → Security features → Enable secure boot

# 烧录
idf.py build
idf.py encrypted-flash
```

**工作流程：**
1. BootROM验证Bootloader签名
2. Bootloader验证App签名
3. App运行

## 三、固件加密

### 3.1 Flash加密

**目的：** 防止固件被读取

**ESP32 Flash加密：**
```bash
# 生成加密密钥
espsecure.py generate_flash_encryption_key my_flash_encryption_key.bin

# 启用加密
idf.py menuconfig
# → Security features → Enable flash encryption

# 烧录
idf.py encrypted-flash
```

---

### 3.2 代码加密

**AES加密：**
```c
#include "mbedtls/aes.h"

// 加密
mbedtls_aes_context aes;
mbedtls_aes_init(&aes);
mbedtls_aes_setkey_enc(&aes, key, 256);
mbedtls_aes_crypt_cbc(&aes, MBEDTLS_AES_ENCRYPT, 
                       len, iv, input, output);
mbedtls_aes_free(&aes);

// 解密
mbedtls_aes_init(&aes);
mbedtls_aes_setkey_dec(&aes, key, 256);
mbedtls_aes_crypt_cbc(&aes, MBEDTLS_AES_DECRYPT, 
                       len, iv, input, output);
mbedtls_aes_free(&aes);
```

## 四、安全通信

### 4.1 TLS/SSL

**配置：**
```c
// CA证书
const char *ca_cert = "-----BEGIN CERTIFICATE-----\n"
    "...\n"
    "-----END CERTIFICATE-----\n";

// MQTT TLS配置
esp_mqtt_client_config_t mqtt_cfg = {
    .broker.address.uri = "mqtts://broker.example.com:8883",
    .broker.verification.certificate = ca_cert,
};
```

---

### 4.2 证书验证

**验证流程：**
1. 服务器发送证书
2. 客户端验证证书链
3. 检查证书有效期
4. 检查吊销状态
5. 建立加密连接

---

### 4.3 双向认证

**客户端证书：**
```c
// 客户端证书
const char *client_cert = "-----BEGIN CERTIFICATE-----\n"
    "...\n"
    "-----END CERTIFICATE-----\n";

// 客户端密钥
const char *client_key = "-----BEGIN RSA PRIVATE KEY-----\n"
    "...\n"
    "-----END RSA PRIVATE KEY-----\n";

// 配置
esp_mqtt_client_config_t mqtt_cfg = {
    .credentials.authentication.certificate = client_cert,
    .credentials.authentication.key = client_key,
};
```

## 五、密钥管理

### 5.1 密钥存储

**安全存储方式：**
| 方式 | 安全性 | 说明 |
|------|--------|------|
| Flash明文 | 低 | 不推荐 |
| eFuse | 高 | 一次性写入 |
| 安全芯片 | 最高 | 独立硬件 |
| NVS加密 | 中 | 加密存储 |

---

### 5.2 eFuse

**ESP32 eFuse：**
```c
#include "esp_efuse.h"

// 读取eFuse
uint32_t value = esp_efuse_read_reg(EFUSE_BLK1, 0);

// 写入eFuse（不可逆！）
esp_efuse_write_reg(EFUSE_BLK1, 0, value);
```

**用途：**
- Flash加密密钥
- 安全启动公钥
- 设备ID

---

### 5.3 安全芯片

**ATECC608A：**
- 安全密钥存储
- 硬件加密加速
- 签名验证
- I2C接口

**应用：**
- 设备认证
- 安全启动
- TLS握手

## 六、安全编码

### 6.1 输入验证

```c
// 验证输入长度
if (len > MAX_BUFFER_SIZE) {
    return -1;
}

// 验证输入范围
if (value < MIN_VALUE || value > MAX_VALUE) {
    return -1;
}

// 验证字符串格式
if (!is_valid_format(input)) {
    return -1;
}
```

---

### 6.2 缓冲区安全

```c
// 使用安全函数
strncpy(dest, src, sizeof(dest) - 1);
dest[sizeof(dest) - 1] = '\0';

snprintf(buf, sizeof(buf), "%s", src);

// 边界检查
if (index >= ARRAY_SIZE) {
    return -1;
}
```

---

### 6.3 密码学最佳实践

**不要：**
- 使用自创加密算法
- 硬编码密钥
- 使用弱哈希(MD5, SHA1)
- 重用Nonce/IV

**要：**
- 使用标准库(mbedTLS)
- 安全随机数生成
- 定期轮换密钥
- 使用认证加密(AES-GCM)
