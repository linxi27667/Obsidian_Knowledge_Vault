# 音频处理技术

## 核心概念

- **音频** - 声音的数字化表示
- **采样率** - 每秒采样次数(Hz)
- **位深度** - 每个采样的位数
- **编解码器(Codec)** - 音频压缩/解压缩

---

## 一、音频基础

### 1.1 数字音频参数

| 参数 | 常用值 | 说明 |
|------|--------|------|
| 采样率 | 8kHz/16kHz/44.1kHz/48kHz | 电话8k, CD 44.1k |
| 位深度 | 8/16/24/32 bit | 16bit最常用 |
| 声道数 | 1(Mono)/2(Stereo) | 单声道/立体声 |

**奈奎斯特定理：** 采样率 ≥ 2 × 最高频率

**数据量计算：**
```
数据率 = 采样率 × 位深度 × 声道数
44.1kHz × 16bit × 2 = 1411.2 kbps
```

| 格式 | 类型 | 特点 | 应用 |
|------|------|------|------|
| PCM | 原始 | 无压缩 | 内部处理 |

## 二、音频接口

### 2.1 I2S总线

**I2S信号：**
| 信号 | 说明 |
|------|------|
| SCK (BCLK) | 位时钟 |
| WS (LRCK) | 字选择(左右声道) |
| SD | 数据线 |

**I2S时序：**
```
WS:   ┌───┐   ┌───┐   ┌───┐
      │ L │ R │ L │ R │ L │ R
    ──┘   └───┘   └───┘   └──

SD:   ─┤MSB├─...─┤LSB├─┤MSB├─...
```

**ESP-IDF I2S配置：**
```c
#include "driver/i2s_std.h"

i2s_chan_handle_t rx_handle, tx_handle;

// 通道配置
i2s_chan_config_t chan_cfg = I2S_CHANNEL_DEFAULT_CONFIG(I2S_NUM_0, I2S_ROLE_MASTER);
i2s_new_channel(&chan_cfg, &tx_handle, &rx_handle);

// 标准模式配置
i2s_std_config_t std_cfg = {
    .clk_cfg = I2S_STD_CLK_DEFAULT_CONFIG(44100),
    .slot_cfg = I2S_STD_PHILIPS_SLOT_DEFAULT_CONFIG(I2S_DATA_BIT_WIDTH_16BIT, I2S_SLOT_MODE_STEREO),
    .gpio_cfg = {
        .mclk = I2S_GPIO_UNUSED,
        .bclk = GPIO_NUM_5,
        .ws = GPIO_NUM_6,
        .dout = GPIO_NUM_7,
        .din = I2S_GPIO_UNUSED,
        .invert_flags = { .mclk_inv = false, .bclk_inv = false, .ws_inv = false },
    },
};
i2s_channel_init_std_mode(tx_handle, &std_cfg);
i2s_channel_enable(tx_handle);

// 写入音频数据
size_t bytes_written;
i2s_channel_write(tx_handle, audio_buffer, buffer_size, &bytes_written, 1000);
```

**ES8311初始化(I2C)：**
```c
#include "driver/i2c_master.h"

#define ES8311_ADDR 0x18

void es8311_init(i2c_master_dev_handle_t dev) {
    uint8_t data[2];

    // 复位
    data[0] = 0x00; data[1] = 0x80;
    i2c_master_transmit(dev, data, 2, 100);

    // 设置时钟
    data[0] = 0x01; data[1] = 0x1F;
    i2c_master_transmit(dev, data, 2, 100);

    // 设置采样率
    data[0] = 0x10; data[1] = 0x0C;  // MCLK/LRCK = 256
    i2c_master_transmit(dev, data, 2, 100);

    // 设置音量
    data[0] = 0x3E; data[1] = 0x00;  // DAC音量
    i2c_master_transmit(dev, data, 2, 100);
}
```

## 三、音频处理算法

### 3.1 基础处理

**音量调节：**
```c
void adjust_volume(int16_t *buffer, int samples, float gain) {
    for (int i = 0; i < samples; i++) {
        int32_t sample = (int32_t)(buffer[i] * gain);
        // 饱和处理
        if (sample > 32767) sample = 32767;
        if (sample < -32768) sample = -32768;
        buffer[i] = (int16_t)sample;
    }
}
```

**混音：**
```c
void mix_audio(int16_t *dst, int16_t *src1, int16_t *src2, int samples) {
    for (int i = 0; i < samples; i++) {
        int32_t mixed = (int32_t)src1[i] + (int32_t)src2[i];
        if (mixed > 32767) mixed = 32767;
        if (mixed < -32768) mixed = -32768;
        dst[i] = (int16_t)mixed;
    }
}
```

### 3.2 滤波器

**低通滤波(IIR)：**
```c
typedef struct {
    float a[3];  // 反馈系数
    float b[3];  // 前馈系数
    float x[3];  // 输入历史
    float y[3];  // 输出历史
} biquad_filter_t;

float biquad_process(biquad_filter_t *f, float input) {
    f->x[0] = input;
    f->y[0] = f->b[0]*f->x[0] + f->b[1]*f->x[1] + f->b[2]*f->x[2]
             - f->a[1]*f->y[1] - f->a[2]*f->y[2];

    // 移位历史
    f->x[2] = f->x[1]; f->x[1] = f->x[0];
    f->y[2] = f->y[1]; f->y[1] = f->y[0];

    return f->y[0];
}
```

### 3.3 FFT与频谱分析

```c
#include "esp_dsp.h"

#define FFT_SIZE 512

float fft_input[FFT_SIZE * 2];  // 复数输入
float fft_output[FFT_SIZE];

void audio_fft(int16_t *audio, int samples) {
    // 转换为浮点并加窗
    for (int i = 0; i < FFT_SIZE; i++) {
        float window = 0.5f - 0.5f * cosf(2 * M_PI * i / FFT_SIZE);  // Hanning窗
        fft_input[i*2] = (float)audio[i] * window;     // 实部
        fft_input[i*2+1] = 0.0f;                        // 虚部
    }

    // FFT
    dsps_fft2r_fc32(fft_input, FFT_SIZE);
    dsps_bit_rev_fc32(fft_input, FFT_SIZE);

    // 计算幅度
    for (int i = 0; i < FFT_SIZE; i++) {
        float re = fft_input[i*2];
        float im = fft_input[i*2+1];
        fft_output[i] = sqrtf(re*re + im*im) / FFT_SIZE;
    }
}
```

### 3.4 语音活动检测(VAD)

```c
typedef struct {
    float energy_threshold;
    int silence_frames;
    int max_silence;
} vad_state_t;

bool vad_detect(vad_state_t *vad, int16_t *buffer, int samples) {
    // 计算帧能量
    float energy = 0;
    for (int i = 0; i < samples; i++) {
        energy += (float)buffer[i] * buffer[i];
    }
    energy /= samples;
    energy = 10 * log10f(energy + 1);

    if (energy > vad->energy_threshold) {
        vad->silence_frames = 0;
        return true;  // 检测到语音
    } else {
        vad->silence_frames++;
        if (vad->silence_frames > vad->max_silence) {
            return false;  // 静音
        }
        return true;  // 仍在语音中
    }
}
```

## 四、音频编解码

### 4.1 PCM压缩

**A-law/μ-law压缩：**
```c
// μ-law编码(8bit压缩16bit PCM)
uint8_t linear_to_ulaw(int16_t sample) {
    const int16_t BIAS = 0x84;
    const int16_t CLIP = 32635;
    uint8_t sign;

    if (sample < 0) {
        sign = 0x80;
        sample = -sample;
    } else {
        sign = 0;
    }

    if (sample > CLIP) sample = CLIP;
    sample += BIAS;

    int exponent = 7;
    int mask = 0x4000;
    while (exponent > 0 && !(sample & mask)) {
        exponent--;
        mask >>= 1;
    }

    int mantissa = (sample >> (exponent + 3)) & 0x0F;
    return ~(sign | (exponent << 4) | mantissa);
}
```

```c
void record_task(void *arg) {
    int16_t *buffer = malloc(1024 * sizeof(int16_t));
    size_t bytes_read;

        i2s_channel_read(rx_handle, buffer, 1024 * 2, &bytes_read, 1000);

void play_task(void *arg) {
    int16_t *buffer = malloc(1024 * sizeof(int16_t));
    size_t bytes_written;

    while (1) {
        // 从文件或队列读取
        load_from_sd(buffer, 1024 * 2);
        i2s_channel_write(tx_handle, buffer, 1024 * 2, &bytes_written, 1000);
    }
}
```

### 5.2 语音识别(离线关键词)

```c
// 简单关键词检测(基于MFCC+DTW)
typedef struct {
    float reference[13][50];  // MFCC特征模板
    int frames;
} keyword_template_t;

bool keyword_detect(int16_t *audio, int samples, keyword_template_t *kw) {
    // 1. 提取MFCC特征
    float mfcc[13][100];
    int n_frames = extract_mfcc(audio, samples, mfcc);

    // 2. DTW匹配
    float distance = dtw_distance(mfcc, n_frames, kw->reference, kw->frames);

    // 3. 阈值判断
    return distance < KEYWORD_THRESHOLD;
}
```

### 5.3 回声消除(AEC)

```
麦克风信号 = 远端回声 + 近端语音 + 噪声

AEC流程：
1. 参考信号(扬声器输出) → 自适应滤波器 → 估计回声
2. 麦克风信号 - 估计回声 = 近端语音
```

```c
// 简化的LMS自适应滤波
typedef struct {
    float *w;         // 滤波器权重
    float *x_buf;     // 参考信号缓冲
    int len;          // 滤波器长度
    float mu;         // 步长
} aec_state_t;

float aec_process(aec_state_t *aec, float mic, float ref) {
    // 更新参考信号缓冲
    memmove(&aec->x_buf[1], &aec->x_buf[0], (aec->len-1)*sizeof(float));
    aec->x_buf[0] = ref;

    // 计估计回声
    float echo_est = 0;
    for (int i = 0; i < aec->len; i++) {
        echo_est += aec->w[i] * aec->x_buf[i];
    }

    // 误差 = 近端语音
    float error = mic - echo_est;

    // 更新权重(LMS)
    for (int i = 0; i < aec->len; i++) {
        aec->w[i] += aec->mu * error * aec->x_buf[i];
    }

    return error;
}
```

## 六、音频系统设计

### 6.1 音频管道

```
麦克风 → ADC/I2S → 音频缓冲 → 处理算法 → 编码 → 传输/存储
                                                    ↓
喇叭 ← DAC/I2S ← 音频缓冲 ← 处理算法 ← 解码 ← 接收/读取
```

### 6.2 实时音频框架

```c
// 双缓冲
#define BUF_SIZE 256
int16_t buf_a[BUF_SIZE], buf_b[BUF_SIZE];
volatile int active_buf = 0;

// DMA回调
void dma_callback(void) {
    active_buf = !active_buf;
    // 通知处理任务
    xTaskNotifyFromISR(audio_task, active_buf, eSetValueWithOverwrite, NULL);
}

void audio_task(void *arg) {
    while (1) {
        uint32_t buf_id;
        xTaskNotifyWait(0, ULONG_MAX, &buf_id, portMAX_DELAY);

        int16_t *input = (buf_id == 0) ? buf_a : buf_b;
        process_audio(input, BUF_SIZE);
    }
}
```
