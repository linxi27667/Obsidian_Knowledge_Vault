## 1. 工业自动化概述

### 1.1 自动化金字塔（Purdue Model）

工业自动化系统按照功能层次划分为五层金字塔结构，自下而上依次为：

```
┌─────────────────────────────────────┐
│         Level 4: 企业管理层          │  ERP / MES / 供应链
│     (Enterprise Planning Layer)     │
├─────────────────────────────────────┤
│         Level 3: 制造执行层          │  MES / 调度 / 质量管理
│     (Manufacturing Operations)      │
├─────────────────────────────────────┤
│         Level 2: 监控层              │  SCADA / HMI / 历史数据库
│     (Supervisory Control Layer)     │
├─────────────────────────────────────┤
│         Level 1: 控制层              │  PLC / DCS / 运动控制器
│     (Control Layer)                 │
├─────────────────────────────────────┤
│         Level 0: 现场层              │  传感器 / 执行器 / 仪表
│     (Field Layer)                   │
└─────────────────────────────────────┘
```

| 层级 | 名称 | 典型设备/系统 | 通信方式 |
|------|------|---------------|----------|
| Level 0 | 现场层 | 传感器、执行器、仪表 | 4-20mA、HART、IO-Link |
| Level 1 | 控制层 | PLC、DCS、运动控制器 | EtherCAT、PROFINET、Modbus |
| Level 2 | 监控层 | SCADA、HMI、历史数据库 | OPC UA、以太网、SQL |
| Level 3 | 制造执行层 | MES、调度系统、质量管理 | TCP/IP、OPC UA、API |
| Level 4 | 企业管理层 | ERP、供应链、财务系统 | 企业以太网、云平台 |

### 1.2 工业自动化发展历程

| 时期 | 阶段 | 关键技术 |
|------|------|----------|
| 1960s | 继电器逻辑时代 | 继电器柜、硬接线逻辑 |

### 1.3 工业自动化与嵌入式的关系

工业自动化系统的核心——PLC、DCS、运动控制器——本质上都是**嵌入式系统**：

- **硬件**：工业级MCU/SoC（STM32、TI Sitara、NXP i.MX）
- **软件**：实时操作系统（RTOS）、IEC 61131-3运行时
- **通信**：工业以太网协议栈（EtherCAT从站、PROFINET IO）
- **安全**：功能安全固件（SIL2/SIL3认证）

### 2.2 IEC 61131-3 编程语言标准

IEC 61131-3 定义了五种标准编程语言：

| 语言 | 缩写 | 类型 | 适用场景 |
|------|------|------|----------|
| 梯形图 | LD | 图形化 | 继电器逻辑替代、离散控制 |
| 功能块图 | FBD | 图形化 | 过程控制、模拟量处理 |
| 结构化文本 | ST | 文本 | 复杂算法、数据处理 |
| 指令表 | IL | 文本 | 底层优化（已弃用） |
| 顺序功能图 | SFC | 图形化 | 顺序控制、状态机 |

#### 2.2.1 梯形图（Ladder Diagram, LD）

```
    ┌──┤ ├──┬──┤/├──┬──( )──┐
    │  I0.0 │  I0.1 │  Q0.0 │
    │       │       │       │
    ├──┤ ├──┘       │       │
    │  I0.2         │       │
    └───────────────────────┘

逻辑表达式：Q0.0 = (I0.0 AND NOT I0.1) OR I0.2
```

梯形图基本元素：
- **常开触点** `--| |--`：对应布尔变量为 TRUE 时导通
- **常闭触点** `--|/|--`：对应布尔变量为 FALSE 时导通
- **线圈** `--( )--`：输出赋值
- **定时器** `TON/TOF/TP`：延时控制
- **计数器** `CTU/CTD/CTUD`：计数控制

#### 2.2.2 功能块图（Function Block Diagram, FBD）

```
        ┌───────┐
 I0.0──→│       │
        │  AND  │──→ Q0.0
 I0.1──→│       │
        └───────┘

        ┌───────┐
  AI0──→│  PID  │──→ AO0
        │       │
  SP0──→│  控制器 │
        └───────┘
```

#### 2.2.3 结构化文本（Structured Text, ST）

```iecst
(* PID 控制器 ST 实现 *)
FUNCTION_BLOCK PID_Controller
VAR_INPUT
    SetPoint   : REAL;     (* 设定值 *)
    ProcessVar : REAL;     (* 过程变量 *)
    Kp         : REAL;     (* 比例系数 *)
    Ki         : REAL;     (* 积分系数 *)
    Kd         : REAL;     (* 微分系数 *)
END_VAR
VAR_OUTPUT
    Output     : REAL;     (* 控制输出 *)
END_VAR
VAR
    Error      : REAL;     (* 偏差 *)
    Integral   : REAL;     (* 积分累加 *)
    Derivative : REAL;     (* 微分项 *)
    PrevError  : REAL;     (* 上次偏差 *)
END_VAR

Error := SetPoint - ProcessVar;
Integral := Integral + Error * CycleTime;
Derivative := (Error - PrevError) / CycleTime;

Output := Kp * Error + Ki * Integral + Kd * Derivative;

(* 输出限幅 *)
IF Output > 100.0 THEN
    Output := 100.0;
ELSIF Output < 0.0 THEN
    Output := 0.0;
END_IF;

PrevError := Error;
```

### 3.2 Modbus 协议详解

#### 3.2.1 Modbus RTU 帧格式

Modbus RTU 使用 RS-485 物理层，主从架构，二进制编码：

```
┌────────┬──────────┬──────────┬──────────┬──────────┐
│ 地址域  │ 功能码    │ 数据域    │ CRC高字节 │ CRC低字节 │
│ 1 Byte │ 1 Byte   │ N Bytes  │ 1 Byte   │ 1 Byte   │
└────────┴──────────┴──────────┴──────────┴──────────┘

帧间隔：≥ 3.5 字符时间（T3.5）
```

**常用功能码**：

| 功能码 | 名称 | 操作对象 | 说明 |
|--------|------|----------|------|
| 0x01 | 读线圈 | Coil (0x) | 读取 DO 状态 |
| 0x02 | 读离散输入 | Discrete Input (1x) | 读取 DI 状态 |
| 0x03 | 读保持寄存器 | Holding Register (4x) | 读取设定值/参数 |
| 0x04 | 读输入寄存器 | Input Register (3x) | 读取测量值 |
| 0x05 | 写单个线圈 | Coil | 控制单个 DO |
| 0x06 | 写单个寄存器 | Holding Register | 写入单个参数 |
| 0x0F | 写多个线圈 | Coil | 批量控制 DO |
| 0x10 | 写多个寄存器 | Holding Register | 批量写入参数 |

**Modbus RTU 通信示例（读保持寄存器）**：

请求帧：`01 03 00 00 00 0A C5 CD`
- `01` = 从站地址 1
- `03` = 功能码（读保持寄存器）
- `00 00` = 起始地址 0
- `00 0A` = 读取 10 个寄存器
- `C5 CD` = CRC-16 校验

响应帧：`01 03 14 00 64 00 C8 ... CRC`
- `01` = 从站地址 1
- `03` = 功能码
- `14` = 字节数 20（10个寄存器 x 2字节）
- `00 64` = 寄存器0值 = 100
- `00 C8` = 寄存器1值 = 200

#### 3.2.2 Modbus TCP 帧格式

Modbus TCP 在以太网上传输，使用 TCP 端口 502：

```
┌──────────┬──────────┬──────────┬──────────┐
│ MBAP Header (7 Bytes)          │ PDU      │
│ ├── 事务ID (2B)                │ 功能码    │
│ ├── 协议ID  (2B) = 0x0000      │ 数据域    │
│ ├── 长度    (2B)               │          │
│ └── 单元ID  (1B)               │          │
└────────────────────────────────┴──────────┘
```

#### 3.2.3 Modbus RTU 主站 C 实现（STM32）

```c
/* Modbus RTU 主站核心实现 */
#include <stdint.h>
#include <string.h>

#define MODBUS_SLAVE_ADDR   0x01
#define MODBUS_FC_READ_HR   0x03
#define MODBUS_FC_WRITE_HR  0x06
#define MODBUS_TIMEOUT_MS   1000

typedef struct {
    uint8_t  slave_addr;
    uint8_t  function_code;
    uint16_t start_addr;
    uint16_t quantity;
    uint16_t *data;
    uint8_t  error_code;
} ModbusRequest_t;

/* CRC-16/Modbus 查表法 */
static const uint16_t crc16_table[256] = {
    0x0000, 0xC0C1, 0xC181, 0x0140, 0xC301, 0x03C0, 0x0280, 0xC241,
    /* ... 完整256项CRC表 ... */
};

uint16_t Modbus_CRC16(const uint8_t *data, uint16_t length) {
    uint16_t crc = 0xFFFF;
    for (uint16_t i = 0; i < length; i++) {
        crc = (crc >> 8) ^ crc16_table[(crc ^ data[i]) & 0xFF];
    }
    return crc;
}

/* 发送读保持寄存器请求 */
int Modbus_ReadHoldingRegisters(UART_HandleTypeDef *huart,
                                 uint8_t slave_addr,
                                 uint16_t start_addr,
                                 uint16_t quantity,
                                 uint16_t *result) {
    uint8_t tx_buf[8];
    uint8_t rx_buf[256];

    /* 构建请求帧 */
    tx_buf[0] = slave_addr;
    tx_buf[1] = MODBUS_FC_READ_HR;
    tx_buf[2] = (start_addr >> 8) & 0xFF;
    tx_buf[3] = start_addr & 0xFF;
    tx_buf[4] = (quantity >> 8) & 0xFF;
    tx_buf[5] = quantity & 0xFF;

    uint16_t crc = Modbus_CRC16(tx_buf, 6);
    tx_buf[6] = crc & 0xFF;
    tx_buf[7] = (crc >> 8) & 0xFF;

    /* 发送请求（RS-485半双工，需控制DE引脚） */
    HAL_GPIO_WritePin(RS485_DE_GPIO, RS485_DE_PIN, GPIO_PIN_SET);
    HAL_UART_Transmit(huart, tx_buf, 8, MODBUS_TIMEOUT_MS);
    HAL_GPIO_WritePin(RS485_DE_GPIO, RS485_DE_PIN, GPIO_PIN_RESET);

    /* 接收响应 */
    uint16_t expected_bytes = 5 + quantity * 2;
    HAL_StatusTypeDef status = HAL_UART_Receive(huart, rx_buf,
                                                 expected_bytes, MODBUS_TIMEOUT_MS);
    if (status != HAL_OK) return -1;  /* 超时 */

    /* CRC校验 */
    uint16_t rx_crc = Modbus_CRC16(rx_buf, expected_bytes - 2);
    uint16_t frame_crc = rx_buf[expected_bytes - 2]
                       | (rx_buf[expected_bytes - 1] << 8);
    if (rx_crc != frame_crc) return -2;  /* CRC错误 */

    /* 解析数据 */
    for (uint16_t i = 0; i < quantity; i++) {
        result[i] = (rx_buf[3 + i * 2] << 8) | rx_buf[4 + i * 2];
    }

    return 0;  /* 成功 */
}
```

### 3.4 EtherCAT 协议

EtherCAT 是实时工业以太网，由 Beckhoff 开发：

```
主站 ──帧1──→ 从站1 ──帧1──→ 从站2 ──帧1──→ ... ──帧1──→ 主站
              提取/插入      提取/插入                     完整帧返回
```

**EtherCAT 核心特点**：
- **处理方式**：帧在传输过程中由每个从站硬件实时提取/插入数据（"on the fly"）
- **抖动**：小于 1μs（分布式时钟同步）
- **拓扑**：线型、树型、星型，支持热连接
- **从站芯片**：ET1100（ASIC）或 LAN9252（SPI接口）

**EtherCAT 从站开发（LAN9252 + STM32）**：

```c
/* LAN9252 SPI 驱动 + EtherCAT 从站核心 */
#define LAN9252_SPI         SPI1
#define LAN9252_CS_PORT     GPIOA
#define LAN9252_CS_PIN      GPIO_PIN_4

/* LAN9252 寄存器定义 */
#define ECAT_PRAM_RD_ADDR   0x0308
#define ECAT_PRAM_RD_LEN    0x030C
#define ECAT_PRAM_WR_ADDR   0x0310
#define ECAT_PRAM_WR_LEN    0x0314
#define ESC_DL_STATUS       0x0110

uint32_t LAN9252_ReadReg(uint16_t addr) {
    uint8_t cmd[4];
    uint8_t data[4];

    cmd[0] = 0x03;  /* 读命令 */
    cmd[1] = (addr >> 8) & 0xFF;
    cmd[2] = addr & 0xFF;
    cmd[3] = 0x00;

    HAL_GPIO_WritePin(LAN9252_CS_PORT, LAN9252_CS_PIN, GPIO_PIN_RESET);
    HAL_SPI_Transmit(&hspi1, cmd, 4, 100);
    HAL_SPI_Receive(&hspi1, data, 4, 100);
    HAL_GPIO_WritePin(LAN9252_CS_PORT, LAN9252_CS_PIN, GPIO_PIN_SET);

    return (data[3] << 24) | (data[2] << 16) | (data[1] << 8) | data[0];
}

/* 从站过程数据交换（PDO映射） */
typedef struct __packed {
    /* RxPDO: 主站 -> 从站 */
    uint16_t digital_output;      /* 数字输出控制字 */
    int16_t  motor_velocity;      /* 目标速度 rpm */
    int32_t  motor_position;      /* 目标位置 cnt */

    /* TxPDO: 从站 -> 主站 */
    uint16_t digital_input;       /* 数字输入状态字 */
    int16_t  actual_velocity;     /* 实际速度 rpm */
    int32_t  actual_position;     /* 实际位置 cnt */
    uint16_t status_word;         /* 状态字 */
} ProcessData_t;
```

### 5.5 4-20mA 电流环

工业现场最常用的模拟量传输标准：

```
传感器（变送器）                  PLC/DCS
┌──────────┐                 ┌──────────┐
│  +24V    │←─── 24V供电 ───│ 电源输出  │
│          │                 │          │
│  信号输出 │─── 4-20mA ───→│ AI输入    │
│          │                 │ (250Ω)   │
│  GND     │←─── 公共地 ────│ GND      │
└──────────┘                 └──────────┘

对应关系：
  4mA  = 量程下限（如 0°C / 0MPa / 0m³/h）
  20mA = 量程上限（如 100°C / 10MPa / 100m³/h）

优势：
  - 抗干扰能力强（电流信号不受线路电阻影响）
  - 可检测断线（< 4mA 表示线路故障）
  - 两线制供电 + 信号共用
```

```

             │ 位置环    │→│ 速度环    │→│ 电流环    │

                  │              │              │

**伺服驱动器参数整定**：

| 参数 | 说明 | 调整原则 |

| 惯量比 J | 负载/电机惯量比 | 影响增益上限，比值越大增益受限 |
| 陷波滤波器 | 抑制机械共振 | 检测共振频率，设置对应陷波 |

### 7.2 TSN 时间敏感网络

TSN (Time-Sensitive Networking) 是 IEEE 802.1 工作组制定的一组标准，目标是在标准以太网上实现确定性通信：

```
TSN 核心标准：

┌─────────────────────────────────────────────┐
│         IEEE 802.1AS - 时间同步              │
│         (gPTP, 广义精确时间协议)               │
│         精度: < 1μs                          │
├─────────────────────────────────────────────┤
│         IEEE 802.1Qbv - 时间感知调度          │
│         (Time-Aware Shaper)                 │
│         门控调度，保障关键流量                  │
├─────────────────────────────────────────────┤
│         IEEE 802.1Qci - 流量过滤与管制        │
│         (Per-Stream Filtering)              │
│         防止异常流量干扰关键通信                │
├─────────────────────────────────────────────┤
│         IEEE 802.1CB - 帧复制与消除           │
│         (Frame Replication and Elimination)  │
│         冗余传输，提高可靠性                    │
├─────────────────────────────────────────────┤
│         IEEE 802.1Qcc - 流预留协议            │
│         (Stream Reservation Protocol)        │
│         集中式/分布式资源管理                   │
└─────────────────────────────────────────────┘
```

**TSN 时间感知调度原理**：

```
时间轴 →
┌────────┬────────┬────────┬────────┬────────┐
│ 门控   │ 门控   │ 门控   │ 门控   │ 门控   │
│ 队列A  │ 队列B  │ 队列A  │ 队列C  │ 队列A  │
│(高优先级)│(中优先级)│(高优先级)│(低优先级)│(高优先级)│
│ 100μs  │ 50μs   │ 100μs  │ 50μs   │ 100μs  │
└────────┴────────┴────────┴────────┴────────┘
  ← 一个调度周期（如 500μs）→

交换机端口的门控列表(Gate Control List)控制
每个时间片只开放特定优先级队列的发送权限
```

## 8. 功能安全

### 8.1 安全完整性等级（SIL）

IEC 61508 定义了四个安全完整性等级：

| SIL等级 | PFD（每小时） | 风险降低因子(RRF) | 典型应用 |
|---------|---------------|-------------------|----------|
| SIL 1 | 10⁻⁵ ~ 10⁻⁴ | 100 ~ 1,000 | 一般机械安全 |
| SIL 2 | 10⁻⁶ ~ 10⁻⁵ | 1,000 ~ 10,000 | 过程工业关键回路 |
| SIL 3 | 10⁻⁷ ~ 10⁻⁶ | 10,000 ~ 100,000 | 化工/石化紧急停车 |
| SIL 4 | 10⁻⁸ ~ 10⁻⁷ | 100,000 ~ 1,000,000 | 核电站安全系统 |

### 8.2 安全 PLC 与标准 PLC

| 特性 | 标准 PLC | 安全 PLC |
|------|----------|----------|
| 处理器 | 单通道 | 双通道（冗余） |
| 诊断覆盖率 | 不要求 | > 90% (SIL2) / > 99% (SIL3) |
| 故障模式 | Fail-Unclassified | Fail-Safe |
| 输入诊断 | 无 | 脉冲测试、断线检测 |
| 输出诊断 | 无 | 回读校验、交叉比较 |
| 通信 | 标准协议 | 安全协议（CIP Safety、PROFIsafe、Safety over EtherCAT） |
| 认证 | 不要求 | TUV、SIL2/SIL3 认证 |

**安全 PLC 架构（2oo3 表决）**：

```
        ┌──────────┐
        │  通道 A   │──┐
        │  CPU + IO │  │
        └──────────┘  │
        ┌──────────┐  │   ┌──────────┐
        │  通道 B   │──┼──→│ 表决逻辑  │──→ 安全输出
        │  CPU + IO │  │   │ (2oo3)   │
        └──────────┘  │   └──────────┘
        ┌──────────┐  │
        │  通道 C   │──┘
        │  CPU + IO │
        └──────────┘

2oo3 = 三取二表决，任意一个通道故障不影响系统运行
```

### 8.3 安全继电器与急停回路

**急停回路设计（符合 ISO 13850 / IEC 60204-1）**：

```
急停按钮设计要求：
  - 红色蘑菇头按钮，黄色背景
  - 自锁式（按下后保持，旋转复位）
  - 强制断开触点（NC触点）
  - 双通道冗余设计

典型急停安全回路：

+24V ──→ ┌──────────┐    ┌──────────┐    ┌──────────┐
          │ 急停1 (NC)│    │ 安全继电器│    │ 接触器   │

### 9.3 预测性维护（PdM）

**振动分析用于轴承故障检测**：

```c
/* 振动信号采集与FFT分析（嵌入式端） */
#include "arm_math.h"

#define FFT_SIZE        1024
#define SAMPLE_RATE     10240   /* Hz */
#define FREQ_RESOLUTION (SAMPLE_RATE / FFT_SIZE)  /* 10Hz */

typedef struct {
    float vibration_rms;        /* 振动有效值 mm/s */
    float peak_frequency;       /* 主频率 Hz */
    float crest_factor;         /* 峰值因子 */
    float kurtosis;             /* 峭度 */
    uint8_t alarm_level;        /* 0=正常, 1=预警, 2=报警 */
} VibrationAnalysis_t;

/* ISO 10816 振动等级标准 */
static const float vibration_limits[] = {
    0.71f,   /* A区: 良好 */
    1.80f,   /* B区: 可接受 */
    4.50f,   /* C区: 警告 */
    11.20f   /* D区: 危险 */
};

VibrationAnalysis_t analyze_vibration(float *raw_data, uint32_t length) {
    VibrationAnalysis_t result;
    float fft_output[FFT_SIZE * 2];  /* 复数数组 */
    float magnitude[FFT_SIZE / 2];

    /* 加窗 + FFT */
    arm_rfft_fast_instance_f32 fft_instance;
    arm_rfft_fast_init_f32(&fft_instance, FFT_SIZE);
    arm_rfft_fast_f32(&fft_instance, raw_data, fft_output, 0);

    /* 计算幅值谱 */
    arm_cmplx_mag_f32(fft_output, magnitude, FFT_SIZE / 2);

    /* RMS值 */
    arm_rms_f32(raw_data, length, &result.vibration_rms);

    /* 峰值频率 */
    uint32_t max_index;
    float max_value;
    arm_max_f32(magnitude + 1, FFT_SIZE / 2 - 1, &max_value, &max_index);
    result.peak_frequency = (max_index + 1) * FREQ_RESOLUTION;

    /* 峰值因子 = 峰值 / RMS */
    float peak;
    arm_max_f32(raw_data, length, &peak, NULL);
    result.crest_factor = fabsf(peak) / result.vibration_rms;

    /* 峭度（判断冲击特征） */
    float sum = 0;
    for (uint32_t i = 0; i < length; i++) {
        sum += powf(raw_data[i], 4);
    }
    result.kurtosis = sum / (length * powf(result.vibration_rms, 4));

    /* 报警判断 */
    if (result.vibration_rms >= vibration_limits[3]) {
        result.alarm_level = 2;  /* 危险 */
    } else if (result.vibration_rms >= vibration_limits[2]) {
        result.alarm_level = 1;  /* 预警 */
    } else {
        result.alarm_level = 0;  /* 正常 */
    }

    return result;
}
```

**轴承故障特征频率**：

| 故障类型 | 频率公式 | 说明 |
|----------|----------|------|
| 外圈故障 BPFO | `n/2 * fr * (1 - d/D * cosα)` | 最常见 |
| 内圈故障 BPFI | `n/2 * fr * (1 + d/D * cosα)` | 含转频调制 |
| 滚动体故障 BSF | `D/(2d) * fr * (1 - (d/D * cosα)²)` | 较少见 |
| 保持架故障 FTF | `fr/2 * (1 - d/D * cosα)` | 通常非关键 |

其中：n=滚珠数，fr=转频，d=滚珠直径，D=节圆直径，α=接触角

### 10.2 宽温设计

**温度等级定义**：

| 等级 | 范围 | 应用环境 |
|------|------|----------|
| 商业级 | 0 ~ 70°C | 办公室/机房 |

| 汽车级 | -40 ~ 125°C | 发动机舱/车载 |
| 军工级 | -55 ~ 155°C | 军事/航空 |

**宽温设计要点**：

```
1. 元器件选型
   - 所有器件选择工业级/汽车级温度等级
   - 电解电容改为陶瓷电容（低温下ESR增大）
   - 晶振选择宽温型号（-40~105°C）

2. PCB设计
   - 使用FR-4高Tg材料（Tg ≥ 170°C）
   - 增加铜箔厚度（2oz vs 1oz）改善散热
   - 关键器件下方增加散热过孔

3. 热设计
   - 计算功耗预算：P_total = Σ(V × I)
   - 散热器选型：R_thermal < (T_j_max - T_ambient) / P_total
   - 导热垫/导热硅脂填充间隙

4. 降额设计
   - 电压降额：使用不超过额定值的80%
   - 电流降额：使用不超过额定值的70%
   - 功率降额：使用不超过额定值的50%
   - 温度降额：结温不超过最大额定的70%
```

### 10.5 长寿命设计

工业产品典型设计寿命 10-20 年，远超消费电子：

```
长寿命设计策略：

1. 元器件选择
   - 选择大厂器件（TI/ADI/ST/NXP），避免小厂淘汰风险
   - 查询产品生命周期（Active/Lifetime Buy/Obsolete）
   - 关键器件保持第二供应商（Second Source）
   - 避免使用最后一站（Last Buy）器件

2. 电容寿命
   - 铝电解电容：寿命 L = L_0 × 2^((T_0-T)/10) × (V_rated/V_applied)^2.5
     L_0: 额定寿命（通常2000-10000小时@105°C）
     T_0: 额定温度
     T: 实际工作温度
   - 固态电容/钽电容替代铝电解可大幅延长寿命
   - 陶瓷电容几乎无寿命限制（但需注意直流偏压效应）

3. 连接器/接插件
   - 选择镀金触点（插拔次数 > 500次）
   - 压接式接线端子（免焊，抗振动）
   - 螺钉端子扭矩标注并使用扭矩扳手

4. 固件升级
   - 支持远程固件升级（OTA/Bootloader）
   - 双Bank升级（A/B分区，升级失败可回退）
   - 签名验证，防止恶意固件

5. 存储器寿命
   - Flash擦写次数：NOR Flash 10万次，NAND Flash 1千-10万次
   - 坏块管理 + 均衡磨损（Wear Leveling）
   - EEPROM仿真（使用Flash模拟EEPROM）
   - 关键参数存FRAM（铁电存储器，10^14次擦写）
```
