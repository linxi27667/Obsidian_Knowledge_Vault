# 电机控制技术

## 核心概念

- **电机** - 将电能转换为机械能的装置
- **FOC** - 磁场定向控制，高性能电机控制算法
- **PWM** - 脉冲宽度调制，控制电机电压
- **编码器** - 测量电机位置和速度

---

## 一、电机类型

### 1.1 直流电机(DC Motor)

**特点：**
- 控制简单
- 成本低
- 速度与电压成正比

**参数：**
| 参数 | 说明 |
|------|------|
| 额定电压 | 正常工作电压 |
| 额定电流 | 正常工作电流 |
| 空载转速 | 无负载时转速 |
| 堵转转矩 | 最大转矩 |

**控制方式：**
```
电压控制：V = Ke * ω + I * R
转矩控制：T = Kt * I
```

---

### 1.2 无刷直流电机(BLDC)

**特点：**
- 无电刷，寿命长
- 效率高
- 需要电子换向

**结构：**
```
定子：三相绕组
转子：永磁体
```

**换向序列：**
```
步进1：A+B- → 步进2：A+C- → 步进3：B+C-
步进4：B+A- → 步进5：C+A- → 步进6：C+B-
```

---

### 1.3 永磁同步电机(PMSM)

**特点：**
- 高效率
- 高功率密度
- 需要FOC控制

**数学模型：**
```
电压方程：
Vd = Rs*id + Ld*did/dt - ωe*Lq*iq
Vq = Rs*iq + Lq*diq/dt + ωe*(Ld*id + ψf)

转矩方程：
Te = 1.5*p*(ψf*iq + (Ld-Lq)*id*iq)
```

---

### 1.4 步进电机

**特点：**
- 精确定位
- 开环控制
- 低速大转矩

**驱动方式：**
| 方式 | 说明 | 精度 |
|------|------|------|
| 全步进 | 两相通电 | 1.8° |
| 半步进 | 交替通电 | 0.9° |
| 细分 | PWM控制电流 | 更高 |

## 三、传感器

### 3.1 编码器

**增量编码器：**
```
A相：位置信号
B相：方向信号
Z相：零点信号
```

**绝对编码器：**
- 直接输出位置
- 断电记忆
- 多圈计数

**读取代码：**
```c
// 增量编码器
int encoder_read(void) {
    static int count = 0;
    int a = gpio_read(ENC_A);
    int b = gpio_read(ENC_B);
    
    if (a != last_a) {
        if (a == b) count++;
        else count--;
    }
    last_a = a;
    
    return count;
}
```

## 四、FOC控制

### 4.1 FOC原理

**控制流程：**
```
目标转矩 → id,iq参考值
    ↓
电流采样 → Clarke变换 → Park变换
    ↓
PI控制器 → 反Park变换 → SVPWM
    ↓
三相逆变器 → 电机
```

---

### 4.2 Clarke变换

**3相→2相：**
$$I_\alpha = I_a$$
$$I_\beta = \frac{I_a + 2I_b}{\sqrt{3}}$$

**代码实现：**
```c
void clarke_transform(float ia, float ib, float *ialpha, float *ibeta) {
    *ialpha = ia;
    *ibeta = (ia + 2.0f * ib) / sqrtf(3.0f);
}
```

---

### 4.3 Park变换

**静止→旋转：**
$$I_d = I_\alpha \cos\theta + I_\beta \sin\theta$$
$$I_q = -I_\alpha \sin\theta + I_\beta \cos\theta$$

**代码实现：**
```c
void park_transform(float ialpha, float ibeta, float theta, 
                    float *id, float *iq) {
    float cos_theta = cosf(theta);
    float sin_theta = sinf(theta);
    
    *id = ialpha * cos_theta + ibeta * sin_theta;
    *iq = -ialpha * sin_theta + ibeta * cos_theta;
}
```

---

### 4.4 反Park变换

**旋转→静止：**
$$I_\alpha = I_d \cos\theta - I_q \sin\theta$$
$$I_\beta = I_d \sin\theta + I_q \cos\theta$$

---

### 4.5 SVPWM

**基本矢量：**
```
V0(000) V1(100) V2(110) V3(010)
V4(011) V5(001) V6(101) V7(111)
```

**扇区判断：**
```c
int get_sector(float valpha, float vbeta) {
    float vref1 = vbeta;
    float vref2 = sqrtf(3.0f)/2.0f * valpha - 0.5f * vbeta;
    float vref3 = -sqrtf(3.0f)/2.0f * valpha - 0.5f * vbeta;
    
    int sector = 0;
    if (vref1 > 0) sector += 1;
    if (vref2 > 0) sector += 2;
    if (vref3 > 0) sector += 4;
    
    return sector;
}
```

### 4.6 PI控制器

```c
typedef struct {
    float kp;
    float ki;
    float integral;
    float output;
    float limit;
} PI_Controller;

float pi_update(PI_Controller *pi, float error, float dt) {
    pi->integral += error * dt;
    
    // 积分限幅
    if (pi->integral > pi->limit) pi->integral = pi->limit;
    if (pi->integral < -pi->limit) pi->integral = -pi->limit;
    
    pi->output = pi->kp * error + pi->ki * pi->integral;
    
    // 输出限幅
    if (pi->output > pi->limit) pi->output = pi->limit;
    if (pi->output < -pi->limit) pi->output = -pi->limit;
    
    return pi->output;
}
```

---

### 4.7 FOC完整实现

```c
void foc_control(float target_torque) {
    // 1. 读取编码器位置
    float theta = get_electrical_angle();
    
    // 2. 采样相电流
    float ia, ib;
    read_phase_current(&ia, &ib);
    
    // 3. Clarke变换
    float ialpha, ibeta;
    clarke_transform(ia, ib, &ialpha, &ibeta);
    
    // 4. Park变换
    float id, iq;
    park_transform(ialpha, ibeta, theta, &id, &iq);
    
    // 5. PI控制器
    float vd = pi_update(&pi_d, 0 - id, dt);      // id目标为0
    float vq = pi_update(&pi_q, target_torque - iq, dt);
    
    // 6. 反Park变换
    float valpha, vbeta;
    inverse_park_transform(vd, vq, theta, &valpha, &vbeta);
    
    // 7. SVPWM
    int sector = get_sector(valpha, vbeta);
    svpwm_generate(sector, valpha, vbeta);
}
```

## 五、速度控制

### 5.1 速度环

```c
typedef struct {
    float kp;
    float ki;
    float integral;
    float output;
    float limit;
} Speed_Controller;

float speed_update(Speed_Controller *sc, float target_speed, 
                   float actual_speed, float dt) {
    float error = target_speed - actual_speed;
    return pi_update(sc, error, dt);
}
```

---

### 5.2 位置环

```c
typedef struct {
    float kp;
    float kd;
    float last_error;
    float output;
    float limit;
} Position_Controller;

float position_update(Position_Controller *pc, float target_pos, 
                      float actual_pos, float dt) {
    float error = target_pos - actual_pos;
    float derivative = (error - pc->last_error) / dt;
    pc->last_error = error;
    
    pc->output = pc->kp * error + pc->kd * derivative;
    
    if (pc->output > pc->limit) pc->output = pc->limit;
    if (pc->output < -pc->limit) pc->output = -pc->limit;
    
    return pc->output;
}
```


---

### 6.2 滑模观测器

```c
typedef struct {
    float alpha;
    float beta;
    float k;
} SMO;

void smo_update(SMO *smo, float ialpha, float ibeta, 
                float valpha, float vbeta, float dt) {
    // 估算电流
    float ialpha_hat = smo->alpha;
    float ibeta_hat = smo->beta;
    
    // 电流误差
    float err_alpha = ialpha - ialpha_hat;
    float err_beta = ibeta - ibeta_hat;
    
    // 滑模控制
    float z_alpha = smo->k * sgn(err_alpha);
    float z_beta = smo->k * sgn(err_beta);
    
    // 更新观测器
    smo->alpha += (valpha - R * ialpha_hat - z_alpha) * dt / L;
    smo->beta += (vbeta - R * ibeta_hat - z_beta) * dt / L;
}
```

## 七、保护功能

### 7.1 过流保护

```c
#define OVERCURRENT_LIMIT 10.0f  // 安培

int check_overcurrent(float ia, float ib, float ic) {
    if (fabsf(ia) > OVERCURRENT_LIMIT || 
        fabsf(ib) > OVERCURRENT_LIMIT || 
        fabsf(ic) > OVERCURRENT_LIMIT) {
        disable_pwm_output();
        return 1;  // 过流
    }
    return 0;
}
```

---

### 7.2 过压/欠压保护

```c
#define OVERVOLTAGE_LIMIT 48.0f
#define UNDERVOLTAGE_LIMIT 12.0f

int check_voltage(float vbus) {
    if (vbus > OVERVOLTAGE_LIMIT) {
        disable_pwm_output();
        return 1;  // 过压
    }
    if (vbus < UNDERVOLTAGE_LIMIT) {
        disable_pwm_output();
        return 2;  // 欠压
    }
    return 0;
}
```

---

### 7.3 过温保护

```c
#define OVERTEMP_LIMIT 80.0f  // 摄氏度

int check_temperature(float temp) {
    if (temp > OVERTEMP_LIMIT) {
        reduce_power();
        return 1;  // 过温
    }
    return 0;
}
```
