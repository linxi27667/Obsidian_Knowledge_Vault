## 一、电机类型总览

### 1.1 电机分类

```
电机
├── 直流电机
│   ├── 有刷直流电机 (Brushed DC Motor)
│   └── 无刷直流电机 (BLDC)
├── 交流电机
│   ├── 永磁同步电机 (PMSM)
│   ├── 感应电机 (Induction Motor)
│   └── 开关磁阻电机 (SRM)
└── 步进电机 (Stepper Motor)
```

### 1.2 各类电机对比

| 特性 | 直流有刷 | BLDC | PMSM | 步进电机 | SRM |
|------|---------|------|------|---------|-----|
| **效率** | 75-80% | 85-90% | 90-95% | 70-80% | 80-85% |
| **寿命** | 短（电刷磨损） | 长 | 长 | 长 | 长 |
| **控制复杂度** | 简单 | 中等 | 复杂 | 简单 | 复杂 |
| **成本** | 低 | 中 | 中高 | 低 | 中 |
| **转矩脉动** | 小 | 中 | 小 | 大 | 大 |
| **功率密度** | 低 | 高 | 高 | 中 | 高 |
| **典型应用** | 玩具、家电 | 无人机、硬盘 | 电动汽车、机器人 | 3D打印机、CNC | 家电、工业 |

### 1.3 开关磁阻电机 SRM

- **结构**：转子无永磁体、无绕组，定子有集中绕组
- **原理**：利用磁阻最小原理，转子趋向与定子磁场对齐
- **优点**：结构坚固、成本低、耐高温、容错性好
- **缺点**：转矩脉动大、振动噪声大、控制复杂
- **应用**：洗衣机、风机、电动汽车辅助系统

## 二、直流有刷电机

### 2.1 工作原理

直流有刷电机通过换向器（整流子）和电刷实现电流方向的自动切换，使转子持续旋转。

**基本结构：**
- **定子**：永磁体或励磁绕组，产生主磁场
- **转子（电枢）**：绕组嵌在铁芯槽中
- **换向器**：铜片组成的圆环，与电刷接触
- **电刷**：碳刷或金属刷，连接外部电源与转子绕组

**反电动势（Back-EMF）：**

$$E = K_e \cdot \omega$$

其中：
- $E$：反电动势（V）
- $K_e$：反电动势常数（V/(rad/s)）
- $\omega$：角速度（rad/s）

**电压方程：**

$$V = E + I \cdot R + L \frac{dI}{dt}$$

简化稳态：$V = K_e \omega + I R$

**转矩方程：**

$$T = K_t \cdot I$$

其中 $K_t$ 为转矩常数（N·m/A），在 SI 单位制中 $K_t = K_e$。

### 2.2 PWM 调速

**基本原理：** 通过改变占空比控制加在电机上的平均电压。

$$V_{avg} = V_{supply} \times D$$

其中 $D$ 为占空比（0~1）。

**PWM 频率选择：**
- **过低（< 1kHz）**：电机抖动明显，噪音大
- **合适（10-25kHz）**：运行平滑，高于人耳听觉范围
- **过高（> 100kHz）**：MOS管开关损耗增加

**典型 PWM 频率：** 20kHz（静音运行）

```
        ┌─────┐         ┌─────┐
        │     │         │     │
  ──────┘     └─────────┘     └──────
        |← D →|
        |←──── T ────→|
  
  V_avg = V_supply × (D / T)
```

### 2.3 H 桥驱动

**H 桥电路拓扑：**

```
         VCC
          │
    ┌─────┼─────┐
    │     │     │
   Q1    Motor   Q3
    │     │     │
    ├─────┼─────┤
    │     │     │
   Q2     │     Q4
    │     │     │
    └─────┼─────┘
          │
         GND
```

**工作模式：**

| 模式 | Q1 | Q2 | Q3 | Q4 | 电机状态 |
|------|----|----|----|----|---------|
| 正转 | ON | OFF | OFF | ON | 正向旋转 |
| 反转 | OFF | ON | ON | OFF | 反向旋转 |
| 制动 | OFF | ON | OFF | ON | 短路制动 |
| 滑行 | OFF | OFF | OFF | OFF | 自由转动 |

**注意事项：**
- **死区时间**：同一桥臂上下管切换时必须插入死区（通常 0.5-2us），防止直通短路
- **自举电容**：上管使用 N-MOS 时需要自举电路提供栅极驱动电压
- **续流二极管**：MOS管体二极管或外接快恢复二极管，为电感电流提供续流通路

### 2.4 制动方式

**1. 能耗制动（动态制动）：**
- 将电机两端短接（所有下管导通或所有上管导通）
- 电机动能通过绕组电阻转化为热能
- 制动力矩随转速降低而减小

**2. 再生制动：**
- 电机作为发电机运行，电流回馈到电源
- 需要电源能够吸收能量（电池或大电容）
- 制动能量可回收，效率高

**3. 反接制动：**
- 反向施加电压，产生反向转矩
- 制动力矩大，但电流也大
- 需要限流保护

## 三、无刷电机 BLDC

### 3.1 基本结构

BLDC 电机将永磁体放在转子上，绕组放在定子上，通过电子换向取代机械换向器。

**结构组成：**
- **转子**：永磁体（表贴式或内嵌式）
- **定子**：三相绕组（星型或三角型连接）
- **位置传感器**：霍尔传感器或编码器（可选）

### 3.2 六步换相（方波驱动）

**换相逻辑（霍尔传感器组合）：**

| 霍尔状态 (H1 H2 H3) | 导通相 | 电流方向 |
|---------------------|--------|---------|
| 1 0 1 | A→B | A+ B- |
| 1 0 0 | A→C | A+ C- |
| 1 1 0 | B→C | B+ C- |
| 0 1 0 | B→A | B+ A- |
| 0 1 1 | C→A | C+ A- |
| 0 0 1 | C→B | C+ B- |

**换相时序图：**

```
电气角度:  0°    60°   120°  180°  240°  300°  360°
           |     |     |     |     |     |     |
Hall A:    ───┐     ┌───┐     ┌───┐     ┌───
Hall B:    ─┐   ┌───┐     ┌───┐     ┌───┐
Hall C:    ┌───┐     ┌───┐     ┌───┐     ┌───
           |     |     |     |     |     |     |
A相:       ████░░░░░░░░░░░░████░░░░░░░░░░░░
B相:       ░░░░░░░░████░░░░░░░░░░░░████░░░░
C相:       ░░░░░░░░░░░░░░░░████░░░░░░░░████
```

**换相过程分析：**
- 每 60° 电角度进行一次换相
- 任意时刻只有两相导通，一相悬空
- 通过检测悬空相反电动势获取转子位置信息

### 3.3 霍尔传感器检测

**安装方式：**
- 3 个霍尔传感器间隔 120° 电角度安装
- 通常安装在定子上，靠近转子永磁体
- 输出高低电平信号，组合成 6 种有效状态

**代码实现（换相逻辑）：**

```c
// 霍尔传感器换相表 (根据实际电机接线调整)
// hall_state = (H1 << 2) | (H2 << 1) | H3
const uint8_t commutation_table[8] = {
    0,          // 000: 无效
    0b010001,   // 001: C-B (AH, BL)
    0b010100,   // 010: B-A (BH, AL)
    0b011000,   // 011: B-C (BH, CL)  -- 修正
    0b000110,   // 100: A-C (AH, CL)
    0b001001,   // 101: A-B (AH, BL)
    0b001100,   // 110: C-A (CH, AL)
    0           // 111: 无效
};

void BLDC_Commutate(uint8_t hall) {
    uint8_t phase = commutation_table[hall];
    // 控制6路PWM输出
    SetPhaseA((phase >> 0) & 1, (phase >> 1) & 1);
    SetPhaseB((phase >> 2) & 1, (phase >> 3) & 1);
    SetPhaseC((phase >> 4) & 1, (phase >> 5) & 1);
}
```

### 3.4 无感反电动势检测

**原理：** 在悬空相检测反电动势过零点，延迟 30° 电角度后换相。

**过零检测电路：**

```
  Motor Phase ──┬── R1 ──┬── Comparator (+)
                │        │
                R2       C1
                │        │
               GND      GND
                         
  Virtual Neutral ────── Comparator (-)
```

**实现要点：**
- 利用电阻分压构造虚拟中性点
- 通过比较器检测悬空相电压与中性点电压
- 过零点发生在反电动势等于零的时刻
- 从过零点延迟 30° 为最佳换相时刻

**启动策略（开环启动）：**
1. **定位阶段**：强制给两相通电，使转子转到已知位置
2. **加速阶段**：逐步增加换相频率，产生旋转磁场拖动转子
3. **切换阶段**：转速足够高后切换到反电动势检测闭环控制

```c
// 开环启动示例
void BLDC_Startup(void) {
    // 1. 定位：强制换相，保持200ms
    forced_commutation(0);
    HAL_Delay(200);

    // 2. 加速：逐步提高换相频率
    uint32_t delay_ms = 50;  // 起始换相间隔
    for (int i = 0; i < 50; i++) {
        forced_commutation(i % 6);
        HAL_Delay(delay_ms);
        if (delay_ms > 5) delay_ms -= 1;  // 逐渐加速
    }

    // 3. 切换到反电动势检测
    enable_bemf_detection();
}
```

## 四、永磁同步电机 PMSM

### 4.1 PMSM 与 BLDC 的区别

| 特性 | BLDC | PMSM |
|------|------|------|
| **反电动势波形** | 梯形波 | 正弦波 |
| **驱动波形** | 方波（六步换相） | 正弦波（FOC） |
| **转矩脉动** | 较大 | 很小 |
| **控制算法** | 简单 | 复杂 |
| **效率** | 较高 | 最高 |
| **高速性能** | 好 | 更好 |
| **NVH 性能** | 一般 | 优秀 |

### 4.2 FOC 磁场定向控制

**FOC 核心思想：** 将三相交流电流分解为产生磁场的分量（$i_d$）和产生转矩的分量（$i_q$），分别独立控制。

**FOC 控制框图：**

```
  速度给定 ──→ [速度PI] ──→ iq_ref ──→ [电流PI] ──→ Vq ──→ [反Park] ──→ [SVPWM] ──→ [逆变器] ──→ 电机
                      ↑                                    ↑
              id_ref=0 ──→ [电流PI] ──→ Vd ─────────────┘
                      ↑
                  iq_fb ↑  id_fb
                      │  │
                  [反Clark/Park]
                      ↑
                  [电流采样] Ia, Ib
                      ↑
                  [编码器/观测器] θe
```

### 4.3 Clark 变换（abc → αβ）

将三相静止坐标系变换到两相静止坐标系。

**等幅值 Clark 变换：**

$$\begin{bmatrix} i_\alpha \\ i_\beta \end{bmatrix} = \frac{2}{3} \begin{bmatrix} 1 & -\frac{1}{2} & -\frac{1}{2} \\ 0 & \frac{\sqrt{3}}{2} & -\frac{\sqrt{3}}{2} \end{bmatrix} \begin{bmatrix} i_a \\ i_b \\ i_c \end{bmatrix}$$

**简化计算（利用 $i_a + i_b + i_c = 0$）：**

$$i_\alpha = i_a$$
$$i_\beta = \frac{i_a + 2i_b}{\sqrt{3}}$$

**代码实现：**

```c
typedef struct {
    float alpha;
    float beta;
} AlphaBeta_t;

AlphaBeta_t Clark_Transform(float ia, float ib) {
    AlphaBeta_t ab;
    ab.alpha = ia;
    ab.beta = (ia + 2.0f * ib) * 0.57735026919f;  // 1/sqrt(3)
    return ab;
}
```

### 4.4 Park 变换（αβ → dq）

将两相静止坐标系变换到两相旋转坐标系（跟随转子磁场）。

**Park 变换：**

$$\begin{bmatrix} i_d \\ i_q \end{bmatrix} = \begin{bmatrix} \cos\theta_e & \sin\theta_e \\ -\sin\theta_e & \cos\theta_e \end{bmatrix} \begin{bmatrix} i_\alpha \\ i_\beta \end{bmatrix}$$

**反 Park 变换：**

$$\begin{bmatrix} v_\alpha \\ v_\beta \end{bmatrix} = \begin{bmatrix} \cos\theta_e & -\sin\theta_e \\ \sin\theta_e & \cos\theta_e \end{bmatrix} \begin{bmatrix} v_d \\ v_q \end{bmatrix}$$

**代码实现：**

```c
typedef struct {
    float d;
    float q;
} DQ_t;

DQ_t Park_Transform(float alpha, float beta, float theta_e) {
    DQ_t dq;
    float cos_theta = cosf(theta_e);
    float sin_theta = sinf(theta_e);
    dq.d =  alpha * cos_theta + beta * sin_theta;
    dq.q = -alpha * sin_theta + beta * cos_theta;
    return dq;
}

AlphaBeta_t InversePark_Transform(float vd, float vq, float theta_e) {
    AlphaBeta_t ab;
    float cos_theta = cosf(theta_e);
    float sin_theta = sinf(theta_e);
    ab.alpha = vd * cos_theta - vq * sin_theta;
    ab.beta  = vd * sin_theta + vq * cos_theta;
    return ab;
}
```

### 4.5 SVPWM 空间矢量调制

**基本原理：** 通过 6 个基本电压矢量和零矢量的组合，在一个 PWM 周期内合成任意方向和幅值的电压矢量。

**基本电压矢量：**

```
              V3 (010)
               /\
              /  \
             /    \
    V4 (011)/______\V2 (001)
            |\    /|
            | \  / |
            |  \/  |
            |  /\  |
            | /  \ |
            |/____\|
    V5 (101)        V1 (100)
             \    /
              \  /
               \/
              V6 (110)
              
    中心: V0 (000), V7 (111) - 零矢量
```

**扇区判断：**

```c
// 根据 Valpha, Vbeta 判断扇区
int Get_Sector(float alpha, float beta) {
    float v1 = beta;
    float v2 = 0.866025f * alpha - 0.5f * beta;   // sqrt(3)/2 * alpha - beta/2
    float v3 = -0.866025f * alpha - 0.5f * beta;  // -sqrt(3)/2 * alpha - beta/2

    int sector = 0;
    if (v1 > 0) sector += 1;
    if (v2 > 0) sector += 2;
    if (v3 > 0) sector += 4;

    // 映射到扇区 1-6
    switch (sector) {
        case 3: return 1;
        case 1: return 2;
        case 5: return 3;
        case 4: return 4;
        case 6: return 5;
        case 2: return 6;
        default: return 0;
    }
}
```

**占空比计算（以扇区 1 为例）：**

```c
void SVPWM_CalcDuty(int sector, float alpha, float beta, float vbus) {
    float T = 1.0f;  // 归一化 PWM 周期
    float sqrt3_T = 1.7320508f * T;
    float v_scale = T / vbus;

    float t1, t2, t0;

    switch (sector) {
        case 1:
            t1 = v_scale * (1.5f * alpha - 0.866025f * beta);
            t2 = v_scale * (1.7320508f * beta);
            break;
        case 2:
            t1 = v_scale * (1.5f * alpha + 0.866025f * beta);
            t2 = v_scale * (-1.5f * alpha + 0.866025f * beta);
            break;
        case 3:
            t1 = v_scale * (1.7320508f * beta);
            t2 = v_scale * (-1.5f * alpha - 0.866025f * beta);
            break;
        case 4:
            t1 = v_scale * (-1.5f * alpha + 0.866025f * beta);
            t2 = v_scale * (-1.7320508f * beta);
            break;
        case 5:
            t1 = v_scale * (-1.5f * alpha - 0.866025f * beta);
            t2 = v_scale * (1.5f * alpha - 0.866025f * beta);
            break;
        case 6:
            t1 = v_scale * (-1.7320508f * beta);
            t2 = v_scale * (1.5f * alpha + 0.866025f * beta);
            break;
    }

    // 过调制处理
    if (t1 + t2 > T) {
        float ratio = T / (t1 + t2);
        t1 *= ratio;
        t2 *= ratio;
    }
    t0 = T - t1 - t2;

    // 计算三相占空比（七段式）
    float ta = t0 * 0.5f;
    float tb = ta + t1 * 0.5f;
    float tc = tb + t2 * 0.5f;

    // 根据扇区分配到 PWM 通道
    Set_PWM_Duty(sector, ta, tb, tc);
}
```

**七段式 SVPWM：**

```
  中心对称七段式 PWM 波形（扇区1为例）:
  
  PWM1: ──┐  ┌──────────┐  ┌──
          └──┘          └──┘
          T0/4  T1/2+T2/2  T0/4
  
  PWM2: ──────┐  ┌──────────────
              └──┘
  
  PWM3: ──────────────────┐  ┌──
                          └──┘
  
  合成矢量: V0 → V4 → V6 → V7 → V6 → V4 → V0
```

### 4.6 FOC 完整代码框架

```c
// FOC 控制结构体
typedef struct {
    // 电流环
    PI_Controller_t pi_id;
    PI_Controller_t pi_iq;

    // 输入
    float id_ref;      // d轴电流给定（通常为0）
    float iq_ref;      // q轴电流给定（来自速度环输出）
    float theta_e;     // 电角度
    float vbus;        // 母线电压

    // 中间变量
    AlphaBeta_t i_ab;  // αβ轴电流
    DQ_t i_dq;         // dq轴电流
    DQ_t v_dq;         // dq轴电压
    AlphaBeta_t v_ab;  // αβ轴电压
} FOC_Controller_t;

void FOC_Update(FOC_Controller_t *foc, float ia, float ib, float theta_e) {
    foc->theta_e = theta_e;

    // 1. Clark 变换
    foc->i_ab = Clark_Transform(ia, ib);

    // 2. Park 变换
    foc->i_dq = Park_Transform(foc->i_ab.alpha, foc->i_ab.beta, theta_e);

    // 3. 电流环 PI 控制
    foc->v_dq.d = PI_Update(&foc->pi_id, foc->id_ref - foc->i_dq.d);
    foc->v_dq.q = PI_Update(&foc->pi_iq, foc->iq_ref - foc->i_dq.q);

    // 4. 反 Park 变换
    foc->v_ab = InversePark_Transform(foc->v_dq.d, foc->v_dq.q, theta_e);

    // 5. SVPWM
    int sector = Get_Sector(foc->v_ab.alpha, foc->v_ab.beta);
    SVPWM_CalcDuty(sector, foc->v_ab.alpha, foc->v_ab.beta, foc->vbus);
}
```

## 五、步进电机

### 5.1 基本原理

步进电机将电脉冲信号转换为角位移，每收到一个脉冲转过一个固定角度（步距角）。

**类型：**
- **永磁式（PM）**：步距角大（7.5°-90°），转矩小
- **反应式（VR）**：步距角小（0.9°-5°），无永磁体
- **混合式（HB）**：结合 PM 和 VR 优点，步距角小（0.9°-1.8°），转矩大

**步距角计算：**

$$\theta_{step} = \frac{360°}{N_r \times m}$$

其中：
- $N_r$：转子齿数
- $m$：相数

常见 1.8° 步进电机 = 360° / (50齿 × 4拍) = 1.8°

### 5.2 全步/半步/微步驱动

**全步驱动（Full Step）：**
```
  A相: ──┐     ┌─────┐     ┌──
         └─────┘     └─────┘
  B相: ──────┐     ┌─────┐
             └─────┘     └──
  
  步序: AB → A'B → A'B' → AB' → AB
  步距角: 1.8° (典型值)
```

**半步驱动（Half Step）：**
```
  A相: ──┐   ┌─┐   ┌───┐   ┌─┐   ┌──
         └───┘ └───┘   └───┘ └───┘
  B相: ────┐   ┌───┐   ┌───┐   ┌──
           └───┘   └───┘   └───┘
  
  步序: A → AB → B → A'B → A' → A'B' → B' → AB'
  步距角: 0.9°
  优点：分辨率提高一倍，运行更平滑
```

**微步驱动（Microstepping）：**

通过给两相施加不同幅值的正弦/余弦电流，实现更精细的角度控制。

$$I_A = I_{max} \cdot \sin(\theta)$$
$$I_B = I_{max} \cdot \cos(\theta)$$

| 细分数 | 步距角 (1.8°电机) | 每圈脉冲数 |
|--------|-------------------|-----------|
| 1 (全步) | 1.8° | 200 |
| 2 (半步) | 0.9° | 400 |
| 4 | 0.45° | 800 |
| 8 | 0.225° | 1600 |
| 16 | 0.1125° | 3200 |
| 32 | 0.05625° | 6400 |
| 256 | 0.00703° | 51200 |

### 5.3 细分控制实现

```c
// 微步正弦表 (256点细分)
const uint16_t sine_table[256] = {
    0, 804, 1608, 2411, 3212, 4011, 4808, 5602,
    // ... 完整正弦表
    4808, 4011, 3212, 2411, 1608, 804, 0
};

typedef struct {
    uint16_t step_index;    // 当前微步索引
    uint16_t micro_steps;   // 每圈总微步数
    uint8_t direction;      // 方向
} Stepper_t;

void Stepper_SetMicrostep(Stepper_t *motor, int32_t position) {
    uint16_t index = position % motor->micro_steps;
    if (index < 0) index += motor->micro_steps;

    uint16_t phase_a = sine_table[index & 0xFF];
    uint16_t phase_b = sine_table[(index + 64) & 0xFF];  // 90°偏移

    Set_DAC_Channel_A(phase_a);
    Set_DAC_Channel_B(phase_b);
}
```

### 5.4 共振问题

**低频共振：** 步进电机在特定频率下（通常 100-300 Hz）会发生共振，导致失步。

**原因：** 转子在相邻步之间的振荡频率与步进频率耦合。

**解决方案：**
1. **避开共振区**：快速通过共振频率范围
2. **微步驱动**：减小每步的步距角，降低振荡幅度
3. **加减速曲线**：使用 S 曲线或梯形加减速
4. **增加阻尼**：机械阻尼器或电子阻尼（反电动势注入）
5. **闭环控制**：使用编码器反馈

### 5.5 闭环步进

**传统步进问题：**
- 开环运行，无法检测失步
- 为保证不失步，需要留安全余量，效率低
- 高速时转矩下降严重

**闭环步进方案：**
- 增加编码器检测实际位置
- 检测到失步时自动补偿
- 可根据负载动态调整电流
- 性能接近伺服系统，成本低得多

```c
// 闭环步进控制
typedef struct {
    int32_t target_pos;     // 目标位置
    int32_t actual_pos;     // 实际位置（编码器反馈）
    int32_t error;          // 位置误差
    float current_scale;    // 电流比例
} ClosedLoopStepper_t;

void ClosedLoopStepper_Update(ClosedLoopStepper_t *motor) {
    motor->actual_pos = Encoder_Read();
    motor->error = motor->target_pos - motor->actual_pos;

    // 位置误差过大时增大电流，误差小时减小电流
    if (abs(motor->error) > 10) {
        motor->current_scale = 1.0f;  // 全电流
    } else if (abs(motor->error) > 2) {
        motor->current_scale = 0.7f;  // 降低电流
    } else {
        motor->current_scale = 0.3f;  // 保持电流
    }

    // 失步检测
    if (abs(motor->error) > 50) {
        // 严重失步，需要停止并报警
        Stepper_Error_Handler();
    }
}
```

## 六、PID 控制在电机中的应用

### 6.1 电机控制三环架构

```
  位置给定 ──→ [位置环 PID] ──→ 速度给定 ──→ [速度环 PI] ──→ 电流给定 ──→ [电流环 PI] ──→ PWM输出
      ↑              ↑               ↑              ↑              ↑              ↑
      │          位置反馈          │          速度反馈          │          电流反馈
      │              │               │              │              │              │
      └──────────────┘               └──────────────┘              └──────────────┘
  
  带宽:   低 ───────────────────────────────────────────────────────────────→ 高
  周期:   长 ───────────────────────────────────────────────────────────────→ 短
```

**三环特点：**

| 环路 | 典型带宽 | 控制周期 | 作用 |
|------|---------|---------|------|
| 位置环 | 10-50 Hz | 1-10 ms | 保证位置精度 |
| 速度环 | 100-500 Hz | 0.1-1 ms | 保证速度平稳 |
| 电流环 | 1-10 kHz | 50-100 us | 保证快速响应，限制电流 |

### 6.2 PID 控制器实现

**位置式 PID：**

$$u(t) = K_p e(t) + K_i \int_0^t e(\tau) d\tau + K_d \frac{de(t)}{dt}$$

```c
typedef struct {
    float Kp, Ki, Kd;
    float integral;
    float prev_error;
    float output_min, output_max;
    float integral_max;  // 积分限幅
} PID_Controller_t;

float PID_Update(PID_Controller_t *pid, float error, float dt) {
    // 比例项
    float P = pid->Kp * error;

    // 积分项（带限幅）
    pid->integral += error * dt;
    if (pid->integral > pid->integral_max) pid->integral = pid->integral_max;
    if (pid->integral < -pid->integral_max) pid->integral = -pid->integral_max;
    float I = pid->Ki * pid->integral;

    // 微分项
    float derivative = (error - pid->prev_error) / dt;
    float D = pid->Kd * derivative;
    pid->prev_error = error;

    // 输出限幅
    float output = P + I + D;
    if (output > pid->output_max) output = pid->output_max;
    if (output < pid->output_min) output = pid->output_min;

    return output;
}
```

**增量式 PID：**

$$\Delta u(k) = K_p [e(k) - e(k-1)] + K_i e(k) + K_d [e(k) - 2e(k-1) + e(k-2)]$$

```c
typedef struct {
    float Kp, Ki, Kd;
    float prev_error;
    float prev2_error;
    float output;
    float output_min, output_max;
} PID_Incremental_t;

float PID_Incremental_Update(PID_Incremental_t *pid, float error) {
    float delta = pid->Kp * (error - pid->prev_error)
                + pid->Ki * error
                + pid->Kd * (error - 2.0f * pid->prev_error + pid->prev2_error);

    pid->prev2_error = pid->prev_error;
    pid->prev_error = error;
    pid->output += delta;

    if (pid->output > pid->output_max) pid->output = pid->output_max;
    if (pid->output < pid->output_min) pid->output = pid->output_min;

    return pid->output;
}
```

### 6.3 参数整定方法

**1. Ziegler-Nichols 临界振荡法：**
1. 先将 $K_i$ 和 $K_d$ 设为 0
2. 逐渐增大 $K_p$ 直到系统出现等幅振荡
3. 记录临界增益 $K_u$ 和振荡周期 $T_u$
4. 按下表计算 PID 参数：

| 控制器 | $K_p$ | $K_i$ | $K_d$ |
|--------|-------|-------|-------|
| P | $0.5K_u$ | - | - |
| PI | $0.45K_u$ | $0.54K_u/T_u$ | - |
| PID | $0.6K_u$ | $1.2K_u/T_u$ | $0.075K_u T_u$ |

**2. 电流环调试经验：**
- 电流环带宽通常设为 PWM 频率的 1/10
- 先调 $K_p$，使阶跃响应无超调
- 再加 $K_i$ 消除稳态误差
- 电流环通常不需要 $K_d$

**3. 速度环调试经验：**
- 速度环带宽设为电流环的 1/5~1/10
- 从较小的 $K_p$ 开始，逐步增大
- 加入适当的 $K_i$ 消除静差
- 过大的 $K_i$ 会导致速度超调和振荡

**4. 抗积分饱和（Anti-Windup）：**

```c
// 条件积分法
if (output < output_max && output > output_min) {
    integral += error * dt;
}

// 回算法
if (output >= output_max && error > 0) {
    integral -= (output - output_max) / Ki;
} else if (output <= output_min && error < 0) {
    integral -= (output - output_min) / Ki;
}
```

### 6.4 电流环控制细节

**FOC 中的 dq 轴电流环：**

```c
// d 轴：控制磁场，通常 id_ref = 0（MTPA 策略）
// q 轴：控制转矩，iq_ref 来自速度环输出

// 电流环 PI 控制（带前馈解耦）
void Current_Loop_Update(FOC_Controller_t *foc) {
    // d 轴电流环
    float id_error = foc->id_ref - foc->i_dq.d;
    float vd_pi = PI_Update(&foc->pi_id, id_error);

    // q 轴电流环
    float iq_error = foc->iq_ref - foc->i_dq.q;
    float vq_pi = PI_Update(&foc->pi_iq, iq_error);

    // 前馈解耦（消除 dq 轴之间的耦合）
    foc->v_dq.d = vd_pi - foc->i_dq.q * foc->omega_e * foc->Lq;
    foc->v_dq.q = vq_pi + foc->i_dq.d * foc->omega_e * foc->Ld
                 + foc->omega_e * foc->psi_f;  // 反电动势前馈

    // 电压限幅（圆限制）
    float v_max = foc->vbus * 0.57735f;  // vbus / sqrt(3)
    float v_mag = sqrtf(foc->v_dq.d * foc->v_dq.d + foc->v_dq.q * foc->v_dq.q);
    if (v_mag > v_max) {
        foc->v_dq.d *= v_max / v_mag;
        foc->v_dq.q *= v_max / v_mag;
    }
}
```

## 七、电机驱动硬件设计

### 7.1 MOS 管选型

**关键参数：**

| 参数 | 符号 | 说明 |
|------|------|------|
| 漏源电压 | $V_{DS}$ | 必须大于母线电压，留 2 倍余量 |
| 漏极电流 | $I_D$ | 必须大于最大负载电流 |
| 导通电阻 | $R_{DS(on)}$ | 越小越好，降低导通损耗 |
| 栅极电荷 | $Q_g$ | 越小越好，降低开关损耗 |
| 体二极管恢复 | $t_{rr}$ | 越小越好，减小反向恢复损耗 |

**N-MOS vs P-MOS：**
- **N-MOS**：$R_{DS(on)}$ 小、成本低、开关速度快，上管驱动复杂（需要自举或电荷泵）
- **P-MOS**：驱动简单，但 $R_{DS(on)}$ 大、成本高、电流能力弱

**选型示例：**

| 应用场景 | 推荐型号 | $V_{DS}$ | $I_D$ | $R_{DS(on)}$ |
|---------|---------|---------|-------|-------------|
| 小型电机 (<5A) | IRFZ44N | 55V | 49A | 17.5mΩ |
| 中型电机 (<30A) | IRF3205 | 55V | 110A | 8mΩ |
| 大功率 (>30A) | IPB017N06N | 60V | 100A | 1.7mΩ |
| 高压 (>100V) | IRFP4110 | 100V | 180A | 3.7mΩ |
| GaN (高频) | EPC2034 | 200V | 48A | 3.2mΩ |

**损耗计算：**

$$P_{conduction} = I_{rms}^2 \times R_{DS(on)}$$

$$P_{switching} = \frac{1}{2} V_{DS} I_D (t_{on} + t_{off}) f_{sw}$$

$$P_{total} = P_{conduction} + P_{switching}$$

### 7.2 栅极驱动

**驱动要求：**
- 提供足够的驱动电流，快速充放电栅极电容
- 提供合适的栅极电压（N-MOS 通常 10-15V）
- 上管驱动需要自举或隔离电源
- 提供死区时间控制

**自举驱动原理：**

```
         VCC (12V)
          │
          ├── 自举二极管 (D_boot)
          │
          ├── 自举电容 (C_boot)
          │
   ┌──────┴──────┐
   │   驱动IC    │
   │             │──→ HO (上管驱动输出)
   │             │──→ LO (下管驱动输出)
   │             │──→ VS (上管源极)
   └─────────────┘
```

**自举电容计算：**

$$C_{boot} = \frac{Q_g + I_{qbs} \times t_{on}}{\Delta V}$$

其中：
- $Q_g$：MOS 管栅极总电荷
- $I_{qbs}$：驱动 IC 静态电流
- $t_{on}$：上管最大导通时间
- $\Delta V$：允许的电压跌落（通常 < 0.5V）

**常用栅极驱动 IC：**

| 型号 | 通道 | 驱动电流 | 特点 |
|------|------|---------|------|
| IR2104 | 半桥 | 130/270mA | 自举，带死区 |
| IR2110 | 半桥 | 2A/2A | 高压自举，独立输入 |
| IR2184 | 半桥 | 1.4A/1.8A | 自举，互补输入 |
| UCC27211 | 半桥 | 4A/4A | TI 高电流驱动 |
| LM5109 | 半桥 | 1A/1A | 低成本方案 |
| Si8271 | 隔离半桥 | 4A/4A | 数字隔离驱动 |

### 7.3 电流采样

**采样方式：**

**1. 低侧电阻采样：**

```
         │
    ┌────┤
    │    │
   MOS   │
    │    │
    └──┬─┘
       │
      Rshunt (1-10 mΩ)
       │
      GND
```

- 成本低，电路简单
- 只能在下管导通时采样
- 需要与 PWM 同步采样

**2. 高侧电阻采样：**

```
    VCC
     │
    Rshunt
     │
    └──→ 运放 → ADC
     │
    MOS
     │
```

- 任何时候都能采样
- 需要高侧电流检测放大器
- 成本较高

**3. 霍尔电流传感器：**

- 非接触式，无损耗
- 带宽高，响应快
- 成本高，体积大
- 常用型号：ACS712（±5A/20A/30A）、MLX91217

**采样电路设计：**

```c
// 三电阻采样（下桥臂）

void ADC_Config(void) {

## 八、编码器

### 8.1 增量式编码器

**原理：** 通过光电码盘产生 A、B 两路正交脉冲信号，通过相位关系判断旋转方向。

**输出信号：**

```
  A相: ──┐  ┌──┐  ┌──┐  ┌──┐  ┌──
         └──┘  └──┘  └──┘  └──┘
  B相: ─┐  ┌──┐  ┌──┐  ┌──┐  ┌──
        └──┘  └──┘  └──┘  └──┘
  
  正转：A 超前 B 90°
  反转：B 超前 A 90°
```

**分辨率计算：**

$$分辨率 = \frac{360°}{线数 \times 倍频}$$

| 线数 | 倍频 | 每圈脉冲数 | 分辨率 |
|------|------|-----------|-------|
| 100 | 4x | 400 | 0.9° |
| 500 | 4x | 2000 | 0.18° |
| 1000 | 4x | 4000 | 0.09° |
| 2500 | 4x | 10000 | 0.036° |

### 8.2 绝对值编码器

**特点：** 每个位置对应唯一的编码值，断电后位置不丢失。

**输出接口：**
- **并行输出**：多根数据线，速度快，线多
- **SSI（同步串行）**：时钟 + 数据，2线
- **BiSS**：高速串行协议，兼容 SSI
- **SPI**：标准 SPI 接口
- **CAN/CANopen**：总线型，适合分布式系统

**分辨率表示：**
- 单圈：12-20 bit（4096 ~ 1048576 位置/圈）
- 多圈：单圈分辨率 + 圈数计数（通常 12-16 bit 圈数）

### 8.3 正交解码

    uint8_t a = HAL_GPIO_ReadPin(ENC_A_GPIO, ENC_A_PIN);
    uint8_t b = HAL_GPIO_ReadPin(ENC_B_GPIO, ENC_B_PIN);

    if (a == b) {
        encoder_count++;  // 正转
    } else {
        encoder_count--;  // 反转
    }
}
```

### 8.4 速度计算

**1. M/T 法（周期/脉冲联合测量）：**

$$\omega = \frac{N_{pulse}}{T_{measure}} \times \frac{60}{PPR} \quad (RPM)$$

```c
// 使用定时器捕获编码器脉冲周期
float Speed_Calculate_M_T(uint32_t pulse_count, uint32_t timer_count) {
    // pulse_count: 采样周期内的脉冲数
    // timer_count: 采样周期的定时器计数值
    if (timer_count == 0) return 0;

    float speed = (float)pulse_count / (float)timer_count;
    speed *= TIMER_FREQ * 60.0f / ENCODER_PPR;
    return speed;  // RPM
}
```

**2. M 法（脉冲计数法）：**
- 适合高速：在固定时间窗口内计数
- 低速时脉冲少，精度差

**3. T 法（周期测量法）：**
- 适合低速：测量相邻脉冲的时间间隔
- 高速时周期短，定时器精度受限

**4. 速度滤波（一阶低通滤波）：**

```c
typedef struct {
    float alpha;     // 滤波系数
    float filtered;  // 滤波后的值
} LowPassFilter_t;

float LowPassFilter_Update(LowPassFilter_t *filter, float input) {
    filter->filtered = filter->alpha * input + (1.0f - filter->alpha) * filter->filtered;
    return filter->filtered;
}

// 使用
LowPassFilter_t speed_filter = {0.1f, 0.0f};  // alpha 越小滤波越强
float speed_raw = Speed_Calculate(...);
float speed_filtered = LowPassFilter_Update(&speed_filter, speed_raw);
```

**Step 2：电流采样校准**

```c
// 电流采样偏移量校准
typedef struct {
    float offset_a;
    float offset_b;
    float offset_c;
} Current_Offset_t;

void Current_Calibrate(Current_Offset_t *offset, int samples) {
    float sum_a = 0, sum_b = 0, sum_c = 0;

    // 电机静止状态下采样
    for (int i = 0; i < samples; i++) {
        sum_a += ADC_Read(CHANNEL_IA);
        sum_b += ADC_Read(CHANNEL_IB);
        sum_c += ADC_Read(CHANNEL_IC);
        delay_us(100);
    }

    offset->offset_a = sum_a / samples;
    offset->offset_b = sum_b / samples;
    offset->offset_c = sum_c / samples;
}

// 校准后采样
float Read_Phase_Current(uint16_t adc_raw, float offset, float gain) {
    return (adc_raw - offset) * gain;  // gain = Vref / (4096 * Rshunt * Amp_Gain)
}
```

**Step 3：编码器校准与初始位置检测**

```c
// 编码器零位校准
void Encoder_Calibrate(void) {
    // 1. 给 d 轴通直流电流，使转子对齐到电角度 0°
    foc.id_ref = 0.5f;  // 小电流
    foc.iq_ref = 0.0f;
    foc.theta_e = 0.0f;  // 强制电角度为0
    FOC_Output(&foc);
    HAL_Delay(500);  // 等待转子稳定

    // 2. 读取编码器值，记录为零位偏移
    encoder_offset = Encoder_Read();
    encoder_aligned = true;

    // 3. 恢复正常控制
    foc.id_ref = 0.0f;
}

// 电角度计算
float Get_Electrical_Angle(void) {
    int32_t encoder_count = Encoder_Read() - encoder_offset;
    float mechanical_angle = (float)encoder_count / ENCODER_PPR * 360.0f;
    float electrical_angle = mechanical_angle * MOTOR_POLE_PAIRS;
    return electrical_angle * DEG_TO_RAD;
}
```

**Step 4：磁场定向控制主循环**

```c
// FOC 主循环（在 ADC 中断中执行，与 PWM 同步）
void FOC_MainLoop(void) {
    // 1. 电流采样
    float ia = Read_Phase_Current(ADC_Read(IA), offset_a, gain_a);
    float ib = Read_Phase_Current(ADC_Read(IB), offset_b, gain_b);

    // 2. 获取电角度
    float theta_e = Get_Electrical_Angle();

    // 3. 速度估算（可选，低通滤波）
    float speed = Speed_Estimate(theta_e);

    // 4. 速度环 PI（如果需要速度控制）
    if (control_mode == SPEED_MODE) {
        foc.iq_ref = PI_Update(&pi_speed, speed_ref - speed);
    }

    // 5. FOC 计算
    FOC_Update(&foc, ia, ib, theta_e);

    // 6. 更新 PWM 占空比
    Set_PWM_Duty(foc.pwm_a, foc.pwm_b, foc.pwm_c);
}
```

### 11.2 电流采样校准技巧

**三点校准法：**

```c
// 更精确的电流校准：考虑增益误差
typedef struct {
    float offset;    // 零点偏移
    float gain;      // 增益系数
} Current_Cal_t;

void Current_Calibrate_3Point(Current_Cal_t *cal, float known_current) {
    // 采样 +known_current 时的 ADC 值
    Apply_Current(+known_current);
    float adc_pos = ADC_Average(1000);

    // 采样 0 时的 ADC 值
    Apply_Current(0);
    float adc_zero = ADC_Average(1000);

    // 采样 -known_current 时的 ADC 值
    Apply_Current(-known_current);
    float adc_neg = ADC_Average(1000);

    // 计算偏移和增益
    cal->offset = adc_zero;
    cal->gain = known_current / ((adc_pos - adc_neg) * 0.5f);
}
```

**双电阻采样重构第三相电流：**

```c
// 当只有两相电流采样时，第三相可通过基尔霍夫定律计算
// ia + ib + ic = 0
// ic = -(ia + ib)

void Current_Reconstruct(float ia, float ib, float *ia_out, float *ib_out, float *ic_out) {
    *ia_out = ia;
    *ib_out = ib;
    *ic_out = -(ia + ib);
}
```

### 11.3 初始位置检测（无编码器启动）

**方法 1：脉冲注入法**

```c
// 向不同方向注入短脉冲，根据电流大小判断转子位置
float Detect_Initial_Position(void) {
    float currents[6];
    float angles[6] = {0, 60, 120, 180, 240, 300};

    for (int i = 0; i < 6; i++) {
        // 向第 i 个方向注入电流脉冲
        foc.id_ref = 0.3f;
        foc.iq_ref = 0.0f;
        foc.theta_e = angles[i] * DEG_TO_RAD;
        FOC_Output(&foc);
        HAL_Delay(10);

        // 记录电流响应
        currents[i] = fabsf(foc.i_dq.d);
    }

    // 找到电流最大的方向，即转子位置
    int max_idx = 0;
    for (int i = 1; i < 6; i++) {
        if (currents[i] > currents[max_idx]) max_idx = i;
    }

    return angles[max_idx] * DEG_TO_RAD;
}
```

**方法 2：高频注入法（适用于凸极电机 IPM）**

```c
// 高频注入法检测转子位置（利用凸极效应）
float HF_Injection_Detect(void) {
    float vhf = 0.5f;  // 高频电压幅值
    float fhf = 1000.0f;  // 注入频率 (Hz)
    float theta_scan = 0;
    float max_response = 0;
    float best_angle = 0;

    // 扫描不同角度
    for (int i = 0; i < 360; i++) {
        theta_scan = i * DEG_TO_RAD;

        // 注入高频信号
        float vd_hf = vhf * cosf(theta_scan);
        float vq_hf = vhf * sinf(theta_scan);

        // 测量电流响应幅值
        float response = Measure_HF_Response(vd_hf, vq_hf);

        if (response > max_response) {
            max_response = response;
            best_angle = theta_scan;
        }
    }

    return best_angle;
}
```

### 11.4 常见问题排查

**问题 1：电机不转**
- 检查电源电压是否正常
- 检查 MOS 管驱动信号（示波器观察）
- 检查电流采样是否正确
- 检查编码器信号是否正常

**问题 2：电机抖动**
- 检查电流环参数（$K_p$ 过大导致振荡）
- 检查编码器分辨率是否足够
- 检查 PWM 频率是否合适
- 检查死区时间设置

**问题 3：电流波形畸变**
- 校准电流采样偏移
- 检查 ADC 采样时机（是否与 PWM 同步）
- 检查母线电压纹波
- 调整 SVPWM 调制策略

**问题 4：高速时失步**
- 检查是否超过弱磁范围
- 检查母线电压是否足够
- 增加超前角补偿
- 检查反电动势是否超过 ADC 量程

**问题 5：温升过高**
- 检查 MOS 管选型（$R_{DS(on)}$ 是否过大）
- 检查开关损耗（PWM 频率是否过高）
- 检查散热设计
- 检查电流是否超过额定值
