# PCB设计基础

## 核心概念

- **PCB** - 印制电路板(Printed Circuit Board)
- **原理图** - 电路连接的逻辑表示
- **布局** - 元器件的放置
- **布线** - 连接线的走线

---

## 一、PCB设计流程

### 1.1 设计流程

```
需求分析 → 原理图设计 → 网络表生成 → PCB布局 → PCB布线 → DRC检查 → 输出生产文件
```

## 二、原理图设计

### 2.1 元件库

**常用元件：**

|------|------|------|
| 电阻 | 0402/0603/0805 | 贴片电阻 |

### 2.2 原理图绘制

**规则：**
- 信号流向清晰
- 电源符号规范
- 网络标号正确
- 注释完整

**网络标号：**
- 相同标号表示连接
- 总线符号
- 电源符号

---

### 2.3 电气规则检查(ERC)

**检查内容：**
- 引脚未连接
- 电源短路

- 网络冲突

## 三、PCB布局

### 3.1 布局原则

**基本原则：**
1. 按功能模块分区
2. 信号流向合理
3. 高速信号短且直
4. 发热元件远离敏感元件

**布局顺序：**
1. 核心芯片
2. 周边元件
3. 连接器
4. 测试点

---

### 3.2 元件放置

**放置规则：**
- 相关元件就近放置
- 去耦电容靠近电源引脚
- 晶振靠近芯片
- 连接器放在板边

---

### 3.3 层叠设计

**常用层叠：**
| 层数 | 说明 | 应用 |
|------|------|------|
| 2层 | 顶层+底层 | 简单电路 |
| 4层 | 信号+地+电源+信号 | 一般电路 |
| 6层 | 信号+地+信号+信号+电源+信号 | 高速电路 |

**4层板层叠：**
```
Top Layer    - 信号层
GND Plane    - 地平面
Power Plane  - 电源平面
Bottom Layer - 信号层
```

---

## 四、PCB布线

### 4.1 布线规则

**线宽规则：**
| 电流 | 线宽(1oz铜) |
|------|------------|
| 0.5A | 0.3mm |
| 1A | 0.5mm |
| 2A | 1.0mm |
| 3A | 1.5mm |

**间距规则：**
| 电压 | 最小间距 |
|------|----------|
| 5V | 0.15mm |
| 12V | 0.2mm |
| 24V | 0.3mm |
| 220V | 1.0mm |

---

### 4.2 走线技巧

**走线原则：**
- 避免直角，使用45°或圆弧
- 避免平行长线
- 关键信号包地处理
- 差分等长布线

**过孔使用：**
- 尽量少用过孔
- 过孔尺寸：0.3/0.5mm
- 过孔间距：≥0.5mm

---

### 4.3 电源布线

**电源布线原则：**
- 电源线加粗
- 电源平面完整
- 去耦电容就近
- 星形布线

**去耦电容：**
```
VCC ──┬── 0.1μF ──┬── 芯片VCC
      │           │
      └── 10μF ──┘
      │
     GND
```

---

### 4.4 高速信号布线

**高速信号规则：**
- 阻抗匹配
- 等长布线
- 包地处理
- 避免stub

**阻抗控制：**
| 信号类型 | 阻抗 |
|----------|------|
| 单端 | 50Ω |
| 差分 | 100Ω |
| USB | 90Ω |

---

## 五、接地设计

### 5.1 接地方式

**单点接地：**
- 低频电路
- 避免地环路

**多点接地：**
- 高频电路
- 减小地线阻抗

**混合接地：**
- 低频单点，高频多点

---

### 5.2 地平面设计

**设计原则：**
- 地平面完整
- 避免地平面开槽
- 信号线下方有地平面
- 模拟地和数字地分离

**模拟/数字地分离：**
```
模拟地 ──┐
         │
         └── 单点连接 ── 数字地
```

---

### 5.3 EMC设计

**EMC措施：**
- 接地平面
- 屏蔽罩
- 滤波器
- 去耦电容

---

## 九、信号完整性

### 9.1 信号完整性问题

| 问题 | 原因 | 解决 |
|------|------|------|
| 反射 | 阻抗不匹配 | 终端匹配 |
| 串扰 | 耦合 | 增加间距 |
| 衰减 | 传输线损耗 | 缩短走线 |
| 时序 | 延迟 | 等长布线 |

---

### 9.2 阻抗匹配

**终端匹配：**
```
串联匹配：靠近源端
并联匹配：靠近负载端
```

## 十、热设计

### 10.1 散热设计

**散热方式：**
- 散热片
- 风扇
- 热管

**PCB散热：**
- 散热焊盘
- 过孔导热
- 铜皮散热

---

### 10.2 热分析

**热阻计算：**
$$R_{ja} = \frac{T_j - T_a}{P}$$

**结温：**
$$T_j = T_a + P \times R_{ja}$$
