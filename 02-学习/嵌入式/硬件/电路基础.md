# 电路基础

## 核心概念

- **电路** - 由电气元件组成的电流流通路径
- **电流** - 电荷的定向移动，单位：安培(A)
- **电压** - 电场力做功的能力，单位：伏特(V)
- **电阻** - 阻碍电流流动的能力，单位：欧姆(Ω)

---

## 一、电路基本定律

### 1.1 欧姆定律

$$U = IR$$

| 物理量 | 符号 | 单位 | 说明 |
|--------|------|------|------|
| 电压 | U | V | 电位差 |
| 电流 | I | A | 电荷流动速率 |
| 电阻 | R | Ω | 阻碍能力 |

**功率公式：**

$$P = UI = I^2R = \frac{U^2}{R}$$

---

### 1.2 基尔霍夫定律

#### KCL（基尔霍夫电流定律）

**定义：** 任意节点，流入电流之和等于流出电流之和

$$\sum I_{in} = \sum I_{out}$$

或：

$$\sum_{k=1}^{n} I_k = 0$$

**应用：**
```
    I1 → ──┐
           ↓
    I2 → ──●── → I3
           ↑
    I4 → ──┘

KCL: I1 + I2 + I4 = I3
```

---

#### KVL（基尔霍夫电压定律）

**定义：** 任意闭合回路，电压升之和等于电压降之和

$$\sum U = 0$$

**应用：**
```
    + U1 -
   ┌──┤├──┐
   │       │
   + U2    + U3
   │       │
   └───────┘

KVL: U1 + U2 + U3 = 0
```

---

## 二、电路分析方法

### 2.1 网孔分析法

**步骤：**
1. 设定网孔电流方向（通常顺时针）
2. 对每个网孔列写KVL方程
3. 联立求解方程组

**示例：**
```
    R1        R2
 ┌──┤├──┬──┤├──┐
 │      │      │
(+Us1)  R3   (+Us2)
 │      │      │
 └──────┴──────┘

网孔1: (R1+R3)I1 - R3*I2 = Us1
网孔2: -R3*I1 + (R2+R3)I2 = -Us2
```

---

### 2.2 节点分析法

**步骤：**
1. 选择参考节点（接地）
2. 设定各节点电压
3. 对每个节点列写KCL方程
4. 联立求解方程组

**示例：**
```
       R1
  ┌──┤├──┐
  │      │
(+Is)    R2      (参考节点)
  │      │
  └──────┴──── V1

节点V1: (1/R1 + 1/R2)*V1 = Is
```

---

### 2.3 叠加定理

**定义：** 线性电路中，多个电源共同作用时，任一支路的电流等于各电源单独作用时在该支路产生的电流的代数和。

**步骤：**
1. 保留一个电源，其余电源置零
   - 电压源短路
   - 电流源开路
2. 计算各支路电流
3. 代数叠加

**示例：**
```
原电路：I = I' + I''

Us单独作用：I' = Us/(R1+R2)
Is单独作用：I'' = Is * R1/(R1+R2)
```

---

### 2.4 戴维南定理（等效电压源）

**定义：** 任何线性有源二端网络，对外电路而言，可以用一个电压源和电阻的串联组合等效。

**等效参数：**
- **Uoc** - 开路电压（外电路断开时的端电压）
- **Req** - 等效电阻（所有独立电源置零后的等效电阻）

**步骤：**
1. 断开待求支路
2. 计算开路电压 Uoc
3. 计算等效电阻 Req
4. 画出等效电路，求解

---

### 2.5 诺顿定理（等效电流源）

**定义：** 任何线性有源二端网络，对外电路而言，可以用一个电流源和电阻的并联组合等效。

**等效参数：**
- **Isc** - 短路电流
- **Req** - 等效电阻

**与戴维南的关系：**
$$U_{oc} = I_{sc} \times R_{eq}$$

---

## 三、电路定理

### 3.1 最大功率传输定理

**条件：** 当负载电阻等于电源内阻时，负载获得最大功率。

$$R_L = R_s$$

**最大功率：**
$$P_{max} = \frac{U_s^2}{4R_s}$$

**效率：** 此时效率仅为50%

---

### 3.2 替代定理

**定义：** 任意线性或非线性电路中，若某支路的电压和电流已知，则该支路可以用等效电压源或电流源替代。

---

### 3.3 特勒根定理

**功率守恒：** 电路中所有支路吸收的功率之和为零。

$$\sum_{k=1}^{b} U_k I_k = 0$$

---

## 四、一阶电路

### 4.1 RC电路

**时间常数：**
$$\tau = RC$$

**零输入响应（放电）：**
$$u_C(t) = U_0 e^{-t/\tau}$$

**零状态响应（充电）：**
$$u_C(t) = U_s(1 - e^{-t/\tau})$$

**全响应：**
$$u_C(t) = U_0 e^{-t/\tau} + U_s(1 - e^{-t/\tau})$$

---

### 4.2 RL电路

**时间常数：**
$$\tau = \frac{L}{R}$$

**零输入响应：**
$$i_L(t) = I_0 e^{-t/\tau}$$

**零状态响应：**
$$i_L(t) = \frac{U_s}{R}(1 - e^{-t/\tau})$$

---

### 4.3 三要素法

**通用公式：**
$$f(t) = f(\infty) + [f(0^+) - f(\infty)]e^{-t/\tau}$$

**三要素：**
1. **f(0⁺)** - 初始值
2. **f(∞)** - 稳态值
3. **τ** - 时间常数

---

## 五、正弦稳态分析

### 5.1 正弦量三要素

$$u(t) = U_m \sin(\omega t + \phi)$$

| 要素 | 符号 | 说明 |
|------|------|------|
| 幅值 | Um | 最大值 |
| 角频率 | ω | ω = 2πf |
| 初相位 | φ | t=0时的相位 |

**有效值：**
$$U = \frac{U_m}{\sqrt{2}} \approx 0.707 U_m$$

---

### 5.2 相量表示

**极坐标形式：**
$$\dot{U} = U \angle \phi$$

**代数形式：**
$$\dot{U} = U\cos\phi + jU\sin\phi$$

**转换：**
$$U \angle \phi = U(\cos\phi + j\sin\phi)$$

---

### 5.3 阻抗与导纳

**阻抗：**
$$Z = R + jX = |Z|\angle\phi$$

| 元件 | 阻抗 |
|------|------|
| 电阻 | Z = R |
| 电感 | Z = jωL |
| 电容 | Z = 1/(jωC) |

**导纳：**
$$Y = G + jB = \frac{1}{Z}$$

---

### 5.4 功率计算

**瞬时功率：**
$$p(t) = u(t) \cdot i(t)$$

**有功功率（平均功率）：**
$$P = UI\cos\phi$$

**无功功率：**
$$Q = UI\sin\phi$$

**视在功率：**
$$S = UI$$

**功率因数：**
$$\cos\phi = \frac{P}{S}$$

**功率三角形：**
```
    S (VA)
    │\
    │ \
  Q │  \ P (W)
    │   \
    └────
```

---

## 六、三相电路

### 6.1 三相电源

**相电压：**
$$u_A = U_p \sin(\omega t)$$
$$u_B = U_p \sin(\omega t - 120°)$$
$$u_C = U_p \sin(\omega t + 120°)$$

**线电压与相电压关系（星形）：**
$$U_L = \sqrt{3} U_P$$

---

### 6.2 三相负载连接

| 连接方式 | 线电压 | 线电流 | 功率 |
|---------|--------|--------|------|
| 星形(Y) | UL = √3 UP | IL = IP | P = 3UPIPcosφ |
| 三角形(△) | UL = UP | IL = √3 IP | P = 3ULILcosφ/√3 |

---

### 6.3 三相功率测量

**两瓦特计法：**
$$P_{total} = W_1 + W_2$$

适用于三相三线制，无论负载是否对称。

---

## 七、谐振电路

### 7.1 串联谐振

**谐振条件：**
$$\omega L = \frac{1}{\omega C}$$

**谐振频率：**
$$f_0 = \frac{1}{2\pi\sqrt{LC}}$$

**特点：**
- 阻抗最小：Z = R
- 电流最大
- 电压谐振：UL = UC = QU

---

### 7.2 并联谐振

**谐振频率：**
$$f_0 = \frac{1}{2\pi\sqrt{LC}}$$

**特点：**
- 阻抗最大
- 电流最小
- 电流谐振：IL = IC = QI

---

## 八、二端口网络

### 8.1 Z参数（阻抗参数）

$$\begin{bmatrix} U_1 \\ U_2 \end{bmatrix} = \begin{bmatrix} Z_{11} & Z_{12} \\ Z_{21} & Z_{22} \end{bmatrix} \begin{bmatrix} I_1 \\ I_2 \end{bmatrix}$$

### 8.2 Y参数（导纳参数）

$$\begin{bmatrix} I_1 \\ I_2 \end{bmatrix} = \begin{bmatrix} Y_{11} & Y_{12} \\ Y_{21} & Y_{22} \end{bmatrix} \begin{bmatrix} U_1 \\ U_2 \end{bmatrix}$$

### 8.3 T参数（传输参数）

$$\begin{bmatrix} U_1 \\ I_1 \end{bmatrix} = \begin{bmatrix} A & B \\ C & D \end{bmatrix} \begin{bmatrix} U_2 \\ -I_2 \end{bmatrix}$$

1. **画图** - 先画出电路图，标出参考方向
2. **选方法** - 根据电路特点选择合适的分析方法
3. **列方程** - 注意符号和方向
4. **验算** - 用功率守恒验证结果

- 电流参考方向设反
- 电压极性标错

- 相量计算中j的运算错误
