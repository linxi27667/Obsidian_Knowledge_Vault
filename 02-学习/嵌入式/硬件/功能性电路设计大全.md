## 一、电源电路

### 1.1 LDO 线性稳压器

#### 1.1.1 基本原理

LDO（Low Dropout Regulator）通过内部调整管（PMOS 或 PNP）工作在线性区，将输入电压降至稳定的输出电压。

**核心参数：**
- **Dropout Voltage**：维持稳压所需的最小输入-输出压差。PMOS 型可低至 100-300mV
- **静态电流 Iq**：LDO 自身消耗的电流，电池供电场景需关注（越低越好）
- **PSRR**：电源抑制比，表征对输入纹波的抑制能力，单位 dB
- **负载调整率**：负载电流变化时输出电压的稳定性
- **线性调整率**：输入电压变化时输出电压的稳定性
- **热阻 θJA**：决定最大功耗能力

**功耗计算：**
$$P_{diss} = (V_{in} - V_{out}) \times I_{load}$$

例如：5V 转 3.3V，负载 500mA → $P = 1.7 \times 0.5 = 0.85W$

**散热注意：** SOT-23 封装 θJA ≈ 200°C/W，0.85W 温升 170°C，不可接受。需选用 SO-8、DFN 或加散热焊盘。

| HT7333 | 3.3V | 500mA | 250mV | SOT-89 | 超低压差，电池设备常用 |

#### 1.1.3 AMS1117 典型应用电路

```
Vin ──┬──[C1 10μF]──┬── AMS1117 ──┬──[C2 22μF]──┬── Vout (3.3V)
      │              │    IN  OUT   │              │
      └──[C3 100nF]──┘      GND    └──[C4 100nF]──┘
                                │
                               GND
```

**设计要点：**
- 输入电容 C1：10μF 钽电容或 MLCC，靠近芯片放置
- 输出电容 C2：22μF，ESR 需在 0.1-10Ω 范围内（影响环路稳定性）
- 旁路电容 C3、C4：100nF MLCC，滤除高频噪声
- AMS1117 的 ESR 要求：输出电容 ESR 不能太低，否则可能振荡

### 1.2 Buck 降压转换器

#### 1.2.1 基本原理

Buck 电路通过 MOSFET 开关和 LC 滤波实现降压，效率通常 85%-95%。

**工作过程：**
1. **导通阶段（Ton）**：MOSFET 导通，电流经电感流向负载，电感储能
2. **关断阶段（Toff）**：MOSFET 关断，电感通过续流二极管（或同步整流管）释放能量

**基本公式：**
- 输出电压：$V_{out} = D \times V_{in}$（D 为占空比 = Ton / T）
- 电感纹波电流：$\Delta I_L = \frac{(V_{in} - V_{out}) \times D}{f \times L}$
- 输出纹波电压：$\Delta V_{out} = \frac{\Delta I_L}{8 \times f \times C_{out}}$
- 电感选择：一般纹波电流取负载电流的 20%-40%

**连续导通模式（CCM）与断续导通模式（DCM）：**
- CCM：电感电流始终大于零，重载时工作
- DCM：电感电流会降到零，轻载时效率更高

#### 1.2.2 常用 Buck 芯片

|------|---------|------|---------|------|------|
| MP1584 | 4.5-28V | 可调 | 3A | 100kHz-4MHz | 经典通用款 |
| MP2315 | 4.5-24V | 可调 | 3A | 500kHz-2MHz | 同步整流，高效率 |
| TPS5430 | 5.5-36V | 可调 | 3A | 500kHz | TI 经典，宽输入 |
| LM2596 | 4.5-40V | 可调/固定 | 3A | 150kHz | 经典但效率较低 |
| SY8089 | 2.5-5.5V | 可调 | 2A | 1.5MHz | 小封装同步整流 |
| RT8059 | 2-5.5V | 可调 | 1A | 1.5MHz | SOT-23-5 小封装 |
| XL4015 | 8-32V | 可调 | 5A | 180kHz | 大电流，常用于充电 |
| LM2676 | 8-40V | 可调 | 3A | 260kHz | 内置 MOSFET |

#### 1.2.3 MP1584 典型设计

**设计步骤（目标：12V → 5V/3A）：**

1. **反馈电阻选择：**
   - $V_{out} = 0.765 \times (1 + \frac{R1}{R2})$
   - 选择 R2 = 10kΩ → R1 = 10kΩ × (5/0.765 - 1) = 55.3kΩ → 取 56kΩ

2. **电感选择：**
   - 取纹波电流 ΔIL = 30% × 3A = 0.9A
   - $L = \frac{(V_{in} - V_{out}) \times V_{out}}{V_{in} \times f \times \Delta I_L}$
   - L = (12-5) × 5 / (12 × 500kHz × 0.9) = 6.5μH → 取 6.8μH/5A

3. **输出电容：**
   - $C_{out} \geq \frac{\Delta I_L}{8 \times f \times \Delta V_{out}}$
   - 取纹波 30mV：C ≥ 0.9/(8 × 500kHz × 30mV) = 7.5μF → 取 22μF/10V × 2

4. **输入电容：** 22μF/25V MLCC + 100nF 陶瓷旁路

5. **续流二极管：** SS34（3A/40V 肖特基）或使用同步整流方案

### 1.3 Boost 升压转换器

#### 1.3.1 基本原理

Boost 电路将低输入电压升高到所需的输出电压，用于电池供电等场景。

**工作过程：**
1. **导通阶段**：MOSFET 导通，电流流过电感储能，负载由输出电容供电
2. **关断阶段**：MOSFET 关断，电感电压叠加输入电压，经二极管向负载和电容充电

**基本公式：**
- $V_{out} = \frac{V_{in}}{1-D}$
- 最大占空比限制了最大升压比，一般 D 不超过 85%

#### 1.3.2 常用 Boost 芯片

| 型号 | 输入范围 | 输出 | 最大电流 | 特点 |
|------|---------|------|---------|------|
| MT3608 | 2-24V | 可调至 28V | 2A | 成本极低，应用广泛 |
| SX1308 | 2-24V | 可调至 28V | 2A | MT3608 兼容替代 |
| TPS61088 | 2.7-12V | 可调至 12.6V | 10A | 大电流同步整流 |
| XL6009 | 5-32V | 可调至 50V | 4A | 大电流升压 |
| FP6276 | 2.4-4.5V | 可调至 5.3V | 3.5A | 用于锂电池升压 5V |

#### 1.3.3 MT3608 典型应用

**参数：** 锂电池 3.0-4.2V 输入，升压至 5V/1A 输出。

- 反馈：Vout = 0.6 × (1 + R1/R2)，取 R2 = 12kΩ，R1 = 88kΩ → 实取 82kΩ+6.2kΩ 串联
- 电感：4.7μH/3A，饱和电流需大于峰值电流
- 输出电容：22μF/10V × 2
- 二极管：SS14 肖特基（1A/40V）

### 1.4 锂电池充电电路

#### 1.4.1 TP4056 线性充电方案

TP4056 是最常用的单节锂电池线性充电 IC。

**特性：**
- 输入电压：4.5-8V（推荐 5V USB）
- 充电电流：通过 PROG 电阻设定
- 充电方式：CC（恒流）→ CV（恒压）→ 截止
- 涓流充电：电池电压 < 2.9V 时以 1/10 设定电流预充
- 充满截止电流：设定电流的 1/10

**充电电流设定：**
| RPROG (kΩ) | 充电电流 (mA) |
|------------|--------------|
| 10 | 130 |
| 5 | 250 |
| 2 | 580 |
| 1.2 | 1000 |

**典型电路（500mA 充电）：**
```
USB 5V ──┬──[C1 100nF]──┬── TP4056 VIN
          │              │    BAT ──┬── 电池正极
          │              │   PROG──[R 5kΩ]──GND
          │              │    STDBY ── LED1（充满指示）
          │              │    CHRG  ── LED2（充电指示）
          └──[C2 10μF]──┘    GND ── GND/电池负极
```

**注意：** TP4056 是线性充电，输入输出压差大时发热严重。3.7V 锂电池充至 4.2V，5V 输入，压差 0.8V × 1A = 0.8W，尚可接受。

#### 1.4.2 带路径管理的充电方案

**问题：** TP4056 不支持边充边用（路径管理），充电时负载波动影响充电判断。

**解决方案：** 使用带路径管理的芯片，如：
- **BQ24075**：TI 出品，支持动态电源路径管理
- **IP5306**：集成充电 + 升压 + 电量指示，充电宝常用
- **ETA6003**：高集成度，支持边充边放

### 1.5 输入保护电路

#### 1.5.1 基本保护元件

**1. 反接保护：**
- **PMOS 反接保护：** 串联在正极，GS 接输入端。正接时 VGS < Vth 导通，反接时 VGS = 0 截止
- **理想二极管：** LTC4357/LM74610 等，正向压降极低（<30mV）
- **普通二极管方案：** 串联肖特基（压降 0.3-0.5V，损耗较大）

**2. 过压保护（OVP）：**
- **TVS 钳位：** SMBJ5.0A（5V 系统）、SMBJ12A（12V 系统）
- **可控硅撬棍保护：** 过压时触发 SCR 将电压拉低至近零，配合保险丝
- **专用 OVP 芯片：** NCP346、LTC4361

**3. 过流保护：**
- **PPTC 自恢复保险丝：** 串联在电源输入端，过流时发热高阻
- **电子保险丝：** TPS2592xx 系列，精确限流
- **限流电阻 + 检测：** 简单但损耗大

**4. ESD 保护：**
- USB 端口：PRTR5V0U2X（专用 USB ESD）
- 通用信号：PESD5V0S1BA

#### 1.5.2 完整输入保护电路

```
输入 ──[保险丝]──[TVS]──┬──[PMOS反接保护]──┬──[OVP电路]── 系统电源
                        │                  │
                       GND                GND
```

## 二、运放电路

### 2.1 虚短与虚断

运放分析的两大基本假设（负反馈条件下）：

- **虚短（Virtual Short）：** V+ ≈ V-，两个输入端电压近似相等
- **虚断（Virtual Open）：** 输入端电流 ≈ 0，运放输入阻抗极高（MOS 输入型 > 10^12 Ω）

**适用条件：** 运放工作在线性区（有负反馈），且开环增益足够大。

### 2.2 反相放大器

**电路结构：**
```
        Rf
Vin ──[R1]──┬──(-)──┐
            │       │  运放
            └── Rf ──┘
                   (+)── Vref（通常接地）
                    │
                   GND
```

**传递函数：**
$$V_{out} = -\frac{R_f}{R_1} \times V_{in}$$

**特点：**
- 输入阻抗 = R1（较低）
- 输出反相
- 电压增益 = -Rf/R1
- 输入端存在共模电压变化（虚地在 V- 处）

**设计实例：** 反相放大 2 倍 → R1 = 10kΩ，Rf = 20kΩ

### 2.3 同相放大器

**电路结构：**
```
Vin ──(+)── 运放 ──┬── Vout
                   │
       GND──[R1]──(-)
                   │
                  [Rf]
                   │
                  Vout
```

**传递函数：**
$$V_{out} = (1 + \frac{R_f}{R_1}) \times V_{in}$$

**特点：**
- 输入阻抗极高（运放本身的差模输入阻抗）
- 输出同相
- 共模抑制比要求高
- 最小增益 = 1（Rf = 0 或 R1 = ∞，即电压跟随器）

### 2.4 电压跟随器

**电路：** 输出直接接反相输入端（100% 负反馈）。

$$V_{out} = V_{in}$$

**用途：**
- 阻抗变换：高阻输入 → 低阻输出
- 隔离：缓冲前后级电路，防止负载效应
- ADC 前端信号缓冲

**关键参数要求：**
- 带宽 ≥ 信号最高频率的 10 倍
- 压摆率 ≥ 信号最大变化速率
- 输入偏置电流要小（高阻源时）

### 2.5 加法器与减法器

#### 2.5.1 反相加法器

```
V1 ──[R1]──┐
V2 ──[R2]──┤──(-)── 运放 ── Vout
V3 ──[R3]──┘
           │
          [Rf]
           │
          GND
(+): GND
```

**公式（R1 = R2 = R3 = R）：**
$$V_{out} = -R_f \times (\frac{V_1}{R_1} + \frac{V_2}{R_2} + \frac{V_3}{R_3})$$

若 Rf = R，则 $V_{out} = -(V_1 + V_2 + V_3)$

#### 2.5.2 差分放大器（减法器）

```
V1 ──[R1]──(-)── 运放 ── Vout
          │             │
         [Rf]          [Rf]
          │             │
         Vout    V2 ──[R2]──(+)── GND/[R3]
```

当 R1 = R2 且 Rf = R3 时：
$$V_{out} = \frac{R_f}{R_1} \times (V_2 - V_1)$$

**注意：** 简单减法器的共模抑制比受电阻匹配精度限制，精密应用需用仪表放大器。

### 2.6 积分器与微分器

#### 2.6.1 反相积分器

```
Vin ──[R]──(-)── 运放 ── Vout
              │          │
             [C]         │
              │          │
             Vout        │
(+): GND
```

**公式：**
$$V_{out}(t) = -\frac{1}{RC} \int_0^t V_{in}(\tau) d\tau$$

**实际应用注意事项：**
- 需要并联电阻限制低频增益（防止输出饱和）
- 输入方波 → 输出三角波
- 复位开关：并联电容两端，积分开始前清零

#### 2.6.2 反相微分器

```
Vin ──[C]──(-)── 运放 ── Vout
             │          │
            [R]         │
             │          │
            Vout        │
(+): GND
```

**公式：**
$$V_{out}(t) = -RC \frac{dV_{in}}{dt}$$

**实际问题：** 高频增益大，噪声敏感。通常串联小电阻限制高频增益。

### 2.7 有源滤波器

#### 2.7.1 Sallen-Key 低通滤波器（二阶）

**拓扑 A（单位增益）：**
```
Vin ──[R1]──┬──[R2]──┬──(+)── 运放 ──┬── Vout
            │        │               │
           [C1]     [C2]             │
            │        │               │
           GND      (-)──────────────┘
```

**传递函数：**
$$H(s) = \frac{1}{1 + s(R_1C_1 + R_2C_1 + R_2C_2(1-K)) + s^2 R_1R_2C_1C_2}$$

单位增益时 K = 1，简化为：
$$H(s) = \frac{1}{1 + s(R_1C_1 + R_2C_1 + R_2C_2) + s^2 R_1R_2C_1C_2}$$

**设计步骤（Butterworth 响应，fc = 1kHz）：**
1. 选择 C1 = 10nF
2. 选择比例 m = C2/C1，Butterworth 取 m = 0.5
3. C2 = 5nF（实际取 4.7nF）
4. $R_1 = \frac{1}{2\pi f_c \sqrt{m} \cdot C_1} = \frac{1}{2\pi \times 1000 \times 0.707 \times 10n} \approx 22.5k\Omega$
5. $R_2 = \frac{1 + \sqrt{m}}{2\pi f_c \cdot m \cdot C_1} = \frac{1.707}{2\pi \times 1000 \times 0.5 \times 10n} \approx 54.3k\Omega$

**常用运放：** TL072（通用）、OPA2340（低噪声）、LM358（廉价）

#### 2.7.2 多反馈低通滤波器

Sallen-Key 的替代方案，反相结构，对运放带宽要求更高但元件更少。

#### 2.7.3 带通滤波器

将低通和高通级联，或使用 MFB 带通拓扑。中心频率、Q 值、增益可独立调整。

### 2.8 仪表放大器

#### 2.8.1 三运放仪表放大器原理

```
        Rg
V1 ──(+)─┤  U1  ├───┐   R    ┌──┤  U3  ├── Vout
   R     └──(-)──┘   │       │   └──(-)──┘
                      ├─[Rg]─┤
   R                 │       │
V2 ──(+)─┤  U2  ├───┘   R   └──(+)── U3
         └──(-)──┘
```

**增益公式：**
$$G = 1 + \frac{2R}{R_g}$$

通过改变 Rg 即可调整增益，而不影响共模抑制比。

#### 2.8.2 AD620 仪表放大器

AD620 是经典的单芯片仪表放大器。

**关键参数：**
- 增益范围：1-10000（单电阻设定）
- CMRR：> 100dB（G = 10）
- 输入偏置电流：1.0nA max
- 输入失调电压：50μV max
- 带宽：120kHz（G = 100）

**增益设定：**
$$G = 1 + \frac{49.4k\Omega}{R_G}$$

| 增益 | RG (Ω) | 带宽 (kHz) |
|------|--------|-----------|
| 1 | ∞（不接） | 1000 |
| 10 | 5.49k | 800 |
| 100 | 499 | 120 |
| 1000 | 49.9 | 12 |

**应用：** 称重传感器、热电偶放大、ECG 信号采集、桥式传感器。

### 2.9 比较器

#### 2.9.1 LM393 双路比较器

**特性：**
- 开集输出（需上拉电阻）
- 响应时间：1.3μs
- 输入失调电压：2mV typ
- 单电源 2-36V，双电源 ±1-±18V
- 输出可直接驱动 LED、继电器

**典型应用：**
```
Vin ──(+)── LM393 ──┬──[上拉 4.7kΩ]── Vcc
Vref ──(-)           │
                     └── 输出（高/低电平）
```

**阈值设定：**
- 单阈值：电阻分压或基准电压
- 迟滞比较器（施密特触发器）：通过正反馈电阻设置上下阈值

**迟滞设计：**
```
        Rf
Vout ──[Rf]──┬──(-)── LM393 ── Vout
Vin ──[R1]──┤
Vref──[R2]──(+)─┘
```

上下阈值：$V_{th} = V_{ref} \pm \frac{R_1}{R_1 + R_f} \times (V_{OH} - V_{OL})$

#### 2.9.2 比较器 vs 运放

| 特性 | 比较器 | 运放 |
|------|--------|------|
| 反馈 | 无（开环） | 有（闭环） |
| 输出 | 数字（高/低） | 模拟（线性） |
| 响应 | 快（ns~μs） | 慢（μs~ms） |
| 补偿 | 无内部补偿 | 有频率补偿 |
| 能否替代 | 不可 | 理论上可以但不推荐 |

## 三、信号调理

### 3.1 ADC 前端电路

#### 3.1.1 设计要点

- **阻抗匹配：** ADC 采样保持电路的输入阻抗有限，高阻源需加缓冲
- **抗混叠滤波：** 采样前必须滤除 Nyquist 频率以上的信号
- **输入范围：** 确保信号在 ADC 输入范围内，必要时分压或放大
- **噪声抑制：** 输入端加 RC 滤波（典型 100Ω + 100pF~10nF）

#### 3.1.2 典型 ADC 前端电路

```
传感器 ──[缓冲运放]──[R 100Ω]──┬── ADC 输入
                               [C 10nF]
                                │
                               GND
```

**RC 滤波器截止频率：**
$$f_c = \frac{1}{2\pi RC}$$

100Ω + 10nF → fc = 159kHz，适合 ADC 采样率 < 500kHz 的场景。

#### 3.1.3 差分 ADC 前端

对于差分 ADC（如 ADS1115、ADS1256），需要差分驱动电路：
```
信号+ ──[运放+]──[RC]── ADC+
信号- ──[运放-]──[RC]── ADC-
```

### 3.2 NTC 热敏电阻接口

#### 3.2.1 原理

NTC（负温度系数热敏电阻）阻值随温度升高而降低。

**Steinhart-Hart 方程：**
$$\frac{1}{T} = A + B\ln(R) + C(\ln(R))^3$$

**简化 Beta 公式：**
$$R_T = R_{25} \times e^{\beta(\frac{1}{T} - \frac{1}{298.15})}$$

其中 β 通常为 3000-5000K。

#### 3.2.2 分压电路

```
Vcc ──[R 上拉]──┬── ADC
                │
               [NTC]
                │
               GND
```

$$V_{ADC} = V_{cc} \times \frac{R_{NTC}}{R_{pullup} + R_{NTC}}$$

**电阻选择：** 上拉电阻选 NTC 在目标温度中点的阻值（如 25°C 时 NTC = 10kΩ，选 Rpullup = 10kΩ）。

#### 3.2.3 查表法 vs 计算法

- **查表法：** 预先计算 ADC 值到温度的映射表，存储在 Flash 中，线性插值。计算量小，适合 MCU
- **计算法：** 直接用 Beta 公式实时计算。需要浮点运算或定点化处理

**NTC 常用型号：**
- MF52-103：10kΩ @ 25°C，β = 3950
- NTC 10K 3950：通用型
- 0603/0805 贴片 NTC：适合 PCB 测温

### 3.3 热电偶信号调理

#### 3.3.1 原理

热电偶利用两种不同金属连接处的塞贝克效应产生与温度成正比的微弱电压。

**常见热电偶类型：**
| 类型 | 材料 | 温度范围 | 灵敏度 | 应用 |
|------|------|---------|--------|------|
| K | 镍铬-镍硅 | -200~1372°C | 41μV/°C | 最常用 |
| J | 铁-铜镍 | -210~1200°C | 52μV/°C | 还原气氛 |
| T | 铜-铜镍 | -270~400°C | 43μV/°C | 低温 |
| E | 镍铬-铜镍 | -270~1000°C | 68μV/°C | 最高灵敏度 |

#### 3.3.2 信号调理电路

**1. 冷端补偿（CJC）：**
- 用 NTC/PT100 测量接线端温度
- 补偿热电偶在冷端产生的电动势
- MAX31855/31856 内置 CJC

**2. 放大电路：**
- 信号极其微弱（K 型 41μV/°C），需要高增益、低漂移运放
- 推荐：AD8495（K 型专用）、INA826（精密仪表放大器）

**3. 集成方案（推荐）：**
- **MAX31855**：SPI 接口，支持 K/J/N/T/S/R 型，内置 ADC 和 CJC
- **MAX31856**：支持更多类型，精度更高
- **MAX6675**：经典 K 型热电偶转数字输出

### 3.4 称重传感器（应变片/桥式传感器）

#### 3.4.1 惠斯通电桥

```
        R1      R2
Vexc ──┬──┤├──┬──┤├──┬── GND
       │       │       │
       ├─ V+   │   V- ─┤
       │       │       │
       └──┤├──┴──┤├──┘
          R3      R4
```

- 称重传感器通常为半桥或全桥结构
- 输出信号：满量程时 2mV/V（如 5V 激励 → 满量程 10mV 输出）

#### 3.4.2 放大电路

**方案一：AD620 仪表放大器**
```
传感器 V+ ──(+) AD620
传感器 V- ──(-) AD620 ── Vout
         RG = 49.4kΩ/(G-1)
```

- 增益 G = 1000 时，10mV → 10V 输出
- 需要注意运放电源电压限制，增益不可太大

**方案二：HX711 专用 ADC**
- 24 位 Σ-Δ ADC
- 内置可编程增益放大器（PGA，增益 32/64/128）
- SPI 兼容接口
- 内部稳压器提供激励电压
- 推荐方案，成本低，精度高

### 3.5 4-20mA 电流环

#### 3.5.1 原理

工业标准信号传输方式：
- 4mA 对应量程下限（零点）
- 20mA 对应量程上限（满量程）
- 4mA 同时为二线制变送器提供供电

**优势：** 抗干扰能力强（电流信号不受线阻影响）、可检测断线（< 4mA）。

#### 3.5.2 接收端电路

**精密电阻采样：**
```
4-20mA ──[250Ω 精密电阻]── GND
                │
                └── ADC（1-5V 对应 4-20mA）
```

**注意事项：**
- 250Ω 电阻精度 ≥ 0.1%，温漂 ≤ 25ppm/°C
- 采样电压 = 4mA × 250Ω = 1V（零点），20mA × 250Ω = 5V（满量程）

**高侧电流检测放大：**
```
       Rsense
I_in ──┤├── I_out
       │     │
       └─[INA199]── Vout = Gain × I × Rsense
```

#### 3.5.3 发送端电路（DAC 转 4-20mA）

使用 XTR111 或 DAC + V-I 转换电路：
- XTR111：精密电压-电流转换器
- 支持 4-20mA / 0-20mA 输出
- 内置保护和诊断功能

## 四、电机驱动

### 4.1 H 桥驱动原理

#### 4.1.1 基本拓扑

```
        Vcc
        │
    ┌───┤ Q1    Q2 ├───┐
    │   │         │   │
    │   └───┬─────┘   │
    │       │MOTOR+   │
    │       Motor      │
    │       │MOTOR-   │
    │   ┌───┴─────┐   │
    │   │ Q3    Q4│   │
    └───┤         ├───┘
        │
       GND
```

**四种工作状态：**
| 状态 | Q1 | Q2 | Q3 | Q4 | 电机动作 |
|------|----|----|----|----|---------|
| 正转 | ON | OFF | OFF | ON | 正转 |
| 反转 | OFF | ON | ON | OFF | 反转 |
| 制动 | OFF | OFF | ON | ON | 短路制动 |
| 滑行 | OFF | OFF | OFF | OFF | 自由转动 |

**PWM 调速：** 高侧 PWM + 低侧常开（或反之），改变占空比控制转速。

#### 4.1.2 死区时间

上下桥臂不能同时导通（直通短路），需插入死区时间（通常 100ns-1μs）。

### 4.2 L298N 驱动模块

**特性：**
- 双 H 桥，可驱动两路直流电机
- 工作电压：逻辑 5V，电机 5-46V
- 持续电流：2A/桥，峰值 3A
- 内置续流二极管（需外加大功率快恢复二极管）

**典型接线：**
```
MCU_IN1 ──┐
MCU_IN2 ──┤ L298N ── 电机A
MCU_ENA ──┘（PWM调速）

MCU_IN3 ──┐
MCU_IN4 ──┤ L298N ── 电机B
MCU_ENB ──┘（PWM调速）
```

**缺点：** 内部达林顿管压降大（约 2V），效率低（仅 60-70%），发热严重。小功率可用，大功率推荐 TB6612 或 MOS 方案。

### 4.3 TB6612FNG 驱动

**优势对比 L298N：**
- MOSFET 驱动，压降仅 0.5V（@1A）
- 效率 90%+
- 体积小（SSOP24 封装）
- 内置过热/过流保护
- 逻辑电压 2.7-5.5V，电机电压 2.5-13.5V

**典型接线：**
```
MCU_AIN1 ──┐
MCU_AIN2 ──┤ TB6612 ── 电机A
MCU_PWMA ──┘

MCU_BIN1 ──┐
MCU_BIN2 ──┤ TB6612 ── 电机B
MCU_PWMB ──┘

STBY ── HIGH（使能）
VM ── 电机电源
VCC ── 逻辑电源
```

### 4.4 步进电机驱动

#### 4.4.1 A4988 驱动

**特性：**
- 微步进：全步、1/2、1/4、1/8、1/16 步
- 最大电流：2A（需加散热）
- 内置过流、过温保护
- 逻辑电压 3.3/5V 兼容

**接线：**
```
MCU_STEP ── A4988 STEP（每脉冲一步）
MCU_DIR  ── A4988 DIR（方向）
MS1-MS3  ── 微步设置
ENABLE   ── 使能（低有效）
VMOT     ── 电机电源 8-35V
VDD      ── 逻辑电源 3.3/5V
```

**电流设定：**
$$I_{max} = \frac{V_{ref}}{8 \times R_{sense}}$$

A4988 板载 Rsense = 0.1Ω，Vref 通过电位器调节。
- 例如：设定 1A → Vref = 1 × 8 × 0.1 = 0.8V

#### 4.4.2 TMC2209 静音驱动

**特性：**
- StealthChop2：极静音运行模式
- SpreadCycle：高动态响应模式
- 微步进：最高 256 细分
- 最大电流：2A（峰值 2.8A）
- UART 接口：可运行时调节参数
- StallGuard：无传感器堵转检测

**接线（UART 模式）：**
```
MCU_TX/RX ── TMC2209 UART（单线半双工）
MCU_STEP  ── TMC2209 STEP
MCU_DIR   ── TMC2209 DIR
```

**对比 A4988：**
| 特性 | A4988 | TMC2209 |
|------|-------|---------|
| 噪音 | 较大 | 极静音 |
| 微步 | 1/16 | 1/256 |
| 接口 | 仅 STEP/DIR | STEP/DIR + UART |
| 堵转检测 | 无 | StallGuard |
| 价格 | 便宜 | 较贵 |

### 4.5 BLDC 无刷电机基础

#### 4.5.1 原理

无刷直流电机（BLDC）采用电子换向代替机械电刷：
- 定子：三相绕组（U/V/W）
- 转子：永磁体
- 通过三相逆变器产生旋转磁场

**驱动方式：**
- **六步换相：** 最简单，每次只有两相通电，力矩波动大
- **FOC（磁场定向控制）：** 通过 Park/Clarke 变换实现平滑控制，效率高

#### 4.5.2 FOC 基础

**坐标变换：**
1. **Clarke 变换：** 三相 (Ia, Ib, Ic) → 两相静止 (Iα, Iβ)
2. **Park 变换：** 两相静止 (Iα, Iβ) → 两相旋转 (Id, Iq)
3. 控制 Id = 0（纯力矩控制），调节 Iq 控制力矩
4. 反变换 → SVPWM → 三相输出

**常用 FOC 方案：**
- **软件 FOC：** STM32 + SimpleFOC 库
- **硬件 FOC：** DRV8313/8316 + MCU
- **集成方案：** TMC6200（Trinamic）、STM32G4 系列（内置运放和比较器）

### 4.6 舵机驱动

#### 4.6.1 原理

舵机内置直流电机 + 齿轮减速 + 位置反馈电位器 + 控制板。

**控制信号：** 50Hz PWM（周期 20ms）
- 0.5ms 脉宽 → 0°
- 1.5ms 脉宽 → 90°
- 2.5ms 脉宽 → 180°

#### 4.6.2 接口电路

```
MCU PWM ──[信号线]── 舵机信号
VCC(5V) ──[电源线]── 舵机电源
GND     ──[地线]── 舵机地
```

**注意事项：**
- 舵机启动电流大（可达 1A+），不能用 MCU 电源直接供电
- 需要独立 5V 电源，与 MCU 共地
- 信号线串联 220-470Ω 电阻保护 MCU 引脚
- 多舵机供电需加 1000μF 以上大电容稳压

## 五、通信接口

### 5.1 RS-485 通信

#### 5.1.1 原理

- 差分信号传输，抗共模干扰能力强
- 半双工（二线制）或全双工（四线制）
- 最大传输距离 1200m（标准规定）
- 最多 32/128/256 个节点（取决于驱动器）

**电气特性：**
- 逻辑 1（MARK）：A-B < -200mV
- 逻辑 0（SPACE）：A-B > +200mV
- 共模电压范围：-7V 到 +12V

#### 5.1.2 MAX485 收发器

**接线：**
```
MCU_TX ── MAX485 DI
MCU_RX ── MAX485 RO
MCU_DE ── MAX485 DE/RE（高=发送，低=接收）
         MAX485 A ── 总线 A
         MAX485 B ── 总线 B
```

**总线终端电阻：** 总线两端各接 120Ω 终端匹配电阻。

**偏置电阻：** 总线空闲时需要确定电平：
- A 线通过 560Ω 上拉至 5V
- B 线通过 560Ω 下拉至 GND

#### 5.1.3 隔离 RS-485

工业环境需隔离：
- **数字隔离：** ADUM1201/1410 隔离信号
- **电源隔离：** B0505S-1W 等 DC-DC 模块
- **集成方案：** ADM2582E（信号+电源隔离一体）

### 5.2 CAN 总线

#### 5.2.1 原理

- 差分信号（CAN_H 和 CAN_L）
- 多主通信，基于优先级的非破坏性仲裁
- 速率：最高 1Mbps（标准 CAN）、5Mbps（CAN FD）
- 最大节点数：理论上无限，受收发器限制（通常 110 个）

**电平：**
| 状态 | CAN_H | CAN_L | 差分电压 |
|------|-------|-------|---------|
| 隐性（1） | 2.5V | 2.5V | ~0V |
| 显性（0） | 3.5V | 1.5V | ~2V |

#### 5.2.2 TJA1050 收发器

**接线：**
```
MCU_TX  ── TJA1050 TXD
MCU_RX  ── TJA1050 RXD
        TJA1050 CANH ── 总线 CAN_H
        TJA1050 CANL ── 总线 CAN_L
SPLIT   ── 中间参考电压（可选）
```

**终端电阻：** 总线两端各 120Ω。

**常用 CAN 收发器：**
| 型号 | 速率 | 特点 |
|------|------|------|
| TJA1050 | 1Mbps | NXP 经典，高速 |
| TJA1040 | 1Mbps | 低功耗待机模式 |
| MCP2551 | 1Mbps | Microchip 经典 |
| SN65HVD230 | 1Mbps | TI 出品，3.3V 逻辑 |
| TJA1145 | CAN FD | 带电源管理、SPI 控制 |

### 5.3 以太网 PHY

#### 5.3.1 LAN8720A

10/100Mbps 以太网 PHY 芯片，RMII 接口。

**关键引脚：**
```
MCU_RMII_REF_CLK ── LAN8720 REF_CLK (50MHz)
MCU_RMII_TX_EN  ── LAN8720 TXEN
MCU_RMII_TXD0   ── LAN8720 TXD0
MCU_RMII_TXD1   ── LAN8720 TXD1
MCU_RMII_RXD0   ── LAN8720 RXD0
MCU_RMII_RXD1   ── LAN8720 RXD1
MCU_RMII_CRS_DV ── LAN8720 CRS_DV
MCU_MDIO        ── LAN8720 MDIO
MCU_MDC         ── LAN8720 MDC
                LAN8720 TXP/TXN ── 变压器 ── RJ45
                LAN8720 RXP/RXN ── 变压器 ── RJ45
```

**50MHz 时钟方案：**
1. 外部 50MHz 晶振（最稳定）
2. MCU MCO 输出 50MHz（节省晶振成本）
3. LAN8720 内部 PLL + 25MHz 晶振

**地址配置：** PHYAD[2:0] 引脚设置 MDIO 地址（0-31）。

### 5.4 USB ESD 保护

#### 5.4.1 设计要点

USB 端口是静电最容易侵入的路径，必须加 ESD 保护。

**USB 2.0 保护：**
- D+/D-：PRTR5V0U2X（0.7pF 低电容，专用 USB ESD）
- VBUS：SMBJ5.0A TVS（5V 钳位）

**推荐 ESD 器件：**
| 型号 | 电容 | 钳位电压 | 通道 | 适用 |
|------|------|---------|------|------|
| PRTR5V0U2X | 0.7pF | 14.5V | 2线 | USB 2.0 D+/D- |
| USBLC6-2SC6 | 0.5pF | 17V | 2线 | USB 2.0 |
| ESD5V3U2RSY | 0.5pF | 10V | 2线 | 高速信号 |
| TPD2E009 | 1.5pF | 14V | 2线 | USB 3.0 |
| PESD5V0S1BA | 45pF | 9.8V | 1线 | 低速信号 |

**PCB 布局：**
- ESD 器件靠近连接器放置
- 接地路径要短且宽
- 避免 ESD 电流流经信号路径

### 5.5 电平转换

#### 5.5.1 需求场景

- 3.3V MCU 与 5V 外设通信
- 1.8V MCU 与 3.3V 传感器通信
- 不同电压域的信号对接

#### 5.5.2 TXB0108 双向电平转换器

**特性：**
- 8 通道双向自动电平转换
- VCCA = 1.2-3.6V，VCCB = 1.65-5.5V
- 无需方向控制信号
- 传输速率：最高 100Mbps

**接线：**
```
3.3V 电源 ── TXB0108 VCCA
5V 电源   ── TXB0108 VCCB
3.3V MCU  ── TXB0108 A1-A8
5V 外设   ── TXB0108 B1-B8
OE ── VCCA（始终使能）
```

**注意事项：**
- TXB0108 采用边沿触发，不适合开漏/开集信号（如 I2C）
- I2C 电平转换推荐 PCA9306 或 MOSFET 方案
- 上拉电阻会影响自动方向检测

#### 5.5.3 其他电平转换方案

| 方案 | 优点 | 缺点 | 适用场景 |
|------|------|------|---------|
| 电阻分压 | 最便宜，无源 | 单向，速度慢 | 低速信号 |
| MOSFET 双向 | 便宜，双向 | 速度有限 | I2C、低速 GPIO |
| TXB0108 | 自动双向，快速 | 不适合开漏 | SPI、UART、GPIO |
| SN74LVC1T45 | 单通道，高速 | 单向 | 高速单向信号 |
| PCA9306 | 专为 I2C 设计 | 仅 I2C | I2C 专用 |

#### 5.5.4 MOSFET 电平转换（I2C 经典方案）

```
3.3V ──[R1 4.7kΩ]──┬── 3.3V 信号
5V  ──[R2 4.7kΩ]──┤── 5V 信号
                   │
                 Gate ── MOSFET (2N7002)
                   │
                  3.3V 侧
```

原理：3.3V 侧拉低 → MOSFET 导通 → 5V 侧也被拉低。5V 侧拉低 → 体二极管导通 → 3.3V 侧拉低 → MOSFET 导通。

## 六、EMC 设计

### 6.1 EMI 滤波

#### 6.1.1 电源 EMI 滤波器

**π 型滤波器：**
```
Vin ──[C1]──┬──[L]──┬──[C2]── Vout
            │       │
           GND     GND
```

- C1、C2：X 电容（跨线，0.1-1μF）+ Y 电容（对地，2.2nF）
- L：共模电感（Common Mode Choke）用于抑制共模干扰
- 差模电感（小值，用于差模滤波）

**共模电感选型：**
- 电流额定值 > 最大负载电流
- 阻抗 @ 目标频率（如 100kHz~30MHz）
- 常用：UU 型、EE 型铁氧体磁芯

#### 6.1.2 信号线 EMI 滤波

**RC 滤波：**
```
信号 ──[R 100Ω]──┬── 输出
                 [C 100pF]
                  │
                 GND
```

**铁氧体磁珠：**
- 选型关键：目标频率下的阻抗和直流电阻
- 常用型号：BLM18AG、BLM21PG
- 注意：磁珠在谐振频率以上变为容性

### 6.2 TVS 瞬态抑制

#### 6.2.1 TVS 选型要点

1. **反向截止电压 VRWM ≥ 电路正常工作电压**
2. **钳位电压 VC < 被保护器件最大耐受电压**
3. **峰值脉冲功率 IPP ≥ 预期浪涌电流 × VC**
4. **结电容 CJ ≤ 信号频率可承受值**

**常用 TVS 型号：**
| 型号 | VRWM | VC | CJ | 适用 |
|------|------|----|----|------|
| PESD5V0S1BA | 5V | 9.8V | 45pF | 低速 I/O |
| SMBJ5.0A | 5V | 9.2V | - | 电源 5V |
| SMBJ12A | 12V | 19.9V | - | 电源 12V |
| SMBJ24A | 24V | 38.9V | - | 电源 24V |
| PRTR5V0U2X | 5V | 14.5V | 0.7pF | USB |
| ESD5V3U2RSY | 5.3V | 10V | 0.5pF | 高速信号 |

#### 6.2.2 TVS 布局

- TVS 尽量靠近被保护端口（连接器）
- 接地焊盘到地平面的过孔要多且短
- 避免 TVS 接地路径阻抗过大（否则钳位效果差）

### 6.3 接地设计

#### 6.3.1 接地策略

**单点接地（串联/并联）：**
- 适合低频电路（< 1MHz）
- 避免地环路
- 数字地和模拟地单点连接

**多点接地：**
- 适合高频电路（> 10MHz）
- 地平面提供低阻抗回流路径
- 接地过孔要足够密

**混合接地：**
- 模拟与数字分区，单点连接
- 高频器件多点接地至地平面

#### 6.3.2 数字地与模拟地处理

```
数字 GND ────┐
            [0Ω 电阻 / 磁珠] ──── 模拟 GND
数字 GND ────┘
```

**推荐做法：**
- 统一地平面（不要分割），布局时分区
- ADC/DA 的模拟地引脚直接连接到模拟区域
- 避免数字信号回流经过模拟区域

#### 6.3.3 星形接地

所有接地线汇聚到一点，避免不同电路的接地电流互相干扰。适合音频等低噪声系统。

### 6.4 屏蔽设计

#### 6.4.1 屏蔽效能

- 电场屏蔽：高导电材料（铜、铝）
- 磁场屏蔽：高导磁材料（铁、坡莫合金）
- 平面波屏蔽：导电材料即可

**屏蔽效能 SE（dB）= 反射损耗 + 吸收损耗 + 多次反射修正**

#### 6.4.2 屏蔽实践

- **完整金属外壳：** 最佳，但成本高
- **PCB 局部屏蔽罩：** 焊接式屏蔽罩覆盖敏感区域
- **线缆屏蔽：** 屏蔽线缆单端或双端接地（低频单端，高频双端）
- **缝隙处理：** 缝隙长度 < λ/20，加导电衬垫

## 七、PCB 设计

### 7.1 布局布线

#### 7.1.1 布局原则

1. **按功能分区：** 电源区、数字区、模拟区、射频区
2. **信号流方向：** 输入在左，输出在右，避免回流
3. **关键器件优先：** CPU、晶振、电源等先布局
4. **去耦电容就近：** 每个电源引脚一个 100nF，靠近引脚
5. **热设计：** 大功率器件远离热敏元件，留散热空间

#### 7.1.2 布线规则

**线宽与电流关系（1oz 铜，温升 10°C）：**
| 线宽 (mil) | 电流 (A) | 线宽 (mm) |
|-----------|---------|----------|
| 10 | 0.5 | 0.254 |
| 15 | 0.8 | 0.381 |
| 20 | 1.0 | 0.508 |
| 30 | 1.5 | 0.762 |
| 50 | 2.5 | 1.27 |
| 100 | 4.0 | 2.54 |
| 200 | 7.0 | 5.08 |

**经验公式（IPC-2221）：**
$$I = K \times \Delta T^{0.44} \times A^{0.725}$$

其中 A 为截面积（mil²），ΔT 为温升（°C），K 为常数（外层 0.048，内层 0.024）。

**布线禁忌：**
- 直角走线（阻抗突变，反射）
- 长距离平行走线（串扰）
- 信号跨越地平面分割（回流路径断裂）
- 晶振下方走高速信号

#### 7.1.3 差分对布线

- 等长匹配：误差 < 5mil（高速信号）
- 等间距：维持恒定差分阻抗
- 对称走线：两条线长度、过孔数量一致
- 参考平面：下方需有完整参考层

### 7.2 阻抗控制

#### 7.2.1 特征阻抗

PCB 走线具有特征阻抗，高速信号需要匹配以减少反射。

**单端阻抗（微带线，表层）：**
$$Z_0 \approx \frac{87}{\sqrt{\varepsilon_r + 1.41}} \ln(\frac{5.98h}{0.8w + t})$$

其中 h = 介质厚度，w = 线宽，t = 铜厚，εr = 介电常数。

**差分阻抗：**
$$Z_{diff} = 2Z_0(1 - 0.48e^{-0.96\frac{s}{h}})$$

其中 s = 线间距。

#### 7.2.2 常见阻抗要求

| 接口 | 单端阻抗 | 差分阻抗 |
|------|---------|---------|
| USB 2.0 | - | 90Ω ± 10% |
| 以太网 100M | - | 100Ω ± 10% |
| HDMI | - | 100Ω ± 10% |
| DDR3/4 | 50Ω | 100Ω |
| CAN/RS485 | 120Ω（总线） | - |
| 射频 50Ω | 50Ω | - |

#### 7.2.3 阻抗计算工具

- Saturn PCB Toolkit（免费）
- 各 PCB 厂商阻抗计算器（如嘉立创阻抗计算）
- Altium Designer 内置阻抗计算器

### 7.3 去耦电容

#### 7.3.1 原理

数字 IC 切换时产生瞬态电流，电源走线电感会导致电压跌落。去耦电容提供本地电荷储备。

**不同频率段的电容组合：**
| 电容值 | 有效频率 | 用途 |
|-------|---------|------|
| 100μF 电解 | < 1kHz | 板级低频滤波 |
| 10μF MLCC | 1k-100kHz | 电源入口大容量 |
| 100nF MLCC | 100k-10MHz | 每个 IC 引脚 |
| 10nF MLCC | 1M-100MHz | 高频补充 |
| 1nF MLCC | 10M-500MHz | 特高频 |

#### 7.3.2 布局要点

- **100nF：** 紧贴 IC 电源引脚，过孔直连电源和地平面
- **10μF：** 每个电源芯片输出端，或电源入口
- **电容到引脚的走线要短：** 增加走线电感会降低高频效果
- **地过孔要近：** 电容接地端到地平面的过孔紧挨着

#### 7.3.3 电容并联问题

不同容值的 MLCC 并联可能出现反谐振（并联谐振），导致某频段阻抗反而增大。

**解决：** 使用同封装、相近容值的电容并联，或选择低 ESL 的多端电容。

### 7.4 走线宽度与载流能力

#### 7.4.1 PCB 铜厚标准

| 铜厚 | 厚度 (μm) | 常用名称 |
|------|----------|---------|
| 0.5oz | 17.5 | 薄铜 |
| 1oz | 35 | 标准 |
| 2oz | 70 | 厚铜 |
| 3oz | 105 | 大电流 |

#### 7.4.2 大电流走线技巧

1. **加宽走线：** 参照线宽电流表
2. **加铜厚：** 2oz 或 3oz 铜
3. **开窗镀锡：** 阻焊层开窗，走线上加锡增加截面积
4. **多层并联：** 多层 PCB 同一网络多层走线
5. **铜皮铺铜：** 电源走线直接铺铜
6. **外接铜排/导线：** 超大电流场景

## 附录：常用设计公式汇总

### 电源类
- LDO 功耗：$P = (V_{in} - V_{out}) \times I_{load}$
- Buck 输出：$V_{out} = D \times V_{in}$
- Boost 输出：$V_{out} = \frac{V_{in}}{1-D}$
- 电感纹波：$\Delta I = \frac{(V_{in} - V_{out}) \times D}{f \times L}$

### 运放类
- 反相放大：$V_{out} = -\frac{R_f}{R_1} V_{in}$
- 同相放大：$V_{out} = (1 + \frac{R_f}{R_1}) V_{in}$
- AD620 增益：$G = 1 + \frac{49.4k}{R_G}$

### 滤波器
- RC 低通：$f_c = \frac{1}{2\pi RC}$
- Sallen-Key 二阶：$f_c = \frac{1}{2\pi\sqrt{R_1 R_2 C_1 C_2}}$

### PCB
- 阻抗（微带线）：$Z_0 \approx \frac{87}{\sqrt{\varepsilon_r+1.41}} \ln(\frac{5.98h}{0.8w+t})$
- 载流（IPC-2221）：$I = K \times \Delta T^{0.44} \times A^{0.725}$
