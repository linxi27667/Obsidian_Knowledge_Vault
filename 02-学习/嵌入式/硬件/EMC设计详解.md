# EMC设计详解

## 核心概念

- **EMC** - 电磁兼容性
- **EMI** - 电磁干扰(发射)
- **EMS** - 电磁敏感度(抗扰)
- **CE** - 传导发射
- **RE** - 辐射发射

---

## 一、EMC基础

### 1.1 EMC三要素

```
干扰源 ──→ 耦合路径 ──→ 敏感设备
  │            │            │
  ├─ 开关电源   ├─ 传导      ├─ MCU
  ├─ 时钟信号   ├─ 辐射      ├─ ADC
  ├─ 电机驱动   ├─ 感应      ├─ 传感器
  └─ 继电器     └─ 耦合      └─ 通信接口
```

---

### 1.2 EMC标准

| 标准 | 类型 | 说明 |
|------|------|------|
| CISPR 11 | 工业设备 | 工科医设备 |
| CISPR 32 | 信息技术 | 信息技术设备 |
| IEC 61000-4-2 | ESD | 静电放电 |
| IEC 61000-4-4 | EFT | 快速瞬变脉冲群 |
| IEC 61000-4-5 | Surge | 浪涌 |
| IEC 61000-4-6 | CS | 传导抗扰度 |

### 1.3 频率与波长

|------|------|----------|

| 30MHz-1GHz | 10m-30cm | 辐射干扰 |

## 二、PCB级EMC设计

### 2.1 去耦电容

```c
// 去耦电容选型
/*
 * 陶瓷电容: 100nF (高频去耦)
 * 电解电容: 10μF-100μF (低频滤波)
 * 安装位置: 尽量靠近芯片电源引脚
 */

// 多级去耦方案
// VCC ──┤100μF├──┤10μF├──┤100nF├──┤10nF├── IC
//        电解    钽    陶瓷    陶瓷

// 去耦电容阻抗特性
/*
 * Z = ESR + jωL + 1/(jωC)
 *
 * 低频: Z ≈ 1/(ωC) → 电容主导
 * 谐振: Z = ESR → 最小阻抗
 * 高频: Z ≈ ωL → 电感主导(失效)
 */
```

---

### 2.2 接地设计

```c
// 接地策略
/*
 * 单点接地: 低频(<1MHz)
 *   ┌───┐   ┌───┐   ┌───┐
 *   │ A │   │ B │   │ C │
 *   └─┬─┘   └─┬─┘   └─┬─┘
 *     └───────┴───────┘
 *            GND
 *
 * 多点接地: 高频(>10MHz)
 *   ┌───┐   ┌───┐   ┌───┐
 *   │ A │   │ B │   │ C │
 *   └─┬─┘   └─┬─┘   └─┬─┘
 *  ═══╧═══════╧═══════╧═══ GND平面
 *
 * 混合接地: 中频(1-10MHz)
 */

// 地平面分割
/*
 * 数字地和模拟地:
 *   ┌─────────────────────────┐
 *   │  数字区域  │  模拟区域   │
 *   │           │            │
 *   │  MCU      │  ADC       │
 *   │  逻辑      │  传感器    │
 *   └───────────┴────────────┘
 *              │
 *          单点连接
 *              │
 *            GND
 */
```

### 2.3 PCB布局规则

```c
// 布局检查清单
/*
 * 1. 高速信号远离敏感信号
 * 2. 时钟线短且有地平面参考
 * 3. 模拟和数字区域分离
 * 4. 电源入口放置滤波电路
 * 5. 接插件靠近板边
 * 6. 晶振靠近芯片
 * 7. 去耦电容靠近电源引脚
 */

// 关键距离要求
/*
 * 信号间距: ≥ 2倍线宽(3W规则)
 * 高速信号: 用地平面隔离
 * 时钟线: 长度匹配，包地处理
 */
```

## 三、滤波设计

### 3.1 EMI滤波器

```c
// π型滤波器
/*
 *     L
 * ────┤├────
 * │         │
 * C1        C2
 * │         │
 * ───────────── GND
 *
 * 插入损耗: IL = 20*log(Vout/Vin)
 */

// 共模电感
/*
 * 火线 ──┐  ┌── 火线
 *        │╱│
 * 零线 ──┤  ├── 零线
 *        │╲│
 *
 * 差模信号: 磁通抵消 → 通过
 * 共模信号: 磁通叠加 → 抑制
 */
```

---

### 3.2 电源滤波

```c
// 电源输入滤波电路
/*
 * VIN ──┤FUSE├──┤TVS├──┤CM├──┤L├──┤C├── VOUT
 *                   │    │     │    │
 *                  GND  GND   GND  GND
 *
 * FUSE: 保险丝(过流保护)
 * TVS: 瞬态抑制(浪涌保护)
 * CM: 共模电感(共模噪声)
 * L: 差模电感(差模噪声)
 * C: 滤波电容(高频旁路)
 */

// LC滤波器设计
/*
 * 截止频率: fc = 1/(2π√(LC))
 *
 * 例: L=10μH, C=10μF
 * fc = 1/(2π√(10e-6 × 10e-6))
 * fc ≈ 15.9kHz
 */
```

## 四、屏蔽设计

### 4.1 金属屏蔽

```c
// 屏蔽效能
/*
 * SE = R + A + B (dB)
 *
 * R: 反射损耗
 *   R = 20*log(η₀/(4ηₛ))
 *   η₀ = 377Ω (自由空间)
 *   ηₛ = 金属表面阻抗
 *
 * A: 吸收损耗
 *   A = 0.131*t√(fμσ)
 *   t: 厚度(mm), f: 频率(MHz)
 *   μ: 相对磁导率, σ: 相对电导率
 *
 * B: 多次反射修正(薄屏蔽时)
 */

// 屏蔽材料选择
/*
 * 铜: 高导电，高频好
 * 铝: 轻便，中等性能
 * 钢: 高磁导率，低频好
 * 导电塑料: 轻便，中等屏蔽
 */
```

---

### 4.2 屏蔽完整性

```c
// 缝隙处理
/*

```

## 五、信号完整性

### 5.1 传输线效应

```c
// 临界长度
/*
 * 当信号上升时间 tr < 2×td (传输延迟)
 * 需要考虑传输线效应
 *
 * td = len/v (v ≈ 15cm/ns for FR4)
 *
 * 例: tr=1ns, 临界长度 = 1ns × 15cm/ns / 2 = 7.5cm
 */

// 特性阻抗
/*
 * 微带线: Z₀ ≈ (87/√(εr+1.41)) × ln(5.98h/(0.8w+t))
 * 带状线: Z₀ ≈ (60/√εr) × ln(4h/(0.67π(0.8w+t)))
 *
 * εr: 介电常数(FR4≈4.4)
 * h: 介质厚度, w: 线宽, t: 铜厚
 */
```

---

### 5.2 阻抗匹配

```c
// 端接策略
/*
 * 串联端接(源端匹配):
 *   源 ──┤R├──────────── 负载
 *         R = Z₀ - Zs
 *
 * 并联端接(终端匹配):
 *   源 ──────────────┬── 负载
 *                     │
 *                     R (= Z₀)
 *                     │
 *                    GND
 *
 * 戴维南端接:
 *   源 ──────────────┬── 负载
 *                   │
 *                   R1 (= Z₀)
 *                   │
 *                   R2 (= Z₀)
 *                   │
 *                  GND
 */
```

## 六、ESD防护

### 6.1 ESD防护器件

```c
// ESD防护器件对比
/*
 * 器件      响应速度  钳位电压  寄生电容
 * TVS       <1ns     低       5-50pF
 * MLV       <1ns     中       100-1000pF
 * GDT       μs       低       <1pF
 * ESD二极管 <1ns     低       0.5-5pF
 */

// TVS选型
/*
 * 1. 钳位电压 < 芯片最大耐压
 * 2. 响应时间 < ESD脉冲上升时间
 * 3. 寄生电容 < 信号频率允许值
 * 4. 反向击穿电压 > 信号最大电压
 */
```

## 九、软件级EMC措施

### 9.1 数字滤波

```c
// 软件滤波抗干扰
float emc_moving_average(float new_val) {
    static float buf[8] = {0};
    static int idx = 0;
    float sum = 0;

    buf[idx] = new_val;
    idx = (idx + 1) % 8;

    for (int i = 0; i < 8; i++) sum += buf[i];
    return sum / 8.0f;
}

// 中值滤波(去除脉冲干扰)
float emc_median_filter(float *samples, int n) {
    // 排序
    for (int i = 0; i < n-1; i++) {
        for (int j = i+1; j < n; j++) {
            if (samples[j] < samples[i]) {
                float t = samples[i];
                samples[i] = samples[j];
                samples[j] = t;
            }
        }
    }
    return samples[n/2];
}
```

### 9.2 冗余与校验

```c
// 多次采样表决
bool emc_vote_read(void) {
    int count = 0;
    for (int i = 0; i < 5; i++) {
        if (read_sensor() > THRESHOLD) count++;
    }
    return count >= 3;  // 3/5表决
}

// 数据校验
uint16_t emc_crc16(const uint8_t *data, int len) {
    uint16_t crc = 0xFFFF;
    for (int i = 0; i < len; i++) {
        crc ^= data[i];
        for (int j = 0; j < 8; j++) {
            if (crc & 1) crc = (crc >> 1) ^ 0xA001;
            else crc >>= 1;
        }
    }
    return crc;
}
```
