# 模拟电子技术

## 核心概念

- **半导体** - 导电能力介于导体和绝缘体之间的材料
- **PN结** - P型和N型半导体的结合处，具有单向导电性
- **放大** - 用小信号控制大信号的输出
- **反馈** - 将输出信号的一部分送回输入端

---

## 一、半导体基础

### 1.1 本征半导体

**硅(Si)和锗(Ge)的特性：**
- 四价元素，形成共价键
- 温度升高，导电能力增强
- 载流子：电子和空穴

**载流子浓度：**
$$n_i^2 = np$$

---

### 1.2 掺杂半导体

| 类型 | 掺杂元素 | 多数载流子 | 少数载流子 |
|------|---------|-----------|-----------|
| N型 | 磷(P)、砷(As) | 电子 | 空穴 |
| P型 | 硼(B)、镓(Ga) | 空穴 | 电子 |

---

### 1.3 PN结

**形成过程：**
```
P型    │    N型
───────┼───────
 空穴 → │ ← 电子
       ↓
    耗尽层
       ↓
    内建电场
```

**特性：**
- **正向偏置** - P接正，N接负，导通
- **反向偏置** - P接负，N接正，截止
- **击穿** - 反向电压过大，失去单向导电性

**伏安特性：**
$$I = I_S(e^{U/U_T} - 1)$$

其中：$U_T = kT/q \approx 26mV$（室温）

---

## 二、二极管

### 2.1 基本特性

**符号：**
```
  ──▶|──
  阳极  阴极
```

**主要参数：**
| 参数 | 符号 | 说明 |
|------|------|------|
| 正向压降 | VF | 硅管约0.7V，锗管约0.3V |
| 最大正向电流 | IFM | 允许通过的最大正向电流 |
| 反向击穿电压 | VBR | 反向击穿时的电压 |
| 反向饱和电流 | IS | 反向偏置时的微小电流 |

---

### 2.2 二极管应用

#### 整流电路

**半波整流：**
```
  ┌─────────────────────┐
  │                     │
  │   ┌───┐    ┌───┐   │
  ├───┤ D ├───┤RL ├───┤
  │   └───┘    └───┘   │
  │                     │
  └─────────────────────┘

输出平均电压：Uo = 0.45U2
```

**全波整流：**
```
输出平均电压：Uo = 0.9U2
```

**桥式整流：**
```
输出平均电压：Uo = 0.9U2
纹波系数较小
```

---

#### 稳压电路

**稳压二极管特性：**
- 工作在反向击穿区
- 电流变化大，电压变化小
- 稳定电压：VZ

**稳压电路：**
```
        R
  ──┤├──┬──
        │
       VZ        → Uo = VZ
        │
  ──────┴──
```

## 三、三极管

### 3.1 结构与符号

**NPN型：**
```
    C (集电极)
    │
    │
B ──┤    (基极)
    │
    │
    E (发射极)
```

**PNP型：**
```
    E (发射极)
    │
    │
B ──┤    (基极)
    │
    │
    C (集电极)
```

---

### 3.2 三种工作状态

| 状态 | 发射结 | 集电结 | 特点 |
|------|--------|--------|------|
| 放大 | 正偏 | 反偏 | IC = βIB |
| 饱和 | 正偏 | 正偏 | VCE ≈ 0.3V |
| 截止 | 反偏 | 反偏 | IC ≈ 0 |

---

### 3.3 电流放大系数

**共射电流放大系数：**
$$\beta = \frac{I_C}{I_B}$$

**共基电流放大系数：**
$$\alpha = \frac{I_C}{I_E}$$

**关系：**
$$\beta = \frac{\alpha}{1-\alpha}$$

---

### 3.4 三极管主要参数

| 参数 | 符号 | 说明 |
|------|------|------|
| 电流放大系数 | β | 典型值50-200 |
| 集电极最大电流 | ICM | 允许的最大集电极电流 |
| 集电极最大功耗 | PCM | 允许的最大功耗 |
| 集-射击穿电压 | V(BR)CEO | 集电极-发射极击穿电压 |
| 特征频率 | fT | β=1时的频率 |

---

## 四、基本放大电路

### 4.1 共射放大电路

**电路结构：**
```
       VCC
        │
        Rb    Rc
        │     │
  ──┤├──┴──┬──┤├──┬──
           │       │
          B       C
           │       │
           └───┬───┘
               │
              E
               │
              ─┴─
```

**静态工作点：**
$$I_{BQ} = \frac{V_{CC} - V_{BE}}{R_b}$$
$$I_{CQ} = \beta I_{BQ}$$
$$V_{CEQ} = V_{CC} - I_{CQ}R_c$$

**电压放大倍数：**
$$A_v = -\frac{\beta R_L'}{r_{be}}$$

其中：$R_L' = R_c // R_L$

**输入电阻：**
$$R_i = R_b // r_{be}$$

**输出电阻：**
$$R_o = R_c$$

---

### 4.2 共集放大电路（射极跟随器）

**特点：**
- 电压放大倍数≈1
- 输入电阻高
- 输出电阻低
- 无电压放大，有电流放大

**应用：** 阻抗匹配、缓冲级

---

### 4.3 共基放大电路

**特点：**
- 电压放大倍数高
- 输入电阻低
- 输出电阻高
- 高频特性好

**应用：** 高频放大

---

## 五、场效应管

### 5.1 MOSFET结构

**N沟道增强型：**
```
    S (源极)
    │
    │
G ──┤    (栅极)
    │
    │
    D (漏极)
```

**符号：**
```
  G
  │
  ├────
  │
  └────
  D     S
```

---

### 5.2 MOSFET特性

**转移特性：**
$$I_D = K(V_{GS} - V_{th})^2$$

**输出特性：**
- 截止区：VGS < Vth
- 可变电阻区：VGD > Vth
- 恒流区（饱和区）：VGD < Vth

---

### 5.3 MOSFET主要参数

| 参数 | 符号 | 说明 |
|------|------|------|
| 开启电压 | Vth | 开始导电的VGS |
| 跨导 | gm | gm = ΔID/ΔVGS |
| 最大漏极电流 | IDM | 允许的最大电流 |
| 最大功耗 | PDM | 允许的最大功耗 |

## 六、运算放大器

### 6.1 理想运放特性

**虚短虚断：**
- **虚短** - V+ ≈ V-（两输入端电压相等）
- **虚断** - I+ = I- = 0（两输入端电流为零）

---

### 6.2 基本运算电路

#### 反相比例放大器

```
       Rf
  ──┤├──┬──
        │
  R1    │
  │     │
  ├───┤-  ├──
  │   │   │
  │  (+)  │
  │   │   │
  └───┴───┘
```

**输出：**
$$V_o = -\frac{R_f}{R_1} V_i$$

---

#### 同相比例放大器

```
  Vi ──┤+  ├── Vo
       │   │
  R1   │   │
  ├────┤-  │
  │    │   │
  Rf   │   │
  │    │   │
  └────┴───┘
```

**输出：**
$$V_o = (1 + \frac{R_f}{R_1}) V_i$$

---

#### 加法器

$$V_o = -R_f(\frac{V_1}{R_1} + \frac{V_2}{R_2} + \frac{V_3}{R_3})$$

---

#### 积分器

$$V_o = -\frac{1}{RC} \int V_i dt$$

---

#### 微分器

$$V_o = -RC \frac{dV_i}{dt}$$

---

### 6.3 有源滤波器

#### 低通滤波器

**一阶RC有源低通：**
$$f_c = \frac{1}{2\pi RC}$$

**幅频特性：**
- 通带：f < fc，增益恒定
- 阻带：f > fc，-20dB/dec衰减

---

#### 高通滤波器

$$f_c = \frac{1}{2\pi RC}$$

**幅频特性：**
- 阻带：f < fc，-20dB/dec衰减
- 通带：f > fc，增益恒定

---

#### 带通滤波器

$$f_0 = \sqrt{f_L f_H}$$

$$Q = \frac{f_0}{f_H - f_L}$$

---

## 七、反馈

### 7.1 反馈类型

| 分类方式 | 类型 | 特点 |
|---------|------|------|
| 正/负反馈 | 正反馈 | 增强输入信号 |
| | 负反馈 | 削弱输入信号 |
| 串/并联 | 串联反馈 | 提高输入电阻 |
| | 并联反馈 | 降低输入电阻 |
| 电压/电流 | 电压反馈 | 稳定输出电压 |
| | 电流反馈 | 稳定输出电流 |

---

### 7.2 负反馈对性能的影响

**改善效果：**
1. **提高增益稳定性** - 降低增益变化
2. **展宽频带** - 带宽增加(1+AF)倍
3. **减小非线性失真** - 改善线性度
4. **改变输入/输出电阻** - 取决于反馈类型

**增益公式：**
$$A_f = \frac{A}{1 + AF}$$

其中：A为开环增益，F为反馈系数，(1+AF)为反馈深度

### 8.1 功率放大电路特点

- 输出功率大
- 效率高
- 非线性失真小
- 散热良好

### 8.2 乙类互补对称电路

**电路结构：**
```
       VCC
        │
        │
  ──┤├──┴──┬──
           │
    NPN ──┤├── PNP
           │
           │
  ─────────┴── Vo
```

**效率：**
$$\eta = \frac{\pi}{4} \approx 78.5\%$$

**交越失真：** 由于三极管存在死区电压
