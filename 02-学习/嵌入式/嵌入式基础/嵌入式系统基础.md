# 嵌入式系统基础

## 核心概念

- **嵌入式系统** - 专用计算系统
- **实时性** - 时间约束
- **资源受限** - 内存、功耗限制
- **可靠性** - 长期稳定运行

---

## 一、嵌入式系统定义

### 1.1 系统特征

```
嵌入式系统特点:
├── 专用性: 针对特定任务设计
├── 实时性: 有时间约束要求
├── 资源受限: 内存、处理能力有限
├── 高可靠性: 长期稳定运行
├── 低功耗: 电池供电场景多
└── 软硬件协同: 硬件加速、软件优化
```

### 1.2 系统分类

```c
// 按实时性分类
typedef enum {
    EMB_HARD_RT,    // 硬实时(毫秒级, 如汽车ABS)
    EMB_SOFT_RT,    // 软实时(秒级, 如视频播放)
    EMB_NON_RT,     // 非实时(如手机)
} realtime_type_t;

// 按复杂度分类
typedef enum {
    EMB_BARE_METAL,  // 裸机(无OS)
    EMB_RTOS,        // 实时操作系统
    EMB_LINUX,       // 嵌入式Linux
    EMB_ANDROID,     // 嵌入式Android
} complexity_t;
```

## 二、硬件基础

### 2.1 处理器类型

```
嵌入式处理器:
├── MCU(微控制器)
│   ├── ARM Cortex-M0/M0+  (低功耗)
│   ├── ARM Cortex-M3/M4   (主流)
│   ├── ARM Cortex-M7      (高性能)
│   └── RISC-V (新兴)
├── MPU(微处理器)
│   ├── ARM Cortex-A7/A53  (应用处理器)
│   └── ARM Cortex-A72     (高性能)
├── DSP(数字信号处理器)
│   └── TI C6000系列
└── FPGA(可编程逻辑)
    └── Xilinx/Altera
```

## 三、软件架构

### 3.1 裸机架构

```c
// 裸机主循环
int main(void) {
    // 系统初始化
    system_init();
    peripheral_init();

    while (1) {
        // 轮询任务
        poll_sensors();
        process_data();
        update_display();
        check_communication();

        // 低功耗等待
        __wfi();
    }
}

// 超级循环的局限
/*
 * 优点:
 * - 简单，无OS开销
 * - 资源占用最小
 * - 确定性强
 *
 * 缺点:
 * - 任务间无隔离
 * - 难以处理复杂时序
 * - 阻塞操作影响响应
 */
```

### 3.2 RTOS架构

```c
// RTOS任务划分
void sensor_task(void *param) {
    while (1) {
        float temp = read_temperature();
        float humidity = read_humidity();

        // 发送到处理任务
        xQueueSend(data_queue, &(sensor_data_t){temp, humidity}, 0);

        vTaskDelay(pdMS_TO_TICKS(1000));
    }
}

void process_task(void *param) {
    sensor_data_t data;
    while (1) {
        if (xQueueReceive(data_queue, &data, portMAX_DELAY)) {
            // 处理数据
            float heat_index = calc_heat_index(data.temp, data.humidity);

            // 发送到显示任务
            xQueueSend(display_queue, &heat_index, 0);
        }
    }
}

void display_task(void *param) {
    float heat_index;
    while (1) {
        if (xQueueReceive(display_queue, &heat_index, portMAX_DELAY)) {
            // 更新显示
            update_lcd(heat_index);
        }
    }
}
```

 * 用户空间:

## 五、低功耗设计

### 5.1 功耗模式

```c
// STM32功耗模式
typedef enum {
    PM_RUN,           // 运行模式(~100mA)
    PM_SLEEP,         // 睡眠模式(~20mA)
    PM_STOP,          // 停止模式(~20μA)
    PM_STANDBY,       // 待机模式(~2μA)
} power_mode_t;

// 功耗模式切换
void enter_sleep_mode(void) {
    // 配置唤醒源(定时器、外部中断)
    configure_wakeup_source();

    // 进入睡眠模式
    __WFI();
}

void enter_stop_mode(void) {
    // 配置唤醒源
    configure_wakeup_source();

    // 进入停止模式
    HAL_PWR_EnterSTOPMode(PWR_LOWPOWERREGULATOR_ON, PWR_STOPENTRY_WFI);
}

void enter_standby_mode(void) {
    // 配置唤醒引脚
    HAL_PWR_EnableWakeUpPin(PWR_WAKEUP_PIN1);

    // 进入待机模式
    HAL_PWR_EnterSTANDBYMode();
}
```

## 六、可靠性设计

### 6.1 看门狗

// 独立看门狗
void iwdg_init(uint32_t timeout_ms) {
    // IWDG时钟: 32kHz LSI
    uint32_t reload = (timeout_ms * 32) / (4 * 1000);

    IWDG->KR = 0x5555;   // 允许写入
    IWDG->PR = 0;         // 分频器=4
    IWDG->RLR = reload;
    IWDG->KR = 0xCCCC;   // 启动看门狗
}

void iwdg_feed(void) {
    IWDG->KR = 0xAAAA;   // 喂狗
}

// 窗口看门狗
void wwdg_init(void) {
    WWDG->CFR = 0x7F;    // 窗口值
    WWDG->CR = 0x7F;     // 计数器
    WWDG->CR |= WWDG_CR_WDGA;  // 启动
}

void wwdg_feed(void) {
    WWDG->CR = 0x7F;     // 喂狗
}

### 6.2 错误处理

```c
// 错误码定义
typedef enum {
    ERR_NONE = 0,
    ERR_TIMEOUT,
    ERR_OVERFLOW,
    ERR_UNDERFLOW,
    ERR_CRC,
    ERR_PARITY,
    ERR_OVERRUN,
    ERR_UNDERRUN,
} error_code_t;

// 错误处理框架
typedef struct {
    error_code_t code;
    const char *file;
    int line;
    uint32_t timestamp;
} error_record_t;

#define RECORD_ERROR(code) do { \
    error_record_t rec = {code, __FILE__, __LINE__, get_tick()}; \
    log_error(&rec); \
} while(0)

// 错误恢复
void error_recovery(error_code_t code) {
    switch (code) {
        case ERR_TIMEOUT:
            // 重试操作
            retry_operation();
            break;
        case ERR_CRC:
            // 请求重传
            request_retransmit();
            break;
        case ERR_OVERRUN:
            // 清空缓冲区
            clear_buffer();
            break;
        default:
            // 未知错误，复位
            system_reset();
            break;
    }
}
```
