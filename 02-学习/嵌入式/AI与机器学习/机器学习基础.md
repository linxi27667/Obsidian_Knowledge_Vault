## 二、线性模型

### 2.1 线性回归

**模型：**
$$y = w_0 + w_1 x_1 + w_2 x_2 + ... + w_n x_n$$

**损失函数（MSE）：**
$$L = \frac{1}{2m} \sum_{i=1}^{m} (y_i - \hat{y}_i)^2$$

**梯度下降：**
$$w_j := w_j - \alpha \frac{\partial L}{\partial w_j}$$

**代码实现：**
```python
import numpy as np

class LinearRegression:
    def __init__(self, lr=0.01, n_iters=1000):
        self.lr = lr
        self.n_iters = n_iters
        
    def fit(self, X, y):
        n_samples, n_features = X.shape
        self.weights = np.zeros(n_features)
        self.bias = 0
        
        for _ in range(self.n_iters):
            y_pred = np.dot(X, self.weights) + self.bias
            
            dw = (1/n_samples) * np.dot(X.T, (y_pred - y))
            db = (1/n_samples) * np.sum(y_pred - y)
            
            self.weights -= self.lr * dw
            self.bias -= self.lr * db
            
    def predict(self, X):
        return np.dot(X, self.weights) + self.bias
```

### 2.2 逻辑回归

**模型：**
$$P(y=1|x) = \sigma(w^T x + b)$$

**Sigmoid函数：**
$$\sigma(z) = \frac{1}{1 + e^{-z}}$$

**损失函数（交叉熵）：**
$$L = -\frac{1}{m} \sum [y \log(\hat{y}) + (1-y) \log(1-\hat{y})]$$

**代码实现：**
```python
class LogisticRegression:
    def __init__(self, lr=0.01, n_iters=1000):
        self.lr = lr
        self.n_iters = n_iters
        
    def sigmoid(self, z):
        return 1 / (1 + np.exp(-z))
        
    def fit(self, X, y):
        n_samples, n_features = X.shape
        self.weights = np.zeros(n_features)
        self.bias = 0
        
        for _ in range(self.n_iters):
            linear = np.dot(X, self.weights) + self.bias
            y_pred = self.sigmoid(linear)
            
            dw = (1/n_samples) * np.dot(X.T, (y_pred - y))
            db = (1/n_samples) * np.sum(y_pred - y)
            
            self.weights -= self.lr * dw
            self.bias -= self.lr * db
            
    def predict(self, X):
        linear = np.dot(X, self.weights) + self.bias
        y_pred = self.sigmoid(linear)
        return [1 if p > 0.5 else 0 for p in y_pred]
```

## 三、神经网络

### 3.1 感知机

**模型：**
$$y = f(\sum w_i x_i + b)$$

**激活函数：**
- 阶跃函数
- Sigmoid
- ReLU

---

### 3.2 多层感知机(MLP)

**结构：**
```
输入层 → 隐藏层1 → 隐藏层2 → 输出层
```

**前向传播：**
$$z^{(l)} = W^{(l)} a^{(l-1)} + b^{(l)}$$
$$a^{(l)} = f(z^{(l)})$$

**反向传播：**
$$\delta^{(L)} = \nabla_a L \odot f'(z^{(L)})$$
$$\delta^{(l)} = (W^{(l+1)})^T \delta^{(l+1)} \odot f'(z^{(l)})$$

**代码实现：**
```python
class NeuralNetwork:
    def __init__(self, layers):
        self.layers = layers
        self.weights = []
        self.biases = []
        
        for i in range(len(layers)-1):
            w = np.random.randn(layers[i], layers[i+1]) * 0.01
            b = np.zeros((1, layers[i+1]))
            self.weights.append(w)
            self.biases.append(b)
    
    def relu(self, z):
        return np.maximum(0, z)
    
    def relu_derivative(self, z):
        return (z > 0).astype(float)
    
    def forward(self, X):
        self.activations = [X]
        self.z_values = []
        
        for i in range(len(self.weights)):
            z = np.dot(self.activations[-1], self.weights[i]) + self.biases[i]
            self.z_values.append(z)
            
            if i == len(self.weights) - 1:
                a = self.softmax(z)
            else:
                a = self.relu(z)
            self.activations.append(a)
        
        return self.activations[-1]
    
    def backward(self, X, y, lr):
        m = X.shape[0]
        deltas = [self.activations[-1] - y]
        
        for i in range(len(self.weights)-2, -1, -1):
            delta = np.dot(deltas[0], self.weights[i+1].T) * self.relu_derivative(self.z_values[i])
            deltas.insert(0, delta)
        
        for i in range(len(self.weights)):
            self.weights[i] -= lr * np.dot(self.activations[i].T, deltas[i]) / m
            self.biases[i] -= lr * np.sum(deltas[i], axis=0, keepdims=True) / m
```

---

### 3.3 激活函数

| 函数 | 公式 | 特点 |
|------|------|------|
| Sigmoid | 1/(1+e^-z) | 输出0-1，梯度消失 |
| Tanh | (e^z-e^-z)/(e^z+e^-z) | 输出-1~1，零中心 |
| ReLU | max(0,z) | 简单高效，神经元死亡 |
| Leaky ReLU | max(0.01z,z) | 解决死亡问题 |
| ELU | z>0:z, z<0:α(e^z-1) | 零中心，负值 |
| Swish | z·σ(z) | 自门控 |
| GELU | z·Φ(z) | Transformer常用 |

---

### 3.4 优化算法

**SGD（随机梯度下降）：**
$$w := w - \alpha \nabla L$$

**Momentum：**
$$v := \beta v + \alpha \nabla L$$
$$w := w - v$$

**Adam：**
$$m := \beta_1 m + (1-\beta_1) \nabla L$$
$$v := \beta_2 v + (1-\beta_2) (\nabla L)^2$$
$$w := w - \alpha \frac{m}{\sqrt{v} + \epsilon}$$

## 四、卷积神经网络(CNN)

### 4.1 卷积层

**操作：**
```
输入特征图 × 卷积核 = 输出特征图
```

**参数：**
- 卷积核大小
- 步长(Stride)
- 填充(Padding)
- 输出通道数

**计算输出尺寸：**
$$O = \frac{I - K + 2P}{S} + 1$$

### 4.4 MobileNet (嵌入式友好)

**深度可分离卷积：**
- 深度卷积：每个通道单独卷积
- 逐点卷积：1×1卷积合并通道

**计算量对比：**
- 标准卷积：Dk·Dk·M·N·Df·Df
- 深度可分离：Dk·Dk·M·Df·Df + M·N·Df·Df

**代码实现：**
```python
class DepthwiseSeparableConv(nn.Module):
    def __init__(self, in_channels, out_channels, stride=1):
        super().__init__()
        self.depthwise = nn.Conv2d(in_channels, in_channels, 3, 
                                   stride, 1, groups=in_channels)
        self.pointwise = nn.Conv2d(in_channels, out_channels, 1)
        self.bn1 = nn.BatchNorm2d(in_channels)
        self.bn2 = nn.BatchNorm2d(out_channels)
        
    def forward(self, x):
        x = F.relu(self.bn1(self.depthwise(x)))
        x = F.relu(self.bn2(self.pointwise(x)))
        return x
```

## 五、循环神经网络(RNN)

### 5.1 基本RNN

**结构：**
$$h_t = f(W_h h_{t-1} + W_x x_t + b)$$
$$y_t = g(W_y h_t + c)$$

**问题：** 梯度消失/爆炸

---

### 5.2 LSTM

**门控机制：**
- 遗忘门：决定丢弃哪些信息
- 输入门：决定添加哪些信息
- 输出门：决定输出哪些信息

**公式：**
$$f_t = \sigma(W_f [h_{t-1}, x_t] + b_f)$$
$$i_t = \sigma(W_i [h_{t-1}, x_t] + b_i)$$
$$\tilde{C}_t = \tanh(W_C [h_{t-1}, x_t] + b_C)$$
$$C_t = f_t \odot C_{t-1} + i_t \odot \tilde{C}_t$$
$$o_t = \sigma(W_o [h_{t-1}, x_t] + b_o)$$
$$h_t = o_t \odot \tanh(C_t)$$

---

### 5.3 GRU

**简化的门控：**
$$z_t = \sigma(W_z [h_{t-1}, x_t])$$
$$r_t = \sigma(W_r [h_{t-1}, x_t])$$
$$\tilde{h}_t = \tanh(W [r_t \odot h_{t-1}, x_t])$$
$$h_t = (1-z_t) \odot h_{t-1} + z_t \odot \tilde{h}_t$$

## 六、Transformer

### 6.1 自注意力机制

**计算：**
$$Attention(Q,K,V) = softmax(\frac{QK^T}{\sqrt{d_k}})V$$

**多头注意力：**
$$MultiHead(Q,K,V) = Concat(head_1,...,head_h)W^O$$
$$head_i = Attention(QW_i^Q, KW_i^K, VW_i^V)$$

---

### 6.2 Transformer架构

```
输入 → 位置编码 → [自注意力 → 前馈网络] × N → 输出
```

**位置编码：**
$$PE_{(pos,2i)} = \sin(pos/10000^{2i/d})$$
$$PE_{(pos,2i+1)} = \cos(pos/10000^{2i/d})$$

### 7.3 知识蒸馏

```python
class DistillationModel(nn.Module):
    def __init__(self, teacher, student):
        super().__init__()
        self.teacher = teacher
        self.student = student
        
    def forward(self, x):
        teacher_out = self.teacher(x)
        student_out = self.student(x)
        return teacher_out, student_out

def distillation_loss(y_pred, y_true, teacher_pred, temperature=3):
    soft_teacher = F.softmax(teacher_pred / temperature, dim=1)
    soft_student = F.log_softmax(y_pred / temperature, dim=1)
    distill_loss = F.kl_div(soft_student, soft_teacher, reduction='batchmean')
    hard_loss = F.cross_entropy(y_pred, y_true)
    return 0.7 * distill_loss + 0.3 * hard_loss
```

### 10.3 学习率调度

**余弦退火：**
$$\eta_t = \eta_{min} + \frac{1}{2}(\eta_{max} - \eta_{min})(1 + \cos(\frac{t}{T}\pi))$$

$$\eta_t = \eta_{max} \cdot \frac{t}{T_{warmup}}$$
