# 传感器技术

## 核心概念

- **传感器** - 能感受被测量并按一定规律转换成可用输出信号的器件
- **精度** - 测量值与真实值的接近程度
- **分辨率** - 能检测到的最小变化量
- **响应时间** - 从输入变化到输出稳定的时间

---

## 一、传感器基础

### 1.1 传感器分类

| 分类方式 | 类型 | 示例 |
|---------|------|------|
| 按被测量 | 温度、压力、光、运动 | DS18B20, BMP280 |
| 按输出信号 | 模拟、数字 | ADC, I2C/SPI |
| 按工作原理 | 电阻、电容、电感、光电 | 应变片, 光敏电阻 |
| 按能量关系 | 自源型、外源型 | 热电偶, 应变片 |

---

### 1.2 传感器特性参数

| 参数 | 符号 | 说明 |
|------|------|------|
| 量程 | - | 测量范围 |
| 精度 | - | 测量误差 |
| 分辨率 | - | 最小可检测变化 |
| 灵敏度 | S | 输出变化/输入变化 |
| 线性度 | - | 输出与输入的线性关系 |
| 响应时间 | τ | 达到稳定的时间 |
| 重复性 | - | 多次测量的一致性 |
| 漂移 | - | 输出随时间的变化 |

---

### 1.3 信号调理

**放大电路：**
```
传感器 → 放大器 → ADC → MCU
```

**滤波：**
- 低通滤波：去除高频噪声
- 高通滤波：去除低频漂移
- 带通滤波：提取特定频段

**ADC转换：**
$$Digital = \frac{V_{in}}{V_{ref}} \times 2^n$$

## 二、温度传感器

### 2.1 热敏电阻(NTC)

**原理：** 温度升高，电阻降低

**Steinhart-Hart方程：**
$$\frac{1}{T} = A + B\ln(R) + C(\ln(R))^3$$

**简化公式（B值方程）：**
$$R_T = R_0 \times e^{B(\frac{1}{T} - \frac{1}{T_0})}$$

**电路：**
```
VCC ──┬── R_fixed ──┬── ADC
      │             │
      │   NTC       │
      │             │
GND ──┴─────────────┘
```

**温度计算：**
```c
float ntc_to_temp(float adc_value) {
    float R = R_FIXED * adc_value / (4096 - adc_value);
    float temp = 1.0 / (1.0/T0 + log(R/R0)/B) - 273.15;
    return temp;
}
```

---

### 2.2 DS18B20 (数字温度传感器)

**特点：**
- 单总线(1-Wire)接口
- 分辨率：9-12位
- 精度：±0.5°C
- 测量范围：-55°C ~ +125°C

**通信协议：**
```
初始化：
主机 ──┬── 480μs低 ──┐
       │              │
       └── 等待响应 ──┘

写时序：
写1：拉低1μs，释放，等待60μs
写0：拉低60μs，释放，等待1μs

读时序：
拉低1μs，释放，15μs内读取
```

**ESP-IDF驱动：**
```c
// 初始化
onewire_bus_install(&bus_config);
ds18b20_new_device(bus, &ds18b20_config, &sensor);

// 读取温度
float temp;
ds18b20_get_temperature(sensor, &temp);
```

---

### 2.3 BME280 (温湿度气压传感器)

**特点：**
- I2C/SPI接口
- 温度：-40°C ~ +85°C，±1°C
- 湿度：0-100%，±3%
- 气压：300-1100hPa，±1hPa

**I2C地址：** 0x76 或 0x77

**寄存器：**
| 寄存器 | 地址 | 说明 |
|--------|------|------|
| temp_msb | 0xFA | 温度高位 |
| temp_lsb | 0xFB | 温度低位 |
| press_msb | 0xF7 | 气压高位 |
| hum_msb | 0xFD | 湿度高位 |

**驱动代码：**
```c
// 读取原始数据
int32_t raw_temp = read_reg(0xFA) << 12 | read_reg(0xFB) << 4 | read_reg(0xFC);
int32_t raw_press = read_reg(0xF7) << 12 | read_reg(0xF8) << 4 | read_reg(0xF9);
int32_t raw_hum = read_reg(0xFD) << 8 | read_reg(0xFE);

// 补偿计算
float temp = compensate_temp(raw_temp);
float press = compensate_press(raw_press);
float hum = compensate_hum(raw_hum);
```

**冷端补偿：**
$$T_{actual} = T_{measured} + T_{cold}$$

## 三、惯性传感器

### 3.1 加速度计

**原理：** 检测加速度引起的惯性力

**MEMS结构：**
```
固定梳齿 ──┬── 可动质量块 ──┬── 固定梳齿
           │               │
           └── 弹簧 ───────┘
```

**输出：**
$$a = \frac{V_{out} - V_{offset}}{Sensitivity}$$

**应用：**
- 姿态检测
- 计步器
- 振动检测
- 自由落体检测

---

### 3.2 陀螺仪

**原理：** 科里奥利效应

**MEMS结构：**
```
振动质量块 ──→ 科里奥利力 ──→ 检测电极
```

**输出：** 角速度 (°/s)

**积分得到角度：**
$$\theta = \int \omega \, dt$$

---

### 3.3 MPU6050 (6轴IMU)

**特点：**
- 3轴加速度计 + 3轴陀螺仪
- I2C接口
- 16位ADC
- 可配置量程

**量程配置：**
| 量程 | 加速度 | 陀螺仪 |
|------|--------|--------|
| 最小 | ±2g | ±250°/s |
| 最大 | ±16g | ±2000°/s |

**寄存器：**
| 寄存器 | 地址 | 说明 |
|--------|------|------|
| WHO_AM_I | 0x75 | 设备ID (0x68) |
| PWR_MGMT_1 | 0x6B | 电源管理 |
| ACCEL_XOUT_H | 0x3B | 加速度X高位 |
| GYRO_XOUT_H | 0x43 | 陀螺仪X高位 |

**驱动代码：**
```c
// 初始化
i2c_write_reg(MPU6050_ADDR, PWR_MGMT_1, 0x00);  // 唤醒
i2c_write_reg(MPU6050_ADDR, ACCEL_CONFIG, 0x00);  // ±2g
i2c_write_reg(MPU6050_ADDR, GYRO_CONFIG, 0x00);   // ±250°/s

// 读取数据
int16_t ax = (read_reg(0x3B) << 8) | read_reg(0x3C);
int16_t ay = (read_reg(0x3D) << 8) | read_reg(0x3E);
int16_t az = (read_reg(0x3F) << 8) | read_reg(0x40);
int16_t gx = (read_reg(0x43) << 8) | read_reg(0x44);
int16_t gy = (read_reg(0x45) << 8) | read_reg(0x46);
int16_t gz = (read_reg(0x47) << 8) | read_reg(0x48);

// 转换
float accel_x = ax / 16384.0;  // ±2g
float gyro_x = gx / 131.0;    // ±250°/s
```

---

### 3.4 姿态解算

**欧拉角：**
- 横滚角(Roll)：绕X轴旋转
- 俯仰角(Pitch)：绕Y轴旋转
- 偏航角(Yaw)：绕Z轴旋转

**互补滤波：**
$$angle = 0.98 \times (angle + gyro \times dt) + 0.02 \times accel\_angle$$

**卡尔曼滤波：**
```
预测：
x_predict = A * x + B * u
P_predict = A * P * A' + Q

更新：
K = P_predict * H' / (H * P_predict * H' + R)
x = x_predict + K * (z - H * x_predict)
P = (I - K * H) * P_predict
```

### 4.3 超声波传感器 (HC-SR04)

**原理：** 发射超声波，测量回波时间

**参数：**

- 精度：3mm
- 角度：15°

**驱动代码：**
```c
float measure_distance() {
    // 发送10μs脉冲
    gpio_set_level(TRIG_PIN, 1);
    delay_us(10);
    gpio_set_level(TRIG_PIN, 0);
    
    // 等待回波
    while (gpio_get_level(ECHO_PIN) == 0);
    uint32_t start = esp_timer_get_time();
    
    while (gpio_get_level(ECHO_PIN) == 1);
    uint32_t end = esp_timer_get_time();
    
    // 计算距离 (声速340m/s)
    float distance = (end - start) * 0.034 / 2;
    return distance;
}
```

```c
void parse_gpgga(char *nmea) {
    char *token = strtok(nmea, ",");
    int field = 0;
    
    while (token != NULL) {
        switch (field) {
            case 1: strncpy(time, token, 10); break;
            case 2: strncpy(latitude, token, 10); break;
            case 3: strncpy(ns, token, 1); break;
            case 4: strncpy(longitude, token, 11); break;
            case 5: strncpy(ew, token, 1); break;
        }
        token = strtok(NULL, ",");
        field++;
    }
}
```

### 5.4 FOC控制

**原理：** 磁场定向控制

**步骤：**
1. 采集相电流 Ia, Ib
2. Clarke变换：Iα, Iβ
3. Park变换：Id, Iq
4. PI控制器
5. 反Park变换
6. SVPWM

**Clarke变换：**
$$I_\alpha = I_a$$
$$I_\beta = \frac{I_a + 2I_b}{\sqrt{3}}$$

**Park变换：**
$$I_d = I_\alpha \cos\theta + I_\beta \sin\theta$$
$$I_q = -I_\alpha \sin\theta + I_\beta \cos\theta$$

## 八、传感器数据融合

### 8.1 卡尔曼滤波

**一维卡尔曼：**
```c
float kalman_filter(float measurement) {
    // 预测
    float x_predict = x;
    float p_predict = p + Q;
    
    // 更新
    float K = p_predict / (p_predict + R);
    x = x_predict + K * (measurement - x_predict);
    p = (1 - K) * p_predict;
    
    return x;
}
```

**参数调整：**
- Q：过程噪声协方差
- R：测量噪声协方差

---

### 8.2 互补滤波

```c
float complementary_filter(float accel_angle, float gyro_rate, float dt) {
    static float angle = 0;
    angle = 0.98 * (angle + gyro_rate * dt) + 0.02 * accel_angle;
    return angle;
}
```

---

### 8.3 传感器校准

**零点校准：**
```c
// 静止状态下采集N个样本
float offset = 0;
for (int i = 0; i < N; i++) {
    offset += read_sensor();
    delay_ms(10);
}
offset /= N;

// 使用时减去偏移
float value = read_sensor() - offset;
```

**多点校准：**
- 使用标准源
- 建立查找表
- 线性插值
