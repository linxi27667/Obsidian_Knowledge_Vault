# 互感与变压器

> **核心概念**：互感系数、耦合系数、同名端、互感电压、T型等效、理想变压器、全耦合变压器

---

## 1. 互感的基本概念

### 1.1 自感与互感的物理意义

**自感（Self-Inductance）**

当一个线圈中的电流变化时，会在自身线圈中产生感应电压，这种现象称为自感。自感系数 $L$ 描述了线圈储存磁场能量的能力：

$$L = \frac{N\Phi}{i} = \frac{\Psi}{i}$$

其中：
- $N$ 为线圈匝数
- $\Phi$ 为磁通量
- $\Psi = N\Phi$ 为磁链
- $i$ 为流过线圈的电流

**互感（Mutual Inductance）**

当两个线圈彼此靠近时，一个线圈中的电流变化会在另一个线圈中产生感应电压，这种现象称为互感。互感系数 $M$ 描述了两个线圈之间磁场耦合的紧密程度：

$$M = \frac{N_2 \Phi_{12}}{i_1} = \frac{N_1 \Phi_{21}}{i_2}$$

其中：
- $\Phi_{12}$ 是线圈1的电流 $i_1$ 产生的、穿过线圈2的磁通
- $\Phi_{21}$ 是线圈2的电流 $i_2$ 产生的、穿过线圈1的磁通

> **注意**：互感系数 $M$ 具有对称性，即 $M_{12} = M_{21} = M$

### 1.2 互感系数 $M$ 的定义

互感系数 $M$ 的定义可以从磁链角度给出：

$$M = \frac{\Psi_{12}}{i_1} = \frac{\Psi_{21}}{i_2}$$

其中：
- $\Psi_{12} = N_2 \Phi_{12}$ 是线圈1的电流在线圈2中产生的磁链
- $\Psi_{21} = N_1 \Phi_{21}$ 是线圈2的电流在线圈1中产生的磁链

**单位**：亨利（H），与自感系数单位相同

**互感系数的物理意义**：
- $M$ 越大，两个线圈之间的电磁耦合越紧密
- $M$ 的大小取决于两个线圈的几何形状、匝数、相对位置和磁介质

### 1.3 耦合系数 $k$

**定义**：

$$k = \frac{M}{\sqrt{L_1 L_2}}$$

其中 $0 \leq k \leq 1$

**耦合系数的物理意义**：

| $k$ 值 | 含义 |
|---------|------|
| $k = 1$ | 全耦合（无漏磁），两个线圈的磁通完全重叠 |
| $0 < k < 1$ | 部分耦合，存在漏磁 |
| $k = 0$ | 无耦合，两个线圈之间没有磁耦合 |

**影响耦合系数的因素**：
- 两个线圈的相对距离
- 线圈的绕制方式（同轴绕制耦合系数高）
- 磁芯材料（铁芯比空气芯耦合系数高）
- 线圈的方位关系

### 1.4 同名端的概念与判定方法

**同名端的定义**

同名端是指两个耦合线圈中，当电流分别从各端流入时，所产生的磁通方向相同的一对端子。

**同名端的标记方法**：
- 用相同的符号（如 "*" 或 "·"）标记同名端
- 同名端是成对出现的

**同名端的判定方法**：

**方法一：右手螺旋定则**
1. 假设电流从某端流入第一个线圈
2. 用右手螺旋定则判断磁通方向
3. 再假设电流从某端流入第二个线圈
4. 如果两个磁通方向相同，则这两个端子为同名端

**方法二：实验法（直流法）**
1. 将两个线圈按一定方向连接
2. 在一个线圈中通入直流电流
3. 观察另一个线圈中感应电压的极性
4. 根据感应电压极性判断同名端

**同名端与互感电压的关系**：

设两个线圈的同名端已标定，当 $i_1$ 从同名端流入时，在线圈2中产生的互感电压 $u_{M2}$ 的正极性端为同名端。

## 2. 互感电压与伏安关系

### 2.1 互感电压的方向判定（同名端规则）

**同名端规则**（极性规则）：

当一个线圈的电流从同名端流入时，在另一个线圈中产生的互感电压，其同名端为正极性。

**具体规则**：

假设线圈1和线圈2的同名端已标定（用 "*" 表示）：

1. **电流参考方向**：
   - 若 $i_1$ 从线圈1的同名端流入（$\rightarrow$）
   - 则在线圈2中产生的互感电压 $u_{M2}$，同名端为正（$+$）

2. **电压参考方向**：
   - 若 $u_{M2}$ 的参考方向从同名端指向非同名端
   - 则 $u_{M2} = M \frac{di_1}{dt}$（取正号）

**四种情况总结**：

| $i_1$ 方向 | $u_2$ 方向 | 互感电压表达式 |
|------------|-----------|---------------|
| 流入同名端 | 同名端为正 | $u_{M2} = +M \frac{di_1}{dt}$ |
| 流入同名端 | 同名端为负 | $u_{M2} = -M \frac{di_1}{dt}$ |
| 流出同名端 | 同名端为正 | $u_{M2} = -M \frac{di_1}{dt}$ |
| 流出同名端 | 同名端为负 | $u_{M2} = +M \frac{di_1}{dt}$ |

**简记**：参考方向"同进同出"取正号，"一进一出"取负号

### 2.2 含互感的伏安关系方程

**时域形式**：

$$u_1 = L_1 \frac{di_1}{dt} \pm M \frac{di_2}{dt}$$

$$u_2 = L_2 \frac{di_2}{dt} \pm M \frac{di_1}{dt}$$

**符号规则**：
- 若两个电流参考方向都流入同名端（或都流出同名端），则 $M$ 项取正号
- 若一个电流流入同名端，另一个流出同名端，则 $M$ 项取负号

**相量形式（正弦稳态）**：

$$\dot{U}_1 = j\omega L_1 \dot{I}_1 \pm j\omega M \dot{I}_2$$

$$\dot{U}_2 = j\omega L_2 \dot{I}_2 \pm j\omega M \dot{I}_1$$

其中：
- $j\omega L_1$ 和 $j\omega L_2$ 为自阻抗
- $j\omega M$ 为互阻抗（互感电抗 $X_M = \omega M$）

### 2.3 正弦稳态下的相量方程

在正弦稳态分析中，使用相量法可以将微分方程转化为代数方程。

**含互感的阻抗矩阵形式**：

$$\begin{bmatrix} \dot{U}_1 \\ \dot{U}_2 \end{bmatrix} = \begin{bmatrix} j\omega L_1 & \pm j\omega M \\ \pm j\omega M & j\omega L_2 \end{bmatrix} \begin{bmatrix} \dot{I}_1 \\ \dot{I}_2 \end{bmatrix}$$

**阻抗矩阵的性质**：
- 对角元素 $Z_{11} = j\omega L_1$，$Z_{22} = j\omega L_2$ 为自阻抗
- 非对角元素 $Z_{12} = Z_{21} = \pm j\omega M$ 为互阻抗
- 矩阵是对称矩阵

**反射阻抗的概念**：

当考虑互感时，一个线圈中的电流会在另一个线圈中产生电压，这个电压可以等效为一个阻抗上的压降，称为反射阻抗。

## 3. 含互感电路的分析

### 3.1 互感消去法（T型等效电路）

**基本思想**：将含有互感的耦合电感电路等效为不含互感的电路，便于使用常规电路分析方法。

**T型等效电路的推导**：

设两个耦合线圈的同名端如图所示，线圈1和线圈2的端口方程为：

$$\dot{U}_1 = j\omega L_1 \dot{I}_1 + j\omega M \dot{I}_2$$

$$\dot{U}_2 = j\omega M \dot{I}_1 + j\omega L_2 \dot{I}_2$$

**同名端相连的T型等效**（同名端为公共端）：

$$Z_a = j\omega(L_1 - M)$$

$$Z_b = j\omega(L_2 - M)$$

$$Z_c = j\omega M$$

**异名端相连的T型等效**（异名端为公共端）：

$$Z_a = j\omega(L_1 + M)$$

$$Z_b = j\omega(L_2 + M)$$

$$Z_c = -j\omega M$$

**T型等效电路的应用**：
1. 将耦合电感替换为T型等效电路
2. 使用常规的网孔法或节点法分析电路
3. 将结果转换回原电路

**注意事项**：
- T型等效仅对外部电路等效
- 等效后的电路不含互感，便于计算
- 必须正确判断同名端位置

### 3.2 受控源等效法

**基本思想**：将互感电压视为受控电压源（CCVS），用受控源模型代替互感。

**受控源等效模型**：

对于耦合线圈：
$$u_{M2} = \pm M \frac{di_1}{dt}$$

可以等效为一个受 $i_1$ 控制的电压源。

**相量形式**：

$$\dot{U}_{M2} = \pm j\omega M \dot{I}_1$$

这是一个电流控制电压源（CCVS），其控制系数为 $\pm j\omega M$。

**受控源等效法的步骤**：
1. 画出两个线圈的自感
2. 在每个线圈中添加受控电压源，表示互感电压
3. 受控源的大小为 $\pm j\omega M$ 乘以另一个线圈的电流
4. 注意受控源的极性（根据同名端规则）

**受控源等效法的优点**：
- 物理意义清晰
- 便于理解互感电压的本质
- 适用于各种耦合电路

### 3.3 反射阻抗（引入阻抗）

**反射阻抗的定义**：

当线圈2接有负载 $Z_L$ 时，从线圈1侧看进去，除了线圈1的自阻抗外，还会感受到一个额外的阻抗，称为反射阻抗 $Z_r$。

**反射阻抗的计算**：

$$Z_r = \frac{(\omega M)^2}{Z_{22} + Z_L}$$

其中：
- $Z_{22} = j\omega L_2 + R_2$ 为线圈2的自阻抗
- $Z_L$ 为负载阻抗
- $\omega M$ 为互感电抗

**反射阻抗的性质**：
1. 反射阻抗与负载阻抗有关
2. 反射阻抗的性质（感性/容性）可能与负载阻抗相反
3. 反射阻抗反映了二次侧对一次侧的影响

**反射阻抗的物理意义**：
- 二次侧的电流通过互感在一次侧产生感应电压
- 这个感应电压的效果相当于在一次侧串联了一个阻抗
- 这个阻抗就是反射阻抗

### 3.4 串联耦合电感

**顺接（Series-Aiding）**：

两个耦合线圈串联，电流从两个线圈的同名端流入（或流出）。

**等效电感**：
$$L_{eq} = L_1 + L_2 + 2M$$

**推导**：
$$u = u_1 + u_2 = L_1 \frac{di}{dt} + M \frac{di}{dt} + L_2 \frac{di}{dt} + M \frac{di}{dt}$$

$$u = (L_1 + L_2 + 2M) \frac{di}{dt}$$

**反接（Series-Opposing）**：

两个耦合线圈串联，电流从一个线圈的同名端流入，从另一个线圈的同名端流出。

**等效电感**：
$$L_{eq} = L_1 + L_2 - 2M$$

**串联耦合电感的应用**：
- 通过测量顺接和反接的等效电感，可以计算互感系数 $M$：

$$M = \frac{L_{顺} - L_{反}}{4}$$

- 也可以计算自感系数：

$$L_1 = \frac{L_{顺} + L_{反}}{2} - L_2$$

### 3.5 并联耦合电感

**同名端并联**：

两个耦合线圈并联，同名端连接在一起。

**等效电感**：
$$L_{eq} = \frac{L_1 L_2 - M^2}{L_1 + L_2 - 2M}$$

**异名端并联**：

两个耦合线圈并联，异名端连接在一起。

**等效电感**：
$$L_{eq} = \frac{L_1 L_2 - M^2}{L_1 + L_2 + 2M}$$

**并联耦合电感的特点**：
- 等效电感与耦合系数有关
- 当 $k = 1$（全耦合）时，同名端并联的等效电感趋近于无穷大（相当于短路）
- 当 $k = 0$（无耦合）时，等效电感为 $L_1$ 和 $L_2$ 的并联

## 4. 空心变压器

### 4.1 空心变压器的电路模型

**空心变压器的结构**：
- 一次绕组（原边）：匝数 $N_1$，自感 $L_1$，电阻 $R_1$
- 二次绕组（副边）：匝数 $N_2$，自感 $L_2$，电阻 $R_2$
- 两个绕组绕在同一骨架上，但没有铁芯
- 耦合系数 $k < 1$（通常 $k$ 在 0.1 到 0.9 之间）

**电路模型**：

一次侧回路方程：
$$\dot{U}_1 = (R_1 + j\omega L_1)\dot{I}_1 + j\omega M \dot{I}_2$$

二次侧回路方程：
$$0 = j\omega M \dot{I}_1 + (R_2 + j\omega L_2 + Z_L)\dot{I}_2$$

其中 $Z_L$ 为负载阻抗。

### 4.2 反射阻抗的计算

**从一次侧看进去的输入阻抗**：

由二次侧方程可得：
$$\dot{I}_2 = -\frac{j\omega M \dot{I}_1}{R_2 + j\omega L_2 + Z_L}$$

代入一次侧方程：
$$\dot{U}_1 = \left[R_1 + j\omega L_1 + \frac{(\omega M)^2}{R_2 + j\omega L_2 + Z_L}\right] \dot{I}_1$$

**反射阻抗**：
$$Z_r = \frac{(\omega M)^2}{Z_{22}} = \frac{(\omega M)^2}{R_2 + j\omega L_2 + Z_L}$$

**反射阻抗的实部和虚部**：

设 $Z_{22} = R_{22} + jX_{22}$，则：
$$Z_r = \frac{(\omega M)^2}{R_{22} + jX_{22}} = \frac{(\omega M)^2}{R_{22}^2 + X_{22}^2}(R_{22} - jX_{22})$$

- 反射电阻：$R_r = \frac{(\omega M)^2 R_{22}}{R_{22}^2 + X_{22}^2}$（始终为正）
- 反射电抗：$X_r = -\frac{(\omega M)^2 X_{22}}{R_{22}^2 + X_{22}^2}$（与 $X_{22}$ 符号相反）

### 4.3 空心变压器的等效电路

**一次侧等效电路**：

将反射阻抗 $Z_r$ 串联在一次侧回路中：

$$Z_{in} = R_1 + j\omega L_1 + Z_r$$

**二次侧等效电路**（戴维南等效）：

从二次侧看进去的等效电路：
- 开路电压：$\dot{U}_{oc} = \frac{j\omega M \dot{U}_1}{R_1 + j\omega L_1}$
- 等效内阻：$Z_{eq} = R_2 + j\omega L_2 + \frac{(\omega M)^2}{R_1 + j\omega L_1}$

### 4.4 信号源内阻与负载的影响

**最大功率传输条件**：

当负载阻抗等于等效内阻的共轭时，负载获得最大功率：

$$Z_L = Z_{eq}^*$$

**阻抗匹配**：

通过调节变压器的匝数比和耦合系数，可以实现阻抗匹配，使负载获得最大功率。

**信号源内阻的影响**：
- 信号源内阻会减小反射阻抗的效果
- 内阻越大，反射阻抗的影响越小
- 在最大功率传输时，需要考虑信号源内阻

## 5. 理想变压器

### 5.1 理想变压器的条件

**理想变压器的假设**：
1. **无损耗**：绕组电阻为零（$R_1 = R_2 = 0$）
2. **全耦合**：耦合系数 $k = 1$，无漏磁
3. **无穷大电感**：$L_1, L_2, M \to \infty$
4. **线性磁芯**：磁导率为常数，无磁饱和

**实际意义**：
- 理想变压器是实际变压器的理想化模型
- 在很多情况下，实际变压器可以近似为理想变压器
- 理想变压器的分析大大简化了电路计算

### 5.2 变比 $n$

**变比的定义**：

$$n = \frac{N_1}{N_2}$$

其中：
- $N_1$ 为一次绕组匝数
- $N_2$ 为二次绕组匝数

**变比的物理意义**：
- $n > 1$：升压变压器（一次侧电压低于二次侧）
- $n < 1$：降压变压器（一次侧电压高于二次侧）
- $n = 1$：隔离变压器（电压不变）

### 5.3 电压关系

**理想变压器的电压关系**：

$$\frac{u_1}{u_2} = \frac{N_1}{N_2} = n$$

**相量形式**：

$$\frac{\dot{U}_1}{\dot{U}_2} = n$$

**注意**：
- 电压关系与同名端有关
- 如果二次侧电压参考方向与一次侧相反，则：
$$\frac{\dot{U}_1}{\dot{U}_2} = -n$$

### 5.4 电流关系

**理想变压器的电流关系**：

$$\frac{i_1}{i_2} = \frac{N_2}{N_1} = \frac{1}{n}$$

**相量形式**：

$$\frac{\dot{I}_1}{\dot{I}_2} = \frac{1}{n}$$

**推导**：
- 理想变压器无损耗，输入功率等于输出功率
- $u_1 i_1 = u_2 i_2$
- $\frac{i_1}{i_2} = \frac{u_2}{u_1} = \frac{1}{n}$

**注意**：
- 电流关系也与同名端有关
- 如果电流参考方向都流入同名端，则：
$$\frac{\dot{I}_1}{\dot{I}_2} = -\frac{1}{n}$$

### 5.5 阻抗变换

**阻抗变换原理**：

当二次侧接有负载阻抗 $Z_L$ 时，从一次侧看进去的等效阻抗为：

$$Z_{in} = n^2 Z_L$$

**推导**：

$$Z_{in} = \frac{\dot{U}_1}{\dot{I}_1} = \frac{n\dot{U}_2}{\frac{1}{n}\dot{I}_2} = n^2 \frac{\dot{U}_2}{\dot{I}_2} = n^2 Z_L$$

**阻抗变换的应用**：
1. **阻抗匹配**：通过选择合适的变比 $n$，使负载阻抗变换为信号源所需的最佳负载
2. **阻抗提升**：$n > 1$ 时，$Z_{in} > Z_L$（阻抗放大）
3. **阻抗降低**：$n < 1$ 时，$Z_{in} < Z_L$（阻抗缩小）

**最大功率传输**：

当 $Z_{in} = Z_s^*$（信号源内阻的共轭）时，负载获得最大功率。

### 5.6 理想变压器的功率特性

**功率守恒**：

$$P_1 = P_2$$

即输入功率等于输出功率。

**无功功率**：

理想变压器不消耗无功功率，只是将无功功率从一侧传递到另一侧。

**视在功率**：

$$S_1 = S_2$$

**理想变压器的特性**：
1. 不消耗能量（无损耗）
2. 不储存能量（无储能元件）
3. 只是传递能量，改变电压和电流的大小
4. 实现阻抗变换

## 6. 全耦合变压器与实际变压器

### 6.1 全耦合变压器的模型

**全耦合条件**：
- 耦合系数 $k = 1$
- 所有磁通都同时穿过两个绕组
- 无漏磁

**全耦合变压器的特点**：
- $\Phi_{11} = \Phi_{21}$（线圈1的自磁通等于互磁通）
- $\Phi_{22} = \Phi_{12}$（线圈2的自磁通等于互磁通）
- $M = \sqrt{L_1 L_2}$

**全耦合变压器的等效电路**：

全耦合变压器可以用理想变压器并联一个励磁电感 $L_m$ 来表示：

$$L_m = L_1$$

**电压关系**：

$$\frac{\dot{U}_1}{\dot{U}_2} = n$$

**电流关系**：

$$\dot{I}_1 = \frac{\dot{I}_2}{n} + \frac{\dot{U}_1}{j\omega L_m}$$

其中 $\frac{\dot{U}_1}{j\omega L_m}$ 为励磁电流。

### 6.2 实际变压器的等效电路

**实际变压器的参数**：
- $R_1, R_2$：一次、二次绕组的电阻
- $L_{1\sigma}, L_{2\sigma}$：一次、二次绕组的漏感
- $L_m$：励磁电感
- $R_m$：铁芯损耗电阻

**实际变压器的等效电路**（折算到一次侧）：

```
     R₁    jωL₁σ      R₂'   jωL₂σ'
  ┌──/\/\/──┬──┬──/\/\/──┬──┬──┐
  │         │  │         │  │  │
  │         │  │         │  │  │
U₁         Rₘ  jωLₘ     │  │  U₂'
  │         │  │         │  │  │
  │         │  │         │  │  │
  └─────────┴──┴─────────┴──┴──┘
```

其中：
- $R_2' = n^2 R_2$（折算到一次侧的二次电阻）
- $L_{2\sigma}' = n^2 L_{2\sigma}$（折算到一次侧的二次漏感）
- $\dot{U}_2' = n\dot{U}_2$（折算到一次侧的二次电压）
- $\dot{I}_2' = \frac{\dot{I}_2}{n}$（折算到一次侧的二次电流）

### 6.3 变压器的频率特性

**低频特性**：
- 励磁电感 $L_m$ 的阻抗 $j\omega L_m$ 随频率降低而减小
- 励磁电流增大
- 低频响应受限

**高频特性**：
- 漏感 $L_{1\sigma}, L_{2\sigma}$ 的阻抗随频率升高而增大
- 分布电容的影响增大
- 高频响应受限

**频率响应曲线**：

变压器的频率响应通常呈带通特性：
- 低频截止频率：$f_L = \frac{R_m}{2\pi L_m}$
- 高频截止频率：$f_H = \frac{1}{2\pi \sqrt{L_{\sigma} C_{分布}}}$

### 6.4 变压器的损耗

**铜损（Copper Loss）**：

$$P_{Cu} = I_1^2 R_1 + I_2^2 R_2$$

- 铜损与电流的平方成正比
- 铜损随负载变化

**铁损（Iron/Core Loss）**：

**磁滞损耗**：
$$P_h = k_h f B_m^n V$$

其中：
- $k_h$ 为磁滞系数
- $f$ 为频率
- $B_m$ 为最大磁通密度
- $n$ 为斯坦梅茨指数（通常 $n \approx 1.6 \sim 2$）
- $V$ 为铁芯体积

**涡流损耗**：
$$P_e = k_e f^2 B_m^2 V$$

其中 $k_e$ 为涡流系数。

**铁损的特点**：
- 铁损与电压（磁通密度）有关
- 铁损近似与频率的平方成正比
- 铁损在空载时就存在

**效率**：

$$\eta = \frac{P_2}{P_1} = \frac{P_2}{P_2 + P_{Cu} + P_{Fe}}$$

## 7. 典型题型

### 7.1 同名端的判定

**例题 1**：判断下图所示耦合线圈的同名端。

```
    ┌───●───┐     ┌───●───┐
    │       │     │       │
    │   L₁  │     │   L₂  │
    │       │     │       │
    └───○───┘     └───○───┘
      端子1           端子3
```

**解题步骤**：
1. 假设电流 $i_1$ 从端子1流入线圈1
2. 用右手螺旋定则判断 $i_1$ 产生的磁通方向
3. 假设电流 $i_2$ 从端子3流入线圈2
4. 判断 $i_2$ 产生的磁通方向
5. 如果两个磁通方向相同，则端子1和端子3为同名端

**例题 2**：通过实验判断同名端

**实验方法**：
1. 将线圈2的端子3和4连接一个电压表
2. 在线圈1的端子1和2之间连接一个电池和开关
3. 闭合开关的瞬间，观察电压表的偏转方向
4. 如果电压表正向偏转，则端子1和端子3为同名端

### 7.2 含互感电路的分析

**例题 3**：使用T型等效法分析含互感电路

**题目**：如图所示电路，已知 $L_1 = 4H$，$L_2 = 9H$，$M = 3H$，$R = 10\Omega$，$\dot{U}_s = 100\angle 0°V$，$\omega = 100 rad/s$。求电流 $\dot{I}_1$。

```
     ┌───L₁───┐
     │   *    │
  Us─┤        ├─L₂─R─┐
     │   *    │       │
     └────────┘       │
          └───────────┘
```

**解法一：T型等效法**

1. 判断同名端连接方式（同名端相连）
2. 计算T型等效参数：
   - $Z_a = j\omega(L_1 - M) = j100(4-3) = j100\Omega$
   - $Z_b = j\omega(L_2 - M) = j100(9-3) = j600\Omega$
   - $Z_c = j\omega M = j300\Omega$

3. 画出等效电路并计算总阻抗：
   $Z_{total} = Z_a + \frac{Z_c(Z_b + R)}{Z_c + Z_b + R}$

4. 计算电流：
   $\dot{I}_1 = \frac{\dot{U}_s}{Z_{total}}$

**解法二：受控源等效法**

1. 画出含受控源的等效电路
2. 列写网孔方程：
   - 网孔1：$(R_1 + j\omega L_1)\dot{I}_1 + j\omega M \dot{I}_2 = \dot{U}_s$
   - 网孔2：$j\omega M \dot{I}_1 + (R_2 + j\omega L_2 + R)\dot{I}_2 = 0$

3. 解方程组，求 $\dot{I}_1$

**例题 4**：串联耦合电感的计算

**题目**：两个耦合线圈串联，已知顺接时等效电感 $L_{顺} = 16H$，反接时等效电感 $L_{反} = 4H$。求互感系数 $M$。

**解**：
$$M = \frac{L_{顺} - L_{反}}{4} = \frac{16 - 4}{4} = 3H$$

### 7.3 变压器电路的计算

**例题 5**：空心变压器的计算

**题目**：空心变压器电路如图所示，已知 $R_1 = 10\Omega$，$L_1 = 100mH$，$R_2 = 5\Omega$，$L_2 = 25mH$，$M = 20mH$，$Z_L = 10\Omega$，$\omega = 1000 rad/s$，$\dot{U}_s = 50\angle 0°V$。求：
1. 反射阻抗 $Z_r$
2. 一次侧电流 $\dot{I}_1$
3. 二次侧电流 $\dot{I}_2$

**解**：

1. 计算各阻抗：
   - $j\omega L_1 = j100\Omega$
   - $j\omega L_2 = j25\Omega$
   - $j\omega M = j20\Omega$

2. 计算反射阻抗：
   $$Z_r = \frac{(\omega M)^2}{R_2 + j\omega L_2 + Z_L} = \frac{(20)^2}{5 + j25 + 10} = \frac{400}{15 + j25}$$
   $$Z_r = \frac{400}{15 + j25} \times \frac{15 - j25}{15 - j25} = \frac{6000 - j10000}{850} = 7.06 - j11.76\Omega$$

3. 计算一次侧电流：
   $$\dot{I}_1 = \frac{\dot{U}_s}{R_1 + j\omega L_1 + Z_r} = \frac{50}{10 + j100 + 7.06 - j11.76}$$
   $$\dot{I}_1 = \frac{50}{17.06 + j88.24} = \frac{50}{89.88\angle 79.1°} = 0.556\angle -79.1°A$$

4. 计算二次侧电流：
   $$\dot{I}_2 = -\frac{j\omega M \dot{I}_1}{R_2 + j\omega L_2 + Z_L} = -\frac{j20 \times 0.556\angle -79.1°}{15 + j25}$$
   $$\dot{I}_2 = -\frac{11.12\angle 10.9°}{29.15\angle 59.0°} = -0.381\angle -48.1°A = 0.381\angle 131.9°A$$

### 7.4 阻抗匹配问题

**例题 6**：理想变压器的阻抗匹配

**题目**：如图所示电路，信号源内阻 $R_s = 100\Omega$，负载电阻 $R_L = 4\Omega$。为使负载获得最大功率，求理想变压器的变比 $n$。

**解**：

1. 阻抗匹配条件：
   $$R_{in} = n^2 R_L = R_s$$

2. 求变比：
   $$n^2 = \frac{R_s}{R_L} = \frac{100}{4} = 25$$
   $$n = 5$$

3. 验证：
   - 一次侧等效电阻：$R_{in} = 5^2 \times 4 = 100\Omega = R_s$
   - 满足最大功率传输条件

**例题 7**：含变压器电路的功率计算

**题目**：如图所示，理想变压器变比 $n = 2$，一次侧接 $\dot{U}_s = 100\angle 0°V$，内阻 $R_s = 10\Omega$，二次侧接负载 $Z_L = 5 + j5\Omega$。求：
1. 负载吸收的有功功率
2. 电源输出的功率

**解**：

1. 将负载折算到一次侧：
   $$Z_L' = n^2 Z_L = 4(5 + j5) = 20 + j20\Omega$$

2. 计算一次侧电流：
   $$\dot{I}_1 = \frac{\dot{U}_s}{R_s + Z_L'} = \frac{100}{10 + 20 + j20} = \frac{100}{30 + j20}$$
   $$\dot{I}_1 = \frac{100}{36.06\angle 33.7°} = 2.77\angle -33.7°A$$

3. 计算负载吸收的功率：
   $$P_L = I_1^2 \times 20 = (2.77)^2 \times 20 = 153.4W$$

4. 计算电源输出功率：
   $$P_s = U_s I_1 \cos\phi = 100 \times 2.77 \times \cos(33.7°) = 230.6W$$

**例题 8**：变压器阻抗变换的综合应用

**题目**：如图所示，信号源 $\dot{U}_s = 10\angle 0°V$，内阻 $R_s = 50\Omega$，通过理想变压器连接负载 $R_L = 8\Omega$。为使负载获得最大功率，求：
1. 变压器的变比 $n$
2. 负载获得的最大功率 $P_{max}$

**解**：

1. 阻抗匹配条件：
   $$n^2 R_L = R_s$$
   $$n = \sqrt{\frac{R_s}{R_L}} = \sqrt{\frac{50}{8}} = 2.5$$

2. 折算后的负载电阻：
   $$R_L' = n^2 R_L = 6.25 \times 8 = 50\Omega$$

3. 一次侧电流：
   $$\dot{I}_1 = \frac{\dot{U}_s}{R_s + R_L'} = \frac{10}{50 + 50} = 0.1A$$

4. 负载获得的最大功率：
   $$P_{max} = I_1^2 R_L' = (0.1)^2 \times 50 = 0.5W$$

## 8. 公式速查表

### 8.1 互感基本公式

| 公式 | 说明 |
|------|------|
| $M = \frac{\Psi_{12}}{i_1} = \frac{\Psi_{21}}{i_2}$ | 互感系数定义 |
| $k = \frac{M}{\sqrt{L_1 L_2}}$ | 耦合系数 |
| $0 \leq k \leq 1$ | 耦合系数范围 |
| $M = k\sqrt{L_1 L_2}$ | 互感与自感的关系 |

### 8.2 互感电压公式

| 公式 | 说明 |
|------|------|
| $u_{M2} = \pm M \frac{di_1}{dt}$ | 互感电压（时域） |
| $\dot{U}_{M2} = \pm j\omega M \dot{I}_1$ | 互感电压（相量） |
| $X_M = \omega M$ | 互感电抗 |

**符号规则**：同进同出取正号，一进一出取负号

### 8.3 含互感电路的伏安关系

| 公式 | 说明 |
|------|------|
| $u_1 = L_1 \frac{di_1}{dt} \pm M \frac{di_2}{dt}$ | 线圈1的伏安关系 |

| $\dot{U}_1 = j\omega L_1 \dot{I}_1 \pm j\omega M \dot{I}_2$ | 相量形式 |
| $\dot{U}_2 = j\omega L_2 \dot{I}_2 \pm j\omega M \dot{I}_1$ | 相量形式 |

### 8.4 T型等效电路公式

| 连接方式 | $Z_a$ | $Z_b$ | $Z_c$ |
|----------|-------|-------|-------|
| 同名端相连 | $j\omega(L_1 - M)$ | $j\omega(L_2 - M)$ | $j\omega M$ |
| 异名端相连 | $j\omega(L_1 + M)$ | $j\omega(L_2 + M)$ | $-j\omega M$ |

### 8.5 串联耦合电感公式

| 连接方式 | 等效电感 |
|----------|----------|
| 顺接 | $L_{eq} = L_1 + L_2 + 2M$ |
| 反接 | $L_{eq} = L_1 + L_2 - 2M$ |

### 8.6 并联耦合电感公式

| 连接方式 | 等效电感 |
|----------|----------|

| 异名端并联 | $L_{eq} = \frac{L_1 L_2 - M^2}{L_1 + L_2 + 2M}$ |

### 8.7 反射阻抗公式

| 公式 | 说明 |
|------|------|
| $Z_r = \frac{(\omega M)^2}{Z_{22} + Z_L}$ | 反射阻抗 |

| $X_r = -\frac{(\omega M)^2 X_{22}}{R_{22}^2 + X_{22}^2}$ | 反射电抗 |

### 8.8 理想变压器公式

| 公式 | 说明 |
|------|------|
| $n = \frac{N_1}{N_2}$ | 变比 |
| $\frac{\dot{U}_1}{\dot{U}_2} = n$ | 电压关系 |
| $\frac{\dot{I}_1}{\dot{I}_2} = \frac{1}{n}$ | 电流关系 |
| $Z_{in} = n^2 Z_L$ | 阻抗变换 |
| $P_1 = P_2$ | 功率守恒 |

### 8.9 变压器效率公式

## 9. 思考题与练习

### 9.1 概念题

1. 什么是互感系数？它与自感系数有什么关系？
2. 耦合系数 $k$ 的物理意义是什么？$k = 1$ 和 $k = 0$ 分别表示什么情况？
3. 如何判断两个耦合线圈的同名端？
4. 什么是反射阻抗？它与哪些因素有关？
5. 理想变压器的条件是什么？为什么实际变压器可以近似为理想变压器？

### 9.2 计算题

1. 两个耦合线圈，$L_1 = 4H$，$L_2 = 9H$，$M = 3H$。求耦合系数 $k$。

   **答案**：$k = \frac{M}{\sqrt{L_1 L_2}} = \frac{3}{\sqrt{4 \times 9}} = \frac{3}{6} = 0.5$

2. 两个耦合线圈串联，顺接时等效电感为 $16H$，反接时等效电感为 $4H$。求互感系数 $M$。

   **答案**：$M = \frac{L_{顺} - L_{反}}{4} = \frac{16 - 4}{4} = 3H$

3. 理想变压器变比 $n = 10$，二次侧接 $10\Omega$ 电阻。求一次侧等效电阻。

   **答案**：$R_{in} = n^2 R_L = 100 \times 10 = 1000\Omega$

4. 信号源内阻 $R_s = 100\Omega$，负载电阻 $R_L = 4\Omega$。为使负载获得最大功率，求理想变压器的变比 $n$。

   **答案**：$n = \sqrt{\frac{R_s}{R_L}} = \sqrt{\frac{100}{4}} = 5$

5. 空心变压器，$M = 20mH$，$\omega = 1000 rad/s$，二次侧总阻抗 $Z_{22} = 15 + j25\Omega$。求反射阻抗 $Z_r$。

   **答案**：$Z_r = \frac{(\omega M)^2}{Z_{22}} = \frac{400}{15 + j25} = 7.06 - j11.76\Omega$

4. 理想变压器阻抗变换时忘记平方
5. 忘记考虑同名端对电压、电流关系的影响

3. **验证**：用功率守恒验证结果的合理性
4. **单位**：注意单位换算（mH, μH, rad/s 等）
