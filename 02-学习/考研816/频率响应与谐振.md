# 频率响应与谐振

> **核心概念**：频率响应、网络函数、谐振频率、品质因数、通频带、滤波器、波特图

---

## 1. 频率响应的基本概念

### 1.1 网络函数 H(jω) 的定义

**网络函数**（Network Function）是电路在正弦稳态下，输出相量与输入相量的比值。

$$H(j\omega) = \frac{\dot{Y}}{\dot{X}}$$

其中：
- $\dot{X}$ 为输入相量（激励）
- $\dot{Y}$ 为输出相量（响应）
- $\omega$ 为角频率（rad/s）

**网络函数的一般形式**：

$$H(j\omega) = \frac{b_m(j\omega)^m + b_{m-1}(j\omega)^{m-1} + \cdots + b_1(j\omega) + b_0}{a_n(j\omega)^n + a_{n-1}(j\omega)^{n-1} + \cdots + a_1(j\omega) + a_0}$$

### 1.2 幅频特性与相频特性

网络函数可以表示为极坐标形式：

$$H(j\omega) = |H(j\omega)| \cdot e^{j\varphi(\omega)}$$

**幅频特性**：

$$|H(j\omega)| = \frac{|b_m(j\omega)^m + \cdots + b_0|}{|a_n(j\omega)^n + \cdots + a_0|}$$

**相频特性**：

$$\varphi(\omega) = \arg[H(j\omega)] = \arg[\text{分子}] - \arg[\text{分母}]$$

### 1.3 频率响应的物理意义

- **幅频特性** $|H(j\omega)|$：描述电路对不同频率信号的**放大或衰减**程度
- **相频特性** $\varphi(\omega)$：描述电路对不同频率信号产生的**相位移动**

**示例**：若输入 $x(t) = A\cos(\omega t)$，则稳态输出为：

$$y(t) = A|H(j\omega)|\cos[\omega t + \varphi(\omega)]$$

### 1.4 网络函数的分类

| 类型 | 定义 | 示例 |
|------|------|------|
| **驱动点阻抗** | $Z(j\omega) = \frac{\dot{U}}{\dot{I}}$ | 端口电压与电流之比 |
| **驱动点导纳** | $Y(j\omega) = \frac{\dot{I}}{\dot{U}}$ | 端口电流与电压之比 |
| **转移阻抗** | $Z_{21}(j\omega) = \frac{\dot{U}_2}{\dot{I}_1}$ | 不同端口的电压与电流之比 |
| **转移导纳** | $Y_{21}(j\omega) = \frac{\dot{I}_2}{\dot{U}_1}$ | 不同端口的电流与电压之比 |
| **电压转移函数** | $H_u(j\omega) = \frac{\dot{U}_2}{\dot{U}_1}$ | 输出电压与输入电压之比 |
| **电流转移函数** | $H_i(j\omega) = \frac{\dot{I}_2}{\dot{I}_1}$ | 输出电流与输入电流之比 |

## 2. 串联谐振

### 2.1 串联谐振电路模型

RLC串联电路的总阻抗：

$$Z(j\omega) = R + j\left(\omega L - \frac{1}{\omega C}\right)$$

### 2.2 串联谐振的条件

**谐振条件**：阻抗虚部为零

$$\omega L - \frac{1}{\omega C} = 0$$

即：

$$\omega L = \frac{1}{\omega C}$$

### 2.3 谐振频率

由谐振条件解得**谐振角频率**：

$$\omega_0 = \frac{1}{\sqrt{LC}}$$

**谐振频率**：

$$f_0 = \frac{\omega_0}{2\pi} = \frac{1}{2\pi\sqrt{LC}}$$

### 2.4 谐振时的阻抗特性

谐振时，阻抗为：

$$Z(j\omega_0) = R + j\left(\omega_0 L - \frac{1}{\omega_0 C}\right) = R$$

**特点**：
- 阻抗为**纯电阻性**
- 阻抗达到**最小值** $|Z|_{\min} = R$
- 阻抗角 $\varphi = 0$

### 2.5 谐振时的电流特性

谐振时电流：

$$\dot{I}_0 = \frac{\dot{U}_s}{Z(j\omega_0)} = \frac{\dot{U}_s}{R}$$

**特点**：
- 电流与电压**同相位**
- 电流达到**最大值** $|I|_{\max} = \frac{U_s}{R}$

### 2.6 品质因数 Q

**品质因数**（Quality Factor）定义：

$$Q = \frac{\omega_0 L}{R} = \frac{1}{\omega_0 CR} = \frac{1}{R}\sqrt{\frac{L}{C}}$$

**物理意义**：
- 衡量谐振电路的**选择性**好坏
- Q值越高，选择性越好
- 表征电路中**储能与耗能**的比值

**能量角度理解**：

$$Q = 2\pi \frac{\text{谐振时存储的最大能量}}{\text{一个周期内消耗的能量}}$$

### 2.7 电压放大现象

谐振时各元件电压：

$$\dot{U}_R = \dot{I}_0 R = \dot{U}_s$$

$$\dot{U}_L = j\omega_0 L \dot{I}_0 = jQ\dot{U}_s$$

$$\dot{U}_C = \frac{1}{j\omega_0 C} \dot{I}_0 = -jQ\dot{U}_s$$

**重要结论**：
- $|U_L| = |U_C| = Q \cdot U_s$
- 电感和电容上的电压是电源电压的 **Q倍**
- $\dot{U}_L + \dot{U}_C = 0$（完全抵消）
- 这种现象称为**电压谐振**或**电压放大**

> **警告**：高Q值电路中，$U_L$ 和 $U_C$ 可能远大于电源电压，需注意元件耐压！

### 2.8 通频带（带宽）

**通频带**定义为幅频特性下降到最大值的 $\frac{1}{\sqrt{2}}$（即 -3dB）时对应的频率范围。

$$BW = \omega_2 - \omega_1 = \frac{\omega_0}{Q}$$

其中 $\omega_1$ 和 $\omega_2$ 为**半功率点频率**（截止频率）：

$$\omega_1 = \omega_0\left(-\frac{1}{2Q} + \sqrt{1 + \frac{1}{4Q^2}}\right)$$

$$\omega_2 = \omega_0\left(\frac{1}{2Q} + \sqrt{1 + \frac{1}{4Q^2}}\right)$$

对于高Q值电路（$Q \gg 1$）：

$$\omega_1 \approx \omega_0 - \frac{\omega_0}{2Q} = \omega_0 - \frac{BW}{2}$$

$$\omega_2 \approx \omega_0 + \frac{\omega_0}{2Q} = \omega_0 + \frac{BW}{2}$$

**带宽与Q值的关系**：

$$BW = \frac{\omega_0}{Q} = \frac{R}{L}$$

- Q值越高，带宽越窄，选择性越好
- Q值越低，带宽越宽，选择性越差

### 2.9 谐振曲线

**归一化谐振函数**：

$$N(j\eta) = \frac{\dot{I}}{\dot{I}_0} = \frac{1}{1 + jQ\left(\eta - \frac{1}{\eta}\right)}$$

其中 $\eta = \frac{\omega}{\omega_0}$ 为归一化频率。

**幅频特性**：

$$|N(\eta)| = \frac{1}{\sqrt{1 + Q^2\left(\eta - \frac{1}{\eta}\right)^2}}$$

**相频特性**：

$$\varphi(\eta) = -\arctan\left[Q\left(\eta - \frac{1}{\eta}\right)\right]$$

### 2.10 选择性

**选择性**指电路从多个不同频率信号中选出所需信号的能力。

- Q值越高，谐振曲线越尖锐，选择性越好
- 通频带越窄，对邻近频率的抑制能力越强

**例题 2.1**：RLC串联电路，$R = 10\Omega$，$L = 10mH$，$C = 0.1\mu F$，求谐振频率、品质因数和通频带。

**解**：

谐振角频率：
$$\omega_0 = \frac{1}{\sqrt{LC}} = \frac{1}{\sqrt{10 \times 10^{-3} \times 0.1 \times 10^{-6}}} = \frac{1}{\sqrt{10^{-9}}} = 10^4 \text{ rad/s}$$

谐振频率：
$$f_0 = \frac{\omega_0}{2\pi} = \frac{10^4}{2\pi} \approx 1592 \text{ Hz}$$

品质因数：
$$Q = \frac{\omega_0 L}{R} = \frac{10^4 \times 10 \times 10^{-3}}{10} = 10$$

通频带：
$$BW = \frac{\omega_0}{Q} = \frac{10^4}{10} = 1000 \text{ rad/s}$$

## 3. 并联谐振

### 3.1 并联谐振电路模型

**理想LC并联电路**的总导纳：

$$Y(j\omega) = j\omega C + \frac{1}{j\omega L} = j\left(\omega C - \frac{1}{\omega L}\right)$$

**实际RL-C并联电路**（电感有内阻R）的总导纳：

$$Y(j\omega) = \frac{1}{R + j\omega L} + j\omega C = \frac{R - j\omega L}{R^2 + \omega^2 L^2} + j\omega C$$

### 3.2 理想LC并联谐振

**谐振条件**：

$$\omega C = \frac{1}{\omega L}$$

**谐振频率**：

$$\omega_0 = \frac{1}{\sqrt{LC}}$$

**谐振时特性**：
- 导纳 $Y = 0$，阻抗 $Z \to \infty$
- 端口电流 $I = 0$
- 电感和电容之间进行能量交换，不从电源吸收能量

### 3.3 实际RL-C并联谐振

**谐振条件**：导纳虚部为零

$$\omega C - \frac{\omega L}{R^2 + \omega^2 L^2} = 0$$

解得**谐振频率**：

$$\omega_0 = \sqrt{\frac{1}{LC} - \frac{R^2}{L^2}} = \frac{1}{\sqrt{LC}}\sqrt{1 - \frac{CR^2}{L}}$$

> **注意**：只有当 $R < \sqrt{\frac{L}{C}}$ 时，才能发生谐振。

对于**高Q值电路**（$Q \gg 1$，即 $R \ll \omega_0 L$）：

$$\omega_0 \approx \frac{1}{\sqrt{LC}}$$

### 3.4 谐振时的阻抗特性

并联谐振时，阻抗达到**最大值**。

谐振阻抗：

$$Z_0 = \frac{R^2 + \omega_0^2 L^2}{R} = \frac{L}{RC}$$

对于高Q值电路：

$$Z_0 \approx \frac{\omega_0^2 L^2}{R} = Q\omega_0 L = \frac{Q}{\omega_0 C} = Q\sqrt{\frac{L}{C}}$$

**特点**：
- 阻抗为**纯电阻性**
- 阻抗达到**最大值**

### 3.5 谐振时的电流特性

**等效并联模型**：

将实际RL-C并联电路等效为理想R₀-L₀-C₀并联电路：

$$R_0 = \frac{L}{RC} = Q\sqrt{\frac{L}{C}}$$

$$L_0 = L$$

$$C_0 = C$$

谐振时总电流：

$$I_0 = \frac{U}{Z_0} = \frac{U}{L/(RC)} = \frac{URC}{L}$$

**支路电流**：

$$I_L = \frac{U}{\sqrt{R^2 + \omega_0^2 L^2}} \approx \frac{U}{\omega_0 L}$$

$$I_C = \omega_0 CU$$

### 3.6 并联谐振的品质因数

**品质因数**定义：

$$Q = \frac{\omega_0 L}{R} = \frac{1}{\omega_0 CR} = \frac{1}{R}\sqrt{\frac{L}{C}}$$

与串联谐振的Q值公式相同。

### 3.7 电流放大现象

谐振时：

$$I_L \approx I_C = Q \cdot I_0$$

**重要结论**：
- 支路电流是总电流的 **Q倍**
- $\dot{I}_L + \dot{I}_C \approx 0$（环流）
- 这种现象称为**电流谐振**或**电流放大**

### 3.8 并联谐振的通频带

与串联谐振相同：

$$BW = \frac{\omega_0}{Q}$$

### 3.9 串联谐振与并联谐振的对比

| 特性 | 串联谐振 | 并联谐振 |
|------|----------|----------|
| **阻抗** | 最小，$Z_0 = R$ | 最大，$Z_0 = L/(RC)$ |
| **电流** | 最大，$I_0 = U_s/R$ | 最小，$I_0 = U/Z_0$ |
| **电压/电流放大** | $U_L = U_C = QU_s$ | $I_L = I_C = QI_0$ |
| **选频特性** | 选择特定频率电流 | 选择特定频率电压 |
| **应用** | 串联在电路中选频 | 并联在电路中选频 |

**例题 3.1**：RL-C并联电路，$R = 10\Omega$，$L = 10mH$，$C = 0.1\mu F$，求谐振阻抗和品质因数。

**解**：

品质因数：
$$Q = \frac{1}{R}\sqrt{\frac{L}{C}} = \frac{1}{10}\sqrt{\frac{10 \times 10^{-3}}{0.1 \times 10^{-6}}} = \frac{1}{10} \times 100 = 10$$

谐振阻抗：
$$Z_0 = Q\sqrt{\frac{L}{C}} = 10 \times 100 = 1000\Omega = 1k\Omega$$

## 4. 一般谐振电路的分析

### 4.1 串并联混合谐振电路

对于复杂的串并联谐振电路，分析步骤：

1. **化简电路**：将电路化简为等效阻抗或导纳
2. **求谐振条件**：令阻抗或导纳的虚部为零
3. **求谐振频率**：解方程得到谐振频率
4. **分析谐振特性**：计算各支路电流和电压

**例题 4.1**：分析下图所示电路的谐振频率。

```
    L₁        C
----[LLL]----||----+
                  |
    R             R₂
----[===]---------+
```

电路总阻抗：

$$Z = R_1 + j\omega L_1 + \frac{1}{\frac{1}{R_2} + j\omega C}$$

$$Z = R_1 + j\omega L_1 + \frac{R_2}{1 + j\omega R_2 C}$$

$$Z = R_1 + j\omega L_1 + \frac{R_2(1 - j\omega R_2 C)}{1 + \omega^2 R_2^2 C^2}$$

令虚部为零：

$$\omega L_1 - \frac{\omega R_2^2 C}{1 + \omega^2 R_2^2 C^2} = 0$$

解得谐振频率：

$$\omega_0 = \sqrt{\frac{1}{L_1 C} - \frac{1}{R_2^2 C^2}}$$

### 4.2 互感耦合谐振电路

**互感耦合谐振电路**由两个或多个谐振电路通过互感耦合组成。

**耦合系数**：

$$k = \frac{M}{\sqrt{L_1 L_2}}$$

其中 $M$ 为互感。

**耦合谐振的特点**：
- 存在两个谐振峰（过耦合时）
- 带宽比单谐振电路宽
- 选择性更好

**临界耦合**条件：

$$k = k_c = \frac{1}{\sqrt{Q_1 Q_2}}$$

### 4.3 复杂谐振电路的分析方法

**方法一：阻抗/导纳法**
- 计算电路的总阻抗或导纳
- 令虚部为零，求谐振频率

**方法二：相量法**
- 画相量图
- 利用谐振时的相位关系求解

**方法三：能量法**
- 利用谐振时电感和电容能量交换的特性
- 适用于高Q值电路

## 5. 滤波器基础

### 5.1 滤波器的分类

滤波器按频率特性分为四类：

| 类型 | 英文缩写 | 功能 |
|------|----------|------|
| **低通滤波器** | LPF | 通过低频，抑制高频 |
| **高通滤波器** | HPF | 通过高频，抑制低频 |
| **带通滤波器** | BPF | 通过某一频段，抑制其他频率 |
| **带阻滤波器** | BEF | 抑制某一频段，通过其他频率 |

### 5.2 低通滤波器 (LPF)

**一阶RC低通滤波器**：

电路结构：输入端串联电阻R，输出端并联电容C

**网络函数**：

$$H(j\omega) = \frac{\dot{U}_2}{\dot{U}_1} = \frac{1}{1 + j\omega RC}$$

**截止频率**：

$$\omega_c = \frac{1}{RC}$$

**幅频特性**：

$$|H(j\omega)| = \frac{1}{\sqrt{1 + (\omega RC)^2}} = \frac{1}{\sqrt{1 + \left(\frac{\omega}{\omega_c}\right)^2}}$$

**相频特性**：

$$\varphi(\omega) = -\arctan(\omega RC) = -\arctan\left(\frac{\omega}{\omega_c}\right)$$

**特性**：
- $\omega = 0$ 时，$|H| = 1$，信号完全通过
- $\omega = \omega_c$ 时，$|H| = \frac{1}{\sqrt{2}} \approx 0.707$（-3dB）
- $\omega \to \infty$ 时，$|H| \to 0$，信号完全被抑制
- 相位从 $0°$ 变化到 $-90°$

**一阶RL低通滤波器**：

电路结构：输入端串联电阻R，输出端并联电感L

**网络函数**：

$$H(j\omega) = \frac{R}{R + j\omega L} = \frac{1}{1 + j\frac{\omega L}{R}}$$

**截止频率**：

$$\omega_c = \frac{R}{L}$$

### 5.3 高通滤波器 (HPF)

**一阶RC高通滤波器**：

电路结构：输入端串联电容C，输出端并联电阻R

**网络函数**：

$$H(j\omega) = \frac{j\omega RC}{1 + j\omega RC} = \frac{j\frac{\omega}{\omega_c}}{1 + j\frac{\omega}{\omega_c}}$$

**截止频率**：

$$\omega_c = \frac{1}{RC}$$

**幅频特性**：

$$|H(j\omega)| = \frac{\omega RC}{\sqrt{1 + (\omega RC)^2}} = \frac{\frac{\omega}{\omega_c}}{\sqrt{1 + \left(\frac{\omega}{\omega_c}\right)^2}}$$

**相频特性**：

$$\varphi(\omega) = 90° - \arctan(\omega RC) = \arctan\left(\frac{1}{\omega RC}\right)$$

**特性**：
- $\omega = 0$ 时，$|H| = 0$，低频信号被抑制
- $\omega = \omega_c$ 时，$|H| = \frac{1}{\sqrt{2}}$（-3dB）
- $\omega \to \infty$ 时，$|H| \to 1$，高频信号完全通过
- 相位从 $90°$ 变化到 $0°$

### 5.4 带通滤波器 (BPF)

**RLC串联带通滤波器**：

网络函数（以电阻电压为输出）：

$$H(j\omega) = \frac{R}{R + j\left(\omega L - \frac{1}{\omega C}\right)}$$

**中心频率**：$\omega_0 = \frac{1}{\sqrt{LC}}$

**带宽**：$BW = \frac{R}{L}$

**品质因数**：$Q = \frac{\omega_0 L}{R}$

**特性**：
- 在 $\omega_0$ 附近，$|H| \approx 1$
- 远离 $\omega_0$ 时，$|H|$ 迅速下降
- 通频带宽度由Q值决定

### 5.5 带阻滤波器 (BEF)

**RLC串联带阻滤波器**：

网络函数（以LC串联电压为输出）：

$$H(j\omega) = \frac{j\left(\omega L - \frac{1}{\omega C}\right)}{R + j\left(\omega L - \frac{1}{\omega C}\right)}$$

**特性**：
- 在 $\omega_0$ 处，$|H| = 0$，信号被完全抑制
- 远离 $\omega_0$ 时，$|H| \approx 1$
- 阻带宽度由Q值决定

### 5.6 二阶RLC滤波器的频率响应

**二阶低通滤波器**：

$$H(j\omega) = \frac{\omega_0^2}{\omega_0^2 - \omega^2 + j\frac{\omega_0 \omega}{Q}}$$

**二阶高通滤波器**：

$$H(j\omega) = \frac{-\omega^2}{\omega_0^2 - \omega^2 + j\frac{\omega_0 \omega}{Q}}$$

**二阶带通滤波器**：

$$H(j\omega) = \frac{j\frac{\omega_0 \omega}{Q}}{\omega_0^2 - \omega^2 + j\frac{\omega_0 \omega}{Q}}$$

**二阶带阻滤波器**：

$$H(j\omega) = \frac{\omega_0^2 - \omega^2}{\omega_0^2 - \omega^2 + j\frac{\omega_0 \omega}{Q}}$$

**例题 5.1**：设计一个截止频率为 $1kHz$ 的一阶RC低通滤波器，$C = 0.1\mu F$，求R的值。

**解**：

$$f_c = 1kHz \Rightarrow \omega_c = 2\pi f_c = 6283 \text{ rad/s}$$

$$R = \frac{1}{\omega_c C} = \frac{1}{6283 \times 0.1 \times 10^{-6}} = \frac{1}{6.283 \times 10^{-4}} \approx 1592\Omega$$

取标称值 $R = 1.6k\Omega$。

## 6. 波特图

### 6.1 对数坐标系

**分贝（dB）** 的定义：

$$|H|_{dB} = 20\log_{10}|H(j\omega)|$$

**常用分贝值**：

| $|H|$ | $|H|_{dB}$ |
|-------|------------|
| 0.001 | -60 dB |
| 0.01 | -40 dB |
| 0.1 | -20 dB |
| 0.5 | -6 dB |
| 0.707 | -3 dB |
| 1 | 0 dB |
| 2 | 6 dB |
| 10 | 20 dB |
| 100 | 40 dB |
| 1000 | 60 dB |

**频率的对数表示**：

频率轴采用对数刻度，单位为 **十倍频程（decade）**。

### 6.2 波特图的绘制方法

**幅频特性波特图**：
- 横轴：$\log\omega$（对数刻度）
- 纵轴：$|H|_{dB}$（线性刻度）

**相频特性波特图**：
- 横轴：$\log\omega$（对数刻度）
- 纵轴：$\varphi(\omega)$（线性刻度，单位：度）

### 6.3 一阶因子的渐近波特图

**一阶因子**的一般形式：

$$H(j\omega) = \frac{1}{1 + j\frac{\omega}{\omega_c}}$$

**幅频特性渐近线**：
- 当 $\omega \ll \omega_c$ 时，$|H|_{dB} \approx 0 dB$（水平线）
- 当 $\omega \gg \omega_c$ 时，$|H|_{dB} \approx -20\log\frac{\omega}{\omega_c}$（斜率为 -20dB/decade 的直线）
- 在 $\omega = \omega_c$ 处，转折点

**相频特性渐近线**：
- 当 $\omega \ll \omega_c$ 时，$\varphi \approx 0°$
- 当 $\omega = \omega_c$ 时，$\varphi = -45°$
- 当 $\omega \gg \omega_c$ 时，$\varphi \approx -90°$

**渐近波特图绘制步骤**：

1. 确定转折频率 $\omega_c$
2. 画幅频特性：
   - $\omega < \omega_c$：画0dB水平线
   - $\omega > \omega_c$：画斜率-20dB/dec的直线
3. 画相频特性：
   - $\omega < 0.1\omega_c$：画0°水平线
   - $0.1\omega_c < \omega < 10\omega_c$：画斜线从0°到-90°
   - $\omega > 10\omega_c$：画-90°水平线

### 6.4 二阶因子的渐近波特图

**二阶因子**的一般形式：

$$H(j\omega) = \frac{1}{1 - \left(\frac{\omega}{\omega_n}\right)^2 + j2\zeta\frac{\omega}{\omega_n}}$$

其中：
- $\omega_n$ 为自然频率
- $\zeta$ 为阻尼比

**幅频特性渐近线**：
- 当 $\omega \ll \omega_n$ 时，$|H|_{dB} \approx 0 dB$
- 当 $\omega \gg \omega_n$ 时，$|H|_{dB} \approx -40\log\frac{\omega}{\omega_n}$（斜率为 -40dB/decade）
- 在 $\omega = \omega_n$ 处，转折点

**相频特性渐近线**：
- 当 $\omega \ll \omega_n$ 时，$\varphi \approx 0°$
- 当 $\omega = \omega_n$ 时，$\varphi = -90°$
- 当 $\omega \gg \omega_n$ 时，$\varphi \approx -180°$

**共振峰**：

当 $\zeta < \frac{1}{\sqrt{2}} \approx 0.707$ 时，在 $\omega = \omega_n$ 附近出现共振峰。

共振峰频率：

$$\omega_r = \omega_n\sqrt{1 - 2\zeta^2}$$

峰值：

$$|H|_{\max} = \frac{1}{2\zeta\sqrt{1 - \zeta^2}}$$

### 6.5 波特图绘制实例

**例题 6.1**：绘制网络函数 $H(j\omega) = \frac{10}{(1 + j\frac{\omega}{10})(1 + j\frac{\omega}{100})}$ 的波特图。

**解**：

**步骤1**：分解为基本因子

$$H(j\omega) = 10 \cdot \frac{1}{1 + j\frac{\omega}{10}} \cdot \frac{1}{1 + j\frac{\omega}{100}}$$

**步骤2**：确定各因子的转折频率

- 常数因子：$20\log10 = 20 dB$
- 一阶因子1：$\omega_{c1} = 10$ rad/s
- 一阶因子2：$\omega_{c2} = 100$ rad/s

**步骤3**：画幅频特性

- $\omega < 10$：$|H|_{dB} = 20 dB$
- $10 < \omega < 100$：斜率 -20dB/dec，从20dB下降
- $\omega > 100$：斜率 -40dB/dec

**步骤4**：画相频特性

- $\omega < 1$：$\varphi \approx 0°$
- $\omega = 10$：$\varphi \approx -45°$
- $\omega = 100$：$\varphi \approx -135°$
- $\omega > 1000$：$\varphi \approx -180°$

## 7. 典型题型

### 7.1 串联谐振参数计算

**例题 7.1**：RLC串联电路，$R = 50\Omega$，$L = 50mH$，$C = 0.2\mu F$，接电压源 $u_s(t) = 10\cos(\omega t)$ V。

(1) 求谐振频率 $f_0$
(2) 求品质因数 $Q$
(3) 求谐振时的电流 $I_0$
(4) 求谐振时电感和电容两端的电压
(5) 求通频带 $BW$

**解**：

**(1) 谐振频率**

$$\omega_0 = \frac{1}{\sqrt{LC}} = \frac{1}{\sqrt{50 \times 10^{-3} \times 0.2 \times 10^{-6}}}$$

$$\omega_0 = \frac{1}{\sqrt{10^{-8}}} = \frac{1}{10^{-4}} = 10^4 \text{ rad/s}$$

$$f_0 = \frac{\omega_0}{2\pi} = \frac{10^4}{2\pi} \approx 1592 \text{ Hz}$$

**(2) 品质因数**

$$Q = \frac{\omega_0 L}{R} = \frac{10^4 \times 50 \times 10^{-3}}{50} = \frac{500}{50} = 10$$

**(3) 谐振时的电流**

$$I_0 = \frac{U_s}{R} = \frac{10}{50} = 0.2 \text{ A} = 200 \text{ mA}$$

**(4) 谐振时的电压**

$$U_L = Q \cdot U_s = 10 \times 10 = 100 \text{ V}$$

$$U_C = Q \cdot U_s = 10 \times 10 = 100 \text{ V}$$

> 注意：电感和电容上的电压高达100V，远大于电源电压10V！

**(5) 通频带**

$$BW = \frac{\omega_0}{Q} = \frac{10^4}{10} = 1000 \text{ rad/s}$$

$$BW_f = \frac{BW}{2\pi} = \frac{1000}{2\pi} \approx 159 \text{ Hz}$$

### 7.2 并联谐振参数计算

**例题 7.2**：RL-C并联电路，$R = 5\Omega$，$L = 2mH$，$C = 0.5\mu F$，接电流源 $i_s(t) = 10\cos(\omega t)$ mA。

(1) 求谐振频率 $f_0$
(2) 求品质因数 $Q$
(3) 求谐振阻抗 $Z_0$
(4) 求谐振时的端电压 $U_0$
(5) 求谐振时电感和电容支路的电流

**解**：

**(1) 谐振频率**

$$\omega_0 = \frac{1}{\sqrt{LC}} = \frac{1}{\sqrt{2 \times 10^{-3} \times 0.5 \times 10^{-6}}}$$

$$\omega_0 = \frac{1}{\sqrt{10^{-9}}} = 10^{4.5} \approx 31623 \text{ rad/s}$$

$$f_0 = \frac{\omega_0}{2\pi} \approx 5033 \text{ Hz}$$

**(2) 品质因数**

$$Q = \frac{1}{R}\sqrt{\frac{L}{C}} = \frac{1}{5}\sqrt{\frac{2 \times 10^{-3}}{0.5 \times 10^{-6}}} = \frac{1}{5}\sqrt{4000} = \frac{63.25}{5} = 12.65$$

**(3) 谐振阻抗**

$$Z_0 = Q\sqrt{\frac{L}{C}} = 12.65 \times 63.25 \approx 800\Omega$$

**(4) 谐振时的端电压**

$$U_0 = I_s \cdot Z_0 = 10 \times 10^{-3} \times 800 = 8 \text{ V}$$

**(5) 支路电流**

$$I_L \approx I_C = Q \cdot I_s = 12.65 \times 10 \text{ mA} = 126.5 \text{ mA}$$

### 7.3 谐振电路的频率响应分析

**例题 7.3**：RLC串联电路，$R = 100\Omega$，$L = 10mH$，$C = 0.1\mu F$，$U_s = 10V$。

(1) 求谐振时的电流
(2) 求 $\omega = 0.8\omega_0$ 时的电流
(3) 求 $\omega = 1.2\omega_0$ 时的电流
(4) 画出电流的频率响应曲线

**解**：

**谐振参数**：

$$\omega_0 = \frac{1}{\sqrt{LC}} = \frac{1}{\sqrt{10^{-2} \times 10^{-7}}} = 10^4 \text{ rad/s}$$

$$Q = \frac{\omega_0 L}{R} = \frac{10^4 \times 10^{-2}}{100} = 1$$

$$I_0 = \frac{U_s}{R} = \frac{10}{100} = 0.1 \text{ A}$$

**(1) 谐振时**：$I = I_0 = 0.1$ A

**(2) $\omega = 0.8\omega_0$ 时**：

$$Z = R + j\left(0.8\omega_0 L - \frac{1}{0.8\omega_0 C}\right)$$

$$= 100 + j\left(0.8 \times 100 - \frac{100}{0.8}\right)$$

$$= 100 + j(80 - 125) = 100 - j45$$

$$|Z| = \sqrt{100^2 + 45^2} = \sqrt{12025} \approx 109.7\Omega$$

$$I = \frac{U_s}{|Z|} = \frac{10}{109.7} \approx 0.091 \text{ A}$$

**(3) $\omega = 1.2\omega_0$ 时**：

$$Z = 100 + j\left(1.2 \times 100 - \frac{100}{1.2}\right) = 100 + j(120 - 83.3) = 100 + j36.7$$

$$|Z| = \sqrt{100^2 + 36.7^2} = \sqrt{11347} \approx 106.5\Omega$$

$$I = \frac{10}{106.5} \approx 0.094 \text{ A}$$

**(4) 频率响应曲线**

| $\omega/\omega_0$ | $|Z|$ (Ω) | $I$ (A) | $I/I_0$ |
|-------------------|-----------|---------|---------|
| 0.5 | 206 | 0.049 | 0.49 |
| 0.8 | 109.7 | 0.091 | 0.91 |
| 1.0 | 100 | 0.100 | 1.00 |
| 1.2 | 106.5 | 0.094 | 0.94 |
| 1.5 | 130 | 0.077 | 0.77 |
| 2.0 | 206 | 0.049 | 0.49 |

### 7.4 滤波器设计与分析

**例题 7.4**：设计一个二阶RC低通滤波器，截止频率 $f_c = 1kHz$，$C = 0.1\mu F$。

**解**：

**一阶RC低通滤波器**：

$$f_c = \frac{1}{2\pi RC}$$

$$R = \frac{1}{2\pi f_c C} = \frac{1}{2\pi \times 1000 \times 0.1 \times 10^{-6}} = \frac{1}{6.283 \times 10^{-4}} \approx 1592\Omega$$

取标称值 $R = 1.6k\Omega$。

**二阶RC低通滤波器**（两级级联）：

第一级：$R_1 = 1.6k\Omega$，$C_1 = 0.1\mu F$

第二级：$R_2 = 1.6k\Omega$，$C_2 = 0.1\mu F$

注意：两级直接级联会改变截止频率，需要调整参数。

### 7.5 波特图绘制

**例题 7.5**：绘制 $H(j\omega) = \frac{100j\omega}{(1 + j\frac{\omega}{10})(1 + j\frac{\omega}{1000})}$ 的波特图。

**解**：

**分解因子**：

$$H(j\omega) = 100 \cdot j\omega \cdot \frac{1}{1 + j\frac{\omega}{10}} \cdot \frac{1}{1 + j\frac{\omega}{1000}}$$

**各因子的贡献**：

1. **常数因子 100**：$20\log100 = 40 dB$

2. **微分因子 $j\omega$**：
   - 幅频：斜率 +20dB/dec，过0dB点在 $\omega = 1$
   - 相频：恒为 $+90°$

3. **一阶滞后因子 $\frac{1}{1 + j\omega/10}$**：
   - 转折频率 $\omega = 10$
   - 幅频：$\omega < 10$ 为0dB，$\omega > 10$ 斜率 -20dB/dec
   - 相频：从 $0°$ 到 $-90°$

4. **一阶滞后因子 $\frac{1}{1 + j\omega/1000}$**：
   - 转折频率 $\omega = 1000$
   - 幅频：$\omega < 1000$ 为0dB，$\omega > 1000$ 斜率 -20dB/dec
   - 相频：从 $0°$ 到 $-90°$

**幅频特性渐近线**：

| 频率范围 | 斜率 | 说明 |
|----------|------|------|
| $\omega < 1$ | +20dB/dec | 微分因子主导 |
| $1 < \omega < 10$ | +20dB/dec | 微分因子主导 |
| $10 < \omega < 1000$ | 0dB/dec | 微分与一阶滞后抵消 |
| $\omega > 1000$ | -20dB/dec | 两个一阶滞后主导 |

**相频特性**：

- $\omega \to 0$：$\varphi = 90°$
- $\omega = 10$：$\varphi = 90° - 45° = 45°$
- $\omega = 1000$：$\varphi = 90° - 90° - 45° = -45°$
- $\omega \to \infty$：$\varphi = 90° - 90° - 90° = -90°$

## 8. 公式速查表

### 8.1 谐振频率

| 电路类型 | 谐振频率 $\omega_0$ |
|----------|---------------------|
| 串联RLC | $\omega_0 = \frac{1}{\sqrt{LC}}$ |
| 并联RL-C（高Q） | $\omega_0 \approx \frac{1}{\sqrt{LC}}$ |
| 并联RL-C（精确） | $\omega_0 = \sqrt{\frac{1}{LC} - \frac{R^2}{L^2}}$ |

### 8.2 品质因数

| 定义 | 公式 |
|------|------|
| 通用定义 | $Q = 2\pi \frac{\text{最大存储能量}}{\text{每周期消耗能量}}$ |
| 串联谐振 | $Q = \frac{\omega_0 L}{R} = \frac{1}{\omega_0 CR} = \frac{1}{R}\sqrt{\frac{L}{C}}$ |
| 并联谐振 | $Q = \frac{\omega_0 L}{R} = \frac{1}{\omega_0 CR} = \frac{1}{R}\sqrt{\frac{L}{C}}$ |

### 8.3 阻抗特性

| 谐振类型 | 谐振时阻抗 |
|----------|------------|
| 串联谐振 | $Z_0 = R$（最小） |
| 并联谐振 | $Z_0 = \frac{L}{RC} = Q\sqrt{\frac{L}{C}}$（最大） |

### 8.4 电压/电流放大

| 谐振类型 | 放大关系 |
|----------|----------|
| 串联谐振 | $U_L = U_C = Q \cdot U_s$ |
| 并联谐振 | $I_L = I_C = Q \cdot I_0$ |

### 8.5 通频带

$$BW = \frac{\omega_0}{Q}$$

半功率点频率（高Q值近似）：

$$\omega_1 \approx \omega_0 - \frac{BW}{2}, \quad \omega_2 \approx \omega_0 + \frac{BW}{2}$$

### 8.6 滤波器网络函数

| 滤波器类型 | 网络函数 $H(j\omega)$ |
|------------|----------------------|
| 一阶RC低通 | $\frac{1}{1 + j\omega RC}$，$\omega_c = \frac{1}{RC}$ |
| 一阶RC高通 | $\frac{j\omega RC}{1 + j\omega RC}$，$\omega_c = \frac{1}{RC}$ |
| 一阶RL低通 | $\frac{R}{R + j\omega L}$，$\omega_c = \frac{R}{L}$ |
| 一阶RL高通 | $\frac{j\omega L}{R + j\omega L}$，$\omega_c = \frac{R}{L}$ |
| 二阶带通 | $\frac{j\frac{\omega_0 \omega}{Q}}{\omega_0^2 - \omega^2 + j\frac{\omega_0 \omega}{Q}}$ |
| 二阶带阻 | $\frac{\omega_0^2 - \omega^2}{\omega_0^2 - \omega^2 + j\frac{\omega_0 \omega}{Q}}$ |

### 8.7 波特图斜率

| 因子 | 幅频斜率 | 相频变化 |
|------|----------|----------|
| 常数 $K$ | $20\log K$ dB（水平线） | $0°$ |
| $j\omega$（微分） | +20 dB/dec | $+90°$ |
| $\frac{1}{j\omega}$（积分） | -20 dB/dec | $-90°$ |
| $\frac{1}{1 + j\omega/\omega_c}$ | -20 dB/dec（$\omega > \omega_c$） | $0°$ 到 $-90°$ |
| $1 + j\omega/\omega_c$ | +20 dB/dec（$\omega > \omega_c$） | $0°$ 到 $+90°$ |

### 8.8 分贝换算

$$|H|_{dB} = 20\log_{10}|H|$$

$$|H| = 10^{|H|_{dB}/20}$$

**功率分贝**：

$$P_{dB} = 10\log_{10}\frac{P_2}{P_1}$$

## 附录：常用公式推导

### A.1 串联谐振频率推导

RLC串联电路阻抗：

$$Z = R + j\left(\omega L - \frac{1}{\omega C}\right)$$

谐振时虚部为零：

$$\omega L - \frac{1}{\omega C} = 0$$

$$\omega^2 = \frac{1}{LC}$$

$$\omega_0 = \frac{1}{\sqrt{LC}}$$

### A.2 品质因数推导

谐振时，电感存储的最大能量：

$$W_L = \frac{1}{2}LI_m^2 = \frac{1}{2}L\left(\frac{U_m}{R}\right)^2$$

电容存储的最大能量：

$$W_C = \frac{1}{2}CU_{Cm}^2 = \frac{1}{2}C(QU_m)^2$$

总存储能量（最大值）：

$$W_{max} = \frac{1}{2}LI_m^2 = \frac{1}{2}L\left(\frac{U_m}{R}\right)^2$$

每周期消耗能量：

$$W_R = I_m^2 R \cdot T = I_m^2 R \cdot \frac{2\pi}{\omega_0}$$

品质因数：

$$Q = 2\pi \frac{W_{max}}{W_R} = 2\pi \frac{\frac{1}{2}LI_m^2}{I_m^2 R \cdot \frac{2\pi}{\omega_0}} = \frac{\omega_0 L}{R}$$

### A.3 通频带推导

在半功率点，$|I| = \frac{I_0}{\sqrt{2}}$，即 $|Z| = \sqrt{2}R$。

$$|Z|^2 = R^2 + \left(\omega L - \frac{1}{\omega C}\right)^2 = 2R^2$$

$$\left(\omega L - \frac{1}{\omega C}\right)^2 = R^2$$

$$\omega L - \frac{1}{\omega C} = \pm R$$

解得：

$$\omega_1 = \omega_0\left(-\frac{1}{2Q} + \sqrt{1 + \frac{1}{4Q^2}}\right)$$

$$\omega_2 = \omega_0\left(\frac{1}{2Q} + \sqrt{1 + \frac{1}{4Q^2}}\right)$$

带宽：

$$BW = \omega_2 - \omega_1 = \frac{\omega_0}{Q}$$
