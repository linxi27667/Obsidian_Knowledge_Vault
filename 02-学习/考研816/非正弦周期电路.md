# 非正弦周期电路（傅里叶分析）

> **核心概念**：傅里叶级数、谐波、频谱、有效值、平均功率、滤波
>
> **考研816重点章节**：非正弦周期电路是电路分析的重要组成部分，掌握傅里叶级数展开和
> 谐波分析法是解决此类问题的关键。

---

## 1. 非正弦周期信号

### 1.1 非正弦周期信号的来源

在实际电路中，非正弦周期信号非常常见，主要来源包括：

1. **发电机产生的电压**：由于气隙磁场分布不完全正弦，实际发电机输出含有高次谐波
2. **电子电路中的信号**：方波、三角波、锯齿波等常见波形
3. **非线性元件**：二极管整流、晶体管饱和等非线性特性产生非正弦波形
4. **多个不同频率正弦信号的叠加**：当频率比不是有理数时，合成信号为非正弦周期信号
5. **数字电路信号**：数字系统中的时钟信号、脉冲信号等

### 1.2 周期信号的一般表示

周期信号满足：

$$f(t) = f(t + T)$$

其中 $T$ 为周期，基波角频率为：

$$\omega = \frac{2\pi}{T}$$

周期信号可以用傅里叶级数表示为无穷多个不同频率正弦信号之和。

## 2. 傅里叶级数展开

### 2.1 傅里叶级数的三角形式

任何满足狄里赫利条件的周期函数 $f(t)$ 都可以展开为傅里叶级数：

$$f(t) = a_0 + \sum_{n=1}^{\infty} (a_n \cos n\omega t + b_n \sin n\omega t)$$

其中：

- $a_0$ 为直流分量（常数项）
- $a_1 \cos \omega t + b_1 \sin \omega t$ 为基波分量（$n=1$）
- $a_n \cos n\omega t + b_n \sin n\omega t$ 为第 $n$ 次谐波分量

**狄里赫利条件**：
1. 在一个周期内，函数只有有限个第一类间断点
2. 在一个周期内，函数只有有限个极值
3. 在一个周期内，函数绝对可积

### 2.2 傅里叶系数的计算公式

傅里叶系数的计算公式为：

**直流分量**：

$$a_0 = \frac{1}{T} \int_0^T f(t) \, dt$$

**余弦系数**：

$$a_n = \frac{2}{T} \int_0^T f(t) \cos n\omega t \, dt$$

**正弦系数**：

$$b_n = \frac{2}{T} \int_0^T f(t) \sin n\omega t \, dt$$

积分区间也可以取 $[-T/2, T/2]$ 或任意一个完整周期。

### 2.3 余弦形式

利用三角恒等式，可以将傅里叶级数写成余弦形式：

$$f(t) = A_0 + \sum_{n=1}^{\infty} A_n \cos(n\omega t + \varphi_n)$$

其中各参数的关系为：

$$A_0 = a_0$$

$$A_n = \sqrt{a_n^2 + b_n^2}$$

$$\varphi_n = -\arctan \frac{b_n}{a_n}$$

反推关系：

$$a_n = A_n \cos \varphi_n$$

$$b_n = -A_n \sin \varphi_n$$

> **注意**：$A_n$ 为第 $n$ 次谐波的振幅，$\varphi_n$ 为第 $n$ 次谐波的初相位。

### 2.4 对称性的利用

利用波形的对称性可以大大简化傅里叶系数的计算。

#### （1）偶函数对称（纵轴对称）

若 $f(t) = f(-t)$，则：
- $b_n = 0$（所有正弦系数为零）
- 只含直流分量和余弦分量
- 傅里叶级数只有 $a_0$ 和 $a_n$ 项

$$f(t) = a_0 + \sum_{n=1}^{\infty} a_n \cos n\omega t$$

#### （2）奇函数对称（原点对称）

若 $f(t) = -f(-t)$，则：
- $a_0 = 0$，$a_n = 0$（所有余弦系数为零）
- 只含正弦分量
- 傅里叶级数只有 $b_n$ 项

$$f(t) = \sum_{n=1}^{\infty} b_n \sin n\omega t$$

#### （3）半波对称（镜像对称）

若 $f(t) = -f(t + T/2)$，则：
- $a_0 = 0$（无直流分量）
- 只含奇次谐波（$n = 1, 3, 5, 7, \ldots$）
- 偶次谐波系数全部为零

#### （4）同时具有多种对称性

| 对称类型 | $a_0$ | $a_n$ | $b_n$ | 含有的谐波 |
|---------|-------|-------|-------|-----------|
| 偶函数 | 可能非零 | 可能非零 | 全为零 | 所有 |
| 奇函数 | 为零 | 全为零 | 可能非零 | 所有 |
| 半波对称 | 为零 | 只有奇次 | 只有奇次 | 仅奇次 |
| 偶函数+半波对称 | 为零 | 只有奇次 | 全为零 | 仅奇次余弦 |
| 奇函数+半波对称 | 为零 | 全为零 | 只有奇次 | 仅奇次正弦 |

### 2.5 傅里叶级数的复数形式

利用欧拉公式 $e^{j\theta} = \cos\theta + j\sin\theta$，傅里叶级数可写成复数形式：

$$f(t) = \sum_{n=-\infty}^{\infty} \dot{C}_n e^{jn\omega t}$$

其中复数傅里叶系数为：

$$\dot{C}_n = \frac{1}{T} \int_0^T f(t) e^{-jn\omega t} \, dt$$

复数系数与三角形式系数的关系：

$$\dot{C}_0 = a_0$$

$$\dot{C}_n = \frac{1}{2}(a_n - jb_n), \quad n > 0$$

$$\dot{C}_{-n} = \frac{1}{2}(a_n + jb_n), \quad n > 0$$

$$|\dot{C}_n| = \frac{1}{2} A_n, \quad n \neq 0$$

> **特点**：复数形式的频谱是双边频谱，正负频率对称，幅度为单边频谱的一半。

## 3. 典型周期信号的傅里叶级数

### 3.1 方波（矩形波）

**波形描述**：幅值为 $A$ 的方波，正半周期 $0 < t < T/2$ 时 $f(t) = A$，
负半周期 $T/2 < t < T$ 时 $f(t) = -A$。

**傅里叶级数**：

$$f(t) = \frac{4A}{\pi} \left( \sin \omega t + \frac{1}{3}\sin 3\omega t + \frac{1}{5}\sin 5\omega t + \cdots \right)$$

$$f(t) = \frac{4A}{\pi} \sum_{n=1,3,5,\ldots}^{\infty} \frac{1}{n} \sin n\omega t$$

**特点**：
- 奇函数，只含正弦项
- 半波对称，只含奇次谐波
- 各次谐波振幅按 $1/n$ 衰减

### 3.2 三角波

**波形描述**：从 $0$ 线性上升到 $A$ 再线性下降到 $0$ 的三角波。

**傅里叶级数**：

$$f(t) = \frac{A}{2} - \frac{4A}{\pi^2} \left( \cos \omega t + \frac{1}{9}\cos 3\omega t + \frac{1}{25}\cos 5\omega t + \cdots \right)$$

$$f(t) = \frac{A}{2} - \frac{4A}{\pi^2} \sum_{n=1,3,5,\ldots}^{\infty} \frac{1}{n^2} \cos n\omega t$$

**特点**：
- 偶函数，只含余弦项
- 含直流分量 $A/2$
- 各次谐波振幅按 $1/n^2$ 衰减（比方波衰减更快）

### 3.3 锯齿波

**波形描述**：从 $0$ 线性上升到 $A$ 然后跳回 $0$ 的锯齿波。

**傅里叶级数**：

$$f(t) = \frac{A}{2} - \frac{A}{\pi} \left( \sin \omega t + \frac{1}{2}\sin 2\omega t + \frac{1}{3}\sin 3\omega t + \cdots \right)$$

$$f(t) = \frac{A}{2} - \frac{A}{\pi} \sum_{n=1}^{\infty} \frac{1}{n} \sin n\omega t$$

**特点**：
- 含直流分量 $A/2$
- 含所有次谐波（奇次和偶次）
- 各次谐波振幅按 $1/n$ 衰减

### 3.4 全波整流波

**波形描述**：正弦波经全波整流后的波形，$f(t) = A|\sin \omega t|$。

**傅里叶级数**：

$$f(t) = \frac{2A}{\pi} - \frac{4A}{\pi} \left( \frac{1}{3}\cos 2\omega t + \frac{1}{15}\cos 4\omega t + \frac{1}{35}\cos 6\omega t + \cdots \right)$$

$$f(t) = \frac{2A}{\pi} - \frac{4A}{\pi} \sum_{n=1}^{\infty} \frac{1}{4n^2 - 1} \cos 2n\omega t$$

**特点**：
- 偶函数，只含余弦项
- 只含偶次谐波（$2, 4, 6, \ldots$）
- 直流分量为 $2A/\pi$
- 谐波振幅按 $1/n^2$ 衰减

### 3.5 半波整流波

**波形描述**：正弦波经半波整流后的波形，正半周保留，负半周为零。

**傅里叶级数**：

$$f(t) = \frac{A}{\pi} + \frac{A}{2}\sin \omega t - \frac{2A}{\pi} \left( \frac{1}{3}\cos 2\omega t + \frac{1}{15}\cos 4\omega t + \cdots \right)$$

**特点**：
- 含直流分量 $A/\pi$
- 含基波和偶次谐波
- 偶次谐波为余弦形式

### 3.6 各信号频谱特点对比

| 信号类型 | 直流分量 | 谐波成分 | 衰减速度 |
|---------|---------|---------|---------|
| 方波 | 0 | 奇次正弦 | $1/n$ |
| 三角波 | $A/2$ | 奇次余弦 | $1/n^2$ |
| 锯齿波 | $A/2$ | 全部正弦 | $1/n$ |
| 全波整流 | $2A/\pi$ | 偶次余弦 | $1/n^2$ |
| 半波整流 | $A/\pi$ | 基波+偶次余弦 | $1/n^2$ |

> **规律总结**：波形越平滑，高次谐波衰减越快。有跳变的波形（如方波）高次谐波
> 衰减慢，光滑波形（如三角波）高次谐波衰减快。

## 4. 频谱分析

### 4.1 幅度频谱与相位频谱

将傅里叶级数的各次谐波用图形表示，称为频谱图。

**幅度频谱**：以频率（或谐波次数 $n$）为横轴，以各次谐波的振幅 $A_n$ 为纵轴。

$$A_n = \sqrt{a_n^2 + b_n^2}$$

**相位频谱**：以频率为横轴，以各次谐波的初相位 $\varphi_n$ 为纵轴。

$$\varphi_n = -\arctan \frac{b_n}{a_n}$$

### 4.2 离散频谱的特点

周期信号的频谱具有以下特点：

1. **离散性**：频谱只在 $n\omega$（$n = 0, 1, 2, \ldots$）处有值，是离散的线状频谱
2. **谐波性**：各频率分量都是基频 $\omega$ 的整数倍
3. **收敛性**：对于满足狄里赫利条件的信号，谐波振幅随 $n$ 增大而趋于零

### 4.3 频带宽度

在实际应用中，不可能取无穷多次谐波。通常取有限次谐波来近似表示原信号。

**频带宽度的确定原则**：
- 当谐波振幅衰减到基波振幅的 $1/10$ 以下时，可以忽略
- 一般取到使累积振幅达到总振幅的 $90\%$ 以上的谐波次数

对于方波：$A_n = \frac{4A}{n\pi}$，当 $n > 10$ 时 $A_n < 0.1 A_1$，一般取 $5 \sim 7$ 次谐波即可。

对于三角波：$A_n = \frac{4A}{n^2\pi^2}$，衰减更快，取 $3 \sim 5$ 次谐波即可。

### 4.4 吉布斯现象

当用有限项傅里叶级数近似有跳变的函数时，在跳变点附近会出现过冲现象。

**吉布斯现象的特点**：
- 过冲量约为跳变幅度的 $9\%$（约 $8.95\%$）
- 增加谐波项数，过冲不会消失，但过冲的宽度会变窄
- 过冲峰值始终约为跳变幅度的 $9\%$
- 过冲向跳变点收缩，但峰值不减小

> **物理意义**：吉布斯现象说明傅里叶级数在间断点处的收敛是非一致的。
> 在连续点处，傅里叶级数收敛于函数值；在间断点处，收敛于左右极限的平均值。

## 5. 非正弦周期电路的分析

### 5.1 谐波分析法

非正弦周期电路的分析采用**谐波分析法**（叠加法），基本步骤为：

1. **傅里叶分解**：将非正弦周期激励展开为傅里叶级数
2. **分别计算**：对直流分量和各次谐波分别用相量法（或直流电路方法）求解
3. **叠加结果**：将各次谐波的瞬时响应叠加得到总响应

> **重要**：叠加法只适用于线性电路。非线性电路中各次谐波会相互作用产生新的频率分量。

### 5.2 各次谐波下的阻抗特性

在正弦稳态分析中，阻抗是频率的函数。对于第 $n$ 次谐波：

#### 电阻 $R$

$$Z_R = R$$

电阻的阻抗与频率无关，各次谐波下阻值相同。

#### 电感 $L$

$$Z_L = jn\omega L$$

感抗随谐波次数增大而增大：

$$X_{L,n} = n\omega L$$

- 第 $n$ 次谐波的感抗是基波感抗的 $n$ 倍
- 电感对高次谐波呈现更大的阻碍作用
- 电感具有**抑制高频**的作用

#### 电容 $C$

$$Z_C = \frac{1}{jn\omega C}$$

容抗随谐波次数增大而减小：

$$X_{C,n} = \frac{1}{n\omega C}$$

- 第 $n$ 次谐波的容抗是基波容抗的 $1/n$
- 电容对高次谐波呈现更小的阻碍作用
- 电容具有**通过高频**的作用

#### RLC串联电路

对于 $RLC$ 串联电路，第 $n$ 次谐波的阻抗为：

$$\dot{Z}_n = R + j\left(n\omega L - \frac{1}{n\omega C}\right)$$

阻抗模为：

$$|\dot{Z}_n| = \sqrt{R^2 + \left(n\omega L - \frac{1}{n\omega C}\right)^2}$$

阻抗角为：

$$\theta_n = \arctan \frac{n\omega L - \frac{1}{n\omega C}}{R}$$

### 5.3 各次谐波分别计算再叠加

对于非正弦周期电压源 $u(t) = U_0 + \sum_{n=1}^{\infty} U_{mn} \cos(n\omega t + \psi_n)$：

**直流分量**（$n=0$）：
- 电感相当于短路（$X_L = 0$）
- 电容相当于开路（$X_C = \infty$）
- 用直流电路分析方法求解

**第 $n$ 次谐波**（$n \geq 1$）：
- 用相量法求解
- 电感阻抗 $j n \omega L$
- 电容阻抗 $1/(j n \omega C)$
- 电阻阻抗不变

**总响应**为各次谐波响应的瞬时值叠加：

$$i(t) = I_0 + \sum_{n=1}^{\infty} I_{mn} \cos(n\omega t + \phi_n)$$

> **注意**：不同频率的相量不能直接相加，必须先化为瞬时表达式再叠加。

### 5.4 非正弦电路中电感和电容的特殊性质

| 元件 | 直流特性 | 低次谐波 | 高次谐波 | 作用 |
|------|---------|---------|---------|------|
| 电感 $L$ | 短路 | 阻抗较小 | 阻抗很大 | 低通特性 |
| 电容 $C$ | 开路 | 阻抗很大 | 阻抗较小 | 高通特性 |

## 6. 非正弦周期量的有效值

### 6.1 有效值的定义

周期信号的有效值（均方根值）定义为：

$$F = \sqrt{\frac{1}{T} \int_0^T f^2(t) \, dt}$$

### 6.2 非正弦周期量的有效值公式

设非正弦周期信号为：

$$f(t) = A_0 + \sum_{n=1}^{\infty} A_{mn} \cos(n\omega t + \varphi_n)$$

则其有效值为：

$$F = \sqrt{A_0^2 + \sum_{n=1}^{\infty} \frac{A_{mn}^2}{2}}$$

即：

$$F = \sqrt{A_0^2 + \frac{A_{m1}^2}{2} + \frac{A_{m2}^2}{2} + \frac{A_{m3}^2}{2} + \cdots}$$

### 6.3 各次谐波有效值的叠加

若用有效值表示各次谐波：$F_n = A_{mn}/\sqrt{2}$，则：

$$F = \sqrt{A_0^2 + F_1^2 + F_2^2 + F_3^2 + \cdots}$$

> **重要结论**：非正弦周期量的有效值等于直流分量的平方与各次谐波有效值的平方之
> 和再开方。**有效值是各次谐波有效值的"方和根"叠加，而非直接代数叠加。**

### 6.4 电压和电流的有效值

对于非正弦周期电压和电流：

$$U = \sqrt{U_0^2 + \sum_{n=1}^{\infty} U_n^2} = \sqrt{U_0^2 + U_1^2 + U_2^2 + \cdots}$$

$$I = \sqrt{I_0^2 + \sum_{n=1}^{\infty} I_n^2} = \sqrt{I_0^2 + I_1^2 + I_2^2 + \cdots}$$

其中 $U_n$ 和 $I_n$ 分别为第 $n$ 次谐波电压和电流的有效值。

## 7. 非正弦周期电路的平均功率

### 7.1 平均功率的定义

瞬时功率为：

$$p(t) = u(t) \cdot i(t)$$

平均功率为：

$$P = \frac{1}{T} \int_0^T u(t) \cdot i(t) \, dt$$

### 7.2 平均功率的计算公式

设电压和电流分别为：

$$u(t) = U_0 + \sum_{n=1}^{\infty} U_{mn} \cos(n\omega t + \psi_{un})$$

$$i(t) = I_0 + \sum_{n=1}^{\infty} I_{mn} \cos(n\omega t + \psi_{in})$$

则平均功率为：

$$P = U_0 I_0 + \sum_{n=1}^{\infty} U_n I_n \cos \varphi_n$$

其中：
- $\varphi_n = \psi_{un} - \psi_{in}$ 为第 $n$ 次谐波电压与电流的相位差
- $U_n = U_{mn}/\sqrt{2}$，$I_n = I_{mn}/\sqrt{2}$ 分别为第 $n$ 次谐波的有效值

展开形式：

$$P = U_0 I_0 + U_1 I_1 \cos \varphi_1 + U_2 I_2 \cos \varphi_2 + U_3 I_3 \cos \varphi_3 + \cdots$$

### 7.3 不同频率电压电流不产生功率的原理

**核心定理**：不同频率的正弦电压和电流的乘积在一个周期内的平均值为零。

数学证明：设 $u = U_m \cos m\omega t$，$i = I_m \cos(n\omega t + \varphi)$，当 $m \neq n$ 时：

$$\frac{1}{T} \int_0^T U_m \cos m\omega t \cdot I_m \cos(n\omega t + \varphi) \, dt = 0$$

这是因为不同频率正弦函数的乘积可以化为两个不同频率正弦函数之和，
其在一个周期内的积分为零。

> **重要结论**：只有同频率的电压和电流才能产生平均功率。
> 不同频率的电压电流之间不产生平均功率。

### 7.4 功率叠加的条件

平均功率可以叠加的条件是：

1. **同频率叠加**：只有同频率的电压电流对才产生功率
2. **各次谐波分别计算**：$P_n = U_n I_n \cos \varphi_n$
3. **总功率为各次谐波功率之和**：$P = P_0 + P_1 + P_2 + \cdots$

**功率因数**的定义在非正弦条件下为：

$$\cos \varphi = \frac{P}{UI}$$

其中 $U$、$I$ 为总有效值。

## 8. 滤波器在非正弦电路中的应用

### 8.1 低通滤波器

**电路结构**：$RC$ 串联，从电容两端取输出电压。

**频率特性**：

$$\dot{H}(j\omega) = \frac{1}{1 + j\omega RC}$$

**幅频特性**：

$$|H(\omega)| = \frac{1}{\sqrt{1 + (\omega RC)^2}}$$

**截止频率**：

$$\omega_c = \frac{1}{RC}$$

**滤波效果**：
- 当 $\omega \ll \omega_c$ 时，$|H| \approx 1$，信号几乎无衰减通过
- 当 $\omega \gg \omega_c$ 时，$|H| \approx 0$，信号被大幅衰减
- 高次谐波被滤除，保留低频分量和直流分量

**应用**：从非正弦信号中提取直流分量或基波分量，滤除高次谐波。

### 8.2 高通滤波器

**电路结构**：$RC$ 串联，从电阻两端取输出电压。

**频率特性**：

$$\dot{H}(j\omega) = \frac{j\omega RC}{1 + j\omega RC}$$

**幅频特性**：

$$|H(\omega)| = \frac{\omega RC}{\sqrt{1 + (\omega RC)^2}}$$

**滤波效果**：
- 当 $\omega \ll \omega_c$ 时，$|H| \approx 0$，低频信号被衰减
- 当 $\omega \gg \omega_c$ 时，$|H| \approx 1$，高频信号通过
- 直流分量被完全阻隔

**应用**：隔直流通交流，滤除直流分量。

### 8.3 带通滤波器

**电路结构**：$RLC$ 串联谐振电路。

**频率特性**：

$$\dot{H}(j\omega) = \frac{R}{R + j(\omega L - \frac{1}{\omega C})}$$

**谐振频率**：

$$\omega_0 = \frac{1}{\sqrt{LC}}$$

**滤波效果**：
- 在谐振频率 $\omega_0$ 附近，阻抗最小，信号通过
- 远离谐振频率的信号被衰减
- 可以选择特定次谐波通过

**应用**：从非正弦信号中选择特定频率分量。

### 8.4 滤波效果的分析

滤波器对非正弦信号的作用可以用传递函数分析：

设输入信号为 $u_i(t) = U_0 + \sum U_{mn} \cos(n\omega t + \psi_n)$

则输出信号为：

$$u_o(t) = H(0) \cdot U_0 + \sum_{n=1}^{\infty} |H(n\omega)| \cdot U_{mn} \cos(n\omega t + \psi_n + \angle H(n\omega))$$

其中 $H(0)$ 为直流增益，$|H(n\omega)|$ 为第 $n$ 次谐波的增益。

> **分析步骤**：先将输入信号傅里叶分解，然后对每个频率分量分别乘以该频率下
> 的传递函数值，最后叠加得到输出。

## 9. 典型题型与例题

### 9.1 题型一：傅里叶级数展开

**例题1**：求下图所示方波的傅里叶级数展开，方波幅值为 $A$，周期为 $T$。

**解**：

方波在一个周期内的表达式为：

$$f(t) = \begin{cases} A, & 0 < t < T/2 \\ -A, & T/2 < t < T \end{cases}$$

利用对称性分析：方波为奇函数且半波对称，因此只含奇次正弦项。

$$a_0 = 0, \quad a_n = 0$$

$$b_n = \frac{2}{T} \int_0^T f(t) \sin n\omega t \, dt$$

$$b_n = \frac{2}{T} \left[ \int_0^{T/2} A \sin n\omega t \, dt + \int_{T/2}^T (-A) \sin n\omega t \, dt \right]$$

$$b_n = \frac{2A}{T} \left[ -\frac{\cos n\omega t}{n\omega} \Big|_0^{T/2} + \frac{\cos n\omega t}{n\omega} \Big|_{T/2}^T \right]$$

$$b_n = \frac{2A}{n\omega T} \left[ -\cos n\pi + 1 + \cos 2n\pi - \cos n\pi \right]$$

$$b_n = \frac{2A}{n\pi} (1 - \cos n\pi) = \frac{2A}{n\pi} [1 - (-1)^n]$$

当 $n$ 为奇数时：$b_n = \frac{4A}{n\pi}$

当 $n$ 为偶数时：$b_n = 0$

因此：

$$f(t) = \frac{4A}{\pi} \left( \sin \omega t + \frac{1}{3}\sin 3\omega t + \frac{1}{5}\sin 5\omega t + \cdots \right)$$

### 9.2 题型二：非正弦周期电路的有效值计算

**例题2**：已知某电压 $u(t) = 100 + 60\sqrt{2}\cos \omega t + 40\sqrt{2}\cos 3\omega t \, \text{V}$，
求该电压的有效值。

**解**：

根据有效值公式：

$$U = \sqrt{U_0^2 + U_1^2 + U_3^2}$$

其中：
- 直流分量 $U_0 = 100 \, \text{V}$
- 基波有效值 $U_1 = 60 \, \text{V}$
- 三次谐波有效值 $U_3 = 40 \, \text{V}$

$$U = \sqrt{100^2 + 60^2 + 40^2} = \sqrt{10000 + 3600 + 1600} = \sqrt{15200}$$

$$U = 123.3 \, \text{V}$$

---

### 9.3 题型三：非正弦周期电路的功率计算

**例题3**：已知某二端网络的电压和电流分别为：

$$u(t) = 100 + 80\cos(\omega t + 30°) + 50\cos(3\omega t + 60°) \, \text{V}$$

$$i(t) = 5 + 6\cos(\omega t - 15°) + 4\cos(3\omega t + 45°) \, \text{A}$$

求该网络吸收的平均功率。

**解**：

平均功率公式：

$$P = U_0 I_0 + U_1 I_1 \cos \varphi_1 + U_3 I_3 \cos \varphi_3$$

**直流分量功率**：

$$P_0 = U_0 I_0 = 100 \times 5 = 500 \, \text{W}$$

**基波功率**：

$$U_1 = 80/\sqrt{2} = 40\sqrt{2} \, \text{V}, \quad I_1 = 6/\sqrt{2} = 3\sqrt{2} \, \text{A}$$

$$\varphi_1 = 30° - (-15°) = 45°$$

$$P_1 = 40\sqrt{2} \times 3\sqrt{2} \times \cos 45° = 240 \times \frac{\sqrt{2}}{2} = 120\sqrt{2} \approx 169.7 \, \text{W}$$

**三次谐波功率**：

$$U_3 = 50/\sqrt{2} \, \text{V}, \quad I_3 = 4/\sqrt{2} \, \text{A}$$

$$\varphi_3 = 60° - 45° = 15°$$

$$P_3 = \frac{50}{\sqrt{2}} \times \frac{4}{\sqrt{2}} \times \cos 15° = 100 \times \cos 15°$$

$$\cos 15° = \frac{\sqrt{6} + \sqrt{2}}{4} \approx 0.9659$$

$$P_3 = 100 \times 0.9659 = 96.6 \, \text{W}$$

**总功率**：

$$P = 500 + 169.7 + 96.6 = 766.3 \, \text{W}$$

### 9.4 题型四：含滤波器的非正弦电路分析

**例题4**：如图所示 $RC$ 低通滤波器，$R = 100 \, \Omega$，$C = 10 \, \mu\text{F}$，
输入电压为 $u_i(t) = 50 + 30\cos \omega t + 20\cos 3\omega t \, \text{V}$，
其中 $\omega = 1000 \, \text{rad/s}$，求输出电压 $u_o(t)$。

**解**：

截止频率：

$$\omega_c = \frac{1}{RC} = \frac{1}{100 \times 10 \times 10^{-6}} = 1000 \, \text{rad/s}$$

**直流分量**（$\omega = 0$）：

$$H(0) = 1$$

$$U_{o0} = 50 \times 1 = 50 \, \text{V}$$

**基波**（$\omega = 1000 \, \text{rad/s}$）：

$$H(j\omega) = \frac{1}{1 + j\omega RC} = \frac{1}{1 + j}$$

$$|H(\omega)| = \frac{1}{\sqrt{2}} = 0.707$$

$$\angle H(\omega) = -45°$$

$$U_{o1,m} = 30 \times 0.707 = 21.2 \, \text{V}$$

**三次谐波**（$3\omega = 3000 \, \text{rad/s}$）：

$$H(j3\omega) = \frac{1}{1 + j3}$$

$$|H(3\omega)| = \frac{1}{\sqrt{10}} = 0.316$$

$$\angle H(3\omega) = -\arctan 3 = -71.6°$$

$$U_{o3,m} = 20 \times 0.316 = 6.32 \, \text{V}$$

**输出电压**：

$$u_o(t) = 50 + 21.2\cos(\omega t - 45°) + 6.32\cos(3\omega t - 71.6°) \, \text{V}$$

**分析**：经过低通滤波器后，直流分量不变，基波略有衰减，三次谐波大幅衰减。
这体现了低通滤波器抑制高次谐波的作用。

### 9.5 题型五：非正弦电路综合分析

**例题5**：$RLC$ 串联电路中，$R = 10 \, \Omega$，$L = 0.05 \, \text{H}$，$C = 100 \, \mu\text{F}$，
外加电压 $u(t) = 100 + 60\sqrt{2}\cos \omega t + 40\sqrt{2}\cos 3\omega t \, \text{V}$，
其中 $\omega = 500 \, \text{rad/s}$。求电流 $i(t)$ 和电路的平均功率。

**解**：

**直流分量**：

电感短路、电容开路，电流为零（电路断路）。

$$I_0 = 0$$

**基波**（$\omega = 500 \, \text{rad/s}$）：

$$X_{L1} = \omega L = 500 \times 0.05 = 25 \, \Omega$$

$$X_{C1} = \frac{1}{\omega C} = \frac{1}{500 \times 100 \times 10^{-6}} = 20 \, \Omega$$

$$\dot{Z}_1 = R + j(X_{L1} - X_{C1}) = 10 + j(25 - 20) = 10 + j5 \, \Omega$$

$$|\dot{Z}_1| = \sqrt{10^2 + 5^2} = \sqrt{125} = 5\sqrt{5} \approx 11.18 \, \Omega$$

$$\varphi_1 = \arctan \frac{5}{10} = 26.57°$$

$$I_1 = \frac{U_1}{|\dot{Z}_1|} = \frac{60}{5\sqrt{5}} = \frac{12}{\sqrt{5}} \approx 5.37 \, \text{A}$$

**三次谐波**（$3\omega = 1500 \, \text{rad/s}$）：

$$X_{L3} = 3\omega L = 3 \times 25 = 75 \, \Omega$$

$$X_{C3} = \frac{1}{3\omega C} = \frac{20}{3} \approx 6.67 \, \Omega$$

$$\dot{Z}_3 = 10 + j(75 - 6.67) = 10 + j68.33 \, \Omega$$

$$|\dot{Z}_3| = \sqrt{10^2 + 68.33^2} = \sqrt{100 + 4669} = \sqrt{4769} \approx 69.06 \, \Omega$$

$$\varphi_3 = \arctan \frac{68.33}{10} = 81.68°$$

$$I_3 = \frac{U_3}{|\dot{Z}_3|} = \frac{40}{69.06} \approx 0.579 \, \text{A}$$

**电流瞬时值**：

$$i(t) = 0 + 5.37\sqrt{2}\cos(\omega t - 26.57°) + 0.579\sqrt{2}\cos(3\omega t - 81.68°) \, \text{A}$$

**平均功率**：

$$P = U_1 I_1 \cos \varphi_1 + U_3 I_3 \cos \varphi_3$$

$$P_1 = 60 \times 5.37 \times \cos 26.57° = 322.2 \times 0.894 = 288.1 \, \text{W}$$

$$P_3 = 40 \times 0.579 \times \cos 81.68° = 23.16 \times 0.1447 = 3.35 \, \text{W}$$

$$P = 288.1 + 3.35 = 291.5 \, \text{W}$$

> **结论**：在 $RLC$ 串联电路中，电感对高次谐波的阻碍作用远大于对基波的阻碍，
> 因此高次谐波电流很小。电路具有低通滤波特性。

## 10. 公式速查表

### 10.1 傅里叶级数

| 公式 | 表达式 |
|------|--------|
| 三角形式 | $f(t) = a_0 + \sum_{n=1}^{\infty} (a_n \cos n\omega t + b_n \sin n\omega t)$ |
| 余弦形式 | $f(t) = A_0 + \sum_{n=1}^{\infty} A_n \cos(n\omega t + \varphi_n)$ |
| 直流分量 | $a_0 = \frac{1}{T} \int_0^T f(t) \, dt$ |
| 余弦系数 | $a_n = \frac{2}{T} \int_0^T f(t) \cos n\omega t \, dt$ |
| 正弦系数 | $b_n = \frac{2}{T} \int_0^T f(t) \sin n\omega t \, dt$ |
| 振幅关系 | $A_n = \sqrt{a_n^2 + b_n^2}$ |
| 相位关系 | $\varphi_n = -\arctan(b_n / a_n)$ |

### 10.2 阻抗特性

| 元件 | 直流（$n=0$） | 第 $n$ 次谐波 |
|------|-------------|-------------|
| 电阻 $R$ | $R$ | $R$ |
| 电感 $L$ | $0$（短路） | $j n \omega L$ |
| 电容 $C$ | $\infty$（开路） | $\frac{1}{j n \omega C}$ |

### 10.3 有效值与功率

| 公式 | 表达式 |
|------|--------|
| 有效值 | $F = \sqrt{A_0^2 + \sum_{n=1}^{\infty} \frac{A_{mn}^2}{2}}$ |
| 有效值（用有效值表示） | $F = \sqrt{A_0^2 + F_1^2 + F_2^2 + \cdots}$ |
| 平均功率 | $P = U_0 I_0 + \sum_{n=1}^{\infty} U_n I_n \cos \varphi_n$ |

### 10.4 典型信号傅里叶级数

| 信号 | 傅里叶级数 |
|------|-----------|
| 方波 | $\frac{4A}{\pi}\sum_{n=1,3,5,...} \frac{1}{n}\sin n\omega t$ |
| 三角波 | $\frac{A}{2} - \frac{4A}{\pi^2}\sum_{n=1,3,5,...} \frac{1}{n^2}\cos n\omega t$ |
| 锯齿波 | $\frac{A}{2} - \frac{A}{\pi}\sum_{n=1}^{\infty} \frac{1}{n}\sin n\omega t$ |
| 全波整流 | $\frac{2A}{\pi} - \frac{4A}{\pi}\sum_{n=1}^{\infty} \frac{1}{4n^2-1}\cos 2n\omega t$ |

## 11. 解题技巧与注意事项

### 11.1 常见错误

1. **混用相量和瞬时值**：不同频率的相量不能直接相加，必须化为瞬时值后叠加
2. **忽略直流分量的特殊性**：直流分析时电感短路、电容开路
3. **有效值计算错误**：有效值是方和根叠加，不是代数叠加
4. **功率计算遗漏**：必须对每个频率分量分别计算功率再求和
5. **相位差计算**：功率计算中 $\varphi_n$ 是同频率电压与电流的相位差

### 11.2 解题步骤总结

1. **分析激励**：将非正弦周期激励展开为傅里叶级数
2. **判断对称性**：利用对称性简化系数计算
3. **分别求解**：对直流和各次谐波分别用相应方法求解
4. **注意阻抗**：不同频率下阻抗不同，需分别计算
5. **叠加结果**：化为瞬时值后叠加得到总响应
6. **计算有效值和功率**：用方和根公式和功率叠加公式
