## 2. 高频考点汇总

### 2.1 直流电路（必考，约30分）

#### 2.1.1 KCL/KVL方程列写

**KCL（基尔霍夫电流定律）**
- 表述：任一时刻，流入任一节点的电流之和等于流出该节点的电流之和
- 公式：∑I_in = ∑I_out 或 ∑I = 0
- 推广：适用于任意闭合面

**KVL（基尔霍夫电压定律）**
- 表述：任一时刻，沿任一闭合回路，各支路电压的代数和为零
- 公式：∑U = 0
- 推广：适用于任意假想闭合回路

**列写要点**：
1. 标定各支路电流参考方向
2. 标定各元件电压参考方向（关联参考方向）
3. 节点法：以节点为对象列KCL方程
4. 回路法：以回路为对象列KVL方程

#### 2.1.2 网孔法（回路电流法）

**基本思想**：以网孔电流为未知量，列写KVL方程

**标准形式**：
```
R₁₁·I₁ + R₁₂·I₂ + ... + R₁ₙ·Iₙ = U_S₁₁
R₂₁·I₁ + R₂₂·I₂ + ... + R₂ₙ·Iₙ = U_S₂₂
...
Rₙ₁·I₁ + Rₙ₂·I₂ + ... + Rₙₙ·Iₙ = U_Sₙₙ
```

**系数特点**：
- R_kk：第k个网孔的自电阻（恒为正）
- R_kj (k≠j)：第k和第j个网孔的互电阻
  - 两网孔电流同向流过公共支路：取正
  - 两网孔电流反向流过公共支路：取负
- U_Skk：第k个网孔中电压源的代数和

**步骤**：
1. 标定网孔电流方向（通常取顺时针）
2. 计算自电阻和互电阻
3. 计算等效电压源
4. 解方程组

**典型题**：含受控源电路的网孔分析

#### 2.1.3 节点电压法

**基本思想**：以节点电压为未知量，列写KCL方程

**标准形式**：
```
G₁₁·U₁ + G₁₂·U₂ + ... + G₁ₙ·Uₙ = I_S₁₁
G₂₁·U₁ + G₂₂·U₂ + ... + G₂ₙ·Uₙ = I_S₂₂
...
Gₙ₁·U₁ + Gₙ₂·U₂ + ... + Gₙₙ·Uₙ = I_Sₙₙ
```

**系数特点**：
- G_kk：第k个节点的自电导（恒为正）
- G_kj (k≠j)：第k和第j个节点的互电导（恒为负）
- I_Skk：流入第k个节点的电流源的代数和

**适用场景**：
- 节点数少于网孔数
- 含多个电流源

#### 2.1.4 叠加定理

**表述**：线性电路中，任一支路的电流（或电压）等于各独立电源单独作用时在该支路产生的电流（或电压）的代数和。

**使用要点**：
1. 仅适用于线性电路
2. "单独作用"意味着：
   - 不作用的电压源短路
   - 不作用的电流源开路
   - 受控源保留不动
3. 功率不能直接叠加（因为功率与电流/电压的平方成正比）

**典型应用**：
- 多个独立源的电路
- 求特定支路的响应
- 验证其他方法的计算结果

#### 2.1.5 戴维宁/诺顿等效

**戴维宁定理**：
- 任何线性有源二端网络，对外可用一个电压源和电阻的串联组合等效
- Uoc = 开路电压
- Req = 等效电阻

**诺顿定理**：
- 任何线性有源二端网络，对外可用一个电流源和电阻的并联组合等效
- Isc = 短路电流
- Req = 等效电阻

**求Req的方法**：
1. **外加电源法**：将内部独立源置零（电压源短路、电流源开路），从端口加电压U，求电流I，Req = U/I
2. **开路短路法**：Req = Uoc / Isc
3. **纯电阻网络**：直接串并联化简

**注意事项**：
- 含受控源时，不能用串并联化简
- 受控源必须保留，用外加电源法或开路短路法

#### 2.1.6 最大功率传输

**条件**：当负载电阻等于电源内阻时，负载获得最大功率

**公式**：
- RL = Req 时（共轭匹配）
- Pmax = Uoc² / (4·Req)

**推导**：
```
P = I²·RL = [Uoc/(Req+RL)]²·RL
令 dP/dRL = 0，解得 RL = Req
代入得 Pmax = Uoc²/(4·Req)
```

**效率**：最大功率传输时，效率为50%

#### 2.1.7 典型题型：含受控源电路的戴维宁等效

**例题**：求下图电路的戴维宁等效电路

```
电路图示意：
    +---R1---+---R2---+
    |        |        |
   (+)      (VCCS)    RL
   Us       g·U1     Uoc
    |        |        |
    +--------+--------+
```

**解题步骤**：
1. **求Uoc**：断开RL，用KVL/KCL或节点法求端口电压
2. **求Req**：
   - 方法一：外加电源法
     - 置零独立源（Us短路）
     - 端口加电压U，求I
     - Req = U/I
   - 方法二：开路短路法
     - 求Uoc（已求）
     - 求Isc（端口短路时的电流）
     - Req = Uoc/Isc
3. **画等效电路**：Uoc串联Req

### 2.2 正弦稳态（重点，约37分）

#### 2.2.1 阻抗/导纳计算

**阻抗定义**：
```
Z = U/I = R + jX
|Z| = √(R² + X²)
φ = arctan(X/R)
```

**基本元件的阻抗**：
| 元件 | 阻抗 | 导纳 |
|------|------|------|
| 电阻R | Z_R = R | Y_R = 1/R |
| 电感L | Z_L = jωL | Y_L = 1/(jωL) = -j/(ωL) |
| 电容C | Z_C = 1/(jωC) = -j/(ωC) | Y_C = jωC |

**串并联公式**：
- 串联：Z_eq = Z₁ + Z₂ + ... + Zₙ
- 并联：1/Z_eq = 1/Z₁ + 1/Z₂ + ... + 1/Zₙ
- 两个阻抗并联：Z_eq = (Z₁·Z₂)/(Z₁+Z₂)

#### 2.2.2 相量图分析

**绘制要点**：
1. 选择参考相量（通常选电压或电流）
2. 电阻电压与电流同相
3. 电感电压超前电流90°
4. 电容电压滞后电流90°
5. 用平行四边形法则求合成相量

**典型相量图**：

**RLC串联电路**：
```
        UL（超前90°）
         ↑
         |
   UR ---+---> I（参考方向）
         |
         ↓
        UC（滞后90°）

UL-UC: 感性（φ>0，电压超前电流）
UC-UL: 容性（φ<0，电流超前电压）
```

#### 2.2.3 功率计算

**瞬时功率**：
```
p(t) = u(t)·i(t) = UIcosφ + UIcos(2ωt-φ)
```

**有功功率（平均功率）**：
```
P = UIcosφ [W]
```
- cosφ为功率因数
- φ为阻抗角（电压与电流的相位差）

**无功功率**：
```
Q = UIsinφ [var]
```
- 感性电路：Q > 0（滞后无功）
- 容性电路：Q < 0（超前无功）

**视在功率**：
```
S = UI [VA]
```

**复功率**：
```
S = P + jQ = U·I* [VA]
```
- I*为电流相量的共轭

**功率三角形**：
```
        S
       /|
      / |
     /  | Q
    /   |
   /φ   |
  +-----+
    P

S = √(P² + Q²)
cosφ = P/S
sinφ = Q/S
```

**功率因数提高**：
- 并联电容可以提高功率因数
- 补偿容量：C = P(tanφ₁ - tanφ₂)/(ωU²)
- φ₁：补偿前功率因数角
- φ₂：补偿后功率因数角

#### 2.2.4 最大功率传输（共轭匹配）

**条件**：当负载阻抗等于电源内阻抗的共轭时，负载获得最大功率

**公式**：
```
ZL = Zs* = Rs - jXs
Pmax = Us² / (4·Rs)
```

**特殊情况**：
- 纯电阻匹配：RL = |Zs| 时，功率最大（但不是最大功率传输）
- 共轭匹配：ZL = Zs* 时，真正达到最大功率

#### 2.2.5 典型题型：功率因数提高+最大功率

**例题**：某感性负载接于220V、50Hz电源，功率P=10kW，功率因数cosφ₁=0.6。
(1) 求并联电容使功率因数提高到0.9所需的电容值
(2) 若电源内阻抗Zs=1+j2Ω，求负载获得的最大功率

**解题过程**：

**(1) 功率因数提高**
```
φ₁ = arccos0.6 = 53.13°
φ₂ = arccos0.9 = 25.84°
C = P(tanφ₁ - tanφ₂)/(ωU²)
  = 10000×(1.333 - 0.484)/(2π×50×220²)
  = 10000×0.849/(15205308)
  = 558μF
```

**(2) 最大功率**
```
共轭匹配条件：ZL = Zs* = 1 - j2 Ω
Pmax = Us²/(4Rs) = 220²/(4×1) = 12100W = 12.1kW
```

### 2.3 动态电路（重点，约30分）

#### 2.3.1 一阶电路三要素法

**三要素**：
1. **初始值** f(0⁺)
2. **稳态值** f(∞)
3. **时间常数** τ

**通用公式**：
```
f(t) = f(∞) + [f(0⁺) - f(∞)]·e^(-t/τ)
```

**求三要素**：

**初始值 f(0⁺)**：
- 换路定则：uC(0⁺) = uC(0⁻)，iL(0⁺) = iL(0⁻)
- 其他量：画0⁺等效电路
  - 电容用电压源替代
  - 电感用电流源替代

**稳态值 f(∞)**：
- 直流稳态：电容开路，电感短路
- 正弦稳态：用相量法求解

**时间常数 τ**：
- RC电路：τ = R₀·C
- RL电路：τ = L/R₀
- R₀为从储能元件看进去的戴维宁等效电阻

#### 2.3.2 二阶电路的响应

**RLC串联电路方程**：
```
LC·d²i/dt² + RC·di/dt + i = 0
特征方程：LCs² + RCs + 1 = 0
特征根：s₁, s₂ = (-R ± √(R² - 4L/C)) / (2L)
```

**三种响应形式**：

**过阻尼（R² > 4L/C）**：
```
s₁, s₂为不等负实根
i(t) = A₁·e^(s₁t) + A₂·e^(s₂t)
```

**临界阻尼（R² = 4L/C）**：
```
s₁ = s₂ = s为相等负实根
i(t) = (A₁ + A₂t)·e^(st)
```

**欠阻尼（R² < 4L/C）**：
```
s₁, s₂ = -α ± jωd
α = R/(2L)（衰减系数）
ωd = √(1/LC - (R/2L)²)（振荡角频率）
i(t) = e^(-αt)·(A₁cosωdt + A₂sinωdt)
```

#### 2.3.3 拉普拉斯变换法

**常用变换对**：
| f(t) | F(s) |
|------|------|
| δ(t) | 1 |
| 1(t) | 1/s |
| e^(-at) | 1/(s+a) |
| t·e^(-at) | 1/(s+a)² |
| sinωt | ω/(s²+ω²) |
| cosωt | s/(s²+ω²) |
| e^(-at)·sinωt | ω/((s+a)²+ω²) |
| e^(-at)·cosωt | (s+a)/((s+a)²+ω²) |

**s域电路模型**：
- 电阻：Z(s) = R
- 电感：Z(s) = sL，需考虑初始电流iL(0⁻)
  - 串联模型：sL + L·iL(0⁻)
  - 并联模型：1/(sL) + iL(0⁻)/s
- 电容：Z(s) = 1/(sC)，需考虑初始电压uC(0⁻)
  - 串联模型：1/(sC) + uC(0⁻)/s
  - 并联模型：sC + C·uC(0⁻)

**部分分式展开**：
```
F(s) = N(s)/D(s)
若D(s)有单实根p₁：F(s) = A₁/(s-p₁) + ...
若D(s)有重根p₁（k重）：F(s) = A₁/(s-p₁) + A₂/(s-p₁)² + ...
若D(s)有共轭复根α±jβ：F(s) = (As+B)/((s-α)²+β²) + ...
```

**求系数的方法**：
```
A₁ = [(s-p₁)·F(s)]|s=p₁（覆盖法）
```

#### 2.3.4 网络函数与频率响应

**网络函数定义**：
```
H(s) = 响应象函数 / 激励象函数
```

**频率响应**：
```
H(jω) = |H(jω)|·e^(jφ(ω))
```

**波特图**：
- 幅频特性：20lg|H(jω)| vs lgω
- 相频特性：φ(ω) vs lgω

**典型环节**：
| 环节 | 传递函数 | 幅频特性 |
|------|----------|----------|
| 比例 | K | 20lgK（水平线） |
| 积分 | 1/s | -20dB/dec |
| 微分 | s | +20dB/dec |
| 一阶滞后 | 1/(1+sτ) | 转折频率1/τ，-20dB/dec |
| 一阶超前 | 1+sτ | 转折频率1/τ，+20dB/dec |

#### 2.3.5 典型题型：二阶电路的s域分析

**例题**：RLC串联电路，R=4Ω，L=1H，C=0.25F，uC(0⁻)=2V，iL(0⁻)=1A，t=0时合闸，求i(t)。

**解题过程**：

**Step 1：画s域模型**
```
Z(s) = R + sL + 1/(sC) = 4 + s + 4/s
初始条件等效电源：L·iL(0⁻) = 1V，uC(0⁻)/s = 2/s
```

**Step 2：列s域方程**
```
I(s)·Z(s) = Us(s) - L·iL(0⁻) + uC(0⁻)/s
假设外加电源为0：I(s)·(s + 4 + 4/s) = 1 - 2/s
```

**Step 3：求解I(s)**
```
I(s) = (s - 2)/(s² + 4s + 4) = (s - 2)/(s+2)²
     = 1/(s+2) - 4/(s+2)²
```

**Step 4：拉氏逆变换**
```
i(t) = e^(-2t) - 4t·e^(-2t) = (1 - 4t)·e^(-2t) A, t≥0
```

### 2.4 三相电路（约15分）

#### 2.4.1 对称三相电路的计算

**基本关系**：
```
对称三相电压：
uA = Um·sinωt
uB = Um·sin(ωt - 120°)
uC = Um·sin(ωt + 120°)
```

**星形(Y)连接**：
```
线电压 = √3·相电压（超前30°）
UL = √3·UP
线电流 = 相电流
IL = IP
```

**三角形(△)连接**：
```
线电压 = 相电压
UL = UP
线电流 = √3·相电流（滞后30°）
IL = √3·IP
```

**Y-△等效变换**：
```
Y→△：Z△ = 3·ZY
△→Y：ZY = Z△/3
```

#### 2.4.2 不对称三相电路

**中性点位移**：
```
UNN' = (UA·YA + UB·YB + UC·YC) / (YA + YB + YC + YN)
```

**各相电压**：
```
UAN' = UA - UNN'
UBN' = UB - UNN'
UCN' = UC - UNN'
```

**中性线的作用**：
- 对称时：中性线无电流，不起作用
- 不对称时：中性线强制UNN'≈0，保证各相电压基本对称

#### 2.4.3 三相功率与两瓦特计法

**三相功率**：
```
P = 3·UP·IP·cosφ = √3·UL·IL·cosφ
Q = 3·UP·IP·sinφ = √3·UL·IL·sinφ
S = 3·UP·IP = √3·UL·IL
```

**两瓦特计法**：
```
P₁ = UL·IL·cos(φ - 30°)
P₂ = UL·IL·cos(φ + 30°)
P = P₁ + P₂ = √3·UL·IL·cosφ
```

**适用条件**：
- 三相三线制（无论对称与否）
- 三相四线制（仅对称时可用）

**功率因数角φ的判断**：
```
P₁ = P₂：φ = 0（纯阻性）
P₁ > P₂ > 0：0° < φ < 60°（感性或容性）
P₂ = 0：φ = 60°
P₂ < 0：φ > 60°
```

#### 2.4.4 典型题型：Y-△系统+功率计算

**例题**：对称三相电源线电压380V，接Y-△系统。负载△连接，每相阻抗Z=30+j40Ω。求：
(1) 负载相电流
(2) 线电流
(3) 三相总有功功率、无功功率、视在功率

**解题过程**：

**Step 1：求相电压**
```
UP = UL/√3 = 380/√3 = 220V
```

**Step 2：求负载相电流**
```
|Z| = √(30²+40²) = 50Ω
φ = arctan(40/30) = 53.13°
IP = UP/|Z| = 220/50 = 4.4A
```

**Step 3：求线电流**
```
IL = √3·IP = √3×4.4 = 7.62A
```

**Step 4：求功率**
```
cosφ = cos53.13° = 0.6
sinφ = sin53.13° = 0.8
P = √3·UL·IL·cosφ = √3×380×7.62×0.6 = 2994W
Q = √3·UL·IL·sinφ = √3×380×7.62×0.8 = 3992var
S = √3·UL·IL = √3×380×7.62 = 4993VA
```

### 2.5 二端口网络（约15分）

#### 2.5.1 Z/Y/T/H参数的求解

**Z参数（阻抗参数）**：
```
U₁ = Z₁₁·I₁ + Z₁₂·I₂
U₂ = Z₂₁·I₁ + Z₂₂·I₂

Z₁₁ = U₁/I₁ |I₂=0 （输出开路时的输入阻抗）
Z₁₂ = U₁/I₂ |I₁=0 （输入开路时的反向转移阻抗）
Z₂₁ = U₂/I₁ |I₂=0 （输出开路时的正向转移阻抗）
Z₂₂ = U₂/I₂ |I₁=0 （输入开路时的输出阻抗）
```

**Y参数（导纳参数）**：
```
I₁ = Y₁₁·U₁ + Y₁₂·U₂
I₂ = Y₂₁·U₁ + Y₂₂·U₂

Y₁₁ = I₁/U₁ |U₂=0 （输出短路时的输入导纳）
Y₁₂ = I₁/U₂ |U₁=0 （输入短路时的反向转移导纳）
Y₂₁ = I₂/U₁ |U₂=0 （输出短路时的正向转移导纳）
Y₂₂ = I₂/U₂ |U₁=0 （输入短路时的输出导纳）
```

**T参数（传输参数）**：
```
U₁ = A·U₂ - B·I₂
I₁ = C·U₂ - D·I₂

A = U₁/U₂ |I₂=0
B = -U₁/I₂ |U₂=0
C = I₁/U₂ |I₂=0
D = -I₁/I₂ |U₂=0
```

**H参数（混合参数）**：
```
U₁ = H₁₁·I₁ + H₁₂·U₂
I₂ = H₂₁·I₁ + H₂₂·U₂

H₁₁ = U₁/I₁ |U₂=0 （输出短路时的输入阻抗）
H₁₂ = U₁/U₂ |I₁=0 （输入开路时的反向电压传输比）
H₂₁ = I₂/I₁ |U₂=0 （输出短路时的正向电流传输比）
H₂₂ = I₂/U₂ |I₁=0 （输入开路时的输出导纳）
```

#### 2.5.2 参数间的转换

| 已知→待求 | Z | Y | T | H |
|-----------|---|---|---|---|
| Z | Z₁₁ Z₁₂<br>Z₂₁ Z₂₂ | Y₂₂/ΔY -Y₁₂/ΔY<br>-Y₂₁/ΔY Y₁₁/ΔY | A/C ΔT/C<br>1/C D/C | ΔH/H₂₂ H₁₂/H₂₂<br>-H₂₁/H₂₂ 1/H₂₂ |
| Y | Z₂₂/ΔZ -Z₁₂/ΔZ<br>-Z₂₁/ΔZ Z₁₁/ΔZ | Y₁₁ Y₁₂<br>Y₂₁ Y₂₂ | D/B -ΔT/B<br>-1/B A/B | 1/H₁₁ -H₁₂/H₁₁<br>H₂₁/H₁₁ ΔH/H₁₁ |
| T | A/C ΔT/C<br>1/C D/C | D/B -ΔT/B<br>-1/B A/B | A B<br>C D | -ΔH/H₂₁ -H₁₁/H₂₁<br>-H₂₂/H₂₁ -1/H₂₁ |
| H | ΔZ/Z₂₂ Z₁₂/Z₂₂<br>-Z₂₁/Z₂₂ 1/Z₂₂ | 1/Z₁₁ -Z₁₂/Z₁₁<br>Z₂₁/Z₁₁ ΔZ/Z₁₁ | B/D ΔT/D<br>-1/D C/D | H₁₁ H₁₂<br>H₂₁ H₂₂ |

**注**：ΔZ = Z₁₁Z₂₂ - Z₁₂Z₂₁，其他类似

#### 2.5.3 二端口网络的连接

**级联（串联）**：
```
T = T₁ · T₂
```

**并联**：
```
Y = Y₁ + Y₂
```

**串联**：
```
Z = Z₁ + Z₂
```

#### 2.5.4 典型题型：给定电路求参数+等效电路

**例题**：求下图电路的Z参数和T参数

```
电路图示意：
    +---Z1---+---Z3---+
    |        |        |
  (1)       Z2      (2)
    |        |        |
    +--------+--------+
```

**解题过程**：

**Step 1：求Z参数**
```
Z₁₁ = U₁/I₁ |I₂=0 = Z₁ + Z₂
Z₁₂ = U₁/I₂ |I₁=0 = Z₂
Z₂₁ = U₂/I₁ |I₂=0 = Z₂
Z₂₂ = U₂/I₂ |I₁=0 = Z₂ + Z₃
```

**Step 2：求T参数**
```
A = Z₁₁/Z₂₁ = (Z₁+Z₂)/Z₂
B = ΔZ/Z₂₁ = (Z₁Z₂+Z₁Z₃+Z₂Z₃)/Z₂
C = 1/Z₂₁ = 1/Z₂
D = Z₂₂/Z₂₁ = (Z₂+Z₃)/Z₂
```

**Step 3：画等效电路**
- T型等效电路或π型等效电路

### 2.6 非正弦周期电路（约12分）

#### 2.6.1 傅里叶级数展开

**一般形式**：
```
f(t) = a₀/2 + Σ[aₙcos(nωt) + bₙsin(nωt)]
     = A₀ + ΣAncos(nωt + φₙ)
```

**系数计算**：
```
a₀ = (1/π)∫f(t)d(t) （直流分量）
aₙ = (1/π)∫f(t)cos(nωt)d(ωt)
bₙ = (1/π)∫f(t)sin(nωt)d(ωt)

An = √(aₙ² + bₙ²)
φₙ = -arctan(bₙ/aₙ)
```

**常见波形的傅里叶级数**：

**方波**：
```
f(t) = (4Am/π)[sinωt + (1/3)sin3ωt + (1/5)sin5ωt + ...]
```

**三角波**：
```
f(t) = (8Am/π²)[sinωt - (1/9)sin3ωt + (1/25)sin5ωt - ...]
```

**半波整流**：
```
f(t) = (Am/π) + (Am/2)sinωt - (2Am/π)[(1/3)cos2ωt + (1/15)cos4ωt + ...]
```

**全波整流**：
```
f(t) = (2Am/π) - (4Am/π)[(1/3)cos2ωt + (1/15)cos4ωt + ...]
```

#### 2.6.2 有效值计算

**定义**：
```
F = √[(1/T)∫f²(t)dt]
```

**傅里叶级数形式**：
```
F = √(A₀² + A₁²/2 + A₂²/2 + A₃²/2 + ...)
  = √(A₀² + ΣAn²/2)
```

**常见波形有效值**：
| 波形 | 有效值 |
|------|--------|
| 正弦波 | Um/√2 |
| 方波 | Am |
| 三角波 | Am/√3 |
| 半波整流 | Am/2 |
| 全波整流 | Am/√2 |

#### 2.6.3 平均功率计算

**公式**：
```
P = U₀I₀ + ΣUnIncosφₙ
  = P₀ + P₁ + P₂ + P₃ + ...
```

**要点**：
- 只有同次谐波的电压电流才产生平均功率
- 不同频率的电压电流不产生平均功率
- 直流分量：P₀ = U₀I₀

**各次谐波的功率**：
```
Pₙ = UnIncosφₙ
Qₙ = UnInsinφₙ
```

#### 2.6.4 典型题型：非正弦信号作用下的RLC电路

**例题**：RLC串联电路，R=10Ω，L=0.1H，C=100μF，外加电压u(t) = 100 + 150sin(100t) + 100sin(200t+30°) V。求：
(1) 电路中的电流i(t)
(2) 电路的平均功率

**解题过程**：

**Step 1：直流分量（ω=0）**
```
Z₀ = R = 10Ω（电容开路，电感短路）
I₀ = U₀/Z₀ = 100/10 = 10A
P₀ = U₀I₀ = 100×10 = 1000W
```

**Step 2：基波分量（ω=100）**
```
XL1 = ωL = 100×0.1 = 10Ω
XC1 = 1/(ωC) = 1/(100×100×10⁻⁶) = 100Ω
Z₁ = R + j(XL1-XC1) = 10 + j(10-100) = 10 - j90 Ω
|Z₁| = √(10²+90²) = 90.55Ω
φ₁ = arctan(-90/10) = -83.66°
I₁ = U₁/|Z₁| = 150/90.55 = 1.656A
i₁(t) = 1.656sin(100t + 83.66°) A
P₁ = U₁I₁cosφ₁ = 150×1.656×cos(-83.66°) = 27.3W
```

**Step 3：二次谐波分量（ω=200）**
```
XL2 = 2ωL = 200×0.1 = 20Ω
XC2 = 1/(2ωC) = 1/(200×100×10⁻⁶) = 50Ω
Z₂ = R + j(XL2-XC2) = 10 + j(20-50) = 10 - j30 Ω
|Z₂| = √(10²+30²) = 31.62Ω
φ₂ = arctan(-30/10) = -71.57°
I₂ = U₂/|Z₂| = 100/31.62 = 3.162A
i₂(t) = 3.162sin(200t + 30° + 71.57°) = 3.162sin(200t + 101.57°) A
P₂ = U₂I₂cosφ₂ = 100×3.162×cos(-71.57°) = 100W
```

**Step 4：合成电流**
```
i(t) = I₀ + i₁(t) + i₂(t)
     = 10 + 1.656sin(100t + 83.66°) + 3.162sin(200t + 101.57°) A
```

**Step 5：总平均功率**
```
P = P₀ + P₁ + P₂ = 1000 + 27.3 + 100 = 1127.3W
```

### 2.7 互感与变压器（约11分）

#### 2.7.1 同名端判定

**定义**：当两个电流同时从同名端流入（或流出）时，互感磁通与自感磁通方向相同。

**判定方法**：

**方法一：右手定则**
1. 假设电流从一端流入
2. 用右手定则判断磁通方向
3. 若两个线圈的磁通同向，则电流流入端为同名端

**方法二：实验法**
1. 将一个线圈接直流电源
2. 用检流计接另一个线圈
3. 合闸瞬间，若检流计正偏，则电源正极和检流计正极所接端子为同名端

**标注方法**：
```
用 "*" 或 "·" 标记同名端

  *----       ----*
  |    |     |    |
  L₁   |  M  |   L₂
  |    |     |    |
  *----       ----*
```

#### 2.7.2 T型等效法

**含互感的电路**：
```
U₁ = jωL₁·I₁ + jωM·I₂
U₂ = jωM·I₁ + jωL₂·I₂
```

**T型等效电路**：
```
  (L₁-M)         (L₂-M)
  ┌────┐         ┌────┐
──┤    ├──┬──┬──┤    ├──
  └────┘  │  │  └────┘
          │M │
          └──┘
```

**等效参数**：
```
Z₁ = jω(L₁ - M)
Z₂ = jω(L₂ - M)
Z₃ = jωM
```

**注意事项**：
- 当L₁ < M或L₂ < M时，等效阻抗为负，物理上仍成立
- T型等效适用于两线圈有公共端的情况

#### 2.7.3 理想变压器的阻抗变换

**理想变压器条件**：
1. 无损耗（R₁=R₂=0）
2. 无漏磁（全耦合，k=1）
3. L₁, L₂, M → ∞，但匝数比n = N₁/N₂ = √(L₁/L₂)有限

**基本关系**：
```
U₁/U₂ = N₁/N₂ = n
I₁/I₂ = N₂/N₁ = 1/n
```

**阻抗变换**：
```
Z₁' = n²·Z₂
```
- Z₂为副边阻抗
- Z₁'为折算到原边的等效阻抗

**阻抗匹配**：
- 当Z₁ = n²·Z₂*时，实现共轭匹配
- 纯电阻匹配：R₁ = n²·R₂

#### 2.7.4 典型题型：含互感的电路分析

**例题**：两线圈耦合，L₁=4H，L₂=1H，M=1H，R₁=10Ω，R₂=5Ω。原边接220V、50Hz电源，副边短路。求：
(1) 原边电流
(2) 副边电流

**解题过程**：

**Step 1：计算感抗**
```
XL1 = ωL₁ = 2π×50×4 = 1256.6Ω
XL2 = ωL₂ = 2π×50×1 = 314.2Ω
XM = ωM = 2π×50×1 = 314.2Ω
```

**Step 2：列方程**
```
原边：U₁ = (R₁ + jXL1)·I₁ - jXM·I₂
副边：0 = -jXM·I₁ + (R₂ + jXL2)·I₂
```

**Step 3：解方程**
```
由副边方程：I₂ = (jXM/(R₂ + jXL2))·I₁
代入原边方程：
U₁ = (R₁ + jXL1)·I₁ - jXM·(jXM/(R₂ + jXL2))·I₁
   = [R₁ + jXL1 + XM²/(R₂ + jXL2)]·I₁

Zeq = R₁ + jXL1 + XM²/(R₂ + jXL2)
    = 10 + j1256.6 + (314.2)²/(5 + j314.2)
    = 10 + j1256.6 + 98722/(5 + j314.2)
    = 10 + j1256.6 + 98722(5 - j314.2)/(5² + 314.2²)
    = 10 + j1256.6 + (493610 - j31035)/(25 + 98722)
    = 10 + j1256.6 + (493610 - j31035)/98747
    = 10 + j1256.6 + 5.0 - j0.314
    = 15 + j1256.3 Ω
```

**Step 4：求电流**
```
|Zeq| = √(15² + 1256.3²) = 1256.4Ω
I₁ = U₁/|Zeq| = 220/1256.4 = 0.175A

I₂ = (XM/|R₂ + jXL2|)·I₁
   = (314.2/√(5² + 314.2²))×0.175
   = (314.2/314.24)×0.175
   = 0.175A
```

## 3. 解题方法论

### 3.1 电路分析通用步骤

```
Step 1: 画电路图、标参考方向
        ↓
Step 2: 选择分析方法
        ↓
Step 3: 列方程、解方程
        ↓
Step 4: 检验（功率平衡、KCL/KVL）
```

**详细说明**：

**Step 1：画电路图、标参考方向**
- 重画电路图，避免交叉线
- 标注所有元件参数
- 标定电压、电流参考方向
- 关联参考方向：电压降方向与电流方向一致

**Step 2：选择分析方法**
- 根据电路特点选择最优方法
- 考虑未知量个数
- 考虑计算复杂度

**Step 3：列方程、解方程**
- 按照所选方法的标准步骤列方程
- 注意正负号
- 用计算器或软件求解

**Step 4：检验结果**
- 功率平衡：电源发出功率 = 负载吸收功率
- KCL：节点电流代数和为零
- KVL：回路电压代数和为零
- 量纲检查

### 3.2 方法选择指南

| 电路特点 | 推荐方法 | 理由 |
|----------|----------|------|
| 支路少 | 支路电流法 | 方程数少 |
| 网孔少 | 网孔法 | 方程数等于网孔数 |
| 节点少 | 节点电压法 | 方程数等于独立节点数 |
| 多电源 | 叠加定理 | 分别计算再叠加 |
| 求特定支路 | 戴维宁/诺顿等效 | 只需求Uoc和Req |
| 含受控源 | 先控制量再求解 | 控制量是关键 |
| 正弦稳态 | 相量法 | 复数运算 |
| 动态电路 | 三要素法/拉氏变换 | 系统化方法 |
| 三相电路 | 单相等效电路 | 对称时简化计算 |
| 二端口网络 | 参数矩阵法 | 矩阵运算规范 |

### 3.3 计算技巧

#### 3.3.1 阻抗串并联简化

**串联**：
```
Zeq = Z₁ + Z₂ + ... + Zₙ
|Zeq| = √[(ΣR)² + (ΣX)²]
```

**并联**：
```
两个阻抗：Zeq = (Z₁·Z₂)/(Z₁+Z₂)
多个阻抗：1/Zeq = 1/Z₁ + 1/Z₂ + ... + 1/Zₙ
```

**技巧**：
- 先化简，再计算
- 利用阻抗的模和角计算
- 并联时用导纳更方便

#### 3.3.2 分压分流的灵活运用

**分压公式**：
```
U₁ = U·(Z₁/(Z₁+Z₂))
U₂ = U·(Z₂/(Z₁+Z₂))
```

**分流公式**：
```
I₁ = I·(Z₂/(Z₁+Z₂))
I₂ = I·(Z₁/(Z₁+Z₂))
```

**技巧**：
- 串联分压，并联分流
- 注意是阻抗分压，不是电阻分压
- 正弦稳态中，分压分流是复数运算

#### 3.3.3 对称性的利用

**电路对称性**：
- 对称点等电位
- 对称支路电流相等
- 可以沿对称轴切开

**常见对称电路**：
- 桥式电路平衡时
- 对称三相电路
- 对称二端口网络

#### 3.3.4 复数运算技巧

**极坐标形式**：
```
Z = |Z|∠φ = |Z|(cosφ + jsinφ)
```

**乘除法**：
```
Z₁·Z₂ = |Z₁|·|Z₂|∠(φ₁+φ₂)
Z₁/Z₂ = (|Z₁|/|Z₂|)∠(φ₁-φ₂)
```

**加减法**：
```
用直角坐标形式
Z₁+Z₂ = (R₁+R₂) + j(X₁+X₂)
```

**计算器技巧**：
- 用复数模式计算
- 或分别计算模和角
- 验算时用另一种形式

## 4. 易错点大全

### 4.1 参考方向

#### 4.1.1 电压电流参考方向

**关联参考方向**：
```
电流从电压正极流入
    +---→---+
    |   I   |
   (+)     (-)
    |       |
    +-------+
    U
```

**非关联参考方向**：
```
电流从电压负极流入
    +---←---+
    |   I   |
   (+)     (-)
    |       |
    +-------+
    U
```

**功率计算**：
```
关联参考方向：P = UI（吸收功率）
非关联参考方向：P = -UI（发出功率）
```

**易错点**：
- 忘记检查参考方向是否关联
- 功率正负号搞反
- 受控源的方向判断错误

#### 4.1.2 受控源的方向判断

**四种受控源**：
```
VCVS（电压控制电压源）
VCCS（电压控制电流源）
CCVS（电流控制电压源）
CCCS（电流控制电流源）
```

**判断要点**：
1. 找到控制量（电压或电流）
2. 确定控制量的参考方向
3. 受控源的极性/方向与控制量的关系
4. 注意比例系数的正负

**易错点**：
- 控制量的参考方向搞错
- 受控源的极性标反
- 忘记保留受控源（叠加定理中）

### 4.2 正弦稳态

#### 4.2.1 阻抗角与功率因数角

**阻抗角**：
```
φ = arctan(X/R)
X > 0：感性，φ > 0，电压超前电流
X < 0：容性，φ < 0，电流超前电压
```

**功率因数角**：
```
cosφ = P/S = R/|Z|
φ = arccos(P/S)
```

**易错点**：
- 混淆阻抗角和功率因数角（它们是同一个角）
- 感性/容性判断错误
- 功率因数角的正负搞反

#### 4.2.2 复功率的计算

**复功率公式**：
```
S = U·I* = P + jQ
```
- I*为电流相量的共轭
- P为有功功率
- Q为无功功率

**易错点**：
- 忘记取共轭
- 无功功率的符号搞反
- 视在功率不等于复功率的模

#### 4.2.3 谐振条件

**串联谐振**：
```
ωL = 1/(ωC)
ω₀ = 1/√(LC)
f₀ = 1/(2π√(LC))
```

**并联谐振**：
```
ωL = 1/(ωC)（理想情况）
ω₀ = 1/√(LC)
```

**易错点**：
- 串联谐振时阻抗最小，并联谐振时阻抗最大
- 谐振时功率因数为1
- 品质因数Q的定义和计算

### 4.3 动态电路

#### 4.3.1 初始值(0⁻/0⁺)的区分

**0⁻状态**：换路前瞬间
- 电路处于稳态
- 电容视为开路（直流）
- 电感视为短路（直流）

**0⁺状态**：换路后瞬间
- 换路定则：uC(0⁺) = uC(0⁻)，iL(0⁺) = iL(0⁻)
- 其他量需要重新计算
- 画0⁺等效电路

**易错点**：
- 混淆0⁻和0⁺
- 忘记换路定则的适用条件
- 其他量直接用0⁻的值

#### 4.3.2 换路定则的适用条件

**适用条件**：
- 电容电流有限时，uC连续
- 电感电压有限时，iL连续

**不适用情况**：
- 理想电压源直接给电容充电
- 理想电流源直接给电感充电
- 冲激函数作用

**易错点**：
- 不检查适用条件就使用
- 忘记验证电流/电压是否有限

#### 4.3.3 时间常数的计算

**RC电路**：
```
τ = R₀·C
R₀为从电容看进去的戴维宁等效电阻
```

**RL电路**：
```
τ = L/R₀
R₀为从电感看进去的戴维宁等效电阻
```

**易错点**：
- R₀求错（忘记置零独立源）
- 含受控源时用串并联化简
- 忘记单位换算

### 4.4 三相电路

#### 4.4.1 线电压与相电压的关系

**Y连接**：
```
UL = √3·UP（仅对称时成立）
线电压超前对应相电压30°
```

**△连接**：
```
UL = UP（始终成立）
线电流滞后对应相电流30°（对称时）
```

**易错点**：
- 在不对称电路中使用√3倍关系
- 相位关系搞错
- Y-△转换时忘记乘3或除3

#### 4.4.2 中性线的作用

**对称电路**：
- 中性线无电流
- 中性线可以去掉
- 各相电压对称

**不对称电路**：
- 中性线有电流
- 中性线强制中性点电位为零
- 保证各相电压基本对称

**易错点**：
- 不对称时去掉中性线
- 忘记计算中性线电流
- 中性点电位计算错误

#### 4.4.3 两瓦特计法

**适用条件**：
- 三相三线制（无论对称与否）
- 三相四线制（仅对称时可用）

**读数含义**：
```
P₁ = UL·IL·cos(φ - 30°)
P₂ = UL·IL·cos(φ + 30°)
P = P₁ + P₂
```

**易错点**：
- 在不对称三相四线制中使用
- 功率因数角判断错误
- 忘记P₁和P₂可以为负

### 4.5 二端口网络

#### 4.5.1 参数矩阵的行列式关系

**互易条件**：
```
Z参数：Z₁₂ = Z₂₁
Y参数：Y₁₂ = Y₂₁
T参数：AD - BC = 1
H参数：H₁₂ = -H₂₁
```

**对称条件**：
```
Z参数：Z₁₁ = Z₂₂
Y参数：Y₁₁ = Y₂₂
T参数：A = D
H参数：H₁₁H₂₂ - H₁₂H₂₁ = 1
```

**易错点**：
- 混淆互易和对称条件
- T参数的互易条件是AD-BC=1，不是AD=BC
- 忘记检查互易性/对称性

#### 4.5.2 参数转换公式的记忆技巧

**Z↔Y转换**：
```
Y = Z⁻¹ = adj(Z)/det(Z)
```

**Z↔T转换**：
```
记住T参数的定义，用Z参数表示
```

**技巧**：
- 理解定义比记忆公式更重要
- 用矩阵运算推导
- 检查互易性/对称性作为验证

## 附录：常用数学工具

### A.1 复数运算

**直角坐标**：
```
Z = a + jb
|Z| = √(a² + b²)
φ = arctan(b/a)
```

**极坐标**：
```
Z = |Z|∠φ = |Z|(cosφ + jsinφ)
```

**欧拉公式**：
```
e^(jφ) = cosφ + jsinφ
```

**运算规则**：
```
乘法：模相乘，角相加
除法：模相除，角相减
加减：用直角坐标
```

### A.2 微分方程

**一阶线性方程**：
```
y' + P(x)y = Q(x)
通解：y = e^(-∫Pdx)[∫Q·e^(∫Pdx)dx + C]
```

**二阶常系数齐次方程**：
```
y'' + py' + qy = 0
特征方程：r² + pr + q = 0
两个不等实根：y = C₁e^(r₁x) + C₂e^(r₂x)
两个相等实根：y = (C₁ + C₂x)e^(rx)
共轭复根：y = e^(αx)(C₁cosβx + C₂sinβx)
```

### A.3 拉普拉斯变换

**线性性质**：
```
L{af + bg} = aF(s) + bG(s)
```

**微分性质**：
```
L{f'} = sF(s) - f(0)
L{f''} = s²F(s) - sf(0) - f'(0)
```

**积分性质**：
```
L{∫f dτ} = F(s)/s
```

**位移性质**：
```
L{e^(at)f(t)} = F(s-a)
```

**延迟性质**：
```
L{f(t-a)·1(t-a)} = e^(-as)F(s)
```
