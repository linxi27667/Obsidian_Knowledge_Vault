# 项目技术栈（只回答“用了什么”）

## 核心概念

- ==主框架是 ESP-IDF，不是 Arduino==。
- ==P4 负责高性能多媒体，S3 负责无线和分布式 IO==。
- ==技术栈分为系统、AI、通信、UI、硬件五层==。

## 一、硬件平台

| 硬件 | 角色 | 关键能力 |
|---|---|---|
| ESP32-P4 | 中央中控 | 双核 RISC-V、MIPI-DSI/CSI、PPA、PSRAM |
| ESP32-C6（板载） | P4 无线协处理 | 经 ESP-Hosted SDIO 提供 Wi-Fi |
| ESP32-S3 ×3 | 楼层节点 | Wi-Fi、GPIO、ADC、LEDC、UART |
| P4 Function EV Board | 主控载板 | 1024×600 LCD、GT911、ES8311、SC2336、TF 卡 |

## 二、系统软件

| 技术 | 用途 | 入口 |
|---|---|---|
| ESP-IDF `>=5.5.2` | 驱动、网络、构建、系统服务 | 根 `CMakeLists.txt` |
| FreeRTOS | 任务、事件组、定时器、同步 | `main/application.cc` |
| C/C++ | C++ 主控与 C 风格 UI/从机 | `main/`、`slave/` |
| NVS | 网络配置、自动模式、键值持久化 | `main/main.cc` |
| SPIFFS 分区 | UI 资源与人脸数据库 | `partitions/v2/16m.csv` |

## 三、AI 与多媒体

| 技术 | 作用 | 目录 |
|---|---|---|
| 小智 MQTT/WebSocket | STT、LLM、TTS、音频通道 | `main/protocols/` |
| MCP | LLM 意图映射为本地工具 | `main/mcp_server.*` |
| ESP-DL | P4 本地人脸识别 | `face_recognition.cc` |
| esp_video | MIPI-CSI 摄像头取帧 | P4 板级 |
| AudioService/ES8311 | 音频采集、处理和播放 | `main/audio/` |
| AFE 唤醒词 | NIHAOXIAOZHI_TTS | sdkconfig |

## 四、UI 与通信

| 技术 | 作用 | 当前配置 |
|---|---|---|
| LVGL | 触控 GUI | 9.4.0 |
| esp_lvgl_port | 显示/触摸适配 | 约 2.7 |
| ESP-Hosted / Wi-Fi Remote | P4 联网 | 4-bit SDIO，目标 C6 |
| 智能家居 MQTT | P4↔S3 二进制协议 | Broker `8.134.167.240:1883` |
| 二进制 packed 结构 | 命令/心跳/场景 | `shared/mqtt_iot_protocol.h` |

> [!NOTE]
> 小智云端 MQTT/WebSocket 与智能家居设备 MQTT 是两套业务协议：前者承载 AI 对话，后者承载设备控制。

## 五、智能家居业务技术

| 技术点 | 作用 |
|---|---|
| 设备模型 | UI/规则/网络的单一事实源 |
| UI 事件队列 + 50 ms timer | 跨线程安全刷新 |
| 自动模式 / 规则引擎 | 火警、雨天、求助、定时氛围 |
| 场景编排 | 一次意图 → 多楼层命令 |
| 心跳超时 60s | 楼层离线判定 |
| 舵机协议 index 6 起 | 逻辑设备与本地数组解耦 |

## 六、构建与资源

| 项目 | 当前配置 |
|---|---|
| Target | `esp32p4` |
| Board | `ESP_P4_FUNCTION_EV_BOARD` |
| Flash | 16 MB QIO |
| PSRAM | 200 MHz + XIP |
| 分区 | 单 factory App + assets + face_db |
| 主任务栈 | 10240 |
| FreeRTOS HZ | 1000 |
| 构建 | CMake + Ninja + `idf.py` / `idf.cmd` |

## 七、技术栈关系

```text
ESP-IDF
├─ FreeRTOS
├─ 网络：ESP-Hosted(C6) / MQTT
├─ UI：LVGL 9.4 / MIPI-DSI
├─ 音频：AudioService / ES8311 / AFE 唤醒
├─ 视觉：esp_video / ESP-DL
└─ 驱动：I2C / UART / ADC / GPIO / LEDC

业务层
├─ 小智协议（云端 AI）
├─ MCP Server
├─ 智能家居 MQTT（设备）
├─ 设备模型与规则
└─ P4/S3 共享协议
```
