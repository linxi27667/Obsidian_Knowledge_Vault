# P4 主控源码精读（Application 是整个系统的总线）

## 核心概念

- ==`Application` 负责业务编排，`Board` 负责硬件抽象==。
- ==主事件循环通过 EventGroup 被动唤醒==。
- ==协议、摄像头和网络回调通过 `Schedule()` 回到主任务==。
- 源码根：`E:/MCU/esp32/p4/xiaozhi-for-p4`

## 四、Initialize 真实顺序

来源：`Application::Initialize()`

```text
1. SetDeviceState(kDeviceStateStarting)
2. display->SetupUI()
3. audio_service_.Initialize/Start + 绑定回调
   - on_send_queue_available → MAIN_EVENT_SEND_AUDIO
   - on_wake_word_detected   → MAIN_EVENT_WAKE_WORD_DETECTED
   - on_vad_change           → MAIN_EVENT_VAD_CHANGE
4. state_machine_ listener → MAIN_EVENT_STATE_CHANGED
5. clock_timer 1s 周期 → MAIN_EVENT_CLOCK_TICK
6. McpServer::AddCommonTools + AddUserOnlyTools
7. SmartHomeMcp_RegisterTools()
8. FaceMcp_RegisterTools()
9. login_ui_init + 订阅 LOGIN_SUCCESS/FAILED
10. xTaskCreatePinnedToCore(face_recognition_task, "face_recog",
                            12*1024, prio=4, core=1)
11. SetDeviceState(kDeviceStateLocked) + login_ui_show()
12. board.SetNetworkEventCallback(...)
13. SmartHomeTasksStart()          // 网络前先起智能家居层
14. xTaskCreate(network_start, 8192, prio=5)
    → Board::StartNetwork()
```

## 五、Run 主循环

```text
Application::Run()
→ 当前任务优先级设为 10
→ xEventGroupWaitBits(ALL_EVENTS, portMAX_DELAY)
→ 按位置位处理
```

| 事件 | 处理要点 |
|---|---|
| `SCHEDULE` | 取出 `main_tasks_` 在主任务执行 |
| `SEND_AUDIO` | 上传音频包 |
| `WAKE_WORD_DETECTED` | 非 Locked 时进入对话 |
| `CLOCK_TICK` | 状态栏；每 10s `PrintHeapStats()` |
| `NETWORK_CONNECTED` | 进入激活流程 |
| `TOGGLE_CHAT/START/STOP` | 用户交互 |
| `STATE_CHANGED` | `HandleStateChangedEvent` |

## 六、Schedule

```cpp
void Application::Schedule(std::function<void()>&& callback) {
    { lock; main_tasks_.push_back(std::move(callback)); }
    xEventGroupSetBits(event_group_, MAIN_EVENT_SCHEDULE);
}
```

用途：MCP `DoToolCall`、人脸 UI 更新、协议 JSON 回调中的状态切换。原则：==回调短，重活投递主任务==。

## 七、协议回调

`InitializeProtocol()` 根据 OTA 配置选择 `MqttProtocol` 或 `WebsocketProtocol`（默认 MQTT）。

| JSON type | 动作 |
|---|---|
| `tts` | start→Speaking；stop→Listening/Idle；sentence_start 显示文本 |
| `stt` | 用户文本 |
| `llm` | 表情 |
| **`mcp`** | `McpServer::ParseMessage(payload)` |
| `system` | 重启等 |
| `alert` | 告警 UI 与音效 |

网络连接后：

```text
HandleNetworkConnectedEvent
→ 若非 Locked → Activating
→ xTaskCreate(ActivationTask, 8KB, prio=2)
   CheckAssetsVersion → CheckNewVersion → InitializeProtocol
→ MAIN_EVENT_ACTIVATION_DONE
→ Idle（若未锁定）
```

> [!WARNING]
> 当前分区是单 factory App，`CheckNewVersion` 中固件 OTA 升级被显式禁用。

## 八、状态机

来源：`main/device_state.h`、`device_state_machine.cc`

```text
Unknown → Starting
Starting → WifiConfiguring | Activating | Locked
Activating → Upgrading | Idle | WifiConfiguring
Idle → Connecting | Listening | Speaking | Activating
     | Upgrading | WifiConfiguring | Locked
Listening ↔ Speaking ↔ Idle
Locked → Idle | Activating | WifiConfiguring
FatalError → (无出口)
```

`HandleStateChangedEvent` 摘要：

| 状态 | 行为 |
|---|---|
| Idle | STANDBY，关语音处理，开唤醒 |
| Locked | 关语音 + 唤醒 |
| Listening | `SendStartListening`，开语音处理 |
| Speaking | 关语音（非 Realtime），ResetDecoder |
| WifiConfiguring | 关语音 + 唤醒 |

锁定时忽略 ToggleChat / WakeWord。

## 十四、自动模式与规则

来源：`auto_mode.c`、`rule_engine.c`

- `rule_engine_on_event` → 转 `auto_mode_on_event`
- 触发节流：距上次 ≥10s；距手动覆盖 ≥60s
- **FIRE_ALARM**：开天窗/灯/大门/红闪（同 FIRE 场景）
- **RAIN_ALARM**：收 2/3 晾衣杆、雨氛围、关天窗
- **HELP_ALARM**：对应楼层 warning 氛围
- tick：18:00 暖归家氛围；23:00 睡眠氛围 + 关全灯
