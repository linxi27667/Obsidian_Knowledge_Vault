# 智慧庭院导读（语音场景 + 本地安全 + 数字孪生）

## 核心概念

- ==主机负责智能交互，从机负责实时执行与传感器熔断==。
- ==场景不是“几个灯开关”，而是成语意境 + 自动接管 + 手动优先==。
- ==Android App 是数字孪生展示层，不是实时安全决策层==。
- 与 P4 三层智能家居是**不同场景产品**：庭院沙盘 vs 楼宇中控。

## 一、项目是什么

```text
用户语音 / Web / Android App
        ↓
小智主机 ESP32-S3
  语音 · MCP(self.garden.*) · MQTT 控制器 · TTS/蜂鸣器
        ↓ Wi-Fi + MQTT (8.134.167.240)
庭院从机 ESP32-S3 (device_id=10)
  灯/继电器/WS2812/舵机 · 土壤/雨滴/DHT11/火焰/求助
  自动模式 · 火灾本地熔断 · 能耗积分 NVS
        ↓
App(Filament 3D) / Web 面板  实时状态与能耗
```
