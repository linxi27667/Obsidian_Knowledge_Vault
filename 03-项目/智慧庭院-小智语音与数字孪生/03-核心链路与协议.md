# 核心链路与协议

## 一、Topic（`shared/mqtt_iot_protocol.h`）

| Topic | 方向 | 作用 |
|---|---|---|
| `xiaozhi/iot/cmd/{id}` / `broadcast` | 主机→从机 | 控制命令 |
| `xiaozhi/iot/resp/{mac}` | 从机→主机 | 执行响应 |
| `xiaozhi/iot/heartbeat/{mac}` | 从机→主机 | 心跳 |
| `xiaozhi/iot/announce/{mac}` | 从机→主机 | 发现注册 |
| `xiaozhi/iot/sensor/{mac}` | 从机→主机 | 传感器 |
| `xiaozhi/iot/emergency/{mac}` | 从机→主机 | 紧急事件 |
| `xiaozhi/iot/energy/{mac}` | 从机→App/主机 | 能耗（QoS1, retained） |
| `xiaozhi/iot/energy/request/{mac}` | App→从机 | 请求能耗 |
| `xiaozhi/garden/chat` | 主机→App | ASR/TTS 文本转发 |

## 二、命令码要点

| 码 | 名 | 含义 |
|---|---|---|
| 0x10/0x11/0x12 | SET_SERVO/LIGHT/RELAY | 基础执行器 |
| 0x13 | SENSOR_REPORT | 传感器 |
| 0x30–0x33 | 广播全开/全关/灯 | 批量 |
| 0x34 | EMERGENCY | 紧急 |
| 0x35 | SET_AUTO_MODE | 总自动模式 |
| 0x36 | FIRE_RESET | 火灾解除恢复 |
| 0x37/0x38 | RAIN/HELP_ALERT | 雨/求助 |
| 0x39 | SET_STRIP_RGB | 灯带 RGB/特效 |
| 0x3A | SET_AMBIENCE_SCENE | 意境场景 |
| 0x3B | SET_DEVICE_AUTO | 单设备自动接管 |

普通包：

```c
typedef struct {
    uint8_t command, device_id, gpio_index, value;
    uint8_t reserved[4];
} __attribute__((packed)) iot_command_packet_t;
```

## 三、语音控制链路

```text
自然语言
→ 小智云 LLM 选 self.garden.* MCP
→ Register_Garden_Mcp_Tools 回调
→ iot_controller / mqtt 下发
→ 从机 mqtt_receive 更新 flags
→ iot_control_task 写 GPIO/舵机/RMT
→ resp + heartbeat
→ 主机可选 TTS 确认；App 刷新孪生
```

演示长句（单模块串联控制）见 `演示流程.md`：开长廊灯→遮雨棚→风扇→雾化→氛围灯效→收回棚→关灯。

## 四、自动模式链路

开启总自动或单设备自动后：

| 条件 | 动作 |
|---|---|
| 土壤干燥 | 开水泵浇水，湿润后停 |
| 高温 | 开风扇/雾化，回落后关 |
| 雨滴 | 遮雨棚展开 + 雨天灯效；雨停收回 |
| 手动控某设备 | 该设备 auto 接管关闭（手动优先） |

## 五、火灾本地熔断（必须能讲）

```text
火焰传感器触发（中断/ADC 阈值，连续确认抗 EMI）
→ 从机本地立即：
    GPIO17 总闸拉低切断供电
    关水泵
    全开照明（便于疏散/观察）
→ MQTT emergency 上报
→ 主机：唤醒、蜂鸣、TTS「火灾警报」
→ 火源移除后电压回稳（如连续 15s 低于阈值）
→ 可自动/主机 FIRE_RESET 恢复「风和日丽」
```

> [!IMPORTANT]
> 火灾切断不依赖云端往返。云端慢或断网时，本地熔断仍生效。

## 六、求助链路

```text
求助键下降沿
→ 全开灯
→ emergency MQTT
→ 主机蜂鸣 + 语音「紧急求助」
→ App 可弹紧急覆盖层（若已接线）
```

## 七、能耗链路

```text
设备 on/off 边沿
→ 累计运行时间 × 额定功率 /1000 → kWh
→ NVS 持久化
→ Topic energy/{MAC} 上报（变化立即；2h 兜底；启动上报；App 请求回复）
```

JSON 形态（协议文档）：

```json
{
  "ts": "2026-05-27T14:35:22",
  "devices": {
    "fan": { "kwh": 1.253, "on": true }
  },
  "total_kwh": 2.934
}
```

**边界**：无电流传感器，数值为估算，面试要主动说明。

## 八、传感器类型

| 枚举 | 含义 |
|---|---|
| `IOT_SENSOR_SOIL_MV` | 土壤湿度 mV |
| `IOT_SENSOR_FIRE_STATUS` | 0 正常 / 1 预警 / 2 确认 |
| `IOT_SENSOR_RAIN_STATUS` | 0 干燥 / 1 下雨 |
| `IOT_SENSOR_HELP_STATUS` | 0 无 / 1 求助 |
| `IOT_SENSOR_RAIN_ADC_MV` | 雨滴原始 ADC |

原光照通道已删除（`RESERVED_1`），App 不应再展示假 lux。
