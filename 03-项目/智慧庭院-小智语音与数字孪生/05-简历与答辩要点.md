# 简历与答辩要点

## 一、简历项目描述（可直接改名使用）

**小智智慧庭院语音控制系统（ESP32-S3 + Android 数字孪生）**

- 设计主从分离架构：主机承载小智语音/MCP 意图解析，从机负责灯带、继电器、舵机与多传感器执行。  
- 实现自动模式（浇水/温湿度/遮雨）与**火灾本地熔断**（本地切总闸 + MQTT 告警 + TTS），保证断云端仍能安全动作。  
- 制定 MQTT 设备/场景/能耗协议，完成额定功率积分与 NVS 持久化；配套 Web 面板与 **Kotlin+Filament 3D 孪生 App**。  

**技术栈**：ESP-IDF、FreeRTOS、MQTT、MCP、WS2812/RMT、ADC、Kotlin、Filament、NVS  

## 二、STAR 精简版

| 段 | 内容 |
|---|---|
| S | 竞赛/作品需要可演示的智能庭院：语音、自动、安全、可视化 |
| T | 一人需打通语音→设备→传感器→App 全链路 |
| A | 主从 MQTT + MCP 工具；从机阈值自动；火灾本地优先；App 孪生 |
| R | 形成可复现演示流程；协议与能耗可对接第三方面板 |

## 三、三分钟讲解骨架

1. **问题**：沙盘设备多、要自然语言 + 环境自治 + 可看懂的界面。  
2. **架构**：S3 主机语义，S3 从机执行，Broker 总线，App 孪生。  
3. **硬点 1**：自动模式 + 手动优先。  
4. **硬点 2**：火灾本地熔断时序。  
5. **硬点 3**：能耗估算与 App 3D。  
6. **边界**：估算电量非计量；App 不做安全闭环。  

## 四、高频追问

| 问 | 答 |
|---|---|
| 和 P4 家居有何不同？ | 庭院是场景沙盘+环境闭环+孪生 App；P4 是楼宇中控+三层节点+人脸 UI。 |
| 为什么火灾不先问云端？ | 延迟与可用性；安全输出必须本地确定。 |
| 自动和手动冲突？ | 手动控制某设备后关闭该路 auto 接管。 |
| 能耗准吗？ | 额定功率×时间，适合展示与相对比较，非计费级。 |
| WS2812 怎么驱动？ | ESP32 RMT（以从机实现为准）。 |
