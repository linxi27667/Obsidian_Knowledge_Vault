# Track_Car 导读（5ms 闭环 + 安全闸门 + 远程调参）

## 核心概念

- ==裸机时分调度，不是 FreeRTOS 项目==。  
- ==Track 算期望，Safety 才授权电机输出==。  
- ==参数唯一源在 `user_tuning.h`，与上位机 schema 对齐并由测试校验==。  

## 一、项目是什么

基于 **TI MSPM0G3507** 的循迹车控制系统：

- 八路灰度循迹 + 双编码器速度环 + ICM42688 陀螺阻尼/直角弯航向  
- 5 ms 非阻塞控制环  
- ESP-01S TCP 透传 + Python Flask 上位机远程调参/仿真  
- 主机可执行逻辑单测（`track_logic.h` pure helpers）

## 二、硬件与路径

| 项 | 内容 |
|---|---|
| MCU | MSPM0G3507 |
| 传感 | 八路灰度、双编码器、ICM42688-P |
| 通信 | ESP-01S AT 固件，UART+DMA |
| 源码根 | `E:/MCU/MSPM0/Contest/Track_Car` |
| 工具链 | Keil 主；另有 TI Clang/GCC 工程 |

## 三、目录职责

```text
Track_Car/
├─ main.c              初始化、中断、时分主循环

```
