# Track_Car 算法全解（零基础版）

> 目标：即使你不懂控制理论，也能按“输入→计算→输出”看懂本车每一块算法。  
> 源码根：`E:/MCU/MSPM0/Contest/Track_Car`  
> 主频率：**每 5ms 跑一轮**（`TRACK_UPDATE_PERIOD_MS = 5`）

---

## 0. 先建立一张总图

```text
路面黑线
  ↓
① 灰度传感器：8路光强度 → 黑/白 → 线在左边还是右边（error）
  ↓
② 线位置 PID：error → 转向量 turn
  ↓
③ 陀螺仪阻尼：抑制直道左右抖
  ↓
④ 曲率变速：弯道减速、直道加速 → 基础速度 base
  ↓
⑤ 差速分解：左轮速度 = base - turn；右轮 = base + turn
  ↓
⑥ 速度环 PID（左右各一个）：目标速度 → PWM
  ↓
⑦ Safety 安全闸门：只有“允许”才真的驱动电机
  ↓
电机转动，车跟着线走
```

直角弯、丢线、原地旋转会**暂时离开**正常循迹，换用另一套算法。

## 1. 灰度感知算法（眼睛）

### 1.1 硬件原理（不是深度学习）

八路灰度探头看地面反光：

- **白底**反光强 → ADC 读数一种范围  
- **黑线**反光弱 → ADC 读数另一种范围  

本车用 74HC4051 模拟开关：**3 根地址线选通道 + 1 路 ADC 轮询 8 路**。

### 1.2 黑白校准

上电要先标定：

| 步骤 | 含义 |
|---|---|
| 白校准 | 车在白底上记每路 `white[i]` |
| 黑校准 | 车压黑线记每路 `black[i]` |
| 对比度检查 | 每路 `|white-black| ≥ 200` 才算校准有效 |

**为什么要校准？**  
不同光线、不同地板，原始 ADC 会漂。校准后才知道“多黑算黑”。

### 1.3 归一化

把每路 ADC 映射到大约：

```text
0.0 = 很白
1.0 = 很黑
```

（代码里 `norm[]`：0=白，1=黑）

### 1.4 二值化（变 0/1）

把连续灰度变成：

```text
digital[i] = 1 黑
digital[i] = 0 白
```

8 路可压成一个字节 `digital_mask`，bit0=S0 … bit7=S7。

### 1.5 线位置误差 error（最核心的几何算法）

传感器从左到右编号 `i = 0..7`，每个黑点有一个位置权重：

```text
权重 w(i) = (i * 2 - 7) * 0.5
即：  -3.5  -2.5  -1.5  -0.5  +0.5  +1.5  +2.5  +3.5
```

**算法（加权平均）：**

```text
只统计 digital=黑 的探头
error = (所有黑探头的权重之和) / (黑探头个数)
```

源码：`Track_ComputeDigitalLineError8()` in `TASK/track_logic.h`

| error | 物理含义 | 车应怎么做 |
|---|---|---|
| 负 | 黑线偏左 | 左转 |
| 0 | 黑线在中间 | 直行 |
| 正 | 黑线偏右 | 右转 |

**类比**：8 只眼睛看线，黑点的“重心”在哪，车就朝哪边回正。

### 1.6 线型分类算法

`Track_ClassifyLine8()` 把当前 mask 分成：

| 类型 | 条件直觉 | 后续 |
|---|---|---|
| `LOST` | 全白 | 丢线处理 |
| `LEFT_CORNER` | 左侧连续黑 + 中心仍有线（直角弯特征） | 进直角弯状态机 |
| `NORMAL` | 黑点数 ≤3 且黑色连续 | 正常 PID 循迹 |
| `INVALID` | 其他怪图案（交叉、噪声） | 短时保持/停车 |

辅助算法：

- **连通性** `Track_MaskIsContiguous`：黑点是不是连成一段  
- **数黑点数** `Track_CountBits8`  
- **左直角特征** `Track_SquareLeftCorner`：中心对(S3S4)+左侧链，或实测 split 模式

## 2. PID 控制算法（大脑通用零件）

本车所有闭环都建立在同一套 **PID** 上。

### 2.1 人话版 PID

目标是把某个量（线位置 / 轮速 / 转角）拉回设定值：

```text
error = 目标 - 当前测量

输出 = Kp * error          ← 现在偏多少，立刻推一把（比例）
     + Ki * ∫error dt      ← 长期一直偏，慢慢加力（积分）
     + Kd * d(error)/dt    ← 变化太快，提前刹车（微分）
```

| 项 | 作用 | 太大时 | 太小时 |
|---|---|---|---|
| P | 响应快 | 左右甩 | 跟线慢 |
| I | 消静差 | 积分饱和、乱冲 | 直道有小偏不消 |
| D | 抑震荡 | 噪声放大 | 抑抖不足 |

### 2.2 本车 PID 的 3 个工程加固（`app_pid.c`）

1. **积分分离**  
   误差很大时先不算 I，避免起步狂加积分。  
2. **积分限幅**  
   `integral` 夹在 ±`integral_limit`。  
3. **不完全微分（微分滤波）**  
   ```text
   derivative = α * 上次derivative + (1-α) * 本次原始微分
   ```  
   灰度噪声大，滤波后 D 不那么“神经质”。  
4. **输出限幅**  
   转向、PWM 修正都有上下限。

## 3. 线位置环算法（跟着线转）

### 3.1 输入输出

```text
输入：error（上一节算出的线偏差）
输出：line_turn（转向量，可理解为左右差速命令）
```

默认参数（`user_tuning.h`）：

```text
Kp = 3.5
Ki = 0.0      ← 循迹通常不用积分
Kd = 1.5
输出限幅 OLIMIT = 30
```

```text
line_turn = PID(目标=0, 反馈=error)
```

目标是 0：希望线永远在车正中间。

### 3.2 陀螺仪角速度阻尼（国一方案核心）

直道时灰度会抖，P 会跟着抖 → 车蛇形。  
本车叠加 **陀螺 Z 轴角速度阻尼**：

```text
turn_output = line_turn + GYRO_DAMP * gyro_z
```

源码：`Track_LineTurn_WithGyroDamping()`  
默认 `GYRO_DAMP ≈ 0.25`

| 现象 | 调法 |
|---|---|
| 直道左右抖 | 加大 GDAMP |
| 弯道跟不上 | 减小 GDAMP |

**直觉**：车已经在晃（有角速度），就先反向“压住晃”，不要只听噪声大的灰度。

### 3.3 差速合成

```text
左轮目标速度 ∝ base_speed - turn_output
右轮目标速度 ∝ base_speed + turn_output
```

- turn>0 → 右轮更快 → 车体右转  
- turn<0 → 左轮更快 → 车体左转  

内侧轮还有 **最小有效 PWM**，防止内侧完全停转（`MOTOR_INNER_MIN`）。

## 4. 连续曲率变速算法（快慢怎么变）

不是“直道 40 / 弯道 20”两档跳变，而是按 |error| **线性插值**：

```text
|error| = 0                 → SPEED_STRAIGHT（默认约 30）
|error| ≥ CURVE_ERROR_MAX   → SPEED_CURVE   （默认约 26）
中间                        → 线性过渡
```

`CURVE_ERROR_MAX` 默认 2.5。

还有 **速度渐变步进** `SPEED_RAMP_STEP`（Slew）：  
每周期最多加减 2，避免速度阶跃把车甩飞。  
通用函数：`Track_Slew_Command()`。

## 5. 速度环算法（轮子真的转到目标速度）

### 5.1 为什么还要速度环？

只有差速开环 PWM 时：

- 电池电压变了，速度变了  
- 左右电机不对称，直道跑偏  

所以：

```text
灰度环只决定“左右差多少、基础多快”
速度环保证“左轮/右轮实际转速跟上目标”
```

### 5.2 编码器测速

电机轴/轮上的正交编码器：

- A/B 两相脉冲  
- **4 倍频解码** 提高分辨率  
- 单位时间脉冲数 → `encoder_speed`

### 5.3 速度低通滤波

```text
filtered = previous + α * (sample - previous)
```

`Motor_Speed_LowPass()`，α≈0.20（约 20ms 时间常数 @5ms 周期）。  
滤掉编码器量化噪声。

### 5.4 左右标定 scale

```text
真实速度感 ≈ encoder_speed
PWM 前馈 ≈ target / SPEED_SCALE
```

左右 `SPEED_SCALE_LEFT/RIGHT` **分别标定**（默认约 0.161 / 0.164），因为机械差。

### 5.5 速度 PID

默认：

```text
Kp ≈ 0.55
Ki = 0
Kd = 0
```

省一经验：**速度环 P 往往够用**，上 I 容易饱和。

输出还经 `Motor_Speed_ConstrainPwm`：

- 目标为 0 → PWM 0  
- 不允许修正量把桥臂方向反转成“倒车对打”  
- 静止启动时抬到 `MIN_DRIVE_PWM`（约 24）克服静摩擦

## 6. IMU / 航向算法（转直角弯用）

### 6.1 传感器

ICM42688-P 六轴，循迹主要用 **陀螺 Z（yaw rate）**。

### 6.2 零偏校准

静止时采一段陀螺平均 → 当 **bias（零漂）** 减掉。  
否则积分航向会“自己慢慢转”。

### 6.3 航向角积分

```text
heading += (gyro_z - bias) * dt
```

`Imu_Update_Heading(dt)`。  
注意：这是积分估计，长期会漂；短时间 90° 转弯够用。

### 6.4 原地旋转 / 直角弯 pivot 控制

不是盲目转固定时间，而是：

```text
angle_error = 目标转角 - (当前heading - 进入弯时的heading)
command = Kp * angle_error - Kd_rate * gyro_rate
```

- 角度还差得多 → 转快点  
- 角速度太大 → 阻尼压住  
- |error| 足够小且角速度足够小，连续 N 帧 → 认为转完  

对应：`Track_RightAngle_PivotPwm` / `Track_Rotate_*` 系列。

还有 **分区限速**：接近目标角进入 fine zone，最大转速降低，避免冲过。

## 7. 直角弯状态机算法（复合策略）

正常循迹发现左直角特征后：

```text
LINE_FOLLOW
  → 确认帧数够（默认 3 帧）且最近有“居中历史”
RIGHT_ANGLE:
  APPROACH  降速前探（编码器测距或时间兜底）
  STOP      短停稳定（约 100ms）
  PIVOT     IMU 左转约 90°
  CAPTURE   低速+小差速重新咬线，确认正常线型
  → 回到 LINE_FOLLOW
```

完成条件：

- 角度误差 ≤ 3°  
- |角速度| ≤ 12°/s  
- 连续 4 帧  

圈数统计：

```text
完成直角数 / 4 = 圈数
目标圈数 * 4 个角 → FINISHED
```

## 8. 丢线与异常线算法

| 情况 | 算法处理 |
|---|---|
| 全白连续 5 帧 | 确认 `LINE_LOST` |
| INVALID 图案 | 先 hold 1 帧，再多帧则停 |
| 丢线过久 | Safety `LINE_LOST_TIMEOUT` 故障停车 |

设计思想：**防抖确认**，单帧噪声不决策。

## 9. Safety 安全算法（最高优先级逻辑）

这不是“让车跑得更好”的算法，而是 **“什么时候禁止跑”** 的算法。

```text
任何 Track/PID 算出的电机目标
        ↓
Safety_AllowsMotorOutput() ?
   否 → PWM=0
   是 → 才下发电机
```

健康检查（`Safety_Logic_Check`）：

| 检查 | 超时/条件 |
|---|---|
| 灰度数据新鲜 | 超时 → 故障 |
| 控制 tick 按时来 | 漏期 → 故障 |
| 左右编码器健康 | 异常 → 故障 |
| 远程调参心跳 | 丢失 → 故障（远程解锁时） |
| 传感器抬起/异常 | 立即故障 |

状态：`BOOT→CALIBRATING→READY→RUNNING→FINISHED/FAULT`

**你要记住的一句话**：  
控制算法负责算得聪明，安全算法负责不允许算错时把车弄飞。

## 10. 编码器测距算法（直角前探）

若标定了 `counts_per_mm`：

```text
left_mm  = Δ脉冲_left  / left_counts_per_mm
right_mm = Δ脉冲_right / right_counts_per_mm
平均 mm ≥ 目标距离 → 前探完成
```

未标定则用时间兜底（如 500ms）。  
当前默认 `COUNTS_PER_MM=0`，表示**必须实测后填**，禁止瞎猜。

## 11. 远程调参相关“算法”

上位机侧不是车载控制核心，但有：

1. **参数 clamp（限幅）**：下发 KP 等限制在 min/max  
2. **LocalRuleEngine**：根据遥测简单规则建议改参（例如抖→加 D）  
3. **可选 LLM 建议**：非实时控制，只是辅助分析  

车端仍以 5ms 环为准；远程改的是 PID 系数，不是每包遥控油门乱开。

## 13. 5ms 一环的伪代码（串起来）

```text
每 5ms:
  读灰度 → 更新 digital_mask, error, line_type
  读 IMU → gyro_z, heading
  读编码器 → 左右速度滤波

  if 状态 == LINE_FOLLOW:
      if 直角特征确认: 切 RIGHT_ANGLE
      elif 丢线确认: 切 LINE_LOST
      else:
          line_turn = PID_line(0, error)
          turn = line_turn + GDAMP * gyro_z
          base = 插值(直道速, 弯道速, |error|)
          base = slew(base)
          vL, vR = base ∓ turn
          pwmL = SpeedPID_L(vL, measL)
          pwmR = SpeedPID_R(vR, measR)

  elif 状态 == RIGHT_ANGLE:
      按 APPROACH/STOP/PIVOT/CAPTURE 子阶段计算 vL,vR

  if Safety 不允许:
      pwmL = pwmR = 0
  else:
      输出电机
```

## 14. 你完全不懂时，怎么学这些算法

建议顺序（由易到难）：

1. **error 加权平均**（几何，最好懂）  
2. **P 控制**：输出 = Kp * error  
3. **PID 三项直觉** + 限幅  
4. **差速怎么转弯**  
5. **速度环为什么要编码器**  
6. **陀螺阻尼 / 航向积分**  
7. **直角弯状态机**  
8. **Safety 为什么卡电机**  

每学一个，只问自己三句话：

- 输入是什么？  
- 输出是什么？  
- 坏了会怎样？（甩线 / 抖 / 冲弯 / 停死）

## 16. 一页纸记忆版

1. **看线**：8 路灰度 → 黑点重心 = error  
2. **回正**：PID 把 error 压到 0 → turn  
3. **稳直道**：turn 加陀螺阻尼  
4. **稳速度**：左右编码器速度环  
5. **过直角**：识别特征 → 停 → IMU 转 90° → 再咬线  
6. **保命**：Safety 不点头，电机为 0  

掌握这 6 句，你就已经能讲懂这个项目 80% 的算法故事。
