# 状态机、安全闸门与调参

## 一、循迹状态机（`track_logic.h`）

```text
IDLE
 → LINE_FOLLOW      正常循迹
 → RIGHT_ANGLE      直角弯：APPROACH→STOP→PIVOT→CAPTURE
 → LINE_LOST        丢线
 → START_LINE / CROSS
 → ROTATE / HEADING_HOLD
 → MOTOR_TEST       台架固定流程（禁止远程任意 PWM）
 → FINISHED
```

线观测类型：`NORMAL / LEFT_CORNER / LOST / INVALID`。

### 直角弯相位

| 相位 | 意图 |
|---|---|
| APPROACH | 降速接近 |
| STOP | 短停稳定 |
| PIVOT | 陀螺目标角原地转 |
| CAPTURE | 重新咬线确认 |

完成条件示例：角度误差、角速度、连续帧数门槛（`DONE_ERROR/RATE/FRAMES`）。

### 丢线

- 连续多帧全白才确认（默认 5 帧）抗抖  
- 可结合航向保持/超时停车（`LINE_LOST_TIMEOUT` 进 Safety 故障）  

## 二、安全状态机（`app_safety.h`）——简历硬点

**原则：Track/PID 可以算速度，只有 `Safety_AllowsMotorOutput()==true` 才许写电机。**

```text
BOOT → CALIBRATING → READY → RUNNING → FINISHED
                         ↘ FAULT
```

| 故障 | 含义 |
|---|---|
| `GRAYSCALE_EXPIRED` | 灰度帧过期 |
| `CALIBRATION_INCOMPLETE` | 校准未完成 |
| `CONTROL_TICK_MISSED` | 控制漏期 |
| `ENCODER_ANOMALY` | 编码器异常 |
| `HEARTBEAT_LOST` | 调参心跳丢失 |
| `SENSOR_ABNORMAL` | 传感器抬起/异常 |
| `MANUAL_STOP` | 手动停 |
| `LINE_LOST_TIMEOUT` | 丢线超时 |

运行中每 5ms 检查控制节拍与健康；远程启动还要求心跳。

## 三、关键默认参数（`user_tuning.h`，以源码为准）

| 参数 | 默认量级 | 作用 |
|---|---|---|
| LINE KP/KI/KD | 3.5 / 0 / 1.5 | 循迹 |
| OLIMIT | 30 | 差速限幅（对标省一 ±28 思路） |
| GYRO_DAMP | 0.25 | 直道抑抖 |
| 速度环 KP | 0.55 | 左右速度闭环 |
| SPEED_SCALE L/R | 0.161 / 0.164 | 标定 |

调参口诀（文件内注释）：先 KP 跟线 → 抖加 KD → 少用 KI → 弯道甩减 KP。
