# 技术栈与控制架构

## 一、技术栈

| 技术 | 用途 |
|---|---|
| MSPM0G3507 + SysConfig | 时钟、GPIO、定时、UART |
| 裸机主循环 + SysTick ms | 非阻塞时分 |
| 八路灰度 | 线位置误差 |
| 正交编码器 4x | 左右轮速反馈 |
| ICM42688-P | 角速度阻尼 / 直角弯航向 |
| 差速电机 PWM+方向 | 执行 |
| ESP-01S AT | Wi-Fi TCP 透传 |
| SEGGER RTT + EasyLogger | 调试日志 |
| Python Flask + SocketIO | 上位机 |
| unittest | 协议/纯逻辑测试 |

## 二、分层纪律

```text
TASK  track.*        只写业务，不碰寄存器
  ↑
APP   app_*          硬件绑定、PID、安全、协议
  ↑
BSP   bsp_*          寄存器/外设
```

`AGENTS.md` 硬约束：

- 5 ms 循迹环必须非阻塞  
- ISR 只服务硬件与有界状态，解析/日志/业务在主循环  
- 通信丢失或传感器无效 → **电机 fail-safe**

## 三、主循环骨架（概念）

```text
System_Init (RTT/SysConfig/elog/外设)
→ 可选 SelfTest
→ while(1):
     到点则 Track_Update (5ms)
     处理调参/遥测/按键
     Safety 授权后才输出电机
```

`main.c` 集中：SysTick、HardFault 诊断、GPIO 输入回读使能（SysConfig 输出脚默认无 INE 的补丁）。

## 四、灰度偏差模型

传感器布局 S0…S7（左→右），权重：

```text
-3.5 -2.5 -1.5 -0.5 +0.5 +1.5 +2.5 +3.5
```

- 负偏差：线偏左 → 需左转  
- 正偏差：线偏右 → 需右转  
- `turn_output>0` 右转（左轮加速）  

## 五、双环控制

### 5.1 线位置环（5ms）

```text
error = f(灰度)
line_pid_out = PID(error)   // 默认 KP=3.5 KI=0 KD=1.5 OLIMIT=30
turn = line_pid_out + GYRO_DAMP * gyro_z   // 国一思路：角速度阻尼
base_speed = 曲率插值(直道速度↔弯道速度)
left/right target = base ± turn
```

### 5.2 速度环

- 左右独立，编码器反馈  
- 默认以 **P 环为主（KI=0）**，避免积分饱和  
- `SPEED_SCALE_LEFT/RIGHT` 分别标定（机械不对称）  

## 六、变速策略

连续曲率变速（非简单二档跳变）：

```text
|error|=0 → SPEED_STRAIGHT
|error|≥CURVE_ERROR_MAX → SPEED_CURVE
中间线性插值
```

进弯减速、出弯加速更平滑。

## 七、远程调参通道

```text
MSPM0 ←UART+DMA→ ESP-01S ←TCP/JSON→ Flask host ←SocketIO→ 浏览器
                 100Hz 遥测               set/cmd
```

8 个远程参数与 `user_tuning.h` / `host/param_schema.py` 对齐，`tests/test_param_schema.py` 校验默认值一致。

## 八、与 RTOS 项目对比（面试加分）

| 点 | Track_Car | 举升机 |
|---|---|---|
| 调度 | 裸机时分 | FreeRTOS 多任务 |
| 周期 | 5ms 硬环 | 1/10ms 控制 + 通信任务 |
| 安全 | Safety 授权电机 | lift_core 安全优先 + All_Off |
| 调参 | Wi-Fi 在线 | 多为编译期/Flash 配置 |
