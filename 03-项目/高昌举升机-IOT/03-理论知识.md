# Gc_Iot_Lift 理论知识（理解代码背后的工程原则）

## 核心概念

- ==状态机==把复杂动作拆成有限状态和确定转换。
- ==非阻塞时序==用 Tick 差值代替长延时，使急停能够随控制周期被检查。
- ==安全闸门==应位于普通业务之后、硬件输出之前。
- ==QoS 1 不等于只收到一次==，必须使用业务幂等。

## 一、有限状态机

一个状态机包含：状态、输入、转换条件、动作和异常路径。

```text
IDLE --按下下降--> PREPARE --200ms--> HOLD --保持结束--> DROPPING
  ^                                                       |
  +------------------按钮释放 / 安全触发------------------+
```

项目中存在两级状态：

- 公共状态：`IDLE/RISING/DROPPING/LOCKED/REFILLING/ESTOP/PHOTO_ALARM`
- 产品子状态：例如两柱的 `DP_DOWN_PHASE_1/2/DROPPING`，小剪的 `DOWN_PREPARE/HOLD/DROPPING`

## 二、轮询不是忙等

控制任务周期调用 `LiftCore_Poll()`，每次只推进一步，然后通过 `vTaskDelayUntil()` 阻塞到下一周期。这是确定周期的时间触发控制，不是占满 CPU 的死循环。

```c
TickType_t last_wake_tick = xTaskGetTickCount();
while (1) {
    LiftCore_Poll();
    LiftIot_Poll();
    vTaskDelayUntil(&last_wake_tick, pdMS_TO_TICKS(period_ms));
}
```

## 三、输入去抖与有效电平

机械按键切换时会在数毫秒内反复抖动。项目保存原始值、稳定值和变化时间，只有持续满足 `debounce_ms` 才更新逻辑输入。

| 输入类型 | 常用去抖 |
|---|---:|
| 普通按钮/限位/急停 | 20 ms |
| 光电/旋转开关 | 50 ms |

`active_level` 把“物理电平”归一化为“是否触发”：按钮/急停多为低有效，限位/光电多为高有效。

## 四、安全优先级

推荐理解为多层防线：

1. 输入层识别急停、限位、光电、非法组合。
2. 公共安全层优先改变系统状态并调用 `App_IO_All_Off()`。
3. 产品状态机只在安全条件满足时推进。
4. 小剪还有最终输出安全闸门，防止上层计算错误直接驱动继电器。
5. RTOS 内存失败和栈溢出钩子也会先关闭输出。

> [!IMPORTANT]
> 网络命令不能绕过急停、限位、光电等本地安全条件。

## 五、FreeRTOS 调度

- Tick 为 1000 Hz，即 1 Tick≈1 ms。
- 数字越大优先级越高。
- 控制任务通常为 `tskIDLE_PRIORITY + 3`。
- DTU 任务 `tskIDLE + 1`，栈 4096 words（JSON 解析占栈大）。
- `vTaskDelayUntil()` 保证相对稳定周期；`vTaskDelay()` 只保证至少延迟。

## 六、UART DMA + FIFO

```text
USART3硬件 → DMA循环缓冲区 → HAL接收事件 → RX FIFO → DTU任务逐字节解析
DTU任务 → TX FIFO/阻塞AT发送 → DMA或UART → TAS DTU
```

DMA 负责批量搬运，FIFO 负责跨执行上下文缓存，任务负责协议解析。中断中不做 JSON 解析和日志等重活。

## 七、MQTT 与幂等

QoS 1 语义是“至少一次”，断线重发可能产生重复命令。项目使用 `msg_id`：

1. Web 为命令生成唯一 `msg_id`。
2. 固件缓存已处理命令结果（16 条环形）。
3. 重复命令直接返回缓存结果，不重复执行危险动作。
4. Web 只接受 UID、命令名和 `msg_id` 都匹配的回执。

## 八、掉电持久化

W25Qxx 是外部 SPI Flash。配置采用双槽思想；操作日志、保养和举升统计需要考虑：

- 写入中掉电
- Flash 擦写寿命
- CRC/提交标记
- 启动恢复
- 异步写入避免阻塞控制任务（两柱 RiseStore）

## 九、面试高频辨析

| 问题 | 正确回答 |
|---|---|
| DTU 是主控吗？ | 不是，STM32 是控制主机，DTU 只负责蜂窝网络和 MQTT。 |
| QoS 1 会重复吗？ | 会，因此需要 `msg_id` 去重和幂等回执。 |
| 断网还能急停吗？ | 能，安全闭环完全在 STM32 本地。 |
| 为什么不用 `HAL_Delay(3000)`？ | 会阻塞控制与安全检查，项目用状态机和 Tick 差值推进。 |
| 四机型都有光电吗？ | 不，两柱没有。 |
