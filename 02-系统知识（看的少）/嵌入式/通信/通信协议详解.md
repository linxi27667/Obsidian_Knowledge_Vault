# 通信协议详解

## 核心概念

- **通信协议** - 设备间数据交换的规则
- **串行通信** - 逐位传输数据
- **并行通信** - 多位同时传输
- **同步/异步** - 是否需要时钟信号

---

## 一、UART串口通信

### 1.1 UART概述

**特点：**
- 异步串行通信
- 全双工
- 点对点

**参数：**
| 参数 | 说明 | 典型值 |
|------|------|--------|
| 波特率 | 每秒传输位数 | 9600, 115200 |
| 数据位 | 每帧数据位数 | 8位 |
| 停止位 | 帧结束标志 | 1位 |
| 校验位 | 错误检测 | 无/奇/偶 |

---

### 1.2 UART帧格式

```
空闲 ──┐ ┌─┬─┬─┬─┬─┬─┬─┬─┬─┬─┬─┬─┐ ┌── 空闲
       │ │S│D│D│D│D│D│D│D│D│P│S│ │
       │ │T│0│1│2│3│4│5│6│7│ │T│ │
       │ └─┴─┴─┴─┴─┴─┴─┴─┴─┴─┴─┘ │
       └───────────────────────────┘
```

**起始位：** 低电平
**停止位：** 高电平
**数据位：** 低位在前

---

### 1.3 ESP-IDF UART配置

```c
#include "driver/uart.h"

// UART配置
uart_config_t uart_config = {
    .baud_rate = 115200,
    .data_bits = UART_DATA_8_BITS,
    .parity = UART_PARITY_DISABLE,
    .stop_bits = UART_STOP_BITS_1,
    .flow_ctrl = UART_HW_FLOWCTRL_DISABLE,
};

// 安装驱动
uart_driver_install(UART_NUM_0, 1024, 1024, 0, NULL, 0);
uart_param_config(UART_NUM_0, &uart_config);

// 发送数据
uart_write_bytes(UART_NUM_0, "Hello", 5);

// 接收数据
uint8_t data[128];
int len = uart_read_bytes(UART_NUM_0, data, 128, pdMS_TO_TICKS(100));
```

---

### 1.4 UART应用场景

| 应用 | 说明 |
|------|------|
| 调试输出 | printf重定向 |
| GPS模块 | NMEA数据 |
| 蓝牙模块 | AT指令 |
| 传感器 | 数据传输 |

## 二、I2C通信协议

### 2.1 I2C概述

**特点：**
- 串行同步通信
- 半双工
- 多主多从
- 两线制(SDA, SCL)

**信号：**
| 信号 | 说明 |
|------|------|
| SDA | 数据线 |
| SCL | 时钟线 |

---

### 2.2 I2C时序

**起始条件：**
```
SCL ──────────────┐
                  │
SDA ──────┐       │
          └───────┘
```
SDA从高到低，SCL保持高

**停止条件：**
```
SCL ──────────────┐
                  │
SDA ──────┐       │
          └───────┘
```
SDA从低到高，SCL保持高

**数据传输：**
```
SCL ──┐ ┌─┐ ┌─┐ ┌─┐ ┌─┐
      └─┘ └─┘ └─┘ └─┘ └─┘
SDA ──┬───┬───┬───┬───┬───
      │D7 │D6 │D5 │D4 │...
      └───┘───┘───┘───┘
```

**应答位：**
- ACK：SDA低电平
- NACK：SDA高电平

---

### 2.3 I2C地址

**7位地址：**
```
从机地址(7位) + R/W位(1位)
```

**常见地址：**
| 器件 | 地址 |
|------|------|
| OLED SSD1306 | 0x3C/0x3D |
| BME280 | 0x76/0x77 |
| MPU6050 | 0x68/0x69 |
| AT24C256 | 0x50-0x57 |

---

### 2.4 ESP-IDF I2C配置

```c
#include "driver/i2c.h"

// I2C配置
i2c_config_t i2c_config = {
    .mode = I2C_MODE_MASTER,
    .sda_io_num = 21,
    .scl_io_num = 22,
    .sda_pullup_en = GPIO_PULLUP_ENABLE,
    .scl_pullup_en = GPIO_PULLUP_ENABLE,
    .master.clk_speed = 400000,
};

// 安装驱动
i2c_param_config(I2C_NUM_0, &i2c_config);
i2c_driver_install(I2C_NUM_0, I2C_MODE_MASTER, 0, 0, 0);

// 写数据
i2c_cmd_handle_t cmd = i2c_cmd_link_create();
i2c_master_start(cmd);
i2c_master_write_byte(cmd, (addr << 1) | I2C_MASTER_WRITE, true);
i2c_master_write(cmd, data, len, true);
i2c_master_stop(cmd);
i2c_master_cmd_begin(I2C_NUM_0, cmd, pdMS_TO_TICKS(1000));
i2c_cmd_link_delete(cmd);

// 读数据
i2c_cmd_handle_t cmd = i2c_cmd_link_create();
i2c_master_start(cmd);
i2c_master_write_byte(cmd, (addr << 1) | I2C_MASTER_READ, true);
i2c_master_read(cmd, data, len, I2C_MASTER_LAST_NACK);
i2c_master_stop(cmd);
i2c_master_cmd_begin(I2C_NUM_0, cmd, pdMS_TO_TICKS(1000));
i2c_cmd_link_delete(cmd);
```

## 三、SPI通信协议

### 3.1 SPI概述

**特点：**
- 串行同步通信
- 全双工
- 主从模式
- 高速

**信号：**
| 信号 | 说明 |
|------|------|
| SCLK | 时钟 |
| MOSI | 主出从入 |
| MISO | 主入从出 |
| CS/SS | 片选 |

---

### 3.2 SPI模式

| 模式 | CPOL | CPHA | 说明 |
|------|------|------|------|
| 0 | 0 | 0 | 空闲低，第1边沿采样 |
| 1 | 0 | 1 | 空闲低，第2边沿采样 |
| 2 | 1 | 0 | 空闲高，第1边沿采样 |
| 3 | 1 | 1 | 空闲高，第2边沿采样 |

---

### 3.3 SPI时序

```
CS ───┐     ┌─────────────────────────────┐     ┌───
      └─────┘                             └─────┘

SCLK ─┐ ┌─┐ ┌─┐ ┌─┐ ┌─┐ ┌─┐ ┌─┐ ┌─┐ ┌─┐ ┌─┐ ┌─┐
       └─┘ └─┘ └─┘ └─┘ └─┘ └─┘ └─┘ └─┘ └─┘ └─┘ └─┘

MOSI ─┬───┬───┬───┬───┬───┬───┬───┬───┬───┬───┬───
      │D7 │D6 │D5 │D4 │D3 │D2 │D1 │D0 │D7 │D6 │...
      └───┘───┘───┘───┘───┘───┘───┘───┘───┘───┘

MISO ─┬───┬───┬───┬───┬───┬───┬───┬───┬───┬───┬───
      │D7 │D6 │D5 │D4 │D3 │D2 │D1 │D0 │D7 │D6 │...
      └───┘───┘───┘───┘───┘───┘───┘───┘───┘───┘
```

---

### 3.4 ESP-IDF SPI配置

```c
#include "driver/spi_master.h"

// SPI配置
spi_bus_config_t bus_config = {
    .mosi_io_num = 23,
    .miso_io_num = 19,
    .sclk_io_num = 18,
    .quadwp_io_num = -1,
    .quadhd_io_num = -1,
    .max_transfer_sz = 4096,
};

spi_device_interface_config_t dev_config = {
    .clock_speed_hz = 10 * 1000 * 1000,
    .mode = 0,
    .spics_io_num = 5,
    .queue_size = 7,
};

// 初始化
spi_bus_initialize(SPI2_HOST, &bus_config, SPI_DMA_CH_AUTO);
spi_bus_add_device(SPI2_HOST, &dev_config, &spi);

// 传输数据
spi_transaction_t trans = {
    .length = 8,
    .tx_buffer = &data,
    .rx_buffer = &rx_data,
};
spi_device_polling_transmit(spi, &trans);
```

## 四、CAN总线

### 4.1 CAN概述

**特点：**
- 多主通信
- 差分信号
- 高可靠性
- 错误检测

**信号：**
| 信号 | 说明 |
|------|------|
| CAN_H | 高电平 |
| CAN_L | 低电平 |

---

### 4.2 CAN帧格式

**数据帧：**
```
SOF(1) + ID(11/29) + RTR(1) + IDE(1) + r(1) + DLC(4) + Data(0-64) + CRC(15) + ACK(2) + EOF(7)
```

**帧类型：**
| 类型 | 说明 |
|------|------|
| 数据帧 | 传输数据 |
| 远程帧 | 请求数据 |
| 错误帧 | 错误信号 |
| 过载帧 | 延迟请求 |

---

### 4.3 CAN波特率

| 波特率 | 位时间 |
|--------|--------|
| 1Mbps | 1μs |
| 500kbps | 2μs |
| 250kbps | 4μs |
| 125kbps | 8μs |

---

## 五、USB协议

### 5.1 USB概述

**特点：**
- 串行通信
- 即插即用
- 供电能力
- 多种速度

**速度：**
| 版本 | 速率 |
|------|------|
| USB 1.1 | 12Mbps |
| USB 2.0 | 480Mbps |
| USB 3.0 | 5Gbps |
| USB 3.1 | 10Gbps |

---

### 5.2 USB设备类

| 类 | 说明 | 示例 |
|----|------|------|
| HID | 人机接口 | 键盘、鼠标 |
| CDC | 通信设备 | 虚拟串口 |
| MSC | 大容量存储 | U盘 |
| Audio | 音频设备 | 声卡 |
| Video | 视频设备 | 摄像头 |

---

## 六、无线通信

### 6.1 WiFi

**频段：** 2.4GHz / 5GHz

**模式：**
- STA模式：连接路由器
- AP模式：作为热点

**ESP-IDF WiFi配置：**
```c
wifi_init_config_t cfg = WIFI_INIT_CONFIG_DEFAULT();
esp_wifi_init(&cfg);
esp_wifi_set_mode(WIFI_MODE_STA);

wifi_config_t wifi_config = {
    .sta = {
        .ssid = "MyWiFi",
        .password = "password",
    },
};
esp_wifi_set_config(WIFI_IF_STA, &wifi_config);
esp_wifi_start();
esp_wifi_connect();
```

---

### 6.2 蓝牙

**类型：**
- 经典蓝牙(BR/EDR)
- 低功耗蓝牙(BLE)

**BLE特点：**
- 低功耗
- 短距离
- 广播模式

---

### 6.3 LoRa

**特点：**
- 长距离(15km)
- 低功耗
- 低速率

**参数：**
| 参数 | 范围 |
|------|------|
| 频率 | 433/868/915MHz |
| 带宽 | 125-500kHz |
| 扩频因子 | 7-12 |

## 七、PCB设计基础

### 7.1 PCB设计流程

```
原理图设计 → 网络表生成 → PCB布局 → PCB布线 → DRC检查 → 输出生产文件
```

---

### 7.2 原理图设计

**符号库：**
- 电阻、电容、电感
- 二极管、三极管
- 集成电路
- 连接器

**网络标号：**
- 相同标号表示连接
- 电源符号
- 接地符号

---

### 7.3 PCB布局

**原则：**
1. 按功能模块分区
2. 信号流向合理
3. 高速信号短且直
4. 发热元件远离敏感元件

**层叠设计：**
| 层 | 说明 |
|----|------|
| Top Layer | 顶层信号 |
| GND Plane | 地平面 |
| Power Plane | 电源平面 |
| Bottom Layer | 底层信号 |

---

### 7.4 PCB布线

**规则：**
| 规则 | 说明 |
|------|------|
| 线宽 | 根据电流确定 |
| 间距 | 满足安全距离 |
| 过孔 | 尽量少用 |
| 走线角度 | 45°或圆弧 |

**线宽与电流：**
| 电流 | 线宽(1oz铜) |
|------|------------|
| 0.5A | 0.3mm |
| 1A | 0.5mm |
| 2A | 1.0mm |
| 3A | 1.5mm |

---

### 7.5 EMC设计

**接地策略：**
- 单点接地（低频）
- 多点接地（高频）
- 模拟/数字地分离

**滤波设计：**
- 去耦电容靠近电源引脚
- 电源入口加滤波
- 信号线加滤波

**屏蔽设计：**
- 关键信号加屏蔽罩
- 高速信号包地处理

---

### 7.6 常用EDA工具

| 工具 | 特点 | 应用 |
|------|------|------|
| Altium Designer | 功能强大 | 专业设计 |
| KiCad | 开源免费 | 学习、小项目 |
| 嘉立创EDA | 在线、易用 | 快速原型 |
| OrCAD | 仿真强大 | 复杂设计 |

## 八、信号完整性

### 8.1 信号完整性问题

| 问题 | 原因 | 解决 |
|------|------|------|
| 反射 | 阻抗不匹配 | 终端匹配 |
| 串扰 | 耦合 | 增加间距 |
| 衰减 | 传输线损耗 | 缩短走线 |
| 时序 | 延迟 | 等长布线 |

---

### 8.2 阻抗匹配

**特征阻抗：**
- 单端50Ω
- 差分100Ω

**终端匹配：**
```
串联匹配：靠近源端
并联匹配：靠近负载端
```

---

### 8.3 差分信号

**特点：**
- 抗干扰强
- EMI低
- 速率高

**应用：**
- USB
- LVDS
- HDMI
- 以太网
