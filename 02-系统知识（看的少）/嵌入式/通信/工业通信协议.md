# 工业通信协议

## 核心概念

- **Modbus** - 工业串行通信协议
- **CANopen** - 基于CAN的高层协议
- **EtherCAT** - 实时以太网协议
- **PROFINET** - 工业以太网标准

---

## 一、Modbus协议

### 1.1 Modbus概述

| 特性 | 说明 |
|------|------|
| 传输模式 | RTU(二进制) / ASCII |
| 物理层 | RS-232 / RS-485 |
| 拓扑 | 主从式 |
| 寻址 | 1-247(从站地址) |
| 数据模型 | 线圈、离散输入、输入寄存器、保持寄存器 |

---

### 1.2 数据模型

| 类型 | 地址范围 | 读/写 | 说明 |
|------|----------|-------|------|
| 线圈(Coil) | 00001-09999 | 读/写 | 1bit, DO |
| 离散输入 | 10001-19999 | 只读 | 1bit, DI |
| 输入寄存器 | 30001-39999 | 只读 | 16bit, AI |
| 保持寄存器 | 40001-49999 | 读/写 | 16bit, AO |

---

### 1.3 RTU帧格式

```
┌──────────┬──────────┬──────────┬──────────┬──────────┐
│ 从站地址 │ 功能码   │ 数据     │ CRC高    │ CRC低    │
│  1字节   │  1字节   │ N字节    │  1字节   │  1字节   │
└──────────┴──────────┴──────────┴──────────┴──────────┘
```

**常用功能码：**
| 功能码 | 说明 |
|--------|------|
| 0x01 | 读线圈 |
| 0x02 | 读离散输入 |
| 0x03 | 读保持寄存器 |
| 0x04 | 读输入寄存器 |
| 0x05 | 写单个线圈 |
| 0x06 | 写单个寄存器 |
| 0x0F | 写多个线圈 |
| 0x10 | 写多个寄存器 |

### 1.4 Modbus RTU实现

```c
#include "driver/uart.h"

#define MODBUS_UART     UART_NUM_1
#define SLAVE_ADDR      0x01
#define FUNC_READ_HOLD  0x03
#define FUNC_WRITE_SINGLE 0x06

// CRC16计算
uint16_t modbus_crc16(uint8_t *data, int len) {
    uint16_t crc = 0xFFFF;
    for (int i = 0; i < len; i++) {
        crc ^= data[i];
        for (int j = 0; j < 8; j++) {
            if (crc & 0x0001) {
                crc = (crc >> 1) ^ 0xA001;
            } else {
                crc >>= 1;
            }
        }
    }
    return crc;
}

// 读保持寄存器
int modbus_read_holding(uint8_t slave, uint16_t start_addr, uint16_t count, uint16_t *values) {
    uint8_t request[8];
    request[0] = slave;
    request[1] = FUNC_READ_HOLD;
    request[2] = (start_addr >> 8) & 0xFF;
    request[3] = start_addr & 0xFF;
    request[4] = (count >> 8) & 0xFF;
    request[5] = count & 0xFF;

    uint16_t crc = modbus_crc16(request, 6);
    request[6] = crc & 0xFF;
    request[7] = (crc >> 8) & 0xFF;

    // 发送
    uart_write_bytes(MODBUS_UART, request, 8);

    // 接收响应
    uint8_t response[256];
    int len = uart_read_bytes(MODBUS_UART, response, sizeof(response), pdMS_TO_TICKS(1000));

    if (len < 5) return -1;

    // 验证CRC
    uint16_t resp_crc = modbus_crc16(response, len - 2);
    if (response[len-2] != (resp_crc & 0xFF) || response[len-1] != ((resp_crc >> 8) & 0xFF)) {
        return -2;  // CRC错误
    }

    // 检查功能码
    if (response[1] & 0x80) {
        return -3;  // 异常响应
    }

    // 解析数据
    uint8_t byte_count = response[2];
    for (int i = 0; i < count; i++) {
        values[i] = (response[3 + i*2] << 8) | response[4 + i*2];
    }

    return 0;
}

// 写单个寄存器
int modbus_write_single(uint8_t slave, uint16_t addr, uint16_t value) {
    uint8_t request[8];
    request[0] = slave;
    request[1] = FUNC_WRITE_SINGLE;
    request[2] = (addr >> 8) & 0xFF;
    request[3] = addr & 0xFF;
    request[4] = (value >> 8) & 0xFF;
    request[5] = value & 0xFF;

    uint16_t crc = modbus_crc16(request, 6);
    request[6] = crc & 0xFF;
    request[7] = (crc >> 8) & 0xFF;

    uart_write_bytes(MODBUS_UART, request, 8);

    uint8_t response[8];
    int len = uart_read_bytes(MODBUS_UART, response, sizeof(response), pdMS_TO_TICKS(1000));

    return (len == 8 && memcmp(request, response, 8) == 0) ? 0 : -1;
}
```

### 1.5 Modbus从站实现

```c
#define REG_COUNT 100
static uint16_t holding_registers[REG_COUNT];

void modbus_slave_process(uint8_t *request, int len) {
    if (len < 4) return;

    uint8_t slave_addr = request[0];
    uint8_t func_code = request[1];

    if (slave_addr != SLAVE_ADDR) return;  // 非本机

    switch (func_code) {
        case 0x03: {  // 读保持寄存器
            uint16_t start = (request[2] << 8) | request[3];
            uint16_t count = (request[4] << 8) | request[5];

            if (start + count > REG_COUNT) {
                // 异常响应
                uint8_t resp[5] = {slave_addr, func_code | 0x80, 0x02};
                uint16_t crc = modbus_crc16(resp, 3);
                resp[3] = crc & 0xFF;
                resp[4] = (crc >> 8) & 0xFF;
                uart_write_bytes(MODBUS_UART, resp, 5);
                return;
            }

            uint8_t response[256];
            response[0] = slave_addr;
            response[1] = func_code;
            response[2] = count * 2;

            for (int i = 0; i < count; i++) {
                response[3 + i*2] = (holding_registers[start + i] >> 8) & 0xFF;
                response[4 + i*2] = holding_registers[start + i] & 0xFF;
            }

            int resp_len = 3 + count * 2;
            uint16_t crc = modbus_crc16(response, resp_len);
            response[resp_len] = crc & 0xFF;
            response[resp_len + 1] = (crc >> 8) & 0xFF;

            uart_write_bytes(MODBUS_UART, response, resp_len + 2);
            break;
        }

        case 0x06: {  // 写单个寄存器
            uint16_t addr = (request[2] << 8) | request[3];
            uint16_t value = (request[4] << 8) | request[5];

            if (addr < REG_COUNT) {
                holding_registers[addr] = value;
                // 回显请求
                uart_write_bytes(MODBUS_UART, request, len);
            }
            break;
        }
    }
}
```

## 二、CANopen协议

### 2.1 CANopen概述

| 特性 | 说明 |
|------|------|
| 基于 | CAN 2.0A/B |
| 对象字典 | 设备参数数据库 |
| 服务 | SDO(配置)、PDO(实时数据) |
| 网络管理 | NMT |
| 节点ID | 1-127 |

---

### 2.2 对象字典

| 索引范围 | 用途 |
|----------|------|
| 0x1000-0x1FFF | 通信对象 |
| 0x2000-0x5FFF | 制造商特定 |
| 0x6000-0x9FFF | 标准化设备 |

**常用对象：**
| 索引 | 名称 | 说明 |
|------|------|------|
| 0x1000 | Device Type | 设备类型 |
| 0x1001 | Error Register | 错误寄存器 |
| 0x1018 | Identity Object | 设备标识 |
| 0x1200-0x127F | SDO Server | SDO参数 |
| 0x1400-0x15FF | RPDO | 接收PDO |
| 0x1800-0x19FF | TPDO | 发送PDO |

### 2.3 PDO通信

```c
// PDO映射
typedef struct {
    uint16_t index;
    uint8_t subindex;
    uint8_t length;  // bit
} pdo_mapping_t;

// TPDO1配置
#define TPDO1_COBID    0x180  // COB-ID = 0x180 + node_id
#define TPDO1_TRANSMIT_TYPE  0x01  // 同步

void pdo_send(uint8_t node_id, uint16_t cob_id, uint8_t *data, uint8_t len) {
    can_message_t msg;
    msg.identifier = cob_id + node_id;
    msg.data_length_code = len;
    memcpy(msg.data, data, len);
    can_transmit(&msg, pdMS_TO_TICKS(100));
}
```

### 2.4 SDO通信

```c
// SDO下载(写)
int sdo_download(uint8_t node_id, uint16_t index, uint8_t subindex,
                 uint8_t *data, uint32_t len) {
    can_message_t msg;
    msg.identifier = 0x600 + node_id;  // SDO请求

    if (len <= 4) {
        // 快速传输
        msg.data[0] = 0x23 | ((4 - len) << 2);  // 命令
        msg.data[1] = index & 0xFF;
        msg.data[2] = (index >> 8) & 0xFF;
        msg.data[3] = subindex;
        memcpy(&msg.data[4], data, len);
        msg.data_length_code = 8;
        can_transmit(&msg, pdMS_TO_TICKS(100));

        // 等待响应
        can_message_t resp;
        if (can_receive(&resp, pdMS_TO_TICKS(1000)) == 0) {
            if (resp.identifier == 0x580 + node_id) {
                if (resp.data[0] == 0x60) return 0;  // 成功
                return -1;  // 错误
            }
        }
    }
    return -1;
}

// SDO上传(读)
int sdo_upload(uint8_t node_id, uint16_t index, uint8_t subindex,
               uint8_t *data, uint32_t *len) {
    can_message_t msg;
    msg.identifier = 0x600 + node_id;
    msg.data[0] = 0x40;  // 上传请求
    msg.data[1] = index & 0xFF;
    msg.data[2] = (index >> 8) & 0xFF;
    msg.data[3] = subindex;
    msg.data_length_code = 8;
    can_transmit(&msg, pdMS_TO_TICKS(100));

    can_message_t resp;
    if (can_receive(&resp, pdMS_TO_TICKS(1000)) == 0) {
        if (resp.identifier == 0x580 + node_id) {
            uint8_t cmd = resp.data[0];
            if ((cmd & 0xE0) == 0x40) {
                // 分段传输
                // ...
            } else if ((cmd & 0xE0) == 0x43) {
                // 快速传输
                int n = 4 - ((cmd >> 2) & 0x03);
                *len = n;
                memcpy(data, &resp.data[4], n);
                return 0;
            }
        }
    }
    return -1;
}
```

### 2.5 NMT网络管理

```c
// NMT命令
#define NMT_START       0x01
#define NMT_STOP        0x02
#define NMT_PRE_OP      0x80
#define NMT_RESET_NODE  0x81
#define NMT_RESET_COMM  0x82

void nmt_send_command(uint8_t node_id, uint8_t command) {
    can_message_t msg;
    msg.identifier = 0x000;  // NMT COB-ID
    msg.data[0] = command;
    msg.data[1] = node_id;  // 0=所有节点
    msg.data_length_code = 2;
    can_transmit(&msg, pdMS_TO_TICKS(100));
}
```

## 三、CAN协议详解

### 3.1 CAN帧格式

**标准帧(11bit ID)：**
```
┌─────┬─────┬─────┬─────┬─────┬─────┬─────┐
│ SOF │ ID  │ RTR │ IDE │ DLC │DATA │ CRC │
│ 1b  │ 11b │ 1b  │ 1b  │ 4b  │0-8B │ 15b │
└─────┴─────┴─────┴─────┴─────┴─────┴─────┘
```

**扩展帧(29bit ID)：**
```
┌─────┬──────┬─────┬─────┬─────┬─────┬─────┐
│ SOF │ ID   │ SRR │ IDE │ DLC │DATA │ CRC │
│ 1b  │ 29b  │ 1b  │ 1b  │ 4b  │0-8B │ 15b │
└─────┴──────┴─────┴─────┴─────┴─────┴─────┘
```

---

### 3.2 CAN波特率

| 波特率 | 位时间 | 采样点 |
|--------|--------|--------|
| 125kbps | 8μs | 87.5% |
| 250kbps | 4μs | 87.5% |
| 500kbps | 2μs | 87.5% |

### 3.3 ESP32 TWAI驱动

```c
#include "driver/twai.h"

void twai_init(void) {
    twai_general_config_t g_config = TWAI_GENERAL_CONFIG_DEFAULT(GPIO_NUM_21, GPIO_NUM_22, TWAI_MODE_NORMAL);
    twai_timing_config_t t_config = TWAI_TIMING_CONFIG_500KBITS();
    twai_filter_config_t f_config = TWAI_FILTER_CONFIG_ACCEPT_ALL();

    twai_driver_install(&g_config, &t_config, &f_config);
    twai_start();
}

// 发送
void twai_send(uint32_t id, uint8_t *data, uint8_t len) {
    twai_message_t message = {
        .identifier = id,
        .data_length_code = len,
    };
    memcpy(message.data, data, len);
    twai_transmit(&message, pdMS_TO_TICKS(1000));
}

// 接收
void twai_receive_task(void *arg) {
    twai_message_t message;
    while (1) {
        if (twai_receive(&message, portMAX_DELAY) == ESP_OK) {
            printf("ID: 0x%03lX, DLC: %d, Data:", message.identifier, message.data_length_code);
            for (int i = 0; i < message.data_length_code; i++) {
                printf(" %02X", message.data[i]);
            }
            printf("\n");
        }
    }
}
```
