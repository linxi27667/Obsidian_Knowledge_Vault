> 适用场景：电机调速、小车循迹/转向、机器人运动控制等一切“让某个量稳定在目标值”的场合
> 学习日期：2026-07-15

## 1. 概述：什么是“控制”，为什么要 PID

生活中很多事情要“稳住一个量”：

- 空调要把室温稳定在 26℃；
- 小车要让左右轮转速稳定在目标值；
- 无人机要让姿态稳定在某个角度。

这类问题的共同结构是 **闭环反馈控制（closed-loop control）**：

```text
   设定值(目标) ──┐
                  ├─→ [控制器] ─→ [执行器] ─→ [被控对象] ─→ 实际输出
                  │                                              │
                  └────────────── [传感器] ←────────────────────┘
                         (把实际输出量回来，和设定值比较)
```

控制器只干一件事：**看“目标”和“实际”差多少（误差），算出“该怎么出力”**。

- 没有反馈的叫 **开环**（比如定时开关、固定给个电压）。开环简单，但负载一变、摩擦一变就歪了。
- 有反馈的叫 **闭环**。PID 就是闭环控制器里最经典、最通用的一种算法。

> **一句话**：PID 是个“看着误差来纠正偏差”的自动调节算法。P 管大小、I 管残留、D 管趋势。

## 2. 核心概念

### 2.1 误差（Error）—— 一切的起点

```text
e = 目标值(target) - 反馈值(feedback)
```

- 车想跑到 0.5 m/s，实际只有 0.3 m/s，误差就是 +0.2。
- 误差为正，说明“还不够，继续加力”；为负，说明“过了，得收力”。

所有 PID 计算都围绕这个 `e` 展开。

### 2.2 PID 三兄弟（用“开车”来理解）

想象你开车去一个目的地，距离就是误差 `e`：

| 项 | 它在算什么 | 开车比喻 | 出力特点 |
|---|---|---|---|
| **P 比例** | `误差 × 系数` | 离得越远，油门踩得越狠 | 误差大出力大，误差小出力小 |
| **I 积分** | `误差的累积 × 系数` | 一直没到，就慢慢加力，直到到达 | 专门消除“死活差一点”的顽固偏差 |
| **D 微分** | `误差变化快慢 × 系数` | 快撞到了，提前松油门 | 预测趋势，防止冲过头 |

**连续域公式：**

```text
u(t) = Kp · e(t)  +  Ki · ∫e(t)dt  +  Kd · de(t)/dt
       └─P─┘        └───I───┘         └─D─┘
```

- `Kp` 比例增益：越大，反应越猛。
- `Ki` 积分增益：越大，消除残留偏差越快，但容易“过冲”。
- `Kd` 微分增益：越大，越“稳重”，抑制晃动，但害怕噪声。

### 2.3 三兄弟各自的毛病（必须知道）

| 项 | 单独用会怎样 | 典型副作用 |
|---|---|---|
| **只用 P** | 永远差一点点到不了（稳态误差/静差）。比如平衡点需要一定力才能顶住摩擦，P 在误差为 0 时出力也为 0，于是停在差一点的地方。 | 有静差 |
| **加 I** | 能消静差，但误差长期存在时会“积过头”，导致超调、来回振荡。 | 超调、积分饱和 |
| **加 D** | 能压振荡，但对噪声极其敏感（微分会放大高频抖动），目标值突变时还会“踢一脚”（微分冲击）。 | 噪声放大、微分冲击 |

> **关键认知**：没有完美的单项，PID 是把三者的优缺点互相抵消——P 快速响应、I 消残差、D 抑超调。

### 2.4 计算机里怎么算（离散 PID）

单片机/MCU 是离散采样的（比如每 5 ms 算一次），所以要用 **离散形式**。本项目用的是 **位置式 PID**：

```text
e[k]    = target - feedback          // 第 k 次采样的误差
I[k]    = I[k-1] + e[k]              // 误差累加（积分）
D[k]    = e[k] - e[k-1]              // 误差的变化量（微分）
u[k]    = Kp·e[k] + Ki·I[k] + Kd·D[k] // 输出
```

> 注意：这里的 `Ki`、`Kd` 是“每个采样点”的增益，**和采样周期绑定**。如果控制周期从 5 ms 改成 10 ms，必须重新换算参数，不能直接套用。

**另一种常见形式：增量式 PID**

只算“这次比上次多出力多少”，对执行器友好（断电后不突变）：

```text
Δu[k] = Kp·(e[k]-e[k-1]) + Ki·e[k] + Kd·(e[k]-2e[k-1]+e[k-2])
```

| 形式 | 优点 | 缺点 | 适合 |
|---|---|---|---|
| 位置式 | 直观，直接给绝对输出 | 积分累积易饱和，断电有跳变 | 电机 PWM、直接控制量 |
| 增量式 | 输出是“增量”，安全，易限幅 | 不带积分记忆（需另存） | 步进电机、阀门 |

### 2.5 工程防御手段（没这些 PID 会翻车）

| 手段 | 作用 |
|---|---|
| **输出限幅** `clamp(u, -O, +O)` | 别让控制器发出“烧毁电机”的指令 |
| **积分限幅** `clamp(I, -I, +I)` | 防止积分项无限累积 |
| **积分分离** | 误差很大时先别积分，避免一上来就“积过头” |
| **微分滤波** | 给 D 项加低通，挡掉高频噪声 |
| **设定值突变时 Reset** | 目标突然跳变时清空 I、D 历史，避免“微分踢一脚”和积分残留 |
| **NaN/Inf 保护** | 传感器读坏（非有限数）时复位输出为 0，别让车失控 |

> 进阶：更强的抗饱和叫 **反算抗饱和（back-calculation）** —— 输出被限幅时，把“多出来的部分”扣回积分项，让它知道“我已经尽力了，别再积了”。本项目目前只用了限幅+分离，没做反算。

## 3. “各种环”到底是什么

### 3.1 一个控制器 ≠ 一个环

复杂系统往往是 **多个控制环串起来**，这叫 **串级控制（cascade control）**。

规则很简单：

```text
外环（慢、管“去哪”）── 输出 ──→ 内环（快、管“准确跟上”）──→ 执行器
```

- **外环**：决定“我想达到什么状态”，它算出来的结果不是直接驱动硬件，而是给内环当“目标值”。
- **内环**：响应快、精度高，拼命让实际值跟上外环给的目标。

> 比喻：外环是“导航说往东开”，内环是“右轮转速给我稳住 0.5 m/s”。

### 3.2 常见几种环

| 环 | 输入（目标/反馈） | 输出（去哪） | 常用结构 | 说明 |
|---|---|---|---|---|
| **电流环** | 目标电流 / 电流采样 | 目标电压 | PI | 最内环，响应最快，抗负载突变。电机驱动常用 |
| **速度环** | 目标速度 / 编码器速度 | PWM（或电流目标） | 前馈+P 或 PI | 让转速稳住，几乎所有运动的内环 |
| **角度环 / 航向环** | 目标角度 / 陀螺仪角度·角速度 | 左右轮目标速度差 | PD | 管朝向，角度不能无限累积，一般不用 I |
| **位置环** | 目标位置 / 位置反馈 | 目标速度 | P 或 PD | 管“走到哪”，输出交给速度环 |
| **循迹环** | 目标线 / 灰度·视觉偏移误差 | 左右轮差速 | 离散 PD + 角速度阻尼 | 误差来自传感器横向偏移 |

### 3.3 串级实例：小车怎么动起来

以“让小车朝某个航向走”为例（正是本项目结构）：

```text
航向环(外) ：误差 = 目标航向 - 实际航向
             ↓  输出左右轮“目标速度差”
速度环(内) ：误差 = 目标轮速 - 编码器轮速
             ↓  输出 PWM 修正
电机/车体
```

还有更经典的三环（工业/无人机常见）：

```text
位置环 ──→ 速度环 ──→ 电流环 ──→ 电机
 (最外)      (中间)      (最内)
```

> 记忆口诀：**越往里越快、越准**；**外环管方向，内环管执行**。

### 3.4 为什么要多环，而不是一个 PID 搞定？

1. **解耦**：把“我想去哪”和“轮子转多快”分开想，逻辑清晰。
2. **快稳兼备**：内环极快，能瞬间压制扰动（比如轮子压到石子）；外环慢慢规划，不慌。
3. **好调参**：内环先调稳，外环再叠加，互不牵扯（见下章）。

### 3.5 前馈（Feedforward）—— 不靠误差的“预判”

有些量你可以 **提前算出来该给多少**，不用等误差出现。例如小车知道“要维持 0.5 m/s 大概要 PWM=50”，就直接先给 50，PID 只在“实际比预期慢”时补差。

```text
pwm = 目标速度(前馈基础) + PID修正(补偿摩擦/负载/左右差异)
```

好处：起步快、不靠慢慢积分爬坡、低速不会卡在静差。本项目速度环就是“前馈 + P”。

## 4. PID 怎么用：调参方法论

### 4.1 调参总原则：**由内到外**

先把手最里面的环调稳，再去调外环。因为外环的输出最终要靠内环执行，内环没稳，外环怎么调都乱。

> 顺序：电流环 → 速度环 → 角度/位置环 → 循迹环。

### 4.2 单环整定步骤（通用“试凑法”）

以速度环为例：

1. **先只开 P（`Ki=Kd=0`）**：把 `Kp` 从小往大加。
   - 太小：反应慢、有静差。
   - 太大：振荡、啸叫。
   - 调到“反应够快、还不振荡”附近，或者用“临界振荡法的 70%”。
2. **再加 I 消静差**：`Ki` 从极小开始加。
   - 加一点就能消除残留偏差就停。
   - 太大→超调、来回晃。
   - 配合积分限幅和积分分离防“积过头”。
3. **（可选）加 D 抑超调**：系统有惯性、容易冲过头时才加。
   - 噪声大时 D 要配滤波，否则越加越抖。
4. **固定内环，去调外环**，重复 1~3。

### 4.3 举个直观例子

调速度环：
- `Kp=0.55, Ki=0, Kd=0`（本项目就是“前馈+P”，低速稳、不积）。
- 想再消除负载变化带来的速度差，就微调加一点 `Ki`，但一定要带 `I_LIMIT` 限幅。

调航向环（角度）：
- 一般 **只用 PD**，因为角度误差到 0 就该停，积分没意义还容易饱和。
- `Kd` 用“实测角速度”做阻尼，车转太快时自动收力，避免冲过目标航向。

### 4.4 调参口诀（背下来）

> **P 管快慢，I 管残差，D 管过冲；**
> **先内后外，先 P 后 I，D 看噪声；**
> **限幅保命，分离防爆，突变要 Reset。**

## 5. 常见坑（避坑清单）

| 现象 | 可能原因 | 解法 |
|---|---|---|
| 永远差一点到不了（静差） | 只有 P，或 I 太小 | 加/增大 Ki，或加前馈 |
| 冲过头、来回振荡 | Kp 太大，或 D 不够 | 降 Kp，加 Kd，加输出限幅 |
| 启动猛地一抖（微分冲击） | 目标突变时 D 项算到突变 | 设定值变化时 `Pid_Reset()`，或 D 改用“对测量值微分” |
| 一直往一个方向攒、输出卡满（积分饱和） | I 无限制累积 | 积分限幅 + 积分分离 + 反算抗饱和 |
| 抖动厉害、噪声大 | D 项放大传感器噪声 | D 加低通滤波，或降低 Kd |
| 改了周期就全乱 | Ki/Kd 与采样周期绑定 | 重新按新周期换算参数 |
| 传感器读坏车失控 | NaN/Inf 没防护 | 非有限数时复位输出为 0 |

## 6. 速查表

**PID 三项一句话：**
- P = 现在差多少 → 出力多大
- I = 过去差多少（累计）→ 补掉残差
- D = 将来会怎样（趋势）→ 提前刹车

**典型环结构：**
- 速度环：前馈 + P（或 PI）
- 角度/航向环：PD（不用 I）
- 位置环：P 或 PD，输出给速度环
- 三环级联：位置 → 速度 → 电流

**调参顺序：** 内 → 外；P → I → D。
