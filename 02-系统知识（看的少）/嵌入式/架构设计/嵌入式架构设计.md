# 嵌入式架构设计

## 核心概念

- **架构** - 系统的整体结构和组织方式
- **分层** - 按功能层次组织代码
- **模块化** - 将系统分解为独立模块
- **解耦** - 降低模块间依赖

---

## 一、架构模式

### 1.1 分层架构

```
┌─────────────────────────────────────┐
│           应用层                     │
│   业务逻辑、用户界面、通信协议       │
├─────────────────────────────────────┤
│           中间件层                   │
│   RTOS、协议栈、文件系统            │
├─────────────────────────────────────┤
│           驱动层                     │
│   外设驱动、传感器驱动              │
├─────────────────────────────────────┤
│           硬件抽象层(HAL)            │
│   寄存器操作、硬件接口              │
└─────────────────────────────────────┘
```

**优点：**
- 结构清晰
- 易于维护
- 便于移植

### 1.3 状态机架构

**有限状态机(FSM)：**
```
┌─────────────────────────────────────┐
│              状态机                  │
│                                     │
│  ┌─────┐   事件   ┌─────┐         │
│  │状态A │────────→│状态B │         │
│  └─────┘         └─────┘         │
│     ↑                │            │
│     └────────────────┘            │
│           事件                     │
└─────────────────────────────────────┘
```

**实现：**
```c
typedef enum {
    STATE_IDLE,
    STATE_RUNNING,
    STATE_PAUSED,
    STATE_ERROR,
} State;

typedef enum {
    EVENT_START,
    EVENT_STOP,
    EVENT_PAUSE,
    EVENT_RESUME,
    EVENT_ERROR,
} Event;

State current_state = STATE_IDLE;

void state_machine(Event event) {
    switch (current_state) {
        case STATE_IDLE:
            if (event == EVENT_START) {
                current_state = STATE_RUNNING;
                start_running();
            }
            break;
            
        case STATE_RUNNING:
            if (event == EVENT_PAUSE) {
                current_state = STATE_PAUSED;
                pause_running();
            } else if (event == EVENT_STOP) {
                current_state = STATE_IDLE;
                stop_running();
            } else if (event == EVENT_ERROR) {
                current_state = STATE_ERROR;
                handle_error();
            }
            break;
            
        case STATE_PAUSED:
            if (event == EVENT_RESUME) {
                current_state = STATE_RUNNING;
                resume_running();
            } else if (event == EVENT_STOP) {
                current_state = STATE_IDLE;
                stop_running();
            }
            break;
            
        case STATE_ERROR:
            if (event == EVENT_STOP) {
                current_state = STATE_IDLE;
                recover_from_error();
            }
            break;
    }
}
```

### 1.4 表驱动架构

**状态转移表：**
```c
typedef struct {
    State current_state;
    Event event;
    State next_state;
    Action action;
} Transition;

Transition transitions[] = {
    { STATE_IDLE,    EVENT_START,  STATE_RUNNING, start_running },
    { STATE_RUNNING, EVENT_PAUSE,  STATE_PAUSED,  pause_running },
    { STATE_RUNNING, EVENT_STOP,   STATE_IDLE,    stop_running },
    { STATE_PAUSED,  EVENT_RESUME, STATE_RUNNING, resume_running },
    { STATE_PAUSED,  EVENT_STOP,   STATE_IDLE,    stop_running },
    { STATE_ERROR,   EVENT_STOP,   STATE_IDLE,    recover_error },
};

void process_event(Event event) {
    for (int i = 0; i < ARRAY_SIZE(transitions); i++) {
        if (transitions[i].current_state == current_state &&
            transitions[i].event == event) {
            transitions[i].action();
            current_state = transitions[i].next_state;
            return;
        }
    }
}
```

## 三、任务设计

### 3.1 任务划分原则

**原则：**
- 单一职责
- 高内聚低耦合
- 优先级合理
- 栈空间充足

**任务类型：**
| 类型 | 特点 | 示例 |
|------|------|------|
| 周期任务 | 固定周期执行 | 传感器采集 |
| 事件任务 | 等待事件触发 | 按键处理 |
| 后台任务 | 低优先级执行 | 日志记录 |

---

### 3.2 任务通信模式

**生产者-消费者：**
```c
QueueHandle_t data_queue;

// 生产者任务
void producer_task(void *param) {
    while (1) {
        Data data = read_sensor();
        xQueueSend(data_queue, &data, portMAX_DELAY);
        vTaskDelay(pdMS_TO_TICKS(100));
    }
}

// 消费者任务
void consumer_task(void *param) {
    Data data;
    while (1) {
        if (xQueueReceive(data_queue, &data, portMAX_DELAY)) {
            process_data(data);
        }
    }
}
```

**发布-订阅：**
```c
typedef struct {
    Event_Type type;
    void *data;
} Event;

// 事件总线
typedef struct {
    QueueHandle_t subscribers[MAX_SUBSCRIBERS];
    int count;
} EventBus;

void event_bus_publish(EventBus *bus, Event *event) {
    for (int i = 0; i < bus->count; i++) {
        xQueueSend(bus->subscribers[i], event, 0);
    }
}
```

---

### 3.3 任务优先级设计

**优先级分配：**
| 优先级 | 任务 | 说明 |
|--------|------|------|
| 最高 | 安全任务 | 看门狗、过流保护 |
| 高 | 实时任务 | 电机控制、PID |
| 中 | 通信任务 | UART、CAN |
| 低 | 应用任务 | 业务逻辑 |
| 最低 | 后台任务 | 日志、统计 |

```c
typedef enum {

    ERR_TIMEOUT = -2,
    ERR_BUSY = -3,
    ERR_NO_MEMORY = -4,
    ERR_HARDWARE = -5,

    Error_Code err = (expr); \

        return err; \
    } \
```

### 4.2 错误恢复策略

```c
typedef enum {
    RECOVERY_NONE,
    RECOVERY_RETRY,
    RECOVERY_RESET,
    RECOVERY_SAFE_STATE,
} Recovery_Strategy;

Error_Code handle_error(Error_Code error, Recovery_Strategy strategy) {
    switch (strategy) {
        case RECOVERY_RETRY:
            // 重试操作
            return retry_operation();
            
        case RECOVERY_RESET:
            // 重置模块
            return reset_module();
            
        case RECOVERY_SAFE_STATE:
            // 进入安全状态
            return enter_safe_state();
            
        default:
            return error;
    }
}
```

## 五、配置管理

### 5.1 参数配置系统

```c
typedef struct {
    uint32_t version;
    uint32_t checksum;
    
    // 系统参数
    struct {
        uint32_t baudrate;
        uint8_t device_id;
        uint8_t mode;
    } system;
    
    // 控制参数
    struct {
        float kp;
        float ki;
        float kd;
    } pid;
    
    // 限值参数
    struct {
        float max_speed;
        float max_current;
        float max_temperature;
    } limits;
} Config;

// 默认配置
static const Config default_config = {
    .version = 1,
    .system = {
        .baudrate = 115200,
        .device_id = 1,
        .mode = 0,
    },
    .pid = {
        .kp = 1.0f,
        .ki = 0.1f,
        .kd = 0.01f,
    },
    .limits = {
        .max_speed = 1000.0f,
        .max_current = 10.0f,
        .max_temperature = 80.0f,
    },
};

// 加载配置
Error_Code config_load(Config *config) {
    if (nvs_read("config", config, sizeof(Config)) != OK) {
        // 使用默认配置
        *config = default_config;
        config_save(config);
    }
    
    // 校验版本和校验和
    if (config->version != default_config.version ||
        config->checksum != calculate_checksum(config)) {
        *config = default_config;
        config_save(config);
    }
    
    return OK;
}

// 保存配置
Error_Code config_save(const Config *config) {
    Config save_config = *config;
    save_config.checksum = calculate_checksum(&save_config);
    return nvs_write("config", &save_config, sizeof(Config));
}
```

### 5.2 运行时配置更新

```c
typedef struct {
    char key[32];
    void *value;
    size_t size;
    void (*callback)(void);
} Config_Entry;

Config_Entry config_entries[] = {
    { "system.baudrate", &config.system.baudrate, sizeof(uint32_t), on_baudrate_change },
    { "pid.kp", &config.pid.kp, sizeof(float), on_pid_change },
    // ...
};

Error_Code config_set(const char *key, const void *value) {
    for (int i = 0; i < ARRAY_SIZE(config_entries); i++) {
        if (strcmp(config_entries[i].key, key) == 0) {
            memcpy(config_entries[i].value, value, config_entries[i].size);
            if (config_entries[i].callback) {
                config_entries[i].callback();
            }
            return OK;
        }
    }
    return ERR_INVALID_PARAM;
}
```

## 六、日志系统

### 6.1 日志级别设计

```c
typedef enum {
    LOG_LEVEL_NONE = 0,
    LOG_LEVEL_ERROR,
    LOG_LEVEL_WARNING,
    LOG_LEVEL_INFO,
    LOG_LEVEL_DEBUG,
    LOG_LEVEL_VERBOSE,
} Log_Level;

// 当前日志级别
static Log_Level current_level = LOG_LEVEL_INFO;

// 日志宏
#define LOG_ERROR(fmt, ...) do { \
    if (current_level >= LOG_LEVEL_ERROR) { \
        log_print(LOG_LEVEL_ERROR, fmt, ##__VA_ARGS__); \
    } \
} while(0)

#define LOG_WARNING(fmt, ...) do { \
    if (current_level >= LOG_LEVEL_WARNING) { \
        log_print(LOG_LEVEL_WARNING, fmt, ##__VA_ARGS__); \
    } \
} while(0)

#define LOG_INFO(fmt, ...) do { \
    if (current_level >= LOG_LEVEL_INFO) { \
        log_print(LOG_LEVEL_INFO, fmt, ##__VA_ARGS__); \
    } \
} while(0)

#define LOG_DEBUG(fmt, ...) do { \
    if (current_level >= LOG_LEVEL_DEBUG) { \
        log_print(LOG_LEVEL_DEBUG, fmt, ##__VA_ARGS__); \
    } \
} while(0)
```

### 6.2 日志输出

```c
typedef enum {
    LOG_DEST_UART,
    LOG_DEST_RTT,
    LOG_DEST_FILE,
    LOG_DEST_SYSLOG,
} Log_Destination;

typedef struct {
    Log_Level level;
    Log_Destination dest;
    uint32_t timestamp;
    const char *module;
    const char *message;
} Log_Entry;

void log_print(Log_Level level, const char *fmt, ...) {
    char buffer[256];
    va_list args;
    
    va_start(args, fmt);
    vsnprintf(buffer, sizeof(buffer), fmt, args);
    va_end(args);
    
    Log_Entry entry = {
        .level = level,
        .dest = current_dest,
        .timestamp = get_tick(),
        .module = current_module,
        .message = buffer,
    };
    
    log_output(&entry);
}

void log_output(Log_Entry *entry) {
    switch (entry->dest) {
        case LOG_DEST_UART:
            uart_printf("[%08u] [%s] [%s] %s\n", 
                       entry->timestamp,
                       log_level_str(entry->level),
                       entry->module,
                       entry->message);
            break;
            
        case LOG_DEST_RTT:
            SEGGER_RTT_printf(0, "[%s] %s\n", 
                             log_level_str(entry->level),
                             entry->message);
            break;
    }
}
```

## 附录：设计原则

### SOLID原则

| 原则 | 说明 |
|------|------|
| 单一职责 | 一个模块只负责一件事 |
| 开闭原则 | 对扩展开放，对修改关闭 |
| 里氏替换 | 子类可以替换父类 |
| 接口隔离 | 接口应该小而专一 |
| 依赖反转 | 依赖抽象而非具体 |

### 其他原则

| 原则 | 说明 |
|------|------|
| DRY | 不要重复自己 |
| KISS | 保持简单 |
| YAGNI | 不需要就不做 |
| 组合优于继承 | 优先使用组合 |
