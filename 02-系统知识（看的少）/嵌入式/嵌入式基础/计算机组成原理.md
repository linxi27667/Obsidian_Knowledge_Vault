# 计算机组成原理

## 核心概念

- **冯·诺依曼体系** - 存储程序、程序控制
- **CPU** - 中央处理器，执行指令的核心
- **存储层次** - 寄存器→Cache→主存→外存
- **总线** - 连接各部件的数据通路

---

## 一、计算机系统概述

### 1.1 冯·诺依曼体系结构

```
┌─────────────────────────────────────┐
│            存储器                    │
│    ┌───────────────────────┐       │
│    │     指令和数据         │       │
│    └───────────────────────┘       │
└───────────────┬─────────────────────┘
                │
    ┌───────────┼───────────┐
    │           │           │
    ▼           ▼           ▼
┌───────┐  ┌───────┐  ┌───────┐
│ 输入  │  │  CPU  │  │ 输出  │
│ 设备  │  │       │  │ 设备  │
└───────┘  └───────┘  └───────┘
```

**特点：**
1. 指令和数据以二进制表示
2. 指令和数据存储在存储器中
3. 指令由操作码和地址码组成
4. 以运算器为中心

---

### 1.2 计算机性能指标

**CPU时间：**
$$T_{CPU} = I_C \times CPI \times T_{clk}$$

| 指标 | 说明 |
|------|------|
| IC | 指令条数 |
| CPI | 每条指令时钟周期数 |
| Tclk | 时钟周期 |
| MIPS | 每秒百万指令数 |
| MFLOPS | 每秒百万浮点运算数 |

---

## 二、数据表示

### 2.1 进制转换

**二进制 ↔ 十进制：**
$$1010B = 1×2^3 + 0×2^2 + 1×2^1 + 0×2^0 = 10D$$

**二进制 ↔ 十六进制：**
$$1010B = AH$$

---

### 2.2 原码、反码、补码

**原码：** 符位 + 绝对值
```
+5: 0 0000101
-5: 1 0000101
```

**反码：** 正数不变，负数按位取反
```
+5: 0 0000101
-5: 1 1111010
```

**补码：** 正数不变，负数反码+1
```
+5: 0 0000101
-5: 1 1111011
```

**补码运算：**
$$[X+Y]_补 = [X]_补 + [Y]_补$$
$$[X-Y]_补 = [X]_补 + [-Y]_补$$

---

### 2.3 浮点数表示

**IEEE 754标准：**
```
┌──────┬──────────┬───────────────────┐
│ 符号 │  阶码    │       尾数        │
│ 1位  │  8位     │       23位        │
└──────┴──────────┴───────────────────┘
```

**单精度：**
$$V = (-1)^S \times 1.M \times 2^{E-127}$$

**双精度：**
$$V = (-1)^S \times 1.M \times 2^{E-1023}$$

---

## 三、运算器

### 3.1 加法器

**半加器：**
$$S = A \oplus B$$
$$C = A \cdot B$$

**全加器：**
$$S = A \oplus B \oplus C_{in}$$
$$C_{out} = (A \oplus B) \cdot C_{in} + A \cdot B$$

**串行进位加法器：** 简单但慢
**并行进位加法器：** 复杂但快

---

### 3.2 算术逻辑单元(ALU)

**功能：**
- 算术运算：加、减、乘、除
- 逻辑运算：与、或、非、异或
- 移位运算：左移、右移

---

### 3.3 乘法运算

**原码乘法：** 符位异或，绝对值相乘
**补码乘法：** Booth算法

---

### 3.4 除法运算

**原码除法：** 恢复余数法、加减交替法
**补码除法：** 补码加减交替法

---

## 四、存储系统

### 4.1 存储层次

```
┌─────────────────────────────────────┐
│           寄存器                     │  最快、最小、最贵
├─────────────────────────────────────┤
│           Cache                     │
├─────────────────────────────────────┤
│           主存                      │
├─────────────────────────────────────┤
│           磁盘                      │
├─────────────────────────────────────┤
│           磁带                      │  最慢、最大、最便宜
└─────────────────────────────────────┘
```

---

### 4.2 主存储器

**SRAM：** 静态随机存储器
- 6个晶体管存储1位
- 速度快，成本高
- 用于Cache

**DRAM：** 动态随机存储器
- 1个晶体管+1个电容
- 需要刷新
- 用于主存

**刷新方式：**
- 集中刷新
- 分散刷新
- 异步刷新

---

### 4.3 Cache

**原理：** 局部性原理
- 时间局部性：最近访问的数据可能再次访问
- 空间局部性：相邻地址可能被访问

**映射方式：**
| 方式 | 说明 | 冲突率 |
|------|------|--------|
| 直接映射 | 固定位置 | 高 |
| 全相联 | 任意位置 | 低 |
| 组相联 | 组内任意 | 中 |

**替换算法：**
- FIFO（先进先出）
- LRU（最近最少使用）
- LFU（最不经常使用）

**写策略：**
| 策略 | 说明 |
|------|------|
| 写直达 | 同时写Cache和主存 |
| 写回 | 只写Cache，替换时写回 |

---

### 4.4 虚拟存储器

**页式虚拟存储：**
- 逻辑地址 → 页号 + 页内偏移
- 物理地址 → 页框号 + 页内偏移
- 页表：记录页到页框的映射

**TLB（快表）：** 加速地址转换

---

## 五、指令系统

### 5.1 指令格式

```
┌──────────┬──────────┐
│  操作码  │  地址码  │
└──────────┴──────────┘
```

**地址码数量：**
- 三地址指令：OP A1, A2, A3
- 二地址指令：OP A1, A2
- 一地址指令：OP A
- 零地址指令：OP

---

### 5.2 寻址方式

| 寻址方式 | 说明 | 有效地址 |
|----------|------|----------|
| 立即寻址 | 操作数在指令中 | - |
| 直接寻址 | 地址在指令中 | EA = A |
| 间接寻址 | 地址指向的单元存地址 | EA = (A) |
| 寄存器寻址 | 操作数在寄存器 | - |
| 寄存器间接 | 寄存器存地址 | EA = (R) |
| 基址寻址 | 基址+偏移 | EA = (BR) + A |
| 变址寻址 | 变址+偏移 | EA = (IX) + A |
| 相对寻址 | PC+偏移 | EA = (PC) + A |

---

### 5.3 CISC与RISC

| 特性 | CISC | RISC |
|------|------|------|
| 指令数量 | 多 | 少 |
| 指令长度 | 可变 | 固定 |
| 寻址方式 | 复杂 | 简单 |
| 执行效率 | 低 | 高 |
| 代表 | x86 | ARM, RISC-V |

## 六、中央处理器

### 6.1 CPU组成

```
┌─────────────────────────────────────┐
│              CPU                     │
│  ┌───────────────────────────────┐ │
│  │         控制器                 │ │
│  │  ┌─────┐ ┌─────┐ ┌─────┐    │ │
│  │  │ PC  │ │ IR  │ │ CU  │    │ │
│  │  └─────┘ └─────┘ └─────┘    │ │
│  └───────────────────────────────┘ │
│  ┌───────────────────────────────┐ │
│  │         运算器                 │ │
│  │  ┌─────┐ ┌─────┐ ┌─────┐    │ │
│  │  │ ALU │ │ ACC │ │寄存器│   │ │
│  │  └─────┘ └─────┘ └─────┘    │ │
│  └───────────────────────────────┘ │
└─────────────────────────────────────┘
```

---

### 6.2 指令周期

**基本周期：**
1. **取指周期** - 从内存取指令
2. **间址周期** - 间接寻址时取有效地址
3. **执行周期** - 执行指令
4. **中断周期** - 处理中断

---

### 6.3 数据通路

**单总线结构：** 简单但慢
**多总线结构：** 复杂但快

---

### 6.4 控制器

**硬布线控制器：** 速度快，不灵活
**微程序控制器：** 灵活，速度较慢

**微指令格式：**
- 水平型：并行操作，长字长
- 垂直型：串行操作，短字长

---

### 6.5 流水线

**原理：** 将指令执行分成多个阶段

```
指令1: 取指 → 译码 → 执行 → 访存 → 写回
指令2:      取指 → 译码 → 执行 → 访存 → 写回
指令3:           取指 → 译码 → 执行 → 访存 → 写回
```

**性能：**
$$加速比 = \frac{T_{串行}}{T_{流水线}}$$

**冲突：**
- 结构冲突：资源冲突
- 数据冲突：数据依赖
- 控制冲突：分支指令

## 八、输入/输出系统

### 8.1 I/O编址

**统一编址：** 内存和I/O统一地址空间
**独立编址：** 内存和I/O独立地址空间

---

### 8.2 I/O控制方式

| 方式 | 说明 | 效率 |
|------|------|------|
| 程序查询 | CPU轮询 | 低 |
| 中断 | 设备主动通知 | 中 |
| DMA | 直接内存访问 | 高 |
| 通道 | 专用处理器 | 最高 |

---

### 8.3 DMA

**工作过程：**
1. CPU设置DMA参数
2. DMA接管总线
3. DMA直接传输数据
4. 传输完成后中断CPU

**传送方式：**
- 停止CPU访问
- 周期挪用
- 交替访问

---

### 8.4 中断系统

**中断分类：**
- 外部中断：I/O设备、定时器
- 内部中断：溢出、除零、缺页

**中断处理过程：**
1. 关中断
2. 保存断点
3. 识别中断源
4. 保存现场
5. 执行中断服务程序
6. 恢复现场
7. 开中断
8. 返回断点

---

## 九、ARM架构基础

### 9.1 ARM处理器模式

| 模式 | 说明 |
|------|------|
| User | 用户模式 |
| FIQ | 快速中断 |
| IRQ | 普通中断 |
| Supervisor | 管理模式 |
| Abort | 终止模式 |
| Undefined | 未定义模式 |
| System | 系统模式 |

---

### 9.2 ARM寄存器

**通用寄存器：** R0-R15
- R13(SP)：栈指针
- R14(LR)：链接寄存器
- R15(PC)：程序计数器

**程序状态寄存器：** CPSR/SPSR

---

### 9.3 ARM指令集

**数据处理指令：**
```assembly
MOV R0, #1      ; R0 = 1
ADD R0, R1, R2  ; R0 = R1 + R2
SUB R0, R1, R2  ; R0 = R1 - R2
AND R0, R1, R2  ; R0 = R1 & R2
ORR R0, R1, R2  ; R0 = R1 | R2
```

**加载/存储指令：**
```assembly
LDR R0, [R1]    ; R0 = *R1
STR R0, [R1]    ; *R1 = R0
LDRB R0, [R1]   ; R0 = *(uint8_t*)R1
STRB R0, [R1]   ; *(uint8_t*)R1 = R0
```

**分支指令：**
```assembly
B label         ; 无条件跳转
BL label        ; 带链接跳转（函数调用）
BEQ label       ; 相等时跳转
BNE label       ; 不等时跳转
```

---

### 9.4 ARM异常处理

**异常向量表：**
```
0x00: Reset
0x04: Undefined Instruction
0x08: SWI
0x0C: Prefetch Abort
0x10: Data Abort
0x14: Reserved
0x18: IRQ
0x1C: FIQ
```

## 十、RISC-V架构

### 10.1 RISC-V特点

- 开源指令集架构
- 模块化设计
- 简洁高效
- 易于扩展

---

### 10.2 RISC-V寄存器

| 寄存器 | 别名 | 用途 |
|--------|------|------|
| x0 | zero | 常数0 |
| x1 | ra | 返回地址 |
| x2 | sp | 栈指针 |
| x3 | gp | 全局指针 |
| x4 | tp | 线程指针 |
| x5-x7 | t0-t2 | 临时寄存器 |
| x8-x9 | s0-s1 | 保存寄存器 |
| x10-x17 | a0-a7 | 函数参数 |
| x18-x27 | s2-s11 | 保存寄存器 |
| x28-x31 | t3-t6 | 临时寄存器 |

---

### 10.3 RISC-V指令

**整数运算：**
```assembly
add x1, x2, x3    # x1 = x2 + x3
sub x1, x2, x3    # x1 = x2 - x3
and x1, x2, x3    # x1 = x2 & x3
or x1, x2, x3     # x1 = x2 | x3
```

**加载/存储：**
```assembly
lw x1, 0(x2)      # x1 = *(int32_t*)(x2)
sw x1, 0(x2)      # *(int32_t*)(x2) = x1
```

**分支：**
```assembly
beq x1, x2, label  # if (x1 == x2) goto label
bne x1, x2, label  # if (x1 != x2) goto label
```
