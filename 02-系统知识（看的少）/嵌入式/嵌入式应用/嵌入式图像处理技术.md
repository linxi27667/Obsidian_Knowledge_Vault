## 一、图像基础

### 1.1 像素与位深

图像是由像素（Pixel）组成的二维矩阵。每个像素携带颜色信息，其数据量由**位深（Bit Depth）**决定。

| 位深 | 颜色数 | 典型用途 |
|------|--------|----------|
| 1-bit | 2（黑白） | 电子价签、OLED单色显示 |
| 8-bit | 256（灰度/调色板） | 灰度图、嵌入式图像处理 |
| 16-bit | 65536（RGB565） | 嵌入式彩色显示 |
| 24-bit | 16.7M（RGB888） | 标准真彩色 |
| 32-bit | 含Alpha通道 | 带透明度的图像 |

**图像数据量计算公式：**

```
数据量(字节) = 宽 × 高 × 位深 / 8
```

示例：320×240 RGB565 图像 = 320 × 240 × 2 = 153,600 字节 ≈ 150 KB

### 1.2 色彩空间

#### 1.2.1 RGB 色彩空间

RGB 是最直观的色彩模型，通过红（R）、绿（G）、蓝（B）三通道混合表示颜色。

**常见 RGB 格式：**

| 格式 | 每像素字节 | 描述 |
|------|-----------|------|
| RGB332 | 1 byte | R3/G3/B2，共256色 |
| RGB565 | 2 bytes | R5/G6/B5，共65536色 |
| RGB555 | 2 bytes | R5/G5/B5，最高位不用 |
| RGB888 | 3 bytes | R8/G8/B8，真彩色 |
| ARGB8888 | 4 bytes | 带Alpha通道的真彩色 |

**RGB565 编码示例：**

```c
// 将 RGB888 转换为 RGB565
uint16_t rgb888_to_rgb565(uint8_t r, uint8_t g, uint8_t b) {
    return ((r >> 3) << 11) | ((g >> 2) << 5) | (b >> 3);
}

// 从 RGB565 提取各通道
void rgb565_to_rgb888(uint16_t color, uint8_t *r, uint8_t *g, uint8_t *b) {
    *r = (color >> 11) << 3;
    *g = ((color >> 5) & 0x3F) << 2;
    *b = (color & 0x1F) << 3;
}
```

#### 1.2.2 YUV 色彩空间

YUV 将亮度（Y）和色度（U、V）分离，广泛用于视频和摄像头领域。

**YUV 的优势：**
- 人眼对亮度敏感、对色度不敏感，可通过**色度下采样**压缩数据量
- 摄像头传感器原生输出 YUV 格式
- 视频编码标准（H.264/H.265）基于 YUV

**RGB 转 YUV 公式（BT.601 标准）：**

```
Y  =  0.299R + 0.587G + 0.114B
U  = -0.169R - 0.331G + 0.500B + 128
V  =  0.500R - 0.419G - 0.081B + 128
```

**YUV 采样格式：**

| 格式 | 采样比 | 每像素字节 | 说明 |
|------|--------|-----------|------|
| YUV444 | 4:4:4 | 3 bytes | 无色度下采样 |
| YUV422 | 4:2:2 | 2 bytes | 水平方向色度减半 |
| YUV420 | 4:2:0 | 1.5 bytes | 水平+垂直色度均减半 |
| NV12 | 4:2:0 | 1.5 bytes | Y平面 + UV交错平面 |
| NV21 | 4:2:0 | 1.5 bytes | Y平面 + VU交错平面（Android常用） |

**YUV422 存储格式（以 YUYV 为例）：**

```
内存排列: Y0 U0 Y1 V0 Y2 U1 Y3 V1 ...
像素对:   [Y0,U0,V0] [Y1,U0,V1] 共享 U,V
```

#### 1.2.3 HSV 色彩空间

HSV 用色相（Hue）、饱和度（Saturation）、明度（Value）描述颜色，更适合颜色识别和分割。

| 参数 | 范围 | 含义 |
|------|------|------|
| H（色相） | 0°~360° | 颜色种类（红0/黄60/绿120/蓝240） |
| S（饱和度） | 0%~100% | 颜色纯度 |
| V（明度） | 0%~100% | 颜色亮暗 |

**RGB 转 HSV 算法（C语言）：**

```c
typedef struct {
    float h; // 0~360
    float s; // 0~1
    float v; // 0~1
} HSV_t;

HSV_t rgb_to_hsv(uint8_t r, uint8_t g, uint8_t b) {
    float rf = r / 255.0f, gf = g / 255.0f, bf = b / 255.0f;
    float cmax = fmaxf(rf, fmaxf(gf, bf));
    float cmin = fminf(rf, fminf(gf, bf));
    float diff = cmax - cmin;
    HSV_t hsv;

    if (cmax == cmin) {
        hsv.h = 0;
    } else if (cmax == rf) {
        hsv.h = 60 * fmodf((gf - bf) / diff, 6);
    } else if (cmax == gf) {
        hsv.h = 60 * ((bf - rf) / diff + 2);
    } else {
        hsv.h = 60 * ((rf - gf) / diff + 4);
    }
    if (hsv.h < 0) hsv.h += 360;

    hsv.s = (cmax == 0) ? 0 : diff / cmax;
    hsv.v = cmax;
    return hsv;
}
```

**HSV 颜色分割在嵌入式中的典型应用：**

```c
// 红色检测（H范围在0附近，需要处理环绕）
bool is_red(HSV_t hsv) {
    return (hsv.s > 0.4f && hsv.v > 0.3f) &&
           (hsv.h < 15 || hsv.h > 345);
}

// 蓝色检测
bool is_blue(HSV_t hsv) {
    return (hsv.s > 0.4f && hsv.v > 0.3f) &&
           (hsv.h > 200 && hsv.h < 260);
}
```

### 1.3 分辨率与帧率

**常见嵌入式摄像头分辨率：**

| 名称 | 分辨率 | 总像素 | 典型应用 |
|------|--------|--------|----------|
| QQVGA | 160×120 | 19K | 超低功耗场景 |
| QVGA | 320×240 | 77K | 基础图像处理 |
| VGA | 640×480 | 307K | 通用嵌入式视觉 |
| SVGA | 800×600 | 480K | 中端显示 |
| XGA | 1024×768 | 786K | 较高分辨率需求 |
| 720P | 1280×720 | 922K | 高清视频 |
| 1080P | 1920×1080 | 2.07M | 高清监控 |

**帧率（FPS）与带宽关系：**

```
带宽 = 宽 × 高 × 位深 × 帧率

示例: 640×480 YUV422(16bit) @ 30fps
带宽 = 640 × 480 × 2 × 30 = 18.4 MB/s
```

**嵌入式帧率选择策略：**
- 静态场景（二维码识别）：5~10 FPS 足够
- 运动检测：15~20 FPS
- 实时视频流：25~30 FPS
- 高速运动分析：60+ FPS（需全局快门）

### 1.4 图像格式

| 格式 | 压缩方式 | 特点 | 嵌入式用途 |
|------|----------|------|-----------|
| RAW | 无压缩 | 传感器原始数据，需ISP处理 | 图像算法开发 |
| BMP | 无压缩 | 文件大，结构简单 | 图像显示测试 |
| JPEG | 有损压缩 | 压缩率高（10:1~20:1） | 图像传输/存储 |
| PNG | 无损压缩 | 支持Alpha，文件较大 | UI资源 |
| MJPEG | 帧内JPEG | 每帧独立编码 | 视频流 |

**BMP 文件结构：**

```
┌─────────────────┐
│  文件头 (14B)    │  bfType="BM", bfSize, bfOffBits
├─────────────────┤
│  信息头 (40B)    │  biWidth, biHeight, biBitCount
├─────────────────┤
│  调色板 (可选)   │  8-bit及以下需要
├─────────────────┤
│  像素数据        │  从下到上、从左到右排列
└─────────────────┘
```

**JPEG 压缩原理简述：**

1. **色彩空间转换**：RGB → YCbCr
2. **色度下采样**：4:2:0 采样
3. **DCT变换**：8×8 块的离散余弦变换
4. **量化**：高频分量大幅量化（有损）
5. **熵编码**：Huffman 编码

## 二、摄像头接口

### 2.1 DVP 并行接口

DVP（Digital Video Port）是传统并行摄像头接口，使用多根数据线并行传输。

**DVP 信号线：**

| 信号 | 方向 | 说明 |
|------|------|------|
| PCLK | Sensor→MCU | 像素时钟 |
| VSYNC | Sensor→MCU | 帧同步 |
| HSYNC/HREF | Sensor→MCU | 行同步/行有效 |
| D[7:0] 或 D[9:0] | Sensor→MCU | 并行数据线（8/10位） |
| XCLK | MCU→Sensor | 主时钟输入 |
| SIOC | MCU→Sensor | I2C时钟（SCCB） |
| SIOD | MCU→Sensor | I2C数据（SCCB） |

**DVP 时序：**

```
VSYNC ─┐                            ┌──────────
       └────────────────────────────┘
        ↑ 新帧开始

HSYNC ─┐    ┌────┐    ┌────┐    ┌──
       └────┘    └────┘    └────┘
        ↑ 行有效区域

PCLK ──┐┌┐┌┐┌┐┌┐┌┐┌┐┌┐┌┐┌┐┌┐┌┐┌┐┌┐┌┐┌┐
        每个时钟沿采样一个像素数据
```

**DVP 接口优缺点：**
- 优点：接口简单、调试方便、兼容性好
- 缺点：引脚多（通常需要12~14个IO）、速率受限（PCLK一般<50MHz）、不适合高分辨率
- 典型速率：VGA@30fps 约需 PCLK=24MHz

**STM32 DCMI 接口示例（DVP接收）：**

```c
// STM32 DCMI 配置
void DCMI_Init(void) {
    DCMI_HandleTypeDef hdcmi;
    hdcmi.Instance = DCMI;
    hdcmi.Init.CaptureRate = DCMI_CR_ALL_FRAME;
    hdcmi.Init.VSPolarity = DCMI_VSPOLARITY_LOW;
    hdcmi.Init.HSPolarity = DCMI_HSPOLARITY_LOW;
    hdcmi.Init.PCKPolarity = DCMI_PCKPOLARITY_RISING;
    hdcmi.Init.SyncroMode = DCMI_SYNCRO_HARDWARE;
    hdcmi.Init.DataWidth = DCMI_DATAWIDTH_8BIT;
    HAL_DCMI_Init(&hdcmi);
}

// 启动DMA接收一帧图像
void start_capture(uint32_t *buffer, uint32_t length) {
    HAL_DCMI_Start_DMA(&hdcmi, DCMI_MODE_CONTINUOUS,
                        buffer, length);
}
```

### 2.2 MIPI-CSI 串行接口

MIPI CSI-2（Camera Serial Interface）是现代移动和嵌入式设备的标准摄像头接口。

**MIPI CSI-2 架构：**

```
┌──────────┐    差分信号线     ┌──────────┐
│  Sensor  │ ═══════════════> │  SoC/ISP │
│          │  Data Lane 0~3   │          │
│          │ ───────────────> │          │
│          │  Clock Lane      │          │
└──────────┘                  └──────────┘
```

**MIPI CSI-2 关键参数：**

| 参数 | 说明 |
|------|------|
| Data Lane | 1/2/4 lane可选，每lane一对差分线 |
| 速率 | 每lane最高2.5 Gbps（D-PHY v1.2） |
| 协议层 | D-PHY物理层 → CSI-2协议层 → 应用层 |
| 包格式 | 短包（同步/控制）+ 长包（像素数据） |
| RAW格式 | RAW8/RAW10/RAW12/RAW14 |
| 虚拟通道 | 最多4个VC，可同时传输不同数据流 |

**MIPI CSI-2 数据包结构：**

```
┌──────────┬──────────────┬──────────┬──────────┬──────────┐
│ SoT      │ 包头(短包)   │ 数据     │ CRC      │ EoT      │
│ Start of │ Data ID +    │ Payload  │ 校验     │ End of   │
│ Transmit │ Word Count   │          │          │ Transmit │
└──────────┴──────────────┴──────────┴──────────┴──────────┘
```

**DVP vs MIPI-CSI 对比：**

| 特性 | DVP | MIPI CSI-2 |
|------|-----|------------|
| 信号类型 | 单端并行 | 差分串行 |
| 引脚数 | 12~14 | 4~10 |
| 最高速率 | ~50 MHz PCLK | 2.5 Gbps/lane |
| 最大分辨率 | VGA~720P | 4K+ |
| EMI | 较差 | 优秀（差分） |
| 布线难度 | 简单 | 阻抗控制要求高 |
| 成本 | 低 | 中等 |

### 2.3 USB 摄像头

USB 摄像头通过 USB Video Class（UVC）协议传输图像，适合需要即插即用的场景。

**UVC 协议要点：**
- 标准 USB 类设备，无需专用驱动
- 支持 MJPEG 和 YUV 两种传输格式
- USB 2.0 High-Speed 理论带宽 480 Mbps（实际约 30~40 MB/s）
- USB 3.0 理论带宽 5 Gbps

**USB 带宽计算：**

```
USB 2.0 实际可用: ~30 MB/s
640×480 YUV422 @ 30fps: 18.4 MB/s (可行)
1280×720 YUV422 @ 30fps: 55.3 MB/s (需MJPEG压缩)
1280×720 MJPEG @ 30fps: ~5-10 MB/s (可行)
```

**ESP32-S3 使用 UVC 示例思路：**

```c
// ESP32-S3 UVC 接收流程
// 1. USB Host 初始化
usb_host_install(&config);

// 2. 枚举 UVC 设备
uvc_device_open(dev_addr);

// 3. 选择流参数（分辨率、帧率、格式）
uvc_stream_open_ctrl(dev_handle, &ctrl);
uvc_stream_start(stream_handle, callback);

// 4. 回调函数中获取帧数据
void frame_callback(uvc_frame_t *frame) {
    // frame->data 为 MJPEG 或 YUV 数据
    // frame->data_bytes 为数据长度
    process_frame(frame->data, frame->data_bytes);
}
```

### 2.4 全局快门 vs 卷帘快门

| 特性 | 全局快门（Global Shutter） | 卷帘快门（Rolling Shutter） |
|------|--------------------------|---------------------------|
| 曝光方式 | 所有像素同时曝光 | 逐行顺序曝光 |
| 运动畸变 | 无果冻效应 | 有果冻效应（运动物体倾斜） |
| 成本 | 较高 | 较低 |
| 典型传感器 | SC031GS, OV9281 | OV2640, OV5640 |
| 适用场景 | 高速运动、机器视觉 | 一般监控、拍照 |

**卷帘快门的果冻效应：**

```
正常静止:         运动中（水平移动的物体）:
┌────────┐        ┌────────┐
│ ████   │        │  ████  │  ← 第1行曝光
│ ████   │        │   ██   │  ← 物体已移动
│ ████   │        │        │  ← 第N行曝光
└────────┘        └────────┘
                  物体呈现倾斜
```

**全局快门的应用场景：**
- 条码/二维码扫描（手持移动）
- 机器视觉定位
- 高速运动物体测量
- 运动中的OCR识别

## 三、图像传感器

### 3.1 CMOS vs CCD

| 特性 | CMOS | CCD |
|------|------|-----|
| 功耗 | 低（3.3V/1.8V） | 高（12V+） |
| 成本 | 低 | 高 |
| 集成度 | 可集成ISP/ADC | 需外部电路 |
| 读出速度 | 快（随机访问） | 慢（串行移位） |
| 噪声 | 较高（固定模式噪声） | 较低 |
| 动态范围 | 中等 | 高 |
| 嵌入式适用 | 首选 | 极少使用 |

**CMOS 传感器工作原理：**

```
光子 → 光电二极管(电荷积累) → 行选择(读出) → ADC(模数转换) → 数字信号
  ↓
每像素自带放大器和ADC（有源像素传感器 APS）
```

### 3.2 常用嵌入式图像传感器

#### 3.2.1 OV2640

| 参数 | 规格 |
|------|------|

```c
// OV2640 SCCB 写寄存器
```

```
选型决策树:

分辨率需求?
├── QVGA/VGA 够用 → OV7725 (性价比) 或 SC031GS (需要全局快门)

├── 是 → SC031GS / OV9281 / AR0234

接口限制?
├── 只有DVP → OV2640 / OV7725
├── 有MIPI  → OV5640 / SC031GS
└── USB     → UVC免驱摄像头

功耗限制?
├── 极低功耗 → OV7725
└── 一般     → OV2640 / OV5640
```

## 四、图像预处理

### 4.1 灰度化

灰度化将彩色图像转换为灰度图像，是大多数图像处理算法的第一步。

**灰度化方法：**

| 方法 | 公式 | 特点 |
|------|------|------|
| 平均值法 | Gray = (R+G+B)/3 | 简单但不准确 |
| 加权法 | Gray = 0.299R+0.587G+0.114B | 最常用，符合人眼感知 |
| 最大值法 | Gray = max(R,G,B) | 偏亮 |
| 绿色通道 | Gray = G | 嵌入式快速近似 |

**嵌入式灰度化实现（RGB565 → Gray）：**

```c
// 方案1：查表法（快速）
// 预计算 R5(0~31) × 0.299 × 256/32 和 G6(0~63) × 0.587 × 256/64
// 以及 B5(0~31) × 0.114 × 256/32
static const uint16_t r_table[32]; // 预计算
static const uint16_t g_table[64];
static const uint16_t b_table[32];

uint8_t rgb565_to_gray_fast(uint16_t pixel) {
    uint8_t r = (pixel >> 11) & 0x1F;
    uint8_t g = (pixel >> 5) & 0x3F;
    uint8_t b = pixel & 0x1F;
    return (r_table[r] + g_table[g] + b_table[b]) >> 8;
}

// 方案2：快速近似（位运算）
uint8_t rgb565_to_gray_approx(uint16_t pixel) {
    uint8_t r = (pixel >> 11) & 0x1F;
    uint8_t g = (pixel >> 5) & 0x3F;
    uint8_t b = pixel & 0x1F;
    // (r*76 + g*150 + b*30) >> 8  近似于 0.299/0.587/0.114
    return (r * 76 + g * 150 + b * 30) >> 8;
}
```

```c
// Otsu 自适应阈值（大津法）
uint8_t otsu_threshold(uint8_t *gray, int total_pixels) {
    int hist[256] = {0};
    for (int i = 0; i < total_pixels; i++) hist[gray[i]]++;

    float sum = 0;
    for (int i = 0; i < 256; i++) sum += i * hist[i];

    float sumB = 0, wB = 0, wF = 0;
    float max_variance = 0;
    uint8_t best_threshold = 0;

    for (int t = 0; t < 256; t++) {
        wB += hist[t];
        if (wB == 0) continue;
        wF = total_pixels - wB;
        if (wF == 0) break;

        sumB += t * hist[t];
        float mB = sumB / wB;
        float mF = (sum - sumB) / wF;
        float variance = wB * wF * (mB - mF) * (mB - mF);

        if (variance > max_variance) {
            max_variance = variance;
            best_threshold = t;
        }
    }
    return best_threshold;
}
```

### 4.3 直方图均衡

直方图均衡增强图像对比度，使像素值分布更均匀。

```c
void histogram_equalize(uint8_t *gray, int width, int height) {
    int total = width * height;
    int hist[256] = {0};

    // 1. 计算直方图
    for (int i = 0; i < total; i++) hist[gray[i]]++;

    // 2. 计算累积分布函数（CDF）
    uint8_t lut[256];
    int cdf = 0, cdf_min = 0;
    for (int i = 0; i < 256; i++) {
        cdf += hist[i];
        if (cdf_min == 0 && cdf > 0) cdf_min = cdf;
        lut[i] = (uint8_t)(((cdf - cdf_min) * 255.0f /
                             (total - cdf_min)) + 0.5f);
    }

    // 3. 应用映射表
    for (int i = 0; i < total; i++) {
        gray[i] = lut[gray[i]];
    }
}
```

```c
// 裁剪直方图限制对比度增强幅度
void clahe_simple(uint8_t *gray, int width, int height,
                   int block_w, int block_h, float clip_limit) {
    int blocks_x = (width + block_w - 1) / block_w;
    int blocks_y = (height + block_h - 1) / block_h;

    for (int by = 0; by < blocks_y; by++) {
        for (int bx = 0; bx < blocks_x; bx++) {
            int x0 = bx * block_w;
            int y0 = by * block_h;
            int x1 = (x0 + block_w > width) ? width : x0 + block_w;
            int y1 = (y0 + block_h > height) ? height : y0 + block_h;

            // 计算局部直方图
            int hist[256] = {0};
            for (int y = y0; y < y1; y++)
                for (int x = x0; x < x1; x++)
                    hist[gray[y * width + x]]++;

            // 裁剪直方图
            int limit = (int)(clip_limit * (x1-x0) * (y1-y0) / 256);
            int excess = 0;
            for (int i = 0; i < 256; i++) {
                if (hist[i] > limit) {
                    excess += hist[i] - limit;
                    hist[i] = limit;
                }
            }
            // 重新分配超出的像素
            int avg_inc = excess / 256;
            for (int i = 0; i < 256; i++) hist[i] += avg_inc;

            // 累积分布 + 应用映射
            uint8_t lut[256];
            int area = (x1-x0) * (y1-y0);
            int cdf = 0, cdf_min = 0;
            for (int i = 0; i < 256; i++) {
                cdf += hist[i];
                if (cdf_min == 0 && cdf > 0) cdf_min = cdf;
                lut[i] = (uint8_t)(((cdf - cdf_min) * 255.0f /
                                     (area - cdf_min)) + 0.5f);
            }
            for (int y = y0; y < y1; y++)
                for (int x = x0; x < x1; x++)
                    gray[y * width + x] = lut[gray[y * width + x]];
        }
    }
}
```

```c
// 3x3 高斯核 (sigma≈1.0)
//  1 2 1
//  2 4 2   ÷ 16
//  1 2 1
void gaussian_filter_3x3(uint8_t *src, uint8_t *dst,
                          int width, int height) {
    for (int y = 1; y < height - 1; y++) {
        for (int x = 1; x < width - 1; x++) {
            int sum = src[(y-1)*width+(x-1)]   + 2*src[(y-1)*width+x]   + src[(y-1)*width+(x+1)]
                    + 2*src[y*width+(x-1)]      + 4*src[y*width+x]      + 2*src[y*width+(x+1)]
                    + src[(y+1)*width+(x-1)]    + 2*src[(y+1)*width+x]  + src[(y+1)*width+(x+1)];
            dst[y * width + x] = (sum + 8) >> 4; // +8 四舍五入
        }
    }
}

// 5x5 高斯核 (sigma≈1.4)
//  1  4  7  4  1
//  4 16 26 16  4
//  7 26 41 26  7   ÷ 273
//  4 16 26 16  4
//  1  4  7  4  1
```

```c
// 将2D卷积分解为两次1D卷积
// 3x3高斯: 先水平[1,2,1]/4，再垂直[1,2,1]^T/4
void gaussian_separable(uint8_t *src, uint8_t *tmp, uint8_t *dst,
                         int width, int height) {

    // 垂直方向
    for (int y = 1; y < height - 1; y++) {
        for (int x = 1; x < width - 1; x++) {
            dst[y*width+x] = (tmp[(y-1)*width+x] +
                              2*tmp[y*width+x] +
                              tmp[(y+1)*width+x]) >> 2;

    }
}
```

```c
// 3x3 中值滤波（排序法）
void median_filter_3x3(uint8_t *src, uint8_t *dst,
                        int width, int height) {
    for (int y = 1; y < height - 1; y++) {
        for (int x = 1; x < width - 1; x++) {
            uint8_t window[9];
            int idx = 0;
            for (int dy = -1; dy <= 1; dy++)
                for (int dx = -1; dx <= 1; dx++)
                    window[idx++] = src[(y+dy)*width+(x+dx)];

            // 9元素取中值（部分排序优化）
            // 插入排序找第5大即可
            for (int i = 1; i < 9; i++) {
                uint8_t key = window[i];
                int j = i - 1;
                while (j >= 0 && window[j] > key) {
                    window[j+1] = window[j];
                    j--;
                }
                window[j+1] = key;
            }
            dst[y * width + x] = window[4]; // 中值
        }
    }
}

// 优化: 直方图法中值滤波（适合大窗口）
// 维护一个滑动窗口直方图，O(1)更新每步
```

## 五、边缘检测

### 5.1 梯度计算

边缘是图像中灰度值剧烈变化的区域，通过梯度算子检测。

**梯度的数学定义：**

```
Gx = ∂I/∂x   (水平方向梯度)
Gy = ∂I/∂y   (垂直方向梯度)

梯度幅值: G = √(Gx² + Gy²)  或近似  |Gx| + |Gy|
梯度方向: θ = arctan(Gy / Gx)
```

### 5.2 Sobel 算子

**Sobel 卷积核：**

```
        Gx (水平)           Gy (垂直)
   -1  0  +1          -1  -2  -1
   -2  0  +2           0   0   0
   -1  0  +1          +1  +2  +1
```

**Sobel 实现：**

```c
void sobel_edge(uint8_t *gray, uint16_t *magnitude,
                 uint8_t *direction, int width, int height) {
    for (int y = 1; y < height - 1; y++) {
        for (int x = 1; x < width - 1; x++) {
            // Gx = 水平梯度（检测垂直边缘）
            int gx = -gray[(y-1)*width+(x-1)] + gray[(y-1)*width+(x+1)]
                     -2*gray[y*width+(x-1)] + 2*gray[y*width+(x+1)]
                     -gray[(y+1)*width+(x-1)] + gray[(y+1)*width+(x+1)];

            // Gy = 垂直梯度（检测水平边缘）
            int gy = -gray[(y-1)*width+(x-1)] - 2*gray[(y-1)*width+x] - gray[(y-1)*width+(x+1)]
                     +gray[(y+1)*width+(x-1)] + 2*gray[(y+1)*width+x] + gray[(y+1)*width+(x+1)];

            // 幅值（近似计算加速）
            int mag = abs(gx) + abs(gy);
            magnitude[y * width + x] = (mag > 65535) ? 65535 : mag;

            // 方向（0/45/90/135 四个方向量化）
            if (direction) {
                float angle = atan2f(gy, gx) * 180.0f / 3.14159f;
                if (angle < 0) angle += 180;
                if ((angle < 22.5) || (angle >= 157.5))
                    direction[y*width+x] = 0;   // 水平边缘
                else if (angle < 67.5)
                    direction[y*width+x] = 45;  // 45度边缘
                else if (angle < 112.5)
                    direction[y*width+x] = 90;  // 垂直边缘
                else
                    direction[y*width+x] = 135; // 135度边缘
            }
        }
    }
}
```

### 5.3 Canny 算子

Canny 边缘检测是最经典的边缘检测算法，包含四个步骤。

**Canny 算法流程：**

```
原图 → 高斯滤波 → Sobel梯度 → 非极大值抑制 → 双阈值检测 → 边缘连接
```

**完整 Canny 实现：**

```c
typedef struct {
    uint16_t low_threshold;
    uint16_t high_threshold;
} canny_params_t;

void canny_edge(uint8_t *gray, uint8_t *edge,
                int width, int height, canny_params_t *params) {
    int size = width * height;
    uint8_t *smoothed = malloc(size);
    uint16_t *magnitude = calloc(size, sizeof(uint16_t));
    uint8_t *direction = malloc(size);
    uint8_t *nms = malloc(size);

    // Step 1: 高斯滤波
    gaussian_filter_3x3(gray, smoothed, width, height);

    // Step 2: Sobel 梯度
    sobel_edge(smoothed, magnitude, direction, width, height);

    // Step 3: 非极大值抑制
    for (int y = 1; y < height - 1; y++) {
        for (int x = 1; x < width - 1; x++) {
            uint16_t mag = magnitude[y * width + x];
            uint8_t dir = direction[y * width + x];
            uint16_t m1, m2;

            if (dir == 0) {       // 水平边缘，比较上下
                m1 = magnitude[(y-1)*width+x];
                m2 = magnitude[(y+1)*width+x];
            } else if (dir == 45) { // 45度
                m1 = magnitude[(y-1)*width+(x+1)];
                m2 = magnitude[(y+1)*width+(x-1)];
            } else if (dir == 90) { // 垂直边缘，比较左右
                m1 = magnitude[y*width+(x-1)];
                m2 = magnitude[y*width+(x+1)];
            } else {              // 135度
                m1 = magnitude[(y-1)*width+(x-1)];
                m2 = magnitude[(y+1)*width+(x+1)];
            }
            // 只保留局部极大值
            nms[y*width+x] = (mag >= m1 && mag >= m2) ? mag : 0;
        }
    }

    // Step 4: 双阈值 + 边缘连接
    uint8_t STRONG = 255, WEAK = 128;
    for (int i = 0; i < size; i++) {
        if (nms[i] >= params->high_threshold) edge[i] = STRONG;
        else if (nms[i] >= params->low_threshold) edge[i] = WEAK;
        else edge[i] = 0;
    }

    // 弱边缘连接：弱边缘与强边缘8连通则保留
    for (int y = 1; y < height - 1; y++) {
        for (int x = 1; x < width - 1; x++) {
            if (edge[y*width+x] == WEAK) {
                bool connected = false;
                for (int dy = -1; dy <= 1 && !connected; dy++)
                    for (int dx = -1; dx <= 1 && !connected; dx++)
                        if (edge[(y+dy)*width+(x+dx)] == STRONG)
                            connected = true;
                edge[y*width+x] = connected ? STRONG : 0;
            }
        }
    }

    free(smoothed); free(magnitude);
    free(direction); free(nms);
}
```

### 6.3 模板匹配

模板匹配在目标图像中搜索与模板最相似的区域。

```c
// 平方差匹配（SQDIFF）
void template_match_sqdiff(uint8_t *image, int iw, int ih,
                            uint8_t *templ, int tw, int th,
                            float *result) {
    for (int y = 0; y <= ih - th; y++) {
        for (int x = 0; x <= iw - tw; x++) {
            float ssd = 0;
            for (int ty = 0; ty < th; ty++) {
                for (int tx = 0; tx < tw; tx++) {
                    float diff = image[(y+ty)*iw+(x+tx)]
                               - templ[ty*tw+tx];
                    ssd += diff * diff;
                }
            }
            result[y * (iw-tw+1) + x] = ssd;
        }
    }
}

// 归一化互相关匹配（NCC）- 光照不变
float template_match_ncc(uint8_t *image, int iw, int ih,
                          int x0, int y0,
                          uint8_t *templ, int tw, int th) {
    // 计算模板均值和标准差
    float t_mean = 0, t_std = 0;
    for (int i = 0; i < tw*th; i++) t_mean += templ[i];
    t_mean /= tw * th;
    for (int i = 0; i < tw*th; i++) {
        float d = templ[i] - t_mean;
        t_std += d * d;
    }
    t_std = sqrtf(t_std);

    // 计算图像区域均值和标准差
    float i_mean = 0, i_std = 0;
    for (int ty = 0; ty < th; ty++)
        for (int tx = 0; tx < tw; tx++)
            i_mean += image[(y0+ty)*iw+(x0+tx)];
    i_mean /= tw * th;
    for (int ty = 0; ty < th; ty++)
        for (int tx = 0; tx < tw; tx++) {
            float d = image[(y0+ty)*iw+(x0+tx)] - i_mean;
            i_std += d * d;
        }
    i_std = sqrtf(i_std);

    // 计算互相关
    float ncc = 0;
    for (int ty = 0; ty < th; ty++)
        for (int tx = 0; tx < tw; tx++)
            ncc += (image[(y0+ty)*iw+(x0+tx)] - i_mean) *
                   (templ[ty*tw+tx] - t_mean);

    return ncc / (t_std * i_std + 1e-6f);
}
```

### 6.4 Haar 特征

Haar 特征是 Viola-Jones 人脸检测的核心，通过矩形区域像素和的差值描述图像特征。

**Haar 特征类型：**

```
类型1（边缘）:     类型2（线）:      类型3（对角）:
┌────┬────┐      ┌────────┐      ┌────┬────┐
│白  │黑  │      │  白    │      │白  │黑  │
├────┼────┤      ├────────┤      ├────┼────┤
│    │    │      │  黑    │      │黑  │白  │
└────┴────┘      ├────────┤      └────┴────┘
                 │  白    │
  特征=黑-白     └────────┘
                 特征=白-黑+白
```

**积分图加速 Haar 特征计算：**

```c
// 积分图: sat[y][x] = sum of all pixels in rect (0,0) to (x,y)
void build_integral_image(uint8_t *gray, uint32_t *integral,
                           int width, int height) {
    for (int y = 0; y < height; y++) {
        uint32_t row_sum = 0;
        for (int x = 0; x < width; x++) {
            row_sum += gray[y * width + x];
            integral[y * width + x] = row_sum +
                (y > 0 ? integral[(y-1) * width + x] : 0);
        }
    }
}

// 利用积分图快速计算任意矩形区域像素和
// rect_sum = sat[y2][x2] - sat[y1-1][x2] - sat[y2][x1-1] + sat[y1-1][x1-1]
static inline uint32_t rect_sum(uint32_t *integral, int width,
                                 int x1, int y1, int x2, int y2) {
    uint32_t sum = integral[y2 * width + x2];
    if (y1 > 0) sum -= integral[(y1-1) * width + x2];
    if (x1 > 0) sum -= integral[y2 * width + (x1-1)];
    if (x1 > 0 && y1 > 0) sum += integral[(y1-1) * width + (x1-1)];
    return sum;
}

// 计算一个 Haar 特征值
float haar_feature(uint32_t *integral, int width,
                    int x, int y, int w, int h) {
    // 边缘特征: 左白右黑
    int half_w = w / 2;
    uint32_t white = rect_sum(integral, width, x, y, x+half_w-1, y+h-1);
    uint32_t black = rect_sum(integral, width, x+half_w, y, x+w-1, y+h-1);
    return (float)black - (float)white;
}
```

```c
typedef struct {
    float x, y, w, h;  // 边界框
    float confidence;    // 置信度
    int class_id;       // 类别
    float class_prob;   // 类别概率
} detection_t;

// NMS 非极大值抑制
void nms(detection_t *dets, int num_dets, float iou_threshold) {
    // 按 confidence 降序排序
    for (int i = 0; i < num_dets; i++) {
        if (dets[i].confidence == 0) continue;
        for (int j = i + 1; j < num_dets; j++) {
            if (dets[j].confidence == 0) continue;
            float iou = calc_iou(&dets[i], &dets[j]);
            if (iou > iou_threshold) {
                dets[j].confidence = 0; // 抑制
            }
        }
    }
}

// IoU 计算
float calc_iou(detection_t *a, detection_t *b) {
    float x1 = fmax(a->x - a->w/2, b->x - b->w/2);
    float y1 = fmax(a->y - a->h/2, b->y - b->h/2);
    float x2 = fmin(a->x + a->w/2, b->x + b->w/2);
    float y2 = fmin(a->y + a->h/2, b->y + b->h/2);

    float inter = fmax(0, x2-x1) * fmax(0, y2-y1);
    float union_area = a->w*a->h + b->w*b->h - inter;
    return inter / (union_area + 1e-6f);
}
```

#### 9.1.2 JPEG 解码

```c
// 使用 libjpeg-turbo 解码（适合有足够 RAM 的 MCU）
#include "jpeglib.h"

int jpeg_decode(uint8_t *jpeg_data, int jpeg_len,
                uint8_t *rgb_output, int *width, int *height) {
    struct jpeg_decompress_struct cinfo;
    struct jpeg_error_mgr jerr;

    cinfo.err = jpeg_std_error(&jerr);
    jpeg_create_decompress(&cinfo);
    jpeg_mem_src(&cinfo, jpeg_data, jpeg_len);
    jpeg_read_header(&cinfo, TRUE);
    jpeg_start_decompress(&cinfo);

    *width = cinfo.output_width;
    *height = cinfo.output_height;

    while (cinfo.output_scanline < cinfo.output_height) {
        uint8_t *row = rgb_output + cinfo.output_scanline * (*width) * 3;
        jpeg_read_scanlines(&cinfo, &row, 1);
    }

    jpeg_finish_decompress(&cinfo);
    jpeg_destroy_decompress(&cinfo);
    return 0;
}
```

```c
// 垂直投影法分割字符
int segment_chars(uint8_t *plate, int pw, int ph,
                   int *char_x, int *char_w) {
    // 1. 计算每列白色像素数（垂直投影）
    int *projection = calloc(pw, sizeof(int));
    for (int x = 0; x < pw; x++)
        for (int y = 0; y < ph; y++)
            if (plate[y * pw + x]) projection[x]++;

    // 2. 寻找投影谷底（字符间隙）
    int chars = 0;
    bool in_char = false;
    for (int x = 0; x < pw; x++) {
        if (projection[x] > 3 && !in_char) {
            char_x[chars] = x;
            in_char = true;
        } else if (projection[x] <= 3 && in_char) {
            char_w[chars] = x - char_x[chars];
            chars++;
            in_char = false;
        }
    }
    free(projection);
    return chars;
}
```

### 11.1 DMA 传输

DMA 是嵌入式图像处理最重要的性能优化手段，让 CPU 在数据传输时可以做其他计算。

**DMA 在图像处理中的应用场景：**

| 应用 | 说明 |
|------|------|
| 摄像头采集 → RAM | DCMI + DMA 接收帧数据 |
| RAM → SPI 屏幕 | SPI + DMA 发送显示数据 |
| 图像处理 → JPEG | DMA2D (ChromArt) 硬件加速 |
| ADC 采样 | 高速模拟信号数字化 |

**STM32 DMA 摄像头接收示例：**

```c

    DMA_Handle.Init.FIFOMode = DMA_FIFOMODE_ENABLE;
```

### 11.3 ROI 裁剪

ROI（Region of Interest）裁剪只处理感兴趣区域，大幅减少计算量。

```c
// ROI 裁剪：只处理图像中的某个矩形区域
typedef struct {
    int x, y, w, h;
} roi_t;

// 只在ROI区域内进行边缘检测
void sobel_roi(uint8_t *gray, uint16_t *magnitude,
               int img_w, int img_h, roi_t *roi) {
    int x1 = roi->x + 1;
    int y1 = roi->y + 1;
    int x2 = roi->x + roi->w - 1;
    int y2 = roi->y + roi->h - 1;

    for (int y = y1; y < y2; y++) {
        for (int x = x1; x < x2; x++) {
            int gx = -gray[(y-1)*img_w+(x-1)] + gray[(y-1)*img_w+(x+1)]
                     -2*gray[y*img_w+(x-1)] + 2*gray[y*img_w+(x+1)]
                     -gray[(y+1)*img_w+(x-1)] + gray[(y+1)*img_w+(x+1)];
            int gy = -gray[(y-1)*img_w+(x-1)] - 2*gray[(y-1)*img_w+x] - gray[(y-1)*img_w+(x+1)]
                     +gray[(y+1)*img_w+(x-1)] + 2*gray[(y+1)*img_w+x] + gray[(y+1)*img_w+(x+1)];
            magnitude[y * img_w + x] = abs(gx) + abs(gy);
        }
    }
}

// 计算ROI处理相比全图的加速比
// 若全图 640×480 = 307200 像素，ROI 100×100 = 10000 像素
// 加速比 = 307200 / 10000 ≈ 30x
```

### 11.4 降低分辨率策略

```c
// 方案1: 跳采样（最快，但有锯齿）
void downsample_skip(uint8_t *src, uint8_t *dst,
                     int sw, int sh, int factor) {
    int dw = sw / factor, dh = sh / factor;
    for (int y = 0; y < dh; y++)
        for (int x = 0; x < dw; x++)
            dst[y*dw+x] = src[(y*factor)*sw+(x*factor)];
}

// 方案2: 均值下采样（质量好）
void downsample_avg(uint8_t *src, uint8_t *dst,
                    int sw, int sh, int factor) {
    int dw = sw / factor, dh = sh / factor;
    for (int y = 0; y < dh; y++) {
        for (int x = 0; x < dw; x++) {
            int sum = 0;
            for (int dy = 0; dy < factor; dy++)
                for (int dx = 0; dx < factor; dx++)
                    sum += src[(y*factor+dy)*sw+(x*factor+dx)];
            dst[y*dw+x] = sum / (factor * factor);
        }
    }
}

// 方案3: 2x2 均值下采样（特化优化版）
void downsample_2x(uint8_t *src, uint8_t *dst, int sw, int sh) {
    int dw = sw / 2, dh = sh / 2;
    for (int y = 0; y < dh; y++) {
        uint8_t *row0 = src + (y*2) * sw;
        uint8_t *row1 = row0 + sw;
        uint8_t *dst_row = dst + y * dw;
        for (int x = 0; x < dw; x++) {
            dst_row[x] = (row0[x*2] + row0[x*2+1] +
                          row1[x*2] + row1[x*2+1]) >> 2;
        }
    }
}
```

### 11.6 内存优化策略

**嵌入式图像处理内存预算示例（QVGA灰度）：**

```
输入缓冲: 320 × 240 × 1 = 76.8 KB
输出缓冲: 320 × 240 × 1 = 76.8 KB
中间缓冲: 320 × 240 × 1 = 76.8 KB（可复用）
积分图:   320 × 240 × 4 = 307.2 KB
──────────────────────────────
总计:     ≈ 537 KB

优化后:
使用单缓冲+原地处理: 76.8 × 2 = 153.6 KB
放弃积分图（或ROI积分图）: 节省 307 KB
```

**原地处理技巧：**

```c
// 在原图上直接做处理，避免额外缓冲
void binarize_inplace(uint8_t *data, int size, uint8_t threshold) {
    for (int i = 0; i < size; i++) {
        data[i] = (data[i] > threshold) ? 255 : 0;
    }
}
```
