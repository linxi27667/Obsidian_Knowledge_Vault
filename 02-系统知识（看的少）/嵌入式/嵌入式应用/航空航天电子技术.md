# 航空航天电子技术

> 航空航天电子系统综合笔记，涵盖航电架构、通信总线、飞控系统、航天级器件、卫星通信、无人机飞控、电源系统、测试验证及可靠性设计。

---

## 一、航空航天电子概述

### 1.1 航电系统架构

航电系统（Avionics）是飞行器上所有电子设备的总称，负责飞行控制、导航、通信、监视和任务管理。

**IMA（综合模块化航电）架构：**
- 核心思想：将多个独立LRU（线性可更换单元）合并为少量通用计算模块
- 采用分区隔离（Partition）技术，不同安全等级的应用运行在同一硬件上
- 典型代表：ARINC 653标准定义的APEX接口
- 波音787、空客A350均采用IMA架构

**传统联合式架构 vs IMA：**

| 特性 | 联合式架构 | IMA架构 |
|------|-----------|---------|
| 硬件数量 | 多个专用LRU | 少量通用模块 |
| 资源利用率 | 低 | 高 |
| 可扩展性 | 差 | 好 |
| 认证复杂度 | 单设备独立认证 | 分区隔离+平台认证 |
| 典型应用 | 老旧机型 | B787/A350/C919 |

**ARINC 653 分区调度：**
- 时间分区：固定时间窗口轮转调度
- 空间分区：内存保护隔离
- 健康监控：分区故障不影响其他分区
- 调度表（Major Frame）定义各分区的执行顺序和时间槽

### 1.2 DO-254 硬件设计保证标准

DO-254（Design Assurance Guidance for Airborne Electronic Hardware）是机载电子硬件的设计保证标准。

**适用范围：**
- FPGA、CPLD、ASIC等可编程逻辑器件
- 定制集成电路
- 不适用于商用货架产品（COTS）

**设计保证等级（DAL）：**

| 等级 | 失效影响 | 说明 |
|------|---------|------|
| A级 | 灾难性 | 导致飞机损失 |
| B级 | 危险 | 严重影响安全 |
| C级 | 重大 | 降低安全裕度 |
| D级 | 轻微 | 不影响安全 |
| E级 | 无影响 | 无安全效应 |

**DO-254设计流程：**
1. **计划过程**：PHAC（计划硬件认证）、确认与验证计划
2. **设计过程**：需求获取 → 概念设计 → 详细设计 → 实现
3. **验证过程**：需求验证、设计验证、实现验证
4. **生产过程**：制造保证、配置管理
5. **支持过程**：过程保证、确认

**关键验证活动：**
- 需求覆盖率分析（Requirements Coverage）
- 代码/设计审查（Peer Review）
- 仿真验证（Functional Simulation）
- 时序分析（Timing Analysis）
- 测试覆盖率分析

### 1.3 DO-178C 软件设计保证标准

DO-178C（Software Considerations in Airborne Systems and Equipment Certification）是机载软件的适航标准。

**软件等级（DAL）：**

| 等级 | 失效条件 | 目标数 | 典型应用 |
|------|---------|--------|---------|
| A | 灾难性 | 71 | 飞控主计算机 |
| B | 危害 | 69 | 自动驾驶仪 |
| C | 重大 | 62 | 飞行管理 |
| D | 轻微 | 26 | 客舱娱乐 |
| E | 无影响 | 0 | 无安全相关 |

**DO-178C 核心目标：**
- 高等级（A/B）：MC/DC（修正条件/判定覆盖）测试
- 中等级（C）：判定覆盖（Decision Coverage）
- 低等级（D/E）：语句覆盖（Statement Coverage）

**DO-330 工具鉴定：**
- TQL-1至TQL-5工具鉴定等级
- 自动代码生成工具需进行鉴定
- 静态分析工具需满足相应TQL

**与DO-254的协同：**
- 软硬件接口需求（SWHIRS）
- 硬件/软件集成测试（HSIT）
- 系统级验证需两者共同覆盖

## 二、航空通信总线

### 2.1 ARINC 429 总线

ARINC 429是商用航空最广泛使用的数据总线标准。

**基本特性：**
- 传输方式：单向广播（一个发送器，最多20个接收器）
- 物理层：双绞线差分信号
- 传输速率：高速100 kbps / 低速12.5 kbps
- 编码方式：双极性归零码（Bipolar RZ）
- 信号电平：+10V（高）、-10V（低）、0V（零）

**32位字格式：**

| 位域 | 位号 | 说明 |
|------|------|------|
| 标号（Label） | 1-8 | 消息类型标识 |
| SDI | 9-10 | 源/目标标识符 |
| 数据 | 11-29 | 有效数据（19位） |
| SSM | 30-31 | 符号/状态矩阵 |
| 奇偶校验 | 32 | 奇校验位 |

**常见Label定义：**
- Label 021：气压高度
- Label 032：指示空速
- Label 110：磁航向
- Label 203：GPS纬度
- Label 204：GPS经度
- Label 260：UTC时间

**ARINC 429优缺点：**
- 优点：简单可靠、EMC性能好、成本低
- 缺点：单向传输、速率低、点对点布线复杂

### 2.2 MIL-STD-1553B 总线

MIL-STD-1553B是军用航空标准数据总线。

**基本特性：**
- 传输方式：半双工、命令/响应式
- 物理层：屏蔽双绞线、变压器耦合
- 传输速率：1 Mbps
- 拓扑结构：冗余双总线
- 最多终端数：31个远程终端（RT）

**总线角色：**
- **BC（总线控制器）**：发起通信，管理总线
- **RT（远程终端）**：响应BC命令
- **BM（总线监视器）**：被动监听记录

**消息格式：**
```
命令字 → 数据字(最多32个) → 状态字
| 同步 | RT地址 | T/R | 子地址 | 字数 | 奇偶 |
```

**1553B vs ARINC 429：**

| 特性 | 1553B | ARINC 429 |
|------|-------|-----------|
| 传输方向 | 双向 | 单向 |
| 速率 | 1 Mbps | 12.5/100 kbps |
| 拓扑 | 共享总线 | 点对点 |
| 协议 | 命令/响应 | 广播 |
| 应用领域 | 军用 | 民用 |
| 冗余 | 双总线 | 手动切换 |

**1553B协议芯片：**
- BU-61580（DDC）：内置RAM的终端芯片
- HI-6130（Holt）：低功耗收发器
- EF4465（恩智浦）：集成BC/RT/BM

### 2.3 AFDX 航空电子全双工交换以太网

AFDX（Avionics Full-Duplex Switched Ethernet）基于以太网的航空数据网络标准。

**技术基础：**
- 基于IEEE 802.3以太网
- 全双工交换式网络
- 确定性通信保障
- 标准：ARINC 664 Part 7

**核心概念：**
- **VL（虚拟链路）**：逻辑通信通道，具有固定带宽分配
- **BAG（带宽分配间隔）**：VL的最小发送间隔（0.5ms ~ 128ms）
- **帧大小**：最大1518字节（以太网帧）
- **网络冗余**：双独立网络（A/B）

**AFDX vs 传统以太网：**

| 特性 | AFDX | 标准以太网 |
|------|------|-----------|
| 确定性 | 是 | 否 |
| 冗余 | 双网络 | 单网络 |
| 流量控制 | VL限速 | 无保证 |
| 延迟 | 有界 | 无界 |
| 应用 | 航空 | 通用 |

**AFDX交换机功能：**
- 帧过滤与转发
- VL带宽监管
- 冗余管理（SN序列号）
- 冗余帧消除

**典型应用：**
- 空客A380：首架采用AFDX的飞机
- 空客A350：全机AFDX骨干网
- 波音787：部分航电网络采用AFDX

## 三、飞行控制系统

### 3.1 飞控计算机

飞控计算机（Flight Control Computer, FCC）是飞行控制的核心。

**功能：**
- 采集传感器数据（角速率、加速度、气压、GPS）
- 执行控制律计算（PID、自适应、鲁棒控制）
- 输出舵面指令（升降舵、副翼、方向舵）
- 故障检测与系统重构

**冗余架构：**
- 三余度：三套计算机表决（2oo3）
- 四余度：四套计算机表决（2oo4），可容忍单故障
- 非相似余度：不同硬件/软件实现相同功能（如A320的ELAC/SEC/FAC）

**A320飞控计算机体系：**
- ELAC（升降舵副翼计算机）：主飞控
- SEC（扰流板升降舵计算机）：备份飞控
- FAC（飞行增稳计算机）：偏航阻尼
- PRIM/SEC架构在A350上进一步演进

**飞控律设计要素：**
- 增益调度（Gain Scheduling）：随飞行状态调整参数
- 过载保护（Load Factor Limiting）
- 迎角保护（Alpha Protection）
- 偏航阻尼（Yaw Damper）
- 自动配平（Auto Trim）

### 3.2 惯性导航系统（INS）

惯性导航利用陀螺仪和加速度计进行自主导航。

**基本原理：**
- 测量载体的角速率和比力
- 通过积分得到姿态、速度、位置
- 不依赖外部信号，完全自主

**惯性传感器类型：**

| 类型 | 精度 | 成本 | 应用 |
|------|------|------|------|
| 机械陀螺 | 高 | 高 | 战略级 |
| 激光陀螺（RLG） | 高 | 中高 | 航空级 |
| 光纤陀螺（FOG） | 中高 | 中 | 航空/航海 |
| MEMS陀螺 | 低 | 低 | 消费/无人机 |

**INS误差模型：**
- 陀螺零偏（Bias）：导致姿态漂移
- 加速度计零偏：导致速度误差
- 刻度因子误差：标度不准
- 安装误差（Misalignment）
- 位置误差随时间二次增长

**初始对准：**
- 静基座对准：利用重力矢量和地球自转
- 动基座对准：利用GPS辅助
- 粗对准（5分钟）+ 精对准（10-15分钟）

### 3.3 GPS/GNSS 导航

**GPS系统组成：**
- 空间段：24+颗卫星，6个轨道面
- 地面段：主控站、监测站、注入站
- 用户段：GPS接收机

**GPS信号：**
- L1（1575.42 MHz）：C/A码、P(Y)码
- L2（1227.60 MHz）：P(Y)码、L2C
- L5（1176.45 MHz）：民用安全生命信号

**定位精度：**
- 标准定位服务（SPS）：水平3-5m
- 精密定位服务（PPS）：水平1-3m
- DGPS差分：亚米级
- RTK：厘米级

**多星座导航：**
- GPS（美国）、GLONASS（俄罗斯）
- BeiDou（中国）、Galileo（欧洲）
- 多星座融合提高可用性和精度

**GPS完好性监测：**
- RAIM（接收机自主完好性监测）
- SBAS星基增强（WAAS/EGNOS/MSAS）
- GBAS地基增强

### 3.4 传感器融合

**融合目的：**
- 单一传感器均有局限性
- INS短期精度高但长期漂移
- GPS长期稳定但动态性能差
- 融合可取长补短

**卡尔曼滤波（KF）：**
- 线性系统最优估计
- 状态预测 + 量测更新
- 协方差矩阵传播
- 状态：位置、速度、姿态、传感器误差

**扩展卡尔曼滤波（EKF）：**
- 处理非线性系统
- 一阶泰勒展开线性化
- INS/GPS融合的标准算法
- 状态向量通常15-21维

**EKF状态向量（15维示例）：**
```
x = [φ, λ, h,       // 位置（纬度、经度、高度）
     Vn, Ve, Vd,     // 速度（北、东、地）
     φ, θ, ψ,        // 姿态（滚转、俯仰、偏航）
     εbx, εby, εbz,  // 陀螺零偏
     Δax, Δay, Δaz]  // 加速度计零偏
```

**融合架构：**
- 松耦合：GPS位置/速度作为量测量
- 紧耦合：GPS伪距/伪距率作为量测量
- 深耦合：GPS接收机环路与INS深度集成

## 四、航天级器件与抗辐射设计

### 4.1 抗辐射设计基础

**空间辐射环境：**
- 地球辐射带（Van Allen带）：质子、电子
- 太阳宇宙线：太阳耀斑期间增强
- 银河宇宙线：高能重离子
- 南大西洋异常区（SAA）：辐射增强区

**辐射效应类型：**

| 效应 | 缩写 | 特征 | 影响 |
|------|------|------|------|
| 单粒子效应 | SEE | 单个粒子引起 | 瞬态或永久 |
| 单粒子翻转 | SEU | 位翻转 | 可恢复 |
| 单粒子锁定 | SEL | 闩锁效应 | 需断电恢复 |
| 单粒子烧毁 | SEB | 功率器件损坏 | 永久损坏 |
| 单粒子栅穿 | SEGR | 栅氧化层击穿 | 永久损坏 |
| 总剂量效应 | TID | 累积损伤 | 性能退化 |
| 位移损伤 | DD | 晶格缺陷 | 性能退化 |

**抗辐射加固手段：**
- 工艺加固：SOI、SOS工艺
- 设计加固：TMR、EDAC、电流限幅
- 屏蔽加固：铝、钽屏蔽层
- 系统级加固：冗余、看门狗、EDAC

### 4.2 三模冗余（TMR）

**基本原理：**
```
模块A ──→ ┐
模块B ──→ ├── 表决器 ──→ 输出
模块C ──→ ┘
```

- 三个相同模块并行执行
- 表决器取多数结果
- 可容忍单模块故障

**TMR实现形式：**
- 硬件TMR：三套物理硬件
- 时间TMR：同一硬件执行三次
- 信息TMR：数据三份存储

**FPGA中的TMR：**
- 每个寄存器复制三份
- 组合逻辑三份独立实现
- 表决逻辑在输出端
- Xilinx TMRTool自动生成

**TMR的局限：**
- 面积/功耗增加约3倍
- 共因故障无法防护
- 表决器本身是单点故障
- 需配合 scrubbing（配置刷新）

### 4.3 EDAC 纠错编码

**常用EDAC编码：**

| 编码 | 纠错能力 | 检错能力 | 开销 |
|------|---------|---------|------|
| 奇偶校验 | 0位 | 1位 | 1 bit/byte |
| SEC-DED | 1位 | 2位 | 5-8 bit/byte |
| SEC-DED-DAEC | 1位+邻位 | 2位 | 8 bit/byte |
| Reed-Solomon | 多位 | 多位 | 可配置 |

**SEC-DED汉明码：**
- 检测并纠正单位错
- 检测双位错（不纠正）
- 用于SRAM、SDRAM存储保护
- 典型：8位数据 → 13位编码（8+5校验位）

**内存Scrubbing：**
- 周期性读取并纠正内存
- 防止单粒子翻转累积
- 悄悄进行，不影响正常访问
- 典型周期：几秒到几分钟

### 4.4 FPGA在航天中的应用

**航天FPGA选型：**

| 厂商 | 型号 | 工艺 | 抗辐射 | 应用 |
|------|------|------|--------|------|
| Xilinx | XQRKU060 | 20nm | TMR+加固 | 高性能载荷 |
| Xilinx | XQR2V3000 | 130nm | 抗辐射 | 传统星载 |
| Microsemi | RTG4 | 65nm | SEE免疫 | 高可靠 |
| 国产 | 紫光PGT系列 | 28nm | 抗辐射 | 国产化 |

**FPGA配置刷新（Scrubbing）：**
- SEU导致配置存储器位翻转
- 周期性重写配置数据
- 不影响用户设计运行
- Xilinx ICAP接口支持在线刷新

**FPGA设计加固实践：**
- 寄存器TMR + 三模冗余
- 避免使用BRAM（改用EDAC保护的SRAM）
- 避免使用DLL/PLL（使用外部时钟）
- 配置存储器周期性刷新
- 输出IO增加限流保护

## 五、卫星通信

### 5.1 星载电子系统

**星载电子系统组成：**
- **星务管理**：OBC（星载计算机）、遥测遥控
- **姿轨控**：反作用轮、磁力矩器、推力器
- **电源系统**：太阳电池阵、蓄电池、功率调节
- **载荷**：通信转发器、遥感相机等
- **热控**：加热器、热管、多层隔热

**星载计算机特点：**
- 抗辐射处理器（LEON系列、ARM抗辐射版）
- EDAC保护内存
- 看门狗定时器
- 双机冷/热备份
- 固件可上注更新

**遥测遥控（TM/TC）：**
- TM（遥测）：下行卫星状态数据
- TC（遥控）：上行指令注入
- 采用CCSDS标准分包协议
- 加密与认证保护

### 5.2 地面站系统

**地面站功能：**
- 卫星跟踪（TT&C测控）
- 数据接收（遥感下行）
- 指令注入（遥控上行）
- 数据处理与分发

**主要设备：**
- 大口径天线（S/X/Ka波段）
- 高功率放大器（HPA）
- 低噪声放大器（LNA）
- 上/下变频器
- 基带调制解调器

### 5.3 链路预算

**链路预算方程：**
```
接收功率 = EIRP + Gr - L大气 - L雨衰 - L自由空间 - L极化失配

其中：
EIRP = Pt + Gt  （等效全向辐射功率）
Gr = 接收天线增益
L自由空间 = 20log(4πd/λ)  （自由空间损耗）
```

**关键参数：**
- EIRP：发射功率 + 发射天线增益 (dBW)
- G/T：接收系统品质因子 (dB/K)
- C/N：载噪比 (dB)
- Eb/N0：每比特能量与噪声密度比

**链路余量（Link Margin）：**
- 通常要求3-6 dB余量
- 需考虑雨衰、大气衰减、指向误差
- Ka波段雨衰显著高于C/S波段

### 5.4 调制与编码方式

**常用调制方式：**

| 调制 | 频谱效率 | 功率效率 | 应用 |
|------|---------|---------|------|
| BPSK | 1 bit/s/Hz | 高 | 深空通信 |
| QPSK | 2 bit/s/Hz | 中高 | 中继卫星 |
| 8PSK | 3 bit/s/Hz | 中 | 高通量卫星 |
| 16APSK | 4 bit/s/Hz | 中 | DVB-S2X |
| 64APSK | 6 bit/s/Hz | 低 | 高速数据 |

**前向纠错编码（FEC）：**
- 卷积码 + 维特比译码：经典方案
- Turbo码：接近香农限，CCSDS标准
- LDPC码：DVB-S2标准，性能优异
- RS码（Reed-Solomon）：外码，纠正突发错

**CCSDS编码标准：**
- TM下行：RS + 卷积码级联
- TC上行：BCH码
- 深空：Turbo码（码率1/6, 1/4, 1/3, 1/2）

## 六、无人机飞控系统

### 6.1 PID 控制

**PID控制器基本形式：**
```
u(t) = Kp * e(t) + Ki * ∫e(t)dt + Kd * de(t)/dt

其中：
Kp：比例增益（快速响应）
Ki：积分增益（消除稳态误差）
Kd：微分增益（抑制超调）
```

**PID参数整定：**
- Ziegler-Nichols法：临界增益法
- Cohen-Coon法：过程响应曲线法
- 手动整定：先P后I再D
- 自动整定：继电反馈法

**级联PID控制：**
```
外环（角度环）: 目标角度 → PID → 角速率指令
                     ↓
内环（速率环）: 角速率指令 → PID → 电机输出
```

- 外环带宽低，内环带宽高（5-10倍）
- 内环快速响应扰动
- 外环提供位置/姿态跟踪

**积分抗饱和（Anti-Windup）：**
- 积分项在执行器饱和时停止累积
- 条件积分：误差在一定范围内才积分
- 积分限幅：限制积分项最大值

### 6.2 姿态估计

**四元数 vs 欧拉角：**
- 欧拉角：直观但存在万向锁
- 四元数：4个参数表示姿态，无万向锁
- 旋转矩阵：9个参数，计算量大

**Mahony互补滤波：**
```
1. 加速度计估计重力方向 → 修正角速率
2. 磁力计估计北方向 → 修正偏航
3. 陀螺积分 → 短期姿态
4. 互补融合：高通陀螺 + 低通加速度计/磁力计
```

**Madgwick滤波器：**
- 基于梯度下降的四元数估计
- 计算量小，适合嵌入式
- 可调参数β控制收敛速度
- 开源实现广泛使用

**EKF姿态估计：**
- 状态：四元数 + 陀螺零偏
- 量测：加速度计、磁力计
- 可融合GPS辅助
- 精度最高，计算量最大

### 6.3 航点导航

**航点（Waypoint）定义：**
- 经纬度坐标
- 高度
- 速度
- 到达半径（Acceptance Radius）

**导航算法：**
- 航线跟踪：计算偏航距，PD修正航向
- 直线跟踪：向量投影法计算侧偏距
- 转弯衔接：Fly-over / Fly-by模式

**航线跟踪控制律：**
```
航向误差 = arctan2(目标经度-当前经度, 目标纬度-当前纬度)
侧偏距 = 当前位置到航线的垂直距离
航向修正 = 航向误差 + Kp * 侧偏距 + Kd * d(侧偏距)/dt
```

**RTL（返航）逻辑：**
- 遥控器失联 → 记录返航点
- 电量不足 → 触发返航
- 按设定高度和速度飞回起降点
- 到达后自动降落或悬停

### 6.4 MAVLink 协议

MAVLink（Micro Air Vehicle Link）是无人机通信协议标准。

**基本特性：**
- 轻量级消息协议
- 支持多种传输层（串口、UDP、TCP）
- 开源，广泛支持
- 版本：MAVLink v1（6字节头）/ v2（10字节头）

**消息结构（v2）：**
```
STX(1) | LEN(1) | INC(1) | COMP(1) | MSG(1) | SYS(1) | COMP(1) | PAYLOAD(0-255) | CRC(2) | SIG(13)
```

**常用消息：**
- `HEARTBEAT`（#0）：心跳，系统状态
- `ATTITUDE`（#30）：姿态角
- `GPS_RAW_INT`（#24）：GPS原始数据
- `RC_CHANNELS`（#65）：遥控通道值
- `COMMAND_LONG`（#76）：长指令
- `MISSION_ITEM`（#39）：航点任务项

**MAVLink命令示例：**
```
起飞：COMMAND_LONG { command=MAV_CMD_NAV_TAKEOFF, param7=高度 }
航点：MISSION_ITEM { seq, lat, lon, alt, speed }
返航：COMMAND_LONG { command=MAV_CMD_NAV_RETURN_TO_LAUNCH }
模式切换：COMMAND_LONG { command=MAV_CMD_DO_SET_MODE, param1=模式 }
```

**地面站软件：**
- Mission Planner（Windows）
- QGroundControl（跨平台）
- APM Planner 2
- DroidPlanner（Android）

## 七、航空电源系统

### 7.1 航空电源标准

**28VDC系统：**
- 适用于小型飞机、直升机
- 发电机输出28VDC
- 蓄电池备份（24V铅酸/锂电池）
- 优点：简单、轻便
- 大型飞机中用于应急电源

**115VAC 400Hz系统：**
- 大型商用飞机标准电源
- 恒速恒频（CSCF）：恒速驱动发电机
- 变速恒频（VSCF）：电力电子变换
- 变速变频（SVVF）：直接使用发电机输出（A350/B787）
- 400Hz频率：减小变压器和电机体积重量

**电源类型对比：**

| 参数 | 28VDC | 115VAC 400Hz |
|------|-------|-------------|
| 适用飞机 | 小型/通航 | 商用运输 |
| 发电方式 | DC发电机 | AC发电机 |
| 变换效率 | 高 | 中 |
| 设备重量 | 轻 | 重 |
| 配电复杂度 | 低 | 高 |

**270VDC高压直流：**
- 军用飞机新趋势（F-35）
- 减少铜缆重量
- 与电力作动兼容
- 需要高压DC/DC变换

### 7.2 电源管理

**电源管理架构：**
- 发电机控制器（GCU）：调节输出电压/频率
- 汇流条功率控制器（BPCU）：管理配电
- 电源负载管理（PLM）：负载优先级
- 外部电源接口

**电源转换：**
- AC/DC整流：二极管/SCR整流桥
- DC/AC逆变：SPWM逆变器
- DC/DC变换：Buck/Boost/隔离变换
- AC/AC变换：变压变频

**电池管理：**
- 锂电池BMS：充放电保护
- 过压/欠压保护
- 过流/短路保护
- 温度监测与限制
- 电池均衡

### 7.3 电源冗余设计

**余度配置：**
- 双发电机：左/右发动机各驱动一台
- APU发电机：第三电源
- RAT（冲压空气涡轮）：应急发电
- 蓄电池：最后备份

**电源汇流条等级：**
```
主汇流条（Essential Bus）→ 关键设备
非重要汇流条（Non-Essential Bus）→ 普通负载
应急汇流条（Emergency Bus）→ 应急设备
电池汇流条（Battery Bus）→ 最后保障
```

**自动转换逻辑：**
- 主电源失效 → 自动切换至备用
- 发电机并联运行（双发）
- 负载卸载（Load Shedding）：非关键负载优先断开
- 黑启动能力

## 八、航空电子测试

### 8.1 环境试验

**温度试验：**
- 工作温度范围：-55°C ~ +85°C（标准航空级）
- 存储温度：-62°C ~ +125°C
- 温度变化率：5°C/min（典型）
- 温度循环次数：通常≥100次
- 标准：DO-160 Section 4（温度/高度）

**振动试验：**
- 正弦振动：5-2000 Hz扫频
- 随机振动：功率谱密度（PSD）
- 典型量级：0.04 g²/Hz（设备级）
- 振动方向：三轴（X/Y/Z）
- 标准：DO-160 Section 8（振动）

**冲击试验：**
- 半正弦脉冲
- 典型量级：15g, 11ms
- 三轴六方向
- 标准：DO-160 Section 7（冲击）

**电磁兼容（EMC）试验：**
- 辐射发射（RE）
- 传导发射（CE）
- 辐射敏感度（RS）
- 传导敏感度（CS）
- 标准：DO-160 Sections 20-26

### 8.2 DO-160 环境试验标准

DO-160（Environmental Conditions and Test Procedures for Airborne Equipment）试验类别：

| 章节 | 试验项目 | 说明 |
|------|---------|------|
| Section 4 | 温度/高度 | 工作范围验证 |
| Section 5 | 温度变化 | 快速温度循环 |
| Section 6 | 湿度 | 高温高湿试验 |
| Section 7 | 冲击 | 功能性冲击 |

| Section 9 | 爆炸大气 | 防爆验证 |
| Section 10 | 防水 | 防水等级 |
| Section 11 | 流体敏感性 | 耐化学腐蚀 |
| Section 12 | 沙尘 | 防尘试验 |
| Section 13 | 防霉 | 霉菌生长试验 |
| Section 15 | 磁效应 | 磁场影响 |

| Section 27 | 雷击 | 雷电防护 |

### 8.3 HALT/HASS 加速试验

**HALT（高加速寿命试验）：**
- 目的：发现设计薄弱环节
- 步骤：
  1. 温度步进应力（逐步加大温变范围）
  2. 温度循环（快速温变）
  3. 振动步进应力（逐步加大量级）
  4. 综合应力（温度+振动）
- 找到工作极限和破坏极限
- 在设计阶段进行

**HASS（高加速应力筛选）：**
- 目的：生产阶段筛选早期失效
- 应力量级：HALT破坏极限的50-80%
- 时间短，覆盖全面
- 替代传统ESS（环境应力筛选）

**HALT/HASS价值：**
- 大幅缩短试验时间
- 提前暴露设计缺陷
- 降低后期故障率
- 需要专用设备（液氮制冷、气动振动台）

## 九、低功耗与可靠性设计

### 9.1 看门狗设计

**看门狗原理：**
```
正常运行：程序定期喂狗 → 计数器清零 → 不触发复位
程序跑飞：未喂狗 → 计数器溢出 → 触发复位
```

**看门狗类型：**
- 简单看门狗：仅检测程序运行
- 窗口看门狗：喂狗必须在时间窗口内
- 外部看门狗：独立硬件，更可靠
- 分级看门狗：任务级+系统级

**窗口看门狗优势：**
- 防止任务过快喂狗（掩盖问题）
- 防止任务过慢喂狗（响应延迟）
- STM32内置窗口看门狗（WWDG）

**看门狗设计实践：**
- 多任务系统中每个任务维护计数器
- 监控任务检查所有计数器
- 区分可恢复故障（复位）和不可恢复故障（告警）
- 看门狗复位后记录故障原因

### 9.2 冗余设计

**冗余类型：**

| 类型 | 说明 | 故障容忍 |
|------|------|---------|
| 冷备份 | 备份设备待命 | 需切换时间 |
| 温备份 | 备份运行但不输出 | 快速切换 |
| 热备份 | 同时运行 | 无切换延迟 |
| 表决冗余 | N取M表决 | 取决于N和M |

**冗余管理策略：**
- 故障检测：比较、监控、自检
- 故障隔离：切断故障单元
- 故障恢复：切换到备份单元
- 降级运行：减少功能维持安全

**C919航电冗余设计：**
- 双冗余飞控计算机
- 三套大气数据系统
- 双惯性导航+GPS
- 双液压+电备份
- 双电源汇流条

### 9.3 故障检测与恢复

**故障检测方法：**
- 比较检测：冗余通道结果对比
- 范围检查：参数是否在合理范围
- 速率检查：参数变化率是否异常
- 一致性检查：多源数据交叉验证
- BIT（机内自检测）：开机/周期自检

**航空系统健康管理：**
- PHM（故障预测与健康管理）
- 实时监测系统状态参数
- 趋势分析预测故障
- 降低非计划停场时间

**故障树分析（FTA）：**
```
        系统失效
       /        \
   硬件故障    软件故障
   /    \         |
CPU   传感器   计算错误
 |      |
SEU   断线
```

**FMEA（故障模式与影响分析）：**
- 识别所有可能的故障模式
- 评估每种故障的影响严重度
- 确定检测方法
- 计算RPN（风险优先级数）= 严重度 x 发生度 x 检测度

### 9.4 低功耗设计策略

**处理器功耗管理：**
- 动态电压频率调节（DVFS）
- 时钟门控（Clock Gating）
- 电源门控（Power Gating）
- 休眠模式（Sleep/Deep Sleep）
- 多核异构：大核+小核

**通信接口功耗：**
- 低功耗无线：ZigBee/LoRa/BLE
- 间歇通信：定期唤醒发送
- 自适应功率：根据距离调节发射功率

**传感器功耗管理：**
- 按需供电：不用时断电
- 低功耗模式：降低采样率
- 事件驱动唤醒：中断触发

**星载系统低功耗设计：**
- 太阳能电池功率有限
- 遮挡期（地影）蓄电池供电
- 功耗预算管理
- 非关键载荷调度供电
