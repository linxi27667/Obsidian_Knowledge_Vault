# 嵌入式应用学习总览

> 将通用嵌入式能力映射到工业、汽车、机器人、医疗、音视频和图像等应用领域。

| 方向 | 笔记 | 关注重点 |
|---|---|---|
| 工业 | [[工业自动化技术]]、[[工业自动化技术详解]] | 现场设备、可靠性与通信。 |
| 汽车 | [[汽车电子技术]]、[[汽车电子技术详解]] | 电源、总线与功能安全。 |
| 机器人 | [[机器人技术]]、[[嵌入式机器人技术]] | 感知、控制与执行。 |
| 医疗 | [[医疗电子技术]]、[[医疗嵌入式]] | 安全、精度与规范。 |
| 航空航天 | [[航空航天电子技术]]、[[航空航天嵌入式]] | 高可靠与环境适应。 |
| 图像与音频 | [[嵌入式图像处理技术]]、[[图像处理技术]]、[[嵌入式音频技术]]、[[音频处理技术]]、[[音频编解码技术]] | 数据吞吐、算法与实时性。 |
| 多媒体与信号 | [[嵌入式多媒体技术]]、[[信号处理基础]] | 媒体链路和信号基础。 |

## 最短总结

- 各行业的基础技术相通，但可靠性、法规、成本和实时性约束不同。
- 进入具体方向前，先掌握硬件、RTOS、通信和调试的通用能力。
- 方案选型必须由实际风险和产品约束驱动。
