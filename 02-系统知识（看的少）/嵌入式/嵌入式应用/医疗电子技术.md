# 医疗电子技术

> 医疗电子是嵌入式系统的重要应用领域，涉及生物信号采集、传感器技术、低功耗设计、数据安全等多个技术方向。

---

## 一、医疗电子概述

### 1.1 医疗器械分类

根据风险程度，医疗器械分为三类：

| 分类 | 风险等级 | 监管要求 | 典型产品 |
|------|----------|----------|----------|
| I类 | 低风险 | 常规管理 | 手术刀、绷带、听诊器 |
| II类 | 中风险 | 控制管理 | 血压计、心电图机、输液泵 |
| III类 | 高风险 | 严格管理 | 心脏起搏器、人工关节、血管支架 |

### 1.2 IEC 60601 安全标准

IEC 60601 是医疗电气设备的核心安全标准：

- **IEC 60601-1**：基本安全和基本性能要求
- **IEC 60601-1-2**：电磁兼容性要求和测试
- **IEC 60601-1-6**：可用性工程
- **IEC 60601-1-8**：报警系统
- **IEC 60601-1-11**：家用医疗设备

关键要求：
- 漏电流限制：正常状态 ≤0.5mA，单一故障 ≤1mA
- 电气隔离：患者应用部分需双重保护
- 接地保护：保护接地阻抗 ≤0.2Ω
- 温度限制：可接触表面温度不超过规定值

### 1.3 认证体系

#### FDA（美国食品药品监督管理局）
- 510(k)：适用于与已上市产品实质等效的设备
- PMA（上市前审批）：适用于III类高风险设备
- De Novo：适用于中低风险但无对比设备的新型产品

#### CE 认证（欧盟）
- MDR (Medical Device Regulation) 2017/745
- 技术文件评审
- 质量管理体系审核（ISO 13485）

#### NMPA（中国国家药品监督管理局）
- 注册检验
- 临床试验（II类、III类）
- 体系核查
- 技术审评

## 二、生物电信号

### 2.1 ECG 心电图

#### 基本原理
心脏电活动在体表产生的电位差变化：

- 幅度范围：0.5mV ~ 5mV
- 频率范围：0.05Hz ~ 150Hz
- 带宽要求：诊断级 0.05Hz~150Hz，监护级 0.5Hz~40Hz

#### 标准导联
- **标准肢体导联**：I、II、III
- **加压肢体导联**：aVR、aVL、aVF
- **胸导联**：V1~V6

#### 采集电路设计
```
电极 → 高通滤波(0.05Hz) → 仪表放大器 → 低通滤波(150Hz) → 50Hz陷波 → ADC
```

关键器件：
- 仪表放大器：AD620、INA333（高CMRR > 100dB）
- 右腿驱动电路：提高共模抑制比
- 导联脱落检测：AC/DC两种方式

### 2.2 EEG 脑电图

#### 基本参数
- 幅度范围：1μV ~ 100μV
- 频率范围：0.5Hz ~ 100Hz
- 电极数量：1~256通道

#### 脑电波分类
| 波形 | 频率范围 | 幅度 | 对应状态 |
|------|----------|------|----------|
| δ波 | 0.5~4Hz | 20~200μV | 深度睡眠 |
| θ波 | 4~8Hz | 10~50μV | 浅睡眠、冥想 |
| α波 | 8~13Hz | 20~100μV | 安静闭眼 |
| β波 | 13~30Hz | 5~30μV | 精神活动 |
| γ波 | 30~100Hz | <2μV | 高级认知 |

### 2.3 EMG 肌电图

#### 表面肌电信号
- 幅度范围：50μV ~ 30mV
- 频率范围：10Hz ~ 500Hz
- 采样率：≥1000Hz

#### 应用场景
- 假肢控制
- 康复训练
- 运动分析
- 人机交互

### 2.4 SpO2 血氧饱和度

#### 测量原理
基于血红蛋白对红光（660nm）和红外光（940nm）的吸收差异：

- 氧合血红蛋白：红光吸收少，红外光吸收多
- 还原血红蛋白：红光吸收多，红外光吸收少

#### 计算公式
```
R = (AC_red/DC_red) / (AC_ir/DC_ir)
SpO2 = A - B × R  （A、B为校准系数）
```

## 三、医疗传感器

### 3.1 体温传感器

| 传感器类型 | 精度 | 响应时间 | 特点 |
|-----------|------|----------|------|
| 热敏电阻(NTC) | ±0.1°C | 1~5s | 成本低、线性化需处理 |
| 热电偶 | ±0.5°C | <1s | 响应快、需冷端补偿 |
| 红外测温 | ±0.2°C | <0.5s | 非接触、适合额温枪 |
| 数字式(MLX90614) | ±0.5°C | <0.1s | 集成度高、I2C接口 |

### 3.2 血压传感器

#### 无创血压测量（示波法）
- 袖带充气加压
- 检测动脉搏动引起的袖带压力变化
- 收缩压/舒张压/平均压计算

#### 压力传感器选型
- MPX5050：0~50kPa，模拟输出
- BMP388：数字式，I2C/SPI接口
- 医疗级：Honeywell 26PC系列

### 3.3 心率传感器

#### 光电容积脉搏波（PPG）原理
- LED发射光照射皮肤
- 光电二极管检测反射/透射光
- 动脉血容量变化引起光吸收变化

#### 推荐传感器
- MAX30102：集成LED和光电二极管，支持SpO2和心率
- MAX86150：支持ECG+PPG双模测量
- TI AFE4404：医疗级模拟前端

### 3.4 脉搏波PPG信号处理

#### 信号特征
- 频率范围：0.5Hz ~ 5Hz（脉搏波）
- 包含呼吸成分：0.15Hz ~ 0.4Hz
- 运动伪迹：需自适应滤波

#### 算法流程
```
原始PPG → 带通滤波 → 运动伪迹消除 → 峰值检测 → 心率计算
                              ↓
                      频谱分析 → HRV分析
```

### 3.5 血糖传感器

#### 电化学法原理
- 葡萄糖氧化酶(GOD)催化反应
- 产生的电流与血糖浓度成正比
- 连续血糖监测(CGM)：植入式微电极

#### 关键参数
- 测量范围：1.1~33.3 mmol/L
- 精度要求：ISO 15197标准（±15%）
- 传感器寿命：7~14天（CGM）

## 四、医疗级MCU选型

### 4.1 选型关键指标

| 指标 | 要求 | 说明 |
|------|------|------|
| 功耗 | <100μA/MHz（活跃） | 纽扣电池供电设备 |
| ADC精度 | 16~24位 | 生物信号采集 |
| 安全特性 | 看门狗、ECC RAM | IEC 60601要求 |
| 时钟精度 | ±50ppm | 心电图时间基准 |
| 封装尺寸 | 小型QFN/BGA | 可穿戴设备 |

### 4.2 主流MCU对比

#### TI MSP430 系列
- **特点**：超低功耗，16位RISC架构
- **功耗**：活跃模式 100μA/MHz，待机 0.1μA
- **ADC**：12位SAR，采样率200ksps
- **适用**：一次性医疗设备、血糖仪
- **型号**：MSP430FR5994（带低功耗加速器）

#### STM32L4 系列
- **特点**：ARM Cortex-M4，低功耗高性能
- **功耗**：活跃模式 30μA/MHz，待机 0.4μA
- **ADC**：12位，采样率5.33Msps
- **安全**：双区Flash、硬件加密
- **适用**：便携式监护仪、心电图机

#### nRF52 系列
- **特点**：集成BLE 5.0，Cortex-M4F
- **功耗**：活跃模式 3.2mA，睡眠 1.9μA
- **无线**：蓝牙5.0、Thread、Zigbee
- **适用**：可穿戴医疗设备、蓝牙体温计

### 4.3 医疗级MCU特殊要求

#### 功能安全
- 看门狗定时器：独立时钟源
- 存储器保护：ECC、MPU
- 时钟监控：检测时钟故障
- 电源监控：欠压/过压检测

#### 软件分区
```c
// 安全关键代码与非关键代码隔离
__attribute__((section(".safe_code")))
void safety_critical_function(void) {
    // 心率报警、药物剂量计算等
}
```

### 6.1 智能手表健康监测

#### 传感器集成
- PPG传感器：心率、血氧、压力
- 加速度计：运动检测、跌倒检测
- 陀螺仪：姿态识别

#### 健康功能
- **心率监测**：24小时连续监测
- **血氧检测**：睡眠呼吸暂停筛查
- **心电图**：单导联ECG
- **压力监测**：HRV分析
- **睡眠分析**：深睡/浅睡/REM识别

### 6.2 连续血糖监测(CGM)

#### 系统组成
- 微型传感器：植入皮下组织
- 发射器：蓝牙数据传输
- 接收器/手机：数据显示和报警

#### 技术指标
- 测量范围：2.2~27.8 mmol/L
- 精度：MARD < 10%
- 更新频率：每5分钟
- 传感器寿命：10~14天

#### 传感器结构
```
工作电极(葡萄糖氧化酶) → 信号转换 → 电流测量
参比电极 → 电位基准
对电极 → 电流回路
```

### 6.3 便携式心电Holter

#### 设计要求
- 24~72小时连续记录
- 3~12导联同步采集
- 存储容量：≥2GB
- 电池寿命：≥48小时

#### 信号处理流程
```
电极信号 → 前端放大 → ADC采集 → 数据压缩 → SD卡存储
                              ↓
                      实时分析 → 异常检测 → 事件标记
```

#### 分析算法
- QRS波检测：Pan-Tompkins算法
- 心律失常分类：房颤、室早、停搏
- ST段分析：心肌缺血检测
- HRV分析：自主神经功能评估

## 七、医疗设备安全

### 7.1 电气安全

#### 保护措施
- **双重绝缘**：基本绝缘 + 补充绝缘
- **保护接地**：接地阻抗 ≤0.2Ω
- **漏电流限制**：
  - B型设备：正常 ≤0.5mA，故障 ≤1mA
  - BF型设备：正常 ≤0.1mA，故障 ≤0.5mA
  - CF型设备：正常 ≤0.01mA，故障 ≤0.05mA

#### 电气隔离
- 光耦隔离：信号隔离
- 磁耦隔离：电源隔离
- 电容隔离：高速信号隔离

- 细胞毒性测试
- 致敏性测试

## 八、低功耗设计

### 8.1 纽扣电池供电设计

#### 电池选型
| 电池类型 | 容量 | 电压 | 适用场景 |
|----------|------|------|----------|
| CR2032 | 230mAh | 3V | 一次性设备 |
| CR2450 | 620mAh | 3V | 中等功耗设备 |
| CR123A | 1500mAh | 3V | 高功耗设备 |

#### 功耗预算
```c
// 功耗计算示例
#define ACTIVE_CURRENT   5    // mA (MCU + 传感器)
#define ACTIVE_TIME      10   // ms (每次测量)
#define SLEEP_CURRENT    2    // μA
#define MEASURE_INTERVAL 1000 // ms (1秒一次)

// 平均电流
avg_current = (ACTIVE_CURRENT * ACTIVE_TIME + 
               SLEEP_CURRENT * (MEASURE_INTERVAL - ACTIVE_TIME)) 
              / MEASURE_INTERVAL;
// = (5*10 + 0.002*990) / 1000 ≈ 0.052mA = 52μA

// 电池寿命
battery_life = 230mAh / 0.052mA ≈ 4423小时 ≈ 184天
```

#### 存储加密
- AES-256：数据库加密
- 文件加密：设备本地存储
- 密钥管理：硬件安全模块(HSM)

#### 加密实现
```c
// AES-256加密示例
#include "mbedtls/aes.h"

int encrypt_patient_data(const uint8_t *key, 
                         const uint8_t *plaintext,
                         uint8_t *ciphertext,
                         size_t len) {
    mbedtls_aes_context aes;
    uint8_t iv[16] = {0}; // 初始化向量
    
    mbedtls_aes_init(&aes);
    mbedtls_aes_setkey_enc(&aes, key, 256);
    
    return mbedtls_aes_crypt_cbc(&aes, 
                                 MBEDTLS_AES_ENCRYPT,
                                 len, iv, 
                                 plaintext, ciphertext);
}
```

    ↓              ↓               ↓          ↓

### 10.2 数据上云

#### 云平台选择

- Azure IoT Hub：设备孪生、边缘计算
- 阿里云IoT：国内合规

- MQTT：轻量级，适合低带宽
- HTTP/REST：通用接口

#### MQTT发布示例

// 发布患者生命体征数据

### 10.3 异常报警

#### 报警规则
```c
// 生命体征异常检测
typedef struct {
    int hr_min;      // 心率下限
    int hr_max;      // 心率上限
    float spo2_min;  // 血氧下限
    float temp_max;  // 体温上限
} alarm_thresholds_t;

int check_vitals_alarm(patient_vitals_t *vitals,
                       alarm_thresholds_t *thresholds) {
    if (vitals->heart_rate < thresholds->hr_min ||
        vitals->heart_rate > thresholds->hr_max) {
        return ALARM_HR_ABNORMAL;
    }
    if (vitals->spo2 < thresholds->spo2_min) {
        return ALARM_SPO2_LOW;
    }
    if (vitals->temperature > thresholds->temp_max) {
        return ALARM_FEVER;
    }
    return ALARM_NONE;
}
```

- 手机：推送通知、短信
