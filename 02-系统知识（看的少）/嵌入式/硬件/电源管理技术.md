# 电源管理技术

## 核心概念

- **电源管理** - 高效转换、分配和使用电能
- **LDO** - 低压差线性稳压器
- **DC-DC** - 开关电源转换器
- **功耗优化** - 降低系统整体功耗

---

## 一、电源基础

### 1.1 电源类型

| 类型 | 特点 | 应用 |
|------|------|------|
| 线性电源 | 低噪声、低效率 | 模拟电路 |
| 开关电源 | 高噪声、高效率 | 数字电路 |
| 电池 | 便携、有限容量 | 移动设备 |

---

### 1.2 电源参数

| 参数 | 说明 | 单位 |
|------|------|------|
| 输入电压 | 允许的输入范围 | V |
| 输出电压 | 稳定的输出 | V |
| 输出电流 | 最大输出能力 | A |
| 效率 | 输出功率/输入功率 | % |
| 纹波 | 输出电压波动 | mV |
| 负载调整率 | 负载变化时输出稳定性 | % |
| 线性调整率 | 输入变化时输出稳定性 | % |

---

### 1.3 功率计算

**直流功率：**
$$P = V \times I$$

**交流功率：**
$$P_{real} = V_{rms} \times I_{rms} \times \cos\phi$$

**效率：**
$$\eta = \frac{P_{out}}{P_{in}} \times 100\%$$

---

## 二、LDO稳压器

### 2.1 工作原理

```
Vin ──┬── 调整管 ──┬── Vout
      │           │
      │   参考电压 │
      │     │     │
      └─────┤     │
            │     │
          误差放大器
            │     │
            └─────┘
```

**压差：**
$$V_{dropout} = V_{in} - V_{out}$$

---

### 2.2 LDO参数

| 参数 | 说明 | 典型值 |
|------|------|--------|
| 压差 | 正常工作的最小压差 | 100-300mV |
| 静态电流 | 无负载时的电流 | 1-100μA |
| 纹波抑制比 | 抑制输入纹波的能力 | 60-80dB |
| 瞬态响应 | 负载突变时的恢复 | μs级 |

---

### 2.3 常见LDO芯片

| 型号 | 输出 | 压差 | 特点 |
|------|------|------|------|
| AMS1117 | 3.3V/1A | 1.3V | 通用 |
| RT9013 | 3.3V/500mA | 250mV | 低噪声 |
| ME6211 | 3.3V/500mA | 100mV | 超低压差 |
| AP2112 | 3.3V/600mA | 250mV | 低功耗 |

---

### 2.4 LDO选型

**选型要点：**
1. 输入电压范围
2. 输出电压和电流
3. 压差要求
4. 静态电流（电池供电）
5. 纹波抑制（模拟电路）
6. 封装和散热

## 三、DC-DC转换器

### 3.1 降压(Buck)转换器

**电路：**
```
Vin ──┬── 开关管 ──┬── 电感 ──┬── Vout
      │           │         │
      │           │    电容 │
      │           │         │
      └── 续流二极管 ────────┴── GND
```

**工作原理：**
- 开关闭合：电感储能
- 开关断开：电感释放能量

**输出电压：**
$$V_{out} = D \times V_{in}$$

其中D为占空比

---

### 3.2 升压(Boost)转换器

**电路：**
```
Vin ──┬── 电感 ──┬── 二极管 ──┬── Vout
      │         │           │
      │    开关管│      电容 │
      │         │           │
      └─────────┴───────────┴── GND
```

**输出电压：**
$$V_{out} = \frac{V_{in}}{1-D}$$

---

### 3.3 升降压(Buck-Boost)转换器

**输出电压：**
$$V_{out} = \frac{D}{1-D} \times V_{in}$$

**应用：** 电池供电系统（电压变化大）

---

### 3.4 DC-DC参数

| 参数 | 说明 | 影响 |
|------|------|------|
| 开关频率 | 开关切换频率 | 效率、EMI |
| 效率 | 功率转换效率 | 电池寿命 |
| 纹波 | 输出电压波动 | 信号质量 |
| 负载瞬态 | 负载突变响应 | 系统稳定性 |

---

### 3.5 常见DC-DC芯片

| 型号 | 类型 | 输出 | 特点 |
|------|------|------|------|
| MP1584 | Buck | 3A | 高效率 |
| LM2596 | Buck | 3A | 通用 |
| TPS63020 | Buck-Boost | 3A | 升降压 |
| MT3608 | Boost | 2A | 升压 |
| SY8089 | Buck | 2A | 小封装 |

## 四、电池管理

### 4.1 锂电池

**参数：**
| 参数 | 说明 |
|------|------|
| 标称电压 | 3.7V |
| 充电截止电压 | 4.2V |
| 放电截止电压 | 2.5-3.0V |
| 容量 | mAh |
| 充放电倍率 | C |

**充电曲线：**
```
电压
4.2V ─────────────────────
      │                 │
      │    恒压充电     │
      │                 │
      │ 恒流充电        │
      │                 │
3.0V ─┴─────────────────┴──→ 时间
```

---

### 4.2 充电管理芯片

**TP4056：**
- 线性充电

- 路径管理
- 最大1.5A
- 电池保护

**电路：**
```
USB 5V ──┬── TP4056 ──┬── 锂电池
         │           │
         │    充电指示│
         │           │
         └───────────┘
```

### 4.3 电量检测

**库仑计：**

## 五、电源设计

### 5.1 电源树设计

```
输入(5V/USB)
    │
    ├── LDO(3.3V) → MCU, 传感器
    │
    ├── Buck(1.8V) → 内核电源
    │
    └── Boost(12V) → 显示屏背光
```

---

### 5.2 去耦电容

**原则：**
- 每个电源引脚加0.1μF陶瓷电容
- 大电容(10-100μF)储能
- 靠近引脚放置

**布局：**
```
VCC ──┬── 0.1μF ──┬── 芯片VCC
      │           │
      └── 10μF ──┘
      │
     GND
```

---

### 5.3 EMC设计

**电源滤波：**
```
输入 ──┬── 电感 ──┬── 输出
       │         │
       └── 电容 ──┘
       │         │
      GND       GND
```

**接地策略：**
- 单点接地（低频）
- 多点接地（高频）
- 模拟/数字地分离

---

## 六、低功耗设计

### 6.1 功耗分析

**功耗组成：**
$$P_{total} = P_{dynamic} + P_{static}$$

**动态功耗：**
$$P_{dynamic} = C \times V^2 \times f$$

**静态功耗：**
$$P_{static} = V \times I_{leak}$$

---

### 6.2 MCU低功耗模式

**ESP32功耗模式：**
| 模式 | 电流 | 唤醒源 |
|------|------|--------|
| Active | 20-240mA | - |
| Modem Sleep | 3-20mA | 定时器 |
| Light Sleep | 0.8mA | GPIO/定时器 |
| Deep Sleep | 10μA | GPIO/定时器 |
| Hibernation | 5μA | RTC GPIO |

**Deep Sleep代码：**
```c
#include "esp_sleep.h"

// 配置唤醒源
esp_sleep_enable_timer_wakeup(60 * 1000000);  // 60秒
esp_sleep_enable_ext0_wakeup(GPIO_NUM_0, 0);  // GPIO0低电平唤醒

// 进入Deep Sleep
esp_deep_sleep_start();
```

---

### 6.3 外设功耗管理

**电源域控制：**
```c
// 关闭不需要的外设
esp_sleep_pd_config(ESP_PD_DOMAIN_RTC_PERI, ESP_PD_OPTION_OFF);
esp_sleep_pd_config(ESP_PD_DOMAIN_RTC_SLOW_MEM, ESP_PD_OPTION_OFF);
```

**动态频率调节：**
```c
// 降低CPU频率
esp_pm_config_esp32_t config = {
    .max_freq_mhz = 80,
    .min_freq_mhz = 10,
    .light_sleep_enable = true
};
esp_pm_configure(&config);
```

---

### 6.4 传感器低功耗

**间歇工作：**
```c
while (1) {
    sensor_power_on();
    delay_ms(10);  // 等待稳定
    
    float data = sensor_read();
    
    sensor_power_off();
    
    send_data(data);
    
    esp_deep_sleep_start();
}
```

---

### 6.5 通信低功耗

**WiFi省电：**
```c
// 启用WiFi省电模式
esp_wifi_set_ps(WIFI_PS_MAX_MODEM);
```

**BLE省电：**
- 降低广播间隔
- 使用连接间隔
- 使用低功耗模式

## 七、电源测试

### 7.1 效率测试

**测试方法：**
```
效率 = Pout / Pin = (Vout × Iout) / (Vin × Iin)
```

**测试条件：**
- 不同负载（10%-100%）
- 不同输入电压
- 不同温度

---

### 7.2 纹波测试

**测试方法：**
- 示波器AC耦合
- 带宽限制20MHz
- 测量峰峰值

**指标：**
- 一般要求<50mV
- 模拟电路<10mV

---

### 7.3 瞬态响应

**测试方法：**
- 负载阶跃（10%-90%）
- 测量过冲/下冲
- 测量恢复时间

---

## 八、散热设计

### 8.1 热阻计算

**热阻：**
$$R_{ja} = \frac{T_j - T_a}{P}$$

**结温：**
$$T_j = T_a + P \times R_{ja}$$

---

### 8.2 散热方式

| 方式 | 热阻 | 应用 |
|------|------|------|
| 自然对流 | 高 | 低功耗 |
| 散热片 | 中 | 中等功耗 |
| 风扇 | 低 | 高功耗 |
| 热管 | 很低 | 紧凑空间 |

---

### 8.3 PCB散热

**散热焊盘：**
- 大面积铜箔
- 过孔导热
- 散热层

**布局建议：**
- 远离热敏元件
- 良好通风
- 均匀分布
