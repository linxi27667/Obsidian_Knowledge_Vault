## 一、电源设计

### 1.1 电源树设计

```
输入电源(5V USB)
    │
    ├── LDO → 3.3V (MCU、数字电路)
    │
    ├── Buck → 1.8V (DDR、IO)
    │
    ├── Buck → 1.2V (核心电压)
    │
    └── LDO → 3.3V_ANA (模拟电路)
```

### 1.2 去耦电容设计

```c
// 去耦电容配置
typedef struct {
    float capacitance;    // 容值
    float voltage;        // 额定电压
    char package[8];      // 封装
    char type[16];        // 类型
    int count;            // 数量
} decoupling_cap_t;

// 典型去耦方案
decoupling_cap_t decoupling[] = {
    {100e-6, 6.3,  "0805", "MLCC", 1},  // 电源入口
    {10e-6,  10,   "0603", "MLCC", 2},  // 每个电源引脚
    {100n,   16,   "0402", "MLCC", 4},  // 高频去耦
    {10n,    16,   "0402", "MLCC", 2},  // 超高频
};

// 去耦原则
/*
 * 1. 大电容(10μF+)靠近电源入口
 * 2. 中电容(100nF)每个IC电源引脚
 * 3. 小电容(10nF)高频敏感器件
 * 4. 电容尽量靠近引脚
 * 5. 过孔直接到地平面
 */
```

## 二、时钟设计

### 2.1 晶振电路

```c
// 晶振参数
typedef struct {
    float frequency;      // 频率
    float load_cap;       // 负载电容
    float esr;            // 等效串联电阻
    float drive_level;    // 驱动电平
    float ppm;            // 频率精度
} crystal_t;

// 晶振电路设计
/*
 *        ┌──────────────┐
 *  XTAL_IN ─┤              │
 *        │  Crystal     │
 *  XTAL_OUT─┤              │
 *        └──────────────┘
 *             │     │
 *            C1    C2
 *             │     │
 *            GND   GND
 *
 * C1 = C2 = 2 × (CL - Cstray)
 * CL: 晶振负载电容
 * Cstray: 杂散电容(约2-5pF)
 */

// 示例: 8MHz晶振
crystal_t hse_crystal = {
    .frequency = 8000000,
    .load_cap = 20e-12,      // 20pF
    .esr = 30,               // 30Ω
    .drive_level = 100e-6,   // 100μW
    .ppm = 20,               // ±20ppm
};
```

## 三、接口设计

### 3.1 UART接口

```c
// UART电平转换
/*
 * 3.3V MCU ──── MAX3232 ──── DB9(RS-232)
 *
 * 或直接TTL连接:
 * 3.3V MCU TX ──── 3.3V MCU RX (直连)
 * 3.3V MCU RX ──── 3.3V MCU TX (直连)
 */

// USB转UART
/*
 * USB ──── CH340/CP2102/FT232 ──── MCU UART
 *
 * 需要:
 * - USB连接器(Type-C/Mini/Micro)
 * - 去耦电容
 * - 可能需要外部晶振
 */
```

---

### 3.2 I2C接口

```c
// I2C上拉电阻计算
/*
 *        VCC
 *         │
 *        R1(R2)
 *         │
 *  SCL(SDA)──── MCU
 *         │
 *       从设备
 *
 * R = (VCC - VOL) / IOL
 *
 * 典型值:
 * - 100kHz: 4.7kΩ
 * - 400kHz: 2.2kΩ
 * - 1MHz: 1kΩ
 */

// I2C总线电容
/*
 * 总线电容限制:
 * - 100kHz: 400pF
 * - 400kHz: 200pF
 * - 1MHz: 100pF
 *
 * 每个器件约10-20pF
 * PCB走线约1-2pF/cm
 */
```

---

### 3.3 SPI接口

```c
// SPI连接
/*
 *        ┌─────┐
 *  MOSI ─┤     │
 *  MISO ─┤ MCU ├──── Flash/Sensor
 *  SCK  ─┤     │
 *   CS  ─┤     │
 *        └─────┘
 *
 * 注意:
 * - 每个从设备独立CS线
 * - 走线尽量等长
 * - 高速SPI需要阻抗匹配
 */

// SPI速度计算
/*
 * SPI时钟 = 系统时钟 / 分频系数
 *
 * 例: 84MHz / 2 = 42MHz
 */
```

## 四、保护电路

### 4.1 ESD保护

```c
// ESD保护器件
typedef struct {
    const char *name;
    float working_voltage;
    float clamping_voltage;
    float capacitance;
    const char *package;
} esd_protection_t;

esd_protection_t esd_devices[] = {
    {"PESD5V0",   5.0,   9.8,  0.5e-12, "SOD-323"},   // USB
    {"PESD3V3",   3.3,   7.0,  0.5e-12, "SOD-323"},   // 信号
    {"PESD24V",   24.0,  40.0, 50e-12,  "SOD-323"},   // CAN
};

// ESD保护布局
/*
 * 信号线 ──┬── ESD器件 ── GND
 *          │
 *        连接器
 *
 * 规则:
 * 1. ESD器件尽量靠近连接器
 * 2. 接地路径尽量短
 * 3. 避免ESD电流经过敏感电路
 */
```

---

### 4.2 过流保护

```c
// 自恢复保险丝
typedef struct {
    float hold_current;   // 保持电流
    float trip_current;   // 跳闸电流
    float resistance;     // 电阻
    float trip_time;      // 跳闸时间
} pptc_fuse_t;

pptc_fuse_t usb_fuse = {
    .hold_current = 0.5,   // 500mA
    .trip_current = 1.0,   // 1A
    .resistance = 0.15,    // 150mΩ
    .trip_time = 0.5,      // 500ms
};
```
