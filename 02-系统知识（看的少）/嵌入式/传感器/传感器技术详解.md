## 一、传感器基础参数

### 1.1 灵敏度（Sensitivity）

- **定义**：输出变化量与输入变化量之比
- **公式**：`S = Δy / Δx`
- **示例**：NTC热敏电阻在25°C时灵敏度约为 -4.4%/°C
- **选型要点**：灵敏度过低会导致小信号淹没在噪声中

### 1.2 精度（Accuracy）

- **定义**：测量值与真实值的接近程度
- **表示**：通常用 ±%FS（满量程百分比）或 ±绝对值
- **示例**：±0.5°C 表示温度测量误差不超过0.5度
- **注意**：精度 ≠ 分辨率，高分辨率不等于高精度

### 1.3 分辨率（Resolution）

- **定义**：传感器能检测到的最小变化量
- **与ADC关系**：`分辨率 = 满量程 / 2^n`（n为ADC位数）
- **示例**：12位ADC测量0-3.3V，分辨率 = 3300/4096 ≈ 0.8mV

### 1.4 线性度（Linearity）

- **定义**：输出与输入之间线性关系的程度
- **非线性误差**：实际曲线与理想直线的最大偏差
- **补偿方法**：查表法、多项式拟合、分段线性插值

### 1.5 响应时间（Response Time）

- **定义**：传感器输出达到稳态值63.2%（一阶系统）所需时间
- **时间常数 τ**：一阶系统的关键参数
- **示例**：DS18B20温度转换时间750ms（12位分辨率）
- **影响**：响应时间决定了可测量的最高变化频率

### 1.6 信噪比（SNR）

- **定义**：信号功率与噪声功率之比
- **公式**：`SNR = 10 × log₁₀(Ps/Pn)` 单位dB
- **提高方法**：硬件滤波、软件平均、差分测量、屏蔽接地

### 1.7 其他重要参数

| 参数 | 说明 | 典型值 |
|------|------|--------|
| 重复性 | 多次测量同一量的一致性 | ±0.1%FS |
| 迟滞 | 正反行程输出差异 | ±0.5%FS |
| 零点漂移 | 无输入时输出变化 | ±0.01%/°C |
| 量程 | 可测量的范围 | 0-100°C |
| 功耗 | 工作电流 | μA~mA级 |
| 工作温度 | 器件可正常工作的环境温度 | -40~85°C |

## 二、温度传感器

### 2.1 NTC热敏电阻

#### 原理
- NTC（Negative Temperature Coefficient）：温度升高，电阻降低
- 材料：锰、镍、钴等金属氧化物陶瓷

#### Steinhart-Hart方程
```
1/T = A + B·ln(R) + C·(ln(R))³
```
- T：开尔文温度
- R：电阻值
- A、B、C：校准系数

#### 简化B参数方程
```
1/T = 1/T₀ + (1/B)·ln(R/R₀)
```
- T₀ = 298.15K（25°C）
- R₀：25°C时的标称电阻（常用10kΩ）
- B值：常用3000K-5000K

#### 典型电路——分压器
```
VCC ──[R_fixed]──┬──[NTC]── GND
                  │
                 ADC
```
- 上拉方式：温度升高→NTC电阻降低→ADC电压升高
- 计算公式：`V_adc = VCC × R_ntc / (R_fixed + R_ntc)`

#### 代码示例（ESP32）
```c
#define NTC_NOMINAL    10000  // 25°C时电阻
#define TEMP_NOMINAL   25     // 标称温度
#define B_COEFFICIENT  3950   // B值
#define SERIES_RESISTOR 10000 // 串联电阻

float ntc_read_temp(uint16_t adc_val) {
    float resistance = SERIES_RESISTOR / (4095.0 / adc_val - 1.0);
    float steinhart = log(resistance / NTC_NOMINAL) / B_COEFFICIENT;
    steinhart += 1.0 / (TEMP_NOMINAL + 273.15);
    return (1.0 / steinhart) - 273.15;  // 转为摄氏度
}
```

### 2.2 PTC热敏电阻

- PTC（Positive Temperature Coefficient）：温度升高，电阻升高
- 用途：过流保护、自恢复保险丝
- 临界温度型PTC（CTR）：在特定温度电阻急剧跳变，用于温度开关

### 2.3 热电偶（Thermocouple）

#### 原理——塞贝克效应
- 两种不同金属构成闭合回路，接点温差产生电动势
- 输出电压：μV级，需要放大和冷端补偿

#### 常见类型

| 类型 | 材料 | 温度范围 | 灵敏度 | 应用 |
|------|------|----------|--------|------|
| K型 | 镍铬-镍硅 | -200~1372°C | 41μV/°C | 最常用，通用 |
| J型 | 铁-铜镍 | -210~1200°C | 52μV/°C | 还原性气氛 |
| T型 | 铜-铜镍 | -270~400°C | 43μV/°C | 低温测量 |
| E型 | 镍铬-铜镍 | -270~1000°C | 68μV/°C | 高灵敏度 |
| S型 | 铂铑-铂 | -50~1768°C | 10μV/°C | 高温精密 |

#### 冷端补偿
- 需要在参考端（冷端）测量实际温度
- 常用方案：热电偶+冷端NTC/DS18B20
- MAX6675/MAX31855：集成冷端补偿的热电偶数字转换器

#### MAX31855驱动示例
```c
typedef struct {
    int16_t temp_raw;    // 14位温度数据
    int16_t internal;    // 冷端温度
    uint8_t fault;       // 故障标志
} thermocouple_t;

thermocouple_t max31855_read(spi_device_handle_t spi) {
    thermocouple_t tc;
    uint8_t buf[4];
    spi_read(spi, buf, 4, 100);

    tc.temp_raw = (buf[0] << 8 | buf[1]) >> 2;
    if (buf[0] & 0x80) tc.temp_raw |= 0xC000;  // 符号扩展
    tc.internal = ((buf[2] << 8 | buf[3]) >> 4) / 16.0;
    tc.fault = buf[1] & 0x01;
    return tc;
}
```

### 2.4 RTD铂电阻

#### 原理
- 金属电阻随温度线性增加
- Pt100：0°C时100Ω；Pt1000：0°C时1000Ω

#### Callendar-Van Dusen方程
```
R(T) = R₀ × [1 + A·T + B·T²]        (T ≥ 0°C)
R(T) = R₀ × [1 + A·T + B·T² + C·(T-100)·T³]  (T < 0°C)
```
- 标准系数：A=3.9083e-3, B=-5.775e-7, C=-4.183e-12

#### 测量电路——四线制
```
I+ ──[引线]──[RTD]──[引线]── I-
               │           │
              V+          V-
```
- 消除引线电阻误差
- 恒流源驱动（0.1~1mA），测量电压差

#### 三线制惠斯通电桥
- 成本较低，精度介于两线和四线之间
- 需要三根引线，通过电桥消除引线电阻

### 2.5 数字温度传感器

#### DS18B20

| 参数 | 值 |
|------|-----|
| 接口 | 1-Wire（单总线） |
| 范围 | -55~125°C |
| 精度 | ±0.5°C（-10~85°C） |
| 分辨率 | 9~12位可配置 |
| 供电 | 3.0~5.5V |
| 转换时间 | 93.75ms(10位)~750ms(12位) |

**1-Wire通信时序**：
- 复位脉冲：主机拉低480μs
- 存在脉冲：传感器拉低60-240μs
- 写0：拉低60μs；写1：拉低1-15μs
- 读时隙：主机拉低1μs，15μs内采样

**命令序列**：
```
1. 复位 → 0xCC（跳过ROM） → 0x44（启动转换）
2. 等待转换完成
3. 复位 → 0xCC → 0xBE（读暂存器）
4. 读取2字节温度数据（LSB在前）
```

**ESP-IDF驱动**：
```c
float ds18b20_read_temp(gpio_num_t pin) {
    // 复位
    onewire_reset(pin);
    onewire_write(pin, 0xCC);  // Skip ROM
    onewire_write(pin, 0x44);  // Convert T

    vTaskDelay(pdMS_TO_TICKS(750));  // 等待12位转换

    onewire_reset(pin);
    onewire_write(pin, 0xCC);
    onewire_write(pin, 0xBE);  // Read Scratchpad

    uint8_t lsb = onewire_read(pin);
    uint8_t msb = onewire_read(pin);
    int16_t raw = (msb << 8) | lsb;
    return raw / 16.0f;
}
```

#### DHT22（AM2302）

| 参数 | 值 |
|------|-----|
| 接口 | 单总线（专用协议） |
| 温度范围 | -40~80°C |
| 温度精度 | ±0.5°C |
| 湿度范围 | 0-100%RH |
| 湿度精度 | ±2%RH |
| 采样周期 | ≥2秒 |

**数据格式**：40位 = 8bit湿度高 + 8bit湿度低 + 8bit温度高 + 8bit温度低 + 8bit校验和

**通信时序**：
```
主机拉低 ≥1ms → 释放 → 等待传感器响应
传感器拉低80μs → 拉高80μs → 开始发送数据
数据0：拉低50μs + 拉高26-28μs
数据1：拉低50μs + 拉高70μs
```

#### SHT30

| 参数 | 值 |
|------|-----|
| 接口 | I2C（地址0x44/0x45） |
| 温度精度 | ±0.3°C |
| 湿度精度 | ±2%RH |
| 响应时间 | 8s(τ63%) |
| 重复性 | 0.04°C(高) |

**CRC-8校验**：多项式 0x31 (x⁸+x⁵+x⁴+1)

```c
sht30_t sht30_read(i2c_port_t port) {
    sht30_t result;
    uint8_t cmd[2] = {0x24, 0x00};  // 高重复性单次测量
    uint8_t data[6];

    i2c_master_write_to_device(port, 0x44, cmd, 2, 100);
    vTaskDelay(pdMS_TO_TICKS(20));
    i2c_master_read_from_device(port, 0x44, data, 6, 100);

    uint16_t temp_raw = (data[0] << 8) | data[1];
    uint16_t hum_raw  = (data[3] << 8) | data[4];

    result.temperature = -45 + 175 * (float)temp_raw / 65535;
    result.humidity    = 100 * (float)hum_raw / 65535;
    return result;
}
```

#### BMP280

| 参数 | 值 |
|------|-----|
| 接口 | I2C(0x76/0x77) / SPI |
| 气压范围 | 300~1100hPa |
| 气压精度 | ±1hPa |
| 温度范围 | -40~85°C |
| 温度精度 | ±1°C |
| 分辨率 | 0.01hPa / 0.01°C |

**补偿计算**（需读取校准参数）：
```c
// 整数版本（BMP280数据手册推荐）
int32_t bmp280_compensate_temp(int32_t adc_T, bmp280_cal_t *cal) {
    int32_t var1 = ((((adc_T >> 3) - ((int32_t)cal->dig_T1 << 1)))
                    * ((int32_t)cal->dig_T2)) >> 11;
    int32_t var2 = (((((adc_T >> 4) - ((int32_t)cal->dig_T1))
                    * ((adc_T >> 4) - ((int32_t)cal->dig_T1))) >> 12)
                    * ((int32_t)cal->dig_T3)) >> 14;
    cal->t_fine = var1 + var2;
    return (cal->t_fine * 5 + 128) >> 8;  // 0.01°C单位
}
```

## 三、压力传感器

### 3.1 压阻式压力传感器

#### 原理
- 基于压阻效应：材料受力时电阻变化
- 硅膜片+扩散电阻构成惠斯通电桥
- 压力→膜片形变→电阻变化→电压输出

#### 特点
- 灵敏度高，mV级输出
- 线性度好（<±0.25%FS）
- 需要放大电路（仪表放大器如INA125、AD620）
- 温度补偿必不可少

#### 惠斯通电桥
```
       VCC
        │
    [R1] [R2]
        │  ├─ Vout+
        │  │
    [R3] [R4]
        │
       GND

Vout = VCC × (R1·R4 - R2·R3) / (R1+R3)(R2+R4)
```

### 3.2 电容式压力传感器

- 原理：压力改变极板间距，电容变化
- `C = ε₀·εᵣ·A / d`
- 优点：功耗低、温度稳定性好
- 缺点：需要复杂的信号调理电路

### 3.3 MEMS压力传感器

#### 制造工艺
- 硅微机械加工：刻蚀形成薄硅膜片
- 集成信号调理、ADC、温度补偿于单芯片
- 封装尺寸小（3mm×3mm QFN）

#### BMP280详细使用

**工作模式**：
| 模式 | 说明 |
|------|------|
| Sleep | 不进行测量 |
| Forced | 一次测量后进入Sleep |
| Normal | 周期性自动测量 |

**过采样设置**：
| osrs_t / osrs_p | 过采样 | 分辨率 |
|-----------------|--------|--------|
| 000 | 跳过 | - |
| 001 | ×1 | 16bit/2.62Pa |
| 010 | ×2 | 17bit/1.31Pa |
| 011 | ×4 | 18bit/0.66Pa |
| 100 | ×8 | 19bit/0.33Pa |
| 101 | ×16 | 20bit/0.16Pa |

**IIR滤波器系数**：
| filter | 系数 | 响应时间(75%) |
|--------|------|--------------|
| 000 | Off | 0ms |
| 001 | 2 | 0.22s |
| 010 | 4 | 0.45s |
| 011 | 8 | 0.9s |
| 100 | 16 | 1.8s |

**完整初始化代码**：
```c
esp_err_t bmp280_init(i2c_port_t port) {
    uint8_t id;
    i2c_read_reg(port, 0x76, 0xD0, &id, 1);
    if (id != 0x58) return ESP_ERR_NOT_FOUND;

    // 配置：温度×2过采样，气压×16过采样，Normal模式
    uint8_t ctrl_meas = (0x02 << 5) | (0x05 << 2) | 0x03;
    i2c_write_reg(port, 0x76, 0xF4, &ctrl_meas, 1);

    // 配置：待机500ms，IIR滤波系数16
    uint8_t config = (0x04 << 5) | (0x04 << 2);
    i2c_write_reg(port, 0x76, 0xF5, &config, 1);

    // 读取校准参数（共26字节）
    i2c_read_reg(port, 0x76, 0x88, (uint8_t *)&cal_data, 26);

    return ESP_OK;
}
```

## 四、加速度与陀螺仪

### 4.1 MEMS加速度计原理

#### 电容式MEMS
- 结构：固定极板 + 可动质量块（弹簧悬挂）
- 加速度→质量块位移→电容变化
- 两个差分电容消除共模干扰

```
  固定极板          可动质量块          固定极板
  |||||||    ←──d──→   ████   ←──d──→   |||||||
                       │
                    弹簧连接
                       │
                    固定基座
```

#### 灵敏度与量程
| 量程 | 灵敏度(16-bit) | 应用 |
|------|----------------|------|
| ±2g | 16384 LSB/g | 倾斜检测 |
| ±4g | 8192 LSB/g | 手势识别 |
| ±8g | 4096 LSB/g | 运动检测 |
| ±16g | 2048 LSB/g | 冲击检测 |

#### 自由落体检测
```c
// 检测总加速度是否接近0g
float total_accel = sqrt(ax*ax + ay*ay + az*az);
bool free_fall = (total_accel < FREE_FALL_THRESHOLD);  // 通常0.3g~0.5g
```

### 4.2 MEMS陀螺仪原理

#### 科里奥利效应
- 振动质量块在旋转参考系中受科里奥利力
- `F_coriolis = -2m(Ω × v)`
- 力导致垂直方向位移，被电容检测

#### 角速度测量
- 输出单位：°/s 或 rad/s
- 典型量程：±250/500/1000/2000°/s
- 零偏漂移：需要校准补偿

#### 陀螺仪积分与漂移
```
角度 = ∫角速度·dt
```
- 陀螺仪积分会累积漂移（零偏误差）
- 长时间积分不可靠，需要加速度计辅助修正

### 4.3 MPU6050

#### 规格

| 参数 | 值 |
|------|-----|
| 接口 | I2C(0x68/0x69) |
| 加速度量程 | ±2/4/8/16g |
| 陀螺仪量程 | ±250/500/1000/2000°/s |
| ADC | 16位 |
| 采样率 | 最高1kHz |
| DMP | 内置数字运动处理器 |
| VDD | 2.375~3.46V |

#### 寄存器映射

| 地址 | 名称 | 说明 |
|------|------|------|
| 0x6B | PWR_MGMT_1 | 电源管理 |
| 0x19 | SMPLRT_DIV | 采样率分频 |
| 0x1B | GYRO_CONFIG | 陀螺仪配置 |
| 0x1C | ACCEL_CONFIG | 加速度计配置 |
| 0x3B | ACCEL_XOUT_H | 加速度数据起始 |
| 0x43 | GYRO_XOUT_H | 陀螺仪数据起始 |

#### 初始化代码
```c
void mpu6050_init(i2c_port_t port, uint8_t addr) {
    // 唤醒
    uint8_t data = 0x00;
    i2c_write_reg(port, addr, 0x6B, &data, 1);

    // 采样率 = 1kHz / (1+9) = 100Hz
    data = 0x09;
    i2c_write_reg(port, addr, 0x19, &data, 1);

    // 陀螺仪 ±500°/s
    data = 0x08;
    i2c_write_reg(port, addr, 0x1B, &data, 1);

    // 加速度计 ±4g
    data = 0x08;
    i2c_write_reg(port, addr, 0x1C, &data, 1);

    // DLPF 低通滤波 带宽44Hz
    data = 0x03;
    i2c_write_reg(port, addr, 0x1A, &data, 1);
}

typedef struct {
    float ax, ay, az;  // g
    float gx, gy, gz;  // °/s
    float temperature;  // °C
} mpu6050_data_t;

mpu6050_data_t mpu6050_read(i2c_port_t port, uint8_t addr) {
    uint8_t buf[14];
    mpu6050_data_t d;
    i2c_read_reg(port, addr, 0x3B, buf, 14);

    int16_t raw_ax = (buf[0] << 8) | buf[1];
    int16_t raw_ay = (buf[2] << 8) | buf[3];
    int16_t raw_az = (buf[4] << 8) | buf[5];
    int16_t raw_temp = (buf[6] << 8) | buf[7];
    int16_t raw_gx = (buf[8] << 8) | buf[9];
    int16_t raw_gy = (buf[10] << 8) | buf[11];
    int16_t raw_gz = (buf[12] << 8) | buf[13];

    d.ax = raw_ax / 8192.0f;  // ±4g
    d.ay = raw_ay / 8192.0f;
    d.az = raw_az / 8192.0f;
    d.gx = raw_gx / 65.5f;    // ±500°/s
    d.gy = raw_gy / 65.5f;
```

### 4.5 九轴融合算法

#### 问题
- 陀螺仪：短期精确，长期漂移
- 加速度计：长期稳定，短期振动噪声大
- 磁力计：提供航向，受干扰

#### 互补滤波（简单实用）
```c
#define ALPHA 0.98  // 陀螺仪权重

typedef struct {
    float roll, pitch, yaw;
} euler_t;

euler_t complementary_filter(float ax, float ay, float az,
                              float gx, float gy, float gz,
                              float mx, float my, float mz,
                              euler_t prev, float dt) {
    euler_t angle;

    // 加速度计求roll和pitch
    float acc_roll  = atan2(ay, az);
    float acc_pitch = atan2(-ax, sqrt(ay*ay + az*az));

    // 陀螺仪积分 + 加速度计修正
    angle.roll  = ALPHA * (prev.roll  + gx * dt) + (1-ALPHA) * acc_roll;
    angle.pitch = ALPHA * (prev.pitch + gy * dt) + (1-ALPHA) * acc_pitch;

    // 磁力计求yaw（需要pitch和roll补偿）
    float mx_comp = mx * cos(angle.pitch) + mz * sin(angle.pitch);
    float my_comp = mx * sin(angle.roll) * sin(angle.pitch)
                  + my * cos(angle.roll)
                  - mz * sin(angle.roll) * cos(angle.pitch);
    angle.yaw = atan2(-my_comp, mx_comp);

    return angle;
}
```

#### Madgwick滤波器
- 基于梯度下降法的四元数姿态估计
- 计算量小，适合嵌入式
- 参数β控制收敛速度

#### Mahony滤波器
- PI控制器形式

#### 卡尔曼滤波

## 六、超声波与ToF测距

### 6.1 HC-SR04超声波模块

#### 规格

| 参数 | 值 |
|------|-----|
| 工作电压 | 5V |
| 静态电流 | <2mA |
| 测量范围 | 2cm~400cm |
| 精度 | ±3mm |
| 分辨率 | 1mm |
| 角度 | <15° |
| 触发脉冲 | ≥10μs高电平 |
| 回波信号 | 高电平时间∝距离 |

#### 工作原理
```
1. Trig引脚发送 ≥10μs 高电平脉冲
2. 模块自动发送8个40kHz超声波脉冲
3. 等待回波，Echo引脚输出高电平
4. 高电平持续时间 = 声波往返时间
5. 距离 = 持续时间 × 声速 / 2
```

#### 计算公式
```
距离(cm) = Echo高电平时间(μs) × 0.034 / 2
         = Echo高电平时间(μs) / 58
```

#### 驱动代码（ESP32 RMT）
```c
float hcsr04_measure(gpio_num_t trig_pin, gpio_num_t echo_pin) {
    // 发送触发脉冲
    gpio_set_direction(trig_pin, GPIO_MODE_OUTPUT);
    gpio_set_level(trig_pin, 0);
    ets_delay_us(2);
    gpio_set_level(trig_pin, 1);
    ets_delay_us(10);
    gpio_set_level(trig_pin, 0);

    // 测量回波时间
    gpio_set_direction(echo_pin, GPIO_MODE_INPUT);

    int64_t start = esp_timer_get_time();
    while (gpio_get_level(echo_pin) == 0) {
        if (esp_timer_get_time() - start > 30000) return -1;  // 超时
    }
    int64_t echo_start = esp_timer_get_time();

    while (gpio_get_level(echo_pin) == 1) {
        if (esp_timer_get_time() - echo_start > 30000) return -1;
    }
    int64_t echo_end = esp_timer_get_time();

    float duration_us = echo_end - echo_start;
    return duration_us * 0.034f / 2.0f;  // cm
}
```

#### 注意事项
- 温度补偿：声速随温度变化 `v = 331.3 + 0.606 × T(°C)`
- 最小测量距离2cm（盲区）
- 多个超声波模块需要分时工作（避免串扰）
- 软质物体（布料、海绵）吸收声波，测不到

```c
    if (len < 32) return false;
    if (buf[0] != 0x42 || buf[1] != 0x4D) return false;

    data->pm1_0_atm = (buf[10] << 8) | buf[11];
    data->pm2_5_atm = (buf[12] << 8) | buf[13];
    data->pm10_atm  = (buf[14] << 8) | buf[15];
    // ... 解析其他字段

    return true;
}
```

### 10.1 模拟输出→ADC

#### ADC基础知识

| 参数 | 说明 |
|------|------|

| 采样率 | 每秒采样次数（SPS） |

#### ESP32 ADC特性
- ADC1：8通道（GPIO32-39）
- ADC2：10通道（受WiFi影响）
- 12位分辨率（0-4095）
- 非线性较大，建议校准

#### 信号调理电路

**分压器**：
```
传感器输出(0-5V) ──[R1]──┬── ADC(0-3.3V)
                          │
                         [R2]
                          │
                         GND

V_adc = V_sensor × R2 / (R1 + R2)
R1 = 5.1kΩ, R2 = 10kΩ → 3.3V/5.1V ≈ 0.65 (适合5V→3.3V)
```

**运算放大器**：
- 仪表放大器：差分转单端，高共模抑制比
- 运放偏置：将双极性信号偏置到ADC输入范围中点

**低通滤波**：
```
传感器 ──[R]──┬── ADC
               │
              [C]
               │
              GND

fc = 1 / (2π × R × C)
```

#### 两点校准

```c
// 已知两个标准点(x1,y1)和(x2,y2)
typedef struct {
    float slope;
    float offset;
} calibration_t;

calibration_t two_point_cal(float x1, float y1, float x2, float y2) {
    calibration_t cal;
    cal.slope = (y2 - y1) / (x2 - x1);
    cal.offset = y1 - cal.slope * x1;
    return cal;
}

float apply_calibration(float raw, calibration_t *cal) {

}
```

#### 多点校准（查表+插值）

```c
#define CAL_POINTS 5
float cal_x[CAL_POINTS] = {0, 25, 50, 75, 100};  // 标准值
float cal_y[CAL_POINTS] = {0.2, 25.3, 49.8, 75.5, 100.1};  // 测量值

float interpolate(float raw, float *x, float *y, int n) {
    if (raw <= x[0]) return y[0];
    if (raw >= x[n-1]) return y[n-1];

    for (int i = 0; i < n-1; i++) {
        if (raw >= x[i] && raw <= x[i+1]) {
            float t = (raw - x[i]) / (x[i+1] - x[i]);
            return y[i] + t * (y[i+1] - y[i]);
        }
    }
    return raw;
}
```

### 11.2 滤波

#### 移动平均滤波
```c
#define WINDOW_SIZE 16

typedef struct {
    float buffer[WINDOW_SIZE];
    int index;
    float sum;
    int count;
} moving_avg_t;

float moving_average(moving_avg_t *f, float new_val) {
    if (f->count >= WINDOW_SIZE) {
        f->sum -= f->buffer[f->index];
    }
    f->buffer[f->index] = new_val;
    f->sum += new_val;
    f->index = (f->index + 1) % WINDOW_SIZE;
    if (f->count < WINDOW_SIZE) f->count++;
    return f->sum / f->count;
}
```

#### 中值滤波（去除脉冲噪声）
```c
float median_filter(float *buf, int size) {
    // 简单冒泡排序（窗口小时可接受）
    for (int i = 0; i < size-1; i++) {
        for (int j = 0; j < size-i-1; j++) {
            if (buf[j] > buf[j+1]) {
                float temp = buf[j];
                buf[j] = buf[j+1];
                buf[j+1] = temp;
            }
        }
    }
    return buf[size/2];
}
```

#### 一阶IIR低通滤波
```c
typedef struct {
    float alpha;     // 滤波系数 0~1
    float filtered;  // 当前滤波值
    bool initialized;
} lowpass_iir_t;

float lowpass_filter(lowpass_iir_t *f, float input) {
    if (!f->initialized) {
        f->filtered = input;
        f->initialized = true;
        return input;
    }
    f->filtered = f->alpha * input + (1 - f->alpha) * f->filtered;
    return f->filtered;
}

// alpha计算: alpha = dt / (RC + dt)
// RC = 1/(2π×fc)，fc为截止频率
```

### 11.3 卡尔曼滤波

#### 基本原理
- 融合预测（模型）和观测（传感器）
- 最小化估计误差协方差
- 递推计算，不需要存储历史数据

#### 一维卡尔曼滤波
```c
typedef struct {
    float x;    // 状态估计值
    float P;    // 估计误差协方差
    float Q;    // 过程噪声（模型不确定度）
    float R;    // 测量噪声（传感器不确定度）
    float K;    // 卡尔曼增益
} kalman1d_t;

float kalman_update(kalman1d_t *k, float measurement) {
    // 预测
    // x_predict = x (简单模型：状态不变)
    // P_predict = P + Q
    k->P += k->Q;

    // 更新
    k->K = k->P / (k->P + k->R);
    k->x = k->x + k->K * (measurement - k->x);
    k->P = (1 - k->K) * k->P;

    return k->x;
}

// 使用示例
kalman1d_t temp_filter = {
    .x = 0,
    .P = 1,
    .Q = 0.01,  // 过程噪声，根据系统调整
    .R = 0.1,   // 测量噪声，根据传感器精度调整
};
```

#### 扩展卡尔曼滤波（EKF）
- 用于非线性系统
- 在当前状态点线性化（雅可比矩阵）
- 用于IMU姿态估计、GPS/INS组合导航

```c
// 伪代码框架
void ekf_predict(float *x, float *P, float *u, float dt) {
    // 1. 状态预测: x = f(x, u, dt)
    // 2. 雅可比矩阵 F = ∂f/∂x
    // 3. 协方差预测: P = F·P·Fᵀ + Q
}

void ekf_update(float *x, float *P, float *z) {
    // 1. 观测预测: z_pred = h(x)
    // 2. 雅可比矩阵 H = ∂h/∂x
    // 3. 新息: y = z - z_pred
    // 4. 新息协方差: S = H·P·Hᵀ + R
    // 5. 卡尔曼增益: K = P·Hᵀ·S⁻¹
    // 6. 状态更新: x = x + K·y
    // 7. 协方差更新: P = (I - K·H)·P
}
```

### 11.4 互补滤波

```c
// 陀螺仪 + 加速度计互补滤波
typedef struct {
    float angle;
    float alpha;  // 陀螺仪权重，通常0.95~0.99
} complementary_t;

float complementary_update(complementary_t *f, float gyro_rate,
                           float accel_angle, float dt) {
    // 陀螺仪短期可信 + 加速度计长期可信
    f->angle = f->alpha * (f->angle + gyro_rate * dt)
             + (1 - f->alpha) * accel_angle;
    return f->angle;
}
```

#### 加权平均融合
```c
// 多传感器加权平均
float weighted_fusion(float *values, float *weights, int n) {
    float sum_val = 0, sum_weight = 0;
    for (int i = 0; i < n; i++) {
        sum_val += values[i] * weights[i];
        sum_weight += weights[i];
    }
```

#### 温度融合示例
```c
// 融合DS18B20（精确但慢）和NTC（快但噪声大）
typedef struct {
    kalman1d_t kalman;
    float ds18b20_temp;
    bool ds18b20_valid;
    uint32_t last_ds18b20_time;
} temp_fusion_t;

float temp_fusion_update(temp_fusion_t *f, float ntc_temp,
                          float ds18b20_temp, bool ds18b20_new,
                          uint32_t now) {

        f->ds18b20_temp = ds18b20_temp;
        f->ds18b20_valid = true;
        f->last_ds18b20_time = now;
        // DS18B20精确，降低测量噪声

    // 用卡尔曼滤波融合
    return kalman_update(&f->kalman, ntc_temp);
}
```

#### 异常值检测
```c
typedef struct {
    float mean;
    float variance;
    int count;
} stats_t;

bool is_outlier(stats_t *s, float value, float threshold) {
    if (s->count < 10) {
        // 收集阶段，直接接受
        s->mean = (s->mean * s->count + value) / (s->count + 1);
        s->count++;
        return false;
    }

    float deviation = fabs(value - s->mean);
    float stddev = sqrt(s->variance);

    if (deviation > threshold * stddev) {
        return true;  // 异常值
    }

    // 更新统计（指数移动平均）
    s->mean = 0.95f * s->mean + 0.05f * value;
    s->variance = 0.95f * s->variance + 0.05f * deviation * deviation;
    return false;
}
```
