# 通信协议学习总览

> 从最常见的串行外设通信开始，再进入现场总线和应用层协议。

| 顺序 | 笔记 | 学会什么 |
|---:|---|---|
| 01 | [[UART串口通信]] | 异步串行通信的帧和收发。 |
| 02 | [[I2C通信]] | 两线同步总线的寻址与时序。 |
| 03 | [[SPI通信]] | 高速同步串行通信。 |
| 04 | [[RS-232]] | 单端串行接口的特点。 |
| 05 | [[RS-485]] | 差分物理层和总线布线。 |
| 06 | [[Modbus]] | 工业设备的常用应用层协议。 |
| 07 | [[CAN总线]] | 仲裁、报文和车载/工业总线。 |

## 最短总结

- UART、I2C、SPI 主要解决板内或近距离外设通信。
- RS-232 与 RS-485 是物理层接口，不等于完整业务协议。
- Modbus 与 CAN 用于不同场景，选择前要分清物理层、链路层和应用层。
