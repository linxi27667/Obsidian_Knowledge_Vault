# 开发工具学习总览

> 用于建立本地开发、构建、自动化和容器化的基本工具链。

| 顺序 | 笔记 | 学会什么 |
|---:|---|---|
| 01 | [[Shell编程详解]] | 用命令行完成重复工作。 |
| 02 | [[Makefile与CMake详解]] | 管理 C/C++ 工程的构建。 |
| 03 | [[Docker容器化详解]] | 用容器统一开发和部署环境。 |
| 04 | [[CI-CD详解]] | 自动化测试、构建和发布。 |

## 最短总结

- Shell 是自动化操作的基础。
- CMake 或 Makefile 负责把源码稳定地构建成产物。
- Docker 解决环境一致性，CI/CD 把验证和发布流程自动化。
