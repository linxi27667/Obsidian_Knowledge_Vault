## 一、高等数学

### 1.1 函数与极限

**函数性质：**
- 有界性
- 单调性
- 奇偶性
- 周期性

**极限计算：**
$$\lim_{x \to a} f(x) = L$$

**常用极限：**
$$\lim_{x \to 0} \frac{\sin x}{x} = 1$$
$$\lim_{x \to 0} \frac{1 - \cos x}{x^2} = \frac{1}{2}$$
$$\lim_{x \to \infty} (1 + \frac{1}{x})^x = e$$

**洛必达法则：**
$$\lim_{x \to a} \frac{f(x)}{g(x)} = \lim_{x \to a} \frac{f'(x)}{g'(x)}$$

---

### 1.2 导数与微分

**导数定义：**
$$f'(x) = \lim_{h \to 0} \frac{f(x+h) - f(x)}{h}$$

**基本导数：**
| 函数 | 导数 |
|------|------|
| $x^n$ | $nx^{n-1}$ |
| $e^x$ | $e^x$ |
| $\ln x$ | $\frac{1}{x}$ |
| $\sin x$ | $\cos x$ |
| $\cos x$ | $-\sin x$ |
| $\tan x$ | $\sec^2 x$ |

**求导法则：**
$$(u + v)' = u' + v'$$
$$(uv)' = u'v + uv'$$
$$\left(\frac{u}{v}\right)' = \frac{u'v - uv'}{v^2}$$
$$[f(g(x))]' = f'(g(x)) \cdot g'(x)$$

---

### 1.3 中值定理

**罗尔定理：**
若 $f(a) = f(b)$，则存在 $\xi \in (a,b)$ 使得 $f'(\xi) = 0$

**拉格朗日中值定理：**
$$f(b) - f(a) = f'(\xi)(b - a)$$

**柯西中值定理：**
$$\frac{f(b) - f(a)}{g(b) - g(a)} = \frac{f'(\xi)}{g'(\xi)}$$

**泰勒公式：**
$$f(x) = f(a) + f'(a)(x-a) + \frac{f''(a)}{2!}(x-a)^2 + \cdots + \frac{f^{(n)}(a)}{n!}(x-a)^n + R_n(x)$$

---

### 1.4 积分

**不定积分：**
$$\int x^n dx = \frac{x^{n+1}}{n+1} + C$$
$$\int e^x dx = e^x + C$$
$$\int \frac{1}{x} dx = \ln|x| + C$$
$$\int \sin x dx = -\cos x + C$$
$$\int \cos x dx = \sin x + C$$

**定积分：**
$$\int_a^b f(x) dx = F(b) - F(a)$$

**积分方法：**
- 换元积分法
- 分部积分法
- 有理函数积分

**分部积分：**
$$\int u dv = uv - \int v du$$

---

### 1.5 微分方程

**一阶微分方程：**
- 可分离变量
- 齐次方程
- 一阶线性方程

**一阶线性方程：**
$$y' + P(x)y = Q(x)$$
$$y = e^{-\int P dx} \left( \int Q e^{\int P dx} dx + C \right)$$

**二阶常系数线性方程：**
$$y'' + py' + qy = 0$$

特征方程：$r^2 + pr + q = 0$

| 判别式 | 通解 |
|--------|------|
| $\Delta > 0$ | $y = C_1 e^{r_1 x} + C_2 e^{r_2 x}$ |
| $\Delta = 0$ | $y = (C_1 + C_2 x) e^{rx}$ |
| $\Delta < 0$ | $y = e^{\alpha x}(C_1 \cos \beta x + C_2 \sin \beta x)$ |

---

### 1.6 多元函数

**偏导数：**
$$\frac{\partial z}{\partial x} = \lim_{\Delta x \to 0} \frac{f(x+\Delta x, y) - f(x, y)}{\Delta x}$$

**全微分：**
$$dz = \frac{\partial z}{\partial x} dx + \frac{\partial z}{\partial y} dy$$

**链式法则：**
$$\frac{dz}{dt} = \frac{\partial z}{\partial x} \frac{dx}{dt} + \frac{\partial z}{\partial y} \frac{dy}{dt}$$

**极值：**
$$\frac{\partial f}{\partial x} = 0, \quad \frac{\partial f}{\partial y} = 0$$

---

### 1.7 重积分

**二重积分：**
$$\iint_D f(x,y) dA$$

**极坐标：**
$$\iint_D f(r\cos\theta, r\sin\theta) r dr d\theta$$

**三重积分：**
$$\iiint_\Omega f(x,y,z) dV$$

---

### 1.8 曲线积分与曲面积分

**第一类曲线积分：**
$$\int_L f(x,y) ds$$

**第二类曲线积分：**
$$\int_L P dx + Q dy$$

**格林公式：**
$$\oint_L P dx + Q dy = \iint_D \left( \frac{\partial Q}{\partial x} - \frac{\partial P}{\partial y} \right) dA$$

---

## 二、线性代数

### 2.1 行列式

**性质：**
- 行列互换，值不变
- 某行乘以k，值乘以k
- 某行加上另一行的k倍，值不变

**计算：**
$$\begin{vmatrix} a & b \\ c & d \end{vmatrix} = ad - bc$$

**展开：**
$$|A| = \sum_{j=1}^n (-1)^{i+j} a_{ij} M_{ij}$$

---

### 2.2 矩阵

**矩阵运算：**
$$(A + B)_{ij} = a_{ij} + b_{ij}$$
$$(AB)_{ij} = \sum_k a_{ik} b_{kj}$$

**逆矩阵：**
$$A^{-1} = \frac{1}{|A|} A^*$$

**秩：** 矩阵中非零子式的最高阶数

---

### 2.3 向量

**线性相关：**
存在不全为零的数使得 $\sum k_i \alpha_i = 0$

**线性无关：**
只有当所有 $k_i = 0$ 时才有 $\sum k_i \alpha_i = 0$

**向量空间：** 向量的集合，对加法和数乘封闭

---

### 2.4 线性方程组

**齐次方程组：** $Ax = 0$
- 有非零解 $\Leftrightarrow$ $|A| = 0$
- 基础解系：$n - r(A)$ 个线性无关解

**非齐次方程组：** $Ax = b$
- 有解 $\Leftrightarrow$ $r(A) = r(A|b)$
- 唯一解 $\Leftrightarrow$ $r(A) = n$

---

### 2.5 特征值与特征向量

**定义：**
$$Ax = \lambda x$$

**特征方程：**
$$|A - \lambda E| = 0$$

**性质：**
$$\sum \lambda_i = \text{tr}(A)$$
$$\prod \lambda_i = |A|$$

**相似对角化：**
$$P^{-1}AP = \Lambda$$

---

### 2.6 二次型

**标准形：**
$$f = \sum a_i x_i^2$$

**正定：**
所有特征值大于零

**惯性定理：** 正惯性指数、负惯性指数不变

---

## 三、概率论

### 3.1 随机事件

**概率性质：**
$$0 \leq P(A) \leq 1$$
$$P(\Omega) = 1$$
$$P(A \cup B) = P(A) + P(B) - P(A \cap B)$$

**条件概率：**
$$P(A|B) = \frac{P(AB)}{P(B)}$$

**全概率公式：**
$$P(A) = \sum_{i=1}^n P(B_i) P(A|B_i)$$

**贝叶斯公式：**
$$P(B_i|A) = \frac{P(B_i) P(A|B_i)}{\sum_j P(B_j) P(A|B_j)}$$

---

### 3.2 随机变量

**分布函数：**
$$F(x) = P(X \leq x)$$

**离散分布：**
| 分布 | 概率 | 期望 | 方差 |
|------|------|------|------|
| 二项分布 $B(n,p)$ | $C_n^k p^k (1-p)^{n-k}$ | $np$ | $np(1-p)$ |
| 泊松分布 $P(\lambda)$ | $\frac{\lambda^k e^{-\lambda}}{k!}$ | $\lambda$ | $\lambda$ |

**连续分布：**
| 分布 | 密度 | 期望 | 方差 |
|------|------|------|------|
| 均匀分布 $U(a,b)$ | $\frac{1}{b-a}$ | $\frac{a+b}{2}$ | $\frac{(b-a)^2}{12}$ |
| 指数分布 $E(\lambda)$ | $\lambda e^{-\lambda x}$ | $\frac{1}{\lambda}$ | $\frac{1}{\lambda^2}$ |
| 正态分布 $N(\mu,\sigma^2)$ | $\frac{1}{\sqrt{2\pi}\sigma} e^{-\frac{(x-\mu)^2}{2\sigma^2}}$ | $\mu$ | $\sigma^2$ |

---

### 3.3 多维随机变量

**联合分布：**
$$F(x,y) = P(X \leq x, Y \leq y)$$

**边缘分布：**
$$F_X(x) = F(x, +\infty)$$

**独立性：**
$$F(x,y) = F_X(x) \cdot F_Y(y)$$

---

### 3.4 数字特征

**期望：**
$$E(X) = \sum x_i p_i$$
$$E(X) = \int x f(x) dx$$

**方差：**
$$D(X) = E(X^2) - [E(X)]^2$$

**协方差：**
$$\text{Cov}(X,Y) = E(XY) - E(X)E(Y)$$

**相关系数：**
$$\rho = \frac{\text{Cov}(X,Y)}{\sqrt{D(X)}\sqrt{D(Y)}}$$

---

### 3.5 大数定律与中心极限定理

**大数定律：**
$$\bar{X}_n \xrightarrow{P} \mu$$

**中心极限定理：**
$$\frac{\bar{X}_n - \mu}{\sigma/\sqrt{n}} \xrightarrow{d} N(0,1)$$
