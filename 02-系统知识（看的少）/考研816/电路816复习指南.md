## 二、电路模型与基本定律

### 2.1 重点考点

**必须掌握：**
- 欧姆定律
- KCL（基尔霍夫电流定律）
- KVL（基尔霍夫电压定律）
- 功率计算
- 电压源、电流源模型

---

### 2.2 典型题型

**题型1：功率计算**
```
已知电路如图，求各元件吸收的功率。

解题步骤：
1. 设定参考方向
2. 计算电流/电压
3. 计算功率 P = UI
4. 判断吸收/发出
```

**题型2：电源等效变换**
```
电压源串联电阻 ↔ 电流源并联电阻

Us = Is × Rs
```

---

### 2.3 解题技巧

1. **画图** - 标出参考方向
2. **设变量** - 设定未知量
3. **列方程** - KCL/KVL
4. **验算** - 功率守恒

## 三、电路分析方法

### 3.1 网孔分析法

**步骤：**
1. 设定网孔电流（顺时针）
2. 列写KVL方程
3. 联立求解

**方程形式：**
```
R11*I1 - R12*I2 = Us1
-R21*I1 + R22*I2 = Us2
```

**示例：**
```
    R1        R2
 ┌──┤├──┬──┤├──┐
 │      │      │
(+Us1)  R3   (+Us2)
 │      │      │
 └──────┴──────┘

网孔1: (R1+R3)*I1 - R3*I2 = Us1
网孔2: -R3*I1 + (R2+R3)*I2 = -Us2
```

---

### 3.2 节点分析法

**步骤：**
1. 选择参考节点
2. 设定节点电压
3. 列写KCL方程
4. 联立求解

**方程形式：**
```
G11*V1 - G12*V2 = Is1
-G21*V1 + G22*V2 = Is2
```

**示例：**
```
       R1
  ┌──┤├──┐
  │      │
(+Is)    R2      (参考节点)
  │      │
  └──────┴──── V1

节点V1: (1/R1 + 1/R2)*V1 = Is
```

---

### 3.3 叠加定理

**步骤：**
1. 保留一个电源
2. 其他电源置零
   - 电压源短路
   - 电流源开路
3. 计算各支路电流
4. 代数叠加

**注意：** 只适用于线性电路

---

### 3.4 戴维南定理

**步骤：**
1. 断开待求支路
2. 计算开路电压 Uoc
3. 计算等效电阻 Req
4. 画等效电路求解

**等效电路：**
```
    Req
 ┌──┤├──┐
 │      │
(+Uoc)  RL
 │      │
 └──────┘
```

---

### 3.5 诺顿定理

**等效电路：**
```
 ┌─────────────┐
 │      Req    │
(+Isc) ──┤├── RL
 │             │
 └─────────────┘
```

**关系：**
$$U_{oc} = I_{sc} \times R_{eq}$$

## 四、正弦稳态分析

### 4.1 正弦量表示

**时域：**
$$u(t) = U_m \sin(\omega t + \phi)$$

**相量：**
$$\dot{U} = U \angle \phi$$

**转换：**
$$U_m = \sqrt{2} U$$

---

### 4.2 阻抗与导纳

**阻抗：**
$$Z = R + jX = |Z|\angle\phi$$

| 元件 | 阻抗 |
|------|------|
| R | R |
| L | jωL |
| C | 1/(jωC) |

**导纳：**
$$Y = G + jB = \frac{1}{Z}$$

---

### 4.3 相量法分析

**步骤：**
1. 时域 → 相量域
2. 画相量模型
3. 列相量方程
4. 求解相量
5. 相量域 → 时域

**示例：**
```
已知：u(t) = 10√2 sin(ωt + 30°) V, Z = 5∠45° Ω
求：i(t)

解：
U = 10∠30° V
I = U/Z = 10∠30° / 5∠45° = 2∠-15° A
i(t) = 2√2 sin(ωt - 15°) A
```

---

### 4.4 功率计算

**有功功率：**
$$P = UI\cos\phi$$

**无功功率：**
$$Q = UI\sin\phi$$

**视在功率：**
$$S = UI$$

**功率因数：**
$$\cos\phi = \frac{P}{S}$$

**功率三角形：**
```
    S (VA)
    │\
    │ \
  Q │  \ P (W)
    │   \
    └────
```

---

### 4.5 最大功率传输

**条件：**
$$Z_L = Z_s^*$$

**最大功率：**
$$P_{max} = \frac{U_s^2}{4R_s}$$

---

## 五、三相电路

### 5.1 三相电源

**相电压：**
$$u_A = U_p \sin(\omega t)$$
$$u_B = U_p \sin(\omega t - 120°)$$
$$u_C = U_p \sin(\omega t + 120°)$$

**线电压与相电压：**
$$U_L = \sqrt{3} U_P$$

---

### 5.2 三相负载

**星形连接：**
```
UL = √3 UP
IL = IP
P = 3UPIPcosφ
```

**三角形连接：**
```
UL = UP
IL = √3 IP
P = √3ULILcosφ
```

---

### 5.3 三相功率测量

**两瓦特计法：**
```
Ptotal = W1 + W2
```

**适用：** 三相三线制

---

## 六、动态电路

### 6.1 一阶电路

**RC电路时间常数：**
$$\tau = RC$$

**RL电路时间常数：**
$$\tau = \frac{L}{R}$$

---

### 6.2 三要素法

**公式：**
$$f(t) = f(\infty) + [f(0^+) - f(\infty)]e^{-t/\tau}$$

**三要素：**
1. f(0⁺) - 初始值
2. f(∞) - 稳态值
3. τ - 时间常数

**解题步骤：**
1. 求初始值：换路前电路
2. 求稳态值：换路后稳态
3. 求时间常数：换路后等效电阻
4. 代入公式

---

### 6.3 零输入响应

**RC放电：**
$$u_C(t) = U_0 e^{-t/RC}$$

**RL放电：**
$$i_L(t) = I_0 e^{-Rt/L}$$

---

### 6.4 零状态响应

**RC充电：**
$$u_C(t) = U_s(1 - e^{-t/RC})$$

**RL充电：**
$$i_L(t) = \frac{U_s}{R}(1 - e^{-Rt/L})$$

---

### 6.5 全响应

$$全响应 = 零输入响应 + 零状态响应$$

或：

$$全响应 = 暂态分量 + 稳态分量$$

---

## 七、频率响应

### 7.1 网络函数

$$H(j\omega) = \frac{输出}{输入}$$

**幅频特性：**
$$|H(j\omega)|$$

**相频特性：**
$$\phi(\omega) = \arg[H(j\omega)]$$

---

### 7.2 谐振

**串联谐振：**
$$\omega_0 = \frac{1}{\sqrt{LC}}$$

**特点：**
- 阻抗最小：Z = R
- 电流最大
- 功率因数 = 1

**并联谐振：**
$$\omega_0 = \frac{1}{\sqrt{LC}}$$

**特点：**
- 阻抗最大
- 电流最小

---

### 7.3 滤波器

**低通滤波器：**
$$H(j\omega) = \frac{1}{1 + j\omega RC}$$

**截止频率：**
$$f_c = \frac{1}{2\pi RC}$$

**波特图：**
- 通带：f < fc
- 阻带：f > fc
- 衰减：-20dB/dec

---

## 八、二端口网络

### 8.1 Z参数

$$\begin{bmatrix} U_1 \\ U_2 \end{bmatrix} = \begin{bmatrix} Z_{11} & Z_{12} \\ Z_{21} & Z_{22} \end{bmatrix} \begin{bmatrix} I_1 \\ I_2 \end{bmatrix}$$

**测量：**
- Z11 = U1/I1 | I2=0
- Z12 = U1/I2 | I1=0
- Z21 = U2/I1 | I2=0
- Z22 = U2/I2 | I1=0

---

### 8.2 Y参数

$$\begin{bmatrix} I_1 \\ I_2 \end{bmatrix} = \begin{bmatrix} Y_{11} & Y_{12} \\ Y_{21} & Y_{22} \end{bmatrix} \begin{bmatrix} U_1 \\ U_2 \end{bmatrix}$$

---

### 8.3 T参数

$$\begin{bmatrix} U_1 \\ I_1 \end{bmatrix} = \begin{bmatrix} A & B \\ C & D \end{bmatrix} \begin{bmatrix} U_2 \\ -I_2 \end{bmatrix}$$

---

### 8.4 参数转换

**Z ↔ Y：**
$$Y = Z^{-1}$$

**Z ↔ T：**
$$A = Z_{11}/Z_{21}, B = (Z_{11}Z_{22}-Z_{12}Z_{21})/Z_{21}$$
$$C = 1/Z_{21}, D = Z_{22}/Z_{21}$$

## 十、解题技巧总结

### 10.1 通用技巧

1. **画图** - 先画电路图，标参考方向
2. **设变量** - 设定未知量和方向
3. **列方程** - 根据KCL/KVL
4. **验算** - 功率守恒验证

---

### 10.2 特定题型技巧

**网孔分析：**
- 顺时针设网孔电流
- 自阻抗为正，互阻抗为负
- 电压源注意方向

**节点分析：**
- 选参考节点
- 自电导为正，互电导为负
- 电流源注意方向

**戴维南：**
- 开路电压：断开待求支路
- 等效电阻：电源置零

**三要素法：**
- 初始值：换路前
- 稳态值：换路后
- 时间常数：换路后

---

### 10.3 常见错误

| 错误 | 原因 | 避免 |
|------|------|------|
| 符号错误 | 方向设定 | 统一参考方向 |
| 单位错误 | 单位换算 | 统一单位 |
| 计算错误 | 粗心 | 验算 |
| 概念错误 | 理解不深 | 回归教材 |
