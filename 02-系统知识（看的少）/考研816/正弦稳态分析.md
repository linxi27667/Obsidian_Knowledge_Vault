# 正弦稳态分析

> **核心概念**：正弦量、相量、阻抗、导纳、相量图、功率因数、有功/无功/视在功率

---

## 1. 正弦量的基本概念

### 1.1 正弦量的三要素

正弦量的一般表达式：

$$
u(t) = U_m \cos(\omega t + \varphi_u)
$$

$$
i(t) = I_m \cos(\omega t + \varphi_i)
$$

三个要素：

| 要素 | 符号 | 含义 |
|------|------|------|
| 幅值 | $U_m$, $I_m$ | 正弦量的最大值 |
| 角频率 | $\omega$ | 每秒变化的弧度数，$\omega = 2\pi f = \frac{2\pi}{T}$ |
| 初相位 | $\varphi$ | $t=0$ 时刻的相位角 |

频率、周期、角频率的关系：

$$
\omega = 2\pi f = \frac{2\pi}{T}
$$

其中 $f$ 为频率（Hz），$T$ 为周期（s）。

### 1.2 同频率正弦量的相位差

设两个同频率正弦量：

$$
u(t) = U_m \cos(\omega t + \varphi_u), \quad i(t) = I_m \cos(\omega t + \varphi_i)
$$

相位差定义为：

$$
\varphi = \varphi_u - \varphi_i
$$

相位差的物理意义：

- $\varphi > 0$：$u$ 超前 $i$（$u$ 先到达最大值）
- $\varphi < 0$：$u$ 滞后 $i$
- $\varphi = 0$：$u$ 与 $i$ 同相
- $\varphi = \pm\pi$：$u$ 与 $i$ 反相
- $\varphi = \pm\frac{\pi}{2}$：$u$ 与 $i$ 正交

```
    u
    |  超前
    |  /  i
    | / /
    |/ /
----+---------> t
   /|
  / |
 /  |
i   u（滞后）
```

**注意**：相位差只对同频率正弦量才有意义。

### 1.3 有效值与幅值的关系

正弦量的有效值（均方根值）定义：

$$
U = \sqrt{\frac{1}{T}\int_0^T u^2(t)\,dt}
$$

对于正弦量，推导过程如下：

$$
U = \sqrt{\frac{1}{T}\int_0^T U_m^2 \cos^2(\omega t + \varphi)\,dt}
$$

利用 $\cos^2\theta = \frac{1+\cos 2\theta}{2}$：

$$
U = \sqrt{\frac{U_m^2}{T}\int_0^T \frac{1+\cos(2\omega t + 2\varphi)}{2}\,dt} = \frac{U_m}{\sqrt{2}}
$$

因此：

$$
U = \frac{U_m}{\sqrt{2}} \approx 0.707\,U_m, \quad I = \frac{I_m}{\sqrt{2}} \approx 0.707\,I_m
$$

$$
U_m = \sqrt{2}\,U, \quad I_m = \sqrt{2}\,I
$$

**工程中通常使用有效值**，如市电 220V 指的是有效值，幅值为 $220\sqrt{2} \approx 311$ V。

## 2. 相量法基础

### 2.1 相量的定义与表示

**相量**是表示正弦量的复数，它包含了正弦量的幅值（或有效值）和初相位信息。

设正弦量 $i(t) = I_m \cos(\omega t + \varphi)$，其**幅值相量**为：

$$
\dot{I}_m = I_m e^{j\varphi} = I_m \angle \varphi
$$

其**有效值相量**为：

$$
\dot{I} = I e^{j\varphi} = I \angle \varphi
$$

**直角坐标形式**与**极坐标形式**的转换：

$$
\dot{I} = I \angle \varphi = I\cos\varphi + jI\sin\varphi = a + jb
$$

$$
I = \sqrt{a^2 + b^2}, \quad \varphi = \arctan\frac{b}{a}
$$

```
    虚轴 (Im)
      |
      |   . (a, b)
      |  /|
      | / |
      |/  | b
 -----+---+----> 实轴 (Re)
      |  a
      |
   I = sqrt(a^2 + b^2)
   phi = arctan(b/a)
```

### 2.2 相量与正弦量的对应关系

正弦量到相量的对应（单射关系）：

$$
i(t) = I_m \cos(\omega t + \varphi) \quad \longleftrightarrow \quad \dot{I} = I \angle \varphi
$$

**关键**：相量只包含幅值和初相信息，**不包含频率信息**。分析同频率正弦稳态电路时，频率 $\omega$ 是已知的公共信息。

相量到正弦量的还原：

$$
\dot{I} = I \angle \varphi \quad \longleftrightarrow \quad i(t) = \sqrt{2}\,I \cos(\omega t + \varphi)
$$

### 2.3 相量的运算规则

**加减法**：使用直角坐标形式

$$
\dot{U}_1 + \dot{U}_2 = (a_1 + jb_1) + (a_2 + jb_2) = (a_1+a_2) + j(b_1+b_2)
$$

**乘除法**：使用极坐标形式

$$
\frac{\dot{U}}{\dot{I}} = \frac{U \angle \varphi_u}{I \angle \varphi_i} = \frac{U}{I} \angle (\varphi_u - \varphi_i)
$$

$$
\dot{U} \cdot \dot{I} = UI \angle (\varphi_u + \varphi_i)
$$

**微分的相量对应**：

$$
\frac{di}{dt} \quad \longleftrightarrow \quad j\omega \dot{I}
$$

推导：设 $i(t) = I_m \cos(\omega t + \varphi)$，则

$$
\frac{di}{dt} = -\omega I_m \sin(\omega t + \varphi) = \omega I_m \cos(\omega t + \varphi + 90°)
$$

对应的相量为 $\omega I_m \angle(\varphi + 90°) = j\omega \cdot I_m \angle \varphi = j\omega \dot{I}_m$

**积分的相量对应**：

$$
\int i\,dt \quad \longleftrightarrow \quad \frac{\dot{I}}{j\omega}
$$

### 2.4 旋转因子与相量图

$j$ 的幂次循环规律：

$$
j^0 = 1, \quad j^1 = j, \quad j^2 = -1, \quad j^3 = -j, \quad j^4 = 1
$$

$j = 1 \angle 90°$：**旋转因子**，乘以 $j$ 表示逆时针旋转 90 度。

$$
j\dot{I} = I \angle (\varphi + 90°)
$$

$$
-j\dot{I} = I \angle (\varphi - 90°)
$$

```
    虚轴
      |    j*Idot (旋转90度)
      |   /
      |  /
      | / Idot
------+---------> 实轴
      |
      |
   -j*Idot (旋转-90度)
```

## 3. 电路定律的相量形式

### 3.1 KCL 的相量形式

时域形式：

$$
\sum_{k=1}^{n} i_k(t) = 0
$$

对同频率正弦量，相量形式为：

$$
\boxed{\sum_{k=1}^{n} \dot{I}_k = 0}
$$

即：流出（或流入）任一节点的电流相量之和为零。

### 3.2 KVL 的相量形式

时域形式：

$$
\sum_{k=1}^{n} u_k(t) = 0
$$

相量形式：

$$
\boxed{\sum_{k=1}^{n} \dot{U}_k = 0}
$$

即：沿任一回路的电压相量之和为零。

**注意**：有效值一般不满足 KVL，即 $\sum U_k \neq 0$（因为存在相位差）。必须用相量进行运算。

### 3.3 三种基本元件 VCR 的相量形式

#### 电阻 R

时域：$u_R = Ri_R$

相量形式：

$$
\boxed{\dot{U}_R = R\dot{I}_R}
$$

- 电压与电流**同相**
- 幅值关系：$U_R = RI_R$
- 相位关系：$\varphi_u = \varphi_i$

```
    I_dot ----+
              |
            [ R ]
              |
    U_dot ----+
    
    相量图：U 和 I 同方向
         Im
         |
     U,I .
         |
    -----+-----> Re
```

#### 电感 L

时域：$u_L = L\frac{di_L}{dt}$

相量形式：

$$
\boxed{\dot{U}_L = j\omega L \cdot \dot{I}_L}
$$

- 电压**超前**电流 90 度
- 感抗：$X_L = \omega L$（单位：$\Omega$）
- 幅值关系：$U_L = \omega L \cdot I_L$

```
    相量图：
         Im
         |
         | U_L
         | ^
         | |
    -----+-----> Re
         |
         | I_L
         v
         
    U_L 超前 I_L 90度
```

#### 电容 C

时域：$i_C = C\frac{du_C}{dt}$

相量形式：

$$
\boxed{\dot{U}_C = \frac{1}{j\omega C}\dot{I}_C = -j\frac{1}{\omega C}\dot{I}_C}
$$

- 电压**滞后**电流 90 度（电流超前电压 90 度）
- 容抗：$X_C = \frac{1}{\omega C}$（单位：$\Omega$）
- 幅值关系：$U_C = \frac{1}{\omega C} \cdot I_C$

```
    相量图：
         Im
         |
         | I_C
         | ^
         | |
    -----+-----> Re
         |
         | U_C
         v
         
    I_C 超前 U_C 90度
```

三种元件相量形式对比：

| 元件 | 时域 VCR | 相量 VCR | 阻抗 | 相位关系 |
|------|----------|----------|------|----------|
| R | $u = Ri$ | $\dot{U} = R\dot{I}$ | $Z_R = R$ | 同相 |
| L | $u = L\frac{di}{dt}$ | $\dot{U} = j\omega L\dot{I}$ | $Z_L = j\omega L$ | $u$ 超前 $i$ 90° |
| C | $i = C\frac{du}{dt}$ | $\dot{U} = \frac{1}{j\omega C}\dot{I}$ | $Z_C = \frac{1}{j\omega C}$ | $u$ 滞后 $i$ 90° |

### 3.4 阻抗与导纳的概念

**阻抗**定义为电压相量与电流相量之比：

$$
\boxed{Z = \frac{\dot{U}}{\dot{I}} = |Z|\angle\varphi_Z}
$$

阻抗的直角坐标形式：

$$
Z = R + jX
$$

其中：
- $R = \text{Re}[Z]$：电阻分量
- $X = \text{Im}[Z]$：电抗分量
- $|Z| = \sqrt{R^2 + X^2}$：阻抗模
- $\varphi_Z = \arctan\frac{X}{R}$：阻抗角

**导纳**定义为阻抗的倒数：

$$
\boxed{Y = \frac{1}{Z} = \frac{\dot{I}}{\dot{U}} = |Y|\angle\varphi_Y}
$$

$$
Y = G + jB
$$

其中：
- $G = \text{Re}[Y]$：电导分量
- $B = \text{Im}[Y]$：电纳分量
- $|Y| = \sqrt{G^2 + B^2}$：导纳模

阻抗与导纳的转换：

$$
Y = \frac{1}{Z} = \frac{1}{R+jX} = \frac{R-jX}{R^2+X^2}
$$

$$
G = \frac{R}{R^2+X^2}, \quad B = \frac{-X}{R^2+X^2}
$$

```
    阻抗三角形：
    
         |Z|
         /|
        / |
       /  | X (电抗)
      /   |
     /phi_Z|
    +------+---> R (电阻)
    
    |Z|^2 = R^2 + X^2
```

## 4. 阻抗的串联与并联

### 4.1 阻抗串联

多个阻抗串联时，等效阻抗为各阻抗之和：

$$
\boxed{Z_{eq} = Z_1 + Z_2 + \cdots + Z_n}
$$

串联电路中，电流相同，各阻抗上的电压按阻抗分配：

$$
\dot{U}_k = \frac{Z_k}{Z_{eq}} \dot{U}_{总}
$$

两个阻抗串联的分压公式：

$$
\dot{U}_1 = \frac{Z_1}{Z_1+Z_2}\dot{U}, \quad \dot{U}_2 = \frac{Z_2}{Z_1+Z_2}\dot{U}
```

```
    I_dot
    ----[ Z1 ]----[ Z2 ]----[ Z3 ]----
    |                                  |
    +------------ U_dot ---------------+
    
    Z_eq = Z1 + Z2 + Z3
```

### 4.2 阻抗并联

多个阻抗并联时，等效阻抗的倒数为各阻抗倒数之和：

$$
\boxed{\frac{1}{Z_{eq}} = \frac{1}{Z_1} + \frac{1}{Z_2} + \cdots + \frac{1}{Z_n}}
$$

或用导纳表示：

$$
Y_{eq} = Y_1 + Y_2 + \cdots + Y_n
$$

两个阻抗并联的等效阻抗：

$$
Z_{eq} = \frac{Z_1 Z_2}{Z_1 + Z_2}
$$

并联电路中，电压相同，各支路电流按导纳分配：

$$
\dot{I}_k = \frac{Y_k}{Y_{eq}} \dot{I}_{总} = \frac{Z_{eq}}{Z_k} \dot{I}_{总}
```

两个阻抗并联的分流公式：

$$
\dot{I}_1 = \frac{Z_2}{Z_1+Z_2}\dot{I}, \quad \dot{I}_2 = \frac{Z_1}{Z_1+Z_2}\dot{I}
$$

```
         +---[ Z1 ]---+
         |             |
    I_dot              U_dot
         |             |
         +---[ Z2 ]---+
         |             |
         +---[ Z3 ]---+
    
    1/Z_eq = 1/Z1 + 1/Z2 + 1/Z3
```

### 4.3 阻抗三角形与导纳三角形

对于 $Z = R + jX$：

```
    阻抗三角形：        导纳三角形（注意方向）：
    
         |Z|                 |Y|
         /|                   |\
        / |                   | \
       /  | X                 |  \ B (电纳)
      /   |                   |   \
     / phi|                   |phi \
    +-----+---> R             +----> G (电导)
```

**注意**：对于感性电路 $X > 0$，$\varphi_Z > 0$；对于容性电路 $X < 0$，$\varphi_Z < 0$。

## 5. 正弦稳态电路的分析

### 5.1 相量模型的建立

将时域电路转换为相量模型的步骤：

1. **确定频率**：找出电路中所有正弦源的角频率 $\omega$（通常只有一个）
2. **替换元件**：
   - 电阻 $R$ → 阻抗 $R$（不变）
   - 电感 $L$ → 阻抗 $j\omega L$
   - 电容 $C$ → 阻抗 $\frac{1}{j\omega C}$
3. **替换电源**：正弦电压源 $u_s = U_m\cos(\omega t + \varphi)$ → 相量电压源 $\dot{U}_s = U\angle\varphi$
4. **替换变量**：$u(t) \to \dot{U}$，$i(t) \to \dot{I}$
5. **应用直流电路分析方法**：在相量域中使用网孔法、节点法等

```
    时域电路                    相量模型
    
    u_s(t)                     U_s_dot
    ~~~                         _____
    |                           |   |
   [R]  [L]  [C]               [R] [jwL] [1/jwC]
    |    |    |                 |    |      |
    +----+----+                 +----+------+
    
    转换：R不变，L -> jwL，C -> 1/(jwC)
```

### 5.2 网孔电流法（相量形式）

步骤：
1. 设定网孔电流相量 $\dot{I}_1, \dot{I}_2, \ldots$
2. 对每个网孔列写 KVL 方程（用阻抗和相量）
3. 解方程组

一般形式（$n$ 个网孔）：

$$
\begin{cases}
Z_{11}\dot{I}_1 + Z_{12}\dot{I}_2 + \cdots + Z_{1n}\dot{I}_n = \dot{U}_{s1} \\
Z_{21}\dot{I}_1 + Z_{22}\dot{I}_2 + \cdots + Z_{2n}\dot{I}_n = \dot{U}_{s2} \\
\vdots \\
Z_{n1}\dot{I}_1 + Z_{n2}\dot{I}_2 + \cdots + Z_{nn}\dot{I}_n = \dot{U}_{sn}
\end{cases}
$$

其中：
- $Z_{kk}$：第 $k$ 个网孔的自阻抗（该网孔所有阻抗之和）
- $Z_{kj} (k \neq j)$：第 $k$ 个和第 $j$ 个网孔之间的互阻抗（取负值，若两网孔电流方向相反在公共支路上）
- $\dot{U}_{sk}$：第 $k$ 个网孔中沿网孔方向的电压源相量之和

### 5.3 节点电压法（相量形式）

步骤：
1. 选定参考节点，设其余节点电压相量为 $\dot{U}_1, \dot{U}_2, \ldots$
2. 对每个独立节点列写 KCL 方程（用导纳和相量）
3. 解方程组

一般形式（$n$ 个独立节点）：

$$
\begin{cases}
Y_{11}\dot{U}_1 + Y_{12}\dot{U}_2 + \cdots + Y_{1n}\dot{U}_n = \dot{I}_{s1} \\
Y_{21}\dot{U}_1 + Y_{22}\dot{U}_2 + \cdots + Y_{2n}\dot{U}_n = \dot{I}_{s2} \\
\vdots \\
Y_{n1}\dot{U}_1 + Y_{n2}\dot{U}_2 + \cdots + Y_{nn}\dot{U}_n = \dot{I}_{sn}
\end{cases}
$$

其中：
- $Y_{kk}$：第 $k$ 个节点的自导纳（连接到该节点所有支路导纳之和）
- $Y_{kj} (k \neq j)$：节点 $k$ 和节点 $j$ 之间的互导纳（取负值）
- $\dot{I}_{sk}$：流入第 $k$ 个节点的电流源相量之和

### 5.4 叠加定理在相量域的应用

在正弦稳态电路中，叠加定理适用于**不同频率**的电源共同作用的情况：

1. 分别计算每个频率电源单独作用时的响应（其他电源置零）
2. **注意**：不同频率的响应不能直接用相量相加，必须先转换回时域，再在时域中叠加

$$
i(t) = i_1(t) + i_2(t) + \cdots = I_{m1}\cos(\omega_1 t + \varphi_1) + I_{m2}\cos(\omega_2 t + \varphi_2) + \cdots
$$

同频率电源作用时，直接在相量域叠加即可。

### 5.5 戴维宁/诺顿等效（相量域）

**戴维宁等效**：任何线性有源二端网络可等效为一个电压源与一个阻抗串联。

$$
\dot{U}_{oc} = \text{开路电压相量}
$$

$$
Z_{eq} = \text{等效阻抗（独立源置零后从端口看入的阻抗）}
$$

```
    原电路                戴维宁等效
    
    +---[ 网络 ]---+      +---[ Z_eq ]---[ U_oc ]---+
    |      a       |  =>  |                          |
    |      b       |      |         a                |
    +--------------+      +-------------------------+
```

**诺顿等效**：

$$
\dot{I}_{sc} = \text{短路电流相量}
$$

$$
\dot{I}_{sc} = \frac{\dot{U}_{oc}}{Z_{eq}}
$$

**求等效阻抗的方法**：
- 方法一：将独立源置零（电压源短路、电流源开路），从端口计算阻抗
- 方法二：$Z_{eq} = \frac{\dot{U}_{oc}}{\dot{I}_{sc}}$

### 5.6 典型例题：RLC 串联电路分析

**例题 5-1**：RLC 串联电路，$R = 30\,\Omega$，$L = 0.1\,\text{H}$，$C = 100\,\mu\text{F}$，外加电压 $u(t) = 100\sqrt{2}\cos(100t + 30°)\,\text{V}$。求电流 $i(t)$ 和各元件电压。

**解**：

(1) 将电源转换为相量：

$$
\dot{U} = 100\angle 30° \,\text{V}, \quad \omega = 100\,\text{rad/s}
$$

(2) 计算各元件阻抗：

$$
Z_R = R = 30\,\Omega
$$

$$
Z_L = j\omega L = j \times 100 \times 0.1 = j10\,\Omega
$$

$$
Z_C = \frac{1}{j\omega C} = \frac{1}{j \times 100 \times 100 \times 10^{-6}} = \frac{1}{j0.01} = -j100\,\Omega
$$

(3) 总阻抗：

$$
Z = Z_R + Z_L + Z_C = 30 + j10 + (-j100) = 30 - j90\,\Omega
$$

$$
|Z| = \sqrt{30^2 + 90^2} = \sqrt{900 + 8100} = \sqrt{9000} = 30\sqrt{10} \approx 94.87\,\Omega
$$

$$
\varphi_Z = \arctan\frac{-90}{30} = \arctan(-3) \approx -71.57°
$$

$$
Z = 94.87\angle{-71.57°}\,\Omega
$$

(4) 求电流相量：

$$
\dot{I} = \frac{\dot{U}}{Z} = \frac{100\angle 30°}{94.87\angle{-71.57°}} = 1.054\angle 101.57° \,\text{A}
$$

(5) 各元件电压：

$$
\dot{U}_R = R\dot{I} = 30 \times 1.054\angle 101.57° = 31.62\angle 101.57° \,\text{V}
$$

$$
\dot{U}_L = j\omega L \dot{I} = j10 \times 1.054\angle 101.57° = 10.54\angle 191.57° \,\text{V}
$$

$$
\dot{U}_C = \frac{1}{j\omega C}\dot{I} = -j100 \times 1.054\angle 101.57° = 105.4\angle 11.57° \,\text{V}
$$

(6) 转换回时域：

$$
i(t) = 1.054\sqrt{2}\cos(100t + 101.57°) \approx 1.49\cos(100t + 101.57°)\,\text{A}
$$

(7) 验证：$\dot{U}_R + \dot{U}_L + \dot{U}_C = \dot{U}$（可用复数运算验证）

**分析**：电路呈容性（$X_C > X_L$），总阻抗角为负，电流超前电压。

## 6. 正弦稳态电路的功率

### 6.1 瞬时功率

设电压和电流为：

$$
u(t) = U_m\cos(\omega t + \varphi_u), \quad i(t) = I_m\cos(\omega t + \varphi_i)
$$

令 $\varphi = \varphi_u - \varphi_i$（功率因数角），则：

$$
p(t) = u(t) \cdot i(t) = U_m I_m \cos(\omega t + \varphi_u)\cos(\omega t + \varphi_i)
$$

利用积化和差公式：

$$
p(t) = UI\cos\varphi + UI\cos(2\omega t + \varphi_u + \varphi_i)
$$

即：

$$
\boxed{p(t) = UI\cos\varphi + UI\cos(2\omega t + 2\varphi_i + \varphi)}
$$

瞬时功率包含一个恒定分量和一个以 $2\omega$ 变化的交变分量。

```
    瞬时功率波形：
    
    p(t)
    |     *
    |   *   *       *
    |  *     *     * *
    | *       *   *   *
    +-*--------*-*-----*----> t
    |           *
    |  恒定分量 + 2倍频交变分量
```

### 6.2 有功功率 P

有功功率（平均功率）是瞬时功率在一个周期内的平均值：

$$
\boxed{P = UI\cos\varphi}
$$

其中：
- $U$：电压有效值
- $I$：电流有效值
- $\varphi$：电压与电流的相位差（即阻抗角 $\varphi_Z$）
- $\cos\varphi$：功率因数

单位：瓦特（W）

**特殊情况**：
- 纯电阻：$\varphi = 0$，$P = UI$（最大）
- 纯电感：$\varphi = 90°$，$P = 0$
- 纯电容：$\varphi = -90°$，$P = 0$

### 6.3 无功功率 Q

$$
\boxed{Q = UI\sin\varphi}
$$

单位：乏（var，volt-ampere reactive）

- 感性电路：$\varphi > 0$，$Q > 0$（电感吸收无功）
- 容性电路：$\varphi < 0$，$Q < 0$（电容发出无功）
- 纯电阻：$Q = 0$

无功功率的物理意义：表示电路中储能元件与电源之间能量交换的最大速率。

### 6.4 视在功率 S

$$
\boxed{S = UI}
$$

单位：伏安（VA，volt-ampere）

视在功率表示电气设备的容量（额定功率）。

三种功率的关系：

$$
S^2 = P^2 + Q^2
$$

$$
S = \sqrt{P^2 + Q^2}
$$

```
    功率三角形：
    
         S (视在功率)
         /|
        / |
       /  | Q (无功功率)
      /   |
     / phi|
    +-----+---> P (有功功率)
    
    P = S*cos(phi)
    Q = S*sin(phi)
    S = sqrt(P^2 + Q^2)
    phi = arctan(Q/P)
```

### 6.5 功率因数 $\cos\varphi$ 的意义与提高

**功率因数的意义**：

$$
\cos\varphi = \frac{P}{S}
$$

- $\cos\varphi$ 越接近 1，设备利用率越高
- 低功率因数导致：线路电流大、线路损耗大、设备容量不能充分利用
- 工厂中大量使用电动机（感性负载），功率因数通常较低（0.6~0.8）

**提高功率因数的方法**：

并联电容补偿感性负载的无功功率。

设感性负载的功率为 $P$，功率因数从 $\cos\varphi_1$ 提高到 $\cos\varphi_2$，需要并联的电容为：

$$
\boxed{C = \frac{P(\tan\varphi_1 - \tan\varphi_2)}{\omega U^2}}
$$

推导过程：

补偿前电流：$\dot{I}_1 = \frac{P}{U\cos\varphi_1}\angle(-\varphi_1)$（滞后电压 $\varphi_1$）

补偿后总电流：$\dot{I} = \dot{I}_1 + \dot{I}_C$

电容电流：$\dot{I}_C = j\omega C \dot{U}$

补偿后的无功功率：

$$
Q_2 = Q_1 - Q_C = P\tan\varphi_1 - \omega CU^2
$$

要求 $Q_2 = P\tan\varphi_2$，解得：

$$
C = \frac{P(\tan\varphi_1 - \tan\varphi_2)}{\omega U^2}
$$

**注意**：并联电容不改变负载的工作状态（负载两端电压和电流不变），只改善从电源侧看的功率因数。

```
    功率因数提高示意（相量图）：
    
         Im
         |
         | I_C (电容电流，超前90度)
         | ^
         | |
         |  \  I (补偿后，角度变小)
         |   \
         |    \ I_1 (补偿前)
         |     \
    -----+------\-----> Re
         |       \
         |        \ U
         |
    
    并联电容后，总电流减小，功率因数提高
```

### 6.6 复功率

复功率定义为电压相量与电流相量共轭的乘积：

$$
\boxed{\tilde{S} = \dot{U}\dot{I}^* = P + jQ}
$$

其中 $\dot{I}^*$ 是 $\dot{I}$ 的共轭复数。

设 $\dot{U} = U\angle\varphi_u$，$\dot{I} = I\angle\varphi_i$，则：

$$
\tilde{S} = UI\angle(\varphi_u - \varphi_i) = UI\angle\varphi = S\angle\varphi
$$

$$
P = \text{Re}[\tilde{S}] = S\cos\varphi, \quad Q = \text{Im}[\tilde{S}] = S\sin\varphi
$$

**复功率守恒**：

$$
\sum_{k=1}^{n} \tilde{S}_k = 0
$$

即全电路的有功功率之和为零（发出 = 吸收），无功功率之和为零。

### 6.7 最大功率传输定理

**问题**：给定信号源 $\dot{U}_{oc}$ 和内阻抗 $Z_{eq} = R_{eq} + jX_{eq}$，负载 $Z_L = R_L + jX_L$ 取何值时获得最大功率？

```
    I_dot
    +--[ Z_eq ]--[ U_oc ]--+
    |     R_eq + jX_eq      |
    |                        |
    +-------[ Z_L ]----------+
           R_L + jX_L
```

**条件1：负载阻抗模可调，阻抗角固定**

当 $|Z_L| = |Z_{eq}|$ 时获得最大功率。

**条件2：负载阻抗的实部和虚部均可独立调节（共轭匹配）**

$$
\boxed{Z_L = Z_{eq}^* = R_{eq} - jX_{eq}}
$$

即负载阻抗等于内阻抗的共轭复数。

此时：

$$
R_L = R_{eq}, \quad X_L = -X_{eq}
$$

最大功率：

$$
P_{max} = \frac{U_{oc}^2}{4R_{eq}}
$$

**证明**：

$$
\dot{I} = \frac{\dot{U}_{oc}}{Z_{eq}+Z_L} = \frac{\dot{U}_{oc}}{(R_{eq}+R_L)+j(X_{eq}+X_L)}
$$

$$
P = I^2 R_L = \frac{U_{oc}^2 R_L}{(R_{eq}+R_L)^2 + (X_{eq}+X_L)^2}
$$

要使 $P$ 最大，先令 $X_{eq}+X_L = 0$（消除虚部），得 $X_L = -X_{eq}$。

此时：

$$
P = \frac{U_{oc}^2 R_L}{(R_{eq}+R_L)^2}
$$

对 $R_L$ 求导并令其为零：

$$
\frac{dP}{dR_L} = U_{oc}^2 \frac{(R_{eq}+R_L)^2 - 2R_L(R_{eq}+R_L)}{(R_{eq}+R_L)^4} = 0
$$

$$
(R_{eq}+R_L) - 2R_L = 0 \implies R_L = R_{eq}
$$

证毕。

**共轭匹配时的效率**：

$$
\eta = \frac{P_{max}}{P_{总}} = \frac{I^2 R_L}{I^2(R_{eq}+R_L)} = \frac{R_L}{R_{eq}+R_L} = \frac{1}{2} = 50\%
$$

**例题 6-1**：电路如下图，求负载 $Z_L$ 为何值时获得最大功率，并求最大功率。

已知：$\dot{U}_s = 100\angle 0°\,\text{V}$，$Z_1 = 10 + j20\,\Omega$，$Z_2 = 20 - j10\,\Omega$。

```
    I_dot
    +--[ Z1 ]--[ U_s ]--+
    |                    |
    +--[ Z2 ]--[ Z_L ]---+
```

**解**：

(1) 求戴维宁等效电路

断开 $Z_L$，求开路电压。$Z_2$ 开路，无电流流过：

$$
\dot{U}_{oc} = \frac{Z_2}{Z_1+Z_2}\dot{U}_s = \frac{20-j10}{(10+j20)+(20-j10)} \times 100\angle 0°
$$

$$
= \frac{20-j10}{30+j10} \times 100 = \frac{22.36\angle{-26.57°}}{31.62\angle{18.43°}} \times 100
$$

$$
= 0.707\angle{-45°} \times 100 = 70.7\angle{-45°}\,\text{V}
$$

(2) 求等效阻抗

将电压源置零（短路），从 $Z_L$ 两端看入：

$$
Z_{eq} = \frac{Z_1 \cdot Z_2}{Z_1 + Z_2} = \frac{(10+j20)(20-j10)}{30+j10}
$$

计算分子：

$$
(10+j20)(20-j10) = 200 - j100 + j400 + 200 = 400 + j300
$$

$$
Z_{eq} = \frac{400+j300}{30+j10} = \frac{500\angle{36.87°}}{31.62\angle{18.43°}} = 15.81\angle{18.44°} = 15+j5\,\Omega
$$

(3) 共轭匹配条件：

$$
Z_L = Z_{eq}^* = 15 - j5\,\Omega
$$

(4) 最大功率：

$$
P_{max} = \frac{U_{oc}^2}{4R_{eq}} = \frac{70.7^2}{4 \times 15} = \frac{5000}{60} \approx 83.3\,\text{W}
$$

## 7. 相量图分析法

### 7.1 相量图的绘制步骤

1. **选定参考相量**：通常选择已知或串联电路中的电流，并联电路中的电压
2. **按序绘制各相量**：根据 VCR 和 KVL/KCL 关系依次画出
3. **标注幅值和角度**
4. **利用几何关系求解**

### 7.2 RLC 串联电路的相量图

以电流 $\dot{I}$ 为参考相量：

- $\dot{U}_R$：与 $\dot{I}$ 同相
- $\dot{U}_L$：超前 $\dot{I}$ 90°
- $\dot{U}_C$：滞后 $\dot{I}$ 90°
- $\dot{U} = \dot{U}_R + \dot{U}_L + \dot{U}_C$

```
    感性电路 (X_L > X_C)：        容性电路 (X_L < X_C)：
    
         Im                            Im
         |                             |
         | U_L                         |
         | ^                           | U
         |/                            |/
    -----+-------> Re            -----+-------> Re
         |  U                          |  U
         | /                           | /
         |/ U_C                        | v U_C (|U_C|>|U_L|)
         v                             |
         U_L - U_C                     I 超前 U
    
    U = sqrt(U_R^2 + (U_L-U_C)^2)
    phi = arctan((U_L-U_C)/U_R)
```

### 7.3 RLC 并联电路的相量图

以电压 $\dot{U}$ 为参考相量：

- $\dot{I}_R$：与 $\dot{U}$ 同相
- $\dot{I}_L$：滞后 $\dot{U}$ 90°
- $\dot{I}_C$：超前 $\dot{U}$ 90°
- $\dot{I} = \dot{I}_R + \dot{I}_L + \dot{I}_C$

```
    感性主导 (I_L > I_C)：         容性主导 (I_C > I_L)：
    
         Im                            Im
         | I_C                         | I_C
         | ^                           | ^
         | |                           | |
         | |                           | |   I
         | |                           | |  /
    -----+--+----> Re             -----+-+/----> Re
         |  |  I                      | /
         | /                          |/
         |/ I_L                       I_L
    
    I = sqrt(I_R^2 + (I_L-I_C)^2)
    phi = arctan((I_L-I_C)/I_R)
```

### 7.4 利用相量图求解电路

**例题 7-1**：RL 串联电路接在正弦电压源上，已知 $U = 100\,\text{V}$，$U_R = 60\,\text{V}$，求 $U_L$。

**解**：利用相量图的直角三角形关系：

$$
U = \sqrt{U_R^2 + U_L^2}
$$

$$
U_L = \sqrt{U^2 - U_R^2} = \sqrt{100^2 - 60^2} = \sqrt{6400} = 80\,\text{V}
$$

```
         U = 100V
         /|
        / |
       /  | U_L = 80V
      /   |
     / phi|
    +-----+---> U_R = 60V
```

**例题 7-2**：RC 并联电路，$I = 5\,\text{A}$，$I_R = 3\,\text{A}$，$I_C = 4\,\text{A}$，验证 KCL。

**解**：$\dot{I}_R$ 与 $\dot{U}$ 同相，$\dot{I}_C$ 超前 $\dot{U}$ 90°：

$$
I = \sqrt{I_R^2 + I_C^2} = \sqrt{3^2 + 4^2} = \sqrt{25} = 5\,\text{A} \quad \checkmark
$$

## 8. 频率特性初步

### 8.1 阻抗随频率变化的规律

RLC 串联电路的阻抗：

$$
Z(j\omega) = R + j\left(\omega L - \frac{1}{\omega C}\right)
$$

$$
|Z| = \sqrt{R^2 + \left(\omega L - \frac{1}{\omega C}\right)^2}
$$

```
    |Z| 随频率变化：
    
    |Z|
    |  \
    |   \          /
    |    \        /
    |     \      /
    |      \    /
    |       \  /
    |        \/ R
    +--------+--------> omega
             omega_0
    
    omega < omega_0: 容性 (X < 0)
    omega = omega_0: 纯阻性 (X = 0)
    omega > omega_0: 感性 (X > 0)
```

### 8.2 串联谐振

**谐振条件**：

$$
\omega L = \frac{1}{\omega C}
$$

$$
\boxed{\omega_0 = \frac{1}{\sqrt{LC}}}, \quad f_0 = \frac{1}{2\pi\sqrt{LC}}
$$

谐振时的特征：

| 特征 | 表达式 |
|------|--------|
| 阻抗最小 | $Z_0 = R$（纯电阻性） |
| 电流最大 | $I_0 = \frac{U}{R}$ |
| $U_L$ 与 $U_C$ 相互抵消 | $U_L = U_C = QU$ |
| 功率因数 | $\cos\varphi = 1$ |

**串联谐振时**：

$$
\dot{U}_L + \dot{U}_C = 0 \quad \text{（L和C串联部分相当于短路）}
$$

但 $\dot{U}_L$ 和 $\dot{U}_C$ 各自可能远大于 $\dot{U}$（电压谐振），这就是谐振过电压现象。

### 8.3 并联谐振

RLC 并联电路的谐振条件（与串联对偶）：

$$
\omega_0 = \frac{1}{\sqrt{LC}}
$$

谐振时的特征：

| 特征 | 表达式 |
|------|--------|
| 导纳最小 | $Y_0 = G$（纯电导性） |
| 阻抗最大 | $Z_0 = \frac{1}{G} = R$ |
| 电压最大 | $U_0 = \frac{I_s}{G}$ |
| $\dot{I}_L$ 与 $\dot{I}_C$ 相互抵消 | $I_L = I_C = QI_s$ |

**实际工程中的并联谐振**（电感线圈与电容并联）：

线圈模型：$R$（等效串联电阻）与 $L$ 串联，再与 $C$ 并联。

$$
Z_{并} = \frac{(R+j\omega L) \cdot \frac{1}{j\omega C}}{R+j\omega L + \frac{1}{j\omega C}}
$$

近似谐振条件（$R$ 较小时）：

$$
\omega_0 \approx \frac{1}{\sqrt{LC}}
$$

### 8.4 品质因数 Q

**串联谐振品质因数**：

$$
\boxed{Q_0 = \frac{\omega_0 L}{R} = \frac{1}{\omega_0 CR} = \frac{1}{R}\sqrt{\frac{L}{C}}}
$$

物理意义：

- $Q_0$ 表征谐振的尖锐程度
- $Q_0$ 越大，谐振曲线越尖锐，选择性越好
- 谐振时电感（或电容）上的电压是外加电压的 $Q_0$ 倍

**带宽（半功率频率范围）**：

$$
BW = \frac{\omega_0}{Q_0} = \frac{R}{L}
$$

$$
\omega_1, \omega_2 = \omega_0 \mp \frac{BW}{2} = \omega_0 \mp \frac{R}{2L}
$$

在 $\omega_1$ 和 $\omega_2$ 处，$|Z| = \sqrt{2}R$，功率降为谐振时的一半（-3dB）。

```
    谐振曲线 (不同Q值)：
    
    I/I_0
    |    Q大       Q小
    |    |*|       |  *
    |    | *|      |   *
    |   *|  *|     |    *
    |  * |   *|    |     *
    | *  |    *    |      *
    +*---+-----*---+-------*---> omega
         omega_0
    
    Q值越大，曲线越尖锐，选择性越好
```

## 9. 典型题型与解题技巧

### 题型 1：已知电路参数求阻抗/导纳

**例题 9-1**：求图示电路在 $\omega = 1000\,\text{rad/s}$ 时的等效阻抗。

```
    +---[ R=10 ]---[ L=20mH ]---+
    |                            |
    +----------[ C=50uF ]--------+
```

$R$ 与 $L$ 串联，再与 $C$ 并联。

**解**：

$$
Z_{RL} = R + j\omega L = 10 + j \times 1000 \times 0.02 = 10 + j20\,\Omega
$$

$$
Z_C = \frac{1}{j\omega C} = \frac{1}{j \times 1000 \times 50 \times 10^{-6}} = -j20\,\Omega
$$

$$
Z_{eq} = \frac{Z_{RL} \cdot Z_C}{Z_{RL} + Z_C} = \frac{(10+j20)(-j20)}{(10+j20)+(-j20)} = \frac{-j200 + 400}{10}
$$

$$
= 40 - j20\,\Omega
$$

$$
|Z_{eq}| = \sqrt{40^2+20^2} = \sqrt{2000} = 20\sqrt{5} \approx 44.7\,\Omega
$$

$$
\varphi = \arctan\frac{-20}{40} = -26.57°
$$

电路呈容性。

### 题型 2：正弦稳态电路的求解

**例题 9-2**：用网孔法求图示电路中的电流 $\dot{I}$。

```
    +---[ 10 ]---+---[ j5 ]---+
    |            |             |
  [100<0°V]   [10<-j5]      [j10]
    |            |             |
    +---[ 5 ]----+-------------+
```

简化电路说明：两个网孔，左网孔含电压源 $100\angle 0°$ V，$10\,\Omega$ 电阻，$5\,\Omega$ 电阻（公共支路）；右网孔含公共支路 $5\,\Omega$，$j10\,\Omega$ 电感。

设左网孔电流 $\dot{I}_1$（顺时针），右网孔电流 $\dot{I}_2$（顺时针）。

**解**：

网孔 1（左侧）：

$$
(10+5)\dot{I}_1 - 5\dot{I}_2 = 100\angle 0°
$$

$$
15\dot{I}_1 - 5\dot{I}_2 = 100 \quad \cdots (1)
$$

网孔 2（右侧）：

$$
-5\dot{I}_1 + (5+j10)\dot{I}_2 = 0 \quad \cdots (2)
$$

由 (2)：$\dot{I}_2 = \frac{5}{5+j10}\dot{I}_1 = \frac{1}{1+j2}\dot{I}_1$

代入 (1)：

$$
15\dot{I}_1 - \frac{5}{1+j2}\dot{I}_1 = 100
$$

$$
\dot{I}_1\left(15 - \frac{5}{1+j2}\right) = 100
$$

$$
\frac{5}{1+j2} = \frac{5(1-j2)}{5} = 1-j2
$$

$$
\dot{I}_1(15 - 1 + j2) = 100
$$

$$
\dot{I}_1(14+j2) = 100
$$

$$
\dot{I}_1 = \frac{100}{14+j2} = \frac{100}{14.14\angle 8.13°} = 7.07\angle{-8.13°}\,\text{A}
$$

$$
\dot{I}_2 = \frac{1}{1+j2} \times 7.07\angle{-8.13°} = \frac{7.07\angle{-8.13°}}{2.236\angle{63.43°}} = 3.16\angle{-71.56°}\,\text{A}
$$

所求电流 $\dot{I} = \dot{I}_1 - \dot{I}_2$（流过公共支路 $5\,\Omega$ 的电流）：

$$
\dot{I} = 7.07\angle{-8.13°} - 3.16\angle{-71.56°}
$$

$$
= (7.0 - j1.0) - (1.0 - j3.0) = 6.0 + j2.0 = 6.32\angle{18.43°}\,\text{A}
$$

### 题型 3：功率计算与功率因数提高

**例题 9-3**：某工厂负载功率 $P = 100\,\text{kW}$，功率因数 $\cos\varphi_1 = 0.6$（感性），接在 $U = 220\,\text{V}$，$f = 50\,\text{Hz}$ 的电源上。

(a) 求补偿前的电流；
(b) 要将功率因数提高到 $\cos\varphi_2 = 0.9$，求并联电容 $C$；
(c) 求补偿后的电流。

**解**：

(a) 补偿前：

$$
I_1 = \frac{P}{U\cos\varphi_1} = \frac{100000}{220 \times 0.6} = \frac{100000}{132} = 757.6\,\text{A}
$$

$$
\varphi_1 = \arccos 0.6 = 53.13°, \quad \tan\varphi_1 = 1.333
$$

(b) $\varphi_2 = \arccos 0.9 = 25.84°$，$\tan\varphi_2 = 0.484$

并联电容：

$$
C = \frac{P(\tan\varphi_1 - \tan\varphi_2)}{\omega U^2} = \frac{100000 \times (1.333 - 0.484)}{2\pi \times 50 \times 220^2}
$$

$$
= \frac{100000 \times 0.849}{314.16 \times 48400} = \frac{84900}{15205664} \approx 5.58 \times 10^{-3}\,\text{F} = 5580\,\mu\text{F}
$$

(c) 补偿后电流：

$$
I_2 = \frac{P}{U\cos\varphi_2} = \frac{100000}{220 \times 0.9} = \frac{100000}{198} = 505.1\,\text{A}
$$

电流从 757.6A 降到 505.1A，减少了 33.3%。

### 题型 4：相量图辅助分析

**例题 9-4**：RC 串联电路接在正弦电压源上，已知 $U = 100\,\text{V}$，$U_R = 80\,\text{V}$，$U_C = 60\,\text{V}$。分析电路是否符合 KVL。

**解**：利用相量图：

$$
U = \sqrt{U_R^2 + U_C^2} = \sqrt{80^2 + 60^2} = \sqrt{6400+3600} = \sqrt{10000} = 100\,\text{V} \quad \checkmark
$$

满足 KVL（相量形式），但 $U_R + U_C = 140 \neq U = 100$，这说明有效值不满足简单的代数相加。

```
         U = 100V
         /|
        / |
       /  | U_C = 60V
      /   |
     / 37°|
    +-----+---> U_R = 80V
    
    sin(37°) = 0.6, cos(37°) = 0.8
```

### 题型 5：最大功率传输问题

**例题 9-5**：电路如下图，求 $Z_L$ 获得最大功率时的阻抗值及最大功率。

已知 $\dot{U}_s = 50\angle 0°\,\text{V}$，$R_1 = 10\,\Omega$，$X_L = 10\,\Omega$（$j\omega L = j10$），$R_2 = 10\,\Omega$。

```
    +---[ R1 ]---+---+
    |            |   |
  [U_s]       [jX_L] [Z_L]
    |            |   |
    +---[ R2 ]---+---+
```

**解**：

(1) 求戴维宁等效

断开 $Z_L$，$R_2$ 与 $jX_L$ 串联后接 $U_s$，$Z_L$ 两端电压即 $jX_L$ 上的电压：

$$
\dot{U}_{oc} = \frac{jX_L}{R_2+jX_L}\dot{U}_s = \frac{j10}{10+j10} \times 50\angle 0°
$$

$$
= \frac{10\angle 90°}{14.14\angle 45°} \times 50 = \frac{500}{14.14}\angle 45° = 35.36\angle 45°\,\text{V}
$$

(2) 求等效阻抗

电压源置零，$R_1$ 与 $R_2$ 并联，再与 $jX_L$ 并联：

等效阻抗为从 $Z_L$ 端口看入：$R_2$ 与 $jX_L$ 并联（注意 $R_1$ 被短路）。

实际上电路结构是：$R_1$ 和 $R_2$ 并联后再与 $jX_L$ 串联？让我重新分析电路拓扑。

根据电路图：$U_s$ 正极 → $R_1$ → 节点A → $jX_L$ → 节点B → $U_s$ 负极，同时 $R_2$ 从节点A → 节点B，$Z_L$ 从节点A → 节点B。

所以 $Z_L$ 与 $jX_L$ 和 $R_2$ 并联。

等效阻抗：将 $U_s$ 短路，$R_1$ 两端等电位（被短路），从 $Z_L$ 看入：

$$
Z_{eq} = R_1 \| jX_L = \frac{R_1 \cdot jX_L}{R_1 + jX_L} = \frac{j100}{10+j10} = \frac{100\angle 90°}{14.14\angle 45°} = 7.07\angle 45° = 5+j5\,\Omega
$$

(3) 共轭匹配：

$$
Z_L = Z_{eq}^* = 5 - j5\,\Omega
$$

(4) 最大功率：

$$
P_{max} = \frac{U_{oc}^2}{4R_{eq}} = \frac{35.36^2}{4 \times 5} = \frac{1250}{20} = 62.5\,\text{W}
$$

## 10. 核心公式速查表

### 10.1 正弦量与相量

| 公式 | 说明 |
|------|------|
| $u(t) = U_m\cos(\omega t + \varphi)$ | 正弦量一般表达式 |
| $U = U_m/\sqrt{2}$ | 有效值与幅值关系 |
| $\dot{U} = U\angle\varphi$ | 有效值相量 |
| $\dot{U}_m = U_m\angle\varphi$ | 幅值相量 |
| $\omega = 2\pi f = 2\pi/T$ | 角频率、频率、周期关系 |

### 10.2 元件 VCR（相量形式）

| 元件 | 阻抗 | 电压-电流关系 | 相位关系 |
|------|------|--------------|----------|
| R | $Z_R = R$ | $\dot{U} = R\dot{I}$ | 同相 |
| L | $Z_L = j\omega L$ | $\dot{U} = j\omega L\dot{I}$ | $u$ 超前 $i$ 90° |
| C | $Z_C = \frac{1}{j\omega C}$ | $\dot{U} = \frac{\dot{I}}{j\omega C}$ | $u$ 滞后 $i$ 90° |

### 10.3 阻抗与导纳

| 公式 | 说明 |
|------|------|
| $Z = R + jX = \|Z\|\angle\varphi_Z$ | 阻抗的直角/极坐标形式 |
| $Y = G + jB = \|Y\|\angle\varphi_Y$ | 导纳的直角/极坐标形式 |
| $\|Z\| = \sqrt{R^2+X^2}$ | 阻抗模 |
| $\varphi_Z = \arctan(X/R)$ | 阻抗角 |
| $Y = 1/Z$ | 阻抗与导纳的转换 |
| $Z_{串} = Z_1+Z_2+\cdots$ | 阻抗串联 |
| $Y_{并} = Y_1+Y_2+\cdots$ | 导纳并联（阻抗并联） |

### 10.4 功率

| 公式 | 说明 |
|------|------|
| $P = UI\cos\varphi$ | 有功功率（W） |
| $Q = UI\sin\varphi$ | 无功功率（var） |
| $S = UI$ | 视在功率（VA） |
| $\tilde{S} = \dot{U}\dot{I}^* = P + jQ$ | 复功率 |
| $S = \sqrt{P^2+Q^2}$ | 三种功率关系 |
| $\cos\varphi = P/S$ | 功率因数 |
| $C = \frac{P(\tan\varphi_1-\tan\varphi_2)}{\omega U^2}$ | 功率因数补偿电容 |

### 10.5 最大功率传输

| 条件 | 负载阻抗 | 最大功率 |
|------|----------|----------|
| 共轭匹配 | $Z_L = Z_{eq}^*$ | $P_{max} = \frac{U_{oc}^2}{4R_{eq}}$ |
| 模匹配 | $\|Z_L\| = \|Z_{eq}\|$ | $P_{max} = \frac{U_{oc}^2}{2(\|Z_{eq}\|+R_{eq})}$ |

### 10.6 谐振

| 公式 | 说明 |
|------|------|
| $\omega_0 = \frac{1}{\sqrt{LC}}$ | 谐振角频率 |
| $Q_0 = \frac{\omega_0 L}{R} = \frac{1}{\omega_0 CR}$ | 品质因数 |
| $BW = \frac{\omega_0}{Q_0} = \frac{R}{L}$ | 带宽 |
| 串联谐振：$\|Z\|_{min} = R$，$I_{max} = U/R$ | 串联谐振特征 |
| 并联谐振：$\|Z\|_{max} = R$，$U_{max} = I_s R$ | 并联谐振特征 |

### 10.7 分压分流公式

| 场景 | 公式 |
|------|------|
| 串联分压 | $\dot{U}_k = \frac{Z_k}{Z_{总}}\dot{U}$ |
| 两阻抗串联 | $\dot{U}_1 = \frac{Z_1}{Z_1+Z_2}\dot{U}$ |
| 并联分流 | $\dot{I}_k = \frac{Y_k}{Y_{总}}\dot{I} = \frac{Z_{总}}{Z_k}\dot{I}$ |
| 两阻抗并联 | $\dot{I}_1 = \frac{Z_2}{Z_1+Z_2}\dot{I}$ |

### 10.8 关键解题技巧

1. **画相量图**：先定性分析，再定量计算
2. **选好参考相量**：串联电路选电流，并联电路选电压
3. **阻抗串并联**：先化简电路，再用分压/分流
4. **功率计算**：先求电压、电流相量，再用公式
5. **共轭匹配**：求戴维宁等效，令 $Z_L = Z_{eq}^*$
6. **谐振问题**：利用谐振条件 $\omega L = 1/(\omega C)$ 简化电路

## 附录 B：复数运算

直角坐标 → 极坐标：

$$
a+jb = \sqrt{a^2+b^2}\angle\arctan\frac{b}{a}
$$

极坐标 → 直角坐标：

$$
r\angle\theta = r\cos\theta + jr\sin\theta
$$

乘法：

$$
(r_1\angle\theta_1)(r_2\angle\theta_2) = r_1 r_2\angle(\theta_1+\theta_2)
$$

除法：

$$
\frac{r_1\angle\theta_1}{r_2\angle\theta_2} = \frac{r_1}{r_2}\angle(\theta_1-\theta_2)
$$

共轭：

$$
(a+jb)^* = a-jb, \quad (r\angle\theta)^* = r\angle(-\theta)
$$
