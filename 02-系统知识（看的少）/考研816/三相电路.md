# 三相电路

> **核心概念**：三相电源、星形/三角形连接、线电压/相电压、线电流/相电流、对称/不对称三相电路、三相功率
>
> **重要程度**：★★★★★（考研816必考章节，几乎每年都有大题）
>
> **前置知识**：正弦稳态分析、相量法、功率计算

---

## 1. 三相电源

### 1.1 三相电动势的产生原理

三相发电机的定子上嵌放三组绕组（A-X、B-Y、C-Z），三组绕组匝数相同、结构相同，空间位置互差 $120°$。当转子（磁极）以角速度 $\omega$ 匀速旋转时，三组绕组中分别感应出频率相同、幅值相等、相位互差 $120°$ 的正弦电动势。

### 1.2 对称三相电源的数学表达

对称三相电源的三个电动势满足：
- **幅值相等**：$E_{Am} = E_{Bm} = E_{Cm} = E_m$
- **频率相同**：$\omega_A = \omega_B = \omega_C = \omega$
- **相位互差 $120°$**

以 A 相为参考（初相为 $0°$），三相电动势的瞬时值表达式为：

$$e_A = E_m \sin(\omega t)$$

$$e_B = E_m \sin(\omega t - 120°)$$

$$e_C = E_m \sin(\omega t - 240°) = E_m \sin(\omega t + 120°)$$

对应的相量形式为：

$$\dot{E}_A = E \angle 0°$$

$$\dot{E}_B = E \angle -120° = a^2 \dot{E}_A$$

$$\dot{E}_C = E \angle 120° = a \dot{E}_A$$

其中 $a = 1 \angle 120° = -\frac{1}{2} + j\frac{\sqrt{3}}{2}$，称为**旋转因子**，满足：

$$a^2 = 1 \angle 240° = 1 \angle -120° = -\frac{1}{2} - j\frac{\sqrt{3}}{2}$$

$$a^3 = 1, \quad 1 + a + a^2 = 0$$

### 1.3 对称三相电源的重要性质

对称三相电动势之和恒为零：

$$e_A + e_B + e_C = 0$$

$$\dot{E}_A + \dot{E}_B + \dot{E}_C = 0$$

这是对称三相电路简化计算的理论基础。

### 1.4 相序

**相序**（相位顺序）：三相电动势达到最大值（或零值）的先后顺序。

- **正序（顺序）**：A → B → C，即 A 相超前 B 相 $120°$，B 相超前 C 相 $120°$。记为 A-B-C。
- **负序（逆序）**：A → C → B，即 A 相超前 C 相 $120°$，C 相超前 B 相 $120°$。记为 A-C-B。

> **注意**：电力系统中默认采用正序。相序的改变只需将三相电源中任意两相对调即可。

### 1.5 三相电源的连接方式

三相电源有两种基本连接方式：**星形（Y）连接**和**三角形（$\triangle$）连接**。

## 2. 星形（Y）连接

### 2.1 连接方式

将三相电源的末端（X、Y、Z）连接在一起，形成一个公共点，称为**中性点**（中点），用 N 表示。从三个始端（A、B、C）引出三条线，称为**端线**（火线）。从中性点引出的线称为**中性线**（中线/零线）。

### 2.2 基本物理量

- **相电压**：端线与中性线之间的电压，即每相电源（或负载）两端的电压。
  - $\dot{U}_{AN}$、$\dot{U}_{BN}$、$\dot{U}_{CN}$

- **线电压**：任意两条端线之间的电压。
  - $\dot{U}_{AB}$、$\dot{U}_{BC}$、$\dot{U}_{CA}$

- **线电流**：流过端线的电流。
  - $\dot{I}_A$、$\dot{I}_B$、$\dot{I}_C$

- **相电流**：流过每相电源（或负载）的电流。

### 2.3 线电压与相电压的关系

由 KVL：

$$\dot{U}_{AB} = \dot{U}_{AN} - \dot{U}_{BN}$$

$$\dot{U}_{BC} = \dot{U}_{BN} - \dot{U}_{CN}$$

$$\dot{U}_{CA} = \dot{U}_{CN} - \dot{U}_{AN}$$

**对称情况下**，设 $\dot{U}_{AN} = U_p \angle 0°$，则：

$$\dot{U}_{AB} = U_p \angle 0° - U_p \angle -120° = U_p \left(1 - \left(-\frac{1}{2} - j\frac{\sqrt{3}}{2}\right)\right) = U_p \left(\frac{3}{2} + j\frac{\sqrt{3}}{2}\right)$$

$$\dot{U}_{AB} = \sqrt{3} U_p \angle 30°$$

同理：

$$\dot{U}_{BC} = \sqrt{3} U_p \angle -90°$$

$$\dot{U}_{CA} = \sqrt{3} U_p \angle 150°$$

**结论**：

$$\boxed{U_l = \sqrt{3} \, U_p}$$

- 线电压是相电压的 $\sqrt{3}$ 倍
- 线电压超前对应相电压 $30°$
- 三个线电压也是对称的

### 2.4 线电流与相电流的关系

在星形连接中，**线电流等于相电流**：

$$\boxed{I_l = I_p}$$

### 2.5 中性线的作用

- **对称负载**：中性线电流为零（$\dot{I}_N = \dot{I}_A + \dot{I}_B + \dot{I}_C = 0$），中性线无电流流过，可省略。
- **不对称负载**：中性线电流不为零，中性线必须存在。中性线的作用是**强制中性点等电位**，保证各相负载电压对称。

### 2.6 相量图

对称星形连接的相量图绘制要点：
1. 画出三相对称相电压 $\dot{U}_{AN}$、$\dot{U}_{BN}$、$\dot{U}_{CN}$，互差 $120°$。
2. 线电压 $\dot{U}_{AB}$ 由 $\dot{U}_{AN} - \dot{U}_{BN}$ 得到，超前 $\dot{U}_{AN}$ 为 $30°$。
3. 线电压幅值为相电压的 $\sqrt{3}$ 倍。

## 3. 三角形（$\triangle$）连接

### 3.1 连接方式

将三相电源依次首尾相连（A→Z、B→X、C→Y），形成闭合回路。从三个连接点引出三条端线。

### 3.2 基本物理量

- **相电压**：每相电源两端的电压。
- **线电压**：端线间的电压。

### 3.3 线电压与相电压的关系

在三角形连接中，**线电压等于相电压**：

$$\boxed{U_l = U_p}$$

$$\dot{U}_{AB} = \dot{E}_A, \quad \dot{U}_{BC} = \dot{E}_B, \quad \dot{U}_{CA} = \dot{E}_C$$

### 3.4 线电流与相电流的关系

由 KCL，在节点 A 处：

$$\dot{I}_A = \dot{I}_{AB} - \dot{I}_{CA}$$

在节点 B 处：

$$\dot{I}_B = \dot{I}_{BC} - \dot{I}_{AB}$$

在节点 C 处：

$$\dot{I}_C = \dot{I}_{CA} - \dot{I}_{BC}$$

**对称情况下**，设 $\dot{I}_{AB} = I_p \angle 0°$，则：

$$\dot{I}_A = I_p \angle 0° - I_p \angle 120° = I_p \left(1 - \left(-\frac{1}{2} + j\frac{\sqrt{3}}{2}\right)\right) = I_p \left(\frac{3}{2} - j\frac{\sqrt{3}}{2}\right)$$

$$\dot{I}_A = \sqrt{3} I_p \angle -30°$$

同理：

$$\dot{I}_B = \sqrt{3} I_p \angle -150°$$

$$\dot{I}_C = \sqrt{3} I_p \angle 90°$$

**结论**：

$$\boxed{I_l = \sqrt{3} \, I_p}$$

- 线电流是相电流的 $\sqrt{3}$ 倍
- 线电流滞后对应相电流 $30°$
- 三个线电流也是对称的

### 3.5 三角形连接的注意事项

三角形连接的电源，回路中总电动势为零（对称时）：

$$\dot{E}_A + \dot{E}_B + \dot{E}_C = 0$$

若三相电源不对称，回路中将产生环流，可能导致电源烧毁。因此**三角形连接的电源必须对称**。

### 3.6 Y 连接与 $\triangle$ 连接对比

| 项目 | Y 连接 | $\triangle$ 连接 |
|------|--------|-----------------|
| 线电压与相电压 | $U_l = \sqrt{3} U_p$ | $U_l = U_p$ |
| 线电流与相电流 | $I_l = I_p$ | $I_l = \sqrt{3} I_p$ |
| 有无中性点 | 有 | 无 |
| 中性线 | 可引出 | 无法引出 |

## 4. 对称三相电路的计算

### 4.1 三相电路的连接方式

三相电路由三相电源和三相负载组成，电源和负载各有 Y 和 $\triangle$ 两种连接方式，因此有四种组合：
- **Y-Y 系统**
- **Y-$\triangle$ 系统**
- **$\triangle$-Y 系统**
- **$\triangle$-$\triangle$ 系统**

### 4.2 Y-Y 系统（三相四线制，有中线）

**电路结构**：三相电源 Y 连接，三相负载 Y 连接，有中性线。

**计算方法**：

由于中性线的存在，各相独立。取单相（A 相）计算：

$$\dot{I}_A = \frac{\dot{U}_{AN}}{Z}$$

由对称性：

$$\dot{I}_B = \dot{I}_A \angle -120°, \quad \dot{I}_C = \dot{I}_A \angle 120°$$

中性线电流：

$$\dot{I}_N = \dot{I}_A + \dot{I}_B + \dot{I}_C = 0$$

### 4.3 Y-Y 系统（三相三线制，无中线）

**电路结构**：三相电源 Y 连接，三相负载 Y 连接，无中性线。

**计算方法**：

对称情况下，中性点 N 和 N' 等电位，即 $\dot{U}_{N'N} = 0$。各相仍然独立，计算方法与有中线时相同。

> **重要结论**：对称 Y-Y 系统中，有无中线不影响计算结果。中性线可以省略。

### 4.4 Y-$\triangle$ 系统

**电路结构**：三相电源 Y 连接，三相负载 $\triangle$ 连接。

**计算步骤**：

1. 已知电源相电压 $\dot{U}_{AN}$、$\dot{U}_{BN}$、$\dot{U}_{CN}$。
2. 计算线电压（即负载的相电压）：
   $$\dot{U}_{AB} = \sqrt{3} \dot{U}_{AN} \angle 30°$$
3. 计算负载的相电流：
   $$\dot{I}_{AB} = \frac{\dot{U}_{AB}}{Z}$$
4. 计算线电流：
   $$\dot{I}_A = \sqrt{3} \dot{I}_{AB} \angle -30°$$

### 4.5 $\triangle$-Y 系统

**电路结构**：三相电源 $\triangle$ 连接，三相负载 Y 连接。

**计算步骤**：

1. 已知电源相电压（即线电压）$\dot{U}_{AB}$、$\dot{U}_{BC}$、$\dot{U}_{CA}$。
2. 计算负载的相电压：
   $$\dot{U}_{AN'} = \frac{\dot{U}_{AB}}{\sqrt{3}} \angle -30°$$
3. 计算负载的相电流（即线电流）：
   $$\dot{I}_A = \frac{\dot{U}_{AN'}}{Z}$$

### 4.6 $\triangle$-$\triangle$ 系统

**电路结构**：三相电源 $\triangle$ 连接，三相负载 $\triangle$ 连接。

**计算步骤**：

1. 线电压等于电源相电压：$\dot{U}_{AB} = \dot{E}_A$
2. 负载相电压等于线电压：$\dot{U}_{AB}' = \dot{U}_{AB}$
3. 计算负载相电流：$\dot{I}_{AB} = \frac{\dot{U}_{AB}'}{Z}$
4. 计算线电流：$\dot{I}_A = \sqrt{3} \dot{I}_{AB} \angle -30°$

### 4.7 单相等效电路法（一相计算法）

**核心思想**：对称三相电路中，利用对称性，只计算一相，其余两相由对称关系直接写出。

**适用条件**：电路对称（电源对称、负载对称、线路阻抗对称）。

**解题步骤**：

1. **判断电路是否对称**。
2. **将 $\triangle$ 连接的电源或负载等效变换为 Y 连接**（若需要）。
3. **画出单相等效电路**（通常取 A 相）：
   - 对于 Y-Y 系统（无中线）：对称时中性点等电位，可将中性点短接。
   - 单相电路为：电源相电压 → 线路阻抗 → 负载阻抗。
4. **计算单相电路的电流和电压**。
5. **由对称关系写出其余两相的电流和电压**。
6. **回到原电路，计算所需的线电压、线电流等**。

### 4.8 $\triangle$-Y 等效变换

将 $\triangle$ 连接的阻抗 $Z_{\triangle}$ 等效变换为 Y 连接的阻抗 $Z_Y$：

$$\boxed{Z_Y = \frac{Z_{\triangle}}{3}}$$

此公式仅适用于**对称**的 $\triangle$ 连接负载（三个阻抗相等）。

一般情况下的 $\triangle$→Y 变换公式：

$$Z_1 = \frac{Z_{12} Z_{31}}{Z_{12} + Z_{23} + Z_{31}}$$

$$Z_2 = \frac{Z_{12} Z_{23}}{Z_{12} + Z_{23} + Z_{31}}$$

$$Z_3 = \frac{Z_{23} Z_{31}}{Z_{12} + Z_{23} + Z_{31}}$$

### 4.9 典型例题 1：Y-Y 对称三相电路

**题目**：对称三相电路，电源线电压 $U_l = 380\text{V}$，频率 $f = 50\text{Hz}$。每相负载阻抗 $Z = 6 + j8 \, \Omega$。求各相电流和线电流。

**解**：

（1）取 A 相计算，电源相电压：

$$U_p = \frac{U_l}{\sqrt{3}} = \frac{380}{\sqrt{3}} = 220 \text{V}$$

设 $\dot{U}_{AN} = 220 \angle 0° \text{V}$

（2）A 相电流：

$$\dot{I}_A = \frac{\dot{U}_{AN}}{Z} = \frac{220 \angle 0°}{6 + j8} = \frac{220 \angle 0°}{10 \angle 53.13°} = 22 \angle -53.13° \text{A}$$

（3）由对称性：

$$\dot{I}_B = 22 \angle -173.13° \text{A}$$

$$\dot{I}_C = 22 \angle 66.87° \text{A}$$

（4）Y 连接中线电流等于相电流，$I_l = I_p = 22 \text{A}$。

### 4.10 典型例题 2：Y-$\triangle$ 对称三相电路

**题目**：对称三相电源，线电压 $U_l = 380\text{V}$。对称 $\triangle$ 负载，每相阻抗 $Z = 30 + j40 \, \Omega$。求负载相电流和线电流。

**解**：

（1）负载相电压等于线电压：

$$U_{AB} = U_l = 380 \text{V}$$

设 $\dot{U}_{AB} = 380 \angle 0° \text{V}$

（2）负载相电流：

$$\dot{I}_{AB} = \frac{\dot{U}_{AB}}{Z} = \frac{380 \angle 0°}{30 + j40} = \frac{380 \angle 0°}{50 \angle 53.13°} = 7.6 \angle -53.13° \text{A}$$

（3）由对称性：

$$\dot{I}_{BC} = 7.6 \angle -173.13° \text{A}$$

$$\dot{I}_{CA} = 7.6 \angle 66.87° \text{A}$$

（4）线电流：

$$\dot{I}_A = \sqrt{3} \dot{I}_{AB} \angle -30° = \sqrt{3} \times 7.6 \angle -83.13° = 13.16 \angle -83.13° \text{A}$$

$$I_l = \sqrt{3} \times 7.6 = 13.16 \text{A}$$

### 4.11 典型例题 3：含线路阻抗的 Y-Y 系统

**题目**：对称三相电路，电源相电压 $U_p = 220\text{V}$，线路阻抗 $Z_l = 1 + j2 \, \Omega$，负载阻抗 $Z = 9 + j12 \, \Omega$。求负载相电压和相电流。

**解**：

（1）取 A 相等效电路，设 $\dot{U}_{AN} = 220 \angle 0° \text{V}$

（2）A 相电流：

$$\dot{I}_A = \frac{\dot{U}_{AN}}{Z_l + Z} = \frac{220 \angle 0°}{(1+j2) + (9+j12)} = \frac{220 \angle 0°}{10 + j14} = \frac{220 \angle 0°}{17.20 \angle 54.46°} = 12.79 \angle -54.46° \text{A}$$

（3）负载相电压：

$$\dot{U}_{A'N'} = \dot{I}_A \cdot Z = 12.79 \angle -54.46° \times (9 + j12) = 12.79 \angle -54.46° \times 15 \angle 53.13° = 191.85 \angle -1.33° \text{V}$$

**注意**：负载相电压（191.85V）小于电源相电压（220V），差值为线路阻抗上的压降。

## 5. 不对称三相电路

### 5.1 不对称三相电路的定义

当以下任一条件不满足时，三相电路为不对称电路：
- 三相电源不对称（幅值不等或相位差不等于 $120°$）
- 三相负载不对称（各相阻抗不同）
- 线路阻抗不对称

实际中最常见的是**负载不对称**的情况。

### 5.2 不对称负载的分析方法

不对称三相电路**不能使用单相等效电路法**，必须用一般电路分析方法：
- **节点电压法**（最常用）
- **网孔电流法**
- **叠加定理**

### 5.3 中性点位移

**定义**：在不对称 Y-Y 系统（无中线）中，负载中性点 N' 与电源中性点 N 之间的电压 $\dot{U}_{N'N} \neq 0$，称为**中性点位移**。

**分析**：设三相负载阻抗分别为 $Z_A$、$Z_B$、$Z_C$（互不相等），由节点电压法：

$$\dot{U}_{N'N} = \frac{\frac{\dot{U}_{AN}}{Z_A} + \frac{\dot{U}_{BN}}{Z_B} + \frac{\dot{U}_{CN}}{Z_C}}{\frac{1}{Z_A} + \frac{1}{Z_B} + \frac{1}{Z_C}}$$

当负载对称时（$Z_A = Z_B = Z_C$），$\dot{U}_{N'N} = 0$，无中性点位移。

当负载不对称时，$\dot{U}_{N'N} \neq 0$，各相负载电压不再对称：

$$\dot{U}_{AN'} = \dot{U}_{AN} - \dot{U}_{N'N}$$

$$\dot{U}_{BN'} = \dot{U}_{BN} - \dot{U}_{N'N}$$

$$\dot{U}_{CN'} = \dot{U}_{CN} - \dot{U}_{N'N}$$

> **危险情况**：当中性点位移较大时，某些相的负载电压可能远超额定电压，导致设备损坏。

### 5.4 中性线的作用（不对称负载）

**有中线时**：中性线将负载中性点 N' 强制与电源中性点 N 等电位（忽略中性线阻抗），即 $\dot{U}_{N'N} = 0$。各相负载电压等于电源相电压，保证各相独立工作。

**无中线时**：中性点位移导致各相电压不对称，可能出现某相电压过高、某相电压过低的情况。

### 5.5 中性线阻抗的影响

当中性线有阻抗 $Z_N$ 时，中性点位移为：

$$\dot{U}_{N'N} = \frac{\frac{\dot{U}_{AN}}{Z_A} + \frac{\dot{U}_{BN}}{Z_B} + \frac{\dot{U}_{CN}}{Z_C}}{\frac{1}{Z_A} + \frac{1}{Z_B} + \frac{1}{Z_C} + \frac{1}{Z_N}}$$

- $Z_N = 0$ 时，$\dot{U}_{N'N} = 0$（完全消除中性点位移）
- $Z_N \to \infty$ 时（无中线），回到上面的公式
- $Z_N$ 越小，中性点位移越小

### 5.6 不对称三相电路的节点电压法解题步骤

1. **选定参考节点**（通常选电源中性点 N）。
2. **列写节点电压方程**，求解 $\dot{U}_{N'N}$。
3. **计算各相负载电压**：$\dot{U}_{AN'} = \dot{U}_{AN} - \dot{U}_{N'N}$ 等。
4. **计算各相电流**：$\dot{I}_A = \frac{\dot{U}_{AN'}}{Z_A}$ 等。
5. **计算中性线电流**：$\dot{I}_N = \frac{\dot{U}_{N'N}}{Z_N}$（有中线时）。

### 5.7 典型例题 4：不对称 Y-Y 系统（无中线）

**题目**：对称三相电源，相电压 $U_p = 220\text{V}$。三相负载不对称：$Z_A = 10 \, \Omega$，$Z_B = 10 \, \Omega$，$Z_C = 20 \, \Omega$（纯电阻）。无中线。求各相负载电压。

**解**：

（1）设 $\dot{U}_{AN} = 220 \angle 0°$，$\dot{U}_{BN} = 220 \angle -120°$，$\dot{U}_{CN} = 220 \angle 120°$

（2）中性点位移：

$$\dot{U}_{N'N} = \frac{\frac{220}{10} + \frac{220 \angle -120°}{10} + \frac{220 \angle 120°}{20}}{\frac{1}{10} + \frac{1}{10} + \frac{1}{20}}$$

分子：$22 + 22 \angle -120° + 11 \angle 120°$

$= 22 + 22(-0.5 - j0.866) + 11(-0.5 + j0.866)$

$= 22 - 11 - j18.86 - 5.5 + j9.53$

$= 5.5 - j9.33$

$= 10.83 \angle -59.5°$

分母：$0.1 + 0.1 + 0.05 = 0.25$

$$\dot{U}_{N'N} = \frac{10.83 \angle -59.5°}{0.25} = 43.32 \angle -59.5° \text{V}$$

（3）各相负载电压：

$$\dot{U}_{AN'} = 220 \angle 0° - 43.32 \angle -59.5° = 220 - 22.0 + j37.4 = 198.0 + j37.4 = 201.5 \angle 10.7° \text{V}$$

$$\dot{U}_{BN'} = 220 \angle -120° - 43.32 \angle -59.5° = (-110 - j190.5) - (22.0 - j37.4) = -132.0 - j153.1 = 202.2 \angle -130.7° \text{V}$$

$$\dot{U}_{CN'} = 220 \angle 120° - 43.32 \angle -59.5° = (-110 + j190.5) - (22.0 - j37.4) = -132.0 + j227.9 = 263.1 \angle 120.0° \text{V}$$

> **分析**：C 相负载电压（263.1V）明显高于电源相电压（220V），这是因为 C 相阻抗最大，分得的电压最高。这就是中性点位移的危害。

## 6. 三相电路的功率

### 6.1 三相功率的计算

#### 6.1.1 有功功率

三相总有功功率等于各相有功功率之和：

$$P = P_A + P_B + P_C = U_{pA} I_{pA} \cos\varphi_A + U_{pB} I_{pB} \cos\varphi_B + U_{pC} I_{pC} \cos\varphi_C$$

其中 $\varphi_A$、$\varphi_B$、$\varphi_C$ 为各相电压与电流的相位差。

**对称三相电路**（$U_p$、$I_p$、$\cos\varphi$ 各相相同）：

$$\boxed{P = 3 U_p I_p \cos\varphi}$$

用线电压和线电流表示（无论 Y 还是 $\triangle$ 连接）：

$$\boxed{P = \sqrt{3} \, U_l I_l \cos\varphi}$$

> **注意**：$\varphi$ 是相电压与相电流的相位差（即每相负载的阻抗角），**不是**线电压与线电流的相位差。

#### 6.1.2 无功功率

$$Q = Q_A + Q_B + Q_C$$

**对称三相电路**：

$$\boxed{Q = 3 U_p I_p \sin\varphi = \sqrt{3} \, U_l I_l \sin\varphi}$$

#### 6.1.3 视在功率

$$S = \sqrt{P^2 + Q^2}$$

**对称三相电路**：

$$\boxed{S = 3 U_p I_p = \sqrt{3} \, U_l I_l}$$

#### 6.1.4 功率因数

**对称三相电路**：

$$\cos\varphi = \frac{P}{S} = \frac{P}{\sqrt{3} U_l I_l}$$

### 6.2 对称三相电路的瞬时功率

**重要结论**：对称三相电路的瞬时功率为常数，等于有功功率 $P$。

**推导**：

$$p = p_A + p_B + p_C = u_A i_A + u_B i_B + u_C i_C$$

设 $u_A = \sqrt{2} U_p \sin\omega t$，$i_A = \sqrt{2} I_p \sin(\omega t - \varphi)$

则：

$$p_A = U_p I_p \cos\varphi - U_p I_p \cos(2\omega t - \varphi)$$

$$p_B = U_p I_p \cos\varphi - U_p I_p \cos(2\omega t - \varphi + 120°)$$

$$p_C = U_p I_p \cos\varphi - U_p I_p \cos(2\omega t - \varphi - 120°)$$

三项中频率为 $2\omega$ 的分量互差 $120°$，其和为零。

$$\boxed{p = 3 U_p I_p \cos\varphi = P = \text{常数}}$$

> **物理意义**：对称三相电路的瞬时功率恒定，这是三相制的重要优点。对于电动机等旋转机械，恒定的瞬时功率意味着**转矩恒定**，运行更平稳，振动更小。

### 6.3 三相功率的测量

#### 6.3.1 三瓦特计法

适用于**三相四线制**系统（有中线），无论负载是否对称。

**方法**：用三个瓦特计分别测量三相的有功功率。

$$P = P_1 + P_2 + P_3$$

每个瓦特计的读数为对应相的有功功率：

$$P_1 = U_{AN} I_A \cos\varphi_A$$

$$P_2 = U_{BN} I_B \cos\varphi_B$$

$$P_3 = U_{CN} I_C \cos\varphi_C$$

**对称时**：$P_1 = P_2 = P_3 = U_p I_p \cos\varphi$，只需一个瓦特计，$P = 3P_1$。

#### 6.3.2 两瓦特计法

适用于**三相三线制**系统（无中线），无论负载是否对称、是否对称。

**接线方式**：
- 瓦特计 $W_1$：电流线圈串入 A 线，电压线圈并联在 A、B 线之间。
- 瓦特计 $W_2$：电流线圈串入 C 线，电压线圈并联在 C、B 线之间。
- 两个瓦特计的电压线圈的公共端（标 * 端）都接在 B 线。

**读数**：

$$P_1 = U_{AB} I_A \cos\varphi_1$$

$$P_2 = U_{CB} I_C \cos\varphi_2$$

其中 $\varphi_1$ 是 $\dot{U}_{AB}$ 与 $\dot{I}_A$ 的相位差，$\varphi_2$ 是 $\dot{U}_{CB}$ 与 $\dot{I}_C$ 的相位差。

**总功率**：

$$\boxed{P = P_1 + P_2}$$

**证明**（对称情况）：

设 $\dot{U}_{AN} = U_p \angle 0°$，$\dot{I}_A = I_p \angle -\varphi$

$$\dot{U}_{AB} = \sqrt{3} U_p \angle 30°$$

$$P_1 = U_{AB} I_A \cos(30° + \varphi) = \sqrt{3} U_p I_p \cos(30° + \varphi)$$

$$P_2 = U_{CB} I_C \cos(30° - \varphi) = \sqrt{3} U_p I_p \cos(30° - \varphi)$$

$$P_1 + P_2 = \sqrt{3} U_p I_p [\cos(30° + \varphi) + \cos(30° - \varphi)]$$

利用和差化积：

$$= \sqrt{3} U_p I_p \cdot 2 \cos 30° \cos\varphi = \sqrt{3} U_p I_p \cdot \sqrt{3} \cos\varphi = 3 U_p I_p \cos\varphi$$

**对称负载时两个瓦特计读数的特点**：

| $\varphi$ | $P_1$ | $P_2$ | $P$ |
|-----------|-------|-------|-----|
| $0°$（纯阻）| $P_1 > 0$ | $P_2 > 0$ | $P_1 = P_2$ |
| $\pm 60°$ | 一个为零 | 另一个为 $P$ | $P = 2P_1$ 或 $2P_2$ |
| $\pm 90°$ | $P_1 = -P_2$ | — | $P = 0$ |

> **重要结论**：当 $|\varphi| > 60°$ 时，$P_1$ 和 $P_2$ 中有一个为负值，该瓦特计**反转**。此时需要将该瓦特计的电流线圈（或电压线圈）**反接**，读数取负值。

#### 6.3.3 两瓦特计法的适用条件

1. 适用于**三相三线制**（无中线），因为推导基于 $\dot{I}_A + \dot{I}_B + \dot{I}_C = 0$。
2. 无论负载是否对称。
3. 无论负载是 Y 还是 $\triangle$ 连接。
4. **不适用于三相四线制**（有中线且中线有电流时）。

### 6.4 典型例题 5：三相功率计算

**题目**：对称三相负载，线电压 $U_l = 380\text{V}$，线电流 $I_l = 10\text{A}$，功率因数 $\cos\varphi = 0.8$（滞后）。求三相有功功率、无功功率和视在功率。

**解**：

$$P = \sqrt{3} U_l I_l \cos\varphi = \sqrt{3} \times 380 \times 10 \times 0.8 = 5265 \text{W}$$

$$\sin\varphi = \sqrt{1 - 0.8^2} = 0.6$$

$$Q = \sqrt{3} U_l I_l \sin\varphi = \sqrt{3} \times 380 \times 10 \times 0.6 = 3949 \text{var}$$

$$S = \sqrt{3} U_l I_l = \sqrt{3} \times 380 \times 10 = 6582 \text{VA}$$

验证：$S = \sqrt{P^2 + Q^2} = \sqrt{5265^2 + 3949^2} = 6582 \text{VA}$ ✓

### 6.5 典型例题 6：两瓦特计法

**题目**：对称三相负载，线电压 $U_l = 380\text{V}$，线电流 $I_l = 20\text{A}$，功率因数 $\cos\varphi = 0.5$（滞后）。用两瓦特计法测量功率，求两个瓦特计的读数。

**解**：

$\varphi = \arccos 0.5 = 60°$

$$P_1 = \sqrt{3} U_p I_p \cos(30° + \varphi) = \sqrt{3} \times 220 \times 20 \times \cos 90° = 0 \text{W}$$

$$P_2 = \sqrt{3} U_p I_p \cos(30° - \varphi) = \sqrt{3} \times 220 \times 20 \times \cos(-30°) = \sqrt{3} \times 220 \times 20 \times 0.866 = 6582 \text{W}$$

验证：$P = P_1 + P_2 = 0 + 6582 = 6582 \text{W}$

直接计算：$P = \sqrt{3} \times 380 \times 20 \times 0.5 = 6582 \text{W}$ ✓

## 7. 典型题型总结

### 7.1 题型一：对称三相电路的计算

**解题思路**：
1. 判断是否对称。
2. 统一连接方式（$\triangle$ → Y 变换：$Z_Y = Z_\triangle / 3$）。
3. 画单相等效电路（取 A 相）。
4. 计算 A 相电流、电压。
5. 由对称性写出其余两相。
6. 回到原电路，计算线量。

**注意事项**：
- Y 连接：$I_l = I_p$，$U_l = \sqrt{3} U_p$
- $\triangle$ 连接：$U_l = U_p$，$I_l = \sqrt{3} I_p$
- 功率公式中 $\varphi$ 是相电压与相电流的夹角

### 7.2 题型二：不对称三相电路的分析

**解题思路**：
1. 判断不对称的原因（负载不对称最常见）。
2. 用节点电压法求 $\dot{U}_{N'N}$。
3. 计算各相负载电压和电流。
4. 分析中性点位移的影响。

**注意事项**：
- 不对称时不能用单相等效电路法。
- 有中线（$Z_N = 0$）时 $\dot{U}_{N'N} = 0$，各相独立。
- 无中线时必须先求 $\dot{U}_{N'N}$。

### 7.3 题型三：三相功率的测量与计算

**解题思路**：
1. 三相四线制用三瓦特计法。
2. 三相三线制用两瓦特计法。
3. 对称时 $P = \sqrt{3} U_l I_l \cos\varphi$。
4. 两瓦特计法：$P = P_1 + P_2$，$P_1 - P_2$ 与 $\varphi$ 有关。

### 7.4 题型四：Y-$\triangle$ 连接的转换

**应用场景**：
- 电源 Y 连接、负载 $\triangle$ 连接时，需将 $\triangle$ 负载等效变换为 Y 负载，才能画单相等效电路。
- 对称时：$Z_Y = Z_\triangle / 3$。
- 不对称时用一般 $\triangle$-Y 变换公式。

### 7.5 典型例题 7：综合题

**题目**：对称三相电源，线电压 $U_l = 380\text{V}$。对称三相负载为 $\triangle$ 连接，每相阻抗 $Z = 30 + j40 \, \Omega$。线路阻抗每相 $Z_l = 1 + j2 \, \Omega$。求：（1）线电流；（2）负载相电流；（3）负载的三相有功功率。

**解**：

（1）将 $\triangle$ 负载等效变换为 Y 负载：

$$Z_Y = \frac{Z_\triangle}{3} = \frac{30 + j40}{3} = 10 + j13.33 \, \Omega$$

（2）取 A 相等效电路，设 $\dot{U}_{AN} = 220 \angle 0° \text{V}$

$$\dot{I}_A = \frac{\dot{U}_{AN}}{Z_l + Z_Y} = \frac{220 \angle 0°}{(1+j2) + (10+j13.33)} = \frac{220 \angle 0°}{11 + j15.33}$$

$$= \frac{220 \angle 0°}{18.87 \angle 54.3°} = 11.66 \angle -54.3° \text{A}$$

线电流 $I_l = 11.66 \text{A}$

（3）回到原 $\triangle$ 电路，负载的线电压等于 $Z_Y$ 上的电压加上 $\triangle$ 连接点的电压关系。实际上，$\triangle$ 负载的相电流等于变换前 $\triangle$ 负载中的电流：

$$I_{p\triangle} = \frac{I_l}{\sqrt{3}} = \frac{11.66}{\sqrt{3}} = 6.73 \text{A}$$

（4）三相有功功率：

$$P = 3 I_{p\triangle}^2 R_\triangle = 3 \times 6.73^2 \times 30 = 3 \times 45.29 \times 30 = 4076 \text{W}$$

或：

$$P = 3 I_l^2 R_Y = 3 \times 11.66^2 \times 10 = 3 \times 135.96 \times 10 = 4079 \text{W}$$

（微小差异由舍入误差造成）

## 8. 公式速查表

### 8.1 基本关系

| 连接方式 | 线电压与相电压 | 线电流与相电流 |
|---------|--------------|--------------|
| Y 连接 | $U_l = \sqrt{3} U_p$ | $I_l = I_p$ |
| $\triangle$ 连接 | $U_l = U_p$ | $I_l = \sqrt{3} I_p$ |

### 8.2 对称三相电路功率公式

| 物理量 | 用相量表示 | 用线量表示 |
|-------|----------|----------|
| 有功功率 $P$ | $3 U_p I_p \cos\varphi$ | $\sqrt{3} U_l I_l \cos\varphi$ |
| 无功功率 $Q$ | $3 U_p I_p \sin\varphi$ | $\sqrt{3} U_l I_l \sin\varphi$ |
| 视在功率 $S$ | $3 U_p I_p$ | $\sqrt{3} U_l I_l$ |

### 8.3 $\triangle$-Y 等效变换

对称情况：

$$Z_Y = \frac{Z_\triangle}{3}$$

一般情况：

$$Z_1 = \frac{Z_{12} Z_{31}}{Z_{12} + Z_{23} + Z_{31}}, \quad Z_2 = \frac{Z_{12} Z_{23}}{Z_{12} + Z_{23} + Z_{31}}, \quad Z_3 = \frac{Z_{23} Z_{31}}{Z_{12} + Z_{23} + Z_{31}}$$

### 8.4 两瓦特计法

$$P = P_1 + P_2$$

对称负载时：

$$P_1 = U_l I_l \cos(30° + \varphi)$$

$$P_2 = U_l I_l \cos(30° - \varphi)$$

$$P_1 - P_2 = U_l I_l [\cos(30° + \varphi) - \cos(30° - \varphi)] = -U_l I_l \sin\varphi$$

由此可得：

$$\tan\varphi = \sqrt{3} \cdot \frac{P_2 - P_1}{P_1 + P_2}$$

### 8.5 中性点位移

无中线时：

$$\dot{U}_{N'N} = \frac{\frac{\dot{U}_{AN}}{Z_A} + \frac{\dot{U}_{BN}}{Z_B} + \frac{\dot{U}_{CN}}{Z_C}}{\frac{1}{Z_A} + \frac{1}{Z_B} + \frac{1}{Z_C}}$$

有中线时（中线阻抗 $Z_N$）：

$$\dot{U}_{N'N} = \frac{\frac{\dot{U}_{AN}}{Z_A} + \frac{\dot{U}_{BN}}{Z_B} + \frac{\dot{U}_{CN}}{Z_C}}{\frac{1}{Z_A} + \frac{1}{Z_B} + \frac{1}{Z_C} + \frac{1}{Z_N}}$$

### 8.6 旋转因子

$$a = 1 \angle 120° = -\frac{1}{2} + j\frac{\sqrt{3}}{2}$$

$$a^2 = 1 \angle -120° = -\frac{1}{2} - j\frac{\sqrt{3}}{2}$$

$$a^3 = 1, \quad 1 + a + a^2 = 0$$

## 9. 常见易错点与注意事项

### 9.1 功率因数角 $\varphi$ 的取值

- $\varphi$ 是**相电压与相电流**的相位差，即负载阻抗角。
- **不是**线电压与线电流的相位差。
- 在 Y 连接中，线电压超前相电压 $30°$，但 $\varphi$ 不受影响。
- 在 $\triangle$ 连接中，线电流滞后相电流 $30°$，但 $\varphi$ 不受影响。

### 9.2 $\triangle$-Y 变换的适用条件

- 公式 $Z_Y = Z_\triangle / 3$ **仅适用于对称负载**。
- 不对称时必须用一般变换公式。
- 变换前后，外部端线的电压和电流不变。

### 9.3 两瓦特计法的接线

- 两个瓦特计的电流线圈分别串入两相（通常 A 和 C）。
- 两个瓦特计的电压线圈的**非公共端**分别接 A 和 C。
- **公共端**都接 B 相（参考相）。
- 接线方式不唯一，但公共端必须是同一相。

### 9.4 三相四线制与三相三线制

- 三相四线制：有中线，可提供两种电压（线电压和相电压）。
- 三相三线制：无中线，只能提供一种电压（线电压）。
- 对称 Y-Y 系统无中线时，中性点自然等电位，与有中线等效。

### 9.5 不对称负载的中线电流

不对称 Y 负载有中线时：

$$\dot{I}_N = \dot{I}_A + \dot{I}_B + \dot{I}_C \neq 0$$

中线有电流流过，中线不能省略。

### 10.1 高频考点

1. **对称三相电路的计算**（几乎必考）
   - Y-Y、Y-$\triangle$、$\triangle$-$\triangle$ 系统的电流、电压计算
   - 含线路阻抗的三相电路

2. **三相功率的计算**
   - 有功功率、无功功率、视在功率

   - 中性点位移的计算
   - 中性线的作用

### 10.2 解题技巧

1. **画图**：一定要画出电路图，标注已知量。
2. **取参考相量**：通常设 A 相电压为 $U_p \angle 0°$。
3. **统一连接方式**：遇到 $\triangle$ 负载，先等效变换为 Y。
4. **单相计算**：对称时只算一相，其余两相对称写出。
5. **验证**：用功率守恒或 KVL/KCL 验证结果。
