# 旧外脑资料查找与迁移

旧 `07-外脑` 工作流已归档。用户要求的73篇旧笔记保存在 `02-嵌入式日志/01-旧外脑/`，按原主题目录可查；不要在 `07-外脑` 或历史分支新增资料。

## 收到新资料时

- 新的嵌入式讨论、图纸分析、技术学习和设计进展，使用 `obsidian-journal`，写入 `02-嵌入式日志/YYYY-MM-DD/YYYY-MM-DD 事项主题.md`。
- 在开始前读取 [日志规则](../../../09-规则/Obsidian日志Skill.md)、目标日期下同事项日志和关联历史笔记；完整对话再读 [完整对话日志规范](../../../09-规则/完整对话日志规范.md)。
- 附件放入同日 `资料/事项主题/` 并从正文链接。保留来源与适用条件，分清参考资料、现场事实、推断、计划和待核参数。
- 与旧笔记有关时保留旧笔记原文，在新日志说明器件和项目边界后建立交叉链接；同一事项才合并进已有日志。

## 查找或迁移一份旧笔记时

1. 从 [旧外脑历史总览](../../../02-嵌入式日志/01-旧外脑/00-旧外脑历史总览.md) 进入对应主题。
2. 比较旧笔记、原始图纸/资料和当前日志，保留旧版本的独有来源、解释与待确认内容。
3. 在新的嵌入式日志中加入相关结论与来源链接；除非用户明确要求重写迁移，不复制整篇内容形成第二个现行版本。
4. 更新历史索引或相关引用，回读确认链接与来源有效。

Git 提交和推送按用户当前授权处理。
