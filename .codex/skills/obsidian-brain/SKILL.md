# Obsidian 外脑资料

先读取 vault 根目录 `README.md`、[外脑整理规范](../../../09-规则/外脑整理规范.md)、`07-外脑/00、外脑知识总览.md`，再读取目标专题的总览及相关笔记。解释知识概念或硬件时同时读取 [笔记规则](../../../09-规则/AI写笔记套路.md)。

- 用户指定位置优先，否则沿用 `07-外脑/知识领域/主题/` 的现有结构。笔记名明确说明资料或问题，不按日期重新组织整个外脑。
- 保留可用结论、适用条件、原始来源、解释与关键例子；把当前现场事实、参考图纸事实、推断和待核内容分开。
- 附件归到相关主题资料位置并链接，不宜复制的原件保留原位置说明；无附件不建空目录。不自动公开敏感资料。
- 同一问题修订原篇，合并前比较全文并保留独有内容、来源和范围。更新专题总览及受影响链接。
- 需要写日期日志时读取 `../obsidian-journal/SKILL.md`；提炼为系统知识时读取 `../obsidian-notes/SKILL.md`。不默认生成多份重复正文。
- 回读来源、结论、待核项和链接；提交及推送 Git 依据用户授权。
